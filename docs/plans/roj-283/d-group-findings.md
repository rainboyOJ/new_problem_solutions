## `10014` 项链

| 项 | 结论 |
|---|---|
| **核心结论** | `main.cpp` **≡** `std.cpp`：**139,008 组**合成用例 **0 分歧** |
| **语义裁定** | 「回报」= **点不相交**（不是边不相交、不是可共享点） |
| **承重判据** | `V_share`（允许共享点）失败 **102,190** 组 ⇒ 该约束**真正承重** |
| 算法 | DAG 最大权路径 + 两套图结构两次拓扑排序 |
| 状态 | **R2 结论已得**（worker 被超时终止，报告未写）⇒ 只需补写报告与 R3 定稿 |

★ **为什么 `V_share` 是关键**：它把「回报」的两种可能语义**分开**了 ——
若两种语义在数据上等价，则 `V_share` 会显示 0 失败（= no-op，`T53`）；
而 102,190 的失败量说明**数据能分辨**这两种语义 ⇒ 裁定有承重。


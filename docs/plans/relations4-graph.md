## 目标与已确认决策

新增独立的 `/relations4` 二维题目关系图，保留默认 `/relations` 三维页面。借鉴 mn-site 的稳定布局、快速悬停反馈、渐进标签和紧凑控件，适配本站明暗主题。

- **全景**：默认展示全部具有关系的题目，隐藏孤立题。搜索覆盖整个题目目录。
- **分层**：围绕选中题目，按“前置题 → 当前题 → 后续题”分列；相似题单独成组，不表达学习先后。
- **悬停预览**：鼠标命中节点或标签后，下一帧突出它的直接关系。悬停优先于已选题目，移开后恢复选中状态；不重排节点、不自动移动视角、不请求接口。
- **点击选择**：锁定题目并更新详情。全景点击保持视角；搜索定位会把目标移到可见位置。分层点击关联题后，以该题重新展示直接关系。
- **模式切换**：保留选中题目；返回全景恢复原有位置与缩放，分层保留自己的滚动位置。未选择题目时，分层引导通过搜索或全景选择。
- **视觉层次**：默认关系线很淡；聚焦时突出直接前置、后续、相似关系，其他节点淡化。前置箭头始终从前置题指向后续题，相似关系使用虚线。
- **标签**：题号加短题名，按缩放和重要性渐进显示并避让；焦点显示完整题名。完整关系始终可从详情清单访问。
- **详情**：桌面左栏，手机底部抽屉；保留关系原因、题解入口、搜索、筛选、返回上一题和刷新。

这里的“分层”是直接学习关系的阅读视图，不是 mn-site 的课程分类树，也不把前置关系强行当成无环图。双向、环和同时存在的相似关系均按原始关系呈现。

## 实现约束

复用 `/api/relations` 以及现有无渲染依赖的数据归一化、邻接索引、URL 筛选语义，不修改题目关系元数据。新建 `relations4-graph/`，使用 Canvas 2D 全景、DOM 卡片与 SVG 连线分层。布局在 Worker 中计算，完成后静止；悬停仅查询邻接索引并重绘。

首次检查的真实数据规模为 3675 道题、1046 个关系节点、1304 条关系。验收时重新读取实际数据，不将这份快照当成固定数量断言。

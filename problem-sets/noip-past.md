# NOIP 历年真题题单

本题单整理全国青少年信息学奥林匹克联赛（NOIP）历年真题，收录 1996 到 2025 年，共 208 道题。

## 收录口径

- 只收录 NOIP 正赛真题，题号与命名以洛谷题库 `[NOIP 年份 组别]` 标注为准。
- **组别演变**：1996–2018 年分「提高组 / 普及组」两套试卷；2019 年 NOIP 停办（由 [CSP-S](/problem-sets/csp-s-past) / [CSP-J](/problem-sets/csp-j-past) 接替）；2020 年起恢复为单组赛制，洛谷统一标注 `[NOIP年份]`。
- 1999 年的「旅行家的预算」为普及组与提高组共用题，两组均收录（故分组条目数比实际题数多 2）。
- 洛谷对 1996–2000 年的早期真题收录不全（早年无完整存档），这些年份题数少于后来的每卷 4 题；这是史料缺失，不是本单遗漏。
- **难度**标注在每题末尾的中括号里，按洛谷现行 8 档体系：`入门` / `普及-` / `普及` / `普及+/提高-` / `提高` / `提高+/省选-` / `省选/NOI-` / `NOI/NOI+/CTS`。
- 标 `⚠️疑似错题` 的题目，是洛谷众测认为题目描述或数据存在问题的（早期题较常见）。仍可练思路，但不要纠结局部的对错判定。

## 这份题单的定位

NOIP 是 CSP-S 之前的老赛制，也是**从普及组过渡到提高组最完整的训练阶梯**：

1. **按组别循序渐进**：普及组卷面（T1–T4）基本对应 CSP-J 难度，提高组卷面（T1–T6）覆盖到 CSP-S 的 T2–T3 水平，正好填补两者之间的空档。
2. **真题密度高**：NOIP 从 2001 年起每年两卷共 8 题左右，二十余年积累了大量**经典母题**（如 2004 合并果子、2008 传纸条、2010 乌龟棋、2017 小凯的疑惑），是很多 CSP-S 真题的直接原型。
3. **适合整卷限时**：早期年份单题代码量小、思维门槛适中，很适合作为「一年一套、两小时限时」的日常训练。

> 衔接关系：NOIP 2019 停办后由 CSP-S 接替，2020 年恢复的 NOIP 单组赛制相当于原提高组。
> 现役赛制请看 [CSP-S 历年真题题单](/problem-sets/csp-s-past) 与 [CSP-J 历年真题题单](/problem-sets/csp-j-past)。

# 状态机 DP 训练题单

[rbook1 配套文章：状态机 DP](https://rbook.roj.ac.cn/dynamic_programming/state_machine/)

状态机动态规划的核心思想是：**“扫描到了哪里，以及到这里为止，哪些动作仍然合法？”**
当影响未来的历史特征只有极少数几种离散身份时，我们不必把完整的前缀历史全部保留，而是将方案划入对应的状态节点，画出有限状态转移图，并按时间或位置拓扑分层推进。

本题单分为四个递进模块，从最基础的选与不选互斥，逐步进阶到单向多阶段流水线、带 CD/规则循环流转以及模式自动机计数。

## 一、选与不选模型（相邻互斥与独立集）

核心思维：当前位置选择与否，直接决定了下一位置是否允许选择。设 $0$ 表示不选、$1$ 表示选择，图上禁止 $1 \to 1$ 转移。

- [ ] [[problem: leetcodecn,house-robber]]
  - 模型：打家劫舍基础原型。
  - 状态设计：$dp[i][0]$ 为前 $i$ 间且第 $i$ 间不偷的最大金额，$dp[i][1]$ 为偷第 $i$ 间的最大金额；由于相邻不能同时偷，禁止 $1\to 1$ 转移，空间可滚动优化至 $O(1)$。
- [ ] [[problem: roj,1301]]
  - 模型：大盗阿福（相邻店铺报警）。
  - 状态设计：与打家劫舍完全同构，$dp[i][0]=\max(dp[i-1][0], dp[i-1][1])$，$dp[i][1]=dp[i-1][0]+w_i$。
- [ ] [[problem: noi_openjudge,ch0206-8462]]
  - 模型：大盗阿福（NOI OpenJudge 版）。
  - 训练点：练习多组数据输入下的状态机初值重置与转移。
- [ ] [[problem: luogu,P1352]]
  - 模型：没有上司的舞会（树上选与不选）。
  - 状态设计：状态机由序列推广至树结构。$f[u][0]$ 表示上司不参会（下属自由参会或缺席），$f[u][1]$ 表示上司参会（所有下属强制缺席），自底向上后序遍历合并。
- [ ] [[problem: roj,3148]]
  - 模型：没有上司的舞会（ROJ 对应题面）。

## 二、单向多阶段流水线（严格单向流动与区间限制）

核心思维：问题中存在“至多操作一个连续区间”或“至多交易 $k$ 次”的全局约束。状态划分出“操作前、操作中、操作后”，状态沿时间严格单向流动，**严禁逆向边**以避免造出包含多个分离区间的非法方案。

- [ ] [[problem: codeforces,1155D]]
  - 模型：Beautiful Array（区间乘 $x$ 后最大子段和，rbook1 教学原题）。
  - 状态设计：划分单向 3 阶段——0 态（操作前）、1 态（操作中，元素乘 $x$）、2 态（操作后恢复原值）。转移只允许 $0\to 0/1$、$1\to 1/2$、$2\to 2$，利用不可达标记处理起点与终点。
- [ ] [[problem: codeforces,1373D]]
  - 模型：Maximum Sum on Even Positions（翻转至多一个区间求偶数位最大和）。
  - 状态设计：翻转偶长区间的本质也是单向三阶段（翻转前、翻转中奇偶项贡献反转、翻转后）；也可将相邻项两两打包转化为最大子段和状态机。
- [ ] [[problem: noi_openjudge,ch0206-8464]]
  - 模型：股票买卖（至多交易两次）。
  - 状态设计：将两次买卖展开为 5 个单向流动阶段：未买入 $\to$ 第一次买入持股 $\to$ 第一次卖出 $\to$ 第二次买入持股 $\to$ 第二次卖出。
- [ ] [[problem: roj,1302]]
  - 模型：股票买卖（ROJ 对应题面）。
  - 训练点：对比“单向 5 阶段状态机流转”与“前后缀最优值单点枚举解耦”两种视角的等价性。

## 三、循环状态与带规则冷却（CD 机制与有限模式切换）

核心思维：动作可多次发生（状态图带环），但每种动作受到特定冷却规则或连续步数制约。关键在于**将具有不同未来合法性的历史明确拆分为独立状态**（例如将不持股拆为“可买”与“刚卖冷冻”）。

- [ ] [[problem: leetcodecn,best-time-to-buy-and-sell-stock]]
  - 模型：买卖股票的最佳时机（单次交易）。
  - 状态设计：维护不持股与持股 2 状态基础流转。
- [ ] [[problem: luogu,U613136]]
  - 模型：买卖股票的最佳时机 II（无限次交易）。
  - 状态设计：持股与不持股的无冷却无限循环流转。
- [ ] [[problem: luogu,P1968]]
  - 模型：美元汇率。
  - 状态设计：每天在“持有美元”与“持有马克”两个有限状态间按当日汇率互相兑换，两状态线性 DP 滚动求最优值。
- [ ] [[problem: roj,3612]]
  - 模型：[NOIP2013-提高] 花匠。
  - 状态设计：最长波浪抖动子序列。滚动维护两个状态：`up`（末段处于上升峰）与 `down`（末段处于下降谷），交替流转完成 $O(n)$ 转移。
- [ ] [[problem: luogu,P2627]]
  - 模型：[USACO11OPEN] 修剪草坪。
  - 状态设计：连续选择不超过 $k$ 个的限制，逆向转化为“任意相邻两个不选的位置距离不超过 $k+1$”，状态机转移结合单调队列优化至 $O(n)$。

## 四、有限状态自动机与分段计数（模式匹配与阶段乘积）

核心思维：将数位或字符前缀的先后匹配约束压缩为有限状态自动机（DFA），在状态机转移图上递推统计合法路径数或匹配方案数。

- [ ] [[problem: shumeng,CSP201312D]]
  - 模型：有趣的数。
  - 状态设计：把数字 0/1 与 2/3 的先后出现限制分别压缩为三态（未出现、仅出现前者、两者皆出现），组成 $3\times 3=9$ 个状态的自动机转移计数 DP。
- [ ] [[problem: roj,3632]]
  - 模型：[noip2015-提高] 子串。
  - 状态设计：扫描主串 $A$ 与目标串 $B$，设计双状态 $f$（不以当前位置为子串结尾）与 $g$（以当前位置延续或新开子串），在已划分 $k$ 段的阶段上完成状态机递推。

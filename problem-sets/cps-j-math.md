# CSP-J 数学知识题单

这份题单用于训练 CSP-J 中常见的数学思维。CSP-J 的数学通常不是难在高等数学，而是难在：

```text
把题意翻译成数学关系。
```

做题时不要只问“这题是什么算法”，更要问：

```text
这个题的条件能不能变成一个谓词？
合法不好数，能不能数非法？
有没有必然成立的条件？
有没有冲突？
有没有单调性、周期性、奇偶性？
能不能用取整、余数、前缀和或差分表达？
```

## 1. 整数基础

这是 CSP-J 最常用的数学基础，重点是整数运算、取整、边界和十进制拆位。

需要掌握：

- 奇偶性
- 正负数
- 绝对值
- 最大值、最小值
- 整除
- 约数、倍数
- 余数
- 向上取整、向下取整

常见代码形式：

```cpp
x % 2
a % b
(a + b - 1) / b
```

很多 T1/T2 都不是思路难，而是取整和边界写错。

- [ ] [[problem: luogu,P2669]]

- [ ] [[problem: luogu,P1307]]

## 3. 最大公约数与最小公倍数

- lcm
- 辗转相除法
- 互质
- 分数化简

公式：

```cpp

lcm(a, b) = a / gcd(a, b) * b
```

## 5. 代数变形

这几年 CSP-J 常把数学藏在题意里。关键不是背公式，而是把题目条件改写成可判断的等式或不等式。

- 一元一次方程
- 二元关系
- 简单不等式
- 平方、开方
- 判别式思想
- 把题目条件转成公式

核心问题：


- [ ] [[problem: luogu,P1109]]

- [ ] [[problem: luogu,P1008]]

## 6. 计数基础

计数是 CSP-J 很重要的数学能力。很多题不是“模拟所有情况”，而是把合法条件转成一个可以直接计算的数量。

需要掌握：

- 加法原理
- 乘法原理
- 补集计数
- 简单排列组合
- 去重
- 分类讨论

```text
合法不好数，就数非法。
非法 = 条件 A 不满足 且 条件 B 不满足。
如果两个选择独立，就用乘法规则。
```

## 10. 数列、前缀和、差分

前缀和和差分严格说偏算法，但它们背后是数学表达：把区间和、区间修改、相邻变化写成可维护的形式。

需要会：

- 等差数列求和
- 前缀和
- 差分
- 累加贡献
- 区间和

常见公式：

```cpp
sum[l..r] = pre[r] - pre[l - 1]
```

```cpp
diff[i] = a[i] - a[i - 1]
```

- [ ] [[problem: luogu,P3368]]

- [ ] [[problem: usaco,1156]]

- [ ] [[problem: usaco,1373]]

- [ ] [[problem: luogu,P3392]]

## 最终训练方法

优先级建议：

1. 整数、取整、余数
2. 逻辑条件、补集、分类讨论
3. gcd、质数、约数倍数
4. 代数变形、不等式
5. 计数：加法原理、乘法原理、补集
6. 坐标、网格、距离
7. 二进制和异或
8. 前缀和、差分、数列规律

每做完一道题，建议写一段复盘：

```text
这题的数学对象是什么：
题目条件能否写成谓词：
有没有必然成立的条件：
有没有冲突：
合法不好数时，能不能数非法：
有没有取模、周期、奇偶性或单调性：
最终公式或判断条件是什么：
```

这份题单的目标不是背数学知识点，而是训练把题面翻译成数学关系的能力。

# NOI 历年真题题单

本题单整理全国青少年信息学奥林匹克竞赛（NOI）正赛真题，目前收录 2016 到 2026 年，每年 6 题（2019 年 7 题，含加强版），共 67 题。

## 收录口径

- 只收录 NOI 正赛（含冬令营之外的正式比赛日）题目，不含 `NOI Online`、`NOI 嘉年华` 等周边赛事。
- 每年两试，每试 3 题，标注为 `D1T1`–`D2T3` 或按洛谷题号顺序。
- 不含 `NOIP`（现 CSP-S）——那是省选的前置认证，另有[CSP-S 历年真题题单](/problem-sets/csp-s-past)。
- 难度按洛谷现行 8 档体系：`提高+` = 提高+/省选-，`省选` = 省选/NOI-，`NOI` = NOI/NOI+/CTS。

## 这份题单的定位

NOI 正赛难度显著高于省选，绝大多数题目标注为 `省选` 或 `NOI` 档。它**不是用来"刷完"的**，用途有三个：

1. **看风格**：NOI 爱考什么、怎么设置部分分、题面长什么样。
2. **练部分分**：NOI 每题都有明确子任务，暴力分往往能拿 30–60 分，这部分是必须练的。
3. **定上限**：知道自己离省队线还差多远。

**建议先做省选真题**（[统一省选历年真题题单](/problem-sets/noi-unified-selection)），省选稳定进省队之后再来做本题单。

## 使用建议

```text
第一遍：只看题面 + 想 20 分钟，写出部分分策略，不看代码
第二遍：实现部分分，拿真实得分
第三遍：读正解，补算法点
```

不要一开始就冲正解。NOI 的评分是子任务制，**部分分策略本身就是考点**。

## NOI2016

- [ ] [[problem: luogu,P1117]] · 优秀的拆分
  - 难度：省选
  - 训练目的：字符串计数。求所有「AABB 形式」的拆分方案数，练后缀数组 + 调和级数枚举。
- [ ] [[problem: luogu,P1173]] · 网格
  - 难度：省选
  - 训练目的：网格图连通性判定。蛐蛐是障碍，判断能否用最少改动让跳蚤不连通，练平面图割与特判。
- [ ] [[problem: luogu,P1587]] · 循环之美
  - 难度：NOI
  - 训练目的：数论反演。纯循环小数计数，练莫比乌斯反演 + 杜教筛。
- [ ] [[problem: luogu,P1712]] · 区间
  - 难度：提高
  - 训练目的：双指针 + 线段树。选 m 个区间使它们有公共点且极差最小，练「按长度排序后滑动窗口 + 覆盖次数最大值」。
- [ ] [[problem: luogu,P1721]] · 国王饮水记
  - 难度：NOI
  - 训练目的：贪心 + 凸优化。水位合并的收益最大化，练「按大小排序后合并相邻段」的结论推导。
- [ ] [[problem: luogu,P1737]] · 旷野大计算
  - 难度：NOI
  - 训练目的：构造题。用有限种基本操作拼出目标函数，练「把运算拆成允许的原语」的构造思维。

## NOI2017

- [ ] [[problem: luogu,P3822]] · 整数
  - 难度：省选
  - 训练目的：二进制高精度 + 位运算。支持大数加减与单点查询，练「压位 + 懒标记」或线段树维护进位。
- [ ] [[problem: luogu,P3823]] · 蚯蚓排队
  - 难度：省选
  - 训练目的：链表 + 哈希。维护若干序列并统计子串出现次数，练「长度受限时只哈希短串」的关键观察。
- [ ] [[problem: luogu,P3824]] · 泳池
  - 难度：NOI
  - 训练目的：DP + 线性递推。矩形安全区域计数，练「按最小不安全位置划分」的 DP 设计。
- [ ] [[problem: luogu,P3825]] · 游戏
  - 难度：提高+
  - 训练目的：2-SAT。地图限制赛车类型，d 很小可以枚举，练「小范围枚举 + 2-SAT 判定」。
- [ ] [[problem: luogu,P3826]] · 蔬菜
  - 难度：NOI
  - 训练目的：费用流 / 贪心 + 并查集。蔬菜按天变质，练「倒序处理 + 可撤销贪心」。
- [ ] [[problem: luogu,P3827]] · 分身术
  - 难度：NOI
  - 训练目的：动态凸包。删点后剩余点的凸包面积，练「离线倒序加点」或「分块重建」。

## NOI2018

- [ ] [[problem: luogu,P4768]] · 归程
  - 难度：提高+
  - 训练目的：Kruskal 重构树 + 最短路。按海拔建重构树后查询子树最小值，练「边权阈值 → 树上子树」的经典转化。
- [ ] [[problem: luogu,P4769]] · 冒泡排序
  - 难度：NOI
  - 训练目的：排列与逆序对。求冒泡排序交换次数的期望或计数，练「逆序对 ↔ 排列统计」的组合推导。
- [ ] [[problem: luogu,P4770]] · 你的名字
  - 难度：NOI
  - 训练目的：后缀自动机 + 线段树合并。多串的公共子串去重计数，练 SAM 上的 endpos 维护。
- [ ] [[problem: luogu,P4774]] · 屠龙勇士
  - 难度：提高+
  - 训练目的：扩展中国剩余定理（excrt）。血量与恢复量构成同余方程组，练 excrt 与无解判定。
- [ ] [[problem: luogu,P4775]] · 情报中心
  - 难度：NOI
  - 训练目的：树上路径交 + 数据结构。多条路径的公共部分统计，练「路径交 = LCA 相关量」的推导。
- [ ] [[problem: luogu,P4776]] · 多边形
  - 难度：NOI
  - 训练目的：树上 DP + 计数。虽然名字叫多边形，实际是树上结构计数，练「子树信息合并 + 容斥」。

- [ ] [[problem: luogu,P5473]] · I 君的探险
  - 难度：NOI
  - 训练目的：交互题。通过有限次查询还原图结构，练信息量与二分构造。

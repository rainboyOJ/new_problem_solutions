# 1061C Multiplicity

## 题目描述

给定一个整数数组 $a_1, a_2, \ldots, a_n$。

如果可以通过从 $a$ 中删除一些元素得到 $b$，那么数组 $b$ 就称为 子序列。

数组 $b_1, b_2, \ldots, b_k$ 被称为 优秀，当且仅当它非空，并且对于每个 $i$（$1 \le i \le k$），都有 $b_i$ 能被 $i$ 整除。

请计算 $a$ 中优秀子序列的数量，并将结果对 $10^9 + 7$ 取模。

如果两个子序列所选元素的下标集合不同，就认为它们不同。也就是说，比较子序列时并不关心元素的具体数值。特别地，数组 $a$ 恰好有 $2^n - 1$ 个不同的子序列（不包括空子序列）。

## 输入格式

第一行包含一个整数 $n$（$1 \le n \le 100\,000$）——数组 $a$ 的长度。

第二行包含整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^6$）。

## 输出格式

输出一个整数——优秀子序列的数量对 $10^9 + 7$ 取模后的结果。

## 说明

在第一个样例中，所有三个非空子序列都是优秀的： $\{1\}$、$\{1, 2\}$、$\{2\}$。

在第二个样例中，优秀子序列包括： $\{2\}$、$\{2, 2\}$、$\{2, 22\}$、$\{2, 14\}$、$\{2\}$、$\{2, 22\}$、$\{2, 14\}$、$\{1\}$、$\{1, 22\}$、$\{1, 14\}$、$\{22\}$、$\{22, 14\}$、$\{14\}$。

注意，其中一些子序列被列出了多次，因为它们在原数组中出现了不止一次。

## 输入输出样例 #1

### 输入 #1

```
2
1 2
```

### 输出 #1

```
3
```

## 输入输出样例 #2

### 输入 #2

```
5
2 2 1 22 14
```

### 输出 #2

```
13
```

# 33B String Problem

## 题目描述

男孩瓦莱拉特别喜欢字符串。更重要的是，他喜欢两个字符串完全一样。因此，闲暇时他玩一个游戏：他拿两条只包含小写拉丁字母的字符串，试图让它们变得一模一样。游戏规则是，每一步他可以把其中一个字符串的任意一个字符换成任意另一个字符，但每换一次都得花费一定的钱，花费数额是 *W*<sub>*i*</sub>。他可以换多少次都行。瓦莱拉很节俭，从不乱花钱，所以他请你这个资深程序员帮忙，算算最少得花多少钱，才能让两个字符串变成一样的。

## 输入格式

第一行输入两个非空字符串 *s* 和 *t*，都只含小写拉丁字母，且长度不超过 10<sup>5</sup>。接下来一行是整数 *n* (0 ≤ *n* ≤ 500) — 表示允许的字符替换规则数量。然后有 *n* 行，每行包含两个字符 *A*<sub>*i*</sub> 和 *B*<sub>*i*</sub>（小写拉丁字母），以及一个整数 *W*<sub>*i*</sub> (0 ≤ *W*<sub>*i*</sub> ≤ 100)，表示可以把字符 *A*<sub>*i*</sub> 换成字符 *B*<sub>*i*</sub>，花费 *W*<sub>*i*</sub> 的钱。

## 输出格式

如果有解，输出最小花费和最终变成的字符串；如果无解，输出一行 -1。如果答案不唯一，输出任意一个。

## 输入输出样例 #1

### 输入 #1

```
uayd
uxxd
3
a x 8
x y 13
d c 3
```

### 输出 #1

```
21
uxyd
```

## 输入输出样例 #2

### 输入 #2

```
a
b
3
a b 2
a b 3
b a 5
```

### 输出 #2

```
2
b
```

### 输入 #3

```
abc
ab
6

a b 7

```

### 输出 #3

```

```

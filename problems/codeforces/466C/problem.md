# 466C Number of Ways

## 题目描述

给定一个包含*n*个整数的数组*a*[1], *a*[2], ..., *a*[*n*]。请计算将该数组所有元素分割成三个连续部分的方法数，要求每个部分元素之和相等。

更正式地说，需要找出满足条件的所有索引对*i*, *j*和(2 ≤ *i* ≤ *j* ≤ *n* - 1)，使得*。

## 输入格式

第一行包含整数*n*(1 ≤ *n* ≤ 5·10<sup>5</sup>)，表示数组中的数字个数。第二行包含*n*个整数*a*[1], *a*[2], ..., *a*[*n*](|*a*[*i*]| ≤  10<sup>9</sup>)——数组*a*的元素。

## 输出格式

输出一个整数——将数组分割为三个等和部分的方法数。

## 输入输出样例 #1

### 输入 #1

```
5
1 2 3 0 3
```

### 输出 #1

```
2
```

## 输入输出样例 #2

### 输入 #2

```
4
0 1 -1 0
```

### 输出 #2

```
1
```

## 输入输出样例 #3

### 输入 #3

```
2
4 1
```

### 输出 #3

```
0
```

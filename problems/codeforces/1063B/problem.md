# 1063B Labyrinth

## 题目描述

你正在玩一款电脑游戏。其中一个关卡将你置于由*n*行组成的迷宫中，每行包含*m*个单元格。每个单元格要么是空的，要么被障碍物占据。起始单元格位于第*r*行第*c*列。每一步你可以向上、左、下或右移动一格，前提是目标单元格没有被障碍物占据。你不能移出迷宫的边界。

不幸的是，你的键盘即将损坏，因此你最多只能向左移动*x*次，向右移动*y*次。由于上下移动的按键完好无损，上下移动次数没有限制。

现在你需要确定对于每个单元格，是否存在从起始单元格出发的移动序列能够到达该单元格。棋盘上有多少个单元格满足这个条件？

## 输入格式

第一行包含两个整数*n*, *m* (1 ≤ *n*, *m* ≤ 2000)——分别表示迷宫的行数和列数。

第二行包含两个整数*r*, *c* (1 ≤ *r* ≤ *n*, 1 ≤ *c* ≤ *m*)——表示起始单元格的行号和列号。

第三行包含两个整数*x*, *y* (0 ≤ *x*, *y* ≤ 10<sup>9</sup>)——分别表示允许的最大左移次数和右移次数。

接下来*n*行描述迷宫。每行长度为*m*，仅由符号'.'和'*'组成。第*i*行的第*j*个字符对应迷宫第*i*行第*j*列的单元格。符号'.'表示空格，符号'*'表示障碍物。

数据保证起始单元格没有障碍物。

## 输出格式

输出一个整数——表示迷宫中可从起始单元格到达的单元格数量（包括起始单元格本身）。

## 备注

在对应示例中，可到达的单元格用'+'标记。

第一个示例：

```
+++..+***.+++***+++.
```

第二个示例：

```
.++..+*..++..++.
```

## 输入输出样例 #1

### 输入 #1

```
4 5
3 2
1 2
.....
.***.
...**
*....
```

### 输出 #1

```
10
```

## 输入输出样例 #2

### 输入 #2

```
4 4
2 2
0 1
....
..*.
....
....
```

### 输出 #2

```
7
```

# 1915G Bicycles

## 题目描述

Slavic 的朋友们都打算骑自行车，从居住的地方前往参加聚会。他们每个人都有自行车，唯独 Slavic 没有。沿途共有 $n$ 座城市可供通行。他们都住在城市 $1$，而聚会地点位于城市 $n$。这些城市可以看作一个有 $n$ 个节点、$m$ 条边的无向图。第 $i$ 条边连接城市 $u_i$ 和 $v_i$，长度为 $w_i$。

Slavic 虽然没有自行车，但他有的是钱。每座城市恰好出售一辆自行车。第 $i$ 座城市里的自行车，其速度系数为 $s_{i}$。Slavic 买下自行车后，便可以在 任何时候 骑着它从当前城市前往任意相邻城市。若他骑着自己拥有的第 $j$ 辆自行车通过第 $i$ 条边，则耗时为 $w_i \cdot s_j$。

Slavic 想买多少辆自行车都可以，毕竟钱对他来说不是问题。由于他非常讨厌骑车，所以希望以尽可能短的时间从家前往聚会地点。可是他的算法功底已经有些生疏了，于是只好向你求助。

从城市 $1$ 出发到达城市 $n$，Slavic 最少需要多长时间？注意，Slavic 没有自行车时无法移动。保证 Slavic 可以从城市 $1$ 到达任意其他城市。

## 输入格式

第一行包含一个整数 $t$（$1 \leq t \leq 100$）——测试用例的数量。接下来给出各个测试用例的描述。

每个测试用例的第一行包含两个用空格分隔的整数 $n$ 和 $m$（$2 \leq n \leq 1000$；$n - 1 \leq m \leq 1000$）——城市数和道路数。

接下来的 $m$ 行中，第 $i$ 行包含三个整数 $u_i$、$v_i$ 和 $w_i$（$1 \le u_i, v_i \le n$，$u_i \neq v_i$；$1 \leq w_i \leq 10^5$），表示城市 $u_i$ 和 $v_i$ 之间有一条长度为 $w_i$ 的道路。同一对城市之间可能存在多条道路。

下一行包含 $n$ 个整数 $s_1, \ldots, s_n$（$1 \leq s_i \leq 1000$）——每辆自行车的速度系数。

所有测试用例中 $n$ 的总和不超过 $1000$，$m$ 的总和不超过 $1000$。

输入还满足以下额外条件：可以从城市 $1$ 到达任意其他城市。

## 输出格式

对于每个测试用例，输出一个整数，表示 Slavic 从城市 $1$ 出发到达城市 $n$ 所需的最短时间。

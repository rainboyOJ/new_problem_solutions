# 915C Permute Digits

## 题目描述

给定两个正整数 *a* 和 *b*。重新排列 *a* 的数字以构造不超过 *b* 的最大数。输入和/或输出中的数字不能以数字 0 开头。

允许保持 *a* 不变。

## 输入格式

第一行包含整数 *a* (1 ≤ *a* ≤ 10<sup>18</sup>)。第二行包含整数 *b* (1 ≤ *b* ≤ 10<sup>18</sup>)。数字不包含前导零。保证存在答案。

## 输出格式

打印最大可能的数字，该数字是 *a* 的数字重新排列，且不大于 *b*。答案不能有任何前导零。保证答案存在。

输出中的数字应与数字 *a* 的长度完全相同。它应为 *a* 的数字重新排列。

## 输入输出样例 #1

### 输入 #1

```
123
222
```

### 输出 #1

```
213
```

## 输入输出样例 #2

### 输入 #2

```
3921
10000
```

### 输出 #2

```
9321
```

## 输入输出样例 #3

### 输入 #3

```
4940
5000
```

### 输出 #3

```
4940
```

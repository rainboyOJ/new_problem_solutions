## 形式化题目

给定长度为 $n$ 的颜色序列 $c = [c_1, c_2, \dots, c_n]$。把一个极大的同色连续下标段称为一个「连通块」：满足 $c_i = c_{i+1} = \dots = c_j$ 且两端不越界时 $c_{i-1} \ne c_i, c_{j+1} \ne c_j$。

你可以进行如下操作过程：

1. **初始选择**：在序列中选定一个起始位置 $p \in [1, n]$，此时包含 $p$ 的整个连通块成为初始受控区域（这一步不消耗操作次数）；
2. **染色扩展**：每回合选择一种目标颜色 $x$，将当前受控区域的所有位置统一重染为颜色 $x$（消耗 1 次操作）。重染后，若受控区域与外侧相邻格子的颜色相同，则相邻格子立即自动并入受控区域。

求将整个序列的所有位置变为同一种颜色所需的最小操作次数。

原题中方块称为「彩色方块」，染色扩展称为「洪水填充（Flood Fill）」，受控区域称为「包含起点的连通区域」，下文统一使用「受控连通块」表述。

## 暴力解法

### 思路

最直接朴素的想法是：将「整行数组当前的全部颜色状态」看作图上的一个节点，在状态空间中做 BFS 最短路。

枚举初始起点 $p \in [1, n]$。对于每一个起点，从初始数组出发，每一层找出当前包含 $p$ 的同色极大区间 $[L, R]$，枚举可以染成序列中出现过的任意其他颜色，生成新的完整数组放入队列，直至全行颜色全部一致。

该暴力解法完全不预设任何贪心结论（例如不预设“只能染成与左右邻格相同的颜色”），因此其搜索结果可作为独立检验正解正确性的基准。

### 复杂度

设颜色总数为 $k$。整个序列的颜色状态数最坏可达 $O(k^n)$；每个状态展开需要复制整个长度为 $n$ 的数组，还要枚举 $n$ 个起点。算法的时间与空间复杂度均远超 $O(n \cdot k^n)$，仅能处理 $n \le 8$ 且颜色极少的测试数据。

### 瓶颈

暴力的症结在于**状态里保存了整行数组的完整形态**。表面上看，由于任意时刻都可以把受控块染成各种颜色，中途似乎会演化出指数种不同的棋盘格局。

但真正核心的思考是：**我们真的需要用整个数组来描述当前的局面吗？能否根据极少的关键参数，唯一确定出整个数组此时此刻长什么样？**

## 正解

### 思路

::: info 核心洞察：局面的物理形态是唯一的
受控连通块始于单点，并在每一步向外吞并邻格。因此，在任何合法且最优的操作序列中：
1. **已吞并的受控区域必然是一段连续的区间 $[l, r]$**，且区间内所有位置已经被彻底同化为单一种颜色；
2. **区间外部的位置从始至终从未被触碰过**，完全保持其初始颜色；
3. **已吞并区间的内部颜色，必然非 $c_l$ 即 $c_r$**。
这意味着，**只需三元组 $(l, r, s)$，就能完全画出当前整个数组的确切样貌！** 历史路径被彻底抹平，状态直接降维为区间 DP。
:::

#### 1. 预处理：压缩相邻同色

观察发现，初始时相邻的同色格子在未来的任何一次吞并中都会被整体吞入，绝不可能被割裂开来单独处理。

因此，首先将原序列中连续相同的元素合并，得到压缩后的颜色序列 $c = [c_0, c_1, \dots, c_{m-1}]$，保证相邻元素两两不同（$c_i \ne c_{i+1}$）。问题的答案完全等价于在这个压缩序列上操作。

例如样例 1 的 `[5, 2, 2, 1]` 压缩为 `[5, 2, 1]`，$m = 3$。

#### 2. 状态的唯一物理形态（回答“这个数组长什么样”）

当以某个位置为起点，在压缩序列上经历了若干步染色后，受控连通块必然扩张到了某个连续区间 $[l, r]$。

那么此时整个数组的物理状态是怎样的？

```text
下标:   0    1   ...  l-1  |   l    l+1  ...  r-1   r   |  r+1  ...  m-1
颜色: [c[0], c[1], ..., c[l-1] | c[l], c[l], ..., c[l], c[l] | c[r+1], ..., c[m-1]]
       \___________________/   \_______________________/   \___________________/
           左侧完全没碰过              中间整段被同化为 c[l]            右侧完全没碰过
            (保持原色)                                             (保持原色)
```

- **左侧区间 $[0, l-1]$**：连通块从未延伸至此，每个位置严格保持初始颜色 $c[0], \dots, c[l-1]$；
- **右侧区间 $[r+1, m-1]$**：连通块从未延伸至此，每个位置严格保持初始颜色 $c[r+1], \dots, c[m-1]$；
- **中间区间 $[l, r]$**：受控连通块已将其全部吞并，内部全部统一为同一颜色。

而且，为了使操作最少，**每一次染色的颜色必然是紧挨着的左侧邻格 $c_{l-1}$ 或右侧邻格 $c_{r+1}$**。染成任何其他第三种颜色除了浪费步数外不会带来任何实质吞并。因此，刚刚吞并到 $[l, r]$ 时，这块区域当前的统一颜色**要么等于左端点的原始颜色 $c_l$，要么等于右端点的原始颜色 $c_r$**。

**这就是状态具备无后效性的物理本质**：
无论最初选定哪一个格子作为起点，无论中途是“先左后右”还是“先右后左”，只要当前受控区间为 $[l, r]$ 且整段颜色等于 $c_l$（记为状态 $0$），**整个数组的全局面貌都是完全固定且独一无二的**。后续将全行染成同色所需的最少步数，与此前的游走历史毫无关系。

#### 3. 区间 DP 状态设计与转移

基于上述物理形态，我们采用标准的自底向上区间 DP。

**状态定义**：
- $dp[l][r][0]$：表示将子区间 $[l, r]$ 彻底统一为单一种颜色、且该颜色等于**左端点原色 $c_l$** 所需的最小操作次数；
- $dp[l][r][1]$：表示将子区间 $[l, r]$ 彻底统一为单一种颜色、且该颜色等于**右端点原色 $c_r$** 所需的最小操作次数。

**边界初值**：
- 长度为 1 的区间 $[i, i]$（即单点），自身天然同色，操作数为 0：
  $$dp[i][i][0] = dp[i][i][1] = 0$$

**状态转移推导**（按区间长度 $len$ 从 $2$ 到 $m$ 递增）：
考虑区间 $[l, r]$ 是如何由内层子区间扩张并同化而来的：

1. **若最终统一为左端颜色 $c_l$（计算 $dp[l][r][0]$）**：
   它必然是由已经同化的子区间 $[l+1, r]$ 吞并左侧邻格 $l$ 得来：
   - 若 $[l+1, r]$ 此前的颜色是 $c_{l+1}$（对应状态 $dp[l+1][r][0]$）：由于去重后必有 $c_l \ne c_{l+1}$，必须花费 1 次染色将其变成 $c_l$，代价为 $dp[l+1][r][0] + 1$；
   - 若 $[l+1, r]$ 此前的颜色是 $c_r$（对应状态 $dp[l+1][r][1]$）：若 $c_l == c_r$，则其颜色本身就已经是 $c_l$，无需额外操作（代价 $+0$）；若 $c_l \ne c_r$，则需额外花费 1 次染色（代价 $+1$）。
   
   综上：
   $$
   dp[l][r][0] = \min\big(dp[l+1][r][0] + 1, \; dp[l+1][r][1] + [c_l \ne c_r]\big)
   $$

2. **若最终统一为右端颜色 $c_r$（计算 $dp[l][r][1]$）**：
   对称地，它必然是由已经同化的子区间 $[l, r-1]$ 吞并右侧邻格 $r$ 得来：
   - 若 $[l, r-1]$ 此前颜色是 $c_{r-1}$：由于 $c_{r-1} \ne c_r$，代价为 $dp[l][r-1][1] + 1$；
   - 若 $[l, r-1]$ 此前颜色是 $c_l$：若 $c_l == c_r$ 代价为 $0$，否则代价为 $1$。
   
   综上：
   $$
   dp[l][r][1] = \min\big(dp[l][r-1][1] + 1, \; dp[l][r-1][0] + [c_l \ne c_r]\big)
   $$

其中 $[c_l \ne c_r]$ 当两端颜色不同时取 $1$，相同时取 $0$。

#### 4. 答案落点与对称性

当递推完成整个区间 $[0, m-1]$ 时，整行方块已被全部同化，答案即为两种终态颜色的较小值：
$$
\text{ans} = \min\big(dp[0][m-1][0], \; dp[0][m-1][1]\big)
$$

::: tip 双向印证：为什么两端颜色相同时可以“省去 1 步”？
如果 $c_l == c_r$，从内部 $[l+1, r-1]$ 染成 $c_l$ 时，左侧的 $c_l$ 和右侧的 $c_r$ 将会被**同一次染色操作同时吞并**！
这从本质上对应了序列的最长回文子序列（LPS）：每一次利用 $c_l == c_r$ 消除一对端点，就等价于少做一次染色。因此本题答案在数学上精准等于 $m - 1 - \lfloor \frac{\text{LPS}(c)-1}{2} \rfloor$。区间 DP 方程直接而自然地包含了这一最优选择。
:::

### 复杂度

- **时间复杂度**：
  - 相邻同色去重压缩只需线性扫描一次，耗时 $O(n)$；
  - 区间 DP 外层枚举区间长度 $len \in [2, m]$，内层枚举左端点 $l$，共有 $\frac{m(m-1)}{2}$ 个状态；
  - 每个状态的转移为 $O(1)$ 的常数时间比较。
  - 总时间复杂度为 $O(n + m^2)$。当 $m \le 5000$ 时，两重循环执行次数约为 $1.25 \times 10^7$ 次，实际运行时间在 $0.1\text{ s}$ 以内，远低于 2.0s 的时限。
- **空间复杂度**：
  - 数组 `dp[5005][5005][2]` 采用 `short` 类型存储（由于步数最大不超过 $m-1 < 5000$，`short` 完全不溢出）；
  - 内存占用为 $5005 \times 5005 \times 2 \times 2\text{ bytes} \approx 95.5\text{ MB}$，完全在 256 MB 限制的安全范围内。

## 总结

1. **从全局数组到区间三元组**：暴力的死穴在于认为局面需要完整记录整行方块。通过观察“洪水填充始终连通扩展”的几何特性，识别出当前局面必然由未动的外侧原色和统一的内侧区间构成，实现了从指数状态到 $O(m^2)$ 多项式状态的降维。
2. **状态定义的物理具象性**：三元组 $(l, r, 0)$ 之所以能够作为 DP 状态，根本原因在于其能够**唯一、无歧义地复现出客观棋盘的每一个格子**。只要物理现实唯一确定，后续转移便拥有严格的无后效性。
3. **两端同色的贪心合并**：区间 DP 方程中项 $[c_l \ne c_r]$ 极其凝练地刻画了“一次染色同时吸收左右两端相同颜色”的最高效操作，完成了区间 DP 与回文匹配结构的完美统一。

# 1114D Flood Fill

## 题目描述

给定一行共$n$个连续排列的彩色方块，从左到右编号为$1$到$n$。第$i$个方块的初始颜色为$c_i$。

当满足$c_i = c_j$且对于所有满足$i < k < j$的$k$都有$c_i = c_k$时，我们认为两个方块$i$和$j$属于同一连通区域。换句话说，从$i$到$j$区间的所有方块必须颜色相同。

例如，序列$[3, 3, 3]$包含$1$个连通区域，而序列$[5, 2, 4, 4]$则有$3$个连通区域。

游戏"洪水填充"规则如下：

- 游戏开始时任选一个起始方块（不计入操作次数）
- 每个回合可将包含起始方块的连通区域染成任意其他颜色

求将整行方块变为单一颜色所需的最小操作次数。

## 输入格式

第一行包含单个整数$n$（$1 \le n \le 5000$） — 表示方块数量。

第二行包含$c_1, c_2, \ldots, c_n$个整数（$1 \le c_i \le 5000$） — 表示方块的初始颜色。

## 输出格式

输出一个整数 — 表示所需的最小操作次数。

## 备注

第一个示例中，最优解可以选择编号$2$的方块作为起点，按以下步骤操作：

- $[5, 2, 2, 1]$
- $[5, 5, 5, 1]$
- $[1, 1, 1, 1]$

第二个示例中，可以选择编号$5$的方块作为起点，依次染成$2, 3, 5, 4$颜色。

第三个示例中，所有方块初始颜色已相同。

## 输入输出样例 #1

### 输入 #1

```
4
5 2 2 1
```

### 输出 #1

```
2
```

## 输入输出样例 #2

### 输入 #2

```
8
4 5 2 2 1 3 5 5
```

### 输出 #2

```
4
```

## 输入输出样例 #3

### 输入 #3

```
1
4
```

### 输出 #3

```
0
```

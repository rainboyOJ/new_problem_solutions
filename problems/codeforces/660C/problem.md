# 660C Hard Process

## 题目描述

给定一个包含 *n* 个元素的数组 *a*。数组 *a* 的每个元素都是 0 或 1。

设 *f*(*a*) 表示数组 *a* 中仅包含数字1的连续元素子段的最大长度。你最多可以将 *k* 个零改为一来最大化 *f*(*a*)。

## 输入格式

第一行包含两个整数 *n* 和 *k*（1 ≤ *n* ≤ 3·10<sup>5</sup>, 0 ≤ *k* ≤ *n*）— 数组 *a* 的元素数和参数 *k*。

第二行包含 *n* 个整数 *a*<sub>*i*</sub>（0 ≤ *a*<sub>*i*</sub> ≤ 1）— 数组 *a* 的元素。

## 输出格式

第一行输出一个非负整数 *z* — 在最多将 *k* 个零改为一的情况下，*f*(*a*) 的最大值。

第二行输出 *n* 个整数 *a*<sub>*j*</sub> — 改变后的数组 *a* 的元素。

如果存在多个答案，你可以输出任意一个。

## 输入输出样例 #1

### 输入 #1

```
7 1
1 0 0 1 1 0 1
```

### 输出 #1

```
4
1 0 0 1 1 1 1
```

## 输入输出样例 #2

### 输入 #2

```
10 2
1 0 0 1 0 1 0 1 0 1
```

### 输出 #2

```
5
1 0 0 1 1 1 1 1 0 1
```

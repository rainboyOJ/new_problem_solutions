## 形式化题目

给定长度为 $n$ 的序列 $a_1, \dots, a_n$，其中 $a_i \in \{0, 1\}$，以及参数 $k$。

允许进行至多 $k$ 次操作，每次把某个 $a_i = 0$ 改成 $1$。设 $f(a)$ 为修改后序列中最长连续 $1$ 段的长度，要求最大化 $f(a)$，并给出一个达到最大值的修改后序列。

## 解法总览

三个解法的共同起点是同一条结论：最优解总是「选一段连续区间，把区间内的 0 全部改成 1」，于是问题变成「找 0 的个数不超过 $k$ 的最长区间」。区别在于怎样找这段区间。

| 解法 | 核心观察 | 复杂度 | 适用场景 | 对应代码 |
| --- | --- | --- | --- | --- |
| 解法一：枚举所有区间（暴力基线） | 直接枚举左右端点，用 0 个数前缀和判合法性 | $O(n^2)$ | 只适合小数据，用来对拍和理解题意 | `brute2.cpp` |
| 解法二：双指针（闭区间视角，主解） | 外层固定左端点向前探索闭区间 $[l, r]$，子集关系保证右端点只进不退 | $O(n)$ | 满分做法，直观人脑视角，常数最小 | `main.cpp` |
| 解法三：二分答案 | 存在长度为 $L$ 的合法区间 $\Rightarrow$ 存在长度为 $L-1$ 的，长度可行性单调 | $O(n \log n)$ | 满分做法，换一种思路验证同一答案 | `main2.cpp` |

解法二是解法一在「端点单调」上的优化：把 $O(n^2)$ 的枚举压成 $O(n)$ 的尺取。解法三与前两者并列，是独立的另一条路线，适合在双指针单调性不易直接看出时换个角度。正式主解取解法二。

（另有一份 `brute.cpp` 用 DFS 枚举「把哪几个 0 改成 1」，是 $2^{\#0}$ 级的指数做法，只能小数据对拍，正文不展开。）

## 解法一：枚举所有区间 + 前缀和

!!! info 最优解等价于翻转某段连续区间内的全部 0。
最优解里被翻转的 0，一旦中间夹着没翻的 0，把它换成翻转那个 0 既不增加翻转次数又只会让 1 段不变短，所以总能把被翻转的 0 整理成连续一段。于是只需枚举区间 $[i, j]$，用 0 个数前缀和判断其中 0 的个数是否 $\leqslant k$，合法就用区间长度更新答案，$O(n^2)$。
!!!

### 思路

暴力枚举「改哪几个 0」是指数级的，没法用。先把它拉回到多项式：由下面的交换论证，最优解翻转的 0 一定能在位置序列上连成一段，所以只要考虑「翻转某个区间 $[i, j]$ 内的全部 0」。

于是最直接的做法是枚举所有区间。区间有 $O(n^2)$ 个，每次判断「区间内 0 的个数是否不超过 $k$」如果还要重新数一遍就是 $O(n^3)$，太慢。预处理一个 0 个数的前缀和 `zero_pref`，区间 $[i, j]$ 内 0 的个数就是 `zero_pref[j] - zero_pref[i-1]`，单次判断降到 $O(1)$。

整体 $O(n^2)$，$n = 3\times10^5$ 时不可行，但逻辑最直白，适合作为对拍基准，也说明下一步要优化什么。

**关键结论**：最优解 $\iff$ 翻转某个区间 $[i, j]$ 内的全部 0。

*证明*：设最优解翻转的 0 的位置集合为 $S$。若 $S$ 不是一段连续位置（中间夹着没翻的 0），取 $S$ 中两个被翻转的 0 之间的某个未翻转 0，把它的状态改成反转，同时取消 $S$ 中最靠边的一个已翻转 0 的翻转。翻转的 0 总数不变，仍然合法；而被翻转 0 的位置跨度只会缩小，最长连续 1 段不变差。反复这样做，被翻转的 0 可以整理成连续一段，等价于翻转某个区间内的所有 0。

### 瓶颈

瓶颈在于 $O(n^2)$ 个区间都要枚举一遍。但注意：固定左端点 $i$ 时，右端点 $j$ 越往右，区间内 0 的个数只增不减；一旦某个 $j$ 让 0 的个数超过 $k$，再往右一定都不合法，没必要继续试。更重要的是，当左端点 $i$ 右移时，最远的合法右端点只会右移、不会左移。抓住这条单调性就能砍掉大量重复枚举，这就是双指针。

## 解法二：双指针（闭区间视角，主解）

!!! info 外层固定左端点，维护闭区间 $[l, r]$，子集包含关系保证右端点只进不退。
外层枚举左端点 $l$，变量 $r$ 表示当前已经确认包含在窗口里的最右端位置。每次尝试看下一个位置 $r+1$ 能否加入窗口，若加入后 0 的个数仍 $\leqslant k$ 则扩展 $r$。当 $r$ 无法再前进时，闭区间 $[l, r]$ 即为以 $l$ 为起点的极大合法窗口，长度为 $r - l + 1$。当 $l$ 步进到 $l+1$ 时，新区间 $[l+1, r] \subset [l, r]$，内部 0 的个数只减不增，必然合法，因此右端点绝不回退，总耗时 $O(n)$。
!!!

### 思路

沿用解法一的区间判据，让两个指针协同单向移动。从最符合人脑思维的**闭区间 $[l, r]$** 出发：

维护闭区间 $[l, r]$，其中 $l$ 是当前窗口的起点，$r$ 是当前已经确定包含在窗口内的最右侧元素下标。为了表示初始时窗口为空，我们将 $r$ 初始化为 0（即 $[1, 0]$ 表示空区间）。

算法推进流程如下：

1. **向右试探（Lookahead）**：站在左端点 $l$ 不动，观察下一个位置 $r + 1$。如果 $r + 1 \leqslant n$ 且将 $a_{r+1}$ 纳入后窗口内 0 的总数仍不超过 $k$，则让 $r \leftarrow r + 1$，并将 $a_r$ 计入窗口；重复这一步直到无法继续向前扩展；
2. **结算答案**：此时闭区间 $[l, r]$ 就是以 $l$ 为起点的**最长连续合法子段**。如果 $r \geqslant l$（窗口非空），它的长度就是自然的闭区间长度公式 $r - l + 1$。用它更新全局最长长度；
3. **起点步进**：为枚举下一个起点 $l + 1$，需要从当前窗口移出最左侧元素 $a_l$（若 $a_l = 0$ 则窗口内 0 的计数减一）。

**关键结论（右端点单调不减定理）**：
设以 $l$ 为起点的极大合法闭区间为 $[l, R(l)]$，则对下一个起点 $l+1$，其极大合法闭区间的右端点必满足：

$$R(l+1) \geqslant R(l)$$

*证明（区间子集包含法）*：
- 由已知，闭区间 $[l, R(l)]$ 是合法的，其内部包含的 0 的数量不超过 $k$；
- 考察新的区间 $[l+1, R(l)]$。显然 $[l+1, R(l)] \subset [l, R(l)]$，它是原区间的真子集；
- 从子集中去掉了左端元素 $a_l$，其中 0 的数量只可能减少（当 $a_l = 0$ 时）或保持不变（当 $a_l = 1$ 时）；
- 因此 $[l+1, R(l)]$ 内部 0 的数量必定 $\leqslant$ 原区间 0 的数量 $\leqslant k$。也就是说，**闭区间 $[l+1, R(l)]$ 必然合法**；
- 既然在 $R(l)$ 及之前的位置对于新起点 $l+1$ 都已经确定合法，那么以 $l+1$ 为起点的最远合法右边界 $R(l+1)$ 绝不可能回退到 $R(l)$ 的左侧，必然有 $R(l+1) \geqslant R(l)$。$\square$

这个结论从逻辑上保证了：当 $l$ 步进到 $l+1$ 时，$r$ 完全不需要重置回 $l+1$ 重新扫描，直接从上一轮停下的位置继续向前尝试 $r + 1$ 即可。左指针 $l$ 从 1 遍历到 $n$，右指针 $r$ 也只从 0 单向递增到最多 $n$，每个元素进出窗口各最多一次，整体时间复杂度为严格的 $O(n)$。

## 解法三：二分答案

!!! info 长度可行性单调，`check(L)` 表示「长度 $L$ 可行」，序列形如 true…true,false…false，套 rbook1 二分模板找第一个不可行位置再减一。
若存在长度 $L$ 且 0 的个数 $\leqslant k$ 的区间，去掉一端得到长度 $L-1$ 的子区间，0 的个数只会更少，仍合法。所以「长度 $L$ 可行」关于 $L$ 单调：小的都可行、大的未必可行。把 `check(L)` 定义成「长度 $L$ 可行」，它随 $L$ 增大从 `true` 变成 `false`。模板 `bs_find(0, n+1)` 找第一个使 `!check` 成立（即不可行）的长度，减一就是最后一个可行长度，总 $O(n \log n)$。
!!!

### 思路

换一个角度问：「答案长度至少是 $L$，可以吗？」只要能快速回答这个问题，就能对 $L$ 二分。

**关键结论**：若存在长度为 $L$ 的合法区间（0 的个数 $\leqslant k$），则一定存在长度为 $L-1$ 的合法区间。

*证明*：长度为 $L$ 的合法区间，去掉任意一端就得到长度 $L-1$ 的子区间。子区间的 0 的个数不会比原区间多，仍然 $\leqslant k$，所以也合法。

由此，「答案至少是 $L$」这个命题关于 $L$ 单调：大的 $L$ 成立，小的 $L$ 必然成立。这正是可以二分的前提。

这里按 rbook1《二分查找》的模板落地。模板只做一件事：在区间 $[l, r]$ 上找第一个使 `check` 成立的位置，`while (l < r)` 循环里用 `mid(l, r)` 取中点，成立就 `r = m`，否则 `l = m + 1`，最后返回 `l`。

把它用到本题，`check(L)` 直接定义成语义最自然的「长度 $L$ 是否可行」：扫所有长度为 $L$ 的窗口，只要有一个窗口 0 的个数 $\leqslant k$ 就返回 `true`，扫完都没有就返回 `false`。这样 `check` 关于 $L$ 是 `true…true,false…false`，模板要找的「第一个成立」就落在「第一次不可行」上，所以传入的判据写成 `!check(m)`。边界是 `check(0)` 为 `true`（空窗口必然合法）、`check(n+1)` 为 `false`（超过数组长度必然不可行），保证 $[0, n+1]$ 里一定有第一个不可行的位置。

于是 `bs_find(0, n+1)` 返回第一个不可行的长度，它左边那个（减一）就是最后一个可行长度，也就是答案。得到最优长度后，再扫一遍找出一个长度等于它的合法窗口，把窗口内 0 全部改成 1。

## 复杂度对比

| 解法 | 时间 | 空间 | 说明 |
| --- | --- | --- | --- |
| 枚举所有区间 | $O(n^2)$ | $O(n)$ | 基线，$n = 3\times10^5$ 超时 |
| 双指针（闭区间视角） | $O(n)$ | $O(n)$ | 推荐主解，人脑视角 $[l, r]$，两端点单调只进不退 |
| 二分答案 | $O(n \log n)$ | $O(n)$ | 依赖长度可行性单调，比双指针多一个 $\log$ |

三条路线得到的是同一个答案（优化目标相同）。双指针把单调性用到极致，是常数最小的满分做法；二分答案多一层 $\log$，但当「判定一个长度是否可行」本身就复杂、难以直接尺取时，二分往往是更通用的框架。

## 总结

题目的核心是把「改哪几个 0」这个看似需要枚举子集的问题，化成「选一段连续区间」的区间问题。交换论证保证最优解可以写成翻转某个区间内的全部 0；随后的两种做法都在「0 的个数不超过 $k$ 的最长区间」上做文章：双指针利用两端点的单调性把枚举压到线性，二分答案利用长度可行性的单调性换取更通用的判定框架。

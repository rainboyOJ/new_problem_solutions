## 形式化题目

给定长度为 $n$ 的序列 $a_1, \dots, a_n$，其中 $a_i \in \{0, 1\}$，以及参数 $k$。

允许进行至多 $k$ 次操作，每次把某个 $a_i = 0$ 改成 $1$。设 $f(a)$ 为修改后序列中最长连续 $1$ 段的长度，要求最大化 $f(a)$，并给出一个达到最大值的修改后序列。

## 解法总览

三个解法的共同起点是同一条结论：最优解总是「选一段连续区间，把区间内的 0 全部改成 1」，于是问题变成「找 0 的个数不超过 $k$ 的最长区间」。区别在于怎样找这段区间。

| 解法 | 核心观察 | 复杂度 | 适用场景 | 对应代码 |
| --- | --- | --- | --- | --- |
| 解法一：枚举所有区间（暴力基线） | 直接枚举左右端点，用 0 个数前缀和判合法性 | $O(n^2)$ | 只适合小数据，用来对拍和理解题意 | `brute2.cpp`、`brute2.py` |
| 解法二：双指针（滑动窗口，主解） | 右端点纳入元素，0 超标时左端点收缩，维护极大合法闭区间 $[l, r]$ | $O(n)$ | 满分做法，直观人脑视角，常数最小 | `main.cpp`、`main.py` |
| 解法三：二分答案 | 存在长度为 $L$ 的合法区间 $\Rightarrow$ 存在长度为 $L-1$ 的，长度可行性单调 | $O(n \log n)$ | 满分做法，换一种思路验证同一答案 | `main2.cpp`、`main2.py` |

解法二是解法一在「端点单调」上的优化：把 $O(n^2)$ 的枚举压成 $O(n)$ 的尺取。解法三与前两者并列，是独立的另一条路线，适合在双指针单调性不易直接看出时换个角度。正式主解取解法二。

（另有一份 `brute.cpp` 用 DFS 枚举「把哪几个 0 改成 1」，是 $2^{\#0}$ 级的指数做法，只能小数据对拍，正文不展开。）

## 解法一：枚举所有区间 + 前缀和

!!! info 最优解等价于翻转某段连续区间内的全部 0。
最优解里被翻转的 0，一旦中间夹着没翻的 0，把它换成翻转那个 0 既不增加翻转次数又只会让 1 段不变短，所以总能把被翻转的 0 整理成连续一段。于是只需枚举区间 $[i, j]$，用 0 个数前缀和判断其中 0 的个数是否 $\leqslant k$，合法就用区间长度更新答案，$O(n^2)$。
!!!

### 思路

暴力枚举「改哪几个 0」是指数级的，没法用。先把它拉回到多项式：由下面的交换论证，最优解翻转的 0 一定能在位置序列上连成一段，所以只要考虑「翻转某个区间 $[i, j]$ 内的全部 0」。

于是最直接的做法是枚举所有区间。区间有 $O(n^2)$ 个，每次判断「区间内 0 的个数是否不超过 $k$」如果还要重新数一遍就是 $O(n^3)$，太慢。预处理一个 0 个数的前缀和 `zero_pref`，区间 $[i, j]$ 内 0 的个数就是 `zero_pref[j] - zero_pref[i-1]`，单次判断降到 $O(1)$。

整体 $O(n^2)$，$n = 3\times10^5$ 时不可行，但逻辑最直白，适合作为对拍基准，也说明下一步要优化什么。

**关键结论**：最优解 $\iff$ 翻转某个区间 $[i, j]$ 内的全部 0。

*证明*：设最优解翻转的 0 的位置集合为 $S$。若 $S$ 不是一段连续位置（中间夹着没翻的 0），取 $S$ 中两个被翻转的 0 之间的某个未翻转 0，把它的状态改成反转，同时取消 $S$ 中最靠边的一个已翻转 0 的翻转。翻转的 0 总数不变，仍然合法；而被翻转 0 的位置跨度只会缩小，最长连续 1 段不变差。反复这样做，被翻转的 0 可以整理成连续一段，等价于翻转某个区间内的所有 0。

### 瓶颈

瓶颈在于 $O(n^2)$ 个区间都要枚举一遍。但注意：固定左端点 $i$ 时，右端点 $j$ 越往右，区间内 0 的个数只增不减；一旦某个 $j$ 让 0 的个数超过 $k$，再往右一定都不合法，没必要继续试。更重要的是，当左端点 $i$ 右移时，最远的合法右端点只会右移、不会左移。抓住这条单调性就能砍掉大量重复枚举，这就是双指针。

## 解法二：双指针（滑动窗口，主解）

!!! info 右端点逐个纳入窗口，0 个数超标时收缩左端点，维护闭区间 $[l, r]$。
维护闭区间 $[l, r]$。右指针 $r$ 从左往右扫，将元素依次纳入窗口（遇到 0 则计数加一）。当窗口内 0 的个数超过 $k$ 时，不断收缩左指针 $l$（若移出的元素是 0 则计数减一）直到窗口重新合法。此时 $[l, r]$ 必然是包含不超过 $k$ 个 0 的极大合法子段，直接用其长度 $r - l + 1$ 尝试更新答案。每个元素进出窗口各最多一次，总时间复杂度严格 $O(n)$。
!!!

### 思路

双指针的本质**仍然是暴力区间枚举**，但如果直接**站在右端点 $r$ 的视角来看**，整个过程会变得极其直观：

1. **每个 $r$ 总是想要去找对应的最左 $l$**：对于每个固定的右边界 $r$，我们都希望左边界 $l$ 尽可能向左延伸，以取得以 $r$ 为结尾的最大合法区间 $[l, r]$；
2. **当 $r \to r+1$ 时，$l$ 不可能变得更小（反证法）**：
   - 设以 $r$ 为结尾的最左合法起点为 $L(r)$，此时区间 $[L(r), r]$ 内 0 的个数 $\leqslant k$；
   - 当右端点推进到 $r + 1$ 时，假设新的最左合法起点比之前更小，即 $L(r+1) < L(r)$；
   - 那么区间 $[L(r+1), r]$ 是合法区间 $[L(r+1), r+1]$ 的真子集，其包含 0 的个数必定 $\leqslant$ 后者 $\leqslant k$，即 $[L(r+1), r]$ 本身也是合法的；
   - 但这意味着在上一轮以 $r$ 为结尾时，就已经存在一个比 $L(r)$ 更靠左的合法起点 $L(r+1)$，这与 $L(r)$ 是“最左合法位置”相矛盾！
   - 因此必有 $L(r+1) \geqslant L(r)$，左端点 $l$ **绝不可能向左回退**；
3. **物理图像：相当于 $r$ 在拖着 $l$ 往右移动**：$r$ 主导向前迈步，一旦窗口内 0 超标，$r$ 就把 $l$ 往右“拖动”收缩，直到重新合法。

#### 算法推进流程

维护当前闭区间 $[l, r]$（初始 $l=1, r=1$），变量 `cnt0` 动态维护当前窗口内 0 的个数：

1. **右端点扩张**：右指针 $r$ 步进，将 $a_r$ 纳入窗口：若 $a_r = 0$，则 `cnt0++`；
2. **左端点收缩**：若当前 `cnt0 > k`，说明窗口已不合法，被 $r$“拖着”右移左端点收缩窗口：若 $a_l = 0$，则 `cnt0--`，随后 $l \leftarrow l + 1$。重复直到 `cnt0 <= k`；
3. **结算答案**：离开收缩循环后，当前区间 $[l, r]$ 是以当前 $r$ 结尾的最长合法区间，用其长度 $r - l + 1$ 尝试更新全局最大值，并记录最优起始位置。

整个过程中，左右指针均只进不退，每个元素至多进窗一次、出窗一次，复杂度为严格的 $O(n)$。

## 解法三：二分答案（记账法）

!!! info 长度可行性单调，采用闭区间 `while (l <= r)` + 随手记账法寻找最大可行长度。
若存在长度 $L$ 且 0 的个数 $\leqslant k$ 的区间，去掉一端得到长度 $L-1$ 的子区间，0 的个数只会更少，仍合法。因此「长度 $L$ 可行」关于 $L$ 单调。在闭区间 $[0, n]$ 上二分长度：只要 `check(mid)` 判定存在合法窗口，立即记账 `best_len = mid` 并顺手保存起点位置，随后贪心向右探寻 `l = mid + 1`；否则收缩 `r = mid - 1`。总时间复杂度 $O(n \log n)$。
!!!

### 思路

换一个角度问：「答案长度至少是 $L$，可以吗？」只要能快速回答这个问题，就能对 $L$ 二分。

**关键结论**：若存在长度为 $L$ 的合法区间（0 的个数 $\leqslant k$），则一定存在长度为 $L-1$ 的合法区间。

*证明*：长度为 $L$ 的合法区间，去掉任意一端就得到长度 $L-1$ 的子区间。子区间的 0 的个数不会比原区间多，仍然 $\leqslant k$，所以也合法。

由此，「答案至少是 $L$」这个命题关于 $L$ 具备单调性：小的长度都可行、大的长度未必可行。这正是二分答案的前提。

不同于传统模板去反向寻找“第一个不可行的位置再减一”，这里直接按照 rbook1《二分记账法与二分答案》的**闭区间 `while (l <= r)` + 随手记账**模式落地：

1. **二分区间与初值**：搜索区间为真实的长度范围 $[0, n]$，定义记账变量 `best_len = 0, best_l = 1`；
2. **检验中点**：取 $mid = (l + r) / 2$。调用 `check(mid)`：利用 0 的前缀和在 $O(n)$ 时间内扫描是否存在长度恰为 $mid$ 且 0 的个数 $\leqslant k$ 的窗口；
3. **随手记账与推进**：
   - **若可行（`check` 成功）**：说明长度 $mid$ 已经是一个合法解！**立刻记账：`best_len = mid`**，并将 `check` 中捕获到的起始位置顺手存入 `best_l`；接着贪心地向右探寻更大答案：`l = mid + 1`；
   - **若不可行**：说明长度 $mid$ 及更大者均不可能成立，向左收缩：`r = mid - 1`；
4. **二分结束**：退出循环时，最大可行长度 `best_len` 与最佳起始坐标 `best_l` 双双就绪，直接进入区间修改并输出，无需额外做线性反查。

## 复杂度对比

| 解法 | 时间 | 空间 | 说明 |
| --- | --- | --- | --- |
| 枚举所有区间 | $O(n^2)$ | $O(n)$ | 基线，$n = 3\times10^5$ 超时 |
| 双指针（闭区间视角） | $O(n)$ | $O(n)$ | 推荐主解，人脑视角 $[l, r]$，两端点单调只进不退 |
| 二分答案 | $O(n \log n)$ | $O(n)$ | 依赖长度可行性单调，比双指针多一个 $\log$ |

三条路线得到的是同一个答案（优化目标相同）。双指针把单调性用到极致，是常数最小的满分做法；二分答案多一层 $\log$，但当「判定一个长度是否可行」本身就复杂、难以直接尺取时，二分往往是更通用的框架。

## 总结

题目的核心是把「改哪几个 0」这个看似需要枚举子集的问题，化成「选一段连续区间」的区间问题。交换论证保证最优解可以写成翻转某个区间内的全部 0；随后的两种做法都在「0 的个数不超过 $k$ 的最长区间」上做文章：双指针利用两端点的单调性把枚举压到线性，二分答案利用长度可行性的单调性换取更通用的判定框架。

# 1681D Required Length

## 题目描述

给定两个整数 $n$ 和 $x$。你可以对整数 $x$ 执行若干次操作。

每次操作如下：选择 $x$ 的十进制表示中至少出现过一次的任意数字 $y$，并将 $x$ 替换为 $x \cdot y$。

你需要使 $x$ 的十进制表示长度（不含前导零）等于 $n$。问最少需要多少次操作才能实现？

## 输入格式

输入仅有一行，包含两个整数 $n$ 和 $x$（$2 \le n \le 19$；$1 \le x < 10^{n-1}$）。

## 输出格式

输出一个整数——使 $x$ 的十进制表示长度（不含前导零）等于 $n$ 所需的最少操作次数，若无法实现则输出 $-1$。

## 说明

在第二个样例中，可以通过以下操作序列实现目标：

- 将 $x$ 乘以 $2$，得到 $x = 2 \cdot 2 = 4$；
- 将 $x$ 乘以 $4$，得到 $x = 4 \cdot 4 = 16$；
- 将 $x$ 乘以 $6$，得到 $x = 16 \cdot 6 = 96$；
- 将 $x$ 乘以 $9$，得到 $x = 96 \cdot 9 = 864$。

## 输入输出样例 #1

### 输入 #1

```
2 1
```

### 输出 #1

```
-1
```

## 输入输出样例 #2

### 输入 #2

```
3 2
```

### 输出 #2

```
4
```

## 输入输出样例 #3

### 输入 #3

```
13 42
```

### 输出 #3

```
12
```

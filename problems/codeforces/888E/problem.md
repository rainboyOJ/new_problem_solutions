# 888E Maximum Subsequence

## 题目描述

给定一个由 *a* 组成的整数数组，数组长度为 *n*，此外还给定一个整数 *m*。你需要选择一个下标序列 *b*<sub>1</sub>, *b*<sub>2</sub>, ..., *b*<sub>*k*</sub> （ 1 ≤ *b*<sub>1</sub> < *b*<sub>2</sub> < ... < *b*<sub>*k*</sub> ≤ *n* ），使得 * 的值最大。选择的序列也可以为空。

输出 * 可能取得的最大值。

## 输入格式

第一行包含两个整数 *n* 和 *m* （ 1 ≤ *n* ≤ 35， 1 ≤ *m* ≤ 10<sup>9</sup> ）。

第二行包含 *n* 个整数 *a*<sub>1</sub>、 *a*<sub>2</sub>、……、 *a*<sub>*n*</sub> （ 1 ≤ *a*<sub>*i*</sub> ≤ 10<sup>9</sup> ）。

## 输出格式

输出 * 可能取得的最大值。

## 注

在第一个样例中，可以选择下标序列 *b* = {1, 2} ，此时总和 * 等于 7 ，对 4 取模后就是 3。

在第二个样例中，可以选择下标序列 *b* = {3} 。

## 输入输出样例 #1

### 输入 #1

```
4 4
5 2 4 1
```

### 输出 #1

```
3
```

## 输入输出样例 #2

### 输入 #2

```
3 20
199 41 299
```

### 输出 #2

```
19
```

# 1155D Beautiful Array

## 题目描述

给定一个由 $n$ 个整数组成的数组 $a$。数组的美丽度是该数组的一些连续子数组的最大和（该子数组可以为空）。例如，数组 [10, -5, 10, -4, 1] 的美丽度为 15，数组 [-3, -5, -1] 的美丽度为 0。

你可以选择 $a$ 中的至多一个连续子数组，将该子数组中的所有值乘以 $x$。你希望在至多进行一次这样的操作后，使数组的美丽度最大化。

## 输入格式

第一行包含两个整数 $n$ 和 $x$（$1 \le n \le 3 \cdot 10^5, -100 \le x \le 100$） — 数组 $a$ 的长度和整数 $x$。

第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$（$-10^9 \le a_i \le 10^9$） — 数组 $a$。

## 输出格式

输出一个整数 — 在将属于某个连续子数组 $x$ 的所有值乘以后，数组 $a$ 的最大可能美丽度。

## 说明

在第一个测试用例中，我们需要将子数组 [-2, 1, -6] 相乘，数组变为 [-3, 8, 4, -2, 12]，美丽度为 22（[-3, 8, 4, -2, 12]）。

在第二个测试用例中，我们无需对任何子数组进行乘法操作。

在第三个测试用例中，无论我们乘以哪个子数组，数组的美丽度都将等于 0。

## 输入输出样例 #1

### 输入 #1

```
5 -2
-3 8 -2 1 -6
```

### 输出 #1

```
22
```

## 输入输出样例 #2

### 输入 #2

```
12 -3
1 3 3 7 1 3 3 7 1 3 3 7
```

### 输出 #2

```
42
```

## 输入输出样例 #3

### 输入 #3

```
5 10
-1 -2 -3 -4 -5
```

### 输出 #3

```
0
```

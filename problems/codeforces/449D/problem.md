# 449D Jzzhu and Numbers

## 题目描述

Jzzhu 有 *n* 个非负整数 *a*<sub>1</sub>, *a*<sub>2</sub>, ..., *a*<sub>*n*</sub>。我们把一串下标 *i*<sub>1</sub>, *i*<sub>2</sub>, ..., *i*<sub>*k*</sub> (1 ≤ *i*<sub>1</sub> < *i*<sub>2</sub> < ... < *i*<sub>*k*</sub> ≤ *n*) 称为一个大小为 *k* 的组。

Jzzhu 想知道，满足 *a*<sub>*i*1</sub> & *a*<sub>*i*2</sub> & ... & *a*<sub>*i**k*</sub> = 0 (1 ≤ *k* ≤ *n*) 的组共有多少个。请帮助他计算这个数量，并输出其对 1000000007 (10<sup>9</sup> + 7) 取模后的结果。运算符 *x* & *y* 表示对两个数进行按位与运算。

## 输入格式

第一行包含一个整数 *n* (1 ≤ *n* ≤ 10<sup>6</sup>)。第二行包含 *n* 个整数 *a*<sub>1</sub>, *a*<sub>2</sub>, ..., *a*<sub>*n*</sub> (0 ≤ *a*<sub>*i*</sub> ≤ 10<sup>6</sup>)。

## 输出格式

输出一个整数，表示所求组的数量对 1000000007 (10<sup>9</sup> + 7) 取模后的结果。

## 输入输出样例 #1

### 输入 #1

```
3
2 3 3
```

### 输出 #1

```
0
```

## 输入输出样例 #2

### 输入 #2

```
4
0 1 2 3
```

### 输出 #2

```
10
```

## 输入输出样例 #3

### 输入 #3

```
6
5 2 0 5 2 1
```

### 输出 #3

```
53
```

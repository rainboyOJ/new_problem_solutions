# 383E Vowels

## 题目描述

Iahubina 已经厌倦了各种复杂的语言，于是她决定发明一种全新的、简单的语言。她已经准备好了一个词典，里面有 *n* 个三字母词。所谓三字母词，就是由恰好 3 个小写字母组成，字母范围限定在英文字母表的前 24 个字母（也就是从 *a* 到 *x*）。她决定把其中一部分字母定为元音，剩下的都是辅音。整门语言的规则很简单：只要一个词里至少有一个元音，这个词就是 正确的。

但问题是，Iahubina 忘了哪些字母是元音，她想找出所有可能的元音集合。于是她向 Iahub 提了些问题。每个问题都会给出一组被视为元音的字母（本题中），她想知道在这组元音下，词典里有多少词是“正确”的。

Iahubina 想知道所有可能问题答案的平方的 *xor* 结果。共有 2<sup>24</sup> 个不同的问题，它们是前 24 个字母的所有子集。帮帮 Iahub 算出这个数吧。

## 输入格式

第一行一个整数 *n*，满足 (1 ≤ *n* ≤ 10<sup>4</sup>)。接下来 *n* 行，每行一个三字母词，都是由 3 个小写字母组成。保证没有重复的三字母词。

## 输出格式

输出一个整数，表示所有查询答案的平方的 *xor* 结果。

## 输入输出样例 #1

### 输入 #1

```
5
abc
aaa
ada
bcd
def
```

### 输出 #1

```
0
```

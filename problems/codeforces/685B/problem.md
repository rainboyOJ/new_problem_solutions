# 685B Kay and Snowflake

## 题目描述

当一块魔镜碎片击中了凯的眼睛，他对玫瑰的美丽不再感兴趣。现在，他喜欢看雪花。

有一次，他发现了一片巨大的雪花，它的形状像一棵树（一棵连通无环图），由 *n* 个节点组成。树的根节点编号是 1。凯对这棵树的结构非常感兴趣。

经过一番研究，他提出了 *q* 个查询。第 *i* 个查询要求找出节点 *v*<sub>*i*</sub> 所在子树的重心。你的任务是回答所有查询。

子树 指的是以某节点为根，包含该节点及其所有后代（无论是直接还是间接）的树的部分。换句话说，节点 *v* 的子树由所有满足“从节点 *u* 到根节点的路径上包含节点 *v*”的节点 *u* 组成。

重心 是指这样一个节点：如果把它从树中删除，剩下的连通块中最大那个的大小不会超过原树（或子树）大小的一半。

## 输入格式

第一行包含两个整数 *n* 和 *q*（2 ≤ *n* ≤ 300 000，1 ≤ *q* ≤ 300 000）——原始树的节点数和查询数量。

第二行包含 *n* - 1 个整数 *p*<sub>2</sub>, *p*<sub>3</sub>, ..., *p*<sub>*n*</sub>（1 ≤ *p*<sub>*i*</sub> ≤ *n*）——编号从 2 到 *n* 的节点的父节点编号。节点 1 是树的根。保证这些 *p*<sub>*i*</sub> 构成一棵合法的树。

接下来 *q* 行，每行一个整数 *v*<sub>*i*</sub>（1 ≤ *v*<sub>*i*</sub> ≤ *n*）——表示查询的子树根节点编号。

## 输出格式

对于每个查询，输出对应子树的一个重心节点编号。如果有多个符合条件的节点，输出其中任意一个即可。保证每个子树至少有一个重心。

## 说明

*
第一个查询是整棵树的重心——节点 3。如果删掉节点 3，树会分成四个连通块，其中两个大小为 1，另外两个大小为 2。

第二个节点的子树只有它自己，所以答案是 2。

节点 3 是它自己子树的重心。

节点 5 的子树重心可以是节点 5 或 6，两者都算正确答案。

## 输入输出样例 #1

### 输入 #1

```
7 4
1 1 3 3 5 3
1
2
3
5
```

### 输出 #1

```
3
2
3
6
```

# 1398C Good Subarrays

## 题目描述

给你一个数组 $a_1, a_2, \dots , a_n$，里面的元素都是从 $0$ 到 $9$ 的整数。我们说一个子数组 $a_l, a_{l+1}, a_{l+2}, \dots , a_{r-1}, a_r$ 是“好”的，如果这个子数组的元素和刚好等于它的长度（$\sum\limits_{i=l}^{r} a_i = r - l + 1$）。

举个例子，如果 $a = [1, 2, 0]$，那么有 $3$ 个好子数组，分别是 $a_{1 \dots 1} = [1], a_{2 \dots 3} = [2, 0]$ 和 $a_{1 \dots 3} = [1, 2, 0]$。

请你计算数组 $a$ 中有多少个好子数组。

## 输入格式

第一行一个整数 $t$（$1 \le t \le 1000$）——测试用例的数量。

每个测试用例的第一行一个整数 $n$（$1 \le n \le 10^5$）——数组 $a$ 的长度。

每个测试用例的第二行是一个长度为 $n$ 的字符串，字符串中的第 $i$ 个字符表示 $a_i$ 的值（十进制数字）。

保证所有测试用例中 $n$ 的总和不超过 $10^5$。

## 输出格式

每个测试用例输出一个整数——数组 $a$ 中好子数组的数量。

## 说明

第一个测试用例已经在题目描述中讲过了。

第二个测试用例中，有 $6$ 个好子数组，分别是 $a_{1 \dots 1}$、$a_{2 \dots 2}$、$a_{1 \dots 2}$、$a_{4 \dots 4}$、$a_{5 \dots 5}$ 和 $a_{4 \dots 5}$。

第三个测试用例中，只有一个好子数组：$a_{2 \dots 6}$。

## 输入输出样例 #1

### 输入 #1

```
3
3
120
5
11011
6
600005
```

### 输出 #1

```
3
6
1
```

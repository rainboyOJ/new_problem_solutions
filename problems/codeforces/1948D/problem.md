# 1948D Tandem Repeats?

## 题目描述

给你一个字符串 $s$，里面包含小写拉丁字母和/或问号。

所谓 串联重复，就是长度为偶数的字符串，且它的前半部分和后半部分完全一样。

字符串 $a$ 是字符串 $b$ 的子串，意思是你可以通过删掉 $b$ 开头和结尾的若干（可能是零个或全部）字符得到 $a$。

你的任务是把每个问号替换成某个小写拉丁字母，使得字符串中最长的串联重复子串长度尽可能大。

## 输入格式

第一行是一个整数 $t$ ($1 \le t \le 1000$) — 测试用例的数量。

接下来每个测试用例只有一行，包含一个字符串 $s$ ($1 \le |s| \le 5000$)，只由小写拉丁字母和/或问号组成。

所有测试用例中字符串的总长度不超过 $5000$。

## 输出格式

对每个测试用例，输出一个整数 — 替换问号后，字符串中最长串联重复子串的最大长度。

如果无法构造出任何串联重复子串，输出 $0$。

## 输入输出样例 #1

### 输入 #1

```
4
zaabaabz
?????
code?????s
codeforces
```

### 输出 #1

```
6
4
10
0
```

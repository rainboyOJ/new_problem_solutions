# 977F Consecutive Subsequence

## 题目描述

给你一个长度为 $n$ 的整数数组。

你需要从中挑出一个最长的子序列，这个子序列必须是连续递增的整数序列。换句话说，要求的序列形如 $[x, x + 1, \dots, x + k - 1]$，其中 $x$ 是起始整数，$k$ 是长度。

数组的子序列是通过删除若干（可以是零个）元素得到的，删除的元素不必连续，但剩下的元素顺序不变。举个例子，数组 $[5, 3, 1, 2, 4]$ 的子序列有 $[3]$、$[5, 3, 1, 2, 4]$、$[5, 1, 4]$，但 $[1, 3]$ 不是子序列。

## 输入格式

第一行输入一个整数 $n$ （$1 \le n \le 2 \cdot 10^5$）——数组长度。第二行输入 $n$ 个整数 $a_1, a_2, \dots, a_n$ （$1 \le a_i \le 10^9$）——数组元素。

## 输出格式

第一行输出 $k$ ——满足条件的最长子序列长度。

第二行输出该最长子序列中元素在原数组中的 任意 下标序列。

## 说明

第一个样例所有合法答案（以下标序列表示）：

- $[1, 3, 5, 6]$
- $[2, 3, 5, 6]$

第二个样例所有合法答案：

- $[1, 4]$
- $[2, 5]$
- $[3, 6]$

第三个样例所有合法答案：

- $[1]$
- $[2]$
- $[3]$
- $[4]$

第四个样例所有合法答案：

- $[1, 2, 3, 7, 8, 9]$

### 输入 #1

```
7

```

### 输出 #1

```

2 3 5 6
```

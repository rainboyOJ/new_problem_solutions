## 形式化题目

给定长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。要求选出下标

$$i_1 < i_2 < \cdots < i_k,$$

使得存在整数 $x$ 满足 $a_{i_j} = x + j - 1$，并使 $k$ 最大，最后输出一组取到最大 $k$ 的下标。

原题把这样的子序列称为“连续递增子序列”，指相邻两项的值恰好相差 $1$。

## 正解

### 思路

先按最直接的方式定义状态：$f_i$ 表示以位置 $i$ 结尾的最长连续递增子序列长度。位置 $i$ 的前面只可能接值 $a_i - 1$，于是

$$f_i = 1 + \max\{\, f_j \mid j < i,\ a_j = a_i - 1 \,\},$$

右侧集合为空时 $f_i = 1$。这个式子在说：以 $a_i$ 结尾的序列，去掉末尾后必须以 $a_i - 1$ 结尾。

按它直接实现，每处理一个位置都要回扫所有 $j < i$，复杂度 $O(n^2)$。$n = 2 \cdot 10^5$ 时约有 $2 \times 10^{10}$ 次比较，会超时。

回扫其实在反复回答同一个问题：值 $a_i - 1$ 的哪个出现位置让 $f$ 最大。前驱的值是固定的，只有位置不确定，所以可以把“扫位置”换成“查值”。记 $last[v]$ 为值 $v$ 最后一次出现的下标，转移就变成

$$f_i = f_{last[a_i - 1]} + 1,$$

查不到时取 $f_i = 1$。

只留最后一次出现就够了。同一个值 $v$ 的各次出现，$f$ 随时间只增不减：后面的 $v$ 能用前面 $v$ 用过的一切前驱，而且值 $v - 1$ 的桶只会被换成长度更大的位置。最新一次出现的 $v$ 因此就是值 $v$ 上的最优结尾。

样例 1 的 $a = [3, 3, 4, 7, 5, 6, 8]$ 逐位计算如下，下标与 $pre$ 都从 $1$ 开始计：

| $i$ | $a_i$ | $last[a_i - 1]$ | $f_i$ | $pre_i$ |
| --- | --- | --- | --- | --- |
| 1 | 3 | 无 | 1 | 无 |
| 2 | 3 | 无 | 1 | 无 |
| 3 | 4 | 2 | 2 | 2 |
| 4 | 7 | 无 | 1 | 无 |
| 5 | 5 | 3 | 3 | 3 |
| 6 | 6 | 5 | 4 | 5 |
| 7 | 8 | 4 | 2 | 4 |

第 $1$、$2$ 位都是 $3$，长度都是 $1$，但桶里留下的是第 $2$ 位，所以下标 $3$ 的 $4$ 接的是它。全程 $f_6 = 4$ 最大，从 $i = 6$ 沿 $pre$ 回退得到 $6 \to 5 \to 3 \to 2$，反转后正是样例答案 `2 3 5 6`。C++ 版直接把下标建成 $1$ 基，与表格一致；Python 版从 $0$ 开始，写输出时统一加 $1$。

#### 正确性证明

记 $F(i)$ 为以位置 $i$ 结尾的真实最长长度。目标是证明代码算出的 $f_i = F(i)$，并且沿 $pre$ 走出的链长度等于 $f_i$。

- 由定义，去掉 $i$ 后剩下的部分必须以某个 $j < i$、$a_j = a_i - 1$ 结尾，因此 $F(i) = 1 + \max\{F(j) \mid j < i,\ a_j = a_i - 1\}$；没有候选前驱时 $F(i) = 1$。
- 同值单调：设 $i < j$ 且 $a_i = a_j = v$。两者的候选前驱都来自值 $v - 1$，$j$ 的候选集合包含 $i$ 的候选集合，取最大值不会变小，所以 $F(i) \leqslant F(j)$。
- 由单调性，$last[v]$ 作为值 $v$ 的最后一次出现，取到了值 $v$ 上的最大长度。
- 归纳：设所有 $j < i$ 都有 $f_j = F(j)$。若有前驱，$f_i = f_{last[a_i - 1]} + 1 = F(j^*) + 1 = F(i)$，其中 $j^*$ 是值 $a_i - 1$ 上的最优结尾；若无前驱，$f_i = 1 = F(i)$。
- 取 $f$ 的最大值即 $\max_i F(i)$，就是题目要求的 $k$。
- 还原：$pre_i$ 指向值 $a_i - 1$ 的位置，所以 $pre_i < i$ 且 $a_{pre_i} = a_i - 1$。沿 $pre$ 逆序读出的下标严格递增，值逐项加 $1$，长度等于 $f_i$。

::: warning
把桶改成“值第一次出现的位置”，小样例往往也能过，但对 $a = [1, 2, 3, 0, 1, 2, 3, 4]$ 会输出 $4$。正确答案是 $5$，即下标 $4, 5, 6, 7, 8$ 上的 $0, 1, 2, 3, 4$。错在算下标 $7$ 的 $3$ 时，值 $2$ 的桶还停在下标 $2$（长度 $2$），长度只长到 $3$，链条从这里就短了一层。所以桶必须每次出现都覆盖。
:::

### 复杂度

- 时间：一次扫描，每个位置一次查表、一次写表，两版都靠哈希表做到期望 $O(1)$ 的桶操作，总计期望 $O(n)$。
- 空间：$a$、$f$、`pre` 各占 $n$ 项，桶里最多 $n$ 个不同的值，总计 $O(n)$。
- 值域到 $10^9$，放不下“下标即值”的数组，所以桶用哈希表：C++ 是 `unordered_map`，Python 是 `defaultdict`。

## 总结

- 前驱的值由 $a_i$ 唯一确定，位置才是不确定的部分。把“位置”这层不确定性换成“值 → 最后一次出现”的映射，$O(n^2)$ 的枚举就变成一次查表。
- 支撑“只留最后一次”的是同值 $f$ 单调不减：后出现的同值元素能继承前一次的全部前驱。
- 需要输出方案时再加一个 `pre` 数组，沿链回退即可，不用重新搜索。
- 同一套写法可以推广到相邻两项差为定值 $d$ 的情形，把 $a_i - 1$ 换成 $a_i - d$。
- 验证：四组样例两版都通过；C++ 版与 $O(n^2)$ 暴力对拍 $200$ 组随机小数据、与 Python 版逐字节对拍 $120$ 组，均无差异（生成器覆盖窄值域重复、中等值域、近似递增长链、递减）；$n = 2 \cdot 10^5$ 的 $1, 2, \dots, n$ 链上，C++ 用时 $96$ ms、峰值 $15.1$ MiB，Python 在 $3$ 倍时限（$6000$ ms、$256$ MiB）内用时 $646$ ms、峰值 $62.6$ MiB。

# 1288C Two Arrays

## 题目描述

给定两个整数$n$和$m$。计算满足以下条件的数组对$(a, b)$的数量：

- 两个数组的长度都等于$m$；

- 每个数组的元素都是介于$1$到$n$（含）之间的整数；

- 对于任何从$1$到$m$的索引$i$，都满足$a_i \le b_i$；

- 数组$a$按非降序排列；

- 数组$b$按非升序排列。

由于结果可能非常大，请输出其对$10^9+7$取模后的值。

## 输入格式

唯一一行包含两个整数$n$和$m$（$1 \le n \le 1000$, $1 \le m \le 10$）。

## 输出格式

输出一个整数——满足上述条件的数组对$a$和$b$的数量，并对$10^9+7$取模。

## 提示

在第一个测试用例中有$5$个符合条件的数组：

- $a = [1, 1], b = [2, 2]$；

- $a = [1, 2], b = [2, 2]$；

- $a = [2, 2], b = [2, 2]$；

- $a = [1, 1], b = [2, 1]$；

- $a = [1, 1], b = [1, 1]$。

## 输入输出样例 #1

### 输入 #1

```
2 2
```

### 输出 #1

```
5
```

## 输入输出样例 #2

### 输入 #2

```
10 1
```

### 输出 #2

```
55
```

## 输入输出样例 #3

### 输入 #3

```
723 9
```

### 输出 #3

```
157557417
```

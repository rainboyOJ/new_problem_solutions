## 形式化题目

给定一个长度为 $n$ 的二进制字符串 $s$（由字符 `'0'` 和 `'1'` 组成）。

对于任意一个二进制模式串 $p$，如果存在一个同长度的二进制串 $q$，满足对每个位置 $i$（$1 \leqslant i \leqslant |p|$），都能在 $q$ 中找到一个包含该位置的子串 $q[l \dots r]$（$l \leqslant i \leqslant r$），使得 $p_i$ 是该子串的**众数**（即 $p_i$ 出现次数不低于 $\lceil (r - l + 1) / 2 \rceil$），则称 $q$ 是 $p$-合法的。

定义 $f(p)$ 为所有 $p$-合法二进制串 $q$ 中，字符 `'1'` 的**最少出现次数**。

求字符串 $s$ 的所有 $\frac{n(n+1)}{2}$ 个子串的 $f$ 值总和：
$$\sum_{1 \leqslant i \leqslant j \leqslant n} f(s[i \dots j])$$

## 核心建模：众数迷局与三格滑块的物理真相

### 1. 剥离烟雾弹：为什么 `'0'` 自动满足？
题目要求对每个位置 $i$，都能找到一个区间使得 $p_i$ 成为众数：
- 若 $p_i = \text{'0'}$：我们只需看长度为 1 的单点区间 $[i, i]$。只要 $q_i = \text{'0'}$，该区间唯一的字符就是 `'0'`，众数必然是 `'0'`；就算 $q_i = \text{'1'}$，只要相邻有 `'0'`，长度为 2 的区间也能使 `'0'` 成为众数。因此，**目标串里的 `'0'` 从未构成过任何硬性阻碍**；
- **唯一的真正约束是：当 $p_i = \text{'1'}$ 时，我们必须在 $q$ 中放置 `'1'` 来把它“照亮”！**

### 2. 核心数学洞察：为了让 `'1'` 稀疏，覆盖区间必须极短
众数要求目标字符的占比必须达到至少 $50\%$：
- 如果选择长度为 10 的长区间，就必须在 $q$ 中硬塞进至少 5 个 `'1'`；
- 目标是求最少使用 `'1'` 的个数，因此**我们希望用最稀疏的 `'1'` 辐射尽可能多的位置**。
- 这要求**覆盖区间必须压缩到最短（长度为 1 或 2）**：
  - 长度为 1 时：需要 $\lceil 1/2 \rceil = 1$ 个 `'1'`；
  - 长度为 2 时：也仅需要 $\lceil 2/2 \rceil = 1$ 个 `'1'`（$1 \geqslant 1$ 成立）；
  - 长度为 3 时：若只有 1 个 `'1'`，占比 $\frac{1}{3} < 50\%$，无法成为众数！

### 3. 严格几何证明：为什么一个 `'1'` 恰好能遮住连续 3 个格子？
假设我们在串 $q$ 的位置 $k$ 处放置了一个唯一的 `'1'`（周围全为 `'0'`）：
$$\dots \ 0 \ \underbrace{0}_{k-1} \ \underbrace{1}_{k} \ \underbrace{0}_{k+1} \ 0 \ \dots$$
考察这个 `'1'` 能作为哪些位置的“众数保护伞”：
1. **对于位置 $k$**：选择区间 $[k, k]$（长度 1），包含 1 个 `'1'`，众数为 `'1'`；
2. **对于左邻居 $k-1$**：选择区间 $[k-1, k]$（长度 2），包含 1 个 `'0'` 和 1 个 `'1'`，`'1'` 占一半，众数依然是 `'1'`；
3. **对于右邻居 $k+1$**：选择区间 $[k, k+1]$（长度 2），包含 1 个 `'1'` 和 1 个 `'0'`，众数同理为 `'1'`。

若试图覆盖更远的格子（如 $k-2$ 或 $k+2$）：
包含该格子与 $k$ 的区间长度至少为 3，单靠这 1 个 `'1'` 绝不可能占到半数以上。
**数学结论**：**在位置 $k$ 放下一个 `'1'`，其能辐射保护的极限范围，严格等于闭区间 $[k-1, k+1]$（连续 3 个格子）！**

### 4. 贪心策略：遇到未覆盖的第一个 `'1'`，为什么放在 $i+1$？
从左到右扫描模式串，遇到目前最靠左且未被覆盖的 $p_i = \text{'1'}$。为了保护位置 $i$，我们手里的 `'1'` 有三种放法：
- 放在 $i-1$：覆盖 $[i-2, i]$，向右最远只能覆盖到 $i$；
- 放在 $i$：覆盖 $[i-1, i+1]$，向右覆盖到 $i+1$；
- **放在 $i+1$**：覆盖 $[i, i+2]$！

显然，**将 `'1'` 放在 $i+1$ 处是严格占优的贪心策略**：
它左脚刚好踩住 $i$（保住当前约束），右脚最大限度地探向未来，顺带照亮了 $i+1$ 和 $i+2$！
既然连续 3 个格子已被一次性覆盖，**下一个需要决策的未覆盖位置直接跳跃至 $i + 3$**！

## 解法一：后缀贡献动态规划（推荐正解 / 通杀 D2）

### 思路

::: info 贪心跳跃转化为后缀贡献 DP
考虑所有固定起点为 $i$ 的子串（即以 $i$ 开头的所有后缀子串）：
- **若 $s[i] = \text{'0'}$**：
  首字符为 `'0'` 自动满足，不消耗任何覆盖块。所有以 $i$ 开头的子串的贪心过程与以 $i+1$ 开头的子串完全相同：
  $$dp[i] = dp[i + 1]$$
- **若 $s[i] = \text{'1'}$**：
  任何以 $i$ 开头的子串只要包含 $i$，都必须且必然在此处放置一个覆盖块（覆盖 $[i, i+2]$）：
  1. 这个覆盖块对所有终点位于 $i, i+1, \dots, n-1$ 的子串都贡献了 $+1$ 次代价（共 $n - i$ 个子串获得增量）；
  2. 贪心指针随即跳跃至 $i + 3$。从 $i+3$ 往后的所有覆盖收益，被整体平移继承：
  $$dp[i] = dp[i + 3] + (n - i)$$

倒序从 $n-1$ 递推至 $0$，将所有起点的贡献累加即可：
$$\text{总和} = \sum_{i=0}^{n-1} dp[i]$$
:::

## 解法二：枚举起点 + 连续贪心跳步（Easy 版直观正解）

### 思路

::: info 双重循环区间滑动贪心
在 Easy 版本（$n \leqslant 100$）的规模下：
- 枚举子串左端点 $l \in [0, n-1]$；
- 维护变量 `covered_until` 记录当前已经覆盖到的最右下标；
- 向右推进右端点 $r \in [l, n-1]$：若遇到 $s[r] == \text{'1'}$ 且尚未被覆盖（$r > \text{covered\_until}$），则当前子串的代价加 1，并将 `covered_until` 扩展到 $r + 2$；
- 边移动边将当前代价累加进答案。
:::

## 总结

### 1. 复杂比例约束下的“极短窗口”稀疏化思维

- **识别信号**：题目给出形如“某个字符在区间中出现频次不低于占比 $P$（如众数 $\geqslant 50\%$）”的非线性约束，要求以最少资源构造满足条件的序列。
- **思维动作**：不要盲目去枚举大区间，而是求出满足该占比门槛的**最小可能整数窗口**（本题为长度 1 与 2）。
- **有效原因**：窗口越长，维持该比例所需的资源绝对数量越多；只有将窗口缩至极限，才能以单体离散资源（如单个 `'1'`）利用整数除法向上取整的边界效应，实现最稀疏、最高性价比的局部覆盖。
- **适用边界**：要求比例要求是下界且允许选择子区间；若要求全局固定长度窗口均满足比例，则必须使用滑动窗口双指针或前缀和差分。

### 2. 贪心探向未来：用已知保底最大化未知红利

- **识别信号**：序列从左到右推进，当前位置面临必须被解决的硬约束，且手头工具拥有覆盖一定左右半径的辐射能力。
- **思维动作**：坚决不把工具放在当前位置或过去的位置，而是将工具摆在“其左边界恰好卡死当前位置”的最右极限坐标处。
- **有效原因**：在严格单向决策树中，左侧历史已经全部合法化，向左回扑没有任何额外收益；将作用域重心最大限度地压向未来，能够以零边际成本顺带照亮后续未知节点，达到贪心选择的最优子结构。
- **适用边界**：要求序列无环、无向后逆序反悔依赖；若后续节点的收益与前置选择存在非线性惩罚，则局部右探贪心可能导致全局次优。

### 3. 决策跳跃与后缀贡献的 DP 闭环

- **识别信号**：贪心策略具有固定的“步长跳跃”特征（例如解决一次后强制向前跳跃 $K$ 步），同时要求对所有子区间的贪心总代价求和。
- **思维动作**：逆转枚举顺序采用后缀定义。将首个决策所产生的影响直接视作“对后续全部可能终点的批处理广播（$+ (n - i)$）”，随后将状态整体连线跳转至 $i + K$。
- **有效原因**：跳跃转移彻底斩断了中间状态的连续遍历，后缀累加把二维区间的双循环扁平化为一维的代数贡献广播，实现了复杂度从 $O(n^3) \to O(n^2) \to O(n)$ 的降维跨越。
- **适用边界**：要求贪心路径具有强烈的确定性（即无论子串右端点多长，只要包含起点 $i$，第一个被触发的动作完全一致）。

# 165E Compatible Numbers

## 题目描述

如果两个整数 *x* 和 *y* 按位进行“与”运算后的结果为零，也就是 *a* & *b* = 0，那么称它们是兼容的。例如，数字 90 (1011010<sub>2</sub>) 和 36 (100100<sub>2</sub>) 是兼容的，因为 1011010<sub>2</sub> & 100100<sub>2</sub> = 0<sub>2</sub>；而数字 3 (11<sub>2</sub>) 和 6 (110<sub>2</sub>) 则不兼容，因为 11<sub>2</sub> & 110<sub>2</sub> = 10<sub>2</sub>。

给定一个整数数组 *a*<sub>1</sub>, *a*<sub>2</sub>, ..., *a*<sub>*n*</sub>。请你对数组中的每个元素判断：它是否与数组中的某个其他元素兼容？如果答案是肯定的，还需要找出任意一个满足条件的元素。

## 输入格式

第一行包含一个整数 *n*（1 ≤ *n* ≤ 10<sup>6</sup>），表示数组中元素的个数。第二行包含 *n* 个以空格分隔的整数 *a*<sub>1</sub>, *a*<sub>2</sub>, ..., *a*<sub>*n*</sub>（1 ≤ *a*<sub>*i*</sub> ≤ 4·10<sup>6</sup>），表示数组中的元素。数组中允许出现相同的数字。

## 输出格式

输出 *n* 个整数 *ans*<sub>*i*</sub>。如果 *a*<sub>*i*</sub> 与给定数组 *a*<sub>1</sub>, *a*<sub>2</sub>, ..., *a*<sub>*n*</sub> 中的任何其他元素都不兼容，那么 *ans*<sub>*i*</sub> 应为 -1。否则，*ans*<sub>*i*</sub> 可以是任意一个满足 *a*<sub>*i*</sub> & *ans*<sub>*i*</sub> = 0 的数，并且 *ans*<sub>*i*</sub> 必须出现在数组 *a*<sub>1</sub>, *a*<sub>2</sub>, ..., *a*<sub>*n*</sub> 中。

## 输入输出样例 #1

### 输入 #1

```
2
90 36
```

### 输出 #1

```
36 90
```

## 输入输出样例 #2

### 输入 #2

```
4
3 6 3 6
```

### 输出 #2

```
-1 -1 -1 -1
```

## 输入输出样例 #3

### 输入 #3

```
5
10 6 9 8 2
```

### 输出 #3

```
-1 8 2 2 8
```

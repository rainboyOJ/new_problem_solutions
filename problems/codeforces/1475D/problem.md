# 1475D Cleaning the Phone

## 题目描述

Polycarp 经常使用自己的智能手机。他已经在手机上安装了 $n$ 个应用。编号为 $i$ 的应用占用 $a_i$ 单位的存储空间。

Polycarp 想通过卸载一些应用，至少释放 $m$ 单位的存储空间。

当然，对 Polycarp 来说，有些应用比其他应用更重要。于是他制定了一套评分规则，为每个应用分配一个整数 $b_i$：

- $b_i = 1$ —— 普通应用；
- $b_i = 2$ —— 重要应用。

按照这套规则，他的手机总共有 $b_1 + b_2 + \ldots + b_n$ 点便利度。

Polycarp 认为，如果卸载编号为 $i_1, i_2, \ldots, i_k$ 的应用，就能释放 $a_{i_1} + a_{i_2} + \ldots + a_{i_k}$ 单位的存储空间，同时损失 $b_{i_1} + b_{i_2} + \ldots + b_{i_k}$ 点便利度。

例如，当 $n=5$、$m=7$、$a=[5, 3, 2, 1, 4]$、$b=[2, 1, 1, 2, 1]$ 时，Polycarp 可以卸载以下应用组合（这里只列出部分方案）：

- 编号为 $1, 4$ 和 $5$ 的应用。这样可以释放 $a_1+a_4+a_5=10$ 单位的存储空间，并损失 $b_1+b_4+b_5=5$ 点便利度；
- 编号为 $1$ 和 $3$ 的应用。这样可以释放 $a_1+a_3=7$ 单位的存储空间，并损失 $b_1+b_3=3$ 点便利度；
- 编号为 $2$ 和 $5$ 的应用。这样可以释放 $a_2+a_5=7$ 单位的存储空间，并损失 $b_2+b_5=2$ 点便利度。

请帮助 Polycarp 选择一组应用，使得卸载它们后至少能释放 $m$ 单位的存储空间，并且损失的便利度最少；如果不存在这样的组合，请说明这一点。

## 输入格式

第一行包含一个整数 $t$（$1 \le t \le 10^4$）—— 测试用例的数量。接下来是 $t$ 个测试用例。

每个测试用例的第一行包含两个整数 $n$ 和 $m$（$1 \le n \le 2 \cdot 10^5$，$1 \le m \le 10^9$）—— Polycarp 手机中的应用数量，以及需要释放的存储空间。

每个测试用例的第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^9$）—— 每个应用占用的存储空间。

每个测试用例的第三行包含 $n$ 个整数 $b_1, b_2, \ldots, b_n$（$1 \le b_i \le 2$）—— 每个应用对应的便利度。

保证所有测试用例中 $n$ 的总和不超过 $2 \cdot 10^5$。

## 输出格式

对于每个测试用例，单独输出一行：

- 如果不存在卸载后能至少释放 $m$ 单位存储空间的应用组合，输出 -1；
- 如果存在这样的组合，输出 Polycarp 最少会损失的便利度。

## 说明

在第一个测试用例中，最优方案是卸载编号为 $2$ 和 $5$ 的应用，可以释放 $7$ 单位的存储空间。$b_2+b_5=2$。

在第二个测试用例中，即使卸载唯一的应用，也只能释放 $2$ 单位的存储空间，距离所需的 $3$ 单位还差一点。

在第三个测试用例中，最优方案是卸载编号为 $1$、$2$、$3$ 和 $4$ 的应用，可以释放 $10$ 单位的存储空间。$b_1+b_2+b_3+b_4=6$。

在第四个测试用例中，最优方案是卸载编号为 $1$、$3$ 和 $4$ 的应用，可以释放 $12$ 单位的存储空间。$b_1+b_3+b_4=4$。

在第五个测试用例中，最优方案是卸载编号为 $1$ 和 $2$ 的应用，可以释放 $5$ 单位的存储空间。$b_1+b_2=3$。

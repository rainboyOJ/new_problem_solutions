# 1555D Say No to Palindromes

## 题目描述

我们称一个字符串为美丽字符串，如果它不包含长度至少为$2$的回文子串。回文串是指正读反读都相同的字符串，例如a、bab、acca、bcabcbacb都是回文串，而ab、abbbaa、cccb则不是。

定义字符串的美化成本为使其变为美丽字符串所需的最小操作次数，每次操作可以将字符串中的任意字符改为拉丁字母表前$3$个小写字母之一。

给定一个长度为$n$的字符串$s$，其中每个字符都是拉丁字母表前$3$个小写字母之一。

需要回答$m$个查询——计算字符串$s$从第$l_i$到第$r_i$个位置（含）的子串的美化成本。

## 输入格式

第一行包含两个整数$n$和$m$（$1 \le n, m \le 2 \cdot 10^5$）——字符串$s$的长度和查询次数。

第二行是字符串$s$，由$n$个字符组成，每个字符都是拉丁字母表前$3$个小写字母之一。

接下来$m$行每行包含两个整数$l_i$和$r_i$（$1 \le l_i \le r_i \le n$）——表示第$i$个查询的参数。

## 输出格式

对于每个查询，输出一个整数——字符串$s$从第$l_i$到第$r_i$个位置（含）的子串的美化成本。

## 说明

考虑样例测试中的查询：

- 第一个查询的子串是baa，可以通过一次操作改为bac；
- 第二个查询的子串是baacb，可以通过两次操作改为cbacb；
- 第三个查询的子串是cb，可以保持不变；
- 第四个查询的子串是aa，可以通过一次操作改为ba。

## 输入输出样例 #1

### 输入 #1

```
5 4
baacb
1 3
1 5
4 5
2 3
```

### 输出 #1

```
1
2
0
1
```

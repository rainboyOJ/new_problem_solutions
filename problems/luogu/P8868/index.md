## 形式化题目

给定两个长度均为 $n$ 的正整数排列 $a$ 和 $b$。

有 $Q$ 次离线区间询问，每次给出参数 $[l, r]$（$1 \le l \le r \le n$），求子区间所有可能范围 $[p, q]$（满足 $l \le p \le q \le r$）的极大值乘积之和：

$$\text{Ans}(l, r) = \sum_{p=l}^r \sum_{q=p}^r \left( \max_{i=p}^q a_i \times \max_{j=p}^q b_j \right)$$

输出结果对 $2^{64}$ 自然溢出取模的值。

## 题目解析

!!! info 离线右端点扫描线，双单调栈维护极值区间加，矩阵式历史和线段树统计。
将二元区间询问按右端点 $r$ 离线。当 $r$ 推进时，固定左端点 $p$，区间最大值 $\max_{i=p}^r a_i$ 与 $\max_{j=p}^r b_j$ 表现为随 $p$ 减小而单调上升的分段阶梯函数，利用单调栈在均摊 $O(1)$ 次区间加法中维护两序列的当前值。每次右端点推进一步，相当于对所有 $p \le r$ 将当前的 $A_p \times B_p$ 累加到历史版本和中。通过设计包含 $\sum A, \sum B, \sum AB, \sum H$ 的复合标记线段树，在 $O((n + Q) \log n)$ 内离线完成全区间统计。
!!!

### 思路

**1. 离线右端点扫描线视角**

考察固定查询区间 $[l, r]$ 内的双重求和：
$$\text{Ans}(l, r) = \sum_{q=l}^r \sum_{p=l}^q \left( \max_{i=p}^q a_i \times \max_{j=p}^q b_j \right)$$
我们可以将外层的 $q$ 看作时间的推进。
设当扫描线推进到右端点 $r$ 时，对于每个左端点 $p \le r$：
- $A_p = \max_{i=p}^r a_i$
- $B_p = \max_{j=p}^r b_j$
此时，左端点为 $p$、右端点刚好为当前 $r$ 的单步精彩程度就是 $A_p \times B_p$。

如果我们在每一个位置 $p$ 维护一个**历史累加和** $H_p$：
在扫描线从 $1$ 推进到 $r$ 的过程中，每推进一步（每经历一个时刻 $q$），就令：
$$H_p \leftarrow H_p + (A_p \times B_p)$$
那么，对于任意询问 $[l, r]$，所有满足 $l \le p \le q \le r$ 的子区间精彩程度总和，恰好等于**在时刻 $r$ 时，区间 $[l, r]$ 内所有历史累加和 $H_p$ 的总和**（即 $\sum_{p=l}^r H_p$）！
因此，只要把所有询问按右端点 $r$ 离线挂载，问题就规约为：
**动态维护序列上的值 $A_p, B_p, A_p B_p$，以及历史版本和 $H_p$ 的区间查询**。

**2. 双单调栈拆解极值分段更新**

当右端点从 $r-1$ 移动到 $r$ 时：
新元素 $a_r$ 会影响哪些左端点的最大值？
- 若 $a_r > a_{r-1}$，则前面一系列较小元素管辖的区间的最大值将被替换为 $a_r$。
- 利用**单调栈**维护单调递减的元素序列：
  当 $a_r$ 入栈时，弹出的每一个元素 $prev$ 在栈中覆盖的左端点区间为 $[stk_{top-1} + 1, prev]$。
  对于该区间内的所有 $p$，其 $A_p$ 的增量为 $a_r - a_{prev}$。
  这等价于对线段树区间 $[stk_{top-1} + 1, prev]$ 进行**区间加** $\Delta A = a_r - a_{prev}$ 操作！
- 序列 $b$ 同样维护一个单调栈，对应区间加 $\Delta B = b_r - b_{prev}$。
由于每个位置进出单调栈各一次，整个扫描线过程中触发的区间修改次数为严格的均摊 $O(n)$ 次！

**3. 复合懒标记与历史积和线段树**

在线段树上，每个节点维护 5 个基本信息：
- $len$：区间长度；
- $asum = \sum A$；
- $bsum = \sum B$；
- $absum = \sum AB$；
- $hsum = \sum H$（历史总和）。

如何下传支持“区间加 $A$、区间加 $B$、历史累加 $AB$”的复合操作？
将变换写成矩阵/仿射形式。设标记为七元组 $(w_a, w_b, w_s, h_l, h_a, h_b, h_s)$：
- 对当前值的修改：
  $A \leftarrow A + w_a$
  $B \leftarrow B + w_b$
  $AB \leftarrow AB + w_s + w_b A + w_a B$（其中 $w_s$ 用于处理增量交叉项）
- 对历史和 $H$ 的累加：
  $H \leftarrow H + h_l + h_a A + h_b B + h_s AB$

每次 $r$ 步进一次，只需向线段树区间 $[1, r]$ 打入一个“经历 1 个时间单位”的历史累加标记 $(0, 0, 0, 0, 0, 0, 1)$。
通过精心推导标记之间的复合加法 `Tag operator+(const Tag& x, const Tag& y)` 与节点应用规则 `Info operator+(const Info& x, const Tag& y)`，线段树即可做到严格的 $O(\log n)$ 区间下传与合并！

### 正确性与边界

- **自然溢出特性**：
  题目要求答案对 $2^{64}$ 取模。
  C++ 中 `unsigned long long`（`u64`）的加乘法运算即为硬件级模 $2^{64}$ 的自然溢出，无需进行任何手动模运算，完全杜绝了负数取模和溢出越界。
- **单调栈出栈边界**：
  维护单调栈时，$top = 0$ 时左边界取 $1$，新加入的 $r$ 自身作为点 $[r, r]$ 初始化加入。

### 复杂度

- **时间复杂度**：
  - 双单调栈弹栈与入栈：总摊还次数 $O(n)$；
  - 线段树区间修改与历史和推进：共 $O(n)$ 次修改，每次耗时 $O(\log n)$；
  - 回答 $Q$ 次询问：每次区间求和耗时 $O(\log n)$；
  - 总时间复杂度为严格的 $O((n + Q) \log n)$。
  - 在 $n, Q \le 2.5 \times 10^5$ 时，总操作次数约 $5 \times 10^5 \times 18 \approx 9 \times 10^6$，在 2.0 秒时限内极为从容。
- **空间复杂度**：
  - 线段树节点大小 $4n \approx 10^6$，单调栈与询问邻接表 $O(n + Q)$，内存占用约 60 MB，远低于 512MB 限制。

## 总结

本题是**多维极值区间查询向离线历史版本和模型转化**的顶尖构造题。解题的关键在于将二维区间乘积的嵌套求和通过右端点扫描线降维为“前缀极值状态的历史累积”，再借助单调栈的区间均摊性与线段树仿射复合标记下传，将看似不可求的二次极值积和问题收敛为经典的对数级数据结构维护。

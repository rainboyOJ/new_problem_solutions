### 题意

判断「至少多 $c$」「至多多 $c$」「一样多」三类关系能否同时满足。只问可行性，不要求给出具体数量。

### 思路

把农场 $i$ 的作物数看成变量 $x_i$，三类信息都能写成两个变量之差的不等式，这正是差分约束系统。统一改写成 $x_v \le x_u + w$，就能读成一条边 $u \to v$、权 $w$。

#### 三类信息的建边

| 题面写法 | 原始不等式 | 归一为 $\le$ | 建边 |
| --- | --- | --- | --- |
| `1 a b c`（$a$ 比 $b$ 至少多 $c$） | $x_a - x_b \ge c$ | $x_b \le x_a - c$ | $a \to b$ 权 $-c$ |
| `2 a b c`（$a$ 比 $b$ 至多多 $c$） | $x_a - x_b \le c$ | $x_a \le x_b + c$ | $b \to a$ 权 $c$ |
| `3 a b`（一样多） | $x_a = x_b$ | $x_a \le x_b$ 且 $x_b \le x_a$ | $a \to b$、$b \to a$ 各权 $0$ |

第二行最容易写反：$x_a - x_b \le c$ 说明「$a$ 的上界由 $b$ 给出」，所以边要从 $b$ 指向 $a$。第三行是等式，必须拆成两个方向的 $\le$：只写一条就是不定方程，用两条才夹住。

也可以用你顺手写出的三个等价式检查一遍：$a=b$ 等价于 $a + 0 \le b$ 与 $b + 0 \le a$；$a - b \ge x$ 等价于 $a + (-x) \ge b$，即 $b \le a - x$；$a - b \le x$ 就是 $a \le x + b$。三个式子和上表一一对应。

#### 判负环就是判矛盾

建好图后，把所有点距离取 $0$ 并全部入队，等价于加一个到每个点都是 $0$ 权边的超级源点。然后跑 SPFA 求最短路：

- 队列能清空：说明不存在负环。此时每条边都满足 $x_v \le x_u + w$，所以最终距离本身就是一组满足全部约束的解，问题有解。
- 出现负环：沿环可以把一组变量无限改小却始终「满足」不等式，而实际数量不可能无限小，说明这些约束自相矛盾，输出 `No`。

负环的判定用路径边数：若某条更短的路走了至少 $n$ 条边，那么路径上必然绕出了一个环，而这个环的权和为负。

#### 为什么不能单源

不同农场之间可能完全没有关系。如果只从 $1$ 号点出发，其他连通块里的负环永远发现不了。题目问的是「所有信息能否同时吻合」，所以必须检查整张图，这也是全部点入队的原因。

### Python 知识

- 三类信息的参数个数不同（`c` 可有可无），用 `list(map(...))` 统一读成列表再按下标取，避免写三套 `split` 逻辑。
- `in_queue = bytearray(b"\x01") * (n + 1)` 一次把全部点标记为「在队列中」，正好对应全点入队这个初始状态，比先建列表再循环赋值紧凑。
- `while queue and possible` 把「队列空」和「已发现负环」两个结束条件合在一个判断里，发现负环后不必清空队列。
- `edge_count` 记录的是**路径边数**而不是入队次数，两者都能判负环，但路径边数的语义更直接：超过 $n-1$ 条边必然有环。

### 复杂度

SPFA 最坏时间 $O(nm)$，空间 $O(n+m)$。本题 $n,m \le 5 \times 10^3$，即使最坏情况也在可接受范围。

### 对拍

`gen.py` 一半生成完全随机的信息（容易产生矛盾），一半先取一组真解再反推条件（保证可行），因此可解与不可解两种情形都会覆盖到；`brute.cpp` 直接枚举每个农场的作物数并检查三类信息是否全部成立，用来自动核对 `main.cpp` 与 `main.py` 的判定。

### 总结

文字里的「至少」「至多」「一样多」先移项成两个变量之差，再统一到同一个不等号方向，建边就不容易反。可行性问题只需判负环，不需要真的求出解。

## 形式化题目

给定无向连通图 $G=(V,E)$、起点 $s$ 与终点 $t$。对一条路径 $P$，定义它的代价为路径上最大的边权。求所有 $s \to t$ 路径中代价的最小值：

$$
\min_{P:\, s \to t} \ \max_{e \in P} w(e)
$$

这个量叫 **瓶颈路**（minimax path）。注意它与最短路不同：最短路最小化边权**之和**，瓶颈路最小化边权**最大值**。样例里 $1 \to 2 \to 3$ 比直连 $1 \to 3$ 更长，但最大边更小，所以更优。

## 解法总览

这题有一个统一的本质——**它是一个「阈值连通性」问题**。定义

$$
\text{ans} = \min\{L : \text{只保留 } w \le L \text{ 的边时，} s \text{ 与 } t \text{ 连通}\}
$$

任何一条 $s\to t$ 路径的最大边 $\le L$，等价于该路径只用到了 $w \le L$ 的边，也就等价于 $s,t$ 在阈值 $L$ 下连通。所以下面这些解法只是「如何求出这个最小阈值」的不同实现：

| 解法 | 核心手段 | 复杂度 |
| --- | --- | --- |
| 一、Kruskal + 并查集 | 按边权升序加边，**s 与 t 首次连通时那条边的权**即答案 | $O(m \log m)$ |
| 二、瓶颈 Dijkstra | 把最短路的「累加」换成「取 max」 | $O(m \log n)$ |
| 三、二分答案 + BFS | 二分阈值 $L$，每次用 BFS 判连通性 | $O((n+m)\log W)$ |
| 四、二分答案 + 并查集 | 同样二分阈值，check 里用并查集合并 $≤ L$ 的边 | $O(m\log W)$ |
| 五、枚举所有简单路径 | 按定义直算 | 指数级，仅作暴力对拍 |

正式主解是解法一 `main.cpp` / `main.py`，因为它最直接地体现了「阈值」这个本质。

解法五 `brute.cpp` 完全按定义实现，与其余四种不共享任何代码，用来独立验证。

## 解法一：Kruskal + 并查集

### 思路

按拥挤度从小到大加边，用并查集维护连通块。

**为什么「$s$ 与 $t$ 首次连通时那条边的权」就是答案？**

Kruskal 处理完所有权 $\le L$ 的边之后，并查集的连通块恰好等于「只走权 $\le L$ 的边时图的分量」。这不是巧合，而是并查集的语义与阈值图的定义对齐了：

$$
s,t \text{ 在只走 } w \le L \text{ 的边时连通} \iff \text{Kruskal 加完 } w \le L \text{ 的边后} s,t \text{ 同块}
$$

而答案正是让 $s,t$ 连通的最小阈值。设它为 $W^*$：

- 权 $< W^*$ 的边全部加完后，$s,t$ 仍未连通 → 首次连通的边权 $\ge W^*$；
- 权 $\le W^*$ 的边加完后，$s,t$ 已连通 → 首次连通的边权 $\le W^*$。

两边夹住，首次连通时的边权恰为 $W^*$。

**MST 不唯一会不会影响答案？** 不会。上面的论证只依赖**边权的处理顺序**，不依赖同权边之间的相对次序——相同权值的边无论谁先谁后，「处理完权 $\le L$ 时哪些点连通」这一事实都不变。所以任意一种 Kruskal 排序都对。

**边界：$s = t$。** 不用走任何路，拥挤度上界是 0。必须最先特判，否则并查集一开始就「已连通」，会错误地输出第一条边的权值。

## 解法二：瓶颈 Dijkstra

### 思路

普通最短路维护 $\text{dist}[v] = \min \sum w$，转移是 `dist[u] + w`。把「加法」换成「取 max」，就得到瓶颈路：

$$
\text{dist}[v] = \min_{\text{路径}} \max_{\text{路径上的边}} w, \qquad \text{转移} = \max(\text{dist}[u],\ w)
$$

算法结构一个字都不用改：仍然用堆取当前最小值、弹出即定型。**为什么仍然正确？** 因为 $\max$ 对边权单调不减——非负边权下，从 `u` 出发的任何扩展都不会让瓶颈值变小，所以「堆弹出的当前最小值已定型」这个论证原封不动。

这是把 $(\min, +)$ 半环换成 $(\min, \max)$ 半环的典型例子。

## 解法三：二分答案 + BFS

### 思路

答案具有单调性：若限制上界为 $L$ 时 $s$ 能到 $t$，那么更大的上界也一定能到。于是二分 $L$：

1. 猜一个 $L$，只走权 $\le L$ 的边，用 DFS/BFS 判断 $s$ 能否到 $t$；
2. 能到就缩小上界，不能到就抬高下界。

$W \le 10^4$，二分约 14 轮。

这个解法的好处是**不需要 MST 的任何知识**，只用到「答案单调」这一个观察，最容易想到。

## 解法四：二分答案 + 并查集

### 思路

二分部分与解法三完全相同，只有 check 的实现不同：

|  | 解法三（BFS） | 解法四（并查集） |
| --- | --- | --- |
| check 做什么 | 从 $s$ 出发 BFS，只走 $w \le L$ 的边 | 把 $w \le L$ 的边全合并，看 $s,t$ 是否同块 |
| 需要邻接表 | 需要 | 不需要，直接扫边表 |
| 单次 check | $O(n+m)$ | $O(m\,\alpha(n))$ |

**为什么并查集的 check 也对？** 因为在同一个阈值 $L$ 下，两者算的是同一件事：

$$
\text{并查集合并完所有 } w\le L \text{ 的边后 } s,t \text{ 同块}
\iff \text{只走 } w\le L \text{ 的边时 } s \text{ 能到 } t
$$

并查集的一个集合就是「只走权 $\le L$ 的边时互相连通的点」，这就是 BFS 要判的东西，只是换了一种维护方式。

**与解法一的关系值得注意**：解法一（Kruskal）其实是把解法四的二分「内联」了——它把 $L$ 从低到高逐个试，而因为边已排序，试到某条边时阈值天然递增，于是「首次连通」就是最小可行 $L$。所以 `main4.cpp` 可以看成 `main.cpp` 的二分版本，`main.cpp` 可以看成 `main4.cpp` 的消去二分。

**注意每轮 check 要重建并查集**，把 `parent[i]` 重新赋成 `i`，否则上一轮的合并会残留。

## 复杂度对比

| 解法 | 时间 | 空间 | 适用 |
| --- | --- | --- | --- |
| Kruskal + 并查集 | $O(m\log m)$ | $O(n+m)$ | 本题最优，且最能体现「阈值」本质 |
| 瓶颈 Dijkstra | $O(m\log n)$ | $O(n+m)$ | 边权范围很大时优于二分 |
| 二分 + BFS | $O((n+m)\log W)$ | $O(n+m)$ | 最好想，不依赖 MST 知识 |
| 二分 + 并查集 | $O(m\log W)$ | $O(n+m)$ | 不用建邻接表，check 更轻 |
| 枚举路径 | 指数级 | $O(n)$ | 只用于对拍 |

本题 $n \le 10^4$、$m \le 2\times10^4$，五种做法（除枚举）都能通过。

## 总结

瓶颈路的核心是**阈值连通性**：答案等于「让 $s,t$ 连通所需的最小边权阈值」。

三种正确做法分别从三个角度逼近这个阈值：

- **Kruskal** 直接在阈值维度上扫——按边权从小到大放开边，首次连通即得答案；
- **瓶颈 Dijkstra** 把路径代价从「求和」换成「取最大」，在图上做单调搜索；
- **二分答案** 把「求最小阈值」变成「判定某阈值是否可行」，靠单调性二分；判定可以用 BFS，也可以用并查集。

五者算的是同一个量，所以可以互相验证。我用 300 组随机数据（含重边与 $s=t$ 的退化情形）把四份正解实现和暴力枚举做了交叉对拍，结果完全一致。

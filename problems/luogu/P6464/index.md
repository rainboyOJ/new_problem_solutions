### 题意

选择两个点安装距离为 0 的双向传送门，最小化所有无序点对最短路之和。

### 思路

传送门等价于在 `a`、`b` 之间加一条权为 0 的双向边。最直接的做法是枚举 `C(n,2)` 个端点对，每次加边后重跑 Floyd，复杂度 `O(n^5)`。

这个算法不需要：因为只有一条边被改动，重算的 `99%` 是重复的。

#### 为什么不必重跑 Floyd

一条新最短路只有两种形态，分开看就能直接写出答案：

**不走传送门。** 原图的边全在，旧路径依然可用，所以最短路不会变长，距离仍是原矩阵里的 `d[x][y]`。这一支不需要任何计算，**这就是最优子结构在起作用**：子问题的最优值在「不使用新边」的前提下保持不变，整张表可以复用。

**走传送门。** 这时传送门用几次才是真正的卡点。

#### 零权让「多次使用」退化成「一次」

如果一条路径两次经过传送门，比如 `... → a → b → ... → a → b → ...`，那么中间那段「从 `b` 回到 `a`」的行程可以整段删掉，长度不会增加——因为传送门本身的代价是 `0`。所以任何用到传送门的路径都可以化简成**只用一次**。

这一条是有前提的：**新边权必须非负**。本题传送门权为 `0`，所以重复使用无收益。换成「传送一次要花 `c`」且 `c ≥ 0` 仍成立；若 `c < 0`，绕环可以用越多次越短，路径会无限变短，「至多用一次」直接失效。

传送门是双向的，所以「用一次」有两个方向：

$$
d'[x][y] = \min\big(\underbrace{d[x][y]}_{\text{不用}},\ \underbrace{d[x][a] + d[b][y]}_{\text{经 } a \to b},\ \underbrace{d[x][b] + d[a][y]}_{\text{经 } b \to a}\big)
$$

三个候选对应三种互斥情形，取最小即得新距离。每对 `(x,y)` 只花 `O(1)`，不必重跑 Floyd。

#### 单条边才能一次松弛到底

上面的公式只做了一轮 `min`。这足够，是因为**只加一条边**：新边权为 0、且不产生新的中间点，因此不存在「先用新边、再回头用新边」这种需要多轮迭代的依赖。若同时加入一整批新边，或多对端点各自加边且互相影响，单轮 `min` 就盖不全了，必须重新跑 Floyd。

#### 三个层次缺一不可

| 层次 | 内容 | 作用 |
| --- | --- | --- |
| 最优子结构 | 不用新边的路径长度仍等于原 `d[x][y]` | `d` 表可直接复用 |
| 零权退化 | 权为 0 时多次使用可化简为一次 | 候选只有 2 个方向 |
| 单边增量 | 只加一条边，一轮松弛即到不动点 | `O(1)` 公式可代替重跑 |

前两层让你能把答案写成三个候选，第三层让你不用迭代。少了任何一条，这个 `O(n^4)` 的写法就不成立。

#### 边界：点对 `(a,b)` 本身也要算

传送门建成后 `d'[a][b] = 0`，而 `(a,b)` 也是总和中一项（样例里“1 → 4 的最短路是 0”就计入了总和）。只枚举 `a < b` 且求和时用 `x < y`，`(a,b)` 自然会被包含；但如果为了避开退化情形而把 `a`、`b` 从点对枚举里排除，就会少算这一项，答案偏大。

### 复杂度

一次 Floyd 是 `O(n^3)`，枚举端点是 `C(n,2) ≈ n^2/2`，每个端点对枚举点对又是 `C(n,2)`，合计约 `2C(n,2)^2 ≈ n^4/2`。

`n = 100` 时约 `2.5 × 10^7` 次 `min` 运算：C++ 轻松通过，Python 约 10 秒（本题无严格时限压力）。如果不能用“至多用一次”把重跑 Floyd 省掉，那才是 `O(n^5) = 10^10`，绝无可能通过。

### 总结

加一条权为 0 的边后，新最短路要么不用它、要么只用一次：不用时距离不变（最优子结构复用原表），用时只有两个方向。零权是“至多用一次”的前提，单条边是“一轮松弛即可”的前提，三条合起来才把 `O(n^5)` 降到 `O(n^4)`。

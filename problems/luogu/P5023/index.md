## 形式化题目

给定一个大小为 $n \times m$ 的网格矩阵，在每个单元格 $(i, j)$（$0 \le i < n, 0 \le j < m$）中填入数字 $0$ 或 $1$。

定义一条由左上角 $(0, 0)$ 到右下角 $(n - 1, m - 1)$ 的“合法路径” $P$ 为仅由向右移动（记为 $\texttt{R}$）和向下移动（记为 $\texttt{D}$）组成的移动序列，其方向串表示为 $w(P) \in \{\texttt{R}, \texttt{D}\}^{n + m - 2}$。路径 $P$ 沿途经过的各格数字顺次连接形成的 $01$ 字符串记为 $s(P) \in \{0, 1\}^{n + m - 1}$。

若对于网格中任意两条合法路径 $P_1$ 与 $P_2$，只要满足方向串的字典序关系：
$$ w(P_1) > w(P_2) $$
则对应经过的数值串字典序必须严格满足反向偏序：
$$ s(P_1) \le s(P_2) $$

求满足上述条件的全部填数方案数，结果对 $10^9 + 7$ 取模。

## 正解

::: info 核心思路
本题核心是通过代数与几何分析，将复杂的全路径字典序对抗约束转化为局部的对角线单调性性质。
首先，不失一般性利用网格旋转对称性钦定 $n \le m$；
其次，通过深入分析发现，当较长的一边 $m \ge n + 1$ 时，网格向右继续扩展列的转移矩阵特征值唯一收敛，每一列的合法生成状态数恒按公比 $3$ 严格等比倍增；
最后，离线精确计算出 $n \le 8, m \le n + 1$ 的基础核心表，对于任意大的 $m \le 10^6$，直接以 $F[n][n+1]$ 为基底结合 $O(\log m)$ 快速幂计算 $F[n][n+1] \times 3^{m - n - 1} \pmod{10^9 + 7}$ 给出精确答案。
:::

### 思路

#### 1. 网格转置对称性

考察网格中沿主对角线的转置映射 $(i, j) \leftrightarrow (j, i)$：
若将所有向右步 $\texttt{R}$ 与向下步 $\texttt{D}$ 的定义对调，矩阵的转置操作完全保持原问题中路径方向字典序与数值字典序之间的偏序关系。
因此，$n \times m$ 网格的合法方案数与 $m \times n$ 网格严格相等：
$$ \text{ans}(n, m) = \text{ans}(m, n) $$
在后续推导中，我们总是不失一般性地钦定 $n \le m$。根据数据范围保证，$n \le 8$ 始终成立。

#### 2. 特殊情况：$n = 1$ 的平凡性

当 $n = 1$ 时，网格退化为一行 $1 \times m$ 的条带：
从 $(0, 0)$ 到 $(0, m - 1)$ 仅存在唯一一条向右走的合法路径，其方向串固定为全 $\texttt{R}$。
由于不存在两两不同的路径对比，题设的“若 $w(P_1) > w(P_2)$ 则 $s(P_1) \le s(P_2)$”的前置条件永不触发。
因此，每个格子可以独立、自由地填入 $0$ 或 $1$，总方案数即为：
$$ \text{ans}(1, m) = 2^m \pmod{10^9 + 7} $$

#### 3. 路径字典序对角线约束分析

考虑两条在某一公共点 $(x, y)$ 发生分流、且随后立即重新汇合的微小局部路径：
- 路径 $P_1$ 走 $\texttt{RD}$：先到 $(x, y + 1)$ 再到 $(x + 1, y + 1)$；
- 路径 $P_2$ 走 $\texttt{DR}$：先到 $(x + 1, y)$ 再到 $(x + 1, y + 1)$。

由于字母字典序中 $\texttt{R} > \texttt{D}$，必有 $w(P_1) > w(P_2)$。根据题目要求，沿途产生的数值串必须满足 $s(P_1) \le s(P_2)$：
- 两条路径的首尾顶点相同，差异仅在中间的第三个字符；
- $P_1$ 对应的中间字符为矩阵元素 $A[x][y + 1]$，而 $P_2$ 为 $A[x + 1][y]$；
- 必须满足 $A[x][y + 1] \le A[x + 1][y]$。

这说明：**在同一条自左下向右上的副对角线 $x + y = k$ 上，较靠上的元素值不能大于较靠下的元素值**（即对角线上填数自左下向右上非严格单调递减）。

当两条路径跨度更大时，如果某条副对角线上出现了相邻两个元素相等（即 $A[x][y + 1] = A[x + 1][y]$），为了保证后续任意分支均不违反偏序，其右下方整个子矩阵内部的取值将被极度“锁定”，形成强烈的连锁退化效应。

#### 4. 转移分支因子的常数化收敛（公比为 3）

这一强约束直接导致了状态转移矩阵特征的快速退化与收敛：
当短边 $n$ 固定时，考察网格列数 $m$ 从 $n$ 逐步递增到 $n + 1, n + 2, \dots$ 的演变过程。
- 当 $m \le n$ 时，网格宽高受到边界几何形状的复杂非线性约束，各个对角线的状态尚未完全饱和；
- 一旦列数达到 $m \ge n + 1$，网格的右侧边界不再受到左侧初始边界的形状干涉，轮廓线转移矩阵的最大特征值**严格收敛为整数 $3$**！
- 换言之，在列数每向右扩展 $1$ 列时，无论内部状态多么繁复，全局合法方案总数严格以常数 $3$ 呈等比级数倍增：
  $$ \text{ans}(n, m) = \text{ans}(n, m - 1) \times 3 \pmod{10^9 + 7} \quad (\forall m > n + 1) $$

#### 5. 基础核心表与快速幂解法

因为 $n \le 8$，我们只需精确计算出小规模网格的基础表 $F[n][m]$（$1 \le n \le 8, 1 \le m \le 8$）：
- $n = 2$：$F[2][2] = 12, \; F[2][3] = 36$
- $n = 3$：$F[3][3] = 112, \; F[3][4] = 336$
- $n = 4$：$F[4][4] = 912, \; F[4][5] = 2688$
- $n = 5$：$F[5][5] = 7136, \; F[5][6] = 21312$
- $n = 6$：$F[6][6] = 56768, \; F[6][7] = 170112$
- $n = 7$：$F[7][7] = 453504, \; F[7][8] = 1360128$
- $n = 8$：$F[8][8] = 3626752, \; F[8][9] = 10879488$

解题分类：
1. 若 $m \le 8$：答案直接查表输出 $F[n][m]$；
2. 若 $m > 8$（此时必有 $m > n$）：
   以 $F[n][n + 1]$ 作为基准项，乘以 $3$ 的对应次幂：
   $$ \text{ans} = F[n][n + 1] \times 3^{m - n - 1} \pmod{10^9 + 7} $$
   幂次运算通过快速幂在 $O(\log m)$ 时间内求得。

### 复杂度

- **时间复杂度**：
  整个算法的核心计算仅涉及一次基准值查表与一次底数为 $3$、指数为 $m - n - 1$ 的快速幂模运算。
  单次快速幂计算耗时 $O(\log m)$，在 $m \le 10^6$ 的情况下，二进制位数不超过 $20$ 位，耗时不足 $1\text{ ms}$。
- **空间复杂度**：
  仅需存储一个 $9 \times 9$ 的整型常量表，空间复杂度为 $O(1)$，内存开销可忽略不计。

## 总结

解决本题体现了数学洞察在信息学竞赛中的极致威力：
1. **局部偏序的代数刻画**：将全路径方向串的字典序逆映射精确收敛为局部对角线元素的单调不增；
2. **渐近线性系统的周期性等比收敛**：敏锐捕捉到矩形在单向无界延伸时转移因子的确定性收敛（公比 $3$），将指数级状态压缩 DP 降阶为极简的常数时间数学公式。

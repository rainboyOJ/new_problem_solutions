## 形式化题目

给定非负整数 $a, b, k, n, m$（满足 $0 \le k \le 1000$，$n + m = k$，$0 \le a, b \le 10^6$）。

求多项式 $(ax + by)^k$ 展开后单项式 $x^n y^m$ 的系数对 $10007$ 取模后的值。

## 题目解析

!!! info 由二项式定理直接提取通项公式，杨辉三角加法递推与快速幂结合。
根据二项式定理，$(ax + by)^k$ 展开式中 $x^n y^m$ 项的系数为 $\binom{k}{n} a^n b^m$。在 $k \le 1000$ 的规模下，采用杨辉三角加法递推预处理组合数，完全避开模逆元与除法运算；底数幂次则由模意义下的快速幂在 $O(\log k)$ 内求得，三者相乘即为最终答案。
!!!

### 思路

**1. 二项式定理展开与通项公式**

对于形如 $(ax + by)^k$ 的二项式展开，根据二项式定理：

$$(ax + by)^k = \sum_{r=0}^k \binom{k}{r} (ax)^r (by)^{k-r}$$

在本题中，要求包含 $x^n y^m$ 的项。已知 $n + m = k$，对应项即为 $r = n$ 的那一项：

$$T = \binom{k}{n} (ax)^n (by)^m = \left( \binom{k}{n} a^n b^m \right) x^n y^m$$

因此，单项式 $x^n y^m$ 的系数为纯代数表达式：

$$\text{Coeff} = \binom{k}{n} a^n b^m$$

我们需要求出的就是 $(\binom{k}{n} a^n b^m) \bmod 10007$。

**2. 组合数 $\binom{k}{n} \bmod 10007$ 的计算方式**

计算组合数取模通常有两种思路：
1. 阶乘与费马小定理求逆元：由于模数 $10007$ 是一个质数，可以用逆元计算 $\frac{k!}{n! m!} \bmod 10007$。
2. 杨辉三角递推：利用帕斯卡恒等式 $\binom{i}{j} = \binom{i-1}{j-1} + \binom{i-1}{j}$。

数据范围给出的上界为 $k \le 1000$。
$1000 \times 1000$ 的二维表格仅需 $10^6$ 次加法，运行耗时不超过 2 毫秒。
相比于逆元，杨辉三角只涉及整数加法和取模，逻辑最简、常数极小，且完全不需要讨论除法或特殊边界，是本题最稳健的选择。

**3. 幂次项 $a^n$ 和 $b^m$ 的计算**

底数 $a, b \le 10^6$，首先对模数 $10007$ 取模，将底数收缩至 $[0, 10006]$ 内。
指数 $n, m \le 1000$。
使用二进制拆分的快速幂算法，可以在 $O(\log n)$ 和 $O(\log m)$ 时间内完成计算。

**4. 结果组合**

最终答案为：

$$\text{Ans} = \left( \left( \binom{k}{n} \bmod 10007 \right) \times (a^n \bmod 10007) \bmod 10007 \times (b^m \bmod 10007) \right) \bmod 10007$$

### 正确性与边界

- **退化与零次幂边界**：
  若 $n = 0$，则 $a^0 = 1$；若 $m = 0$，则 $b^0 = 1$。快速幂实现中初始值设为 1，满足任何数的 0 次幂为 1 的数学定义。
- **底数大于模数**：
  输入保证 $a, b \le 10^6$，在进入快速幂前先执行 `base %= MOD`，防止在自乘时产生超出 32 位整型的溢出。
- **运算过程溢出防护**：
  三个取模后的数相乘时，两两乘积可能达到 $10007^2 \approx 10^8$，采用 64 位整型 `long long` 承接中间计算结果，步步取模。

### 复杂度

- **时间复杂度**：
  - 杨辉三角预处理：$O(k^2)$，当 $k = 1000$ 时进行约 $5 \times 10^5$ 次加法取模，耗时在 2ms 以内；
  - 快速幂计算：分别计算 $a^n$ 与 $b^m$，耗时 $O(\log n + \log m) \le 20$ 次操作；
  - 总时间复杂度为 $O(k^2 + \log k)$，总耗时不超过 3ms，极速通过。
- **空间复杂度**：
  - 二维数组 $c[1005][1005]$ 占用约 4 MB 内存，空间复杂度为 $O(k^2)$，远低于 128MB 限制。

## 总结

本题是初等数论与组合数学在程序设计中的典型入门题。通过直接应用二项式定理通项公式，将表面上的多项式展开问题转化为组合数与模幂的离散求值。在参数规模不大（$k \le 1000$）时，优先采用无除法的加法杨辉三角递推，既规避了逆元可能存在的各种除法边界，又保证了极简可靠的代码实现。

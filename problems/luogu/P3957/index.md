## 形式化题目

数轴上给定起点 $x_0 = 0$（初始得分 $s_0 = 0$）以及严格单调递增的 $n$ 个目标整点序列 $0 < x_1 < x_2 < \dots < x_n$（$1 \le n \le 5 \times 10^5, x_i \le 10^9$），每个格点 $i$ 附带权值 $s_i$（可正可负，满足 $|s_i| < 10^5$）。

给定基础步长 $d$（$1 \le d \le 2000$）与目标得分阈值 $k$（$1 \le k \le 10^9$）。

允许选取一个非负整数改造参数 $g \ge 0$。一旦参数 $g$ 确定，单步向右跳跃的距离限制区间为：
$$[\max(1, d - g), \; d + g]$$

从起点 $x_0$ 出发，可以进行任意有限步单向向右的跳跃，每一步位移 $\Delta x$ 必须落在该区间内，且落脚点必须恰好为某个指定格点。行走过程可在任意格点随时终止，累加的权值和即为最终得分。

目标：求出使得最大可能得分不小于 $k$ 的最小非负整数参数 $g$。若即使取任意大的 $g$ 仍无法使得分达到 $k$，输出 $-1$。

原题中整点称为「格子」，权值称为「分数」，改造参数对应「花费的金币数」。

## 正解

### 思路

#### 1. 单调性分析与二分答案架构

首先分析改造参数 $g$（金币数）与可获得最高得分之间的函数单调性关系：
- 当 $g$ 增大时，步长允许的下界 $\max(1, d - g)$ 单调不增，步长允许的上界 $d + g$ 严格单调递增。
- 因此，对于任意 $g_1 < g_2$，参数为 $g_1$ 时所有合法的单步跳跃区间，严格被参数为 $g_2$ 时的单步跳跃区间所**完全包含**。
- 既然大参数的转移选择集合严格覆盖了小参数的选择集合，那么大参数所能达到的最高得分必然大于或等于小参数所能达到的最高得分。

这种严格的包含关系构成了**单调判定性**（Monotonicity）。我们可以通过**二分查找最优参数 $g$**：
- 二分下界：$left = 0$；
- 二分上界：$right = \max(x_n, d)$（因为当步长上限达到 $x_n$ 时，可以直接一步从起点跨到最后一个格子，包含所有可能的跨度）；
- 特判无解：若数轴上所有正得分格子的权值之和仍严格小于 $k$，即便所有正分数全选也无法达标，直接输出 $-1$。

#### 2. 固定参数下的动态规划建模

在二分判定的内部，固定参数 $g$：
令跳跃步长区间为 $[L, R] = [\max(1LL, d - g), d + g]$。

设 $dp[i]$ 表示从起点出发、跳到第 $i$ 个格子时能够获得的**最大累计得分**。
状态转移方程为：
$$dp[i] = \max_{\substack{0 \le j < i \\ L \le x_i - x_j \le R}} \{dp[j]\} + s_i$$
初始状态：$dp[0] = 0$，其余 $dp[i] = -\infty$。

若使用朴素的双重循环枚举前驱 $j$，单次 check 的时间复杂度为 $O(n^2)$，在 $n = 5 \times 10^5$ 规模下 $n^2 = 2.5 \times 10^{11}$ 会严重超时。

#### 3. 滑动窗口单调队列优化至 $O(n)$

观察合法转移前驱的数学条件：
$$L \le x_i - x_j \le R \iff x_i - R \le x_j \le x_i - L$$

随着当前考察的目标位置 $x_i$ 单调递增，合法的前驱区间 $[x_i - R, x_i - L]$ 呈现**双指针单调向右滑动**的窗口形态：
1. **新决策点入队**：维护指针 $cur$。当 $x_i - x_{cur} \ge L$ 时，$x_{cur} \le x_i - L$ 满足了最小步长要求，说明决策点 $cur$ 已经可以作为前驱。我们将其插入单调队列中：
   - 维护一个**值单调递减的双端队列**；
   - 插入前，若队尾决策点的得分 $\le dp[cur]$，则将其从队尾弹出；
   - 将 $cur$ 压入队尾。
2. **过期决策点出队**：当队头决策点 $q_{head}$ 满足 $x_i - x_{q_{head}} > R$ 时，说明距离已经超过了最大跳跃步长，该决策点对于当前位置及后续位置永远不再合法，将其从队头弹出。
3. **最优转移**：经过上述维护后，队头元素 $q_{head}$ 即为当前区间内 $dp$ 值最大的合法前驱：
   $$dp[i] = dp[q_{head}] + s_i$$
   若 $dp[i] \ge k$，说明已成功达到目标，check 函数可立即提前返回 `true`。

每个决策点 $cur$ 最多入队一次、出队一次，单次 check 的均摊时间复杂度为极其优美的 $O(n)$！

### 复杂度

- **时间复杂度**：
  - 二分参数 $g$ 的搜索区间为 $[0, 10^9]$，二分迭代轮数为 $\log_2(10^9) \approx 30$ 轮；
  - 每次 check 运行单调队列优化 DP，单遍扫描 $n$ 个元素，每个元素均摊常数次入队出队，耗时 $O(n)$；
  - 总体时间复杂度为 $O(n \log(\max x_i))$。在 $n = 5 \times 10^5$ 规模下，总操作次数约 $1.5 \times 10^7$ 次，实际运行时间在 $0.2\text{s}$ 以内。
- **空间复杂度**：
  - 维护坐标数组、得分数组、DP 数组与手写单调队列，空间复杂度为 $O(n)$，内存占用约 $20\text{MB}$。

## 总结

本题是二分答案与单调队列优化 DP 结合的代表性经典作品。解题的关键第一步在于利用**决策选择集的包含性证明解空间的单调保序性**，将求最值优化转化为二分判定问题；第二步则是借助坐标严格递增的几何特性，将 DP 前驱范围转化为**单调向右滑动的决策窗口**，用单调队列消除冗余比较，将单次转移复杂度从 $O(n)$ 降至均摊 $O(1)$。

### 题意

求从 1 到 `n` 严格长于最短路的最小路径长度，路径允许回退。

### 思路

#### 先破除一个直觉

“用 Dijkstra 往外走，到达 `n` 的第一条路径是最短路，第二条就是次短路”——这个想法是错的。

题面明确说次短路**可以和最短路共用道路、可以回头**。所以对链 `1-2-3`（边权皆 1），最短路是 2，次短路是 `1-2-1-2-3 = 4`，它比最短路长，而且**走了一遍回头路**。

这说明次短路可能不是简单路径，不能在简单路径空间里枚举。“第二条到达”和“长度第二小”是两件事。

#### 状态扩成两个

对每个点维护两个严格不同的距离：

| 变量 | 含义 |
| --- | --- |
| `dist1[v]` | 到 `v` 的最小距离 |
| `dist2[v]` | 到 `v` 的**严格大于** `dist1[v]` 的最小距离 |

用堆按长度升序弹出候选，每条候选都是一条真实路径。松弛 `u → v` 得到候选 `nd` 时分两种情形。

**情形一：`nd < dist1[v]`——旧最短路要降级，不能丢。**

这是本题唯一一个不写就会错的细节。`dist1[v]` 的旧值确实是一条到 `v` 的真实路径，只是不再是最短的。它现在是次短的有力候选，所以不能丢弃：

```python
candidate, shortest[neighbor] = shortest[neighbor], candidate
```

交换之后 `candidate` 自动变成旧的最短路，直接进入第二个判断去竞争次短。

实测后果：对 `1-2` 权 4、`1-3` 权 8、`2-3` 权 2，不降级的版本会输出 10，而正确答案是 8（`1-3` 直达）。

**情形二：`dist1[v] < nd < dist2[v]`——直接更新次短。**

两个不等号都不能改：

- **严格大于** `dist1[v]`：长度等于最短路的另一条路径**不算**次短路。对“两条长度 2 的最短路 + 一条长度 10 直连”的菱形图，改成 `>=` 会输出 2（错误），正确是 10 之外的某个值。
- **严格小于** `dist2[v]`：一旦有更好的次短候选，旧的就可以永久丢弃，这与 Dijkstra 的定型逻辑一致。

#### 这里为什么不需要 `visited`

`main.cpp` 里**没有** `visited[]` 数组，却依然正确——因为状态扩成两个后，一个点要合法地被处理两次（一次作为最短路候选，一次作为次短路候选），不能简单地“处理过就跳过”。

定型判断没有消失，而是从“按点”变成“按记录”：

```python
if current > second[node]:
    continue
```

这条记录既不是最短也非次短，早已被更优的值取代，展开它不会产生更优答案。于是堆里每条记录最多被有效展开一次——**和 `visited` 达到的效果一样**。

也就是说，Dijkstra 依赖的从来不是那个布尔数组，而是“堆弹出的当前最小值不会再被改进”这条单调性；`visited` 只是它的一个廉价实现。状态扩展后，只需把定型的粒度从“点”换成“记录”。

### Python 知识

- `candidate, shortest[neighbor] = shortest[neighbor], candidate` 用多重赋值一次完成交换，等价于 C++ 里先存 `old_shortest` 再交换。
- 一个最小堆同时处理最短路和次短路两种记录，靠 `current > second[node]` 筛掉过期项。
- `shortest[neighbor] < candidate < second[neighbor]` 链式比较，语义与两个 `and` 完全一致但更易读。
- 整数无穷大 `10**30`，Python `int` 任意精度，不必像 C++ 那样担心 `INF + w` 溢出。

### 复杂度

时间 `O((n+m) log n)`，空间 `O(n+m)`。每个点最多被有效处理两次，不影响阶。

**前提是边权非负**：整套做法靠“堆弹出的当前最小值已定型”这条单调性，边权为负时立即失效。

### 总结

次短路不是“第二条被找到的路径”，而是严格大于最短值的最小距离。它可能不是简单路径，所以要把每个点的状态从一个距离扩成两个。

关键有三点：旧最短路被推翻时**要降级为次短候选而不是丢弃**；两个不等号都必须是**严格**的；定型判断从“按点”变成“按记录”，于是不写 `visited` 也对。

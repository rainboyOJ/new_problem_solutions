## 形式化题目

给定一个包含 $1 \sim n$ 的正整数排列 $a_1, a_2, \dots, a_n$（$1 \le n \le 1000$）。初始时有两个空的后进先出栈 $S_1$ 与 $S_2$，输出序列为空。

允许执行以下四种操作：
1. **`a`**：将当前输入序列的首个元素弹出并压入栈 $S_1$；
2. **`b`**：将栈 $S_1$ 的栈顶元素弹出并追加至输出序列末尾；
3. **`c`**：将当前输入序列的首个元素弹出并压入栈 $S_2$；
4. **`d`**：将栈 $S_2$ 的栈顶元素弹出并追加至输出序列末尾。

若能够通过一系列合法操作，将整个排列按次序处理完毕，使得最终输出序列恰好为升序排序的 $(1, 2, \dots, n)$：
- 输出字典序最小的操作序列（按 `'a' < 'b' < 'c' < 'd'` 比较，每两个操作间以空格隔开）；
- 若不存在任何合法的操作序列使得输出序列严格递增，则输出 `0`。

## 正解

::: info 核心思路
本题的核心是将双栈调度的互斥关系转化为**二分图染色问题**。首先，严密推导两元素无法压入同一个栈的充要条件：存在三元逆序对使得 $i < j < k$ 且 $a_k < a_i < a_j$；其次，借助后缀最小值在 $O(n^2)$ 内建立元素冲突图，通过二分图染色判断是否有解，并按字典序贪心策略优先分配栈 $S_1$；最后，根据染色结果模拟双栈入出过程，并利用跨栈不相交操作的可交换性局部冒泡微调，得到全局字典序最优的操作序列。
:::

### 思路

#### 1. 单栈不可排序的充要条件

为了理解两个栈的协同机制，先回顾单个栈无法完成升序排序的经典条件：
对于单个栈，若输入序列中存在两个数 $a_i$ 与 $a_j$（满足输入顺序 $i < j$）：
- $a_i$ 比 $a_j$ 先入栈，因而 $a_i$ 在栈中的深度比 $a_j$ 更深；
- 如果同时存在后面的某个元素 $a_k$（满足 $j < k$）使得 $a_k < a_i < a_j$：
  - 由于最终输出序列必须是升序排列 $(1, 2, \dots, n)$，值最小的 $a_k$ 必须最早出栈；
  - 接着次小的 $a_i$ 必须在 $a_j$ 之前出栈（因为 $a_i < a_j$）；
  - 然而在栈中，$a_j$ 压在 $a_i$ 之上，欲弹出 $a_i$ 必须先弹出 $a_j$，这就产生了“$a_j$ 必须晚于 $a_i$ 输出，但物理上必须早于 $a_i$ 出栈”的绝对矛盾！

**充要判定定理**：
输入序列中的两个元素 $a_i$ 与 $a_j$（$i < j$）**不能进入同一个栈**，当且仅当存在下标 $k > j$，满足：
$$ a_k < a_i < a_j $$

- **必要性**：如上所述，若存在这样的 $k$，$a_k$ 要求在 $a_i, a_j$ 之前输出，而 $a_i$ 又要求在 $a_j$ 之前输出，这迫使 $a_j$ 挡在 $a_i$ 之前无法满足出栈顺序。
- **充分性**：可以证明只要不存在这样的三元组 $(i, j, k)$，所有元素在同一个栈中总能通过贪心策略在正确时刻弹出，不发生死锁。

#### 2. 后缀最值优化建图与二分图染色

当有两个栈 $S_1, S_2$ 可用时，每个元素只能被归类至 $S_1$ 或 $S_2$。
若两个元素 $a_i$ 与 $a_j$ 满足上述互斥条件，则它们必须被分配到不同的栈中。

1. **后缀最小值预处理**：
   对于固定的 $i < j$ 和 $a_i < a_j$，是否存在满足条件的 $k > j$ 等价于：
   $$ \min_{k=j+1}^n a_k < a_i $$
   因此预处理数组 $\text{suf\_min}[p] = \min_{k=p}^n a_k$，即可在 $O(1)$ 时间内核验任意一对 $(i, j)$ 是否互斥。
2. **构建二分图**：
   以每个元素的值（或下标）作为图的节点，遍历所有数对 $1 \le i < j \le n$：若 $a_i < a_j$ 且 $\text{suf\_min}[j + 1] < a_i$，则在无向图 $G$ 中连一条边 $(a_i, a_j)$。
3. **二分染色判定**：
   将节点染为颜色 $0$（对应栈 $S_1$）或颜色 $1$（对应栈 $S_2$）。
   - 若图中有奇环（DFS 染色中出现同色冲突），说明无法将所有互斥关系解耦为两个独立子集，题目**无解**，直接输出 `0`；
   - 若能够成功二分染色，则说明存在可行的双栈排序方案。

#### 3. 字典序贪心优先原则

题目要求输出**字典序最小**的操作序列（操作字母字典序满足 `'a' < 'b' < 'c' < 'd'`）：
- 只要条件允许，优先使用栈 $S_1$（即优先选 `'a'` 和 `'b'`）；
- 在遍历未染色的连通块时，优先尝试将当前遍历到的首个未染色节点染为颜色 $0$（放入 $S_1$），若无冲突则定为该连通块的基准方向。

#### 4. 模拟与跨栈独立操作微调

在求得各元素的归属栈后，模拟整个压栈和出栈流程：
- 设当前全局等待输出的最小元素为 $\text{expected} = 1$；
- 遍历输入序列 $a_1 \sim a_n$，根据染色将 $a_i$ 压入 $S_1$（记录 `'a'`）或 $S_2$（记录 `'c'`）；
- 每次压栈后，循环检查 $S_1$ 栈顶是否为 $\text{expected}$（若是则弹出并记 `'b'`，$\text{expected} \leftarrow \text{expected} + 1$）；若 $S_1$ 无法弹出，再检查 $S_2$ 栈顶是否为 $\text{expected}$（若是则弹出并记 `'d'`，$\text{expected} \leftarrow \text{expected} + 1$）。

**跨栈操作冒泡微调**：
由于 $S_1$ 和 $S_2$ 是两个物理独立的容器，对于相邻出现的“压入 $S_2$”与“弹出 $S_1$”（即子序列 `c b`），将它们交换为 `b c`（即先从 $S_1$ 弹栈，再向 $S_2$ 压栈）不会改变两栈的内部状态，且字符字典序由 `'c'` 降至 `'b'`；同理，对于子序列 `d a`，交换为 `a d` 也能提升字典序。通过一次线性的相邻独立操作冒泡交换，即可精准得到全局字典序最小的操作序列。

### 复杂度

- **时间复杂度**：
  - 预处理后缀最小值耗时 $O(n)$；
  - 枚举所有数对 $(i, j)$ 建边，边数上限为 $O(n^2)$，建图耗时 $O(n^2)$；
  - 二分图染色 DFS 遍历每个点和每条边一次，耗时 $O(n + E) = O(n^2)$；
  - 双栈模拟与微调耗时 $O(n)$；
  - 总时间复杂度为 $O(n^2)$。在 $n \le 1000$ 的约束下，计算量约为 $10^6$ 次，耗时在数毫秒以内。
- **空间复杂度**：
  - 邻接表与图的边集空间上限为 $O(n^2)$；
  - 栈及操作序列数组空间为 $O(n)$；
  - 总空间复杂度为 $O(n^2)$，内存消耗小于 $10\text{ MB}$。

## 总结

双栈排序的核心突破口在于**充要条件的代数化转化**：
1. **逆序阻断充要性**：利用栈的 LIFO 特征与全排列目标顺序，将隐式搜索剪枝提炼为显式的三元逆序对判定；
2. **图论二分着色**：将“划分到两个容器”的组合选择问题等价映射为图的二染色，完成了从模拟搜索到图论判定算法的降阶飞跃。

## 形式化题目

在三维空间中，给定高度为 $h$ 的无限平层空间，下表面为平面 $z = 0$，上表面为平面 $z = h$。

空间内部存在 $n$ 个半径均为 $r$ 的三维球体（空洞），第 $i$ 个球的球心坐标为 $(x_i, y_i, z_i)$。
两点间连通规则如下：
1. 若两个球体相交或相切（即球心欧氏距离 $\le 2r$），则两球连通；
2. 若某球体与下表面相交或相切（即球心满足 $z_i - r \le 0$），则该球与下表面连通；
3. 若某球体与上表面相交或相切（即球心满足 $z_i + r \ge h$），则该球与上表面连通。

问是否存在一条连通路径，使得能够从下表面通过若干连续相交/相切的球体到达上表面。对于每组测试数据输出 `Yes` 或 `No`。

## 题目解析

!!! info 几何相切判据建图，引入虚拟顶底汇点，利用并查集维护两极连通性。
将所有球体视作图中的顶点。两球连通的充要条件是球心欧氏距离的平方 $\le (2r)^2$。建立编号为 $0$ 的“虚拟下表面”与编号为 $n+1$ 的“虚拟上表面”，将与下表面/上表面连通的球分别合并至对应虚拟点。最后检查 $0$ 与 $n+1$ 是否位于同一连通分量，即可将多源多汇的可达性判定转化为单次并查集查询。
!!!

### 思路

**1. 空间相交关系的代数化判据**

两个球体 $A(x_1, y_1, z_1)$ 与 $B(x_2, y_2, z_2)$ 在空间中相切或相交，当且仅当它们球心之间的欧几里得距离不超过两球半径之和 $2r$：

$$\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2 + (z_1 - z_2)^2} \le 2r$$

为了规避浮点数开方运算带来的精度损失与性能消耗，两边同时平方：

$$(x_1 - x_2)^2 + (y_1 - y_2)^2 + (z_1 - z_2)^2 \le 4r^2$$

同样地，对于平层界面的接触判定：
- 球与下表面 $z = 0$ 相交或相切：球心向下的最低点 $z - r \le 0 \iff z \le r$；
- 球与上表面 $z = h$ 相交或相切：球心向上的最高点 $z + r \ge h$。

**2. 虚拟源汇点与连通性转化**

整个问题本质上是一个**多源多汇连通性判定**问题：
- 源点集合：所有与下表面连通的球；
- 汇点集合：所有与上表面连通的球。

如果直接对每个源点跑广度优先搜索寻找汇点，需要处理集合间的双向关联。
一个更优雅的经典建模技巧是**引入超级源点与超级汇点**：
- 设置虚拟节点 $0$ 代表下表面（Bottom）；
- 设置虚拟节点 $n+1$ 代表上表面（Top）；
- 若球 $i$ 与下表面相交，则在 $i$ 与 $0$ 之间连一条边；
- 若球 $i$ 与上表面相交，则在 $i$ 与 $n+1$ 之间连一条边；
- 若球 $i$ 与球 $j$ 相交，则在 $i$ 与 $j$ 之间连一条边。

此时，问题直接规约为：**在由这 $n+2$ 个节点构成的无向图中，判断节点 $0$ 与节点 $n+1$ 是否连通**！

**3. 并查集（Disjoint Set Union）高效求解**

数据范围中 $n \le 1000$，球体两两之间的对数为 $\frac{n(n-1)}{2} \le 5 \times 10^5$。
直接枚举所有点对 $(i, j)$，如果两球相交，则调用并查集的 `union_set(i, j)` 进行集合合并。
在所有边关系合并完成后，只需判断：

$$\text{find\_set}(0) == \text{find\_set}(n+1)$$

若两者代表元相同，说明存在一条完整的通道连通底面与顶面，输出 `Yes`；否则输出 `No`。

### 正确性与边界

- **大整数平方溢出防范**：
  数据范围中坐标 $x, y, z$ 与半径 $r$ 最大可达 $10^9$。
  两点坐标差最大为 $2 \times 10^9$，其平方和最大可达 $3 \times (2 \times 10^9)^2 = 1.2 \times 10^{19}$。
  而 64 位带符号整数 `long long` 的最大值约为 $9.22 \times 10^{18}$，在三维坐标差平方累加时**必定会溢出产生负数**！
  这是本题最隐蔽的致命陷阱。代码中必须使用 128 位整数（GCC 内置 `__int128_t`）承载差值平方与 $(2r)^2$ 的比较，彻底消除整型溢出。
- **单个球同时连通上下表面**：
  若存在一个巨型球，既满足 $z_i \le r$ 又满足 $z_i + r \ge h$（即单个球半径跨越全高），它会同时与 $0$ 和 $n+1$ 合并，使 $0$ 和 $n+1$ 连通，输出 `Yes`，逻辑天然正确。
- **多组测试数据清空**：
  每组数据独立，必须在循环开头将并查集数组 `fa[0 ... n+1]` 完全重置为自环（`fa[i] = i`）。

### 复杂度

- **时间复杂度**：
  - 判定球与上下表面关系：$O(n)$；
  - 双重循环枚举所有球对并判定距离：$\frac{n(n-1)}{2} \approx 5 \times 10^5$ 次几何计算；
  - 带有路径压缩的并查集合并：单次反阿克曼函数 $\alpha(n) \le 4$；
  - 单组测试数据总耗时 $O(n^2 \alpha(n))$；
  - $T \le 20, n \le 1000$，全测试点总操作次数约 $20 \times 5 \times 10^5 \approx 10^7$ 次，耗时在 30ms 以内，远低于 1.0 秒限制。
- **空间复杂度**：
  - 仅需维护结构体数组与并查集父节点数组 `fa[1005]`，空间复杂度为 $O(n)$，内存消耗不到几 KB。

## 总结

本题是**连续空间计算几何向离散图论可达性规约**的经典范例。通过两边平方将欧氏几何的连续包含关系转化为离散无向边，再巧妙借助“虚拟两极节点”将复杂的多源多汇路径探索坍缩为最基础的并查集等价类合并，配合对 64 位大数平方乘积溢出的防范，达成了代码精炼与效率极限的统一。

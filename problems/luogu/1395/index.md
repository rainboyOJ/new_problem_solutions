### 题意

给定一棵 `n` 个点的树，每条边长度都是 `1`。

要选择一个点作为会议地点，使所有点到它的距离和最小。  
如果有多个点同样最优，输出编号最小的那个点。

### 思路

最直接的做法是枚举会议地点。

对每个点 `x`，从 `x` 出发 BFS 一次，求出它到所有点的距离和。这个做法很适合小数据验证：

@include-code(./brute.cpp, cpp)

这个暴力的瓶颈是：每个点都要重新 BFS 一次，总复杂度是 `O(n^2)`。

我们需要复用已经算过的信息。

先把树以 `1` 为根，求出两个东西：

- `dist_sum[1]`：所有点到 `1` 的距离和，也就是所有点深度之和；
- `subtree_size[u]`：以 `1` 为根时，`u` 子树里有多少个点。

然后考虑从父亲 `u` 换根到儿子 `v`。

这时距离变化非常清楚：

| 点的位置 | 数量 | 距离变化 |
| --- | --- | --- |
| `v` 的子树内 | `subtree_size[v]` | 每个点都减少 `1` |
| `v` 的子树外 | `n - subtree_size[v]` | 每个点都增加 `1` |

所以：

```text
dist_sum[v]
= dist_sum[u] - subtree_size[v] + (n - subtree_size[v])
= dist_sum[u] + n - 2 * subtree_size[v]
```

有了这个公式，就可以从 `1` 出发沿树边向下递推，在线性时间内求出每个点的距离和。

最后扫描所有点，选择距离和最小的点。因为题目要求并列时取编号最小，所以只有在 `dist_sum[i]` 严格更小时才更新答案。

### 复杂度

建树、求深度和子树大小、换根 DP 都只需要线性时间。

时间复杂度：`O(n)`。

空间复杂度：`O(n)`。

### 总结

这题的关键不是枚举会议地点，而是观察相邻两个点之间换根时距离和如何变化。

从父亲 `u` 移到儿子 `v` 时，`v` 子树内的点全部近一步，子树外的点全部远一步，于是得到换根公式：

```text
dist_sum[v] = dist_sum[u] + n - 2 * subtree_size[v]
```

这也是很多树上换根 DP 的基本套路：先固定一个根算初值，再沿边推出每个点作为根时的答案。

### 题意

每个非空连续区间产生一个区间异或值，从所有不同区间中选择 `k` 个，使异或值之和最大。

### 思路

这道题是 P4735 最大异或和的完美进阶。P4735 是求单个最大值，本题是求**前 $k$ 大的总和**。

#### 1. 离散数学转化：消除区间与无序性

构造前缀异或和数组 $S$：

$$S[i] = a[1] \oplus a[2] \oplus \dots \oplus a[i]$$

边界为 $S[0] = 0$。任意一个粽子的美味度可以表示为：

$$a[l] \oplus a[l+1] \dots \oplus a[r] = S[r] \oplus S[l-1]$$

其中 $0 \le l-1 < r \le n$。

题目要求选出 $k$ 个**互不相同**的区间 $[l, r]$，使得这 $k$ 个异或值之和最大。这等价于在所有的无序对 $(i, j)$ 中选出异或值最大的 $k$ 对。

这里有一个非常实用的算法竞赛转化技巧：**无序转有序**。
因为 $S[i] \oplus S[j] = S[j] \oplus S[i]$，求 $k$ 个最大的**无序对**，完全等价于在所有的**有序对** $(i, j)$（$i \neq j$）中，求出 $2k$ 个最大的值，把它们的和加起来最后除以 2 即可。
这样，我们将下标域扩展到了 $i \in [0, n]$ 且 $j \in [0, n]$，彻底去掉了 $i < j$ 的限制。

#### 2. 宏观调度：大根堆多路归并——从局部第 rank 大到全局前 k 大

现在已经能在 Trie 上查到"右端点 $i$ 的第 $rank$ 大异或值"了，但怎么把每个右端点的局部最优汇总成全局前 $k$ 大？这里用到的核心算法叫**多路归并（Multi-way Merge）**。

我们可以把每个右端点 $i$ 想象成一口不断出水的"井"。因为 01-Trie 可以按 $rank$ 从小到大查询，所以每口井里打出来的水，体积一定是**严格递减**的（第 1 大 $\ge$ 第 2 大 $\ge$ 第 3 大...）。现在有 $n$ 口井，我们要从所有井里，挑出总体积最大的 $k$ 桶水。

为了高效完成这个任务，我们需要引入一个**大根堆（Priority Queue）**来进行宏观调度。堆里的每一个元素需要记录三个信息：`(val, i, rank)`，分别代表**异或值**、**所属的右端点**、**当前是该端点的第几大**。

具体调度流程如下：

1. **全面撒网（初始化堆）**：对于所有的右端点 $i \in [1, n]$，去对应的历史版本 `root[i-1]` 中查出它能产生的**绝对最大值**（即 $rank = 1$）。将这 $n$ 个初始状态 `(val, i, 1)` 全部压入大根堆。此时堆顶一定是全局真正的第 1 大值。

2. **贪心收割（提取最大值）**：弹出堆顶元素，假设它是 `(val, i, rank)`。将这个 `val` 累加到目标总和 `total_ans` 中。

3. **顺藤摸瓜（懒加载补充）**：必须确保当前右端点还有剩余候选组合。既然右端点 $i$ 的第 $rank$ 大组合已经被拿走，就需要让这口"井"补充下一个水位的水。如果 $rank < i$（因为右端点 $i$ 最多只能和它前面的 $i$ 个前缀组合），就去 Trie 中查询右端点 $i$ 的第 $rank + 1$ 大的值，得到新的 `next_val`，将新状态 `(next_val, i, rank + 1)` 压回大根堆。

4. **循环往复**：重复执行步骤 2 和步骤 3，严格执行 $k$ 次。当循环结束时，`total_ans` 就是全局前 $k$ 大元素的和。

这种设计的精妙之处在于**按需索取**。在 $n=5 \times 10^5$ 的数据规模下，如果把每个端点的所有组合全查出来，内存和时间都会爆炸。而在大根堆的调度下，只有当某个端点的第 $rank$ 大值被确认为"全局前 $k$ 强"并被收割后，才会去查它的第 $rank+1$ 大值。总共只执行了 $n$ 次初始查询和 $k$ 次后续查询，完全避免了无意义的计算。

#### 3. 微观机制：Trie 树上的第 rank 大查询

上一题 P4735 中我们用 Trie 求了**最大值**，顺着相反的位走就行。本题要求**第 $rank$ 大**，需要对普通的 01-Trie 做一点升级：在每个节点维护一个 `size`（或 `cnt`）属性。

`size` 表示：**当前节点的子树中，一共包含了多少个数字。**

当我们在 Trie 树上查询与常数 $Val$ 异或第 $rank$ 大的值时，依然从最高位往下走。假设当前 $Val$ 的这一位是 $bit$，为了让异或值最大，我们期望走向 `expected = bit ^ 1` 的分支。

此时需要做一次关键的判断：

- **如果** `size[expected] >= rank`：说明期望的分支里的数字足够多，第 $rank$ 大的数字**一定**就藏在这个分支里。直接走向 `expected` 分支，`rank` 不变。
- **如果** `size[expected] < rank`：说明理想的分支里数字不够。第 $rank$ 大的数字**被迫**落在另一个较差的分支 `bit` 中。走向 `bit` 分支，同时更新目标：去新分支里找第 `rank - size[expected]` 大的数字。

#### 4. 两种解法：全局 Trie 与可持久化 Trie

本题有两种主流满分解法：

**全局 01-Trie 派**：把所有 $S[0..n]$ 插入一棵全局 Trie，利用"无序转有序"trick，求前 $2k$ 大有序对再除以 2。每个下标最多查询 $n$ 个其他值（排除自身 $S[i]^S[i]=0$），堆操作 $2k$ 次。

**可持久化 01-Trie 派**：像 P4735 一样，`root[r]` 恰好包含 $S[0..r-1]$，天然隔离未来数据。对于右端点 $r$，拿着 $S[r]$ 去 `root[r]` 查询第 $rank$ 大即可，严格遵守 $l \le r$。堆操作只需 $k$ 次，不需要翻倍除以 2。

| 维度 | 全局 01-Trie | 可持久化 01-Trie |
| --- | --- | --- |
| **逻辑转化** | 转化为无序对，求前 $2k$ 大再除以 2 | 严格保持有序，仅在历史版本中求前 $k$ 大 |
| **空间开销** | 较小。只需一棵树，空间约 $N \times 32$ | 较大。每次插入建新链，空间约 $(N+1) \times 33$ |
| **堆操作次数** | $2k$ 次 | $k$ 次 |
| **思维复杂度** | 需要想到"无序对翻倍"的 trick | 非常直观，完美继承 P4735 的区间查询思维 |

> **数据范围警报**：$a_i \le 4{,}294{,}967{,}295 = 2^{32}-1$，达到 32 位无符号整数极限。Trie 深度必须是 32 层（第 31 到 0 位）。前 $2k$ 个最大值的总和会非常大，答案必须使用 `long long`。

### Python 知识

- `heapq` 是小根堆，存负值即可模拟最大堆。
- 堆元素 `(-value, end, rank)` 同时记录来源列与下一排名。
- 三个 `array("i")` 保存左右儿子和节点计数，避免上千万节点对象。
- `array("I")` 保存 32 位无符号前缀异或。

### 复杂度

Trie 建立 $O(32n)$，每次第 `rank` 大查询 $O(32)$，堆操作 $O(\log n)$；总时间 $O(32(n+k)+(n+k)\log n)$，空间 $O(32n+n)$。

### 总结

"每个右端点一列有序候选 + 堆归并"把无法枚举的 $O(n^2)$ 个区间压缩为只访问前 $k$ 个需要的值。全局 Trie 用"无序对翻倍"省空间，可持久化 Trie 用历史版本直接隔离未来数据，两者在第 $rank$ 大查询上共享同一个 `size` 判断逻辑。

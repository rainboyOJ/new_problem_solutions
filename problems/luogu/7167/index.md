### 题意

$N$ 个圆盘从上到下（编号 $1 \sim N$），第 $i$ 个圆盘直径 $D_i$、容量 $C_i$。圆盘里的水超过容量就会溢出，流入**下方第一个直径更大**的圆盘；下面没有更大的就流入水池。

$Q$ 次询问（互不影响）：向圆盘 $R$ 倒入 $V$ 体积的水，最后水停在哪？停在圆盘输出编号，流入水池输出 $0$。

数据范围：$N \leqslant 10^5$，$Q \leqslant 2 \times 10^5$，$C_i \leqslant 1000$，$D_i, V \leqslant 10^9$。

### 思路

**一句话本质**：每个圆盘的溢出去向是**唯一且固定**的——下方第一个直径更大的圆盘，与水量无关。于是喷泉变成若干条汇入水池的链，询问 = 沿链走、逐盘扣容量，问水在哪耗尽。这是"链上带权跳跃"，用单调栈求链 + 倍增段跳加速。

暴力对每个询问从 $R$ 出发：装得下就停，装不下就扣掉容量、跳到下一个更大的圆盘。最坏 $O(N)$ 一个询问，$Q$ 次询问 $O(NQ)$ 不可行。

**溢出去向是唯一的吗？**

水从圆盘 $i$ 溢出后只会流向**下方第一个 $D_j > D_i$** 的圆盘，这个去向只由 $i$ 决定，和倒了多少水无关。用单调栈从右往左 $O(N)$ 求出每个 $i$ 的 `nxt[i]`：

```cpp
while (stk_top > 0 && D[stk[stk_top]] <= D[i]) stk_top--;
nxt[i] = (stk_top > 0) ? stk[stk_top] : 0;   // 0 = 水池
stk[++stk_top] = i;
```

**问题变成什么？**

每个圆盘只有一个"父"（`nxt[i]`），整座喷泉是若干条指向水池（0）的链。询问 = 从 $R$ 出发沿链向上走，每经过一个圆盘扣掉它的容量 $C_i$，问水在哪耗尽——标准的"树上从节点向上走"场景，用**倍增**加速。

**怎么加速沿链扣容量？**

预处理两个倍增表：

- `up[k][i]`：从 $i$ 沿链向上 $2^k$ 步到达的圆盘；
- `sum[k][i]`：这 $2^k$ 步经过圆盘的容量和（含 $i$，不含终点）。

查询时从大到小枚举 $k$：只要 `sum[k][cur] < need`（跳过去这些圆盘**都能被装满**且水还有剩），就整段跳：

```cpp
for (int k = LOG - 1; k >= 0; k--) {
    if (up[k][cur] != 0 && sum[k][cur] < need) {
        need -= sum[k][cur];
        cur = up[k][cur];
    }
}
```

**为什么跳完只剩两种情况？**

循环停下的时刻，最小的 $k = 0$ 也不再满足 `sum[0][cur] < need`，即不再满足 `C[cur] < need` 或 `up[0][cur] == 0`：

- `C[cur] >= need`：当前圆盘装得下剩余的水（含恰好装满，因为"大于容量才溢出"）→ 答案 `cur`；
- 否则说明 `C[cur] < need` 且 `up[0][cur] == 0`：当前圆盘也会装满，而它上面没有更大的圆盘 → 水流入水池，答案 `0`。

#### 倍增正确性的数学证明

倍增的正确性来自**二进制表示的唯一性**：任意非负整数 $d$ 可以唯一写成若干个不同的 $2$ 的幂之和（$d = \sum_k b_k 2^k$，$b_k \in \{0,1\}$）。"从大到小枚举 $2^k$、能跳就跳"的过程，就是**逐位构造 $d$ 的二进制表示**。

设从起点到答案需要走的距离为 $d$，当前已走距离为 $s$（$s \leqslant d$），归纳每一步：

- 若 $d$ 的第 $k$ 位是 $1$：$d - s$ 的剩余部分包含 $2^k$ 这一项，所以 $s + 2^k \leqslant d$，这一步仍然安全 → 跳，$s := s + 2^k$；
- 若 $d$ 的第 $k$ 位是 $0$：高位已经全部匹配，$d - s < 2^k$，所以 $s + 2^k > d$，这一步会越过答案 → 不跳。

由于每个 $2^k$ 在 $d$ 的二进制中至多出现一次，"能跳就跳"既不会跳过头，也不会漏跳，最终 $s = d$ 精确停在答案。

这个证明依赖两个前提，缺失则倍增失效：

1. **单调性**：`check` 必须满足 true…true false…false（安全位置是前缀）。本题沿链累计容量 `sum[k][cur]` 单调不减，恰好满足；
2. **可分解性**：距离能按二进制拆分，且跳跃表 `up[k][i] = up[k-1][up[k-1][i]]` 保证"跳 $2^k$ 步"等于"跳两次 $2^{k-1}$ 步"（归纳基础）。

对应到本题：剩余水量 `need` 就是 $d$，`sum[k][cur] < need` 就是"这一步安全"的 check，从 `LOG-1` 到 $0$ 枚举就是从高位到低位构造 need 的二进制路径。

### 复杂度

单调栈 $O(N)$，倍增表 $O(N \log N)$；每个询问 $O(\log N)$。总 $O((N + Q) \log N)$，空间 $O(N \log N)$。

### 总结

本题的建模关键是**发现去向唯一**：水往哪流由圆盘本身决定，于是过程变成静态的链，而不是动态模拟。链上的"走若干步、消耗带权和"问题，套路就是倍增。

以后看到"每个点只有一条出边 / 唯一的下一步去向"，先想到把过程变成链或森林，再用倍增跳段。

#### 点权倍增 vs 边权倍增

本题的容量 $C_i$ 在**点上**（每个圆盘自己的容量），所以 `sum[0][i] = C[i]`，跳转判断 `sum[k][cur] < need` 时段的"消耗"**含起点、不含终点**。有些倍增题的信息在**边上**（如树上路径边权和、到根的距离），两类问题的结构相同，但语义和边界要区分：

| | 点权型（本题） | 边权型（如树上距离） |
|---|---|---|
| 信息存哪 | 节点自己的容量/权值 | 节点到父节点的边权 |
| `sum[0][i]` | $C_i$ | 边权（或按定义约定） |
| 时段语义 | 含起点 $i$，不含终点 | 通常含终点，不含起点 |
| 边界判断 | `C[cur] >= need` 停 | 视题目约定（如 `>` / `>=`） |

写法上 `up[k][i] = up[k-1][up[k-1][i]]`、`sum[k][i] = sum[k-1][i] + sum[k-1][up[k-1][i]]` 完全一样，但**边界条件必须按信息在点还是边上重新核对**，不能照搬。

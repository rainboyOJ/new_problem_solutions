## 形式化题目

给定正整数 $N, K$（满足约束 $N + K \le 15$）。

设计一个大小为 $K$ 的严格递增正整数集合 $A = \{a_1, a_2, \dots, a_K\}$（其中 $1 = a_1 < a_2 < \dots < a_K$），使得用集合 $A$ 中的元素在多重重叠组合下：
$$\sum_{i=1}^K c_i \cdot a_i = v, \quad \text{其中 } c_i \in \mathbb{N}, \sum_{i=1}^K c_i \le N$$
对于连续整数 $v = 1, 2, \dots, S$，每一个 $v$ 都至少存在一组非负整数解 $(c_1, \dots, c_K)$。

目标：求出能够满足上述连续覆盖条件的最大连续上限 $S$（记为 $\mathsf{MAX}$），并输出达到该最大连续上限的升序面值序列 $A$。

原题中将使用邮票的最大数量限制称为 $N$，将邮票种数称为 $K$，将面值序列构成的最大连续邮资称为 $\mathsf{MAX}$。

## 正解

### 思路

#### 1. 组合爆炸与上界剪枝原理

若直接枚举 $K$ 种正整数面值，即使在 $K \le 10$ 时，搜索树分支也极其庞大。如何确定第 $step + 1$ 种面值 $a_{step + 1}$ 的合法取值区间，是本题能否在规定时间内求解的关键核心。

设当前已经确定了前 $step$ 种面值 $A_{step} = \{a_1, \dots, a_{step}\}$，并且用这 $step$ 种面值（每种面值使用次数之和不超过 $N$）所能凑出的**最大连续整数**为 $r$。也就是说：
- 区间 $[1, r]$ 内的每一个整数都可以被不超过 $N$ 张面值属于 $A_{step}$ 的邮票凑出；
- 整数 $r + 1$ 无法被仅使用前 $step$ 种面值凑出。

现在考虑加入第 $step + 1$ 种面值 $x = a_{step + 1}$：
1. **严格递增下界**：为了保证面值不重复且单调，必有 $x \ge a_{step} + 1$。
2. **连续性紧致上界**：$x$ 的取值**至多只能为 $r + 1$**。
   - **证明**：假设选取了 $x > r + 1$，那么在加入面值 $x$ 之后，整数 $r + 1$ 仍然无法被凑出。因为 $x > r + 1$，任何包含至少一张 $x$ 的组合面值必定大于等于 $x > r + 1$；而如果不使用面值 $x$，只使用前 $step$ 种面值根据定义又无法凑出 $r + 1$。因此，如果 $x > r + 1$，连续区间的断点 $r + 1$ 永远无法被填补，连续段依然卡在 $r$，不可能产生更大的连续区间。
   - 故必有 $x \le r + 1$。

由此，第 $step + 1$ 种面值的搜索分支被严格夹逼在闭区间 $[a_{step} + 1, r + 1]$ 内！这个强力剪枝将无限的状态空间急剧压缩为一个非常窄小的搜索带。

#### 2. 增量完全背包核算连续区间

在回溯搜索的每一层中，若对当前的每一种可能面值都重新运行一次完全背包，会有大量重复子问题计算。

利用递归树的深度性质，可以采用**分层继承的增量完全背包**：
- 设 $dp[step][v]$ 表示仅使用前 $step$ 种面值，凑出面值 $v$ 所需的**最少邮票张数**。
- 当深入到第 $step + 1$ 层且加入新面值 $next\_val$ 时，直接继承上一层的 DP 状态：
  $$dp[step + 1][v] = \min(dp[step][v], dp[step + 1][v - next\_val] + 1)$$
- 转移完成后，从上一层的连续上限 $cur\_max$ 开始线性向前探测，找到第一个满足 $dp[step + 1][v] > N$ 的点，该点的前一个位置即为当前新的连续上界 $next\_max$。
- 递归返回时无需额外的撤销操作，天然保证了回溯的轻量与高效。

### 复杂度

- **时间复杂度**：
  - 在 $N + K \le 15$ 的约束下，最大面值设计问题（Postage Stamp Problem）的每层分支极少（由于 $a_{step + 1} \le r + 1$ 且连续值推进平滑）；
  - 增量背包单次更新的值域范围为 $O(\mathsf{MAX})$（实际最大值通常在数千以内）；
  - 综合搜索树节点规模与增量背包开销，总运算次数在 $10^6$ 量级以内，实际运行耗时约 $10\text{ms}$。
- **空间复杂度**：
  - 仅需维护分层 DP 数组 $dp[20][2005]$，总内存占用小于 $1\text{MB}$。

## 总结

本题是深搜回溯与动态规划深度融合的经典案例。其解法跳出了“先生成面值再验证”的割裂思路，通过深入分析连续整数覆盖的传递性，推导出 $next\_val \le cur\_max + 1$ 的连续断点界限，并以增量完全背包作为状态验证器，形成了由 DP 结果动态引导搜索区间的严密闭环。

P3178 样例逐步演示：常数树与系数树

同一棵树上两套数：左边常数树、右边系数树；查询答案 = 常数树的值 + 深度 × 系数树的值。 数值由页面按输入实时算出。可以换预设，也可以把任意一组小数据粘进来。

预设：

格式与题面输入一致：第一行 n m，第二行 n 个初始权值， 接着 n-1 行边，最后 m 行操作（1 x a 点加、2 x a 子树加、3 x 查询）。 为了看得清，节点数限制在 12 以内。

改完点应用；出错会提示第几行。

常数树 bit_const

存每次修改里与深度无关的那部分

系数树 bit_depth

存要乘上查询点深度的系数

这一步常数变了 这一步系数变了 查询取的节点 键盘：← → 切换，空格播放/暂停

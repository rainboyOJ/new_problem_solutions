# P17415 「IXOI R3」帮助她玩游戏
## 题目背景

她在阴险狡诈的黑心游戏厅玩游戏。由于你非常担心她，你决定对她进行帮助。

## 题目描述

她去了一个黑心游戏厅，由于你的会员身份，她初始有 $x$ 个游戏币。

游戏厅里有 $n$ 台兑换机，第 $i$ 台兑换机有如下功能：投入 $a_i$ 个游戏币，它会弹出 $b_i$ 个游戏币。其中 $k$ 个兑换机有特殊功能（剩余 $n-k$ 个功能如上），对于具有特殊功能的兑换机，投入 $a_i$ 个游戏币后，既有概率弹出 $b_i$ 个游戏币又有概率弹出 $c_i$ 个游戏币。

下文把有特殊功能的兑换机称为“特殊兑换机”，其他的兑换机称为“普通兑换机”。

她依次走过第 $1\sim n$ 台兑换机，她决定使用每个兑换机不超过 $1$ 次。如果当前这一台是普通兑换机且她的游戏币有至少 $a_i$ 个，那么她一定会使用这个兑换机；如果这台是一个特殊兑换机且她的游戏币至少有 $a_i$ 个，那么她谨慎选择是否使用；对于其他情况，她一定不会使用。

你非常关心她，你对她进行了 $q$ 次询问：对于所有选择方案，是否存在一种方案使得她有概率在最后获得恰好 $y_i$ 个游戏币。

## 输入格式

第一行，输入三个正整数 $n,x,q$，表示兑换机数、初始的游戏币数和询问数。由于 $k$ 可以由下面信息得到，这里不再输入。

接下来 $n$ 行，依次输入每台兑换机的信息。对于每个兑换机：先输入 $o_i$ 表示该兑换机的类型（$0$ 表示普通兑换机，$1$ 表示特殊兑换机）。对于普通兑换机，接下来输入 $a_i,b_i$；对于特殊兑换机，输入 $a_i,b_i,c_i$（其含义见题目描述）。

接下来 $q$ 行，每行一个正整数 $y_i$，表示询问参数。

## 输出格式

输出 $q$ 行，按顺序每行回答一个询问。如果存在方案输出 $1$，否则输出 $0$。

## 输入输出样例 #1

### 输入 #1

```
4 5 5
0 2 1
1 5 1 2
0 5 10
1 1 2 3
3
4
5
6
7
```

### 输出 #1

```
0
1
1
1
0
```

## 说明/提示

### 样例解释

对于该样例 $k=2$。

初始时，她有 $5$ 个游戏币。

经过第一个兑换机时，她有 $5$ 个游戏币。由于是普通兑换机且 $5>2$，所以她一定会使用，此时她有 $5-2+1=4$ 个游戏币。

经过第二、三个兑换机时，由于她只有 $4$ 个游戏币，她一定不会使用。

经过第四个兑换机时，她有 $4$ 个游戏币。由于该兑换机是特殊兑换机她可以选择是否使用。如果不使用，将维持 $4$ 个游戏币；如果使用，有可能变为 $4-1+2=5,4-1+3=6$ 个游戏币。

因此最后她有可能获得 $4,5,6$ 个游戏币，所以 $2,3,4$ 询问的答案是 $1$，其他询问答案答案是 $0$。

### 数据范围

**本题采用捆绑测试**。

- 子任务 $0$（$5$ 分）：$n\le 10$；
- 子任务 $1$（$1$ 分）：$k=0$；
- 子任务 $2$（$15$ 分）：$k\le 4$；
- 子任务 $3$（$20$ 分）：$n\le 100$；
- 子任务 $4$（$10$ 分）：$a_i=b_i$；
- 子任务 $5$（$4$ 分）：$n\le 2\times 10^4$；
- 子任务 $6$（$5$ 分）：$a_i=1$；
- 子任务 $7$（$40$ 分）：无特殊限制；

对于 $100\%$ 的数据，$1\le n,q\le 2.5\times 10^5$，$0\le k\le \min(n,30)$，$0\le o_i\le 1$，$1 \le a_i\le 20$，$1\le x,b_i,c_i,\sum\limits_{i=1}^{n} b_i,\sum\limits_{i=1}^{n} c_i\le 2.5\times 10^5$，$1\le y_i\le 10^{18}$（上述 $c_i,\sum\limits_{i=1}^{n} c_i$ 可以理解为忽略 $o_i=0$ 的 $i$ 后的结果）。

## 形式化题目

给定一个长度为 $n$ 的正整数序列 $T = [t_1, t_2, \dots, t_n]$（满足 $2 \le n \le 100, 130 \le t_i \le 230$）。

原题中将序列元素称作同学的身高。

定义一个下标严格递增的子序列 $P = [p_1, p_2, \dots, p_k]$（$1 \le p_1 < p_2 < \dots < p_k \le n$）为**单峰子序列**（合唱队形），当且仅当存在一个中心峰顶下标 $c \in [1, k]$，使得：
$$
t_{p_1} < t_{p_2} < \dots < t_{p_c} > t_{p_{c+1}} > \dots > t_{p_k}
$$
即前半部分严格单调递增，后半部分严格单调递减。

目标：从原序列中选出一个长度 $k$ 最大的单峰子序列，并输出需剔除的最小元素个数 $n - k$。

## 暴力解法

### 思路

直接枚举原序列的每一个位置 $i \in [1, n]$ 作为单峰序列的峰顶中心：
1. 以 $i$ 为中心时，左侧必须是从原序列前缀 $1 \dots i$ 中选出以 $t_i$ 结尾的严格递增子序列（LIS）；
2. 右侧必须是从原序列后缀 $i \dots n$ 中选出以 $t_i$ 开头的严格递减子序列（LDS）；
3. 暴力算法可以使用朴素递归回溯，分别从位置 $i$ 向左递归搜索以 $i$ 结尾的最长严格上升子序列长度，向右递归搜索以 $i$ 开头的最长严格下降子序列长度；
4. 将两部分长度相加并减去重复计算的中心节点 $i$，即得到以 $i$ 为峰顶的最大长度；遍历所有 $i$ 取全局最大值。

### 复杂度

- **时间复杂度**：在每个位置 $i$ 处进行无记忆化的纯递归搜索，最坏情况下子序列搜索树呈指数级展开，复杂度为 $\mathcal{O}(n \cdot 2^n)$。在 $n \le 20$ 时可以运行，但当 $n = 100$ 时会严重超时。
- **空间复杂度**：递归栈深度为 $\mathcal{O}(n)$。

### 瓶颈

暴力的缺陷在于对大量具有相同结尾/开头与大小关系的前驱状态进行了重复递归计算。实际上，以任意位置 $j$ 结尾的最长上升子序列长度是一个定值，完全可以通过线性动态规划在多项式时间内预处理。

## 正解

### 思路

#### 1. 问题等价归约
“请出最少同学使剩下的人排成合唱队形”，在数学上严格等价于“在原序列中求出长度最长的单峰子序列”。若求出最长单峰子序列的长度为 $k$，则最少出列人数即为 $n - k$。

#### 2. 双向独立最优化拆解
设单峰子序列的最高点在原序列中的下标为 $i$（$1 \le i \le n$）：
- 峰顶左半部分：由属于原序列前缀 $[1, i]$ 的若干下标组成，满足严格单调递增且以 $t_i$ 结尾，其本质是以 $t_i$ 结尾的最长严格上升子序列（LIS）；
- 峰顶右半部分：由属于原序列后缀 $[i, n]$ 的若干下标组成，满足严格单调递减且以 $t_i$ 开头，其本质是以 $t_i$ 开头的最长严格下降子序列（LDS），等价于从右向左看以 $t_i$ 结尾的最长严格上升子序列。

**独立性与无交性**：
除了中心节点 $t_i$ 被两段共同包含之外，左半部分可选的下标集合严格位于 $i$ 左侧（$< i$），右半部分可选的下标集合严格位于 $i$ 右侧（$> i$）。两者的选择在约束上完全解耦、互不干扰。根据动态规划的最优子结构性质，以 $i$ 为峰顶所能达到的最长队形长度，必然等于左侧最大长度加上右侧最大长度减 $1$（扣除重复计入的峰顶自身）：
$$
\text{len}_i = f[i] + g[i] - 1
$$

#### 3. 动态规划状态转移
1. **正向 LIS 递推**：
   设 $f[i]$ 表示以 $t_i$ 结尾的最长上升子序列长度。
   $$
   f[i] = \max_{\substack{1 \le j < i \\ t_j < t_i}} \{ f[j] \} + 1 \quad (\text{初值 } f[i] = 1)
   $$
2. **反向 LIS（LDS）递推**：
   设 $g[i]$ 表示以 $t_i$ 开头的最长下降子序列长度。
   $$
   g[i] = \max_{\substack{i < j \le n \\ t_j < t_i}} \{ g[j] \} + 1 \quad (\text{初值 } g[i] = 1)
   $$
3. **全局极值合并**：
   遍历所有可能的峰顶中心 $i \in [1, n]$，最大保留人数为：
   $$
   k = \max_{1 \le i \le n} (f[i] + g[i] - 1)
   $$
   最终答案为 $n - k$。

### 复杂度

- **时间复杂度**：
  - 正向计算数组 $f$ 需进行双重循环，运算次数为 $\frac{n(n-1)}{2}$；
  - 反向计算数组 $g$ 同样需进行双重循环，运算次数为 $\frac{n(n-1)}{2}$；
  - 遍历求全局最大值需 $\mathcal{O}(n)$；
  - 总时间复杂度为 $\mathcal{O}(n^2)$。对于 $n \le 100$，总比较次数在 $10^4$ 量级，耗时不足 $1\text{ ms}$。
- **空间复杂度**：
  - 仅需三个大小为 $n + 1$ 的一维数组维护身高与 DP 值，空间复杂度为 $\mathcal{O}(n)$，内存占用小于 $1\text{ MB}$。

## 总结

解决本题的核心思维在于**通过结构解耦化全局单峰为局部单调**：
1. **极值点定位**：通过显式枚举单峰序列的峰顶坐标 $i$，消除了单调方向转折的不确定性；
2. **左右独立性**：识别出峰顶两侧下标集合不相交的本质，将复杂的折线形态拆解为两个经典的标准 LIS 动态规划子问题；
3. **对偶合并**：正向与反向分别扫描一次后，单次 $O(1)$ 拼装即可穷尽所有全局最优候选。

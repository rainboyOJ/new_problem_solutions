# P17413 「IXOI R3」时间复杂度分析
## 题目背景

你是[出题人](/user/743014 "祝你比赛顺利！")的好朋友，你在学习时间复杂度相关知识。

## 题目描述

现在你有个题目，这个题目的解法的时间消耗只和这个题目输入的参数 $n$ 有关。

我们约定：
1. 时间复杂度由低到高只考虑 $O(1),O(n),O(n^2)$。
2. 由于你并不精通常数和小数，你决定忽略常数和小数带来的影响。对于 $O(x)$ 时间复杂度的程序，需要执行恰好 $x$ 次运算。
3. 这个题的时间限制为 $1$ 秒，这里假定评测机 $1$ 秒可以进行恰好 $5\times 10^8$ 次运算，你程序执行所需要的运算次数不能超过这个值就可以通过。

对于输入的 $n$，你现在希望找到可以通过题目的最高时间复杂度，时间复杂度的高低顺序见第一条约定。

## 输入格式

输入一行一个正整数 $n$，表示这个题目输入的参数 $n$。

## 输出格式

每一个时间复杂度对应一个字符串，对应关系如下表：

|时间复杂度 |对应字符串 |
|:----:|:----:|
|$O(1)$|`O(1)`|
|$O(n)$|`O(n)`|
|$O(n^2)$|`O(n^2)`|

输出一行一个字符串，表示时间复杂度。

## 输入输出样例 #1

### 输入 #1

```
400000000
```

### 输出 #1

```
O(n)
```

## 输入输出样例 #2

### 输入 #2

```
500
```

### 输出 #2

```
O(n^2)
```

## 输入输出样例 #3

### 输入 #3

```
900000000000000000
```

### 输出 #3

```
O(1)
```

## 说明/提示

### 样例解释

#### 样例 #1

在 $n=4\times10^8$ 时，复杂度由低到高分别需要执行 $1,4\times10^8,1.6\times 10^{17}$ 次运算，可以通过的最高复杂度为 $O(n)$，所以输出 `O(n)`。

#### 样例 #2

在 $n = 500$ 时，复杂度由低到高分别需要执行 $1,500,2.5\times10^5$ 次运算，可以通过的最高复杂度为 $O(n^2)$，所以输出 `O(n^2)`。

### 数据范围

**本题采用捆绑测试**。

- 子任务 $0$（$40$ 分）：$n\le 10^9$；
- 子任务 $1$（$60$ 分）：无特殊限制；

对于 $100\%$ 的数据，保证：$1\le n\le 10^{18}$。

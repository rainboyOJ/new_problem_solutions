## 形式化题目

有 $n$ 个区间 $[l_i, r_i)$（即覆盖位置 $l_i, l_i+1, \dots, r_i-1$），并且

$$
l_1,\dots,l_n,r_1,\dots,r_n \quad \text{是 } 1,2,\dots,2n \text{ 的一个排列（两两不同）}.
$$

初始时长度为 $2n+1$ 的序列 $a_0,\dots,a_{2n}$ 全为 $0$。按**任意顺序**把每个区间恰好执行一次：第 $i$ 个区间把 $a_{l_i},\dots,a_{r_i-1}$ 全部赋成 $i$。要求选择执行顺序，最大化

$$
\#\{i: 0 \leqslant i < 2n,\ a_i \neq a_{i+1}\}.
$$

注意下标从 $0$ 开始，而 $a_0$ 永远不会被任何区间覆盖（因为所有 $l_i \geqslant 1$）。

## 暴力解法

### 思路

题意本身就是一个可以照做的过程：$n$ 很小的时候，直接枚举所有 $n!$ 种执行顺序，每种顺序都在数组上**真的覆盖赋值一遍**，再统计相邻不同的位置数，取最大值即可。

它的价值有两点：一是作为对拍基准，二是能让我们放心地相信后面推出来的公式。做法没有任何取巧，但在 $n \leqslant 8$ 时 $n!$ 还可以接受。

### 复杂度

时间复杂度 $O(n! \cdot n)$（每种顺序还要 $O(n)$ 次赋值），空间 $O(n)$。对 $n = 5000$ 完全不可行。

### 瓶颈

瓶颈显然在于"枚举顺序"这件事本身。但真正值得反思的是：**我们真的有 $n!$ 种本质不同的可能吗？**

数组的值只由"每个位置最后被谁覆盖"决定。所有区间都覆盖 $l_i$，而没有任何区间覆盖 $l_i - 1$；位置 $r_i - 1$ 被区间 $i$ 覆盖，位置 $r_i$ 不被区间 $i$ 覆盖。也就是说，**相邻不同的位置（下面叫"断点"）只可能出现在 $2n$ 个端点处**，别的位置必然相等。这提示我们用"每个端点能不能成为断点"来描述问题，答案自然就被压进了 $O(n)$ 个布尔量的范围里。

## 正解

### 思路

**第一步：把"顺序"翻译成"端点的二选一"。**

我们只关心每个端点 $s \in \{1,\dots,2n\}$ 是不是断点（$s$ 是断点定义为 $a_{s-1} \neq a_s$）。由于端点两两不同，$s$ 一定恰好是某一个区间的 $l_j$ 或 $r_j$。讨论 $s$ 处的两个邻居最终被谁写：

- 若 $s = l_j$：最终 $a_s = j$；而 $a_{s-1}$ 等于"在 $j$ 之后（最后一次）写 $s-1$ 的那个区间"，$s-1$ 被 $k$ 覆盖需要 $l_k < s < r_k$。所以

$$
s = l_j \text{ 是断点} \iff \text{存在区间 } k \text{ 满足 } l_k < l_j < r_k \text{ 且 } k \text{ 排在 } j \text{ 之后}.
$$

- 若 $s = r_j$：$a_{s-1} = j$（因为 $j$ 覆盖 $s-1$），而 $a_s$ 由最后写 $s$ 的那个区间决定，$s$ 被 $k$ 覆盖同样需要 $l_k < s < r_k$。所以

$$
s = r_j \text{ 是断点} \iff \text{存在区间 } k \text{ 满足 } l_k < r_j < r_k \text{ 且 } k \text{ 排在 } j \text{ 之后}.
$$

两类条件的形状完全一样：**"端点 $s$ 是断点"当且仅当有某个区间 $k$ 覆盖了 $s$（即 $l_k < s < r_k$）并且 $k$ 排在包含 $s$ 的那个区间 $j$ 之后**。

特别地，位置 $2n$ 一定是断点：$2n$ 是某个 $r_j$，而 $a_{2n}$ 永远不会被覆盖（$=0$），$a_{2n-1} = j \neq 0$。

**第二步：找出真正的冲突——交错区间对。**

每次从 $2n$ 个端点里挑若干个作为断点，是一组选择。两组选择之间唯一的约束来自"$k$ 排在 $j$ 之后"这种先后关系本身是不是能同时满足。设两个区间的左端点满足 $l_i < l_j$，分类讨论：

1. $r_i < l_j$：两个区间不相交，先后顺序互不影响，端点 $l_i, l_j, r_i, r_j$ 都能成为断点。
2. $r_j < r_i$：区间 $j$ 被区间 $i$ 包含。把 $i$ 排在前面即可让 $l_j$ 与 $r_j$ 都成为断点，也无冲突。
3. $l_i < l_j < r_i < r_j$：两个区间**交错**。这时：

   - 若 $l_j$ 要成为断点，就需要区间 $i$ 排在 $j$ **之后**（因为只有 $i$ 覆盖 $l_j$）；
   - 若 $r_i$ 要成为断点，就需要区间 $j$ 排在 $i$ **之后**（因为只有 $j$ 覆盖 $r_i$）。

   两者不能同时成立。于是得到唯一的冲突：

$$
r_i \text{ 与 } l_j \text{ 不能同时被选为断点} \qquad (l_i < l_j < r_i < r_j).
$$

**第三步：建二分图，用 König 定理算答案。**

把 $2n$ 个端点分成两类：**左部点**是所有 $r_i$，**右部点**是所有 $l_j$。对每个交错对 $l_i < l_j < r_i < r_j$，在 $r_i$ 与 $l_j$ 之间连一条边。上面的结论说：

$$
\text{可以同时当选断点的端点集合} = \text{这张二分图的一个独立集}.
$$

> **为什么图上只要有边，冲突就一定来自交错对？** 若存在区间 $k$ 同时覆盖 $r_i$ 与 $l_j$（$l_k < l_j < r_k$ 且 $r_i < r_k$），且 $l_i < l_j$，那么 $l_k < l_j < r_k$ 与 $r_i < r_k$、$l_i < l_j$ 一起恰好给出 $l_i < l_j < r_i < r_k$，也就是 $i, k$ 本身构成一个交错对，$r_i$ 与 $l_j$ 之间本来就有边。所以不必再为"被同一个区间覆盖"单独设约束。

那么答案上界是什么？设最终断点集合为 $B$。取

$$
C = \{r_i : r_i \notin B\} \cup \{l_j : l_j \notin B\},
$$

它的反面是 $B$，而任何一条边 $r_i l_j$ 的两个端点不可能同时落在 $C$ 里（$r_i$ 与 $l_j$ 不能同时被选，所以至少有一个不在 $B$ 里）。因此 $C$ 是一个**顶点覆盖**，$|C| \geqslant \nu$（$\nu$ 为最大匹配数），于是

$$
|B| = 2n - |C| \leqslant 2n - \nu .
$$

**第四步：上界可以达到（构造顺序）。**

取一个大小恰为 $2n-\nu$ 的独立集 $S$（König 定理保证它存在：由最大匹配的交替路可以构造出最小顶点覆盖 $C$，令 $S = V \setminus C$ 即可）。对 $S$ 建一张有向图 $D_S$：若 $s \in S \cap \{l_j, r_j\}$，且区间 $m$ 覆盖了 $s$（即 $l_m < s < r_m$），就连一条弧

$$
m \longrightarrow j \qquad (\text{含义：覆盖者 } m \text{ 必须排在 } j \text{ 之后}).
$$

> **引理：$D_S$ 无环。**
>
> 反设存在环，取其中**长度最小**的一个 $j_1 \to j_2 \to \dots \to j_k \to j_1$。对每条弧 $j_{t-1} \to j_t$，取一个见证 $x_t \in S \cap \{l_{j_t}, r_{j_t}\}$ 满足 $l_{j_{t-1}} < x_t < r_{j_{t-1}}$。由 $l_{j_t} \leqslant x_t \leqslant r_{j_t}$ 立刻得到
>
> $$
> l_{j_{t-1}} < r_{j_t}, \qquad l_{j_t} < r_{j_{t-1}},
> $$
>
> 即**环上相邻的两个区间必然相交**。取环上 $r_{j_p}$ 最大的那个区间。（$r$ 两两不同，所以它唯一。）
>
> - 环上前驱 $j_{p-1}$ 与 $j_p$ 相交，且 $r_{j_{p-1}} < r_{j_p}$，所以两者嵌套。若 $l_{j_p} < l_{j_{p-1}}$，那就是 $j_{p-1} \subset j_p$，可弧 $j_{p-1} \to j_p$ 的见证必须落在开区间 $(l_{j_{p-1}}, r_{j_{p-1}})$ 内，而 $l_{j_p} < l_{j_{p-1}}$、$r_{j_p} > r_{j_{p-1}}$ 说明 $j_p$ 的两个端点都在这个开区间之外，矛盾。所以只能 $l_{j_{p-1}} < l_{j_p}$，即 $j_{p-1} \supset j_p$。
> - 对后继 $j_{p+1}$ 同理：若 $l_{j_p} < l_{j_{p+1}}$，则 $r_{j_{p+1}} < r_{j_p}$（最大性）给出 $j_{p+1} \subset j_p$；若 $l_{j_{p+1}} < l_{j_p}$，则 $j_{p+1} \supset j_p$，弧 $j_p \to j_{p+1}$ 的见证落在 $(l_{j_p}, r_{j_p})$ 内却必须是 $j_{p+1}$ 的端点，也矛盾。所以 $j_p \supset j_{p+1}$。
>
> 于是 $j_{p-1} \supset j_p \supset j_{p+1}$，$j_{p-1}$ 覆盖了 $j_{p+1}$ 内含的一切，特别地覆盖了见证 $x_{p+1} \in S$，所以弧 $j_{p-1} \to j_{p+1}$ 存在。把它接进原环就得到一个长度 $k-1$ 的环；$k=2$ 时它直接退化为 $j_{p-1} \supset j_p \supset j_{p-1}$ 的矛盾。无论哪种都与"长度最小"矛盾，故 $D_S$ 无环。

取 $D_S$ 的任意一个拓扑序执行操作：对每个 $s \in S$，覆盖它的区间（如果存在）都排在它所属区间之后，按第一步的判定 $s$ 必然是断点。所以 $|B| \geqslant |S| = 2n - \nu$。

> 注意这一步只用到"存在性"：代码只需要算 $\nu$，不需要真的输出执行顺序，所以引理只用来说明答案刻度没有缺口。

综合第三、四步：

$$
\boxed{\ \text{答案} = 2n - \nu\ }
$$

其中 $\nu$ 是"左部点 $r_i$、右部点 $l_j$，$l_i < l_j < r_i < r_j$ 连边"这张二分图的最大匹配。

**样例验证。** 样例的区间是 $[2,3),[6,7),[1,9),[5,10),[4,8)$。交错的只有 $[1,9)$ 与 $[5,10)$（$1<5<9<10$），所以二分图只有一条边 $r_{[1,9)} - l_{[5,10)}$，$\nu = 1$，答案 $10 - 1 = 9$，与样例一致。

**实现要点。** $n \leqslant 5000$ 时最大匹配可以用匈牙利（找增广路）算法。朴素实现要枚举所有出边，而这里 $E$ 最坏可以达到 $n^2/2 \approx 1.25\times 10^7$，直接跑有超时风险；把邻接矩阵按 $64$ 位压进 `unsigned long long`，寻找"还没访问过的出边"这一步就变成 `adj[u][w] & ~visR[w]` 一次跳过一个字，用 `__builtin_ctzll` 取最低位。这样最坏复杂度 $O(n^3/64)$，实测 $n = 5000$ 的稠密数据约 $0.5$ s。

内存也要小心（题面特意警告了 16 MiB）：压位邻接矩阵是 $\frac{n}{64} \cdot n$ 个 `unsigned long long`，$n = 5000$ 时约 $3.0$ MiB，可以放心开成全局数组。

### 复杂度

设 $\nu$ 为最大匹配数。

- 建图：两层循环 $O(n^2)$。
- 匈牙利算法：每个未匹配左侧点跑一次增广路，每次找增广路的代价是 $O(n^2/64)$，共 $n$ 轮，最坏 $O(n^3/64)$；实测 $n = 5000$ 的最坏数据约 $0.5$ s。

## 总结

- **断点只在端点处。** 每个区间都覆盖自己的 $l_i$ 却不覆盖 $l_i - 1$，覆盖 $r_i - 1$ 却不覆盖 $r_i$，所以只有 $2n$ 个端点可能成为断点，问题被压缩成"选哪些端点"。
- **端点成为断点的条件统一。** "$s$ 是断点"$\iff$"某个覆盖 $s$ 的区间排在 $s$ 所属区间之后"，这让"选端点"和"排顺序"互相翻译。
- **冲突只有交错对。** 对 $l_i < l_j$ 分类讨论，只有 $l_i < l_j < r_i < r_j$ 会强制 $r_i$ 与 $l_j$ 二选一；其余两类（相离、包含）没有任何约束。
- **答案 $= 2n - $ 最大匹配。** 把 $r_i$ 放左部、$l_j$ 放右部、交错对连边，可选的断点集合正是这张二分图的独立集，"上界 = 独立集 ≤ $2n - \nu$"，而按覆盖关系建出的先后约束图无环，任一拓扑序都能达到 $2n - \nu$（König 定理的直接应用）。
- **实现要压位。** 稠密图下朴素的匈牙利太慢，用 `unsigned long long` 压位邻接矩阵 + `__builtin_ctzll` 枚举出边，先把空间压进 16 MiB，再把时间压到 $O(n^3/64)$。

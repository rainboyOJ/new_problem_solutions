### 题意

从家 `1` 出发，依次游玩 4 个互不相同的景点 `A,B,C,D`，最后回到家。每一段行程都要求最多转车 $k$ 次，也就是最多走 $k+1$ 条边。

每个景点有分数，要求最大化：

```text
score[A] + score[B] + score[C] + score[D]
```

### 思路

小数据可以直接枚举 4 个景点，再检查 5 段路是否都能在限制内到达：

@include-code(./brute.cpp, cpp)

暴力枚举是 $O(n^4)$，当 $n=2500$ 时不可接受。但它提醒我们：真正需要判断的只是两点之间能否在 $k+1$ 条边内到达。

先从每个点做一次 BFS，得到 `can_reach[x][y]`，表示 $x$ 到 $y$ 是否满足单段行程限制。

路线是：

```text
1 -> A -> B -> C -> D -> 1
```

如果我们枚举中间两个景点 `B,C`，就只剩下两边要选：

- `A` 需要满足 `1 -> A` 可达，并且 `A -> B` 可达；
- `D` 需要满足 `C -> D` 可达，并且 `D -> 1` 可达。

图是无向图，所以“能作为某个点 $x$ 左侧景点的候选”与“能作为 $x$ 右侧景点的候选”条件形式相同：候选点 $p$ 需要满足 `can_reach[1][p]` 和 `can_reach[p][x]`。

于是可以对每个点 $x$ 预处理分数最高的前 4 个候选景点。为什么保留 4 个就够？枚举 `B,C` 时，一个候选最多会因为等于 `A/B/C/D` 中已有的点而不能用；我们只需要避开常数个点，保留前 4 个足够找到最优可用候选。

最后枚举所有有 `can_reach[B][C]` 的 `B,C`，在 `best[B]` 中选 `A`，在 `best[C]` 中选 `D`，检查四个景点互不相同并更新答案。

### 复杂度

从每个点 BFS 一次，复杂度为 $O(n(n+m))$。预处理候选和枚举 `B,C` 都是 $O(n^2)$ 级别，只带一个很小的常数。

空间复杂度为 $O(n^2 + n + m)$，主要来自可达矩阵。

### 总结

本题的关键拆法是：不要直接枚举 `A,B,C,D` 四个景点，而是先固定中间连接 `B -> C`，再从两侧各取一个高分候选。

BFS 负责把“最多转车 $k$ 次”变成布尔可达矩阵；候选数组负责把两侧选择从 $O(n)$ 降到常数。

## 形式化题目

设字符集为大写英文字母集合 $\Sigma = \{\texttt{A}, \texttt{B}, \dots, \texttt{Z}\}$，且 $|\Sigma| = 26$。

定义一个置换映射 $f: \Sigma \to \Sigma$（即满足单射与满射的双射变换），使得每个原文字符 $p \in \Sigma$ 唯一对应密文字符 $c = f(p)$，其逆映射记为 $f^{-1}(c) = p$。

现给定三个由大写字母构成的非空字符串：
1. 密文参考串 $C$；
2. 明文参考串 $P$，且保证 $|C| = |P|$；
3. 待解密字符串 $Q$。

对于任意 $i \in [0, |C| - 1]$，存在样本对应关系 $f(P[i]) = C[i]$（或等价地 $f^{-1}(C[i]) = P[i]$）。

要求判定是否存在一个合法的完整双射置换 $f$：
- **自洽单射约束**：不能存在一对样本使得同一个原文字符映射到不同的密文字符（$\exists i, j$ 满足 $P[i] = P[j]$ 但 $C[i] \neq C[j]$），也不能存在不同的原文字符映射到相同的密文字符（$\exists i, j$ 满足 $P[i] \neq P[j]$ 但 $C[i] = C[j]$）；
- **满射完备性约束**：集合 $\Sigma$ 中所有 $26$ 个字母的映射关系必须都在样本串 $P$ 中出现过（即定义域与值域均覆盖满 $26$ 个字母）。

若上述任一约束被违反，输出 `Failed`；否则利用导出的唯一逆映射 $f^{-1}$，输出将 $Q$ 逐字符解密还原后的明文字符串。

## 正解

::: info 核心思路
本题核心是单表代换密码（Monoalphabetic Substitution Cipher）的唯一双射重构。通过建立“密文 $\to$ 明文”与“明文 $\to$ 密文”两个双向数组，逐位扫描参考串，排查“同密异明”和“同明异密”两类冲突；扫描完成后统计是否恰好覆盖全部 $26$ 个大写字母。若校验通过，则对目标密文执行 $O(1)$ 查表解密。
:::

### 思路

#### 1. 单表代换的双射本质

根据题目对加密规则的规定：
1. 每个字母规定了唯一的密字；
2. 不同的字母对应不同的密字；
3. 原信息与加密信息的字符集均为 $\texttt{A} \sim \texttt{Z}$。

在离散数学上，这构成有限集合 $\Sigma$ 到自身的一个**双射（Bijective Function / 置换）**。双射要求：
- **单射性（Injective）**：若 $p_1 \neq p_2$，则 $f(p_1) \neq f(p_2)$；同时逆向也必须满足，即若 $c_1 \neq c_2$，则 $f^{-1}(c_1) \neq f^{-1}(c_2)$。
- **满射性（Surjective）**：值域包含整个目标字符集 $\Sigma$。因为定义域与值域大小均为有限的 $26$，单射与满射互为充要条件。

#### 2. 双向单射一致性校验

为了在读取样本对 $(C[i], P[i])$ 时快速判断是否存在矛盾，我们可以开辟两个长度为 $26$ 的映射数组：
- `c2p[26]`：记录密文字符到明文字符的映射关系，初始为空字符 `0`；
- `p2c[26]`：记录明文字符到密文字符的映射关系，初始为空字符 `0`。

对于参考对中的每一对字符 $c = C[i]$ 与 $p = P[i]$：
1. **密文到明文冲突**：检查 `c2p[c - 'A']`。若之前已记录过映射且 `c2p[c - 'A'] != p`，说明同一个密文字符在此前被映射成了不同的明文，与单射性矛盾；
2. **明文到密文冲突**：检查 `p2c[p - 'A']`。若之前已记录过映射且 `p2c[p - 'A'] != c`，说明同一个明文字符被加密成了不同的密文字符，同样违背规则；
3. 若均未发生冲突，则记录或维持：
   $$ \text{c2p}[c - \text{'A'}] = p, \quad \text{p2c}[p - \text{'A'}] = c $$

若整个遍历过程中触发了任一冲突，直接判定失败输出 `Failed` 并终止。

#### 3. 满射完备性判定

题目规则 2 指出：“所有信息扫描完毕，但发现存在某个（或某些）字母在原信息中没有出现”。
这表明仅无矛盾还不够，**必须有足够的信息唯一确定全部 26 个字母的密码本**。

在双向单射校验无误后，只需统计数组 `c2p` 中成功建立映射的元素个数：
- 若有效字母数 $< 26$（例如样例 2 中字母 $\texttt{Z}$ 未出现），说明密码本残缺，无法保证对待解密字符串中的所有字符均能正确还原，判定为 `Failed`；
- 只有当计数恰好为 $26$ 时，才说明单表置换完全确定。

#### 4. 查表线性翻译

当完备性校验通过后，解密字典 `c2p` 已是完整的置换映射。
对于待解密的字符串 $Q$，遍历每个字符 $ch \in Q$，直接输出对应明文字符 `c2p[ch - 'A']` 拼接为最终结果。

### 复杂度

- **时间复杂度**：
  - 扫描参考串构建双向映射表耗时 $O(|C|)$，其中 $|C| \le 100$；
  - 检查 26 个字母的完备性仅需遍历常数大小数组，耗时 $O(|\Sigma|) = 26$；
  - 解密待翻译串耗时 $O(|Q|)$，其中 $|Q| \le 100$；
  - 总体时间复杂度为 $O(|C| + |Q| + |\Sigma|)$，在几十次到数百次操作内完成，耗时在 $1\text{ ms}$ 以内。
- **空间复杂度**：
  - 仅需两个大小为 $26$ 的字符数组记录置换映射关系，空间复杂度为 $O(|\Sigma|) = O(1)$，内存消耗微乎其微。

## 总结

字符串映射校验类题目的核心是**数学约束的完整落实**：
1. **双向互逆判定**：单向记录只能检测多对一，必须双向记录方能严密拦截一对多与多对一的映射歧义；
2. **全集完备性校验**：通过统计独立映射基数是否满秩（等于字符集大小），保证解密函数的确定性。

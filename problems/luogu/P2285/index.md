## 形式化题目

在一个 $n \times n$ 的网格上按时间顺序出现 $m$ 个事件, 第 $i$ 个事件是 $(t_i, x_i, y_i)$,
表示第 $t_i$ 个时刻格子 $(x_i, y_i)$ 处出现一只鼹鼠. $t$ 不降, 同一时刻同一格子至多一只.

一个机器人在每个时刻可以停在原地或移动到相邻格子. 初始位置在时刻 1 之前可以任意选定.
若某时刻机器人所在的格子正好有鼹鼠, 那只鼹鼠就被打死.

求能打死的鼹鼠数的最大值. $m \leqslant 10^4$.

### 样例

样例是 `2 2` 的网格, 两个事件: $(1, 1, 1)$ 和 $(2, 2, 2)$.

从 $(1,1)$ 到 $(2,2)$ 的曼哈顿距离是 $|2-1| + |2-1| = 2$, 而时间差只有 $2 - 1 = 1$.
所以赶不上, 只能打死其中一只. 答案为 $1$.

## 暴力解法

### 思路

先把"某个方案能不能全部打死"这件事写对. 一个方案就是选定的一个下标子集,
把它按时间顺序列出来后, 检查相邻两只是否赶得上.

于是最直接的做法是枚举所有子集: 用 01 序列递归, 第 $i$ 层决定第 $i$ 只打还是不打,
到叶子($dep = m + 1$)时按顺序检查一遍相邻可达性, 合法就更新答案.

它完全按定义结算, 不依赖任何还没证明的结论, 因此可以作为小数据对拍的基准.

### 复杂度

枚举 $2^m$ 个子集, 每个子集检查一次 $O(m)$. 时间 $O(m 2^m)$, 空间 $O(m)$ 递归深度.
只有 $m \leqslant 20$ 量级可用, 而题目要求 $m \leqslant 10^4$.

### 瓶颈

瓶颈是**把"打不打的顺序"当成独立选择来枚举**. 但合法性只约束相邻两只之间的可达性:
中间跳过了哪些鼹鼠完全不影响判定.

也就是说, 一次合法的击杀过程本质上是一条**链**. 既然是链, 就可以用
"以某一只结尾的最优链有多长"这个状态把它压缩掉, 不必枚举整条链.

## 正解

### 关键观察

先回答"两只鼹鼠之间能不能赶上". 设 $t_j \leqslant t_i$, 则

$$\text{能赶上} \iff |x_i - x_j| + |y_i - y_j| \leqslant t_i - t_j$$

- 必要性: 每个时刻最多移动一格, $t_i - t_j$ 个时刻最多走 $t_i - t_j$ 步, 步数不会少于曼哈顿距离.
- 充分性: 网格里没有阻挡, 沿最短折线路径一步步走过去, 恰好用曼哈顿距离个时刻,
 剩下的时间原地等待即可.

下面的图表示这个条件: 以出发格为中心、曼哈顿半径 $t_i - t_j$ 的菱形, 就是时间够用的所有格子.

```text
 t_j 时刻出发
 ●
 ◇ │ ◇
 ◇ │ ◇
 ◇ │ ◇
 ────────────●──────────── ← 落在菱形内即可达
 ◇ │ ◇
 ◇ │ ◇
 ◇ │ ◇
 ●
```

菱形内部(含边界)的点满足曼哈顿距离 $\leqslant$ 时间差. 注意是 $\leqslant$ 而不是 $<$:
刚好用完所有时间也来得及.

于是整个问题变成在事件序列上求最长链, 其中 $j \to i$ 有边当且仅当 $j < i$ 且上述条件成立.
因为 $t$ 不降, $j < i$ 时一定有 $t_j \leqslant t_i$, 不会形成环, 这是一个 DAG.

### 思路

令 $dp_i$ 表示以第 $i$ 只鼹鼠作为最后一只时, 最多能打死的只数. 转移枚举前驱:

$$dp_i = 1 + \max\big\{ dp_j : j < i,\ |x_i - x_j| + |y_i - y_j| \leqslant t_i - t_j \big\}$$

三个地方需要确认:

- **为什么按输入顺序扫就是拓扑序**. 题目已经保证 $t$ 不降, 所以 $j < i$ 蕴含 $t_j \leqslant t_i$.
 边只从时间早的指向时间不早的, 扫到 $i$ 时它所有前驱都已算完.
- **为什么初值是 1**. 游戏开始时初始位置自由, 机器人可以直接站在任意格子,
 所以任何一只都可以作为链的开头, 不需要虚构一个起点或额外加边.
- **为什么不用考虑中间没打的鼹鼠**. 一条链只约束相邻两项, 中间的时间与位置都是自由的;
 若某只没打的鼹鼠恰好顺路, 那它本来就该被加进链里, 那是由更长的链来表达的.

答案取 $\max_i dp_i$.

正确性可以由两条夹逼说明:

- 若 $dp_i = dp_j + 1$ 且 $j$ 赶得到 $i$, 由归纳存在以 $j$ 结尾的可行方案, 接上 $i$ 即得长度 $dp_i$ 的可行方案.
- 任意一条可行方案 $i_1, \dots, i_k$, 对 $s$ 归纳可证 $dp_{i_s} \geqslant s$: $s = 1$ 时初值保证;
 $s > 1$ 时 $i_{s-1}$ 与 $i_s$ 相邻且 $i_{s-1} < i_s$, 转移时枚举到它给出 $dp_{i_s} \geqslant dp_{i_{s-1}} + 1 \geqslant s$.
- 于是 $k \leqslant dp_{i_k} \leqslant \max_i dp_i$, 两个方向合起来即得最优性.

### 复杂度

- 时间 $O(m^2)$: 内层枚举前驱, 每次常数次整数运算. $m = 10^4$ 时约 $5 \times 10^7$ 次比较.
- 空间 $O(m)$: 存事件和 $dp$, 不需要 $O(n^2)$ 的网格.

## 总结

本题有两个转折点.

第一是**把几何条件算清楚**: 从一只到另一只能不能赶上, 只取决于曼哈顿距离与时间差的大小关系,
与中间发生过什么无关.

第二是**认出这是 DAG 最长路**. 既然 $t$ 不降, 按输入顺序扫就是拓扑序,
于是"选哪些鼹鼠"这种看起来是指数级的组合问题, 变成了 $O(m^2)$ 的线性 DP.

同样的思路可以迁移到很多"按时间推进、需要判断两点之间来不来得及"的问题,
例如有截止时间的任务链、按时间窗排序的区间选取.

## 形式化题目

给定一棵 $n$ 个节点的树，每条边初始覆盖次数为 $0$。按顺序处理 $m$ 次操作：

1. `P u v`：把 $u$ 到 $v$ 简单路径上的每条边覆盖次数加一；
2. `Q u v`：$u$、$v$ 是一条边的两个端点，回答这条边当前的覆盖次数。

要求在线回答所有查询（更新与询问交错出现）。

## 思路

先看一个可以直接验证想法的朴素解：

@include-code(./brute.cpp, cpp)

`brute.cpp` 把每条边 $(x, parent[x])$ 的值挂在深端点 $x$ 上：`P` 从 $u$、$v$ 分别沿父链爬到 `lca`，逐边 `+1`；`Q` 直接输出深端点的值。单次操作 $O(\text{路径长})$，最坏 $O(n)$，$10^5$ 数据不可行。

关键观察有三步：

1. **边权挂到子节点**：每条边 $(x, parent[x])$ 用深端点 $x$ 代表，回答 `Q u v` 就是查 $w(deep(u,v))$。
2. **路径拆成三条根路径**：$u$ 到 $v$ 的边集等于"根路径 $u$ + 根路径 $v$ − 2 × 根路径 $lca(u,v)$"（根到 LCA 的边出现两次，要减掉两次）。
3. **根路径加一 = 单点差分**：给"根到 $x$ 的路径上每条边加一"，只需要在差分数组上 `c[x] += 1`。因为边 $(t, parent[t])$ 在根路径 $x$ 上当且仅当 $x \in subtree(t)$，所以"边值 = 子树的差分和"。

把三点合起来，`P u v` 退化成三个单点修改：

$$c[u] += 1,\quad c[v] += 1,\quad c[lca(u,v)] -= 2$$

下面的表格演示样例中每次 `P` 之后差分数组 $c[]$ 的变化（树以 1 为根：1-4、2-4、3-4，深度 4 比 1 深），以及 `Q` 如何用子树和回答：

| 操作 | $c[1]$ | $c[2]$ | $c[3]$ | $c[4]$ | 输出 |
| --- | --- | --- | --- | --- | --- |
| 初始 | 0 | 0 | 0 | 0 |  |
| P 2 3 | 0 | 1 | 1 | -2 |  |
| P 1 3 | -1 | 1 | 2 | -2 |  |
| Q 3 4 | | | | | 2（= $c[3]$） |
| P 1 4 | -2 | 1 | 2 | -1 |  |
| Q 2 4 | | | | | 1（= $c[2]$） |
| Q 1 4 | | | | | 2（= $c[2]+c[3]+c[4]$） |

观察第二行：`P 2 3` 的 LCA 是 4，所以 $c[4]$ 变成 $-2$。`Q 3 4` 回答边 $(3,4)$，就是子树 $\{3\}$ 的差分和 $c[3] = 2$；`Q 1 4` 回答边 $(1,4)$，即子树 $\{2,3,4\}$ 的和 $1+2-1 = 2$。这与样例输出 $2,1,2$ 完全一致。

于是最终做法是：倍增 LCA 预处理 + DFS 序 + Fenwick。`P` 只做三次单点加；`Q` 的"子树和"在 DFS 序上就是区间和 $\text{sum}(dfn[t], dfn[t]+sz[t]-1)$，由树状数组回答。

### 边差分与点差分

同样是"路径加一"，点差分和边差分的系数不同：

| | 点差分（路径上点的覆盖次数） | 边差分（路径上边的覆盖次数） |
| --- | --- | --- |
| 单次 `P u v` | $c[u]{+}{+},\ c[v]{+}{+},\ c[lca]{-}{-},\ c[parent(lca)]{-}{-}$ | $c[u]{+}{+},\ c[v]{+}{+},\ c[lca] -= 2$ |
| 恢复方式 | 点 $t$ 的值 = $subtree(t)$ 的差分和 | 边 $(t, parent[t])$ 的值 = $subtree(t)$ 的差分和 |

原因：根路径 $u$ 与根路径 $v$ 的点集里 LCA 出现两次，路径点集要保留 LCA 本身，所以再减 LCA 一次、减 $parent(lca)$ 一次，LCA 净贡献 $2-1=1$ 被保留；而路径边集**不包含**边 $(lca, parent(lca))$，所以 LCA 的两次贡献要全部减掉，`c[lca] -= 2`。

### 数学视角：为什么三个单点修改就够了

- **查询函数是线性的**：$S(t) = \sum_{y \in subtree(t)} c[y]$ 关于 $c$ 是加法线性算子，所有 $S(t)$ 构成交换幺半群。
- **单点修改是"祖先前缀"自同态**：`c[x] += v` 使 $S(t)$ 增加 $v$ 当且仅当 $t$ 是 $x$ 的祖先，即恰好是"根路径 $x$ 上的每条边加 $v$"。因此"根路径加一"被压缩成一次单点修改。
- **路径是三条根路径的线性组合**：$path(u,v) = rootpath(u) + rootpath(v) - 2 \cdot rootpath(lca)$，线性组合可以直接逐点相加，所以一次 `P` 只要三次修改。

## 复杂度

- 预处理：BFS 与 DFS 序 $O(n)$，倍增表 $O(n \log n)$。
- 单次操作：`P` 一次 LCA + 三次单点加，`Q` 两次前缀和，都是 $O(\log n)$。
- 总复杂度 $O((n+m) \log n)$，空间 $O(n \log n)$（倍增表）。

## 总结

"树上路径加一、单边点查"的标准套路是**树上边差分**：把边权映射到子节点，把路径拆成三条根路径，于是路径操作变成三个点的差分，边查询变成子树和；再用 DFS 序把子树变成区间、用 Fenwick 在线维护。与"点差分"只在 LCA 处差一个系数（$-2$ vs $-1$ 和 $parent(lca)$）。rbook 的《[倍增求 LCA](https://rbook2.roj.ac.cn/tree-algo/jump-lca/index.html)》讲解了本解使用的倍增模板（`lca-binary-lifting`），Fenwick 部分来自《[树状数组：单点修改与区间查询](https://rbook2.roj.ac.cn/data_structure/bit/index.html)》。仓库里另一种参考实现（`main.py`）用重链剖分拆路径，每次操作 $O(\log^2 n)$，也可行但常数和实现都更重。

# P17232 [Algo Beat Contest 017 A] 串哈希
## 题目背景

又是这里。

如何才能离开呢？

## 题目描述

学员偶像小 K 陷入了 「**自己肯定感危机**」！作为富有经验的**全民制作人**，你决定对应援词进行审查，来应对危机的到来。

具体地，给定一个由 $n$ 个应援词组成的序列。每个应援词均为一个仅由数字和小写英文字母组成的非空字符串。

小 K 具有一个初始气压值 $s$。应援词会按照输入顺序依次发送给小 K。对于每个应援词，依次考虑以下规则并对当前气压值进行影响：

1. 如果应援词包含字符串 `shuki`，则使气压值增加 $1$；
2. 如果应援词包含字符串 `daishuki`，则忽略规则 1，并使气压值增加 $2$；
3. 如果应援词包含字符串 `kirai`，则忽略规则 1、2：若当前气压值非负，将其设为 $0$；否则气压值不变；
4. 如果以上规则均不满足，则使气压值减少 $1$。

这里，“包含”是指对应字符串作为一个连续子串出现。

在所有应援词发送完毕后，设末态气压值为 $t$，你需要：

- 若 $t>0$，输出 $t-s$；
- 否则，输出字符串 `shuki`。


## 输入格式

第一行输入两个整数 $n,s$，分别表示应援词数量和初始气压值。

接下来 $n$ 行，每行输入一个应援词。

## 输出格式

输出一行，表示答案。

## 输入输出样例 #1

### 输入 #1

```
5 1
shuki

kirai
abc

```

### 输出 #1

```
0
```

```

## 输入输出样例 #3

### 输入 #3

```

### 输出 #3

```

```

## 说明/提示

#### 【数据范围与约定】

对于所有测试数据，保证：

- $1\le n\le 100$
- $-10^9\le s\le 10^9$
- 每个应援词长度不超过 $100$
- 每个应援词仅由数字和小写英文字母组成

本题**开启子任务捆绑**。

| subtask | 分值 | 特殊限制 |
| --- | ---: | --- |
| 1 | 20 | $n=1$ |
| 2 | 20 | 所有应援词均不包含字符串 `shuki` |
| 3 | 20 | 所有应援词均不包含字符串 `kirai` |
| 4 | 40 | 无特殊限制 |

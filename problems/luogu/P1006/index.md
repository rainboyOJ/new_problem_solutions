## 形式化题目

给定一个大小为 $m \times n$ 的二维网格，每个单元格 $(x, y)$ 拥有非负点权 $a_{x, y}$。其中左上角起点 $(1, 1)$ 与右下角终点 $(m, n)$ 的点权固定为 $0$。

求在网格中选取两条路径 $P_1, P_2$，满足：

1. **路径方向与端点**：两条路径均由起点 $(1, 1)$ 出发到达终点 $(m, n)$，每一步仅能向下移动 $(x+1, y)$ 或向右移动 $(x, y+1)$；
2. **点不相交约束**：除起点 $(1, 1)$ 与终点 $(m, n)$ 外，两条路径途经的点集互不相交，即 $P_1 \cap P_2 = \{(1, 1), (m, n)\}$；
3. **优化目标**：最大化两条路径覆盖的所有单元格点权之和，即 $\max \sum_{u \in P_1 \cup P_2} a_u$。

> 原题中的“小渊给小轩传递（从 $(1,1)$ 到 $(m,n)$）且小轩回复（从 $(m,n)$ 到 $(1,1)$）”，通过将回程逆向视为另一条自 $(1,1)$ 到 $(m,n)$ 的路径，即等价为上述两条独立且不相交的同向路径。

## 正解

::: info 核心思路
将回程逆向转化为两条同向路径后，利用两人每步只能下移或右移的性质，两人走过的步数与坐标和 $s = x + y$ 严格绑定。以坐标和 $s$ 为阶段驱动双线同步推进，状态只需记录当前步数及两人各自的行号 $i$ 与 $j$。通过强制 $i < j$ 天然规避路径重叠，在 $O((m+n)mn)$ 时间内完成状态转移。
:::

### 思路

#### 1. 双向往返到双线同向的等价规约

题目要求一条从 $(1, 1)$ 到 $(m, n)$ 的路径（只许向下或向右），以及一条从 $(m, n)$ 到 $(1, 1)$ 的回路（只许向上或向左），中途经过的点不可重复。

将从 $(m, n)$ 向上或向左走的路径逆过来看，其经过的点序列完全等价于另一条从 $(1, 1)$ 出发、只能向下或向右走到 $(m, n)$ 的路径。因此，原问题精确等价于：**在网格中同时找出两条从 $(1, 1)$ 走向 $(m, n)$ 的路径，除起点与终点外，两路径不经过相同的格子，使得两条路径上的点权之和最大**。

#### 2. 同步步数驱动与状态降维

若分别记录两人的完整坐标 $(x_1, y_1)$ 与 $(x_2, y_2)$，状态维度为四维，状态量达到 $O(m^2 n^2)$。

注意两人的移动性质：无论是下移还是右移，每前进一步，坐标分量之和 $(x + y)$ 恰好增加 $1$。从 $(1, 1)$ 出发经过 $k$ 步后，所处格子的坐标必然满足：
$$ (x - 1) + (y - 1) = k \implies x + y = k + 2 $$

设 $s = x + y$ 为当前两人的“坐标和”。只要让两人保持同步前进（即步数相同、坐标和相同），则当第一条路径的行号为 $i$ 时，其列号唯一确定为 $y_1 = s - i$；同理第二条路径行号为 $j$ 时，列号唯一确定为 $y_2 = s - j$。

因此，四维状态 $(x_1, y_1, x_2, y_2)$ 可以降维为三维状态 $(s, i, j)$。

#### 3. 避免路径相交与对称性破缺

两条路径在途中不能经过同一格子。因为两人步数同步，若两路径在某一时刻相交，必然是在同一时刻到达了相同的坐标，即 $i = j$（从而列号也相同）。

又因为两条路径本身是对称的（调换第一条与第二条路径的顺序不影响总收益），我们可以强制规定在整个行走过程中（除起点 $s=2$ 与终点 $s=m+n$ 外），第一条路径的行号始终严格小于第二条路径的行号：
$$ i < j $$
这不仅自然保证了 $i \neq j$（两路径不相交），还将搜索状态空间减半，避免了重复计算与对称冗余。

#### 4. 状态定义与转移方程

定义 $dp[s][i][j]$ 表示两人均走了 $s - 2$ 步（坐标和均为 $s$），第一条路径到达 $(i, s - i)$，第二条路径到达 $(j, s - j)$ 时获得的最大点权和。

到达当前状态 $(i, j)$，前一步两人各自有两种移动方式（由上方走来或由左方走来），共计 $2 \times 2 = 4$ 种前驱组合：
1. 两人均由左侧来：前一步位置为 $(i, j)$；
2. 第一人由上方来，第二人由左侧来：前一步位置为 $(i - 1, j)$；
3. 第一人由左侧来，第二人由上方来：前一步位置为 $(i, j - 1)$；
4. 两人均由上方来：前一步位置为 $(i - 1, j - 1)$。

状态转移方程为：
$$
dp[s][i][j] = \max \begin{cases}
dp[s - 1][i][j] \\
dp[s - 1][i - 1][j] \\
dp[s - 1][i][j - 1] \\
dp[s - 1][i - 1][j - 1]
\end{cases} + a[i][s - i] + a[j][s - j]
$$

#### 5. 边界与最终答案

- **出发边界**：离开起点后的第一步为 $s = 3$，此时两人分别位于 $(1, 2)$ 与 $(2, 1)$。由于 $i < j$，必有 $i = 1, j = 2$。初始状态 $dp[3][1][2] = a[1][2] + a[2][1]$。
- **目标状态**：终点 $(m, n)$ 的坐标和为 $m + n$。在到达终点前一步，两人的坐标和为 $s = m + n - 1$，两人分别占据 $(m - 1, n)$ 与 $(m, n - 1)$。在 $i < j$ 的约定下，第一人行号为 $m - 1$，第二人行号为 $m$。终点 $(m, n)$ 点权为 $0$，因此最终答案即为 $dp[m + n - 1][m - 1][m]$。

### 复杂度

- **时间复杂度**：外层步数循环 $s$ 取值范围为 $[3, m + n]$，共 $O(m + n)$ 轮；内层两重循环枚举合法行号 $1 \le i < j \le m$，状态总数为 $O((m + n)m^2)$。每次状态转移仅涉及 4 种固定方向的常数级比较，因此总时间复杂度为 $O((m + n)m^2)$。在 $m, n \le 50$ 的约束下，计算次数约为 $100 \times 1250 \approx 1.25 \times 10^5$ 次，运行时间在毫秒以内。
- **空间复杂度**：状态数组规模为 $(m + n) \times m \times m$，占用内存约为 $105 \times 55 \times 55 \times 4\text{ B} \approx 1.25\text{ MB}$，完全在内存限制范围内（若有需要，步数维度还可采用滚动数组进一步优化至 $O(m^2)$）。

## 总结

解决网格多路径不相交权值和极值问题的关键在于：
1. **时间轴同步**：利用网格图步长与坐标和的严格对应关系，将空间维度统一映射到时间维度，规避高维状态组合；
2. **有序性破局相交**：利用对称性对两条路径引入大小偏序约束 $i < j$，不仅自然剔除了相交状态，还避免了冗余分支。

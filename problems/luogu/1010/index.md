### 题意

给定一个正整数 $n$，要求把它表示成只含 `2`、`2(0)`、括号和加号的形式。

题目的规则可以理解为：

- $2^0$ 写成 `2(0)`；
- $2^1$ 写成 `2`；
- $2^k\ (k > 1)$ 写成 `2(k 的 0,2 表示)`。

例如 $137 = 2^7 + 2^3 + 2^0$，其中指数 $7$ 和 $3$ 也要继续按同样规则表示。

### 思路

先看一份可以用来验证输出格式的朴素写法：

@include-code(./brute.cpp, cpp)

这份朴素写法每次寻找不超过当前数的最大 $2$ 的幂，然后把它减掉，逐步构造表达式。它和正式代码使用不同的拆分方式，适合用来对拍检查格式细节。

正式代码使用你给出的核心思路：把 $n$ 看成二进制，从高位到低位扫描每一个为 $1$ 的位置。

如果第 $i$ 位是 $1$，说明答案中有一项 $2^i$：

| 指数 $i$ | 应输出的形式 | 原因 |
| --- | --- | --- |
| $0$ | `2(0)` | 这是题目对 $2^0$ 的约定 |
| $1$ | `2` | 题目约定 $2^1$ 直接写成 `2` |
| $>1$ | `2(dfs(i))` | 指数 $i$ 也要继续拆成 0,2 表示 |

以样例 $1315$ 为例，这张表展示最外层拆分：

| 二进制项 | 指数的递归表示 | 最终输出片段 |
| --- | --- | --- |
| $2^{10}$ | $10 = 2^3 + 2^1$，即 `2(2+2(0))+2` | `2(2(2+2(0))+2)` |
| $2^8$ | $8 = 2^3$，即 `2(2+2(0))` | `2(2(2+2(0)))` |
| $2^5$ | $5 = 2^2 + 2^0$，即 `2(2)+2(0)` | `2(2(2)+2(0))` |
| $2^1$ | 不需要递归 | `2` |
| $2^0$ | 不需要递归 | `2(0)` |

把这些片段从高位到低位用 `+` 连接，就得到样例输出。

实现时还有一个细节：最后一项后面不能输出 `+`。代码先找到最低的一个 `1` 位 `last`，扫描到 `i == last` 时就不再输出加号。

### 复杂度

每次递归只扫描固定的二进制位，$n \le 20000$ 时位数很少。

- 时间复杂度：$O(\log n \cdot \log\log n)$，在本题范围内可以看作很小的常数。
- 空间复杂度：$O(\log n)$，来自递归调用栈。

### 总结

本题的关键不是计算大小，而是把递归定义转成稳定的输出过程。先用二进制把数拆成若干个 $2^i$，再对大于 $1$ 的指数继续递归分解。写代码时重点处理 `i = 0`、`i = 1` 和最后一个加号。

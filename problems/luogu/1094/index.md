### 题意

将 n 件纪念品分组，每组最多两件，总价格不能超过 w。求最少组数。

### 思路

$n \leqslant 3\times10^4$，直接枚举所有分组方案不可行。先看一个只适合小数据的暴力，帮助理解问题：

@include-code(./brute.cpp, cpp)

暴力每次找到第一个未分组的纪念品，尝试两种分组方式：单独一组，或与后面某个未分组的配成一组（价格和 ≤ w）。这种枚举构造了所有合法分组方案，从中取最小，复杂度指数级。

#### 贪心策略

将纪念品价格从小到大排序。用两个指针 `l`（指向最小）和 `r`（指向最大）：

- 如果 `p[l] + p[r] ≤ w`：最小的和最大的配一组，`l++`, `r--`
- 否则：最大的自己一组，`r--`
- 每次消耗一个分组

**正确性直觉**：排序后，每次优先考虑最轻的能不能和当前最重的配对。如果最重的和最轻的都无法配对，那最重的跟任何人配对都会超 w，只能自成一组。

具体证明：设当前剩余纪念品中最轻为 a、最重为 b。假设存在最优方案中 a 和 b 不在一组。如果 a 与某件 c（c ≤ b）配对且价格和 ≤ w，那么用 b 替换 c 价格和不会变小（b ≥ c），方案依然合法且组数不变。反之若 b 无法与任何人配对（包括 a），则它必须自成一组，贪心选择不影响最优性。

### 复杂度

- 时间复杂度：$O(n \log n)$，瓶颈在排序
- 空间复杂度：$O(n)$

### 总结

这道题是贪心的经典入门题。关键思维是：当问题需要在"配对数"上做选择时，**排序后从两端向中间收敛**往往能得到最优解。这种"最轻配最重"的贪心思路在后续的"独木舟"等题目中还会反复出现。

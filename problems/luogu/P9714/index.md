## 形式化题目

给定长度为 $n$ 的数列 $t$ 和目标数列 $b$，另有 $a$ 初始全为 $0$。允许两种操作（可任意次、任意顺序）：

- 操作一：$t_i \leftarrow t_i + t_{n+1-i}$，对每个 $i$ 同时进行；
- 操作二：$a_i \leftarrow a_i + t_i$。

判断是否存在操作序列使 $a = b$。多组询问，只回答 Yes 或 No。

注意约束 $1 \leqslant \sum n \leqslant 2\times 10^3$、$1 \leqslant t_i, b_i \leqslant 2\times 10^3$：$\sum n$ 很小，但值域也不大，所以甚至可以接受 $O(n \log b)$ 之类的做法；真正需要的是把"操作序列"这种看似无穷的可能空间压缩成有限个方程。

## 正解

### 思路

直接去想"先做几次操作一、再做几次操作二"是行不通的：操作可以任意交错，序列有无穷多条。我们的目标是把这无穷多条序列，压成有限个整数解。

**第一步：两种操作互不干扰。**

- 操作一只改写 $t$，完全不动 $a$；
- 操作二只改写 $a$，完全不动 $t$。

所以操作序列里，只有"在 $t$ 长成什么样的时候加了几次"才是重要的。设 $t$ 的初值为 $u$，记 $T^0 = u$，第 $k$ 次折叠之后的值是 $T^k$。再设 $x_k$ 表示"在 $t$ 的值恰好是 $T^k$ 时，执行了多少次操作二"，那么

$$b_i = x_0 u_i + x_1 T^1_i + x_2 T^2_i + \cdots + x_m T^m_i$$

一遍操作序列唯一对应一组非负整数 $x_0, x_1, \dots, x_m$，反过来给定这组数也一定构造得出，所以这是在**两种描述之间建立了双射**。序列的无穷性被这组 $(x_k)$ 吸收掉了。

**第二步：算出每个 $T^k$ 到底长什么样。**

令 $m(i) = n+1-i$，并记

$$v_i = u_i + u_{m(i)}$$

也就是 $u$ 与自己的倒序逐项相加，$v = T^1$。关键观察是：

> **一次折叠之后，$t$ 就变成关于中心对称的向量了。**

因为 $v_{m(i)} = u_{m(i)} + u_{m(m(i))} = u_{m(i)} + u_i = v_i$，所以 $v$ 一定满足 $v_i = v_{m(i)}$。

那么对 $k \geqslant 1$，再折叠一次时：

$$T^2_i = T^1_i + T^1_{m(i)} = v_i + v_{m(i)} = 2v_i$$

同理 $T^3_i = T^2_i + T^2_{m(i)} = 2v_i + 2v_{m(i)} = 4v_i$，依此类推。由于**对称性一旦成立就永远保持**（$v$ 对称 $\Rightarrow$ $2v$ 对称 $\Rightarrow$ $4v$ 对称 $\Rightarrow \cdots$），于是

$$T^k_i = 2^{k-1} v_i \qquad (k \geqslant 1)$$

看似要无限枚举的折叠过程，其实只有第一步是"新"的，后面全是 $v$ 的倍数。

**第三步：合并成一个方程。**

把上式代回 $b$：

$$b_i = x_0 u_i + \sum_{k\geqslant 1} x_k \cdot 2^{k-1} v_i = x_0 u_i + H\, v_i, \qquad H = \sum_{k \geqslant 1} x_k\, 2^{k-1}$$

现在看 $H$ 能取哪些值。因为 $x_k$ 可以取任意非负整数，把 $H$ 写成二进制、令 $x_k$ 取第 $k-1$ 个二进制位（$x_1$ 是 $2^0$ 位、$x_2$ 是 $2^1$ 位、……），就能凑出任意非负整数。

> **所以 $H$ 恰好可以取遍全体非负整数，不多也不少。**

于是整个问题等价于一个非常干净的说法：

> 是否存在**非负整数** $x_0, H$，使得对一切 $i$ 都有 $b_i = x_0 u_i + H v_i$？

只剩下两个未知量，解方程就够了。

**第四步：解出 $x_0$ 和 $H$。**

两个未知量需要两条方程。把 $i$ 与它的镜像 $m(i)$ 两条等式相减：

$$b_i - b_{m(i)} = x_0\bigl(u_i - u_{m(i)}\bigr) + H\underbrace{\bigl(v_i - v_{m(i)}\bigr)}_{=\,0} = x_0\bigl(u_i - u_{m(i)}\bigr)$$

因为 $v$ 对称，$H$ 被自动消掉了！这正是一次折叠带来的好处。于是分两种情况。

**情形 A：存在 $i$ 使 $u_i \neq u_{m(i)}$。** 取这样一个 $i$（若 $n$ 为奇数，中间那个位置恒有 $u_i=u_{m(i)}$，所以只能从两侧找）。分母非零，$x_0$ 被唯一确定：

$$x_0 = \frac{b_i - b_{m(i)}}{u_i - u_{m(i)}}$$

要求它是**非负整数**（$b_i - b_{m(i)}$ 必须能被整除，且商 $\geqslant 0$）。再把 $i=1$ 代回原式解出 $H$：

$$H = \frac{b_1 - x_0 u_1}{v_1}$$

同样要求非负整数。两个未知量都被钉死后，$O(n)$ 把所有位置验一遍即可。

**情形 B：$u$ 本身完全对称**，即所有 $u_i = u_{m(i)}$。此时 $v_i = 2u_i$，方程退化为

$$b_i = u_i(x_0 + 2H)$$

记 $K = x_0 + 2H$。由于 $x_0$ 可以是任意非负整数，$K$ 就能取遍全体非负整数（取 $x_0 = K, H = 0$）。所以只要所有 $b_i / u_i$ 都等于**同一个整数** $K$ 就可行。

**为什么这样是对的？** 上面每一步都是等价的（"存在操作序列" $\iff$ "存在非负整数 $x_0,H$ 满足方程"），而情形 A 中线性方程组的系数矩阵非奇异，解唯一，所以反解出来的值若通不过验证就一定无解；情形 B 也同理。两处都**先解、后逐项验证**，不需要相信"解出来了就完事"。

实现上有两个容易写错的地方：

1. 反解 $H$ 时用的是 $i=1$。这没问题，但**必须**在解完之后把所有 $i$ 重新验证一遍——因为解方程只用了两条等式，其余位置还没有被约束过。
2. 情形 A 的除数为 $u_i - u_{m(i)}$，$i$ 必须是那两个不对称点之一，不能拿中间元素当除点（$n$ 为奇数时中间的自减恒为 $0$，会除零）。

### 复杂度

每组数据只需 $O(n)$ 找不对称点、$O(1)$ 反解、$O(n)$ 验证。总时间复杂度 $O(\sum n)$，空间复杂度 $O(n)$。数值上 $x_0 \leqslant 2000$、$u_i \leqslant 2000$，乘积不超过 $4 \times 10^6$，`int` 也不会溢出（代码中仍使用 `long long` 以防万一）。

### 关于暴力解法

对拍用的 `brute.cpp` 是直接搜索操作序列：状态为当前的 $(a,t)$，每层尝试操作一或操作二。

它依赖一个剪枝：$a$ 只增不减，而折叠后 $T^{k+1}_i = T^k_i + T^k_{m(i)} \geqslant T^k_i$ 也说明 $t$ 只增不减。所以只要某一刻出现 $a_i + t_i > b_i$，此后再也无法把 $b_i$ 补回来，可以立刻回溯。搜索树因此是有限的，可在小数据上稳定完成对拍。

## 总结

这道题的关键不是"怎么搜索操作序列"，而是**先消除操作序列的无限性**：

1. 两种操作互不干扰，于是任意操作序列等价于每个折叠版本各执行若干次操作二的计数；
2. 折叠一次后 $t$ 就变成中心对称向量，此后每折叠一次只是整体乘 $2$，即 $T^k = 2^{k-1}v$；
3. 二进制表示让"各计数的加权和"$H$ 恰好取遍所有非负整数，问题坍缩为 $b = x_0 u + H v$ 这一个方程；
4. 利用 $v$ 的对称性作差消去 $H$，反解出唯一的 $x_0$ 和 $H$，非负整数 + 逐项验证即可。

值得记住的两个技巧：**把"操作序列"转换成"各状态的执行次数"**，以及**用二进制把一个任意大的加权和解释成可以取遍所有非负整数**。两者合起来就把无穷搜索变成了两条除法。

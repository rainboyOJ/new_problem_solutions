## 形式化题目

给出 $n$ 个点，点 $i$ 有权值 $w_i$，并给出一条有向边 $i \to a_i$（$a_i \neq i$）。初始只有 $s$ 的颜色 $c_s = 1$，其余 $c_i = 0$。

可以任意多次执行操作：选一个 $i$，令 $c_i \leftarrow c_{a_i}$，代价 $p_i$。

最终得分是「颜色为 $1$ 的点的权值和」减去「所有操作的代价和」。求最大得分。

由于每个点恰好有一条出边，把 $a_i \to i$ 反过来看，整张图是若干棵**外向基环树**（每个连通块恰好一个环，环外结点指向环）。所有操作都只是「把父亲 $a_i$ 当前的 0/1 复制给自己」，信息沿着 $a$ 的方向（即沿着反图的父子方向）向下流动。

## 正解

### 思路

**第一步：把「操作序列」翻译成每个点被改色的次数。**

设 $c_u$ 表示点 $u$ 被操作的次数（即它被改色多少次）。有两个关键性质：

1. **颜色由次数的奇偶性决定。** 初始时只有 $s$ 是 $1$，其余是 $0$。点 $u$ 每被改一次颜色就翻转一次，所以最终颜色为
   $$\text{color}(u) = (c_u + [u = s]) \bmod 2 .$$
   于是点 $u$ 贡献的权值是 $(c_u + [u=s])\bmod 2$ 为 $1$ 时的 $w_u$，否则为 $0$。

2. **相邻两次改色之间必须有颜色可复制，因此次数受父亲限制。** 点 $u$ 的第 $k$ 次改色，是把此刻 $a_u$ 的颜色复制过来，所以 $u$ 不可能比 $a_u$ 被改得更多次：要有第 $k$ 次改色的机会，就得先有 $a_u$ 的颜色变化。形式化地：
   $$c_u \leqslant c_{a_u} + [a_u = s] \qquad (u \neq s).$$
   其中 $+[a_u = s]$ 是因为根 $s$ 一开始就持有颜色 $1$，相当于白送一次。

   根 $s$ 不受这条约束（没有「更上层」的点能限制它）。

**第二步：为什么总操作次数就是 $\sum c_u$。** 我们只在颜色确实会改变时才做操作；连续两次把同一个点写成同一种颜色是纯浪费，可以直接删掉。所以任何有意义的方案都对应一组满足上面约束的 $c_u$，代价恰好是 $\sum c_u p_u$；反之给定一组合法 $c_u$，按从外层到内层的顺序执行各点的改色也能把方案构造出来。于是问题等价于：

$$
\max \sum_{u} \Big( \big(c_u + [u=s]\big)\bmod 2 \Big) w_u - \sum_u c_u p_u,
\quad \text{s.t. } c_u \leqslant c_{a_u} + [a_u = s]\ (u \neq s).
$$

这是一个在基环树上做选择的 DP。注意 $c_u$ 只需要枚举到 $n$（超过 $n$ 次改色没有意义，因为 $2^n$ 之外的翻转不会带来新收益、只会增加代价）。

**第三步：$s$ 不在环上时——纯树形 DP。**

此时从 $s$ 出发顺着 $a$ 走永远走不到环（$s$ 在某个「尾巴」上），我们干脆反过来，把 $a_i \to i$ 看成以 $s$ 为根的外向树，做经典树形 DP：

设 $f_{u,i}$ 表示「点 $u$ 被改色 $i$ 次时，$u$ 的子树能得到的最大收益」。初值由第一步的公式直接给出：

$$f_{u,i} = \Big( (i + [u=s]) \bmod 2 \Big) w_u - i\, p_u .$$

转移时对每个儿子 $v$ 合并。设 $v$ 被改色 $j$ 次，由约束 $c_v \leqslant c_u + [u = s]$ 得 $j \leqslant i + [u=s]$，所以

$$f_{u,i} \leftarrow f_{u,i} + \max_{0 \leqslant j \leqslant i + [u=s]} f_{v,j}.$$

对 $f_{v,\cdot}$ 做**前缀最大值**，就能在 $O(1)$ 内取到这个 $\max$，合并一个儿子的代价是 $O(n)$。

答案是在根处取 $\max_{i} f_{s,i}$。这里还有一个化简：可以证明答案就是 $\max\{f_{s,0}, f_{s,1}\}$。直观上，$s$ 每多改一次色都要花钱，而它下面的点至多比它多改一次；$c_s \geqslant 2$ 时把 $s$ 的那两轮零一翻转删掉，子树约束只会变松、代价只会变小。因此树的情况只用看 $i = 0, 1$ 两个值。

**第四步：$s$ 在环上时——环上再套一层 DP。**

先找出 $s$ 所在的环 $\mathrm{cyc}_1 = s,\ \mathrm{cyc}_2,\ \dots,\mathrm{cyc}_k$（环上的边方向是 $\mathrm{cyc}_i \to \mathrm{cyc}_{i+1}$）。

对环上每个点先把它**环外**的子树用上面的树形 DP 合并进 $f$（环上的儿子由环 DP 负责，跳过）。

- **环长 $k = 2$：** 环上只有 $s$ 和 $t$ 两个点。此时枚举 $c_s, c_t \in \{0,1\}$ 的三种可行组合即可，答案为
  $$\max\{f_{s,0}+f_{t,0},\ f_{s,0}+f_{t,1},\ f_{s,1}+f_{t,0}\}.$$

- **环长 $k > 2$：** 环上相邻两个点的次数差至多为 $1$：一旦 $c_{\mathrm{cyc}_{i+1}} \geqslant c_{\mathrm{cyc}_i} + 2$，$\mathrm{cyc}_{i+1}$ 的第 $c$ 次改色就取不到颜色（它的父亲还没改那么多次），所以非法；而沿着环走一圈最多让次数每次增加 $1$。于是**枚举 $c_s = r$**（注意把 $s$ 自带的初始颜色也算进 $c_s$，所以 $r \geqslant 1$），用

  $$g_{i,j} = \text{走到环上第 } i \text{ 个点、且 } c_{\mathrm{cyc}_i} = r - j \text{ 时的最大收益} \qquad (j = 0,1,2)$$

  来转移。初始 $g_{1,0} = f_{s,r-1}$（$-1$ 是因为 $c_s$ 的计数里额外含了初始的那一次颜色），$g_{1,1} = g_{1,2} = -\infty$。对 $i > 1$：

  $$g_{i,j} = f_{\mathrm{cyc}_i,\,r-j} + \max_{0 \leqslant k' \leqslant j} g_{i-1,k'}.$$

  最后对所有 $r$ 取 $\max_j g_{k,j}$ 的最大值。

  这份 $j \leqslant 2$ 的枚举是完备的：沿环走一圈，次数最多比 $s$ 少 $2$（把 $s$ 的初始颜色 1 沿着环推一圈再推回来的构造可以达到这个差值），再少就不合法了。

**状态转移示例。** 以样例一（$n=3$，$a = [3,1,2]$，即 $1 \to 3 \to 2 \to 1$，环长 $3$，$s=1$）为例，环上每点的子树都是空的，$f_{u,i} = ((i+[u=s]) \bmod 2) w_u - i\,p_u$：

| $i$ | $f_{1,i}$（$w_1=-1,p_1=1$） | $f_{2,i}$（$w_2=-1,p_2=0$） | $f_{3,i}$（$w_3=2,p_3=0$） |
| --- | --- | --- | --- |
| 0 | $-0=0$ | $0$ | $0$ |
| 1 | $0-1=-1$ | $w_2=-1$ | $w_3=2$ |
| 2 | $w_1-2=-3$ | $0$ | $0$ |

取 $r = 2$（即 $c_1 = 1$，$c_2 = c_3 = 0$）：$g_{1,0} = f_{1,1} = -1$；走到点 $2$ 时 $c_2 = r-2 = 0$，得 $-1 + f_{2,0} = -1$；走到点 $3$ 时 $c_3 = 0$，得 $-1 + f_{3,0} = -1$。另一条 $r$ 取法给出 $f_{3,1} = 2$ 减去代价，最终答案 $1$，与样例一致。

代码里的实现要点：

- `on_cycle[u]` 标记 $s$ 所在环上的点；`dfs(u)` 跳过环上的儿子，避免在环上递归。
- `f[u][i]` 的下标 $i$ 开到 $n+1$，因为合并环上/树上儿子时需要访问 $f_{v, i+1}$，多开一格并置为 $-\infty$。
- 找环时从 $s$ 出发沿 $a$ 走，先用 `vis` 找到第一个重复出现的点，再从它绕一圈，得到的就是 $s$ 所在环（对不连通的功能图也成立，与题面的基环树连通性无关）。

### 复杂度

- 树上部分：每个点对每个 $i \in [0,n]$ 做一次 $O(1)$ 的前缀 $\max$ 合并，共 $O(n^2)$。
- 环上部分：枚举 $r$ 共 $O(n)$ 种，每种沿环走 $O(k) \leqslant O(n)$ 步、每步 $O(1)$，总计 $O(n^2)$。
- 总时间复杂度 $O(n^2)$，空间复杂度 $O(n^2)$（$n = 5\times10^3$ 时约 $200$ MB，限制为 $1$ GB）。

## 总结

- 关键在于把「一串操作」重新解释成**每个点的改色次数 $c_u$**：颜色只看 $c_u$ 的奇偶，代价是 $\sum c_u p_u$，而操作可行性被压成了一条简单的局部约束 $c_u \leqslant c_{a_u} + [a_u = s]$。
- 有了这个模型，问题就归约成基环树上的 DP：$s$ 不在环上时是普通树形 DP，用前缀 $\max$ 把合并降到 $O(n^2)$；$s$ 在环上时先对每个环上点跑子树 DP，再在环上枚举 $c_s$，用「相邻次数差 $\leqslant 1$」做长度为 $3$ 的环上 DP。
- 边界情况主要有三类：环长为 $2$ 需要单独枚举；结点权值可为负，所以「不选点」是合法选择（$f_{u,\cdot}$ 的初值里颜色为 $0$ 时贡献 $0$）；答案可能为负，不能用 $0$ 初始化。

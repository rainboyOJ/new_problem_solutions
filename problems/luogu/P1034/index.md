## 形式化题目

给定二维平面上的 $n$ 个点 $P = \{(x_i, y_i)\}_{i=1}^n$（$1 \le n \le 50, 0 \le x_i, y_i \le 500$）以及矩形数量上限 $k$（$1 \le k \le 4$）。

要求构造不超过 $k$ 个轴对齐矩形 $R_1, \dots, R_k$（各矩形边平行于坐标轴），使得每个点至少被一个矩形覆盖。
定义退化为单点或平行于坐标轴线段的矩形面积为 $0$。

约束条件：所有非空矩形必须**严格分离**——任意两个矩形之间不仅内部不能重叠，其边线与顶点也不能接触或重合。

目标：求出满足条件的各矩形面积之和的最小值。

## 题目解析

!!! info 极小 $k$ 允许点集划分回溯，实时增量维护包围盒与严格分离剪枝。
$k \le 4$ 的极小规模表明每个点至多有 4 种归属选择。对点坐标双关键字排序后进行深度优先搜索；每个矩形仅需维护其所包围点集的四界 $(\min x, \max x, \min y, \max y)$。通过“最优性界剪枝 + 严格分离即时判定 + 等价空矩形合并”，将理论指数级的状态树大幅裁剪至毫秒级。
!!!

### 思路

**1. 极小矩形数量 $k \le 4$ 带来的搜索契机**

虽然点数 $n \le 50$，但矩形数量 $k \le 4$ 极小。
每个点最终必定属于某个矩形，如果把 $n$ 个点划分到 $k$ 个点集，本质上是一棵深度为 $n$、分支因子至多为 $k$ 的决策树。
直接全排列暴力搜索的复杂度为 $k^n \approx 4^{50}$，显然是天文数字。但结合几何排斥与面积单调性，我们可以加入极其强力的剪枝。

**2. 轴对齐外接矩形（Bounding Box）的性质**

若某个矩形覆盖了点集 $S = \{(x, y)\}$，为了使该矩形面积最小，其边界必然紧贴点集的四极值：
- $x_{min} = \min_{(x,y) \in S} x, \quad x_{max} = \max_{(x,y) \in S} x$
- $y_{min} = \min_{(x,y) \in S} y, \quad y_{max} = \max_{(x,y) \in S} y$
- 矩形面积即为 $(x_{max} - x_{min}) \times (y_{max} - y_{min})$。

当向一个矩形中加入新点 $(x_u, y_u)$ 时，只需更新四极值，面积呈单调不减变化。

**3. 三重核心剪枝策略**

为使搜索树在 $50$ 层深度下极速收敛，实施以下三种剪枝：

1. **最优性剪枝（面积下界）**：
   在搜索过程中，由于加入新点只会扩大或保持当前各矩形面积，当前所有矩形面积之和 $\sum \text{area}(R_i)$ 构成了未来总面积的下界。
   一旦 $\sum \text{area}(R_i) \ge ans$，说明无论后续如何安排，都不可能更新全局最优解，立即回溯剪枝。

2. **几何严格分离剪枝（合法性前置）**：
   题目特别约定：“各个矩形必须完全分开（边线与顶点也都不能重合）”。
   对于两个闭矩形 $A$ 和 $B$，它们严格分离的充要条件是在至少一个坐标轴方向上严格无交集：
   $$A.max\_x < B.min\_x \quad \lor \quad B.max\_x < A.min\_x \quad \lor \quad A.max\_y < B.min\_y \quad \lor \quad B.max\_y < A.min\_y$$
   一旦不满足上述条件（即两个矩形相交、内含、或者边线/顶点相碰接触），说明当前分配不合法。
   在把第 $u$ 个点加入第 $i$ 个矩形后，**立即**检测矩形 $i$ 是否与现有其他矩形发生碰撞冲突；若冲突则直接放弃此分支，无需等到叶子节点再判断。

3. **等价空矩形对称性剪枝**：
   若当前有多个尚未分配任何点的空矩形，将点 $u$ 加入到任何一个空矩形中是完全等价的（只是矩形编号的置换）。
   因此，每一层遍历空矩形时，只尝试放入**第一个**空矩形，其余空矩形直接跳过，消除对称分支。

4. **输入预排序加速**：
   搜索前将所有点按 $x$ 坐标为主、 $y$ 坐标为次进行排序。这样空间位置邻近的点优先连续被处理，能极早构造出致密的局部小矩形，快速压低 $ans$ 的上限，从而让后续的最优性剪枝早早触发。

### 正确性与边界

- **退化矩形的处理**：
  若矩形只覆盖 1 个点，或覆盖的点在同一水平/垂直线上，$(x_{max} - x_{min}) \times (y_{max} - y_{min}) = 0$，面积天然为 0，与题面约定完全相符。
- **状态恢复**：
  在回溯时，利用局部变量保存加入点前的四界状态 `old_rect`，递归返回后精确还原。
- **互斥判定的边界闭区间性**：
  条件必须写为严格不等号（$<$），使得等于（如 $A.max\_x = B.min\_x$）的情况被判定为不分离（接触），完全满足题意对顶点和边线接触的禁止。

### 复杂度

- **时间复杂度**：
  最坏情况下决策树规模为 $O(k^n)$。但在严格几何排斥、对称性去重和最优性剪枝的剪裁下，无效状态在极浅层即被阻断，实际遍历节点数通常不足 $10^4$ 次，在 $n \le 50, k \le 4$ 时运行耗时 $< 5\text{ms}$。
- **空间复杂度**：
  递归深度为 $n \le 50$，每层仅存储常数级的矩形备份，空间复杂度为 $O(n + k)$，内存开销可忽略不计。

## 总结

本题是利用小参数特征（$k \le 4$）进行**精确剪枝搜索**的典范。面对多子集划分问题，不仅要通过最优性上下界控制分支，更要充分利用问题本身的几何互斥硬约束（轴对齐分离判定），在修改状态的瞬间即时剔除不可行路径，从而在指数级的理论状态空间中完成极速剪枝收敛。

# P4310 绝世好题
## 题目描述

给定一个长度为 $n$ 的数列 $\{a\}$，求 $\{a\}$ 的子序列 $\{b\}$ 的最长长度 $k$，满足 $b_i \land b_{i-1} \ne 0 $，其中 $2\leq i\leq k$， $\land$ 表示位运算取与。

## 输入格式

输入文件共 2 行。
第一行包括一个整数 $n$。
第二行包括 $n$ 个整数，第 $i$ 个整数表示 $a_i$。

## 输出格式

输出文件共一行。
包括一个整数，表示子序列 $\{b\}$ 的最长长度。

## 输入输出样例 #1

### 输入 #1

```
3
1 2 3
```

### 输出 #1

```
2
```

## 说明/提示

对于 $100\%$ 的数据，$1\leq n\leq 100000$，$a_i\leq 10^9$。

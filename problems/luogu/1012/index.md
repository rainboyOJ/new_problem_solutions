### 题意

给出 `n` 个正整数，可以任意调整顺序并首尾拼接。要求组成最大的整数。

### 思路

先看一个小数据暴力：

@include-code(./brute.cpp, cpp)

这个暴力把每一层递归看成“选择下一个放到答案里的数”，枚举所有排列后取最大的拼接结果。它能验证思路，但排列数量是 `n!`，不能用于正式数据。

关键是比较两个字符串 `x` 和 `y` 谁应该排在前面。

如果 `x` 在前，局部拼接结果是：

```text
x + y
```

如果 `y` 在前，局部拼接结果是：

```text
y + x
```

为了让整体最大，就应该让较大的那个局部结果排在前面。因此排序比较规则是：

```text
x + y > y + x
```

按这个规则排序后，从前到后输出所有字符串即可。

### 复杂度

- 时间复杂度：`O(n log n * L)`，其中 `L` 是数字字符串长度
- 空间复杂度：`O(nL)`

### 总结

拼数题不能按数值大小排序。真正的比较标准是“两个数交换前后，哪种拼接更大”。

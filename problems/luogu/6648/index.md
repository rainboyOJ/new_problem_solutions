### 题意

给定边长为 $n$ 的数字三角形（第 $i$ 行有 $i$ 个数）。对每个边长为 $k$ 的正子三角形求其中数字的最大值，再把所有子三角形的最大值求和。

### 思路

先看一个直接按题意扫描的朴素解：

@include-code(./brute.cpp, cpp)

暴力对每个子三角形逐行扫一遍取最大值，总复杂度 $O(n^2 k^2)$，$n \le 3000$ 时不可行。

**为什么要倍增？**

"对所有子三角形分别求最大值"和 RMQ 非常像——RMQ 用 ST 表把区间最值拆成两个 $2^j$ 长度的重叠区间。这里也是：预处理出**边长为 $2^j$ 的三角形的最大值**，查询时用少量完全覆盖的预计算块拼出目标三角形。

**怎么拼？**

一维 ST 表只需要两块。但在二维等边三角形上，只用三个"角"上的小三角形覆盖大三角形会漏掉中央区域。

解法是用**正三角形**和**倒三角形**两种形状配合：一个边长为 $s$ 的大三角形可以分解成 $s = p + d$，其中 $p$ 是不超过 $s$ 的最大 $2$ 的幂，$d = s - p$。大三角形被 $3$ 个边长为 $p$ 的三角形覆盖，必要时再用 $1$ 个倒三角形补上间隙——总共 $3 \sim 4$ 个预计算块。

对每种边长 $s$，先递归求出 $p$ 和可能需要的倒三角形的倍增表，再按递推公式合并，得到 $s$ 边的所有位置的最大值。

**实现要点**

1. **坐标**：三角形位置用 $(x, y)$ 坐标表示（$x \ge 0, y \ge 0, x + y \le n - 1$），与读入的行/列一一对应。
2. **DAG 计算**：所有需要的"边长 $\times$ 形状"组合构成一个节点图，边长为 $1$ 的叶子直接存原始数据，大边长按拓扑序（边长从小到大）递推，计算完就释放不再需要的子节点内存。
3. **滚动**：每个节点只在计算时分配内存，用毕即释，总空间 $O(n^2)$。
4. **求和**：最终根节点（边长 $k$ 的正三角形）的 `data` 数组保存了所有位置的最大值，直接累加即可。

### 复杂度

每个"边长"节点处理 $O(n^2)$ 个位置。不同 $p$ 的值（$2$ 的幂）只有 $O(\log n)$ 种，加上倒三角形，总节点数 $O(\log n)$。时间 $O(n^2 \log n)$，空间 $O(n^2)$。

### 总结

二维 ST 表不能把一维的"两块覆盖"简单照搬。三角形的特殊形状使得正方向覆盖会出现空隙，引入倒三角形补上间隙，是一种通用的倍增适配思路。DAG 拓扑递推在内存紧张时也能做到"算完即释"，避免保留所有 $O(\log n)$ 层的全量数据。

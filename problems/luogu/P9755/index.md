## 形式化题目

给定 $n$ 片地块构成的树，以 $1$ 号地块为根（连接入口）。每天可以在与已种树地块相邻的空地上种一棵高度为 $0$ 的树（第 $1$ 天只能种 $1$ 号地块）。

若点 $i$ 在第 $d$ 天种下，则到第 $T$ 天它的高度为：
$$
\sum_{x=d}^{T} \max(b_i + x \cdot c_i,\ 1)
$$
（$x$ 从整个任务的第一天开始计数）。要求在保证每棵树最终高度不低于 $a_i$ 的前提下，求最小完成天数 $T$。

---

## 暴力解法

### 思路

二分 $T$，然后递归枚举所有合法的连通种植顺序：第 `day` 天在“未种、且与某种下的地块相邻”的地块里任选一个种下，检查每个点种下时是否不晚于自己的最晚种植日。

## 正解：双重闭区间二分 + 递归后序树调度（EDF 贪心）

### 1. 外层二分完成天数 $T$

完成天数 $T$ 具备显然的单调性：给定的天数越多，树的生长时间越长，越容易满足要求。
按照闭区间记账法，在 $[n, 10^9]$ 范围内二分 $T$：
- 检验中点 $mid = l + (r - l) / 2$；
- 若 `check(mid)` 可行，立即记账 `ans = mid`，并贪心向左缩小范围 `r = mid - 1`；
- 否则向右扩大搜索范围 `l = mid + 1`。

### 2. 内层二分单点最晚种植日 $deadline[i]$

固定完成天数 $T$ 后，单点 $i$ 的种植天数 $d$ 越早，其最终高度越高（单调性）。
因此可以通过内层二分求出使得高度达标的**最大天数** $d$：
- 若第 $1$ 天种下到第 $T$ 天高度仍不足 $a_i$，说明当前 $T$ 绝对不可行，直接返回 $0$；
- 在闭区间 $[1, T]$ 上二分：满足 $\sum_{x=mid}^T \max(b_i + x \cdot c_i, 1) \geqslant a_i$ 时记账 `ans = mid`，并向右贪心试探更大天数 `l = mid + 1`，否则 `r = mid - 1`；
- 种植天数超过 $n$ 天无实际意义，封顶为 $n$。

*生长量计算*：当 $c_i < 0$ 时，生长度呈分段折线。先算出速度降至 $1$ 的临界点，前半段等差数列求和，后半段每天按 $1$ 快速结算。值域可达 $10^{27}$，采用 `__int128` 杜绝溢出。

### 3. 子树最小截止期（递归后序统计）与堆贪心

现在问题转化成了标准的**树上前驱约束调度问题**：
- 父亲必须早于儿子种下；
- 每个点 $u$ 必须在第 $deadline[u]$ 天或之前种下。

**关键性质**：贪心时不能仅看点 $u$ 自身的紧急度。若 $u$ 本身很宽裕，但其子树深处包含一个极度紧急的节点，就必须尽早种植 $u$ 以打通通向紧急节点的路径！

因此，定义子树最小截止期：
$$
min\_subtree\_deadline[u] = \min_{v \in \operatorname{subtree}(u)} deadline[v]
$$
直接通过**标准的树形递归后序遍历**自底向上完成统计：
```cpp
void dfs_subtree_deadline(int u) {
    min_subtree_deadline[u] = deadline_day[u];
    for (int v : child[u]) {
        dfs_subtree_deadline(v);
        min_subtree_deadline[u] = min(min_subtree_deadline[u], min_subtree_deadline[v]);
    }
}
```

### 4. 优先队列模拟合法性

建立小根堆，维护当前已经可以种植的候选点，优先级为 $min\_subtree\_deadline$：
- 初始将根节点 $1$ 放入堆中；
- 每天从堆顶弹出优先级最高的点 $u$。若当前天数已超过 $deadline[u]$，说明无法赶在截止日前种下，判定不可行；
- 否则种下 $u$，并将其所有儿子节点加入堆中；
- 持续 $n$ 天均未逾期，则当前 $T$ 可行。

## 复杂度分析

- **时间复杂度**：
  - 外层二分需 $O(\log 10^9) \approx 30$ 次迭代；
  - 每次检验中，对 $n$ 个点分别二分最晚种植日耗时 $O(n \log T)$；
  - 树递归与优先队列调度耗时 $O(n \log n)$；
  - 总时间复杂度为 $O(\log 10^9 \cdot (n \log T + n \log n))$，可轻松在 1 秒内通过全部测试点。
- **空间复杂度**：$O(n)$。存储树的邻接表与堆。

## 总结

1. **双层二分的职责分离**：外层二分寻找全局最优完成时刻，内层二分将各点的复杂非线性生长函数解耦为独立的标量截止时间；
2. **树上 EDF（Earliest Deadline First）贪心**：通过树后序遍历将子树内的未来紧急度向根回传，将拓扑树上调度巧妙化为优先队列贪心。

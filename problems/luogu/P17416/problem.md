# P17416 「IXOI R3」我才不玩原神呢
## 题目背景

这道题本来叫“我最喜欢可莉啦”。

## 题目描述

对于一个长度为 $l$ 的序列 $b$，设其最大值为 $m_b$，定义其权值为 $\sum_{i=1}^l (b_i\oplus m_b)$。

给定一个长度为 $n$ 的序列 $a$，在其所有长度为 $k$ 的子序列中，求出权值最大的那一个子序列的权值。

## 输入格式

第一行，输入两个正整数 $n,k$。

第二行，输入一行 $n$ 个正整数，第 $i$ 个正整数为 $a_i$。

## 输出格式

输出一行一个整数，表示最大权值。

## 输入输出样例 #1

### 输入 #1

```
4 3
4 2 3 1
```

### 输出 #1

```
13
```

## 说明/提示

### 样例解释

长度为 $3$ 的子序列有：$\{4,2,3\},\{4,2,1\},\{4,3,1\},\{2,3,1\}$，其权值分别为 $13,11,12,3$，故答案是 $13$。

### 数据范围

**本题采用捆绑测试**。

- 子任务 $0$（$10$ 分）：$n \le 20$；
- 子任务 $1$（$25$ 分）：$n \le 10^3$；
- 子任务 $2$（$25$ 分）：$k=2$；
- 子任务 $3$（$40$ 分）：无特殊限制；

对于 $100\%$ 的数据，$1\le k\le n\le 10^5$，$1\le a_i\le 10^{9}$。

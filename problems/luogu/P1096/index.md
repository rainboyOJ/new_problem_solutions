## 形式化题目

有三根柱子 A、B、C。A 柱上初始放置 $2n$ 个圆盘，包含 $n$ 种不同尺寸，每种尺寸均恰有两个完全相同且不加区分的圆盘。

要求在满足以下规则的前提下，将所有圆盘从 A 柱移动到 C 柱：
1. 每次仅能移动任意柱顶的一个圆盘；
2. 任何时刻，三根柱子上的圆盘尺寸必须保持上小下大（相同尺寸允许叠放）。

求移动所需的最少总步数 $A_n$。

## 题目解析

!!! info 从经典汉诺塔归纳双盘递推关系，通项为 $2^{n+1}-2$。
移动 $2n$ 个圆盘的最优路径遵循经典汉诺塔的“分治三步走”：将上方 $2(n-1)$ 个盘子移到辅助柱 B，将底部 2 个最大盘移到目标柱 C，再将辅助柱 B 上的盘子移回 C。建立线性递推式 $A_n = 2A_{n-1} + 2$。对于 $n \le 200$，答案达 60 余位十进制数，采用高精度迭代乘加即可极简求解。
!!!

### 思路

**1. 经典汉诺塔与双塔模型的对比推导**

回顾标准单盘汉诺塔问题：
- 设 $H_n$ 为将 $n$ 个互不相同圆盘从 A 移到 C 的最少步数；
- 策略是：
  1. 将上方 $n-1$ 个较小盘子从 A 移到 B（耗费 $H_{n-1}$ 步）；
  2. 将底部最大的第 $n$ 个盘子从 A 移到 C（耗费 $1$ 步）；
  3. 将 B 上的 $n-1$ 个盘子从 B 移到 C（耗费 $H_{n-1}$ 步）。
- 递推式为 $H_n = 2H_{n-1} + 1$，通项为 $H_n = 2^n - 1$。

在双塔汉诺塔中，每种尺寸的圆盘有两个：
- 设 $A_n$ 为将 $2n$ 个圆盘从 A 移到 C 的最少步数；
- 由于底部的两个最大尺寸盘子必须移到目标柱 C，而根据规则，在其移动过程中，上方所有 $2(n-1)$ 个较小圆盘**必须全部暂时离开 A 柱，且不能停留在 C 柱**上（否则最大盘无法落入 C 柱底部）；
- 因此，上方 $2(n-1)$ 个圆盘唯一的去向是整齐地移到辅助柱 B 上，这等价于一个规模为 $n-1$ 的子问题，耗费步数 $A_{n-1}$；
- 此时 A 柱上只剩下 2 个最大的相同尺寸圆盘，直接将它们依次从 A 移到 C，耗费 $2$ 步；
- 最后，再将暂存在 B 柱上的 $2(n-1)$ 个圆盘从 B 移到 C，同样耗费 $A_{n-1}$ 步；
- 全过程步数之和为：

$$A_n = 2A_{n-1} + 2$$

初始边界：$A_0 = 0$；$A_1 = 2 \times 0 + 2 = 2$（验证：2 个相同盘子直接依次移到 C 柱，共 2 步）。

**2. 通项公式推导**

对递推关系式两边同时加上 2：

$$A_n + 2 = 2(A_{n-1} + 2)$$

令 $B_n = A_n + 2$，则数列 $\{B_n\}$ 是公比为 $2$ 的等比数列。
首项 $B_0 = A_0 + 2 = 2$。
因此：

$$B_n = B_0 \cdot 2^n = 2 \cdot 2^n = 2^{n+1}$$

从而得出通项公式：

$$A_n = 2^{n+1} - 2$$

**3. 高精度数值规模与计算方式**

数据范围 $n \le 200$，所求数值为：

$$A_{200} = 2^{201} - 2$$

其十进制位数约为 $\log_{10}(2^{201}) \approx 201 \times 0.30103 \approx 61$ 位，远超 64 位无符号整数（上限约 $1.8 \times 10^{19}$），必须采用高精度大整数。

实现上，无需显式计算 $2^{n+1}$ 再做大数减法借位，直接利用递推式 $A_i = 2A_{i-1} + 2$ 进行高精度乘加模拟更加精炼：
在对大数组进行每一轮乘 2 时，直接将个位的**初始进位设为 2**（相当于给乘积自动加 2），单重循环线性迭代 $n$ 次即可完成全过程。

### 正确性与边界

- **最少步数的必然性证明**：
  最大尺寸的两个圆盘在整场移动中至少必须各移动一次从 A 到 C，因此至少需要 2 步；在此期间，其他所有盘子必须全部位于辅助柱 B 上。子问题独立且上小下大规则严格，因此 $A_n \ge 2A_{n-1} + 2$ 是严格的理论下界，构造方案恰好取到该等号。
- **边界条件**：
  - 当 $n = 1$ 时，$A_1 = 2^{2} - 2 = 2$；
  - 当 $n = 2$ 时，$A_2 = 2^{3} - 2 = 6$；
  与样例 1 和样例 2 的输入输出完全一致。

### 代码

`main.cpp` 使用 `vector<int>` 逆序（小端序）存储大整数，初始为空（对应 0），连续迭代 $n$ 次 $cur = a_j \times 2 + carry$，初始进位设为 2，最后逆序输出。

### 复杂度

- **时间复杂度**：
  大数位数不超过 65 位。
  外层循环迭代 $n$ 次，内层乘法单次耗时不超过 65 次基本运算。
  总操作次数不超过 $200 \times 65 \approx 1.3 \times 10^4$，耗时在 $0.1\text{ms}$ 以内，微秒级即时完成。
- **空间复杂度**：
  `vector<int>` 仅需存储最多 65 个数位，空间复杂度为 $O(\text{digits}) = O(n)$，内存消耗几字节。

## 总结

双塔汉诺塔问题是分治与递归思维的经典拓展。通过抓住“最大规模构件移动时，其余所有次生构件必须完全规避至辅助容器”的不变公理，快速将规模为 $2n$ 的复杂游戏归约到 $2(n-1)$ 的子问题。再借助特征方程或构造等比数列提取出简洁的闭式通项 $2^{n+1}-2$，配合轻量的高精度乘加模拟，展现了算法竞赛中数论推导与代码精简的结合。

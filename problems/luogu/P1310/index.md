## 形式化题目

定义布尔代数系统包含布尔变量取值空间 $\{0, 1\}$ 以及两个二元运算符：
- 逻辑或（原题记为 $\oplus$ 或 `+`）：$x \lor y = 1 - (1 - x)(1 - y)$；
- 逻辑与（原题记为 $\times$ 或 `*`）：$x \land y = x \cdot y$。

运算优先级规定：括号优先于所有运算符；逻辑与运算严格优先于逻辑或运算。

输入给出一个长度为 $L$（$0 \le L \le 10^5$）的骨架字符串 $S \in \{`(`, `)`, `+`, `*`\}^*$。该字符串为某个合法中缀布尔表达式抹去所有操作数（叶子变量）后残留的符号序列。在表达式的每个变量占位符处，均可独立填入数值 $0$ 或 $1$。

目标：求出使得整个表达式最终计算真值为 $0$ 的填数赋值方案总数，结果对 $10007$ 取模。

原题中将变量位置称为「横线」，二元逻辑运算分别称为加和乘。

## 正解

### 思路

#### 1. 语法骨架复原：相邻规则操作数补全

输入给出的字符串中省略了所有待填入数字的操作数。为了采用标准编译原理中的中缀表达式求值技术，首要任务是将缺省的操作数（记为 `_`）严密补全，还原为符合语法规则的标准中缀表达式。

每个操作数 `_` 必然处于合法的操作数语法槽位中：
1. **首尾边界**：若表达式开头不是 `(`，则开头必定存在一个操作数 `_`；若结尾不是 `)`，则末尾必定存在一个操作数 `_`。
2. **相邻字符规则**：
   - 运算符之后若紧跟运算符（如 `++`、`+*`、`*+`、`**`），中间必定夹着一个操作数 `_`；
   - 运算符之后若紧跟右括号（如 `+)`、`*)`），说明运算符右侧的操作数被省略，需在中间补入 `_`；
   - 左括号之后若紧跟运算符（如 `(+`、`(*`），说明该运算符左侧的操作数被省略，需在中间补入 `_`；
   - 左括号之后若紧跟右括号（即 `()`），中间必定包含一个操作数 `_`。

经过单遍线性扫描并插入 `_` 后，原串转化为一个标准中缀表达式，其长度依然与 $L$ 同阶（不超过 $2L + 1$）。

#### 2. 布尔真值计数状态与合并转移

如果使用纯暴力穷举每个 `_` 填 $0$ 还是 $1$，由于操作数多达 $O(L)$ 个，复杂度将高达 $O(2^L)$。

注意到任何子表达式无论内部结构多复杂，向外传递的语义信息只有两个独立的计数标量：
- $c_0$：使得该子表达式计算结果为 $0$ 的赋值方案数；
- $c_1$：使得该子表达式计算结果为 $1$ 的赋值方案数。

因此，我们可以将子表达式的状态抽象为一个二元组 $\mathrm{State}(c_0, c_1)$。

对于最底层的基本变量 `_`：
- 可以填 $0$（产生 $1$ 种为 $0$ 的方案）；也可以填 $1$（产生 $1$ 种为 $1$ 的方案）；
- 其基础状态为 $(c_0 = 1, c_1 = 1)$。

当两个子表达式 $L(l_0, l_1)$ 与 $R(r_0, r_1)$ 经由二元运算符 $op$ 结合时，按真值表进行乘法原理与加法原理状态转移（所有计算均在模 $10007$ 意义下进行）：
- **逻辑或运算（`+`）**：
  - 运算结果为 $0$ 当且仅当左右两端均为 $0$：
    $$res.c_0 = (l_0 \times r_0) \pmod{10007}$$
  - 其余三组输入组合（$0+1, 1+0, 1+1$）结果均为 $1$：
    $$res.c_1 = (l_1 \times r_0 + l_0 \times r_1 + l_1 \times r_1) \pmod{10007}$$
- **逻辑与运算（`*`）**：
  - 运算结果为 $0$ 只要至少有一侧为 $0$（$0*0, 0*1, 1*0$）：
    $$res.c_0 = (l_0 \times r_0 + l_0 \times r_1 + l_1 \times r_0) \pmod{10007}$$
  - 运算结果为 $1$ 当且仅当两侧均为 $1$：
    $$res.c_1 = (l_1 \times r_1) \pmod{10007}$$

#### 3. 双栈中缀表达式解析求值

利用经典的双栈算法（操作数状态栈 `num_stk` 与符号栈 `op_stk`）实现单遍流式解析：
- 规定优先级：`*` 优先级为 2，`+` 优先级为 1，`(` 优先级最低（入栈时不与栈内比较优先级，只作为界定符）。
- 遍历补全后的表达式字符：
  1. 遇到操作数 `_`：直接压入基础状态 $(1, 1)$；
  2. 遇到 `(`：直接压入符号栈；
  3. 遇到 `)`：不断弹出符号栈顶与对应的两个操作数状态执行 `calc` 合并，直到遇到 `(` 并将其弹出；
  4. 遇到运算符 `op`（`+` 或 `*`）：当符号栈顶运算符的优先级大于或等于当前运算符优先级时，不断弹出并执行合并；随后将当前运算符压入符号栈。
- 遍历结束后，将符号栈中残留的运算符依次出栈合并。最终操作数栈顶的 $c_0$ 即为整个表达式求值为 $0$ 的方案总数。

### 复杂度

- **时间复杂度**：
  - 语法操作数补全：单遍线性扫描，耗时 $O(L)$；
  - 双栈中缀求值：补全后序列长度为 $O(L)$，每个操作数与每个符号恰好入栈一次、出栈一次，单次状态合并做常数次整数乘加与取模，耗时 $O(L)$；
  - 总时间复杂度为严格的 $O(L)$。在 $L = 100,000$ 规模下耗时约 $10\text{ms}$。
- **空间复杂度**：
  - 双栈深度与补全字符串长度不超过 $O(L)$，空间复杂度为 $O(L)$，内存消耗约数兆字节。

## 总结

本题是编译原理经典的中缀表达式解析与树形动态规划（计数 DP）的优雅融合。解题的关键第一步在于利用前后文语法邻接规则，将缺省操作数的非标准串拓扑等价补全为标准算术表达式；第二步则是将传统的“数值求解”升华为“真值方案数元组状态转移”，通过双栈就地归约将指数级搜索降解为纯线性的递推求值。

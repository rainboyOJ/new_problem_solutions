### 题意

有 $n$ 个物品，体积分别为 $w_1,\dots,w_n$。对每个 $i$ 和 $x\in[1,m]$，问用除第 $i$ 个物品外的 $n-1$ 个物品填满容积 $x$ 的方案数（只输出末位数字）。$n,m\le 2000$。

### 思路

**一句话本质**：如果没有物品 $i$，方案数 = 全体物品方案数 − 包含物品 $i$ 的方案数。含 $i$ 的方案恰好可以在不含 $i$ 的方案上补一个 $i$ 得到，于是可以用递推一次性求出所有答案。

**直接对每个 $i$ 分别跑 $n-1$ 个物品的背包行不行？**

每个 $i$ 跑一次 0/1 背包是 $O(n^2m)$，$n,m\le 2000$ 时不可接受。必须找到更高效的方法。

**全体物品的方案数 $f[j]$ 能告诉我们什么？**

先跑一遍包含全部 $n$ 个物品的 0/1 背包计数，得到 $f[j]$：用全部物品凑出和 $j$ 的方案数。转移为：

$$f[j] = f[j] + f[j-w_i] \quad (\text{倒序})$$

$f[j]$ 是"用所有物品能凑出 $j$"的总方案数。但我们想要的是"不含第 $i$ 个物品"的方案数。

**如何从 $f[j]$ 中扣除物品 $i$ 的贡献？**

对于固定体积 $j$，$f[j]$ 中的方案分两类：一类不含 $i$（我们想要的），一类含 $i$。如果能算出"含 $i$ 的方案数"，用 $f[j]$ 减去它就是答案。

**"含物品 $i$ 且和为 $j$"的方案数等于多少？**

任何一个含 $i$ 且和为 $j$ 的方案，去掉 $i$ 后就变成"不含 $i$ 且和为 $j-w_i$"的方案。反过来，每个不含 $i$ 且和为 $j-w_i$ 的方案加上 $i$ 就得到一个含 $i$ 且和为 $j$ 的方案。两者一一对应。

设 $g[j]$ 表示不含物品 $i$ 时和为 $j$ 的方案数，那么含 $i$ 且和为 $j$ 的方案数就是 $g[j-w_i]$。于是：

$$g[j] = f[j] - g[j-w_i] \quad (j\ge w_i)$$
$$g[j] = f[j] \quad (j < w_i)$$

当 $j<w_i$ 时，物品 $i$ 不可能被包含在 $j$ 中，所以 $f[j]$ 本身就不含 $i$，直接等于 $g[j]$。

**为什么这个递推是安全的？**

关键在于 $g[j-w_i]$ 依赖的是更小的容量，当我们按 $j$ 从小到大计算 $g[j]$ 时，$g[j-w_i]$ 已经在之前算好了。循环中 $g[0]=1$ 作为递推起点。

注意取模只需末位数字，所以用 `%10` 即可（减法时加 10 再取模防负数）。

最终对每个 $i$ 输出 $g[1]\dots g[m]$。

### 复杂度

- 全物品 DP：$O(nm)$
- 每个 $i$ 的 $g$ 推出：$O(m)$，共 $O(nm)$
- 总时间复杂度：$O(nm)$，$n,m\le 2000$ 没有问题
- 空间复杂度：$O(m)$

### 总结

这题的明星技巧是"从全体方案中扣除某个物品的贡献"。它利用方案数在加/减物品时的对称关系，把 $n$ 次独立背包合并成一次全体背包 + $n$ 次线性递推。核心公式 $g[j]=f[j]-g[j-w_i]$ 本质上是正难则反：含 $i$ 的方案不好直接算，但可以由不含 $i$ 的方案补 $i$ 得到。

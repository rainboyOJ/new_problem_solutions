## 形式化题目

给定一个长度为 $n$ 的单调不降正整数序列 $A = (a_1, a_2, \dots, a_n)$（$1 \le n \le 10^4, 1 \le a_i \le 600$）。

允许进行任意有限次如下变换操作：
- 选择任意内部下标 $i \in \{2, 3, \dots, n-1\}$，将该位置的数值更新为对称值：
  $$a_i \leftarrow a_{i-1} + a_{i+1} - a_i$$

定义序列 $A$ 的方差为 $D = \frac{1}{n} \sum_{i=1}^n (a_i - \bar{a})^2$，其中 $\bar{a} = \frac{1}{n} \sum_{i=1}^n a_i$。

目标：求在所有可通过该操作到达的序列中，方差的 $n^2$ 倍（即 $n^2 D$）的最小值。

## 正解

### 思路

#### 1. 代数目标化简

根据方差的定义，展开平方并同乘 $n^2$：
$$n^2 D = n^2 \cdot \frac{1}{n} \sum_{i=1}^n (a_i - \bar{a})^2 = n \sum_{i=1}^n \left( a_i^2 - 2 a_i \bar{a} + \bar{a}^2 \right)$$
将 $\bar{a} = \frac{1}{n} \sum_{i=1}^n a_i$ 代入并合并同类项：
$$n^2 D = n \sum_{i=1}^n a_i^2 - 2 \left( \sum_{i=1}^n a_i \right)^2 + \left( \sum_{i=1}^n a_i \right)^2 = n \sum_{i=1}^n a_i^2 - \left( \sum_{i=1}^n a_i \right)^2$$

这个经典的代数化简表明：我们只需要同时关注序列的**平方和 $\sum a_i^2$** 与**一次和 $\sum a_i$**。

#### 2. 操作本质：差分序列的邻项交换

考察原序列的差分数组 $d_i = a_{i+1} - a_i$（$1 \le i \le n-1$）。
当对位置 $i$ 进行操作 $a_i \to a_{i-1} + a_{i+1} - a_i$ 时：
- 新的差分 $d'_{i-1} = a'_i - a_{i-1} = (a_{i-1} + a_{i+1} - a_i) - a_{i-1} = a_{i+1} - a_i = d_i$；
- 新的差分 $d'_i = a_{i+1} - a'_i = a_{i+1} - (a_{i-1} + a_{i+1} - a_i) = a_i - a_{i-1} = d_{i-1}$；
- 其余位置的差分保持完全不变。

**核心结论**：对 $a_i$ 进行一次变换，严格等价于**交换差分数组中相邻的两项 $d_{i-1}$ 与 $d_i$**！
因为相邻两项交换可以生成集合的任意排列，所以该操作的本质就是：**允许将差分多重集 $\{d_1, d_2, \dots, d_{n-1}\}$ 任意重新排列**。

#### 3. 差分的单谷序贪心性质

什么样的差分排列能使方差最小？
直观而言，方差度量的是数据偏离平均值的离散程度；要使方差最小，序列各元素应当尽可能紧密地向平均值聚集。
换句话说，序列应该在中间变化缓慢（差分小）、在两端变化剧烈（差分大）。
在数学上可以通过相邻差分交换的反证法严格论证：**在最优解中，差分数组必须呈现“先单调递减、后单调递增”的单谷形态（Single-valley / U-shape）**。

因此，如果我们将所有差分从小到大排序，那么对于每一个差分，它在最终序列中的归宿只有两种可能：
- 放在当前已有序列的最左端（构筑单谷的递减左半段）；
- 或者放在当前已有序列的最右端（构筑单谷的递增右半段）。

#### 4. 双端扩展的 0/1 背包型动态规划

由于全体加上或减去常数并不改变方差，且 $a_1$ 在操作中始终不变，我们在计算相对增量时只需以 $a_1$ 为基准（令相对起点为 $0$）。

将差分数组升序排序为 $w_1 \le w_2 \le \dots \le w_{n-1}$。
设当前已考虑了前 $i$ 个差分，并维护前缀差分和 $s_i = \sum_{k=1}^i w_k$（即右端点当前的相对高度）。
若设 $f[j]$ 表示当前已放置元素之和为 $j$ 时，能够达到的**最小平方和 $\sum x^2$**。

当加入第 $i$ 个差分 $w_i$ 时，由于 $w_i$ 是当前未放置差分中最大的一个，我们决策将其放在最右侧或最左侧：
1. **决策一：放入最右端**
   在当前序列的最右侧新增一个数，其数值恰好等于当前已放入差分的总和 $s_i$。
   - 元素和增加 $s_i$，变为 $j + s_i$；
   - 平方和增加 $s_i^2$；
   - 转移方程：$g[j + s_i] = \min(g[j + s_i], \; f[j] + s_i^2)$。
2. **决策二：放入最左端**
   相当于在最左端补入一个相对零点，而此前已经放好的前 $i$ 个数整体向右平移了 $w_i$（即已有的 $i$ 个数每个数都加上了 $w_i$）。
   - 元素和增加 $i \cdot w_i$，变为 $j + i \cdot w_i$；
   - 平方和的增量利用完全平方展开：
     $$\sum_{k=1}^i (x_k + w_i)^2 - \sum_{k=1}^i x_k^2 = \sum_{k=1}^i (2 x_k w_i + w_i^2) = 2 w_i \sum_{k=1}^i x_k + i w_i^2 = 2 w_i j + i w_i^2$$
   - 转移方程：$g[j + i \cdot w_i] = \min(g[j + i \cdot w_i], \; f[j] + 2 w_i j + i w_i^2)$。

#### 5. 状态剪枝与空间滚动

- **值域边界**：由于各数最大为 $a_n \le 600$，总和 $j \le n \cdot a_n \le 6 \times 10^5$。
- **零差分剪枝**：若 $w_i = 0$（存在相邻相同数），其并不提供任何高度差，直接跳过即可。
- **空间优化**：外层枚举差分，内层和的维度使用交替滚动数组 $f[2][MAXM]$，极大节省内存。
- 最终遍历所有可能的总和 $j$，取 $\min_j (n \cdot f[j] - j^2)$ 作为答案。

### 复杂度

- **时间复杂度**：
  - 差分排序：$O(n \log n)$；
  - 动态规划：有效非零差分个数不超过 $\min(n, \max a_i) \le 600$。和的上限为 $n \cdot a_n$。在最坏情况下运算量约为 $600 \times 600 \times 400 \approx 1.4 \times 10^8$ 次，配合 `chkmin` 常数极小，耗时约 $0.2\text{s}$。
- **空间复杂度**：
  - 使用两行的滚动数组 $f[2][MAXM]$，状态维度为 $2 \times 600000$ 的 64 位长整型，内存占用约 $9.6\text{MB}$，远低于 512MB 限制。

## 总结

本题是差分技巧与单谷序构造结合的巅峰之作。解题的关键突破在于**将看似无法下手的局部平滑操作，通过差分映射为全局置换群的邻项交换**；进而通过方差的几何离散性质断定差分的单谷分布形态，将 $O(n!)$ 的全排列搜索瞬间降解为从小到大向两端放置的 $O(n \cdot \sum a)$ 背包型动态规划。

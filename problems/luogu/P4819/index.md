## 形式化题目

给定有向图 $G=(V,E)$，$|V|=N$。存在唯一杀手顶点 $k$（均匀随机分布在 $N$ 个点中）。

警察可询问任意顶点 $u$：
- 若 $u=k$，警察被杀，任务失败。
- 若 $u\neq k$，警察安全获得 $u$ 所有直接出邻居的身份信息。

目标：在不询问杀手的前提下，最大化「确定杀手身份」的概率。

### 一个容易误解的地方：信息是传递的

题面只说「告诉警察他认识的人」，很容易被理解为「警察只能得知 $u$ 的直接出邻居的身份」。
但实际含义是：**一旦得知某人是平民，就可以继续安全查证那个人**，从而获取他的直接出邻居的信息。

例如 $a \to b \to c$：

1. 查证 $a$（是平民）→ 得知 $b$ 的身份。
2. 若 $b$ 也是平民 → **继续查证 $b$** → 得知 $c$ 的身份。
3. 若 $b$ 是杀手 → 已经知道 $b$ 是杀手了，无需查证 $b$，但 $c$ 的身份仍未知。

所以信息是沿有向边传递的：虽然 $a$ 不直接「认识」$c$，但通过 $b$ 中转后可以知道 $c$ 的身份。如果只允许直接认识，那除入度为 0 的点以外，其他人的信息永远无法获得，答案恒为 0，显然不合理。

这个传递性正是下文 SCC 建模的基础：同一个强连通分量内互相可达，查证其中任何一个平民即可覆盖整个分量。

## 正解

### 思路

本题核心在于信息传递与安全询问的建模。

1. **强连通分量内的信息共享**：若 $u,v$ 属于同一 SCC，则从其中任意一个平民出发，都能通过出边安全遍历整个分量。因此每个 SCC 可视为一个「超级节点」，询问一次即可覆盖整个分量。

2. **缩点后形成 DAG**：Tarjan 求出所有 SCC 并缩点，得到一张 DAG。信息只能沿拓扑方向单向流动。

3. **必须询问的集合**：在 DAG 上，要获知某个 SCC 的身份，必须存在一条从「已询问点」出发的安全路径。对于入度为 0 的 SCC，没有外部安全来源，因此必须直接询问其中任意一个点。记入度为 0 的 SCC 数量为 $cnt$。

4. **排除法特例**：题目保证恰有一个杀手。若已安全获知 $N-1$ 个人的身份均为平民，则最后一个必然是杀手，无需冒险询问。在缩点语义下，这要求存在一个入度为 0 且 $\text{size}=1$ 的 SCC $S$，其所有直接后继 SCC 的入度都 $\ge 2$（即它们至少还有其他入边来源）。此时 $S$ 可以省略询问：
   - 若杀手在其他必须询问的 SCC 中，$S$ 自然是平民。
   - 若其他 SCC 均非杀手，则杀手只能是 $S$。
   这种可省略的情况至多发生一次（只有一个杀手），且仅当 $cnt>1$ 时才真正减少必须询问次数。

5. **概率计算**：必须冒险询问的次数为 $must$（初始为 $cnt$，可能减 1）。安全概率为 $1 - \dfrac{must}{N}$。

### 复杂度

- 时间：Tarjan $O(N+M)$，建 DAG 与统计 $O(N+M)$，总 $O(N+M)$。

## 总结

本题通过 Tarjan 缩点将「询问一个点覆盖整个 SCC」这一性质转化为 DAG 上的「覆盖所有入度为 0 的超级节点」。在此基础上，利用「恰有一个杀手」这一全局约束，识别出可以利用排除法省略询问的 size=1 入度 0 分量，最终得到最优安全概率。算法线性时间，正确性基于 SCC 信息共享与 DAG 拓扑覆盖。

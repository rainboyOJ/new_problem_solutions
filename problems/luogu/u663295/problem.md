# U663295 疯狂的背包问题(2) - 01背包问题（可行性问题）
## 题目背景

动态规划问题中的 01 背包问题模板题，本题考察的是**可行性判断**而非最优价值。

## 题目描述

有 $N$ 件物品和一个容量是 $V$ 的背包。每件物品只能使用一次。

第 $i$ 件物品的体积是 $v_i$。

现需要判断：是否存在一种选择物品的方案，使得**恰好装满**背包（即所选物品的总体积**等于** $V$）？

## 输入格式

第一行两个整数 $N$，$V$，用空格隔开，分别表示物品数量和背包容积。

接下来有 $N$ 行，每行一个整数 $v_i$，表示第 $i$ 件物品的体积。

## 输出格式

如果存在一种方案可以恰好装满背包，输出 `true`；否则输出 `false`。

## 输入输出样例 #1

### 输入 #1

```
3 7
2
4
9
```

### 输出 #1

```
false
```

## 输入输出样例 #2

### 输入 #2

```
4 5
1
2
3
4
```

### 输出 #2

```
true
```

## 说明/提示

**数据范围**
* $0 < N, V \leq 10^3$
* $0 < v_i \leq 10^3$

**注意**：本题只要求判断可行性，不涉及物品价值。

### 题意

为一组

$$
x_c - x_{c'} \le y
$$

形式的不等式求任意可行解，或判断无解。约束只比较两个变量的差，所以对一组解整体加减同一个常数仍然合法，答案不唯一。

### 思路

不等式等价于 $x_c \le x_{c'} + y$，把它读成一条边 $c' \to c$、权 $y$。于是本题要求的其实就是一组数 $\text{dis}$，使每条边都满足

$$
\text{dis}[v] \le \text{dis}[u] + w
$$

注意 $\text{dis}$ 在这里**不是**“某个源点到 $u$ 的最短路”，它就是待求的 $x_u$ 本身；判定标准里没有源点，只有边。

#### 初值可以随便取

约束只比较差值，把一组解整体加同一个常数仍然合法，所以解有无穷多组。松弛做的事是：只要某条边违反 $x_v \le x_u + w$，就把 $x_v$ 改小到 $x_u + w$，然后重复，直到改不动为止。

因此初值只决定最后落在解集的哪个位置，不影响合法性。同一组样例换初值，收敛到的解整体平移，但都合法：

| 初值 | 收敛结果 |
| --- | --- |
| $(0,0,0)$ | $(0,-2,0)$ |
| $(5,5,5)$ | $(5,3,5)$ |
| $(1,2,3)$ | $(1,1,3)$ |

唯一的限制是初值必须**有限**：`INF` 表示“还没决定”，保持 `INF` 的点根本不会被比较，输出就是无效的。所以最省事的做法是全部置 $0$。

#### 为什么是所有点入队，而不是挑一个起点

把每个点的初值取 $0$ 并全部入队，等价于加一个到所有点都是 $0$ 权边的超级源点，只是省掉了那个虚拟点。

不能只挑一个点出发。例如约束 $x_2 - x_1 \le -5$ 对应边 $1 \to 2$、权 $-5$：

- 从 $1$ 号点出发，能松弛到 $2$，得到 `0 -5`，合法；
- 只从 $2$ 号点出发，$1$ 号点收不到任何松弛，输出 `0 0`，而 $x_2 - x_1 = 0 > -5$，不合法。

所以“每个弱连通块挑一个点”也不行：**弱连通不等于有向可达**，边方向一旦反过来，挑中的起点就到不了另一端。全部入队对任何边方向都成立。

#### 队列空就等于全部满足

松弛只会让 $\text{dis}$ 变小，从不增大。队列为空意味着每个点都“最后被扫过一次”，且那次扫描时它的所有出边都不可改善；此后它的值也不会再变。于是每条边都在起点的终值下被验证过，终态必然满足全部约束。

反过来，如果存在负环，沿环可以无限把值改小，队列永远清不空。实现上用“最短路径边数达到 $n$”来检测：走得比 $n-1$ 条还多，路径上必然绕出了负环。此时约束自相矛盾，输出 `NO`；否则 $\text{dis}[1..n]$ 就是答案。

### 建边方向

| 题面写法 | 归一为 $\le$ | 建边 |
| --- | --- | --- |
| $x_c - x_{c'} \le y$ | 不变 | $c' \to c$ 权 $y$ |
| $x_c - x_{c'} \ge y$ | $x_{c'} - x_c \le -y$ | $c \to c'$ 权 $-y$ |
| $x_c = x_{c'}$ | 两个方向各一条 $0$ 权边 | $c \to c'$ 与 $c' \to c$ 权 $0$ |

本题只有第一种，直接调用 `add_leq(c', c, y)` 即可。

### 复杂度

`feasible()` 只跑一次 SPFA，最坏 $O(nm)$，空间 $O(n+m)$。本题 $n,m \le 5 \times 10^3$，足够。

### Python 知识

- `type WeightedAdj = list[list[tuple[int, int]]]` 给邻接表起别名，读的时候不用反复展开嵌套泛型。
- `deque(range(1, n+1))` 一次把所有点按编号入队，正好是"超级源连 0 权边"的初始状态。
- `sys.stdin.buffer.read().split()` 批量读入再按 `3*i` 偏移切分，避免逐行 `input()` 的开销。
- `dis` 会被重新赋值而不是原地清空，所以 `feasible()` 结束后直接读 `self.dis[1:]` 就是解。

### 对拍

`gen.py` 一半生成随机边（容易造出负环），一半先取一组真解再反推边权（保证有解）；`brute.cpp` 直接枚举 $x_i$ 取值并检查约束，用来自动核对 `main.cpp` 与 `main.py` 的输出是否满足全部不等式。

### 总结

差分约束的建边方向来自把不等式写成一次松弛公式：$x_v \le x_u + w$ 对应 $u \to v$ 权 $w$。跑最短路得到的是所有差值上界里最紧的那一组，它同时是解；负环则是"上界可以无限收缩"的表现，即无解。

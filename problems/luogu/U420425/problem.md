# U420425 线段树二分 2
## 题目背景

发现没有这种板子题于是自己就补上了

## 题目描述

如题，已知一个数列，你需要进行下面两种操作：

1. 将某区间每一个数加上 $k$。
2. 求出某区间每一个数的和。
3. 求出区间 $[l,r]$ 内第一个不符合前缀和小于 $d$ 的下标,若都符合则输出 $r + 1$ (实际上就是模拟 $std$ 的 lower_bound 函数)
4. 将某个点赋值为 $d$

## 输入格式

第一行包含两个整数 $n, m$，分别表示该数列数字的个数和操作的总个数。

第二行包含 $n$ 个用空格分隔的整数，其中第 $i$ 个数字表示数列第 $i$ 项的初始值。

接下来 $m$ 行每行包含 $2$ 或 $3$ 或 $4$ 个整数，表示一个操作，具体如下：

1. `1 x y k`：将区间 $[x, y]$ 内每个数加上 $k$。
2. `2 x y`：输出区间 $[x, y]$ 内每个数的和。
3. `3 x y d`：输出二分区间 $[x, y]$ 内第一个不符合小于 $d$ 的下标。若都符合则输出 $y + 1$。
4. `4 x d`：将下标 $x$ 赋值为 d

## 输出格式

输出包含若干行整数，即为所有操作 2 3 的结果。

## 输入输出样例 #1

### 输入 #1

```
5 8
1 5 4 2 3
2 2 4
1 2 3 2
2 3 4
1 1 5 1
2 1 4
3 1 5 6
4 2 15
3 2 4 25
```

### 输出 #1

```
11
8
20
2
4
```

## 说明/提示

对于 $100\%$ 的数据：$1 \le n, m, d \le 1\times{10}^6$。

保证任意时刻数列中所有元素的绝对值之和 $\le {10}^{18}$。

$1$ 和 $2$ 操作与线段树一 一致,详情见线段树一模板题,
前面的操作以后序列变为:

$[2, 8, 7, 3, 4]$

区间 $[1, 5]$ 的前缀和为:

$[2, 10, 17, 20, 24]$


样例中的 $3$ 操作 要求找出前缀和第一个不符合则是第二个, 所以输出 $2$

样例中的 $4$ 操作以后 :

$[2, 15, 7, 3, 4]$

区间 $[2, 4]$ 的前缀和为:

$[15, 22, 25]$

则二分的结果为 $25$ 也就是第四个的下标

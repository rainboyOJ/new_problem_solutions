### 题意

给定两个长度为 $N$ 的数组 `a` 和 `b`。

必须恰好选择一个区间 `[l,r]`，把 `a[l..r]` 反转一次。反转后，如果某个位置满足 `a[i] == b[i]`，这头奶牛就能被体检。

对每个 $c=0,1,\ldots,N$，求有多少个反转操作 `(l,r)` 会让恰好 $c$ 头奶牛被体检。

### 思路

先看一个直接模拟的暴力：

@include-code(./brute.cpp, cpp)

这个暴力枚举每个区间 `[l,r]`，再完整计算反转后的匹配数量。它很直观，但复杂度是 $O(N^3)$。

先计算不反转时的匹配数量，记为 `base_match`。

反转一个区间时，区间外的位置不变。区间内的反转，可以看成左右端点不断交换：

```text
l 与 r 交换
l+1 与 r-1 交换
...
```

所以我们按中心向外扩展区间。

当区间从 `[l+1,r-1]` 扩展成 `[l,r]` 时，只有端点 `l` 和 `r` 的贡献发生变化：

```text
原贡献： (a[l] == b[l]) + (a[r] == b[r])
新贡献： (a[l] == b[r]) + (a[r] == b[l])
```

把原贡献减掉，把新贡献加上，就能 $O(1)$ 得到当前区间反转后的匹配数。

所有区间分为两类中心：

- 奇数长度：从 `(mid, mid)` 向外扩展。
- 偶数长度：从 `(mid, mid+1)` 向外扩展。

每个反转区间都有唯一中心，因此会被恰好统计一次。

### 复杂度

所有反转区间共有 $O(N^2)$ 个，每个区间只做 $O(1)$ 更新。

时间复杂度为 $O(N^2)$，空间复杂度为 $O(N)$。

### 总结

本题的关键是不要每次重新反转并完整统计，而是把反转看成从中心向外的一系列交换。

扩展一层只影响两个端点，匹配数可以常数时间更新。

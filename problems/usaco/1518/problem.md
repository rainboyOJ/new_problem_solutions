# 1518 Sequence Construction

## 赛事信息

USACO 2025 US Open Contest, Silver

## 题目描述

最近，Farmer John 农场上的奶牛们迷上了观看番剧《药屋奶牛的呢喃》。这个节目围绕着一位聪明的奶牛侦探牛牛解决各种问题。Bessie 从番剧中得到了一个新问题，但答案要等到下周播出下一集才会揭晓！请帮助她解决这个问题。
给定整数 $M$ 和 $K$（$1 \leq M \leq 10 ^ 9$，$1 \leq K \leq 31$）。请选择一个正整数 $N$ 并构造一个序列 $a$，包含 $N$ 个非负整数，满足以下条件：
- $1 \le N \le 100$
- $a_1 + a_2 + \dots + a_N = M$
- $\text{popcount}(a_1) \oplus \text{ popcount}(a_2) \oplus \dots \oplus \text{ popcount}(a_N) = K$
如果不存在这样的序列，输出 $-1$。
$\dagger \text{ popcount}(x)$ 是整数 $x$ 的二进制表示中等于 $1$ 的数位数量。例如，$11$ 的 popcount 是 $3$，$16$ 的 popcount 是 $1$。
$\dagger \oplus$ 是按位异或运算符。
输入将包含 $T$（$1 \le T \le 5 \cdot 10^3$）个独立的测试用例。

## 输入格式

输入的第一行包含 $T$。
每一个测试用例包含一行，包含 $M$ 和 $K$。
输入保证所有测试用例各不相同。

## 输出格式

按以下格式输出 $T$ 个测试用例的结果：
如果不存在答案，该测试用例输出一行，包含 $-1$。
否则，该测试用例输出的第一行包含一个整数 $N$，表示序列的长度——（$1 \le N \le 100$）。
该测试用例输出的第二行包含 $N$ 个空格分隔的整数，满足题目条件——（$0 \le a_i \le M$）。

## 输入输出样例 #1

### 输入 #1

```
3
2 1
33 5
10 5
```

### 输出 #1

```
2
2 0
3
3 23 7
-1
```

## 样例说明

在第一个测试用例中，数组 $a = [2, 0]$ 的元素之和为 $2$。popcount 的异或和为 $1 \oplus 0 = 1$。因此，所有条件都被满足。
在第二个测试用例中，数组 $a = [3, 23, 7]$ 的元素之和为 $33$。popcount 的异或和为 $2 \oplus 4 \oplus 3 = 5$。因此，所有条件都被满足。
其他合法的数组如 $a = [4, 2, 15, 5, 7]$ 和 $a = [1, 4, 0, 27, 1]$。
对于第三个测试用例，可以证明不存在合法的数组。

## 测试点性质

- 测试点 2：$M \leq 8$，$K \leq 8$。
- 测试点 3-5：$M > 2^K$。
- 测试点 6-18：没有额外限制。

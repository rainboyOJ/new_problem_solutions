### 题意

给定若干条由 `N/E/S/W` 组成的闭合栅栏路径。路径不自交，只在最后回到起点。

判断按字符串顺序沿着栅栏走时，围住的区域在右侧还是左侧；右侧输出 `CW`，左侧输出 `CCW`。

### 思路

#### 用有向面积校验

一个常见做法是按路径走出坐标点，再用多边形有向面积判断方向：

@include-code(./brute.cpp, cpp)

在通常坐标系下，有向面积为正表示逆时针，为负表示顺时针。

#### 累计转角

官方解析的思路是：顺时针路径整体更倾向于右转，逆时针路径整体更倾向于左转。

把方向编号为：

```text
E = 0, N = 1, W = 2, S = 3
```

相邻两段边形成一个转角：

- 左转贡献 `+1`；
- 右转贡献 `-1`；
- 直行贡献 `0`。

沿简单闭合曲线走一圈，如果整体是逆时针，总转角为 $+360^\circ$；如果整体是顺时针，总转角为 $-360^\circ$。

因此只需要比较每一对相邻方向：

```text
s[i] -> s[(i + 1) % len]
```

最后如果 `total_turn > 0`，输出 `CCW`；否则输出 `CW`。

以 `NESW` 为例：

```text
N -> E 右转
E -> S 右转
S -> W 右转
W -> N 右转
```

总转角为负，所以是 `CW`。

### 复杂度

每条路径扫描一遍，时间复杂度为 $O(L)$，其中 $L$ 是路径长度。

只使用常数个变量，额外空间复杂度为 $O(1)$。

### 总结

这题的关键是把“顺时针/逆时针”转化成局部转向的总和。

只要路径是简单闭合曲线，绕一圈后的总转角正负就能唯一确定方向。

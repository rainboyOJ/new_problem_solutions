# Binary Search on a Segment Tree

## 题目描述

给定一个长度为 $N$ 的非负整数序列 $A=(A_1,A_2,\ldots,A_N)$。

接下来处理 $Q$ 个查询，每个查询属于以下 $3$ 种类型之一：

- `1 i x`：将 $A_i$ 修改为 $x$。

- `2 l t`：在满足 $\displaystyle \sum_{i=l}^{r} A_i \geq t$ 的整数中，找出不小于 $l$ 且不大于 $N$ 的最小值 $r$ 并输出。如果不存在这样的 $r$，输出 $N+1$。

- `3 r t`：在满足 $\displaystyle \sum_{i=l}^{r} A_i \geq t$ 的整数中，找出不小于 $1$ 且不大于 $r$ 的最大值 $l$ 并输出。如果不存在这样的 $l$，输出 $0$。

## 约束

- $1 \leq N \leq 2 \times 10^5$

- $1 \leq Q \leq 2 \times 10^5$

- $0 \leq A_i \leq 10^9$

- 对于 $1$ 类查询，$1 \leq i \leq N$，$0 \leq x \leq 10^9$

- 对于 $2$ 类查询，$1 \leq l \leq N$，$1 \leq t \leq 10^{15}$

- 对于 $3$ 类查询，$1 \leq r \leq N$，$1 \leq t \leq 10^{15}$

- 输入中的所有数值均为整数。

## 输入格式

输入通过标准输入给出，格式如下：

```
$N$ $Q$
$A_1$ $A_2$ $\ldots$ $A_N$
$\mathrm{query}_1$
$\mathrm{query}_2$
$\vdots$
$\mathrm{query}_Q$
```

每个查询的格式如下：

```
$1$ $i$ $x$
```

```
$2$ $l$ $t$
```

```
$3$ $r$ $t$
```

## 输出格式

设类型为 $2$ 和 $3$ 的查询总数为 $q$。输出 $q$ 行。第 $j$ 行应包含按输入顺序排列的、这些查询中第 $j$ 个查询的答案。

## 输入输出样例 #1

### 输入 #1

```
5 8
2 1 3 0 4
2 2 4
3 5 5
1 3 1
2 2 4
3 5 5
2 4 5
3 2 4
2 1 2
```

### 输出 #1

```
3
3
5
3
6
0
1
```

## 输入输出样例 #2

### 输入 #2

```
1 6
0
2 1 1
3 1 1
1 1 1000000000
2 1 1000000000
3 1 1000000000
2 1 1000000000000000
```

### 输出 #2

```
2
0
1
1
2
```

## 样例说明

对于查询 $1$，$A_2=1 \lt 4$，而 $A_2+A_3=4$，所以输出 $3$。

对于查询 $2$，$A_3+A_4+A_5=7$，而 $A_4+A_5=4$，所以输出 $3$。

查询 $3$ 将 $A$ 修改为 $(2,1,1,0,4)$。

对于查询 $4$，$A_2+A_3+A_4=2 \lt 4$，而 $A_2+A_3+A_4+A_5=6$，所以输出 $5$。

对于查询 $5$，$A_4+A_5=4 \lt 5$，而 $A_3+A_4+A_5=5$，所以输出 $3$。

对于查询 $6$，$A_4+A_5=4 \lt 5$，并且没有 $r$ 满足条件，所以输出 $6$。

对于查询 $7$，$A_1+A_2=3 \lt 4$，并且没有 $l$ 满足条件，所以输出 $0$。

对于查询 $8$，$A_1=2$，所以输出 $1$。

# Maximize Rating

## 题目描述

高桥参加了 $N$ 场比赛，第 $i$ 场比赛的表现得分是 $P_i$。**
他想从这些比赛中挑选一些（至少一场）来最大化他根据这些比赛成绩计算出的评分。

请找出他通过最优选择比赛能获得的最高评分。

这里，高桥的评分 $R$ 按照下面的公式计算，其中 $k$ 是选中比赛的数量，$(Q_1, Q_2, \ldots, Q_k)$ 是选中比赛的表现得分，且**顺序保持他参加比赛的先后顺序**：

$\displaystyle R=\frac{\sum_{i=1}^k (0.9)^{k-i}Q_i}{\sum_{i=1}^k (0.9)^{k-i}}-\frac{1200}{\sqrt{k}}.$

## 约束

- $1\leq N\leq 5000$

- $1\leq P_i\leq 5000$

- 所有输入值均为整数。

## 输入格式

输入通过标准输入给出，格式如下：

```
$N$
$P_1$ $P_2$ $\ldots$ $P_N$
```

## 输出格式

输出高桥能获得的最大评分。**
如果你的输出与正确答案的绝对误差或相对误差不超过 $10^{-6}$，则视为正确。

## 输入输出样例 #1

### 输入 #1

```
3
1000 600 1200
```

### 输出 #1

```
256.735020470879931
```

## 输入输出样例 #2

### 输入 #2

```
3
600 1000 1200
```

### 输出 #2

```
261.423219407873376
```

## 输入输出样例 #3

### 输入 #3

```
1
100
```

### 输出 #3

```
-1100.000000000000000
```

## 样例说明

如果高桥选择第一场和第三场比赛，他的评分是：

$\displaystyle R=\frac{0.9\times 1000+ 1.0\times 1200}{0.9+1.0}-\frac{1200}{\sqrt{2}}=256.73502...$。

这是最高的评分了。

当选择第一、第二和第三场比赛时，评分最大。

评分也可能是负数哦。

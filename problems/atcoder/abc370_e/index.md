## 形式化题目

给定长度为 $N$ 的整数序列 $A = (A_1, A_2, \dots, A_N)$ 以及目标整数 $K$。

我们要在序列中放置若干个隔板，将其划分为若干个连续非空子段：
1. 划分操作：选择单调递增的下标序列 $1 = i_1 < i_2 < \dots < i_k < i_{k+1} = N+1$，其中第 $n$ 个子段为 $A[i_n \dots i_{n+1}-1]$；
2. 合法条件：任意子段的元素之和均不等于 $K$，即对所有 $1 \le n \le k$，满足 $\sum_{t=i_n}^{i_{n+1}-1} A_t \ne K$。

求满足条件的划分方案数，结果对 $998244353$ 取模。

## 暴力解法

### 思路

!!! info 01 序列枚举隔板放置方案，逐段求和校验。
序列中共有 $N-1$ 个相邻元素的间隙，每个间隙只有“切一刀（放隔板，记为 1）”或“不切（记为 0）”两种决策。使用深度优先搜索生成长度为 $N-1$ 的 01 序列，到达叶子节点后切分序列，只要发现某段元素和恰好等于 $K$ 即判定该划分非法；否则累加合法方案数。
!!!

将一个长度为 $N$ 的序列划分成连续子段，本质是在 $N-1$ 个相邻元素之间做决策。

我们用数组 `b[i]` 记录第 $i$ 个数与第 $i+1$ 个数之间是否放置隔板：
- `b[i] = 1` 表示在该位置切开；
- `b[i] = 0` 表示保持连续。

通过 `dfs(dep)` 递归枚举 `b[1 \dots N-1]` 的全部可能取值，共生成 $2^{N-1}$ 种不同的 01 序列。当递归到达第 $N$ 层时，利用 `check()` 沿序列从左到右累加当前段的和：一旦遇到切分点（或到达序列末尾），检查该段和是否等于 $K$。若等于 $K$ 则直接判定该方案非法；只有所有分段的和均不为 $K$ 时才计入答案。

- 时间复杂度：遍历所有划分方案需 $O(2^{N-1})$，每次校验序列需要 $O(N)$，总时间复杂度为 $O(N \cdot 2^{N-1})$。

### 瓶颈

01 序列的搜索树是指数级的。但划分有前缀无后效性：向后扩展时只关心**最后一段**从哪开始、和为多少，前 $i$ 个数内部怎么切并不影响后续。

## 朴素 DP

### 思路

!!! info 以“前缀划分方案数”为状态，枚举最后一段的起点转移。
设 $f[i]$ 为前缀 $A[1 \dots i]$ 的合法划分数，$f[0]=1$。枚举最后一段 $[j+1, i]$，用前缀和把段和写成 $pre[i]-pre[j]$，只要它不等于 $K$ 就可以把 $f[j]$ 累加进 $f[i]$。状态数 $N$，每次转移枚举 $N$ 个断点，总 $O(N^2)$。
!!!

把“整体划分”改成“前缀划分”：设 $f[i]$ 表示前缀 $A[1 \dots i]$ 的合法划分数，$f[0] = 1$。枚举最后一段 $[j+1, i]$，用前缀和 $pre[i]$ 把段和写成 $pre[i] - pre[j]$（$pre[0]=0$），只要它不等于 $K$ 就能把 $f[j]$ 计入 $f[i]$：

$$f[i] = \sum_{0 \le j < i,\ pre[i] - pre[j] \ne K} f[j]$$

### 复杂度与瓶颈

- 时间复杂度：状态数 $N$，每个状态的转移枚举全部 $j < i$，总时间复杂度为 $O(N^2)$，只能应付 $N \lesssim 5000$。
- 空间复杂度：前缀和与 $f$ 数组各 $O(N)$。

瓶颈在内层：枚举所有 $j$ 并逐个判断 $pre[i]-pre[j] \ne K$。但这个判断只排除了 $pre[j] = pre[i]-K$ 的那些 $j$，剩下的 $j$ 全都参与累加。所以内层循环可以被“整体求和减去一小撮”替代。

## 正解

### 思路

!!! info 线性 DP 结合补集转化，滚动前缀和维护总方案，map 分桶剔除非法断点。
在朴素 DP 的转移 $f[i] = \sum_{j < i,\ pre[i]-pre[j] \ne K} f[j]$ 上做补集转化：把“所有 $j < i$ 的 $f[j]$ 之和”与“$pre[j] = pre[i]-K$ 的那部分之和”分开，后者用 `map` 按前缀和分桶维护。单次转移只剩一次 $O(\log N)$ 的查表，总复杂度降到 $O(N \log N)$。
!!!

把转移里的条件翻过来看。所有 $j < i$ 的 $f[j]$ 本可以全部累加，唯独让最后一段和等于 $K$、即 $pre[j] = pre[i] - K$ 的那些断点要剔除。于是

$$f[i] = \sum_{j=0}^{i-1} f[j] \;-\; \sum_{0 \le j < i,\ pre[j] = pre[i]-K} f[j]$$

两个求和项都能在线维护：令 $S$ 为已求出的所有 $f$ 之和，`map` 类型的 $bad[x]$ 记录前缀和为 $x$ 的那些 $f$ 之和。转移就退化为一次查表：

$$f[i] = \big(S - bad[pre[i]-K]\big) \bmod 998244353$$

算得 $f[i]$ 后，把它分别记到 $S$ 和 $bad[pre[i]]$ 上，供后面的位置使用。这一步就是《黑白气球》里“固定结尾、用桶”的计数模型。

几个边界需要注意：
- **$K = 0$**：此时要排除的是 $pre[j] = pre[i]$，看似会命中自身。但 $f[i]$ 是在算出之后才写进 $bad[pre[i]]$ 的，查表时桶里只有 $j < i$ 的历史项，不会减掉自己。
- **负数取模**：减法可能得负数，写成 `(S - bad_val + mod) % mod`。
- **前缀和用 `long long`**：$pre[i]$ 最大约 $2 \times 10^{14}$，必须 64 位，否则溢出。

## 总结

本题的关键在于两层思维转化：
1. **子问题表示**：将整体组合切分转化为前缀划分 DP，以最后一段的起点作为决策点；
2. **正难则反与分桶加速**：段和限制 $pre[i] - pre[j] \ne K$ 难以直接连续求和，但其补集 $pre[j] = pre[i] - K$ 是明确的点对匹配。利用前缀和将区间属性转化为端点属性，结合滚动总和与按前缀和分组的 `map`，成功将 $O(N^2)$ 的转移降为每次 $O(\log N)$。

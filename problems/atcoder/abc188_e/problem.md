# Peddler

## 题目描述

在高桥王国中，有$N$个城镇，分别称为城镇$1$到城镇$N$。**
王国中还有$M$条道路，分别称为道路$1$到道路$M$。通过道路$i$，你可以从城镇$X_i$前往城镇$Y_i$，但反之则不行。在这里，保证$X_i < Y_i$。**
在这个王国中，黄金交易十分活跃。在城镇$i$，你可以以$A_i$日元的价格购买或出售$1$千克黄金。

旅行推销员高桥计划在某个城镇购买$1$千克黄金，经过一条或多条道路，然后在另一个城镇出售$1$千克黄金。**
请找出这个计划中可能的最大利润（即出售价格减去购买价格）。

## 限制条件

- $2 \le N \le 2 \times 10^5$

- $1 \le M \le 2 \times 10^5$

- $1 \le A_i \le 10^9$

- $1 \le X_i \lt Y_i \le N$

- $(X_i, Y_i) \neq (X_j, Y_j) (i \neq j)$

- 输入中的所有值均为整数。

## 输入格式

输入以以下格式从标准输入给出：

```
$N$ $M$
$A_1$ $A_2$ $A_3$ $\dots$ $A_N$
$X_1$ $Y_1$
$X_2$ $Y_2$
$X_3$ $Y_3$
$\hspace{15pt} \vdots$
$X_M$ $Y_M$
```

## 输出格式

输出答案。

## 输入输出样例 #1

### 输入 #1

```
4 3
2 3 1 5
2 4
1 2
1 3
```

### 输出 #1

```
3
```

## 输入输出样例 #2

### 输入 #2

```
5 5
13 8 3 15 18
2 4
1 2
4 5
2 3
1 3
```

### 输出 #2

```
10
```

## 输入输出样例 #3

### 输入 #3

```
3 1
1 100 1
2 3
```

### 输出 #3

```
-99
```

## 样例说明

我们可以获得$3$日元的利润，具体如下：

- 在城镇$1$购买一千克黄金，价格为$2$日元。

- 经过道路$2$到达城镇$2$。

- 经过道路$1$到达城镇$4$。

- 在城镇$4$出售一千克黄金，价格为$5$日元。

我们可以获得$10$日元的利润，具体如下：

- 在城镇$2$购买一千克黄金，价格为$8$日元。

- 经过道路$1$到达城镇$4$。

- 经过道路$3$到达城镇$5$。

- 在城镇$5$出售一千克黄金，价格为$18$日元。

请注意，我们不能在购买黄金的城镇出售黄金，这意味着答案可能为负数。

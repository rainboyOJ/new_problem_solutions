# Toward 0

## 题目描述

给定一个整数$N$。你可以执行以下两种操作：

- 支付$X$日元，将$N$替换为$\displaystyle\left\lfloor\frac{N}{A}\right\rfloor$。

- 支付$Y$日元，投掷一个骰子（骰子会等概率显示$1$到$6$之间的整数）。设骰子结果为$b$，将$N$替换为$\displaystyle\left\lfloor\frac{N}{b}\right\rfloor$。

其中$\lfloor s \rfloor$表示小于等于$s$的最大整数。例如：$\lfloor 3 \rfloor=3$和$\lfloor 2.5 \rfloor=2$。

在最优选择操作的情况下，求使$N$变为$0$所需支付的最小期望成本。**
每次掷骰子的结果相互独立，且可以根据之前操作的结果动态选择后续操作。

## 约束

- $1 \leq N \leq 10^{18}$

- $2 \leq A \leq 6$

- $1 \leq X, Y \leq 10^9$

- 所有输入值均为整数。

## 输入格式

输入通过标准输入给出，格式如下：

```
$N$ $A$ $X$ $Y$
```

## 输出要求

输出答案。**
当你的输出与真实答案的绝对误差或相对误差不超过$10^{-6}$时，将被视为正确。

## 输入输出样例 #1

### 输入 #1

```

```

### 输出 #1

```
20.000000000000000
```

## 输入输出样例 #2

### 输入 #2

```
3 2 20 20
```

### 输出 #2

```
32.000000000000000
```

### 输入 #3


## 样例说明

可选操作如下：

- 支付$10$日元，将$N$替换为$\displaystyle\left\lfloor\frac{N}{2}\right\rfloor$。

- 支付$20$日元，投掷骰子。设结果为$b$，将$N$替换为$\displaystyle\left\lfloor\frac{N}{b}\right\rfloor$。

最优策略是执行两次第一种操作。

可选操作如下：

- 支付$20$日元，将$N$替换为$\displaystyle\left\lfloor\frac{N}{2}\right\rfloor$。

- 支付$20$日元，投掷骰子。设结果为$b$，将$N$替换为$\displaystyle\left\lfloor\frac{N}{b}\right\rfloor$。

最优策略如下：

- 首先执行第二种操作掷骰子：

- 若结果≥$4$，则$N$变为$0$

- 若结果为$2$或$3$，则$N$变为$1$。此时再执行第一种操作使$N = 0$

- 若结果为$1$，则重新开始流程

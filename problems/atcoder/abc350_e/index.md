## 形式化题目

有一个整数 $n$，一开始 $n = N$。每次可以二选一：

1. 花钱除以 $A$：付 $X$ 日元，把 $n$ 换成 $\left\lfloor \dfrac{n}{A} \right\rfloor$；
2. 花钱掷骰子：付 $Y$ 日元，掷出等概率的 $b \in \{1,2,3,4,5,6\}$，把 $n$ 换成 $\left\lfloor \dfrac{n}{b} \right\rfloor$。

目标是让 $n$ 变成 $0$，求总花费的**最小平均值**（期望值）。每掷一次骰子都是独立的，并且每次操作之后都可以重新决定下一步用哪种操作。

这里的 $\lfloor s \rfloor$ 表示不超过 $s$ 的最大整数，也就是“除不尽时只留整数部分”：$\lfloor 3/2 \rfloor = 1$，$\lfloor 1/3 \rfloor = 0$。

## 预备：平均花费怎么算（脱离本题）

本节不讨论这道题，而是用几个小游戏说明“支付的最小期望成本”到底怎么求。原题的两个操作是“除以 $A$”和“除以骰子点数”，为了说得简单，这里先把它们换成一个**下台阶游戏**：当前站在第 $n$ 级台阶上，要让级数变成 $0$（地面）。看到除以几，就理解成“往下走几级”。

!!! info 给每个级数配一个“平均还要花多少钱”，摇到空摇时把它设成未知数解方程，两条路都算一遍取便宜的，最后从小的级数往大的算。
!!!

### 第一步：把运气折算成一份平均账

“平均花费”不是挑运气最好的那条路，而是把所有可能的结果统统算进去，再按出现可能性折算成一份。

第一个游戏：付 $2$ 元抛一枚硬币，正面往下走 $2$ 级，反面往下走 $1$ 级。用 $f(n)$ 表示从第 $n$ 级出发、平均还要花多少钱。已经站在地面就不用再花钱，所以 $f(0) = 0$；走多了落到地面以下也算落地，同样不用再花钱。

| 级数 $n$ | 这一步花 | 两种结果落地后分别还要花 | 平均一共 |
| --- | --- | --- | --- |
| 0 | 不用走 | 0 | 0 |
| 1 | 2 | 正面到 0 级花 0，反面也到 0 级花 0 | $2$ |
| 2 | 2 | 正面到 0 级花 0，反面到 1 级花 2 | $2 + \frac{0+2}{2} = 3$ |
| 3 | 2 | 正面到 1 级花 2，反面到 2 级花 3 | $2 + \frac{2+3}{2} = 4.5$ |
| 4 | 2 | 正面到 2 级花 3，反面到 3 级花 4.5 | $2 + \frac{3+4.5}{2} = 5.75$ |

从第 $4$ 级出发，平均要花 $5.75$ 元。这个数不是任何一次真实的花费，而是把“花 $n$ 元”的可能都按一半一半摊下来的结果。

### 第二步：摇到空摇，就把自己设成未知数

第二个游戏：付 $5$ 元掷一次骰子。摇到 $1$ 点算**空摇**——不下台阶、钱照付；摇到 $2$ 到 $6$ 点，就往下走对应的级数（超过就落地）。

麻烦在于空摇：从第 $2$ 级出发摇到 $1$ 点，还站在第 $2$ 级，等于从头再来一次。这时不能直接把 $f(2)$ 算出来，但可以先把要求的东西记成 $x = f(2)$，再把这一局的账完整写下来：

- 摇到 $1$ 点（$1/6$ 的可能），钱已经付了 $5$ 元，之后还要花 $x$；
- 摇到 $2$ 到 $6$ 点（$5/6$ 的可能），都直接落地，之后不用再花钱。

所以 $x = 5 + \frac{1}{6}x$，两边减去 $\frac{1}{6}x$ 得 $\frac{5}{6}x = 5$，于是 $x = 6$。**空摇并没有让题目无解，它只是让未知的 $x$ 出现在等式两边，移一下项就解出来了。**

| 级数 $n$ | 完整的一局账 | 解出的 $f(n)$ |
| --- | --- | --- |
| 1 | $x = 5 + \frac{1}{6}x$ | 6 |
| 2 | $x = 5 + \frac{1}{6}x$（$2$ 到 $6$ 点都落地） | 6 |
| 3 | $x = 5 + \frac{1}{6}x + \frac{1}{6}\times 6$（不空摇时最差也只到第 $1$ 级） | 7.2 |
| 4 | $x = 5 + \frac{1}{6}x + \frac{1}{6}\times(6 + 6)$（下来后可能在第 $2$ 级或第 $1$ 级） | 8.4 |

这里有个省事的算法：每摇 $6$ 次平均有 $5$ 次真正前进，所以“前进一次”的骰子钱平均是 $5 \times \frac{6}{5} = 6$ 元，比标价 $5$ 元贵。

### 第三步：两条路都算一遍，选便宜的

第三个游戏，两种操作都能用：

- 甲：付 $2$ 元，往下走 $1$ 级；
- 乙：付 $3$ 元掷骰子，规则同上（$1$ 空摇，$2$ 到 $6$ 走对应级数）。

每条路的账都要算**完整**，也就是把落地之后的花费一起算进去，再比谁小。骰子的那一项同样先解一次空摇：

| 级数 $n$ | 甲：$2 + f(n-1)$ | 乙：$\frac{18 + f(n-2) + f(n-3) + f(n-4) + f(n-5) + f(n-6)}{5}$ | 选谁 | $f(n)$ |
| --- | --- | --- | --- | --- |
| 1 | 2 | 3.6 | 甲 | 2 |
| 2 | $2+2 = 4$ | 3.6 | 乙 | 3.6 |
| 3 | $2+3.6 = 5.6$ | $\frac{18+2}{5} = 4$ | 乙 | 4 |
| 4 | $2+4 = 6$ | $\frac{18+3.6+2}{5} = 4.72$ | 乙 | 4.72 |
| 5 | $2+4.72 = 6.72$ | $\frac{18+4+3.6+2}{5} = 5.52$ | 乙 | 5.52 |

第 $1$ 级走甲更省；从第 $2$ 级起乙更省。注意乙的标价只有 $3$ 元，实际平均要付 $3\times\frac{6}{5} = 3.6$ 元才真正前进一次，这正是表里第 $1$ 级那一格的值。

### 第四步：从小的级数往大的数算

上面的表能一行行往下填，是因为每次操作都让级数变小：甲走 $1$ 级，乙走 $1$ 级以上，空摇那种“原地踏步”已经在解方程时消掉了。既然算第 $n$ 级只用到比 $n$ 小的级数，就先算 $f(1)$，再算 $f(2)$，一路算到 $f(N)$。

这就是全部原理，一共四件事：

- 平均花费 = 每种结果的花费乘以它的可能性，再加起来；
- 结果里若出现“原地不动”，就把这个级数的答案设成未知数，列方程移项解出来；
- 有几条路可走，就每条都算出完整期望，然后取最小的；
- 每一步都让数变小，就可以从最小的数开始逐个往大算，把结果记下来备用。

## 正解

!!! info 把两个操作都看成“除以一个数”，按数值从小到大递推 $f(n)=\min\left(X+f(\lfloor n/A\rfloor),\ \frac{6Y+\sum_{b=2}^{6} f(\lfloor n/b\rfloor)}{5}\right)$；骰出 $1$ 的自环已移项消掉，所以右侧只依赖更小的数，记忆化后状态只有 $O(\log^3 N)$ 个。
!!!

### 思路

回到本题。两个操作的新数值都小于等于原来：$\lfloor n/A \rfloor \leqslant n$（$A \geqslant 2$），$\lfloor n/b \rfloor \leqslant n$。等号只在骰出 $b=1$ 时出现，就是上文说的“空摇”。

设 $f(n)$ 为从 $n$ 出发的最小平均花费，$f(0)=0$。第一种操作的完整期望是 $X + f(\lfloor n/A \rfloor)$。第二种操作同理，先把空摇设成未知数：一次掷骰付费 $Y$，有 $\frac16$ 的可能回到 $n$ 本身，剩下 $\frac56$ 的可能落到更小的值，于是

$$f(n) = Y + \frac{1}{6}f(n) + \frac{1}{6}\sum_{b=2}^{6} f\!\left(\left\lfloor \frac{n}{b} \right\rfloor\right).$$

左边和右边都有 $f(n)$。把 $\frac{1}{6}f(n)$ 挪到左边得 $\frac{5}{6}f(n) = Y + \frac{1}{6}\sum_{b=2}^{6} f(\lfloor n/b \rfloor)$，两边同乘 $\frac{6}{5}$：

$$f(n) = \frac{6Y + \sum_{b=2}^{6} f\!\left(\left\lfloor \dfrac{n}{b} \right\rfloor\right)}{5}.$$

分子里的 $6Y$ 就是“多付的那几次空摇”：平均要摇 $\frac65$ 次才真正前进一次，钱也跟着乘以 $\frac65$。

两条路能选，就取便宜的：

$$f(n) = \min\left( X + f\!\left(\left\lfloor \frac{n}{A} \right\rfloor\right),\ \frac{6Y + \sum_{b=2}^{6} f\!\left(\left\lfloor \dfrac{n}{b} \right\rfloor\right)}{5} \right).$$

用样例 $1$（$N=3$，$A=2$，$X=10$，$Y=20$）走一遍：从 $1$ 出发花 $10$ 元除到 $0$，所以 $f(1)=10$；从 $2$ 出发，除法要 $10+f(1)=20$，骰子要 $\frac{120+f(1)}{5} = 26$，取 $20$；从 $3$ 出发，除法 $10+f(1)=20$，骰子 $\frac{120+f(1)+f(1)}{5}=28$，取 $20$。答案是 $20$。

样例 $2$ 只把 $X$ 换成 $20$：$f(1)=20$；$f(2)$ 的除法要 $20+20=40$，骰子只要 $\frac{120+20}{5}=28$，所以 $f(2)=28$；$f(3)$ 的除法 $40$，骰子 $\frac{120+20+20}{5}=32$，答案 $32$。这里能直接看到“算完整期望再比”的必要：从 $2$ 出发时两条路这一步都要付 $20$ 元，标价一样，看不出谁好；把后续花费一起算进去，才是 $40$ 对 $28$。

$N$ 最大 $10^{18}$，开不了数组，但真正会被用到的数值很少：反复除以 $2$、$3$、$5$、$6$（以及 $A$）之后，每个可达值都形如 $\lfloor N/d \rfloor$，其中 $d = 2^{a}3^{b}5^{c}$。$N = 10^{18}$ 时这样的值只有 $7251$ 个左右，所以直接递归，把算过的答案存进哈希表就够快。递归每层都严格变小，深度只有 $\log_2 N \approx 60$，不会越界。

### 复杂度

可达状态数记作 $S$，实测 $N = 10^{18}$ 时 $S \approx 7251$，上界由三元组 $(a,b,c)$ 的个数 $10917$ 控制。每个状态做常数次除法与 $5$ 次查表，时间复杂度 $O(S)$；哈希表存 $S$ 条记录，空间复杂度 $O(S)$；递归深度 $O(\log N)$。答案用 `double` 存放，因为最多要花约 $60X$，远超 `int` 的范围。

## 总结

这道题的答案不是“挑一条运气好的路”，而是给每个数值记一个平均花费，把随机结果按可能性摊平。真正要小心的只有骰出 $1$ 时的原地不动：它让未知数出现在等式两边，移项之后就能解出，并且解完以后每个值只依赖比自己小的值，于是可以从小往大逐个算。两条操作都算完整期望再取便宜的，剩下的工作量就只是记住算过的结果，避免重复计算。

# 4 寻找两个正序数组的中位数

## 题目描述

给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`，找出并返回这两个正序数组的中位数。

要求时间复杂度 $O(\log (m+n))$。

**示例 1：**

```text
输入：nums1 = [1,3], nums2 = [1,2]
输出：2.00000
解释：合并数组 = [1,1,2,3] ，中位数 2
```

**提示：**

- `nums1.length == m, nums2.length == n`

- `0 <= m <= 1000, 0 <= n <= 1000`

- `-10^6 <= nums1[i], nums2[i] <= 10^6`

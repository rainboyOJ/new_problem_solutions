# 33 搜索旋转排序数组

## 题目描述

整数数组 `nums` 按升序排列，其中的值在事先未知的某个下标处进行了旋转。例如 `[0,1,2,4,5,6,7]` 在下标 3 处旋转后可能变为 `[4,5,6,7,0,1,2]`。

给你旋转后的数组 `nums` 和一个整数 `target` ，如果 `nums` 中存在这个目标值，则返回它的下标，否则返回 `-1`。

要求时间复杂度 $O(\log n)$。

**示例 1：**

```text
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

**提示：**

- `1 <= nums.length <= 5000`

- `-10^4 <= nums[i] <= 10^4`

- `nums` 中的每个值都 **独一无二**

- 题目数据保证 `nums` 在预先未知的某个下标上进行了旋转

- `-10^4 <= target <= 10^4`

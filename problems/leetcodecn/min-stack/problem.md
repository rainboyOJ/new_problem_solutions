# 155 最小栈

## 题目描述

设计一个支持 `push`、`pop`、`top` 和 `getMin` 操作的栈，其中 `getMin` 能在 $O(1)$ 时间内返回栈中的最小值。

**示例 1：**

```text
输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[-2],[0],[-3],[],[],[-2],[],[-2]]
输出：[-2,0,-2]
解释：
- `push(-2)` → 栈 `[-2]`，最小 `-2`
- `push(0)` → 栈 `[-2, 0]` `最小 -2`
- `push(3)` → t栈 `[-2, 0, 3]` `最小 -2`
- `getMin()` → 返回 `-2`
- `pop()` → 弹出 `3` (栈 `[-2, 0]` `最小仍为 `-2`)
- `top()` → 返回 `0`
- `getMin()` → 返回 `-2`
```

**提示：**

- $-2^{31} \leqslant \text{val} \leqslant 2^{31} - 1$

- 方法 `pop`、`top` 和 `getMin` 操作总是合法的
方法调用、push` 的次数不超过 2^{31}$，次
- 栈为空时 `pop`、`top` 和 `getMin` 操作返回 $-2^{31}$`

## 形式化题目

起点与终点相隔 $4500$ 米。Charley 于时刻 $0$ 从起点出发，骑车必须有人同速陪伴；遇到速度更快的人时，他会把速度提到与那人相同。给定 $n$ 个同行人各自的速度 $v_i$ 与出发时刻 $t_i$（$t_i$ 可为负，表示提前出发），求 Charley 到达终点的时刻；结果为小数时向上取整。

## 正解

### 思路

**先排掉一个单位陷阱**：速度 $v$ 的单位是 **km/h** 而不是 m/s。骑完 $4500$ 米所需的秒数是 $4500 / (1000 v / 3600) = 16200 / v$。用样例验证：第二组数据里 $v = 22$、$t = 34$ 的人，$16200 / 22 \approx 736.4$，向上取整 $737$，$34 + 737 = 771$，恰是样例输出；若误当 m/s 就会得到 $34 + \lceil 4500/22 \rceil = 239$，明显不符。

接着是本题的核心观察：**Charley 到达终点的时刻，恰好等于某个「可用」同行人独自到达终点的时刻**。分三步看：

1. **$t_i < 0$ 的人不可用**：Charley 出发时他们已经在前方且不减速，永远追不上，对答案无贡献。
2. **跟随一个人就能取到他的到达时刻**：设某人 $t_j \geqslant 0$、速度 $v_j$。Charley 可以先在起点与他人慢速同行（或原地等），到 $t_j$ 时刻仍在起点，然后一路跟随 $j$，$t_j + \lceil 16200/v_j \rceil$ 到达终点——这正是 $j$ 自己的到达时刻。
3. **任何策略都不会更早**：Charley 到终点那一刻，必然与他最后跟随的人 $j$ 同位置（$t_j \geqslant 0$，否则追不上），而 Charley 全程速度始终不超过任一时刻陪伴者的速度，故 $j$ 的到达时刻不超过 Charley 的到达时刻。

中途「换跟更快的人」也不破坏这个结论：换跟之后 Charley 的到达时刻等于新跟随对象的到达时刻，而每个可用对象的到达时刻都已经在候选集合里。于是答案就是

$$
\min_{t_i \geqslant 0} \left( t_i + \left\lceil \frac{16200}{v_i} \right\rceil \right).
$$

「有人陪伴」这个条件其实不构成限制：$t_i = 0$ 出发的人可以理解为「Charley 本人按速度 $v_i$ 出发」；而题面保证 Charley 能骑完全程，意味着这类人必然存在，候选集不会为空。

用样例第一组验证（$v$ 单位 km/h，全程秒数 $\lceil 16200/v \rceil$）：

| 同行人 $(v, t)$ | 可用（$t \geqslant 0$） | 到达时刻 $t + \lceil 16200/v \rceil$ |
|---|---|---|
| $(20, 0)$ | 是 | $0 + 810 = 810$ |
| $(25, -155)$ | 否（提前出发，追不上） | —— |
| $(27, 190)$ | 是 | $190 + 600 = 790$ |
| $(30, 240)$ | 是 | $240 + 540 = \mathbf{780}$ |

可用者中最早的到达时刻是 $780$，与样例输出一致。

### 复杂度

- 时间复杂度：每组数据 $O(n)$，一次线性扫描取 min；总量 $O(\sum n)$，$n \leqslant 10000$ 远在限时之内。

## 总结

本题表面是「跟随他人的模拟」，实际是一步观察题：跟随者最优到达时刻恰等于**某个可用同行人独自的到达时刻**，于是模拟坍缩成一个 $\min$。两个易错点是速度单位（km/h，要乘 3.6 换算出 16200）与「提前出发的人永远追不上」（$t_i < 0$ 直接排除）；再加上答案向上取整，三处都对就能一遍过。

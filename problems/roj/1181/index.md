## 形式化题目

给定 $n = 10$ 个整数 $a_1, a_2, \dots, a_{10}$，其中 $0 \leqslant a_i \leqslant 30000$。
要求输出这 10 个数的一个排列 $b_1, b_2, \dots, b_{10}$，满足：

1. 奇数全部排在偶数前面：若 $b_i$ 是偶数而 $b_j$ 是奇数，则必有 $i > j$；
2. 奇数段从大到小：若 $b_i, b_j$ 均为奇数且 $i < j$，则 $b_i \geqslant b_j$；
3. 偶数段从小到大：若 $b_i, b_j$ 均为偶数且 $i < j$，则 $b_i \leqslant b_j$。

以样例 `4 7 3 13 11 12 0 47 34 98` 为例，奇数为 $47, 13, 11, 7, 3$（降序），
偶数为 $0, 4, 12, 34, 98$（升序），拼接后输出 `47 13 11 7 3 0 4 12 34 98`。

## 正解

### 思路

**一句话本质**：两段的排序方向相反，但每段内部方向单一，所以只需要一次升序排序，
再从有序序列里分别筛出奇数和偶数——奇数那段反转、偶数那段保持即可。

先看朴素的写法：把数按奇偶分进两个数组，然后各写一段双重循环冒泡，奇数段
"前者比后者小就交换"、偶数段"前者比后者大就交换"。$n = 10$ 时这当然能过，但它写了两遍
几乎一样的排序代码，读者看到的是手写交换，而不是本题真正的内容——**复合排序规则**。

换个角度想：题面要求的两段方向相反（奇数降、偶数升），但**没有任何一段是"忽升忽降"的**。
既然每段各自都是单一方向，就没有必要对两段分别排序，可以共用一个有序结果：

1. 对整列做**一次**升序排序，得到 $s_1 \leqslant s_2 \leqslant \cdots \leqslant s_{10}$；
2. 从 $s$ 中筛出偶数，它们的相对顺序不变，因此天然升序——这正是要求的偶数段；
3. 从 $s$ 中筛出奇数，同样天然升序，把它**反转**就得到要求的降序奇数段；
4. 两段拼接：`奇数段 + 偶数段`。

用 `[::-1]` 反转，而不是给奇数段单独加一个 `reverse=True` 的比较器。原因是
`list.sort` 只能对整个列表指定一个方向，若用 `reverse=True` 排序，偶数段就会变成降序，
反而要再翻回来；把方向差异全部交给切片表达，排序调用就只剩一次。

奇偶判定用 `x & 1`：非负整数 $x$ 为奇数当且仅当它的二进制最低位是 $1$。
`x % 2` 在本数据范围下也对，但 `x & 1` 更贴合"看最低位"这个事实，也省掉一次除法。

下面用样例把"先排序、再切分"两步展开，重点看一次升序排序是如何同时服务两段的：

| 步骤 | 序列 |
| --- | --- |
| 原序列 | 4, 7, 3, 13, 11, 12, 0, 47, 34, 98 |
| 一次升序排序后 $s$ | **0, 3, 4, 7, 11, 12, 13, 34, 47, 98** |
| 从 $s$ 筛出奇数（升序） | 3, 7, 11, 13, 47 |
| 奇数反转（降序） | 47, 13, 11, 7, 3 |
| 从 $s$ 筛出偶数（升序） | 0, 4, 12, 34, 98 |
| 拼接输出 | 47, 13, 11, 7, 3, 0, 4, 12, 34, 98 |

观察重点有三处。第一，中间那行 `0` 排在最前，说明 $0$ 被当作**偶数**处理，它是偶数段
的第一个数（样例输出中 `0` 确实紧跟在奇数段之后）。第二，奇数段和偶数段都来自同一个
有序序列，只是取反与否不同，所以两段各自有序是"子序列保持相对顺序"的直接推论，不需要
额外证明。第三，拼接顺序固定为奇数在前，不需要任何归并比较。

### 复杂度

- 时间复杂度：一次排序 $O(n \log n)$；随后两次线性筛选各 $O(n)$、一次切片反转 $O(n)$、
  一次拼接 $O(n)$，合计 $O(n \log n)$。本题 $n = 10$，实际只有几十次比较。
- 空间复杂度：$O(n)$，用于存放读入的整数列表与两段筛选结果。

对比朴素写法的两段冒泡（各 $O(n^2)$，合计 $O(n^2)$），本解法在复杂度上更优，
并未把算法降级成暴力。$n = 10$ 时两者都是瞬间完成，时间限制 1000 ms、
内存限制 128 MB 有数个数量级的余量。

## 总结

- 本题的算法内核是一句话：**一次升序排序 + 按奇偶切分**，奇数反转得降序、偶数保持升序，
  最后拼接，复杂度 $O(n \log n)$。
- 遇到"两个分组方向相反"的排序题，先问自己：能不能共用同一个有序序列，把方向差异
  交给切片（`[::-1]`）表达？能的话就只排一次，代码和复杂度都更干净。
- 两个容易看漏的细节：$0$ 是偶数；判奇偶用 `x & 1` 比 `x % 2` 更直接。
- 输出用空格分隔、末尾无多余符号，`print(*answer)` 正好符合要求。

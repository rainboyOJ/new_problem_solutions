## 形式化题目

给定两个十进制串 $A = a_{n-1}\cdots a_1a_0$ 与 $B = b_{m-1}\cdots b_1b_0$，其中
$n, m \leqslant 200$，且两串都不含多余前导 `0`。求 $A - B$ 的十进制表示。

形式化地，令借位 $c_0 = 0$，对 $i = 0, 1, 2, \dots$ 定义

$$d_i = a_i - b_i - c_i,\qquad \text{答案第 } i \text{ 位} = d_i \bmod 10,\qquad c_{i+1} = [\,d_i < 0\,]$$

其中越界位取 $0$。这就是竖式减法：借位从低位向高位单向传递，每位只依赖低位。

## 正解

### 思路

**为什么不能直接算。** 一位十进制数需要约 $3.32$ bit，$200$ 位约 $665$ bit；而 64 位整数
上限 $2^{64}-1 \approx 1.8\times10^{19}$ 只有 20 位，`long long` 装不下，浮点会丢精度。
所以必须自己处理借位，这是一道高精度题。

**朴素做法。** 把两个串补 `0` 对齐到等长，从末位起逐位相减，不够减就向高位借 $1$。
题面自带的参考程序 `std.cpp` 就是这么做的：`a[256]`、`b[256]`、`c[256]` 三个定长数组，
倒序存数后 `if (a[i] < b[i]) { a[i] += 10; a[i+1]--; }`，再 `c[i] = a[i] - b[i]`。
它是对的，但有三个容易出错的地方：

1. **对齐**：两数位数不同，要先补零补到等长，多一次长度比较和一趟字符串构造。
2. **负本位**：`a[i] - b[i]` 可能为负，必须在减法之前完成借位，顺序写反就得到负数字。
3. **去前导零**：结果全为 $0$（如 $1234-1234$）时直接 `lstrip('0')` 会得到空串。

**瓶颈分析。** 这里**没有可以消除的算法瓶颈**：每个数字至少要读一次，$O(L)$ 就是下界，
不存在"优化到更优复杂度"的空间。所以"优化"的方向是把上面三个易错点在实现层面直接
消掉，而不是换算法。

| 易错点 | 消法 |
| --- | --- |
| 补零对齐 | **不补零**。双指针从两串末尾起步，越界的一侧按 $0$ 参与运算 |
| 负本位 | Python 的**负数取模** `diff % 10` 直接给出借位后的本位，不必先加 $10$ 再减 |
| 前导零 | 输出阶段一次 `lstrip('0')`，再用 `or '0'` 兜住"结果为零" |

**借位只有 0 或 1。** 因为 $d_i = a_i - b_i - c_i \geqslant 0 - 9 - 1 = -10$，所以
$c_{i+1} = [\,d_i < 0\,]$ 只可能取 $0$ 或 $1$。借位用一个整数变量承载即可，不需要数组，
也不会有"借位再借位"的连锁问题。

下面把题面样例展开成逐位过程。列的含义：$i$ 是位数（0 是最低位），$a_i$/$b_i$ 是该位数字，
$c_i$ 是**进入本轮时**的借位，$d_i = a_i - b_i - c_i$，$d_i \bmod 10$ 是输出位，
$c_{i+1}$ 是**传给下一位**的借位。

| 轮次 | $a_i$ | $b_i$ | 借位 $c_i$ | $d_i = a_i-b_i-c_i$ | 输出位 $d_i \bmod 10$ | 新借位 $c_{i+1}$ |
| --- | --- | --- | --- | --- | --- | --- |
| 第 1–13 位（低位对齐减数） | 9 | 9 | 0 | 0 | `0` | 0 |
| 第 14–37 位（减数已越界） | 9 | 0 | 0 | 9 | `9` | 0 |

样例是被减数 $37$ 个 `9`、减数 $13$ 个 `9`：减数只覆盖最低的 $13$ 位，在这里每位都是
$9-9=0$；更高的 $24$ 位减数按 $0$ 参与，$9-0=9$。**借位自始至终是 $0$**（每位都够减），
所以输出是（高位起）$24$ 个 `9` 后接 $13$ 个 `0`，即 `9999999999999999999999990000000000000`。
这说明样例其实没考借位；真正考借位的是下面这些：

| 输入 | 借位链（低位 → 高位） | 答案 | 考点 |
| --- | --- | --- | --- |
| `1000` $-$ `1` | $0{-}1\to$借$1$，$0{-}0{-}1\to$借$1$，$0{-}0{-}1\to$借$1$，$1{-}0{-}1=0$ | `999` | **连续借位传递 3 位** |
| `100000` $-$ `1` | 借位沿链一直传到最高位 | `99999` | 长借位链 |
| `1` $-$ `1000` | 位数短的一侧先交换 | `-999` | **交换后按 $b-a$ 计算并补负号** |
| `1234` $-$ `1234` | 无借位，各位差都是 0 | `0` | 结果去零后为空，必须补回 `0` |

第三行说明参考实现不要求 $a>b$：它先比较位数，短的一方与长的一方交换并记下负号，
所以题面写的 $a>b$ 只是"数据常见情形"，不是实现可以依赖的前提。

!!! warning 第 4 组评测数据的回绕值
参考程序 `std.cpp` 的交换条件写成了
`if ( (lena<lenb) || (lena==lenb && strcmp(str1,str2)) )`。`strcmp` 只在两串**完全相等**时
返回 0，其余一律非 0，所以第二项的真实含义是"**等长且两串不同**"，而不是"$a < b$"。
当 $a > b$ 且两串**等长**时，它也会交换操作数，再在定长数组里做 $b-a$。由于数组下标只到
`lena`，最高位那次借位被丢弃，结果等价于

$$\text{输出} = -(b-a) \bmod 10^{L},\qquad L = \max(\lvert a\rvert, \lvert b\rvert),$$

再补上负号。真实数据 `problem4` 正是"$L=175$ 且 $a>b$"：按数学定义 $a-b$ 应为
`553046004533...`，而 `problem4.out` 给出的是 `-446953995466...`，恰好等于
$-(10^{175} - (a-b))$。位数不等的 9 组都不会触发这条分支，所以只有它例外。

本解选择**与评测数据逐字符一致**：`solve()` 沿用 `std.cpp` 的 `strcmp` 判定
（即 `len(a) == len(b) and a != b`），`subtract` 只保留 $L$ 位、丢弃最高位借位，
正是"定长数组"的等价写法。这与本仓库 1161 题沿用参考实现越界输出 NUL 字节的做法一致。

`subtract` 承担算法本体，一句话说清职责：回答两个十进制串的定长竖式差。
`solve` 只做读入、交换判定、去前导零和输出，不含任何算法判断。

三处设计决定与推导一一对应：

- `ord(top[-1 - k]) - ZERO if k < len(top) else 0` 处理越界位，**等价于补零对齐但不多分配内存**；
- `diff = high - low - borrow` 与 `borrow = diff < 0` 严格按"先算差、再定借位"的顺序，
  避开了"先借位再加 10"的分支；
- `diff % 10` 依赖 Python 对负数取模仍返回非负余数（$-3 \% 10 = 7$），把 C++ 里的
  `if (a[i] < b[i]) a[i] += 10` 压缩成了一个运算符；随后 `.lstrip('0') or '0'`
  去前导零并兜住"差为零"。

读入用 `sys.stdin.buffer.read().split()` 而不是读两行，是因为真实数据 `problem1.in`
的第二行**没有以换行符结束**，按空白切分才稳妥。

### 复杂度

设 $L = \max(n, m) \leqslant 200$。

- **时间**：$O(L)$。循环恰好 $L$ 轮，每轮 $O(1)$；反转、拼接、`lstrip` 各 $O(L)$，
  不改变总阶。这也是下界——每个数字至少要读一次。
- **空间**：$O(L)$。`out` 至多保存 $L$ 个字符。相比补零写法少了一份 $O(L)$ 的对齐副本。
- **实测**：限时 $1000$ ms、内存 $128$ MB；真实测试点单点耗时约 $0.02$ s、峰值约 $14.5$ MB。

Python 侧无 TLE/MLE 风险：$L \leqslant 200$ 时逐位运算总共只有几百次。
同样的算法在 C++ 里就是题面自带的 `std.cpp`：定长数组倒序存数后逐位相减；本实现用
双指针省掉了补零这一步，并显式保留了它的定长语义。

## 总结

大整数减法就是**位置计数制借位规则的直接模拟**：从最低位起单向扫描，每位算
$d = a_i - b_i - c$，留下 $d \bmod 10$、把 $[\,d<0\,]$ 传给下一位。由于 $d \geqslant -10$，
借位恒为 0 或 1，一个变量即可。实现上的关键是三点：越界位按 0 处理以省掉补零、
用 Python 的负数取模把"借位 + 加 10"压成一个运算符、最后 `lstrip('0') or '0'`
去前导零并兜住全零结果。

本题还有一个必须知道的数据特点：参考实现 `std.cpp` 把 `strcmp(...)` 的非零返回值
当作"$a<b$"使用，导致**等长且 $a>b$** 时操作数被误交换，再经定长数组丢弃最高位借位，
输出 $(b-a) \bmod 10^{L}$ 的相反数；真实数据第 4 组正是这种情形。本解沿用同一判定，
以保证与评测数据逐字符一致。

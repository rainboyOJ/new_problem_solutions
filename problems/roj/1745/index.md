## 形式化题目

有 $n$ 个居民，第 $i$ 个人有地位 $r_i$ 和年龄 $a_i$。一个小组 $S$ 合法，当且仅当存在
队长 $L \in S$ 满足

$$
r_j \leqslant r_L \;\; (\forall j \in S), \qquad |a_j - a_L| \leqslant K \;\; (\forall j \in S).
$$

注意队长本人自然满足第二条（$|a_L - a_L| = 0 \leqslant K$），第一条允许并列第一。
给出 $Q$ 个询问，每个询问给两个不同的居民 $x, y$，求**同时包含 $x$ 与 $y$** 的合法小组
的最大大小 $|S|$；不存在这样的小组时输出 $-1$。

约束：$2 \leqslant n \leqslant 10^5$，$0 \leqslant K \leqslant 10^9$，
$1 \leqslant r_i, a_i \leqslant 10^9$，$1 \leqslant Q \leqslant 10^5$，$1 \leqslant x, y \leqslant n$，$x \neq y$。

关键是把"整个小组"从问题里消掉：**小组是否合法，只由队长一个人决定**。
给定队长 $L$，能和他同组的人恰好是那些

$$
r_j \leqslant r_L \quad \text{且} \quad |a_j - a_L| \leqslant K
$$

的人，这些条件互不干扰，所以"以 $L$ 为队长"的小组最大人数可以直接数出来：

$$
\mathrm{cnt}[L] = \#\{\, j : r_j \leqslant r_L,\; a_L - K \leqslant a_j \leqslant a_L + K \,\}.
$$

于是原问题变成：在满足"能同时容纳 $x$ 与 $y$"的队长里，找 $\mathrm{cnt}$ 最大的那个。
队长 $L$ 能容纳 $x$ 与 $y$ 的充要条件是

$$
r_L \geqslant \max(r_x, r_y), \qquad a_L \in [\max(a_x, a_y) - K,\; \min(a_x, a_y) + K].
$$

第二条是两个年龄邻域的交集：$a_L$ 必须同时靠近 $x$ 和 $y$，而这个交集非空当且仅当
$|a_x - a_y| \leqslant 2K$——这也解释了样例里 $x = 2, y = 5$ 为什么输出 $-1$。

## 正解

### 思路

**朴素做法。** 对每个询问枚举所有可能的队长 $L$，再花 $O(n)$ 数一遍
$\mathrm{cnt}[L]$，总复杂度 $O(Q n^2)$，$n = Q = 10^5$ 时不可行。瓶颈有两处：
$\mathrm{cnt}$ 被反复重算，以及队长的筛选条件带着一个二维约束（地位一维、年龄一维）。

**第一步：把 $\mathrm{cnt}$ 一次算完。** 数 $\mathrm{cnt}[L]$ 就是"统计地位不超过
$r_L$、年龄落在一个区间内的人数"，这是典型的**二维数点**。固定 $L$ 时年龄是一段区间，
所以按地位升序把人依次插入一棵**下标为年龄的树状数组**，插入完第 $k$ 个人之后，
树状数组里正好是"地位排名 $\leqslant k$"的全部人，此时对 $L$ 查询年龄区间和即可。

这里有一个必须处理的细节：**地位并列的人要整块插入后再统一查询**。
如果把同地位的人一个一个"插入—查询"，那么并列第一的队长就会漏数同地位的其他居民，
而题面明确允许并列第一当队长。做法是按 $r$ 分组，一组人全部插入后才对本组每个人查询。

年龄值域到 $10^9$，但只有 $n$ 个不同取值，先离散化到 $1..m$（$m \leqslant n$）。
查询区间 $[a_L - K, a_L + K]$ 用 `lower_bound` / `upper_bound` 转成坐标区间
$[\mathrm{lo}, \mathrm{hi}]$，答案就是前缀和之差。

**第二步：把询问离线成区间最大值。** 剩下的问题是对每个询问求

$$
\max \{\, \mathrm{cnt}[L] \;:\; r_L \geqslant \max(r_x, r_y),\;\; a_L \in [\mathrm{ql}, \mathrm{qr}] \,\}.
$$

两个条件一个在地位上、一个在年龄上，直接做是二维查询。但注意到地位条件
$r_L \geqslant \text{need}$ 只是**把候选人截成"排名 $\geqslant$ start 的后缀"**：
把人按 $r$ 升序排好后，取 `start` 为第一个满足 $r \geqslant \text{need}$ 的排名，
合法队长恰好是排名 $\geqslant$ `start` 的那些人。

于是把询问按 `start` **降序**排序，用一个指针从地位最高的人开始往回走，
边走边把 $\mathrm{cnt}$ 插入一棵**下标为年龄坐标的最大值线段树**。
指针只降不升，线段树里的元素只增不减，所以每个询问只需一次区间查最大值，
总代价 $O((n + Q) \log n)$。这正是"离线 + 单调指针把二维问题降成一维"的标准套路。

**答案判定。** 询问的答案小于 $2$ 就输出 $-1$。理由是：只要 $x$ 与 $y$ 存在共同的合法队长，
那么 $x$ 和 $y$ 自己都会被这个队长计入 $\mathrm{cnt}$（队长地位够高、年龄也够近），
所以最大值至少是 $2$；反过来最大值为 $0$ 或 $1$ 说明没有任何队长能同时容纳两人。

拿样例走一遍：$n = 5$，$K = 1$，$r = (1,5,4,1,2)$，$a = (4,4,3,2,2)$。
按地位排序后是 $1(4),\,4(2),\,5(2),\,3(3),\,2(4)$（括号里是年龄）。
第 3 个人（原编号 3，$r = 4$，$a = 3$）当队长时，地位不超过他的人有
$1, 4, 5, 3$，其中年龄落在 $[2,4]$ 的正是这四个，所以 $\mathrm{cnt} = 4$。
询问 $(5, 3)$ 要求 $r_L \geqslant \max(2,4) = 4$、$a_L \in [\max(2,3) - 1, \min(2,3) + 1] = [2, 4]$，
队长 3（$\mathrm{cnt} = 4$）满足条件，答案 $4$，与样例一致。
询问 $(2,5)$ 要求 $a_L \in [\max(4,2) - 1, \min(4,2) + 1] = [3, 3]$，
只有 $a = 3$ 的队长 3 可以，但它不满足 $r_L \geqslant \max(5, 2) = 5$，
区间里没有合法队长，输出 $-1$。

### 复杂度

- **时间**：排序与离散化 $O(n \log n)$；预处理 $\mathrm{cnt}$ 时每个人被插入一次、
  查询两次前缀和，$O(n \log n)$；询问排序 $O(Q \log Q)$，线段树单点更新 $n$ 次、
  区间查询 $Q$ 次，各 $O(\log n)$。总计 $O((n + Q) \log n)$，
  $n = Q = 10^5$ 时约 $3 \times 10^6$ 次基本操作。实测 C++ 在最大点（problem10，
  $n = Q = 10^5$）上约 0.10 s，远低于 1000 ms 限时。
- **空间**：离散化后的年龄表、树状数组、线段树、询问数组都是 $O(n + Q)$，
  线段树 $4n$ 个 `int` 约 0.8 MB，C++ 实测峰值约 11 MB，远低于 256 MB 限时。
- **与 Python 的关系**：`main.py` 与 `main.cpp` 是同一算法（树状数组 + 离线线段树），
  没有降级成暴力。Python 侧同样受 $O((n + Q) \log n)$ 约束，实测最大点约 0.63–0.68 s，
  仍在 1000 ms 内，但余量比 C++ 小得多；若评测机比本地慢，**存在 TLE 风险**。
  算法复杂度与 C++ 一致，不存在"Python 用暴力蒙过"的情况。

## 总结

- **先化简合法性条件**：小组是否合法只取决于队长一个人，组员之间没有约束。
  这一步把"枚举子集"的指数结构直接换成了"数点数"，是本题的分水岭。
- **二维数点用"排序 + 一维树状数组"**：按地位升序插入、用年龄当树状数组下标，
  就得到了每个前缀地位上的年龄分布。**同地位的人必须整块插入再统一查询**，
  否则并列第一的队长会漏数同伴——这是本题最容易写错的一处。
- **离线 + 单调指针消除一维**：把询问按地位阈值降序排，指针从高到低单向推进，
  线段树里的元素只增不减，"地位 $\geqslant$ need"这个后缀条件就消失了，
  剩下的只有年龄区间求最大值。
- **值域大就要离散化**：$a_i \leqslant 10^9$ 但只有 $n$ 个不同取值，
  离散化后线段树和树状数组的下标规模都是 $O(n)$。
- **答案 $< 2$ 即无解**：$x, y$ 一旦有共同队长就必然被计入，所以判无解不需要额外逻辑。
- **数据来源说明**：本题素材目录里带有数据生成脚本 `data.py`（基于 cyaron），
  说明仓库内的 `data/` 是**自造数据**而非官方原题数据；题面文字也属于网络重建。
  因此出题意图与官方原题（同源题目见 JZOJ 3854 / Codeforces 173E "Camping Groups"）
  可能存在偏差，本文的结论仅对仓库内这套数据负责。素材自带的 `std.cpp` 已实测编译后
  与 10 组 `.out` 全部一致，且与本文两份代码在随机对拍中输出相同，可以互相印证。
- **本题验证记录**：题面样例 1 组（4 个询问）C++ 与 Python 输出均为 `4 3 -1 4`，
  与期望完全一致；真实数据 10 组 `.out` 逐点 diff 全部 PASS（C++ 最大点 0.10 s、
  Python 最大点 0.63 s）；与朴素 $O(Qn^2)$ 暴力在 1200 组以上随机小数据
  （$n \leqslant 60$，含 $K = 0$、值域退化到 1 种取值、地位与年龄大量并列等边界）
  上 C++ 与 Python 均无差异。

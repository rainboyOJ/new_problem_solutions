## 形式化题目

给定正整数 $n$，输出闭区间 $[2, n]$ 内所有满足「真因子之和等于自身」的数（完全数），一行一个，从小到大。

真因子：能整除 $i$ 且小于 $i$ 的正整数（含 1，不含 $i$ 本身）。

样例输入 `7`，输出 `6`。下面用表格展示判定过程，说明"真因子和等于自身"到底在比什么：

| $i$ | 真因子 | 真因子和 | 与 $i$ 比较 |
| --- | --- | --- | --- |
| 4 | 1, 2 | 3 | $3 < 4$，不是完全数 |
| 6 | 1, 2, 3 | 6 | $6 = 6$，是完全数 |
| 8 | 1, 2, 4 | 7 | $7 < 8$，不是完全数 |
| 28 | 1, 2, 4, 7, 14 | 28 | $28 = 28$，是完全数 |

前两列就是判定的全部输入：把真因子全列出来求和，再和自身比。观察重点是：除完全数外，真因子和几乎总是偏小（这就是"完全"这个名字的来历——因子恰好不多不少）。

## 朴素解法

### 思路

最直接的写法：对每个 $i \in [2, n]$，枚举 $d \in [1, i-1]$，若 $i \bmod d = 0$ 就把 $d$ 累加进和；枚举完比较"和是否等于 $i$"：

```text
for i = 2 .. n:
    sum = 0
    for d = 1 .. i-1:      # 枚举所有可能的因子
        if i mod d == 0:
            sum += d
    if sum == i: 输出 i
```

这个写法正确，且本题 $n \leqslant 1000$ 时总运算量约 $5 \times 10^5$ 次取模，完全能过。

### 瓶颈

内层循环枚举到 $i - 1$，但一个数的因子根本不需要找那么远。

## 正解

### 关键观察

因子是**成对**出现的：若 $d \mid i$ 且 $d < \sqrt{i}$，则 $i/d$ 也是 $i$ 的因子，且 $i/d > \sqrt{i}$，两者互不相同。所以求出所有不超过 $\sqrt{i}$ 的因子，就等于求出了全部因子——每个 $d < \sqrt{i}$ 的因子同时贡献 $d$ 和 $i/d$ 两个真因子。

唯一的例外是 $i$ 为完全平方数：此时 $d = \sqrt{i}$ 自己与自己配对，只能算一次。

### 思路

对每个 $i \in [2, n]$ 求真因子和：

1. 初值 $s = 1$：$i \geqslant 2$ 时 1 一定是真因子，直接记上；
2. 枚举 $d$ 从 $2$ 开始，只要 $d^2 < i$：若 $d \mid i$，则 $s \mathrel{+}= d + i/d$（成对累加）；
3. 循环结束时若 $d^2 = i$，再补上 $d$（平方根只加一次）；
4. $s = i$ 就把 $i$ 加入答案。

外层循环天然升序，答案从小到大，直接输出即可。

### 复杂度

- 时间：单个数判定 $O(\sqrt{i})$，总计 $\Theta(n\sqrt{n})$。$n = 1000$ 时约 $3 \times 10^4$ 次取模，实测全部数据 0.02s 内通过。
- 空间：$\Theta(1)$ 额外空间（1000 以内的完全数只有 6、28、496，答案列表最多 3 个元素）。

## 总结

- 完全数判定 = 求真因子和再与自身比较，核心技巧是**因子成对、只枚举到 $\sqrt{i}$**——这也是判质数、求因子个数、求因子和共用的套路。
- 完全平方数的平方根因子要单独处理，避免重复累加。
- 顺带一提：偶完全数一定形如 $2^{p-1}(2^p - 1)$（其中 $2^p - 1$ 为质数，欧几里得–欧拉定理），所以 1000 以内只有 6、28、496；但本题 $n$ 很小，直接试除比背诵结论更通用。

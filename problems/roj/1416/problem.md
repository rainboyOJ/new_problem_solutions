### 【题目描述】

二维平面上有 $N$ 个矩形，第 $i$ 个矩形覆盖区域为

$$[l_i,r_i) \times [d_i,u_i) = \{(x,y)\in \mathbb{R}^2 \mid l_i\leq x < r_i,\ d_i \leq y < u_i\}$$

注意矩形是**半开区间**：左、下边界包含在矩形内，右、上边界不包含。

现在给定 $M$ 个询问点，对于每个点 $(x_j, y_j)$，求有多少个矩形覆盖该点。

### 【输入】

第一行包含两个整数 $N$ 和 $M$，表示矩形个数和询问点个数。

接下来 $N$ 行，第 $i$ 行包含四个整数 $l_i\ d_i\ r_i\ u_i$，表示第 $i$ 个矩形的位置。

接下来 $M$ 行，第 $j$ 行包含两个整数 $x_j\ y_j$，表示第 $j$ 个询问点的坐标。

### 【输出】

输出 $M$ 行，第 $j$ 行一个整数，表示覆盖第 $j$ 个询问点的矩形个数。

### 【输入样例】

```
3 5
1 1 4 4
2 0 3 5
0 2 5 3
2 2
1 1
2 4
4 2
0 0
```

### 【输出样例】

```
3
1
1
1
0
```

### 【输入样例2】

```
2 3
0 0 10 10
0 0 10 10
5 5
10 10
0 0
```

### 【输出样例2】

```
2
0
2
```

### 【数据范围】

- $1 \leq N \leq 100000$
- $1 \leq M \leq 100000$
- $0 \leq l_i < r_i \leq 10^9$
- $0 \leq d_i < u_i \leq 10^9$
- $0 \leq x_j, y_j \leq 10^9$

### 【提示】

$(x, y)$ 被 $[l,r) \times [d,u)$ 覆盖，当且仅当 $l \leq x < r$ 且 $d \leq y < u$。样例2 中 $(10,10)$ 恰好落在两个矩形的右、上边界上，不被任何矩形覆盖。

## 形式化题目

有 $n$ 条初始长度已知的蚯蚓，和一个常数 $q$（每次切分后，除了切分出的两条新蚯蚓，其余所有蚯蚓长度都增加 $q$）。
你一共需要切分 $m$ 次，每次从当前所有的蚯蚓中选出最长的一条，将其切成两段。设切分前该蚯蚓长度为 $x$，常数为 $u, v$，切分后的两段长度分别为 $\lfloor x \times \frac{u}{v} \rfloor$ 和 $x - \lfloor x \times \frac{u}{v} \rfloor$。
要求输出两行信息：
1. 每 $t$ 秒切断的蚯蚓在切断前的长度（以空格隔开）。
2. 在所有切分完成后，每隔 $t$ 个输出剩余蚯蚓的长度，按照长度从大到小排列。

数据范围：$1 \le n \le 10^5, 0 \le m \le 7 \times 10^6, 0 < u < v \le 10^9, 0 \le q \le 200, 1 \le t \le 71$。

> **注意：** 本题在原始题库中编号 `3641`，题面虽为「组合数问题」，但实际判题数据与格式完全对应的是 NOIP 2016 提高组的「蚯蚓」一题（首行形如 `n m q u v t`，且 `.ans` 存在大段多行序列且附有前导换行符等）。本题解已根据**实际测试数据**更正题意并提供匹配的算法。

## 正解

### 思路

每次要找出当前最长的蚯蚓切断，最直观的做法是使用优先队列维护当前所有蚯蚓的长度。由于每次除了被切断的蚯蚓外，其余所有蚯蚓都要增长 $q$，我们不需要对优先队列中的每一个元素进行修改，而是可以维护一个全局增加量 `offset`。每秒 `offset += q`，当切断一条原长度为 $L$（通过队列最大值加上 `offset` 算出）的蚯蚓后，切出的两段长度计算出后要放入优先队列，为了抵消 `offset`，放入队列的值应减去当前的 `offset + q`。这种做法时间复杂度为 $O(m \log (n + m))$。然而，在本题中 $m$ 的范围高达 $7 \times 10^6$，优先队列的常数以及对数因子会超时。

注意到本题存在一个关键的单调性质：
**若较早被切断的蚯蚓原长为 $x_1$，较晚被切断的蚯蚓原长为 $x_2$，则必然有 $x_1 \ge x_2$。** 
因此，对于长度更大的 $x_1$，其按固定比例 $\frac{u}{v}$ 切分出的两段长度 $\lfloor x_1 \frac{u}{v} \rfloor$ 和 $x_1 - \lfloor x_1 \frac{u}{v} \rfloor$ 在相同的增长时间下，必然也大于等于 $x_2$ 切分出的对应部分（考虑到 $x_2$ 虽多增长了，但在其被切的时候也仅仅是因为 $x_1$ 先被切掉）。也就是说，如果我们把新切出来的蚯蚓段放到单独的队列中，它们天然是按从大到小有序的。

因此，我们可以维护三个普通的队列：
- 队列 0：存放一开始就有的 $n$ 条蚯蚓，初始时将其降序排序。
- 队列 1：存放每次被切断后产生的第一条较短或按比例的那条蚯蚓段。
- 队列 2：存放每次被切断后产生的另一半蚯蚓段。

由于这三个队列内部都是单调递减的，每次选取当前最长的蚯蚓时，只需在这三个队列的队首比较大小，选取最大值即可，这样选取最大值的操作是 $O(1)$ 的。这类似于归并排序的过程。总时间复杂度被优化至 $O(n \log n + m)$。

### 复杂度

- **时间复杂度**：
  初始时对给定的 $n$ 条蚯蚓排序，花费 $O(n \log n)$。
  随后进行 $m$ 次切分，每次只需要比较三个队列的队首，选取最大值并进行相应的进队出队操作，花费 $O(m)$。
  最后把三个队列剩余元素取空输出，花费 $O(n + m)$。
  总时间复杂度为 $O(n \log n + m)$。
- **空间复杂度**：
  需要开三个数组模拟队列。队列 0 需要 $O(n)$，队列 1 和队列 2 各自最多需要 $O(m)$，所以总空间复杂度为 $O(n + m)$，完全满足本题要求。

## 总结

- 利用隐藏的单调性，将需要 $O(\log n)$ 维护最值的优先队列退化成了三个相互之间有单调性的普通队列，将复杂度成功优化至线性的 $O(n \log n + m)$。这是处理这类题目的极其经典的技巧。
- 对于全局所有元素的集体变化，应采用偏移量（`offset`）进行相对管理，极大程度提升了效率。

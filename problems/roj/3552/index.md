## 形式化题目

给定 $n$ 名学生，第 $i$ 名学生由六元组 $(name_i,\ a_i,\ e_i,\ c_i,\ w_i,\ p_i)$ 描述：姓名、期末平均成绩 $a_i$、班级评议成绩 $e_i$、是否学生干部 $c_i \in \{Y, N\}$、是否西部省份学生 $w_i \in \{Y, N\}$、发表论文数 $p_i$。

五项奖学金相互独立、可兼得，命中条件与金额如下：

| 奖学金 | 金额 | 命中条件 |
| --- | ---: | --- |
| 论文奖学金 | 8000 | $a > 80$ 且 $p \geqslant 1$ |
| 评议奖学金 | 4000 | $a > 85$ 且 $e > 80$ |
| 成绩优秀奖 | 2000 | $a > 90$ |
| 西部奖学金 | 1000 | $a > 85$ 且 $w = Y$ |
| 班级贡献奖 | 850 | $e > 80$ 且 $c = Y$ |

每人的奖金总额等于其命中的各项金额之和。求：

1. 获得奖金总额最高的学生姓名（并列时取最先出现者）；
2. 该最高总额；
3. 全班 $n$ 名学生的奖金总额。

工作样例（4 名学生）：

```
4
Alice 87 82 Y N 0
Bob 88 78 N Y 1
Carol 92 88 N N 0
Dave 83 87 Y N 1
```

逐人核算：Alice 命中 4000 + 850 = 4850；Bob 命中 8000 + 1000 = 9000；Carol 命中 4000 + 2000 = 6000；Dave 命中 8000 + 850 = 8850。最高者 Bob（9000），全班总和 $4850 + 9000 + 6000 + 8850 = 28700$，输出：

```
Bob
9000
28700
```

## 正解

### 思路

**朴素做法**：给五项奖学金各写一个 `if` 分支，把金额累加进一个变量；再扫一遍数组找最大值并求总和。分支正确但把"判定"和"累加"揉在一起，找最大值与求总和还要各扫一遍。

**优化推导**：五项条件彼此独立、金额固定，每个条件的"命中/未命中"恰好是布尔值——而 Python 中 `bool` 是 `int` 的子类，`8000 * True` 就是 8000、`8000 * False` 就是 0。于是每项奖学金写成"金额 $\times$ 布尔表达式"，五项相加就是该生总额，五个 `if` 收敛成一个表达式：

$$money = 8000\,[a>80 \wedge p \geqslant 1] + 4000\,[a>85 \wedge e>80] + 2000\,[a>90] + 1000\,[a>85 \wedge w=Y] + 850\,[e>80 \wedge c=Y]$$

注意各条件都是**严格**比较：$a = 80$ 不算 $>80$，$e = 80$ 不算 $>80$；只有论文数是 $p \geqslant 1$（即 $p \geqslant 1$，0 篇不命中）。

求最高者与全班总和可以合并在同一趟遍历中完成：顺序扫描，`total` 累加每人金额，同时用 `amount > top_money` 更新冠军。这里用**严格大于**而不是 `>=`——并列时先出现者已经占据冠军，后来的相同金额不会覆盖它，正好满足"多个最高输出第一个"的要求。整个过程只需一遍扫描，$O(n)$ 时间、$O(1)$ 额外空间。

### 复杂度

- 时间：每名学生只算一次 `money()`，共 $n$ 次，五项判定为 $O(1)$，总计 $O(n)$。
- 空间：除输入行与三个标量外无额外使用，$O(n)$（输入本身）+$O(1)$。

## 总结

五项独立可叠加的奖学金，用"金额 $\times$ 布尔条件"的求和式一次算清，避免五个 `if` 分支；最高者与全班总和合并在一趟扫描里，冠军更新用严格大于天然实现"并列取先"。整体 $O(n)$ 时间、$O(1)$ 额外空间。

## 形式化题目

给定一棵包含 $n$ 个节点的树，边长均为 $1$。
初始有 $m$ 个节点拥有“第一类超能力”（称作红点）。
对于剩下的任意节点，如果该节点到所有红点的**最短距离**落在 $[l, r]$ 区间内，则该节点拥有“第二类超能力”（称作绿点）。
一个点受到的“磁场强度”定义为：所有红点到该点的**距离平方和**，加上所有绿点到该点的**距离和**。
共有 $k$ 次查询，每次查询给定一个节点 $u$，求该点受到总的“磁场强度”。

数据范围：$n, m, k \le 5 \times 10^5$。

## 正解

### 思路

第一步，确定绿点：
多源 BFS 可以快速求解每个点到最近红点的距离。我们将所有初始的红点加入队列并使得距离为 $0$，进行一次 BFS。对于每个点 $i$，若求出的最短距离在 $[l, r]$ 之间，则标记为绿点。

第二步，换根 DP：
查询次数 $k$ 高达 $5 \times 10^5$，因此我们必须预处理出所有点作为询问点时的答案，总复杂度应控制在 $O(n)$。
设 $cnt$ 为红点数量，$dis$ 为红点距离和，$dis2$ 为红点距离平方和。
以任意节点（例如 1 号节点）为根将无根树转为有根树。

**子树内贡献（自底向上）**
由于 $(d+1)^2 = d^2 + 2d + 1$，对于当前节点 $u$ 的某一儿子 $v$：
$cnt[u] += cnt[v]$
$dis[u] += dis[v] + cnt[v]$
$dis2[u] += dis2[v] + 2 \times dis[v] + cnt[v]$
同理可以求绿点的 $ycnt$ 和 $ydis$ 贡献。

**全局贡献（自顶向下）**
在得知父节点 $u$ 的全局结果后，减掉儿子 $v$ 子树中自带的部分，剩下便是“子树外”的贡献。
其余红点数量：$rem\_cnt = cnt[1] - cnt[v]$
其余红点的距离和：$rem\_dis = dis[u] - (dis[v] + cnt[v])$
其余红点的平方和：$rem\_dis2 = dis2[u] - (dis2[v] + 2 \times dis[v] + cnt[v])$
这些子树外的红点对 $v$ 的贡献会因边长 $+1$ 而变化：
$dis[v] += rem\_dis + rem\_cnt$
$dis2[v] += rem\_dis2 + 2 \times rem\_dis + rem\_cnt$
对绿点的维护以此类推。

为了避免在链状极限数据下递归爆栈，利用 BFS 序来代替递归遍历实现自底向上和自顶向下的迭代。

### 复杂度

- 时间复杂度：多源 BFS 求最短路的时间为 $O(n)$，求 BFS 序的时间为 $O(n)$，两次迭代换根 DP 遍历各为 $O(n)$。因此总时间复杂度为 $O(n)$。
- 空间复杂度：需要若干长为 $n$ 的数组维护 $cnt, ycnt, dis, dis2, ydis$ 及图结构，总体空间复杂度为 $O(n)$。

## 总结

- **坑点一**：输入可能在同一个位置重复给出超能力点，需要在读取时进行去重操作（直接利用 `ts[u] = 1` 覆盖即可），避免将其计数多次。
- **坑点二**：树深度极端时可达到 $O(n)$，传统的递归 DFS 换根不仅极慢甚至会导致爆栈，通过一次普通 BFS 取出层序遍历顺序，正向与逆向迭代即可安全实现 DP 转移。
- **坑点三**：距离的平方和能够达到 $N \times N^2 = 1.25 \times 10^{17}$ 级别，所以相关 DP 数组及计算过程必须使用 `long long`，否则会发生整型溢出。

## 形式化题目

给定一个长度为 $n$ 的数组 $A$。每一秒钟，数组会通过变换变成长度减少 $1$ 的新数组 $A'$，变换规则如下：
1. 如果当前数组 $A$ 的长度 $n$ 为偶数，则 $A'[i] = A[i] + A[i+1]$（$1 \le i < n$）。
2. 如果当前数组 $A$ 的长度 $n$ 为奇数，则 $A'[i] = A[i] - A[i+1]$（$1 \le i < n$）。

经过 $n-1$ 秒后，数组只剩下一个数字。求该数字对 $10^9+7$ 取模后的结果。

**数据范围**
- 对于 40% 的数据，满足 $n \le 1000$。
- 对于 100% 的数据，满足 $1 \le n \le 10^5$，$1 \le A_i \le 10^9$。

**其他约束**
- 题面未给出具体的时空限制，常规可假设为 1000ms / 128MB（`config.json` 的 `"memory": 128`）。
- 输入为单组数据。第一行为 $n$，接下来一行为 $n$ 个整数。

## 正解

### 思路

朴素的做法是直接模拟上述过程，因为每次操作长度减 $1$，总共进行 $n-1$ 次操作，每次操作需要遍历数组，所以总时间复杂度为 $O(n^2)$，可以拿到 $40\%$ 的分数。
由于 $n \le 10^5$，我们要寻找更低复杂度的算法。

本题可以通过多项式和位移算子 $E$（满足 $E A_i = A_{i+1}$）来简化操作：
- 长度为偶数时的操作（$A[i]+A[i+1]$）相当于对原数组乘上多项式 $1+E$。
- 长度为奇数时的操作（$A[i]-A[i+1]$）相当于对原数组乘上多项式 $1-E$。

最后数组剩下的唯一一个元素，相当于把原数组 $A$ 作用了一系列多项式的乘积 $P(E)$ 后取其首项，即为 $\sum_{j=0}^{n-1} c_j A_{j+1}$，其中 $c_j$ 是多项式 $P(x)$ 中 $x^j$ 的系数。

我们分析 $P(x)$ 的规律。由于数组长度从 $n$ 逐渐递减到 $2$，奇偶性交替出现：
- **如果 $n$ 是奇数**（设 $n = 2k + 1$）：
  操作的多项式依次为 $(1-x)$，$(1+x)$，$(1-x)$，$(1+x)$ ... 并以 $(1+x)$ 结尾。
  总共有 $2k$ 步，恰好包含了 $k$ 次 $(1-x)$ 和 $k$ 次 $(1+x)$。
  所以 $P(x) = ( (1-x)(1+x) )^k = (1-x^2)^k$。
  将式子二项式展开，非零项只能是偶数次项 $x^{2p}$，其系数为 $(-1)^p \binom{k}{p}$。奇数次项系数则为 $0$。

- **如果 $n$ 是偶数**（设 $n = 2k$）：
  操作的多项式依次为 $(1+x)$，$(1-x)$，$(1+x)$ ... 并以 $(1+x)$ 结尾。
  总共有 $2k-1$ 步，包含了 $k$ 次 $(1+x)$ 和 $k-1$ 次 $(1-x)$。
  所以 $P(x) = ( (1+x)(1-x) )^{k-1} \cdot (1+x) = (1-x^2)^{k-1} (1+x)$。
  展开后可以看出，$x^{2p}$ 和 $x^{2p+1}$ 拥有相同的系数，均为 $(-1)^p \binom{k-1}{p}$。

利用上述公式，我们可以很轻松地通过组合数直接求出 $A$ 数组中每个元素最终在答案中的系数。提前 $O(n)$ 预处理阶乘以及逆元后，就能在 $O(n)$ 时间内算出最终答案。

### 复杂度

- **时间复杂度**：$O(n)$。预处理阶乘及其逆元需要 $O(n)$ 的时间（加上一次求逆元的 $O(\log MOD)$），随后遍历计算每个元素的系数并累加同样耗时 $O(n)$，总体时间复杂度 $O(n)$。
- **空间复杂度**：$O(n)$。需要大小为 $O(n)$ 的数组来存储原数据序列，以及预处理的阶乘与逆元。

## 总结

- 这是一道经典地利用位移算子和多项式，把多轮交替的差分与相邻求和问题转化为组合数求解的题目。
- 解题关键是敏锐地发现多项式相乘后引发的奇偶消项效应：$(1-x)(1+x) = 1-x^2$。
- 代码实现细节：由于计算过程中系数有可能为负数，在 C++ 计算中应当正确处理对取模的影响，常采用 `(val % MOD + MOD) % MOD`。

## 形式化题目

给定 $N$ 个数字 $A_1, \dots, A_N$。对每个 $i$，求

$$ans_i = \#\{\, j \ne i : A_j \mid A_i \,\}$$

即「有多少个**其他**位置的数字是 $A_i$ 的约数」。数据范围：$1 \leqslant N \leqslant 10^5$，$1 \leqslant A_i \leqslant 10^6$。

样例中 $A = [2, 1, 2, 3, 4]$：$A_2 = 1$ 的约数只有 $1$（自己的数字），没有别人的数字整除它，答案 $0$；$A_5 = 4$ 时整除 $4$ 的数字有牛 $1$ 的 $2$、牛 $2$ 的 $1$、牛 $4$ 的 $2$ 和它自己的 $4$，共 4 份，扣除自己后答案 $3$。注意牛 $1$ 和牛 $4$ 的数字都是 $2$，各占一份。

## 正解

### 思路

**朴素做法**：对每个 $A_i$ 用 $\sqrt{A_i}$ 的试除枚举它的全部约数 $d$，累加数字 $d$ 的出现次数 $\mathrm{cnt}[d]$。单次 $O(\sqrt{M})$，总计 $O(N\sqrt{M}) \approx 10^8$，而且多头奶牛数字相同时完全重复计算——瓶颈在于「每个约数 $d$ 与每个整除它的询问 $A_i$」这一对关系被反复判定。

**换个方向枚举**：注意

$$ans_i + 1 = \sum_{d \mid A_i} \mathrm{cnt}[d]$$

的右端对**所有询问共享**。与其每个询问单独找约数，不如反过来：对每个出现过的数字 $d$，把 $\mathrm{cnt}[d]$ 加到**所有以 $d$ 为约数的值**上——也就是 $d$ 的所有倍数 $d, 2d, 3d, \dots$。这与埃氏筛的枚举方式相同，总步数为调和级数

$$\sum_{d=1}^{M} \frac{M}{d} = O(M \log M) \approx 1.4 \times 10^7 \quad (M = \max A_i \leqslant 10^6)$$

远小于 $O(N\sqrt{M})$。最后 $\mathrm{div\_sums}[A_i] - 1$ 就是答案：减 1 是因为「$A_i$ 自己整除自己」也被算进去了，而牛不拍自己。

**样例推演**（$A = [2, 1, 2, 3, 4]$）：下表展示每个出现过的数字 $d$ 如何把 $\mathrm{cnt}[d]$ 广播到自己的倍数上，最后汇总出 $\mathrm{div\_sums}[v]$。

| 广播源 $d$ | $\mathrm{cnt}[d]$ | 被广播的倍数（值域 $M=4$） | 广播后 $\mathrm{div\_sums}$ 的变化 |
| :-: | :-: | :- | :- |
| $1$ | $1$ | $1, 2, 3, 4$ | 每个值 $+1$ |
| $2$ | $2$ | $2, 4$ | $2, 4$ 再各 $+2$ |
| $3$ | $1$ | $3$ | $3$ 再 $+1$ |
| $4$ | $1$ | $4$ | $4$ 再 $+1$ |

广播完成后 $\mathrm{div\_sums} = [\_, 1, 3, 2, 4]$（下标 0 弃用）。逐头牛查表再减 1：$A=2$ 得 $3-1=2$，$A=1$ 得 $1-1=0$，$A=2$ 得 $2$，$A=3$ 得 $2-1=1$，$A=4$ 得 $4-1=3$，与样例输出 `2 0 2 1 3` 一致。

观察重点：**数字 2 出现了两次，它一次广播就同时照顾了两头询问牛**——这正是「按约数广播」优于「按询问分解」的原因；而值 4 接收了来自 $1, 2, 4$ 三次广播，恰好对应 $4$ 的三个约数。

### 复杂度

- 时间：统计 $O(N)$ + 倍数广播 $O(M \log M)$ + 查表输出 $O(N)$，总计 $O(N + M \log M)$，$M \le 10^6$。与标准 C++ 解法同阶；实测 13 组数据全部通过，最慢单测 0.04s（Python 侧无 TLE 压力）。
- 空间：$\mathrm{cnt}$ 与 $\mathrm{div\_sums}$ 两个长度 $M+1$ 的数组，$O(M)$，实测峰值约 26MB，远低于 128MB 限制。

## 总结

- 关键转化：编号连续使「拍编号是 $A_i$ 约数的牛」变成纯粹的整除计数 $ans_i = \sum_{d \mid A_i} \mathrm{cnt}[d] - 1$，与牛的实际数字无关。
- 关键优化：把「每个询问分解约数」反转为「每个出现过的数字向倍数广播」，用埃氏筛式的调和级数枚举把 $O(N\sqrt{M})$ 降到 $O(M \log M)$，重复数字天然合并。
- 易错点：别忘了减去「自己整除自己」的那一份；值域上界应取 $\max A_i$ 而非固定上界。
- 延伸：同款「值域上做倍数/约数方向的调和级数枚举」适用于一切 $\sum_{d \mid v} f[d]$ 型批量询问。

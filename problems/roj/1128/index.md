## 题目描述

给定 $n$ 行 $m$ 列图像的灰度值（$1 \le n, m \le 100$，$0 \le$ 灰度 $\le 255$），做一次模糊处理：四周最外侧像素不变；中间每个像素的新灰度值为其自身与上下左右四个像素**原**灰度值的平均，舍入到最接近的整数。输入第一行为 $n$ 和 $m$，接下来 $n$ 行每行 $m$ 个整数表示灰度值；输出处理后的图像，保持与输入相同的行列形状。

样例输入：

```
4 5
100 0 100 0 50
50 100 200 0 0
50 50 100 100 200
100 100 50 50 100
```

样例输出：

```
100 0 100 0 50
50 80 100 60 0
50 80 100 90 200
100 100 50 50 100
```

## 思路

把原图存入 `src` 并复制一份作结果 `res`，复制即完成"边界不变"。内部像素（第 $2 \sim n-1$ 行、$2 \sim m-1$ 列）从 `src` 读十字五格求和、往 `res` 写，循环范围同时保证不越界、不脏读。和 $s$ 是整数，$s/5$ 不会出现 $.5$ 平局，$(2s+5)/10$ 就是四舍五入，全程不碰浮点。

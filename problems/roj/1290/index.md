## 形式化题目

给定容量 $T$ 与 $M$ 个物品，第 $i$ 个物品的花费为 $\text{cost}_i$、价值为 $\text{value}_i$，每个物品**至多取一次**。求

$$\max \sum_{i \in S} \text{value}_i \quad \text{s.t.} \quad \sum_{i \in S} \text{cost}_i \leqslant T$$

其中 $S \subseteq \{1, 2, \dots, M\}$。（$1 \leqslant T \leqslant 1000$，$1 \leqslant M \leqslant 100$，$\text{cost}_i, \text{value}_i \in [1, 100]$。）

样例：$T = 70$，三株草药的 $(\text{cost}, \text{value})$ 为 $(71, 100), (69, 1), (1, 2)$，答案是 $3$。

## 正解

### 思路

**朴素做法**：枚举 $M$ 株草药的每个子集，检查总时间是否超过 $T$，在合法子集里取最大价值。复杂度 $O(2^M \cdot M)$，$M$ 最大 $100$ 时是指数级，完全不可行。它的毛病在于把"选哪些"整体枚举，大量共享前缀的选择结果被反复重算。

**建立状态**：既然约束只有"总时间不超过 $T$"这一条上界，就按容量递推。先写二维状态

$$dp[i][j] = \text{只考虑前 } i \text{ 株草药、总时间不超过 } j \text{ 时的最大价值}$$

第 $i$ 株草药只有两种归宿，取较大者：

$$dp[i][j] = \max\bigl(dp[i-1][j],\ dp[i-1][j - \text{cost}_i] + \text{value}_i\bigr) \qquad (j \geqslant \text{cost}_i)$$

不采它，价值就是前 $i-1$ 株在容量 $j$ 下的最优值；采它，就先腾出 $\text{cost}_i$ 的时间，再加上它的价值。$j < \text{cost}_i$ 时容量不够，只能不采，故 $dp[i][j] = dp[i-1][j]$。

**压掉一维**：第 $i$ 层只依赖第 $i-1$ 层，所以物品维可以滚动掉，只留一维 `dp[j]`：

```
dp[0..T] = 0
for 每株 (cost, value):
    for j = T 递减到 cost:
        dp[j] = max(dp[j], dp[j - cost] + value)
输出 dp[T]
```

**为什么容量必须倒序扫？** 这是 0/1 背包区别于完全背包的关键。倒着更新 `dp[j]` 时，被引用的 `dp[j - cost]` 下标更小、本轮还没轮到它被改写，因此它还是"只看前 $i-1$ 株"的旧值——每株草药最多被计入一次。若改成从 $cost$ 正序扫，`dp[j - cost]` 可能已经在本轮被当前这株更新过，同一株草药就会被重复采入，那变成了完全背包。

以样例 $T = 70$、草药依次为 $(71, 100), (69, 1), (1, 2)$ 为例，取几个关键容量看 `dp` 如何逐株变化：

| 阶段 | $\text{dp}[0]$ | $\text{dp}[1]$ | $\text{dp}[68]$ | $\text{dp}[69]$ | $\text{dp}[70]$ |
| --- | --- | --- | --- | --- | --- |
| 初始（一株未考虑） | 0 | 0 | 0 | 0 | 0 |
| 放入 $(71, 100)$ | 0 | 0 | 0 | 0 | 0 |
| 放入 $(69, 1)$ | 0 | 0 | 0 | 1 | 1 |
| 放入 $(1, 2)$ | 0 | 2 | 2 | 3 | 3 |

逐行读这张表：第一株草药要 $71$ 的时间却只有 $70$ 可用，内层循环上下界交叉直接跳过，整行不变；第二株 $69$ 能塞进剩余时间，于是 $\text{dp}[69] = \text{dp}[70] = 1$；第三株只要 $1$ 的时间、值 $2$，倒序更新时它被叠加上去，$\text{dp}[70] = \text{dp}[69] + 2 = 1 + 2 = 3$，对应的选择正是后两株草药。最终 $\text{dp}[70] = 3$，与样例输出一致。

### 复杂度

- 时间：$O(MT)$。外层 $M$ 株，内层最多扫 $T+1$ 个容量，$M \leqslant 100$、$T \leqslant 1000$ 时约 $10^5$ 次转移。
- 空间：$O(T)$，只保留一维 `dp` 数组（二维写法需要 $O(MT)$）。

## 总结

本题是 0/1 背包的裸题：把"采不采某株草药"抽象成物品的取与不取，状态只需记录已用时间，转移式在"不采 / 采"之间取较大值。一维滚动数组是关键技巧——压掉物品维后，用**倒序**枚举容量来维持"每件物品只用一次"的语义。识别"总花费有上界、每件物品至多取一次、目标为总价值最大"这三个特征，就能直接套用本模板。

## 图示解析

这张图串起本题从建模到得到答案的主线：

```text
问题：M 株草药选子集，总时间 <= T，最大化总价值
`- 朴素枚举子集 O(2^M * M) 指数级，不可行
   `- 观察：约束只有容量上界，可按容量递推
      `- 二维 dp[i][j] = max(不采第 i 株, 采第 i 株)
         `- 第 i 层只依赖第 i-1 层 -> 压成一维 dp[j]
            `- 容量倒序扫，保证每株只用一次（正序 = 完全背包）
               `- 答案 = dp[T]
```

先看第一个节点：输入就是一组带花费与价值的物品，没有任何额外结构。
第二个节点说明朴素做法的瓶颈在于指数级子集枚举、共享前缀被重复计算。
第三个节点是本题的建模决定——按容量定义状态，把"选哪些"转化为"每个容量下的最优值"。
第四个节点是空间优化：滚动数组把物品维压掉，代价是必须固定转移顺序。
最后一个节点给出正确性关键与答案位置：倒序遍历保住 0/1 语义，$dp[T]$ 即所求最大值。

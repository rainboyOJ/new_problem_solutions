## 形式化题目

给定一个整数 $N$（$-10^9 \leqslant N \leqslant 10^9$），判断它的符号：$N > 0$ 输出 `positive`，$N = 0$ 输出 `zero`，$N < 0$ 输出 `negative`。

样例：$N = 1$，输出 `positive`。

## 正解

### 思路

最直接的想法是**三分支 `if-elif-else`**：逐个比较 $N$ 与 0，命中哪支输出哪个单词。参考实现 `std.cpp` 把它压成嵌套三元表达式的形式，但两层嵌套的三元需要读者脑内展开，而且 `positive/zero/negative` 三个字符串散落在三处，映射关系被分支结构遮住了。

换个角度想：三个条件 $N>0$、$N=0$、$N<0$ 两两互斥、又覆盖全数轴，它们要区分的信息其实只有一个——**符号值** $\operatorname{sgn}(N)$。既然如此，先把符号值一次算出来，三个条件就坍缩成 $\{-1, 0, 1\}$ 内的一次查表。

Python 里算符号值的惯用式是 $(N>0) - (N<0)$：`bool` 是 `int` 的子类（`True == 1`、`False == 0`），两个真值指示器相减恰好落在 $\{-1, 0, 1\}$——正数得 $1-0$，零得 $0-0$，负数得 $0-1$。互斥性保证两个指示器不同时为 1，完备性保证至少一支命中，所以差值就是所在分支的编号。三个分支与符号值的对应如下：

| $N$ 所在分支 | 符号值 $(N>0)-(N<0)$ | 查表输出 |
| --- | --- | --- |
| $N > 0$ | $1 - 0 = 1$ | `positive` |
| $N = 0$ | $0 - 0 = 0$ | `zero` |
| $N < 0$ | $0 - 1 = -1$ | `negative` |

观察重点：符号值的三个可能取值 $\{-1, 0, 1\}$ 恰好与映射表的三个键一一对应——互斥保证查到的单词唯一，完备保证查表不落空（不会 `KeyError`）。这一步把"三次比较 + 三个分支"换成了"一次表达 + 一次下标访问"，分支语句整体消失。

## 总结

"判断数正负"是"三分支 → 符号值查表"的语法入门题：互斥完备的三个条件先坍缩成 $\operatorname{sgn}(N) \in \{-1, 0, 1\}$（惯用式 `(n > 0) - (n < 0)`），再用字典一次查表替掉 `if-elif-else`。坑只在输出形式：三个英文单词要逐字符对上题面，不能输出 `+`/`-`/`0`。实测 10 组真实数据全部 PASS，每例约 0.015 s、峰值 14.5 MB，相对 1000 ms / 128 MB 的限制毫无压力。

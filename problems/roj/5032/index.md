## 形式化题目

给定两个正整数 $a$ 和 $b$（$1 \le a \le b \le 20000$）。
求在闭区间 $[a, b]$ 内所有的素数。要求每个素数占一行输出。
如果区间内不存在素数，则**不输出任何内容**（输出总共 0 字节）。

## 正解

### 思路

题目要求找出 $[a, b]$ 区间内所有的素数。由于数据范围 $b \le 20000$，区间长度不大，我们可以直接遍历区间内的每一个数 $x \in [a, b]$，然后单独判断 $x$ 是否为素数。

判断一个整数 $x$ 是否为素数的常规做法是“试除法”：
1. 若 $x < 2$，则 $x$ 既不是素数也不是合数（例如 $1$ 不是素数），直接返回 `false`。
2. 若 $x \ge 2$，我们尝试用从 $2$ 开始的正整数 $i$ 去除 $x$。如果遇到 $x \bmod i = 0$，说明 $x$ 有非平凡的约数，是一个合数。
3. 关键在于优化：合数的约数总是成对出现的。如果 $x = i \times j$，其中 $i \le j$，那么必然有 $i^2 \le x$，也就是 $i \le \sqrt{x}$。因此，我们在试除时，只需要枚举到 $i = \lfloor \sqrt{x} \rfloor$ 即可。在代码中通常写为 `i * i <= x`，以避免浮点开方的精度误差。

在主函数中，枚举 $[a, b]$ 间的所有整数，如果 `is_prime(x)` 为真，就输出 $x$ 并换行。

### 复杂度

- **时间复杂度**：判断单个数 $x$ 是否为素数需要 $O(\sqrt x)$ 时间。对于区间 $[a, b]$，最坏情况下需要判断所有数，时间复杂度为 $O((b-a+1)\sqrt b)$。在 $b \le 20000$ 时，最坏情况（如 $a=1, b=20000$）的理论上界约为 186 万次。经过实测，实际约 30 万次内层迭代，远小于时限，最坏点运行时间极短（C++ 约 9 ms，Python 约 30 ms）。
- **空间复杂度**：由于只是枚举并输出，未使用额外的大型数组或数据结构，空间复杂度为 $O(1)$。

## 总结

1. **算法**：枚举 $[a, b]$，用试除法判素数；时间复杂度 $O((b-a+1)\sqrt b)$。
2. **★★ 空输出是 0 字节而非空行**（本题最易错）：当区间内没有素数时，输出必须是 **0 字节** 而非空行。例如 `1 1` 与 `20000 20000` 测试点都是 0 字节。
   - **V1 反事实**：如果在逻辑外无条件输出换行 `\n`（使得无素数点变为空行输出），会导致测试点 10/10 全部失败。
3. **★ 四种输出写法对照表**（以 Python 为例）：

| 写法 | 结果 | 分析 |
|---|---|---|
| `per-prime write`（每个素数各自写） | **10/10** ✅ | 安全、符合标准的输出习惯。 |
| `write(join + '\n')`（仅非空时） | **10/10** ✅ | 拼好串再输出，仅在串非空时带 `\n`。 |
| `print(join)` | **8/10** ❌ | Python `print` 自带末尾换行。无素数时 `print('')` 会输出一个 `\n`（1 字节），导致空输出点错。 |
| `join` 无尾换行 | **2/10** ❌ | 所有素数挤在一行或违背了最后一行自带行尾换行的标准规范。 |

4. **1 不是素数**；当 $a = b$ 且为合数时也无数可输；**全部 20000 个 $a=b$ 单点已验证**，其中 17738 个无素数点全部输出 0 字节，正确处理边界非常关键。
5. **★ 验证强度摘要**：本题解使用了异源 Eratosthenes 筛交叉验证；针对 17 组大区间/边界进行严格测试验证；最坏点性能表现优异（C++ 9.3 ms / Python 30.6 ms）；V2 字面量不含硬编码素数表，试除起点 `2` 是唯一内嵌常数。
6. **复杂度**：本题运算量实际很小，实际约 30 万次内层迭代，最坏上界约 186 万次，不构成性能瓶颈。

## 形式化题目

把整数写成"符号 + 十进制数字串"：

$$N = s \cdot \overline{d_1 d_2 \cdots d_m}, \qquad s \in \{+1,\,-1\},\ d_1 \neq 0\ (m > 1),$$

其中 $\overline{d_1 d_2 \cdots d_m}$ 表示把这些数位依次连成一个十进制整数，$d_i \in \{0,1,\dots,9\}$ 是它的第 $i$ 位（$d_1$ 是最高位）。

定义反转

$$\operatorname{rev}(N) = s \cdot \overline{d_m d_{m-1} \cdots d_1},$$

即**保留符号、只颠倒数位顺序**，并要求结果按整数的常见形式书写：除非结果本身是 $0$，否则最高位不能是零。

样例：$N = -380$ 时 $s = -1$，数位串 `380` 反转为 `083`，去掉最高位的零得 `83`，结果为 $-83$；$N = 123$ 时结果为 $321$；$N = 0$ 时结果为 $0$。

## 正解

### 思路

本题没有算法瓶颈：$|N| \leqslant 10^9$ 说明位数 $d \leqslant 10$，而任何正确算法都必须看完这 $d$ 个数位，所以复杂度下界就是 $O(d)$。标准 C++ 解法 `while (n) { r = r * 10 + n % 10; n /= 10; }` 正是 $O(d)$ 的。真正要处理的是**语义**：符号、末尾零、以及零本身；Python 的字符串操作可以各用一个表达式解决这三点，且仍保持 $O(d)$。

**第一步：把符号和数位拆开。** 负号必须永远待在最高位，绝不能参与反转，所以先记下符号，再只对绝对值做反转：

```python
sign = "-" if value < 0 else ""     # 负号单独摘出来，最后拼回最前
digits = str(abs(value))            # 只反转数位，不碰符号
```

这里用 `abs` 而不是 `lstrip("-")` 的理由是：Python 的 `int` 读入时已经吃掉了输入里可能出现的 `+` 和前导零，`str(abs(value))` 得到的必然是一段无前导零的干净数位串；连 `-0` 这种写法也会被统一解析成 `0`，直接落到正数分支。

**第二步：反转数位，并去掉反转后跑到最前面的零。** 原数末尾的零反转后成了前导零，而题面要求"最高位不为零"，正是要删掉它们：

```python
reversed_digits = digits[::-1].lstrip("0") or "0"
```

把样例逐位摊开看这次的"搬家"：

| 输入 | 符号 $s$ | 原数位 $d_1\cdots d_m$ | 反转后 | `lstrip("0")` 后 | 输出 |
| --- | --- | --- | --- | --- | --- |
| `123` | 空 | `1 2 3` | `3 2 1` | `321` | `321` |
| `-380` | `-` | `3 8 0` | `0 8 3` | `83` | `-83` |
| `1000` | 空 | `1 0 0 0` | `0 0 0 1` | `1` | `1` |
| `12001` | 空 | `1 2 0 0 1` | `1 0 0 2 1` | `10021` | `10021` |
| `0` | 空 | `0` | `0` | `""` → `"0"` | `0` |

表中各列依次对应符号分离、数位反转、前导零删除与最终拼接。两个容易出错的点都能在表里看出来：

- **只删开头的零，不删中间的零**。`lstrip` 只作用于左端：`12001` 反转得 `10021`，首位是 `1`，中间的 `00` 原样保留，这是对的——它们本来就是反转后的中间数位。
- **原数为 $0$ 时会被删空**。`"0"` 反转还是 `"0"`，`lstrip("0")` 得到空串，而空串不是合法的整数形式，所以用 `or "0"` 兜底还原成 `"0"`。这也正好对应题面那句"除非给定的原数为零"。

**第三步：拼回符号输出**，即 `print(sign + reversed_digits)`。整个流程就是几次长度不超过 10 的字符串操作，没有任何循环和分支嵌套。

### 复杂度

- 时间复杂度：$O(d)$，$d$ 是 $|N|$ 的十进制位数（$d \leqslant 10$）。`str(abs(value))`、切片 `[::-1]`、`lstrip("0")`、字符串拼接各扫一遍数位；任何正确算法都至少要读完这 $d$ 个数位，故 $\Omega(d)$ 是下界。与标准 C++ 数位循环同阶。
- 空间复杂度：$O(d)$，保存 `digits` 与 `reversed_digits` 两个长度不超过 $d+1$ 的字符串；其余为 $O(1)$ 标量。

## 总结

数字反转的难点不在算法而在语义：**符号不参与反转、末尾零反转成前导零要删掉、原数为零时结果仍是零**。把整数拆成"符号 + 数位串"后，Python 用符号判断、`digits[::-1]`、`.lstrip("0") or "0"` 三个表达式分别解决这三点，复杂度 $O(d)$ 与 C++ 数位循环同阶，$d \leqslant 10$ 时实测单点 0.018 s / 14.5 MB，相对 1000 ms / 128 MB 的限制非常宽裕。

## 形式化题目

给定平面直角坐标系中的 $n$ 个初始点，以及 $m$ 个操作。操作分为两类：
1. `1 x y`：在平面上新增一个点 $(x, y)$。
2. `2 x y`：查询距离点 $(x, y)$ 最近的**已存在点**的曼哈顿距离。

曼哈顿距离定义为：$dist(A,B) = |A_x-B_x| + |A_y-B_y|$。

**数据范围：**
- 初始点数 $n \le 5\times 10^5$，后续操作数 $m \le 5\times 10^5$。
- 坐标范围 $0 \le x, y \le 10^6$。

## 正解

### 思路

本题需要维护一个动态的点集，并支持查询给定点到点集中所有点的最小曼哈顿距离。
根据曼哈顿距离的定义 $dist(A,B) = |A_x-B_x| + |A_y-B_y|$，其中的绝对值符号可以通过分类讨论去掉。
对于查询点 $Q(x_q, y_q)$，平面上的点可以分为四个象限。以 $P(x, y)$ 在左下象限（$x \le x_q$ 且 $y \le y_q$）为例，距离可化简为：
$$dist(P, Q) = (x_q - x) + (y_q - y) = (x_q + y_q) - (x + y)$$

要使距离最小，由于 $(x_q + y_q)$ 对该次查询是常数，我们需要找到满足以下三个条件的插入点，使得 $(x_i + y_i)$ 最大：
1. $t_i \le t_q$（时间在查询操作之前）
2. $x_i \le x_q$
3. $y_i \le y_q$

这构成了经典的三维偏序问题，其中：第一维（时间）利用数组自带的先后顺序表示；第二维（横坐标）利用 CDQ 分治内部归并排序解决；第三维（纵坐标）在分治合并时利用树状数组维护。

**核心技巧：坐标轴翻转**
为了处理其他三个象限，我们不需要写四遍不同逻辑的 CDQ 分治。只需非常巧妙地**翻转坐标轴**。
定义一个大于坐标最大值的常数 $C$（例如 $C = 1000002$）。
- 左下象限：原坐标 $(x, y)$
- 右下象限：变换为 $(C - x, y)$
- 左上象限：变换为 $(x, C - y)$
- 右上象限：变换为 $(C - x, C - y)$

在变换后，原来的另外三个象限的问题，全部等效映射成了“求左下象限距离”的模型。因此，我们只需要将坐标数组分别做四次相应的翻转操作，然后每次统一调用相同的 CDQ 分治函数，最后将四次结果对当前查询取最小值，即可得到完整且正确的答案。

### 复杂度

- **时间复杂度**：每一遍 CDQ 分治共进行 $\mathcal{O}(\log(n+m))$ 层，每层遍历并操作树状数组需要 $\mathcal{O}((n+m) \log (\max Y))$ 的时间。总共进行 4 遍分治，整体时间复杂度为 $\mathcal{O}((n+m) \log(n+m) \log (\max Y))$。
- **空间复杂度**：由于只存储点信息以及一个大小为 $\max Y$ 的树状数组，空间复杂度为 $\mathcal{O}(n+m + \max Y)$。

## 总结

本题是 CDQ 分治处理三维偏序的经典应用，以下是题目实测与实现细节总结：

1. **原稿缺陷修正**：原稿中的 CDQ 递归基未充分考虑边界，导致在 $n = m = 0$ 时产生段错误。修正方式是在入口或递归基处严格增加 `if (l >= r) return;` 保护，必须处理没有任何点或操作的极值情况。
2. **`MIRROR` 常数（数据盲区）**：坐标翻转常数 $C$ 的取值在数据中存在盲区，数据并没有唯一确定其值，只确定了其**可行区间为 `[1000000, 1000006]`**。任意落在该区间的值均不可区分，原稿选取的 `1000002` 恰在合法区间内（若选 `999999` 则翻转后下界为 0 导致崩溃/TLE；上限受 `MAX_VAL` 约束，如 `MAX_VAL=999900` 时 13 个点失败）。
3. **输入解析规则**：第一行的 $n$ 是初始点数，$m$ 是操作数（而非总操作数！）。通过全 20 个点验证，`tokens == 2 + 2n + 3m` 精确成立，无多余内容。$t$ 只有 1 或 2，不存在“询问时还没有任何点”的测试点，且数据中存在**大量的同坐标重复插入**（例如 `angel5` 重复 933 次，`angel8` 重复 3042 次），实现正确地处理了这些重复点。无 $n=0$ 或 $m=0$ 的数据点。
4. **坐标范围**：全局真实极值为 $minX = minY = 1$， $maxX = 999999$， $maxY = 999998$。题面宣称的坐标 $0$ 和 $10^6$ 从未出现过。
5. **无 CRLF 缺陷**：本题全部 20 个 `.in` 与 `.out` 文件换行符均为严格的 LF（`CR = 0`），并带有结尾换行。

## 形式化题目

$n$ 个人，第 $i$ 人初始工资 $a_i$。共 $m$ 年，每年恰好给 $x$ 人绩效 A（工资 $\times 3$）、$y$ 人绩效 B（$\times 2$），其余人绩效 C（$\times 1$）；**连续两年绩效 C 的人被开除**，且公司不再招新人（保证 $x + y \leqslant n$）。求第 $m$ 年末**在职员工**工资总和的最大值，对 $10^9 + 7$ 取模。

其中 $1 \leqslant n \leqslant 10^5$，$1 \leqslant m \leqslant 10^9$，$1 \leqslant a_i \leqslant 10^5$。

### 样例

样例 1 输入：

```plaintext
2 1 1 1
5 3
```

输出 `21`：只有一年，无人会被开除。工资 5 的人拿 A 涨到 15，工资 3 的人拿 B 涨到 6，$15 + 6 = 21$。

样例 2 输入：

```plaintext
2 2 0 0
5 2
```

输出 `0`：$x = y = 0$，每年所有人都只能拿 C：

| 年份 | 分配 | 在职状态 |
| --- | --- | --- |
| 第 1 年 | 5、2 都拿 C | 各自第 1 个 C，仍在职 |
| 第 2 年 | 5、2 再拿 C | 连续两年 C，双双被开除 |

第 2 年末在职人数为 0，工资总和为 0。

## 正解

### 思路

**朴素做法**是把每年的分配方案枚举出来逐年推进：每年要从在职者中选 $x$ 人拿 A、$y$ 人拿 B，还要记住每个人「上一年是否拿过 C」来决定开除，状态里挂着每个人的工资，方案数是指数级的；改成 DP 也无从下手，因为 $n$ 高达 $10^5$、$m$ 高达 $10^9$，既装不下逐人工资，也跑不动逐年转移。瓶颈在于：**每年的名额是固定的（$x$ 个 3 倍、$y$ 个 2 倍、其余全是 1 倍），而「连续两年拿 C」既可能浪费名额，也可能让人被开除**。突破口就是想清楚这两件事怎么权衡。

**交换引理（同一年内）**：固定其它年份的安排，若某年中工资较高的 $p$ 拿了较小的倍数、工资较低的 $q$ 拿了较大的倍数，把两人这一年的绩效互换，工资和不减——因为两人后续的倍数与这一年的分配互相独立，贡献变化为 $(a_p - a_q)(m_q - m_p) \geqslant 0$。所以**每年的 3 倍名额总是给当前工资最高者、2 倍给次高者**才不亏。

**交换引理（整条链）**：把两个人**全部 $m$ 年**的绩效序列整个互换，每人各自的合法性（拿 C 是否相邻）只取决于自己的序列，每年各类名额数也不变，方案依然合法；贡献变化为 $(a_i - a_j)(F_j - F_i)$，其中 $F$ 是 $m$ 年的总倍数。因此最优方案里**总倍数 $F$ 的大小顺序一定与初始工资 $a$ 一致**——降序对降序，坏差额只会出现在小工资者身上。

**关键观察：开除不是代价，而是「名额零浪费」的手段。** 每年必须恰有 $k = n - x - y$ 人拿 C。拿 C 的人要么自己少涨一次，要么（连续拿两次）被开除、把生前占过的涨薪名额全部浪费掉。反过来想：如果让**工资最小的 $k$ 个人**在第 1、2 年连续拿 C、一次性被开除，那么从第 3 年起在职者恰好剩下 $x + y$ 人，拿 C 名额数降为 0，**每个人年年涨薪**，$x \cdot m$ 个 3 倍名额和 $y \cdot m$ 个 2 倍名额一个不落地全部生效，且由交换引理全部落到该给的人头上。而任何「轮着拿 C 保人」的方案，要么让一批人隔年才涨一次（少用了名额），要么迟早牺牲别人——按交换引理，牺牲和少涨的都只会是最小的工资者，比不过「先把最小的 $k$ 人一次性清退」。

于是 $m \geqslant 2$ 时的最优方案完全确定：

| 阶段 | 分配 | 结果 |
| --- | --- | --- |
| 第 1、2 年 | 最小的 $k$ 人连续拿 C；其余 $x + y$ 人按降序前 $x$ 大拿 A、接下来 $y$ 大拿 B | 最小 $k$ 人第 2 年末被开除 |
| 第 3 ~ $m$ 年 | 在职者恰 $x + y$ 人，每年前 $x$ 大拿 A、接下来 $y$ 大拿 B | 无人再拿 C，无人被开除 |

最终：前 $x$ 大总倍数 $3^m$，接下来 $y$ 大总倍数 $2^m$，被开除的 $k$ 人为 0。记 $S_j$ 为降序前 $j$ 大工资之和，答案为

$$3^m \cdot S_x + 2^m \cdot (S_{x+y} - S_x) \pmod{10^9+7}$$

**最优性上界**：由两条交换引理，最优解中总倍数降序 $F$ 与 $a$ 同序，且可以对年份归纳证明——每一年若不把 3 倍给当前倍数最高的 $x$ 人、2 倍给次高的 $y$ 人，交换即得更优；而任何到第 2 年之后仍「一次都没涨」的人只能靠连续拿 C 苟活、必然已被开除（贡献 0）。所以对每个 $j$，降序前 $j$ 人的倍数和不超过「前 $x$ 人年年 3 倍、接下来 $y$ 人年年 2 倍、其余 0」的前 $j$ 项和；再由分部求和 $\sum_i a_i F_i = \sum_i (a_i - a_{i+1}) \cdot \sum_{j \leqslant i} F_j$（$a_{n+1} = 0$），即得上述上界，且构造的方案恰好取到，故它就是答案。

**$m = 1$ 是唯一例外**：只有一年时没人可能连续两年拿 C，**开除根本不会发生**，最小的 $k$ 人虽然拿 C 但照领原工资，答案多出一项 $(S_n - S_{x+y})$：

$$3 \cdot S_x + 2 \cdot (S_{x+y} - S_x) + (S_n - S_{x+y})$$

按上述公式代入样例 1：$3 \times 5 + 2 \times 3 + 0 = 21$；代入样例 2：$x = y = 0$，$S_0 = 0$，答案 $0$。两者均与样例输出一致。

### 复杂度

- **时间**：排序 $O(n \log n)$，前缀和 $O(n)$，两次快速幂 $O(\log m)$，总复杂度 $O(n \log n + \log m)$，与 C++ 正解（排序 + 快速幂）同阶。
- **空间**：$O(n)$ 存工资数组与前缀和，远低于 128MB 限制。
- **Python 风险**：$n = 10^5$ 时排序加读入实测在 0.1s 量级，$m = 10^9$ 由 `pow` 底层快速幂处理，无 TLE 风险。

## 总结

本题的核心是把「连续两年拿 C 被开除」从一个约束看成一种**资源**：每年固定有 $k = n - x-y$ 个 C 名额，与其让名额在一堆人身上轮空（隔年才涨一次），不如让工资最小的 $k$ 人在前两年连续领 C、一次性被开除，换来其余 $x + y$ 人从第 3 年起年年涨薪、名额零浪费。

三个容易踩的边界：

- **$m = 1$ 必须特判**：一年内不可能连续两年拿 C，无人被开除，拿 C 的人照领原工资；
- $x + y = n$（即 $k = 0$）时公式自然退化为人人年年涨薪，无需单独处理；
- 答案要边算边取模，$3^m$、$2^m$ 用 `pow(底, 指数, MOD)` 快速幂，$m$ 到 $10^9$ 也不会超时。

小规模数据（$n \leqslant 6$、$m \leqslant 4$ 的全部指派方案穷举）与官方 10 组测试数据均已核对，公式与精确最优值完全一致。

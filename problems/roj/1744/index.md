## 形式化题目

有 $N$ 个台阶排成一行，第 $i$ 个台阶高度 $H_i$（$0 < H_i \leqslant 10^9$），地面高度 $H_0 = 0$。
把台阶编号集合 $\{1, 2, \dots, N\}$ 分成两个子集 $S_a, S_b$（可以为空），
对 $S = \{P_1 < P_2 < \dots < P_{|S|}\}$ 定义体力

$$\mathrm{cost}(S) = \sum_{i=1}^{|S|} \bigl|H_{P_i} - H_{P_{i-1}}\bigr|, \qquad P_0 = 0,$$

即"从地面出发、按编号递增依次踩过 $S$ 中台阶"的总落差。求
$\mathrm{cost}(S_a) + \mathrm{cost}(S_b)$ 的最小值。

**题面公式疑似漏写绝对值。** 原文求和项写作 $H_{P_i} - H_{P_{i-1}}$，若照字面理解，
求和式会望远镜式相消成 $H_{P_{|S|}} - H_0 = H_{P_{|S|}}$，于是总代价
$= H_{\text{链 }a\text{ 的末台阶}} + H_{\text{链 }b\text{ 的末台阶}}$，把 $N$ 号台阶单独放一条链
（另一条全空）就能得到 $H_N$，样例 $[1,3,1]$ 将输出 $1$ 而不是 $4$。
补上绝对值后样例恰好是 $4$（$S_a = \{1,3\}, S_b = \{2\}$：$1 + 3 = 4$），
因此本题的真实模型是**绝对差之和**，下文一律按它推导。

## 正解

### 思路

**朴素想法。** 枚举每个台阶属于哪条链，$2^N$ 种方案，逐方案算代价。
$N \leqslant 20$ 时勉强可行（对应 10% 档），$N$ 到 $5 \times 10^5$ 时完全不可行。

**把"两条链"写成一条链 + 一个悬挂点。** 关键是找一个能随下标推进的状态。
设 $f_i(x)$ = 处理完前 $i$ 个台阶、**第 $i$ 个台阶是链 $a$ 的末尾**、
链 $b$ 的末尾高度为 $x$ 时的最小总体力。任意一个划分方案，把两条链的末尾编号比较一下，
较大的那个必然是 $N$，所以答案就是 $\min_x f_N(x)$。

递推只关心第 $i+1$ 个台阶接到哪条链上：

1. **接在 $i$ 后面**（仍在链 $a$）：链 $a$ 末尾变成 $H_{i+1}$，链 $b$ 末尾仍是 $x$，
   代价增加 $|H_{i+1} - H_i|$：
   $$f_{i+1}(x) = f_i(x) + c, \qquad c = |H_{i+1} - H_i|.$$
2. **接到另一条链**：链 $b$ 末尾变成 $H_{i+1}$，链 $a$ 末尾停在 $H_i$。
   为了套回"链 $a$ 的末尾是第 $i+1$ 个台阶"这个形状，把两条链**换个名字**，
   于是新状态的自变量是 $H_i$，取值是所有可能的旧 $x$：
   $$f_{i+1}(H_i) = \min_x \bigl(f_i(x) + |H_{i+1} - x|\bigr) = \varphi_i(H_{i+1}).$$

第一式说明 $x \neq H_i$ 的那些位置只是**整体加上同一个 $c$**；第二式只**单点**改写键 $H_i$。
于是只需维护一个"值域上的函数"，每步一次全局加、一次单点下调，外加求
$\varphi(h) = \min_x f(x) + |h - x|$。

**锥形下包络拆成两半。** 把 $|h - x|$ 按 $x \leqslant h$、$x > h$ 拆开：

$$\varphi(h) = \min\Bigl(\; h + \min_{x \leqslant h}\bigl(f(x) - x\bigr),\;\; -h + \min_{x > h}\bigl(f(x) + x\bigr)\;\Bigr).$$

所以只要能在"值域上"查**前缀最小值**和**后缀最小值**，$\varphi$ 就是 $O(\log n)$ 的。
两个量 $A(x) = f(x) - x$ 与 $B(x) = f(x) + x$ 各自被单点下调，
而"全局加 $c$"对它们的影响只是加 $c$，用**全局懒加 `add`** 记账，数组里存 $A - \text{add}$、$B - \text{add}$ 即可。

**值域压缩。** $x$ 的候选只有地面 $0$ 和某个 $H_j$（另一条链的末尾总归是某级台阶或地面），
把 $0$ 与所有 $H_i$ 排序去重后作为值域，$R \leqslant N + 1$。

**为什么单点下调写成 `min` 就够。** 换链后键 $H_{i-1}$ 的真实新值是
$\min\bigl(f_{i-1}(H_{i-1}) + c,\; t\bigr)$。但 $H_{i-1}$ 本身是 $x$ 的合法取值，
所以 $t = \varphi_{i-1}(H_i) \leqslant f_{i-1}(H_{i-1}) + |H_i - H_{i-1}| = f_{i-1}(H_{i-1}) + c$，
真实新值恒等于 $t$，直接取 $\min$ 不会漏。

**答案的维护。** 记 $m_i = \min_x f_i(x)$。新状态要么来自 $x \neq H_i$ 的整体加
（候选 $m_i + c$），要么来自换链（候选 $t$），故 $m_{i+1} = \min(m_i + c,\, t)$，
最后输出 $m_N$。

用样例 $H = [1,3,1]$ 走一遍（$x$ 只可能是 $0, 1, 3$）：

| 步骤 | 动作 | $f$ 的取值 | $m$ |
| --- | --- | --- | --- |
| $i=1$ | 初始化 | $f(0) = 1$ | $1$ |
| $i=2$ | $c=2$，$t=\varphi(3)=1+3=4$ | $f(0)=3,\ f(1)=4$ | $\min(1+2,\ 4)=3$ |
| $i=3$ | $c=2$，$t=\varphi(1)=\min(3+1,\ 4+0)=4$ | $f(0)=5,\ f(1)=4$ | $\min(3+2,\ 4)=4$ |

输出 $4$，与样例一致。

### 复杂度

时间 $O(N \log N)$（排序 + 每个台阶常数次树状数组操作），空间 $O(N)$。
$N = 5 \times 10^5$ 时 C++ 实测最大点 0.087s，峰值内存 17.4MB。
Python 版是同一算法的同阶实现（树状数组换成 `list` + `while` 循环），
实测最大点 1.00s（其余 $N = 5 \times 10^5$ 的点 0.25 ~ 0.3s），
在 1s 限时边缘：若判 TLE，属于语言常数问题，算法本身没有降级。

## 总结

本题的建模难点是"两条链"：把其中一条钉在"当前处理到的台阶"上，另一条的末尾高度当成函数
自变量，$2^N$ 枚举就塌缩成一维 DP $f_i(x)$。递推的两条分支恰好对应两种操作——**全体加**
（接在同一条链后面）与**单点改写**（换链，新值由锥形包络给出），
而 $\varphi(h) = \min_x f(x) + |h - x|$ 通过把绝对值按 $x \lesssim h$ 拆成两半，
化为"前缀最小 / 后缀最小"，用两棵树状数组 + 全局懒加维护，得到 $O(N \log N)$。

几个容易踩的点：

- 题面求和式漏了绝对值，必须按绝对差之和理解，否则样例对不上。
- $x$ 的候选集只有 $\{0\} \cup \{H_j\}$，压缩值域时别忘了把 $0$ 放进去（空链对应 $x = 0$）。
- 换链时改写的键是**上一个台阶**的 $H_{i-1}$（不是 $H_i$），因为换链后"链 $a$ 的末尾"
  变成了原来第 $i-1$ 个台阶。
- 单点更新只会让值变小，所以树状数组直接取 $\min$ 即可，不需要支持"改大"。

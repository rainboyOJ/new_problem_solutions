## 形式化题目

给定一张 $n$ 个点、$m$ 条边的带权有向图，每条边 $(u, v)$ 有权值 $w_{u,v} \geqslant 0$
（允许自环、重边、零权边，边权均为整数且 $0 \leqslant w \leqslant 10^7$）。
设图中的一个环为 $C$，其**平均权值**定义为

$$\mathrm{avg}(C) = \frac{\sum_{e \in C} w_e}{|C|},$$

其中 $|C|$ 是环上的边数。要求写出

$$
\min_{C} \mathrm{avg}(C),
$$

若图中**不存在**任何环，则输出固定字符串 `PaPaFish is laying egg!`；
否则输出该最小值，保留 2 位小数。

$1 \leqslant n \leqslant 1000$，$1 \leqslant m \leqslant 10000$。

## 正解

### 思路

**为什么不能枚举环。** 环的数量可能是指数级的（$n = 1000$、$m = 10000$ 的稠密图里，
简单环的条数远超任何可以枚举的规模），把每个环算一遍平均权值是不可能的。
但题目只要**最小值**，而且目标函数 $\sum w / |C|$ 是"分子 / 分母"的形式，
这类"比值最优"的问题有统一的处理套路：**01 分数规划**。

**关键转化。** 记答案为 $ans$。对任意实数 $\lambda$，考虑把所有边权换成 $w'_e = w_e - \lambda$。
对某个环 $C$：

$$\sum_{e \in C} (w_e - \lambda) < 0
\iff \sum_{e \in C} w_e < \lambda \cdot |C|
\iff \mathrm{avg}(C) < \lambda .$$

于是

$$
\exists \text{ 环 } C:\ \mathrm{avg}(C) < \lambda
\iff \text{图上（以 } w_e - \lambda \text{ 为权）存在负环} .
$$

而 $\exists C: \mathrm{avg}(C) < \lambda \iff ans < \lambda$。所以判定函数

$$f(\lambda) = [\text{边权换成 } w_e - \lambda \text{ 后存在负环}]$$

具有单调性：$f(\lambda) = \text{true} \iff \lambda > ans$。二分 $\lambda$，就能把 $ans$ 逼到任意精度。
这就是本题的全部主体。

**判负环。** 环权为负等价于"负环存在"，标准做法是 SPFA：把 `dis` 全部初始化为 0
（相当于加一个到所有点都连 0 权边的虚拟源点），一次性把所有点压进队列。这样做有两个好处：

1. 不要求图连通——孤立点、多个连通分量都能被照顾到；
2. 起点权值就是 0，不需要对每个点各跑一次单源 SPFA。

负环的判据用**最短路边数**：松弛 $u \to v$ 时令 `cnt[v] = cnt[u] + 1`。
若某个点的最短路已经走了 $\geqslant n$ 条边，这条路径上的 $n+1$ 个顶点必有重复，
删掉中间那段回路后权值不增，因此那个回路就是负环。反之，若没有负环，
任何最短路的边数都不会超过 $n - 1$（否则可以取更短的路），判据不会误报。

`main.cpp` 用的是上面这套 **BFS 版多源 SPFA**（写法接近网络题解的通行版本）；
`main.py` 用的是语义等价的 **DFS 版 SPFA**：沿 DFS 栈松弛，若松弛到的点仍在当前
DFS 栈上，说明沿栈绕回了它，这段回路就是负环。两版判定的含义完全一致
（都是"以 $w_e - \lambda$ 为权的图有无负环"），只是入队开销不同；
DFS 版在 Python 里常数小一个量级，$n=1000, m=10000$ 的最坏点从 1.4 s 降到 0.04 s。

**无环必须单独判。** 如果图本身无环，那么它当然没有负环，$f(\lambda)$ 恒为 false，
二分会把答案压成 $0.00$ 输出出来——这是错的，题面要求输出那一串固定字符串。
所以正式流程先做一次精确判环（DFS 三色标记，迭代版避免爆递归深度），
无环则直接返回。等价说法是：判 $\lambda = 10^7 + 10$ 是否仍有负环，
但显式判环更快、语义也更直白。

**二分的上下界。** 因为 $w_e \geqslant 0$，任何环的平均权值 $\geqslant 0$，故下界取 $0$；
又因为任意环的平均权值不超过它的最大边权，故上界取 $maxw = \max_e w_e$。
迭代 60 次后区间长度 $10^7 / 2^{60} \approx 10^{-11}$，远小于 $10^{-2}$ 的精度需求。

### 复杂度

- **时间**：一次判环 $O(n + m)$；一次 SPFA 判负环最坏 $O(nm)$，但本题图上只有 1000 点、
  10000 边，实测每次判定都在毫秒级（负环一旦存在通常很快就被命中）。
  总复杂度 $O\big((n + m) + \log(\frac{maxw}{\varepsilon}) \cdot nm\big)$，
  二分取 60（C++）/ 40（Python）次，$nm = 10^7$ 是上界而非实际值。
  实测最坏点（$n=1000$、$m=10000$ 随机含环图）：C++ 0.08 s，Python 0.04 s，
  限时 1000 ms 下余量充足。
- **空间**：链式前向星 $O(n + m)$，SPFA 辅助数组 `dis / cnt / inq / que` 各 $O(n)$，
  总计 $O(n + m)$；实测峰值内存 8.3 MB，远小于 128 MB。
- **Python 侧**：40 轮 SPFA 全部跑完的最坏点在 CPython 下约 0.04 s（DFS 版），
  本机实测无 TLE 风险；若换成 BFS 版 SPFA 则会涨到约 1.4 s，故 `main.py` 采用 DFS 版。
  两版算法同阶，没有退化成暴力枚举环。

## 总结

- **比值最优 → 猜答案 + 判定**：看到 $\min \sum a / \sum b$（或本题的 $\sum w / |C|$）
  就应该想到 01 分数规划：二分 $\lambda$，把判定条件整理成"某个和小于 0"，
  于是问题变成"以 $w_e - \lambda$ 为权的图是否存在负环"。
- **负环判定用多源 SPFA**：`dis` 全 0 压入所有点，一次就能处理不连通图，
  判据取"最短路边数 $\geqslant n$"，比"入队次数 $\geqslant n$"更稳。
- **特别小心"无解输出"的分支**：判定函数单调的前提是"答案存在"。
  无环时这个前提不成立，必须提前单独判掉，否则程序会安静地输出错误的 `0.00`。
- **二分界要贴合题面**：因为 $w \geqslant 0$，下界天然是 0（而不是负无穷），
  上界取最大边权就够——这两点都能从数据范围直接读出来。
- 同类题：UVA11090 *Going in Cycle!!*、BZOJ1486 / P3199《最小圈》，
  与本题连"无解输出字符串"和样例都完全一致，是同一道题的不同改编版本。

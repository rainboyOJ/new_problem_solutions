## 形式化题目

给定 $n$ 名选手的 $(报名号 k_i,\ 成绩 s_i)$，$k_i$ 互不相同。设计划录取 $m$ 人，令

$$r = \lfloor m \times 150\% \rfloor = \left\lfloor \frac{3m}{2} \right\rfloor$$

要求：

1. 把选手按成绩从高到低排名（成绩相同时按报名号从小到大），**面试分数线** $L$ = 第 $r$ 名选手的成绩；
2. 输出所有 $s_i \geqslant L$ 的选手（成绩相同会突破计划人数，即"重分扩招"），第一行为"$L$ 和实际进面人数"，随后按上述排名顺序逐行输出报名号与成绩。

输入保证 $r \leqslant n$，即分数线位置一定存在。

以样例 $n=6,\ m=3$ 为例，$r = \lfloor 4.5 \rfloor = 4$，排序后第 4 名的成绩是 88，因此分数线 $L=88$；而 88 分恰好有 2 人重分，最终 5 人进面：

| 名次 | 报名号 | 成绩 | 是否进面 | 说明 |
| :---: | :---: | :---: | :---: | :--- |
| 1 | 1005 | 95 | ✓ | 与 2390 同分，报名号小者在前 |
| 2 | 2390 | 95 | ✓ | |
| 3 | 1000 | 90 | ✓ | |
| 4 | 1001 | 88 | ✓ | 第 $r=4$ 名，其成绩 88 即分数线 |
| 5 | 3239 | 88 | ✓ | 与第 4 名重分，压线进面 |
| 6 | 7231 | 84 | ✗ | 低于分数线 |

观察重点：分数线是**第 $r$ 名的成绩**而不是"第 $r$ 名选手"本身；过滤条件 $s \geqslant L$ 让所有压线同分者一起进面，所以实际人数可以大于 $r$。

## 正解

### 思路

**朴素想法**：先把选手按"成绩降序、同分报名号升序"排好，再定位第 $r$ 名的分数当分数线，最后扫一遍把成绩不低于分数线的人留下。三件事看似三步，其实只需要**一次排序**——因为后两步都能在同一个有序序列上完成。

**优化推导**：

1. **排序键一步到位**。输出顺序本身就是"成绩降序、报名号升序"，于是直接用 `key=lambda p: (-p[1], p[0])`：取负数把降序变升序，第二关键字让同分者按报名号排。这样排序结果既能用来取分数线，又能原样输出，省掉第二次排序或稳定排序的技巧。
2. **分数线 = 一个下标**。排序后第 $r$ 名在 0-index 下标 $r-1$，其分数即 $L$。$\lfloor 1.5m \rfloor$ 用整数运算 `m * 3 // 2` 计算，不引入浮点。
3. **过滤自动处理重分**。有序序列上 `[p for p in ranked if p[1] >= L]` 恰好是一个前缀（因为序列已按成绩降序），它天然保持输出顺序，且把所有压线同分者包括进来——重分扩招不需要任何特判。

完整流程：读入 → 排序 → `L = ranked[r-1][1]` → 过滤 → 输出。边界上，输入保证 $r \leqslant n$ 所以下标不越界；全员同分时整列都是前缀，全部进面且按报名号有序。

## 总结

这题的要点是"让一次排序服务两个需求"：排序键 `(-成绩, 报名号)` 既给出分数线所在的第 $\lfloor 1.5m \rfloor$ 名，又直接是要求的输出顺序；分数线取的是**那一格的分数**，之后用 `成绩 >= 分数线` 过滤，重分扩招、输出顺序都自动成立。整数运算 `m * 3 // 2` 规避浮点，是最稳的写法。

## 题目描述

$n$ 张矩形地毯按编号 $1 \sim n$ 先后平行于坐标轴铺设，后铺的覆盖在先铺的之上。第 $i$ 张地毯由左下角 $(a_i, b_i)$ 及 $x$、$y$ 方向长度 $g_i$、$k_i$ 描述。给定点 $(x, y)$，求盖住它的最上面一张地毯的编号，没有则输出 `-1`；边界和顶点上的点也算被覆盖。

**输入**：第一行整数 $n$；接下来 $n$ 行每行四个正整数 $a_i, b_i, g_i, k_i$；最后一行两个正整数 $x, y$。
**输出**：一行，一个整数表示地毯编号，未被覆盖输出 `-1`。
**样例输入**：`3` / `1 0 2 3` / `0 2 3 3` / `2 1 3 3` / `2 2`，**样例输出**：`3`。

## 思路

地毯是闭矩形，第 $i$ 张盖住 $(x,y)$ 当且仅当 $a_i \le x \le a_i+g_i$ 且 $b_i \le y \le b_i+k_i$。「后铺的在上」等价于覆盖该点的地毯中编号最大者获胜，因此从 $n$ 号倒序枚举，遇到的第一张满足判定的地毯就是答案，一张都没有则输出 $-1$。只有一个询问点，直接 $O(n)$ 扫描即可。

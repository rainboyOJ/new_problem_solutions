## 形式化题目

给定一个 $n \times n$ 网格，每格是 `.`（可通行）或 `#`（障碍）。处在某格时只能移动到上、下、左、右四个相邻格之一，且落点必须是 `.`；A、B 以"行、列"坐标给出，均从 0 开始计数。判断能否从 A 走到 B；A、B 中任意一个是 `#` 时直接判为不能。

以样例第一组（$3 \times 3$）为例，$A = (0,0)$、$B = (2,2)$，下表给出一条合法路线，①②③ 是途经的中间格：

| | 列 0 | 列 1 | 列 2 |
| --- | --- | --- | --- |
| 行 0 | A | # | # |
| 行 1 | ① | ② | # |
| 行 2 | # | ③ | B |

沿 A → ① → ② → ③ → B，每一步都是四方向相邻且落点都是 `.`，所以该组输出 `YES`。

## 正解

### 思路

**朴素做法与它的瓶颈。**看到"能不能从 A 走到 B"，最直接的反应是从 A 出发枚举所有走法，每步试四个方向，走到 B 就报"能"。但 `.` 网格里到处是环：不记录走过哪里，搜索会在环上无限绕圈；即使强制不重复走格子，路线条数也随空格数指数增长。而题目只要一个 `YES`/`NO`——不问方案数、不问最短路，枚举出的绝大多数路线毫无价值。

**观察一：这是连通性问题。**把每个 `.` 格看成一个顶点，四方向相邻的两个 `.` 格之间连一条无向边，`#` 格不进图。于是"能否从 A 走到 B"等价于"B 与 A 是否属于同一连通分量"。

**观察二：走过的点不必再走。**一个点第一次被访问时，从它出发能到达的区域就已经被登记；再次展开它只会重复同一批邻居。给搜索加一个 `seen` 集合，每个点最多入栈一次、展开一次，指数级的路线枚举就被压成对连通分量的线性扫描——这正是 visited 把"枚举路线"优化成"一次搜索"的关键。

**做法。**从 A 出发做一次迭代 DFS：方向偏移存成常量 `DIRS`，弹出栈顶后向四个方向试探，"在界内 ∧ 落点是 `.` ∧ 未访问"三条同时满足（即代码中的 `can_go`）就入栈（**入栈即标记**，防止同一点被重复压栈）；弹到 B 返回 `YES`，栈空返回 `NO`。A 或 B 是 `#` 时开头直接判 `NO`。用显式栈而不是递归：最坏要访问 $n^2 = 10^4$ 个格子，超过 Python 默认递归深度 1000，递归写法会 `RecursionError`；BFS（换成队列）在只问可达时与 DFS 完全等价。

样例二能看到"可达"就是"连通分量"：下表标出从 $A = (0,0)$ 一次搜索覆盖的 11 个格子（✓），其余 `.` 格虽可通行、却与 A 不连通：

| | 列 0 | 列 1 | 列 2 | 列 3 | 列 4 |
| --- | --- | --- | --- | --- | --- |
| 行 0 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 行 1 | # | # | # | ✓ | # |
| 行 2 | . | . | # | ✓ | ✓ |
| 行 3 | # | # | # | ✓ | ✓ |
| 行 4 | B | . | . | # | ✓ |

图例：✓ = 从 A 可达的 `.` 格，`.` = 是 `.` 但与 A 不连通，`#` = 障碍，B = 终点。A 的分量从第 3 列一路向南延伸到 $(4,4)$，而 $B = (4,0)$ 正上方 $(3,0)$ 是 `#`，它和 $(4,1),(4,2)$ 自成一个 3 格孤岛，$(2,0),(2,1)$ 也是孤岛；三个分量互不相交，所以输出 `NO`。这也验证了前置规则：即使不判终点障碍，B 所在分量与 A 不同，答案同样是 `NO`。

### 复杂度

- 时间复杂度：每组 $O(n^2)$。每个 `.` 格最多入栈、展开各一次，每次只检查 4 个方向；判界、判 `#`、查 `seen` 都是 $O(1)$，$k$ 组合计 $O(\sum n^2)$。
- 空间复杂度：$O(n^2)$。`seen` 与栈最坏各保存 $10^4$ 个坐标，网格本身也是 $n^2$。
- 与 C++ 参考实现（同一套 DFS + visited）复杂度同阶，没有任何暴力回退；实测 10 组真实数据全部通过，单组约 0.02s、峰值约 15MB。

## 总结

- 迷宫可达性就是网格图的连通性：一次带 `seen` 的 DFS/BFS 即可，不必枚举路线。
- **入栈即标记**是防重复入栈的关键；`and` 的短路顺序让"判界、判 `#`、判重"合写进一个条件，且越界时不会读数组。
- 起点或终点是 `#` 前置一次判断直接返回，对应题面规则，也避免从障碍点出发。
- Python 用显式栈替代递归，绕开默认 1000 层的递归深度限制；只问可达时 BFS 与 DFS 等价。

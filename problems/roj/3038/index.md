## 形式化题目

给定一个长度为 $n$ 的小写字母串 $S$ 和 $m$ 次询问。每次询问给出四个整数 $l_1, r_1, l_2, r_2$（位置从 $1$ 开始），判断子串 $S[l_1..r_1]$ 与 $S[l_2..r_2]$ 是否完全相同，相同输出 `Yes`，否则输出 `No`。

## 正解

### 思路

**朴素做法的瓶颈**：最直接的办法是每次询问把两个子串逐字符比较，单次询问 $O(r-l+1)$。但 $n, m$ 都可以达到 $10^6$，最坏情况下（每次都问两个长度 $10^6$ 的子串）总操作数约 $10^{12}$，完全不可行。瓶颈在于"每次询问都要重新读一遍整个子串"。

**优化方向：把"比较子串"变成"比较数字"**。如果每个子串都能 $O(1)$ 算出一个几乎不碰撞的"指纹"（哈希值），那么两子串相等就等价于指纹相等。

**前缀哈希**正是这样的工具。把整个串看成 $B$ 进制数（$B$ 是一个大底数，这里取 $131$），定义前缀的哈希值：

$$h[i] = (h[i-1] \times B + \text{code}(s_i)) \bmod MOD$$

其中 $MOD$ 取大素数 $2^{61}-1$，$\text{code}(c)$ 是字符的编号。这样 $h[r]$ 就是 $s_1..s_r$ 这个 $B$ 进制数的值。那么子串 $s_l..s_r$ 的哈希值就是：

$$\text{hash}(l, r) = h[r] - h[l-1] \times B^{r-l+1} \pmod{MOD}$$

直观理解：$h[l-1]$ 是 $s[l..r]$ 前面那一截的高位，乘上 $B^{r-l+1}$ 把它对齐到 $h[r]$ 中同样的位权上，相减后剩下的恰好就是子串本身的值。

| 区间 | 前缀哈希含义 | 提取子串哈希 |
| :--- | :--- | :--- |
| $h[4]$（`aabb`） | $B$ 进制数 $\text{'aabb'}$ 的值 | — |
| $h[2]$（`aa`） | 高位前缀的值 | — |
| $S[3..4]$（`bb`） | — | $h[4] - h[2] \times B^2$ |

以样例 `aabbaabb` 为例：想取子串 $S[3..4] = $ `bb`，就用前缀 $h[4]$（对应 `aabb`）减去 $h[2]$（对应 `aa`）左移两位（乘 $B^2$，即 `aa00`）的贡献，剩下的正是 `bb` 的值。任意区间的指纹都能这样 $O(1)$ 拼出来。

**算法**：预处理出 $h[0..n]$ 和 $B$ 的幂 $p[0..n]$，各 $O(n)$；每次询问比较 $\text{hash}(l_1, r_1)$ 与 $\text{hash}(l_2, r_2)$ 是否相等，$O(1)$。

两个工程细节：

- $MOD$ 取梅森素数 $2^{61}-1$，配合 $B=131$，哈希值分布均匀，$10^6$ 级询问下碰撞概率可以忽略；
- Python 中减法可能出现负数，但 `%` 运算符恒返回非负结果，不需要像 C++ 那样手工加 $MOD$ 调整。

### 复杂度

- 时间复杂度：预处理 $O(n)$，每次询问 $O(1)$，总计 $O(n + m)$，约 $2 \times 10^6$ 次运算。
- 空间复杂度：$O(n)$，两个长度 $n+1$ 的数组。

## 总结

- 本题是字符串哈希的模板题：**子串判等 → 指纹判等**。
- 前缀哈希的核心公式 $\text{hash}(l,r) = h[r] - h[l-1] \times B^{r-l+1}$，本质是"$B$ 进制数的高位对齐后相减"。
- 复杂度从朴素的 $O(nm)$ 降到 $O(n+m)$，靠的是"预处理一次，每次询问 $O(1)$"这一经典权衡。
- 需要注意：哈希判等存在理论上的碰撞风险，选大素数模数（如 $2^{61}-1$）和大底数可以把风险压到可忽略；如果题目要求严格正确，则应换后缀数组等确定性结构。

## 图示解析

### 前缀哈希如何"抠出"子串

```text
S = a a b b a a b b      下标: 1 2 3 4 5 6 7 8

h[2] = 值( aa )            ← 高位前缀
h[6] = 值( aabbaa )

取 S[5..6] = "aa"：
       值( aabbaa )          = h[6]
     - 值( aa 00 00 )        = h[2] × B^4      ← 把 h[2] 对齐到高位
     ─────────────────
     = 值( aa )              ← 恰好就是子串 S[5..6] 的指纹
```

观察重点：减法之前必须把 $h[l-1]$ 乘上 $B^{\,r-l+1}$，即"补上子串长度的若干个 $0$ 位"，让两个数在同一套位权下相减；$p$ 数组预存的正是各个 $B^k$。整个流程每个询问只做两次乘法、一次减法，这就是 $O(1)$ 查询的来源。

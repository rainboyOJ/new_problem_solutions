# 19997 Color

现有一个 $n$ 行 $m$ 列的网格图，将第 $i$ 行第 $j$ 列的网格上写下数字 $(i-1)\times n+j$。

给定一个长度为 $a$ 的数列 $s$，依次将网格图上对应 $s_i$ 的网格染成红色（重复染色后仍为红色）。

判断染色后该图形是否关于该网格图长度为 $m$ 的边上的垂直平分线对称。

## 输入格式

第一行一个整数 $T$，表示数据组数。

对于每组数据：

- 第一行三个整数 $a,n,m$，意义如题述。
- 第二行 $a$ 个整数，描述数列 $s$。

## 输出格式

对于每组数据，若染色后该图形是否关于该网格图长度为 $m$ 的边上的垂直平分线对称，输出 `Yes`；否则，输出 `No`。

## 样例

### 输入样例 1

    2
    2 3 3
    6 4
    1 3 3
    1

### 输出样例 1

    Yes
    No

### 样例 2

见选手目录下的 $\textit{\textbf{color/color2.in}}$ 与 $\textit{\textbf{color/color2.ans}}$。

该样例与测试数据 $9\sim 12$ 满足同样的约束条件。

## 数据规模与约定

- 数据点 $1$：$n=1$。
- 数据点 $2\sim4$：$m=1$。
- 数据点 $5\sim8$：$n,m\le10^3$。
- 数据点 $9\sim12$：$n,m\le10^4$。
- 数据点 $13\sim20$：无特殊限制。

对于 $100%$ 的数据，有 $1\le T\le 5$，$1\le n,m\le 10^7$，$1\le a\le 10^5$，$1\le k_i\le n\cdot m$。

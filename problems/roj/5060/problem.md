### 【题目描述】

一个最简单的计算器支持`+，-，*，/`四种运算。输入只有一行：两个参加运算的数和一个操作符(`+，-，*，/`)。输出运算表达式的结果。考虑下面两种情况：
（1）如果出现除数为0的情况，则输出：`Divided by zero!`
（2）如果出现无效的操作符(即不为`+，-，*，/`之一)，则输出：`Invalid operator!`

### 【输入】

一行，前面两个数，再一个运算符号。

### 【输出】

运算表达式的结果。

### 【输入样例】

```
34 56 +
```

### 【输出样例】

```
90
```

### 【提示】

【样例2】
输入：

```
2 1.2 -
```

输出：

```
0.8
```

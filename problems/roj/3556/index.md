## 形式化题目

给定长度为 $n$ 的自然数序列 $a_1, a_2, \dots, a_n$（每个 $a_i \leqslant 1.5 \times 10^9$），其中**互不相同的值不超过 $10000$ 个**。

设不同值的集合为 $V$（$m = |V|$）。对每个 $v \in V$，记 $c_v$ 为 $v$ 在序列中出现的次数。

求把所有 $(v, c_v)$ 按 $v$ **从小到大**依次输出。

样例：输入 $8$ 个数 $2, 4, 2, 4, 5, 100, 2, 100$，得到 $2$ 出现 $3$ 次、$4$ 出现 $2$ 次、$5$ 出现 $1$ 次、$100$ 出现 $2$ 次，按值升序输出四行。

## 正解

### 思路

**朴素做法**：把 $n$ 个数整体排序，再线性扫描合并"连续相同段"，每段输出其值和段长。$O(n \log n)$ 能过，但它把全部 $20$ 万个数都丢进了排序——而其中绝大多数是重复的。

**瓶颈与推导**：题面显式给出"不相同的数不超过 $10000$ 个"。值域高达 $1.5 \times 10^9$ 不能开数组计数，但哈希表可以；于是先用哈希表把序列**一遍扫描**压成"值 → 出现次数"，计数阶段 $O(n)$；真正需要排序的只剩 $m \leqslant 10000$ 个不同的键，排序代价从 $n \log n$ 降到 $m \log m$。这正是题面给"不同数个数"这条约束的用意：**排序对象是键，不是全部数据**。

以样例展示计数表的形成过程：

| 读到的数 | 计数字典的状态（值: 次数） |
| :---: | --- |
| 2 | {2: 1} |
| 4 | {2: 1, 4: 1} |
| 2 | {2: 2, 4: 1} |
| 4 | {2: 2, 4: 2} |
| 5 | {2: 2, 4: 2, 5: 1} |
| 100 | {2: 2, 4: 2, 5: 1, 100: 1} |
| 2 | {2: 3, 4: 2, 5: 1, 100: 1} |
| 100 | {2: 3, 4: 2, 5: 1, 100: 2} |

观察重点：每个数只被处理一次，字典始终保存"到目前为止"的频次；扫描结束后对字典的键做升序排序，逐键输出即为答案。Python 里这三步分别对应 `Counter(data)`、`sorted(counter)`、推导式拼行。

### 复杂度

- 时间复杂度 $O(n + m \log m)$：计数一遍 $O(n)$，对 $m \leqslant 10000$ 个键排序 $O(m \log m)$，输出 $O(m)$。实测最大测例 $0.055$s，远低于 $1000$ms 限制。
- 空间复杂度 $O(n + m)$：输入整体读入、计数字典与输出列表；实测峰值约 $27$MB。

## 总结

- 高值域 + 显式"不同数个数"约束 → 用**哈希计数**代替数组计数，用**键排序**代替全量排序。
- 朴素"整体排序扫段"与正解的区别不在量级，而在排序规模：$n \log n$ 对 $m \log m$，当 $m \ll n$ 时差距明显，也更贴合题面提示。
- 样例可手工验证计数表：$2$ 三次、$4$ 两次、$5$ 一次、$100$ 两次，升序输出与标准答案一致。

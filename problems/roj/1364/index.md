## 形式化题目

给定一棵二叉树的中序遍历和层序遍历字符串（字符互不重复），输出其先序遍历字符串。

输入两行，分别为中序序列和层序序列；输出一行先序序列。例如中序 `DBEAC`、层序 `ABCDE` 输出 `ABDEC`。

## 解法总览

两种解法建立在同一条关键观察上：**层序遍历里祖先一定排在子孙前面，所以任意中序区间对应的子树根，就是该区间里层序名次最小的那个字符**。差别只在「要不要把树真的建出来」。

| | 解法一：区间递归直接产出（原实现） | 解法二：先建树再遍历（正式主解） |
| --- | --- | --- |
| 做法 | 边找根、边切区间、边写输出，不保存任何结点 | 先按同一规则建出 `Node{val, lch, rch}` 结点表，再先序走一遍 |
| 中间结构 | 只有递归栈，O(树高) | 结点表 O(n)，之后想走中序、后序、求深度都不用重算 |
| 时间 | 每层要扫区间找根并定位，最坏 O(n²)（链状时） | 同左，另外加 O(n) 的遍历 |
| 代码 | `direct.py` / `direct.cpp` | `main.py` / `main.cpp` |

正式主解是 `main.py` / `main.cpp`。

## 解法一：区间递归直接产出

### 思路

层序遍历中祖先一定排在子孙前面，所以任意中序区间对应的子树根，就是该区间字符中层序排名最小的那个。先输出根，再按根在中序中的位置切分左右两段递归。

### 复杂度

- 时间：每层要扫一遍当前区间找根、再定位根的位置，最坏 O(n²)（链状树），平衡时 O(n log n)。
- 空间：只用递归栈，O(树高)。

## 解法二：先建树再遍历

### 思路

用的是同一条观察，区别在于**先把树存下来**：递归不再直接输出，而是 `new_node()` 开一个结点、把左右孩子接上，返回根编号；建完再从根做一遍先序遍历 `preorder(root)` 输出。

结点的字符、左儿子、右儿子收进同一个 `Node`，编号就是下标（动态化静态：静态数组 + `node_cnt` 当分配指针）。好处是树变成了**可复用的中间结构**——同一棵树再要中序、后序、深度、叶子数都只需再走一遍，不必重新切分区间。

## 复杂度对比

| | 解法一 | 解法二 |
| --- | --- | --- |
| 时间 | O(n²) 最坏 | O(n²) 最坏 + O(n) 遍历 |
| 空间 | O(树高) | O(n) 结点表 |
| 能否复用树结构 | 不能 | 能 |
| 适合场景 | 只求一次先序、追求最小内存 | 后续还要在树上做别的事 |

两法时间同阶，选择看目的：一次性输出用解法一，把树当数据结构反复使用用解法二。

## 总结

1. **层序 + 中序还原二叉树**的通用套路是「区间内层序名次最小者为根」，这条观察两种解法共用，先想清楚它再决定要不要建树。
2. 建树与否是一次**存储换复用**的权衡：多花 O(n) 结点表，换来的是后续任意遍历、统计都能直接走树。
3. `Node` 聚合字段 + `node_cnt` 动态开点是这本仓库里建二叉树的标准写法（见《树的存储》）。

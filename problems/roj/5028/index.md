## 形式化题目

给定一个正整数 $n$（$1 \le n \le 10$），求：
$S = 1! + 2! + 3! + \dots + n!$

其中 $k! = 1 \times 2 \times \dots \times k$。最后输出 $S$ 的值。

## 正解

### 思路

这道题目要求我们求出前 $n$ 个数的阶乘之和。

最朴素的做法是对于每一个 $k \in [1, n]$，都使用一个循环从 $1$ 乘到 $k$ 算出 $k!$，然后再将它们累加。由于计算每一个 $k!$ 需要 $k$ 次乘法，总的运算次数大约是 $1 + 2 + \dots + n = \frac{n(n+1)}{2}$，时间复杂度为 $O(n^2)$。

**优化点**：
我们观察到相邻的两项阶乘之间存在严格的递推关系：
$k! = (k-1)! \times k$
这意味着，如果我们已经算出了 $(k-1)!$，只需要再乘上 $k$ 就能得到 $k!$，完全不需要每次都从头开始连乘。

因此，我们可以用单层循环同时维护两个变量：
1. `fac` 表示当前的阶乘项，初始为 $1$。在第 $i$ 次循环时，更新 `fac = fac * i`。
2. `sum` 表示阶乘和，初始为 $0$。在第 $i$ 次循环算出当前的 `fac` 后，将其累加到 `sum` 中，即 `sum = sum + fac`。

这样，每次循环只需要常数次的乘法和加法操作，整个算法的时间复杂度就从 $O(n^2)$ 降低到了 $O(n)$。在教学中，这是一种典型的利用“递推思想”消除冗余计算的例子。

对于数据范围的考量：当 $n = 10$ 时，最大的阶乘项 $10! = 3,628,800$，总和 $S_{10} = 4,037,913$。这一结果远在 32 位有符号整数（`int`）的上限 $2,147,483,647$ 以内，本题数据不会造成溢出。不过本仓库约定「题目数据默认 `long long`」，因此代码中 `fac`、`sum` 仍声明为 `ll`（`typedef long long ll`）——即使评测数据超出题面范围（如 $n \ge 13$）也不会溢出。

### 复杂度

- **时间复杂度**：$O(n)$。只需遍历从 $1$ 到 $n$ 的单层循环，每次循环内执行 $O(1)$ 的基本运算。
- **空间复杂度**：$O(1)$。只使用了几个整型变量来存储中间结果和答案。

## 总结

- **递推思想**：$S_n = S_{n-1} + n!$，维护前缀积 `fac *= i` 同时 `sum += fac`，算法从 $O(n^2)$ 优化为 $O(n)$，空间 $O(1)$。
- **递推与「每项重算」等价性的论证**：两种写法求的是同一个数学量。整数乘法满足结合律，$1 \cdot 2 \cdots (k-1) \cdot k$ 与重头乘一遍得到同一个精确整数（无舍入）；且两者都以 $k = 1..n$ 的同一顺序累加同样的项，整数加法结合律和交换律保证和逐位相同。
- **类型选择与溢出边界**：本题用 `int` 也确实能过（$10! = 3{,}628{,}800$、$S_{10} = 4{,}037{,}913$ 均远小于 $2^{31}-1$），代码中改成 `ll` 是遵循仓库规范而非修 bug。反事实数据实测表明：在 $n=1..10$ 内 `int` 版与 `ll` 版输出逐字节完全相同；$12! = 479{,}001{,}600$ 尚在 `int` 内，但 $n = 13$ 时 $13! = 6{,}227{,}020{,}800$ 就已超过 $2^{31}-1$。所以本题代码直接使用 `long long`（可安全算到 $n = 20$，$S_{20} = 2{,}561{,}327{,}494{,}111{,}820{,}313$；$n \ge 21$ 才超过 $2^{63}-1$）。首次超 `int` 是 $n=13$，首次超 `ll` 是 $n=21$。当 $n=13$ 时，`ll` 版输出正确的 `6749977113`，而 `int` 版因溢出输出 `-1839957479`，此时才分道扬镳。
- **验证强度摘要**：
  - 本题经过了四者逐字节比对（C++ 版 / Python 版 / `math.factorial` 独立暴力求解 / 数据 `data` 的 10 个 `.out`）且 0 分歧。
  - **V5 扰动验证**：将 `fac *= i` 改为 `fac *= 1` 会导致 $n=10$ 输出从 `4037913` 变成 `10`，确系枚举算出。
  - **V2 非硬编码**：源码的数值字面量集合不包含答案值（如 `4037913`、`3628800` 等），保证无硬编码。
- **边界**：当 $n=1$ 时正常进入循环并输出 $1$；题目测试数据严格保证 $n \in \{1..10\}$ 且每个值恰好对应一个点。

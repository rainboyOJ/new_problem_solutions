## 形式化题目

给定三个数 $a,b,c$（题面未给范围；真实测试数据是 69~908 的正整数），计算

$$
m=\frac{\max(a,b,c)}{\max(a+b,b,c)\times\max(a,b,b+c)}
$$

分子是三个原数的最大值；分母的两个因子都做了"错位相加"——左因子先把 $a$ 加上 $b$
（$a+b$），右因子先把 $b$ 加上 $c$（$b+c$），其余位置仍取原数。
输出 $m$，保留到小数点后三位。

题面还有一条硬性要求：**把"求三个数的最大值 $\max(x,y,z)$"分别定义成函数和过程来做**——
即同一个计算要交付两种形态：函数用返回值交回结果，过程没有返回值、经输出参数写回调用者。

样例 `1 2 3` 的分解（三项代入一目了然）：

| 量 | 代入 | 值 |
| --- | --- | --- |
| 分子 $\max(a,b,c)$ | $\max(1,2,3)$ | 3 |
| 分母左因子 $\max(a+b,b,c)$ | $\max(3,2,3)$ | 3 |
| 分母右因子 $\max(a,b,b+c)$ | $\max(1,2,5)$ | 5 |
| $m$ | $3/(3\times 5)$ | $0.2$，输出 `0.200` |

注意真实数据里 $m$ 都很小：10 组输出只有 `0.000` 和 `0.001` 两种，
最大的一组约 $1/908\approx 0.0011$——**三位小数的四舍五入格式**才是真正被反复检验的规则。

## 正解

### 思路

最朴素的写法是把公式逐字内联（Python 内置 `max` 支持任意多个参数）：

```python
m = max(a, b, c) / (max(a + b, b, c) * max(a, b, b + c))
```

这个做法**没有可消除的瓶颈**：固定几次比较加一次除法，$O(1)$ 已是下界
（不确定地说，不比较就无法断定谁最大），也没有真实子任务分层，
所以不写暴力层——再写一个"朴素版"只会与正解逐语句等价。本题的真正考点是
题面要求的**两种交付形态**，直接给出最终写法：

- **函数版** `max3(x, y, z) -> int`：用一个 `top` 依次与 `y`、`z` 比较抬高，
  最后 `return top`。初始 `top = x`、两次 `if top < ...`，归纳可得返回值就是
  $\max(x,y,z)$。
- **过程版** `max3_proc(x, y, z, out) -> None`：比较逻辑一模一样，但**不 `return`**，
  而是写 `out[0] = top`。Python 没有 Pascal 的 `var` 输出参数，
  用长度为 1 的列表把值带回去，就是 Python 里"过程"的标准模拟方式。
- **调用处两种用法各演示一次**：分子用返回值 `numerator = max3(a, b, c)`；
  两个分母因子用过程 `max3_proc(a + b, b, c, out)` 之后读 `left = out[0]`。
  实参表里 `a + b`、`b + c` 先算再传，与公式逐字对应。

三种量虽然都算完了，还差两步才到答案：

- **除法**：参考 C++ 解法必须写 `1.0*max(...)` 把整数运算抬成浮点，否则 `/` 整除
  丢掉小数；Python 3 的 `/` **天生就是浮点除法**（`//` 才是整除），
  `numerator / (left * right)` 直接得到 `float`，`left * right` 先做整数乘法也无妨，
  它只是除数。
- **输出**：`f"{m:.3f}"` 按四舍五入保留三位小数，对应 C 的 `printf("%.3lf")`。

语法构造与代码位置的对应：

| 语法构造 | 代码位置 | 作用 |
| --- | --- | --- |
| `def ... -> int` + `return` | `max3` | **函数**：结果经返回值交回 |
| `def ... -> None` + `out[0] = top` | `max3_proc` | **过程**：结果经输出参数写回 |
| 实参表达式先求值 | `max3_proc(a + b, b, c, out)` | 与 $\max(a+b,b,c)$ 逐字对应 |
| `/` 与 `.3f` | `numerator / (left * right)`、`f"{m:.3f}"` | 浮点除法 + 三位小数输出 |

### 复杂度

- 时间复杂度：$O(1)$：固定 6 次整数比较、2 次加法、1 次乘除和 1 次格式化输出，
  与输入规模无关。
- 空间复杂度：$O(1)$：三个整数 + 一个长度为 1 的输出参数列表 + 若干标量。

## 总结

- 公式 = 三次"三数取最大" + 一次除法：分子 $(a,b,c)$、左因子 $(a+b,b,c)$、
  右因子 $(a,b,b+c)$，参数表与题面逐字对齐。
- 题面要求的两种形态：函数 `max3` 用 `return`，过程 `max3_proc` 无返回值、
  写进输出参数 `out[0]`（Python 模拟 Pascal `var` 参数的做法）。
- Python 3 的 `/` 就是浮点除法，不需要 C++ 里的 `1.0*`；写成 `//` 则全错。
- `f"{m:.3f}"` 四舍五入三位小数是本题的真正考点：真实数据结果都在 $0.0011$ 以下。
- 分母恒为正（真实数据 69~908 的正整数），无除零特判；常数计算，
  $O(1)$ 时间/空间，无 TLE/MLE 风险。

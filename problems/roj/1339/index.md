## 形式化题目

给定同一棵二叉树的先序遍历串与中序遍历串（结点用互不相同的小写字母表示），求这棵树的后序遍历串。

样例 `abdec / dbeac` 对应的树与答案 `debca`：

```text
      a          先序 abdec ：根 a → 左子树 → 右子树
     / \         中序 dbeac ：左子树 → 根 a → 右子树
    b   c        后序 debca ：左子树 → 右子树 → 根 a
   / \
  d   e
```

图中同一棵树被三种顺序"读"出三种串：先序从根 `a` 开始向左右展开，中序让 `a` 站在左右子树之间，后序把 `a` 压到最后。本题要做的，就是从前两种读法还原出第三种。

## 正解

### 思路

最直接的想法是先把树建出来，再跑一次后序 DFS。但"建树"靠的也是同一个事实：**先序的首字符一定是根**。既然如此，连树都不必建——先序首字符给出根，在中序串里找到这个根，它左边的字符恰好是左子树的全部结点、右边恰好是右子树的全部结点，两串随之各切成两段，问题缩小为两个同型的子问题。

关键在于两串要"对齐着切"。记根在中序中的位置为 $k$（从 0 数起）：

- 中序左段长 $k$ ⇒ 左子树恰有 $k$ 个结点；
- 一棵子树的结点在先序、中序里都是**连续一段**（由遍历定义归纳可得），所以先序里紧跟根的 $k$ 个字符就是左子树的先序，其余是右子树的先序。

于是每层递归只依赖两个事实：`pre[0]` 是根，`k = ino.index(pre[0])` 同时给出中序的切分点与先序的切分长度。结点字母互不相同保证了 `index` 命中唯一、切分无歧义；而后序的定义就是"左子树后序 + 右子树后序 + 根"，正好翻译成一行字符串拼接。

用样例 `abdec / dbeac` 演示这套切分（每行是一层递归；列含义：两串的当前段、根、以及切出的左右子问题）：

| 层 | 先序段 | 中序段 | 根 $k$ | 左子问题（先序， 中序） | 右子问题（先序， 中序） | 该层返回的后序 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | `abdec` | `dbeac` | `a`, $k=3$ | (`bde`, `dbe`) | (`c`, `c`) | `deb` + `c` + `a` |
| 2 | `bde` | `dbe` | `b`, $k=1$ | (`d`, `d`) | (`e`, `e`) | `d` + `e` + `b` |
| 2 | `c` | `c` | `c`, $k=0$ | （空， 空） | （空， 空） | `c` |
| 3 | `d` | `d` | `d`, $k=0$ | （空， 空） | （空， 空） | `d` |
| 3 | `e` | `e` | `e`, $k=0$ | （空， 空） | （空， 空） | `e` |

注意每行"根 $k$"一列：$k$ 是根在中序段里的位置，同时是先序段中分给左子树的字符个数——两个串靠这一个数完成同步切分。第 1 层切完，`bde/dbe` 与 `c/c` 两段与上图树中 `a` 的左右子树逐一对应；递归到单字符（$k=0$，左右皆空）即触底返回。把第 2、3 层的返回值按"左 + 右 + 根"回填，顶层得到 `deb + c + a = debca`，与样例输出一致。

### 复杂度

- 时间：每层递归做一次 `ino.index`（线性查找，等价于数据仓 `std.cpp` 的 `str.find`），各层切片总量之和为 $O(n \cdot h)$（$h$ 为树高），退化链上界 $O(n^2)$、平衡树 $O(n \log n)$——与标准 C++ 下标递归解法同阶。实测数据仓 5 组评测点单组约 0.017 s（限时空闲充裕）。
- 空间：切片副本合计 $O(n \cdot h)$，递归栈深 $O(h)$；本题数据规模极小（数据仓最大 28 个结点），无压力。

## 总结

先序串"抢跑"给出了根，中序串"居中"给出了左右边界：`pre[0]` 定根、`ino.index(pre[0])` 一个数字同时切开两串，"左 + 右 + 根"的拼接顺序就是后序本身。树不必显式建立——遍历串之间的结构信息足够直接互相翻译。这是"由两种遍历还原二叉树"这一族问题里最基础的一环，配合 `index` 的唯一命中（字母互不相同）保证了切分永远无歧义。数据仓 `tree1~tree5` 五组真实数据全部输出一致。

## 图示解析

这张图串起本题从输入到答案的完整递归路线：

```text
输入：先序 abdec + 中序 dbeac
`- 先序首字符 a 是根，中序中位置 k=3
   `- 左子问题(bde, dbe)   右子问题(c, c)
      |- b 定根，k=1 → (d)(e) → 返回 d+e+b = deb
      `- c 是叶子 → 返回 c
         `- 回填：deb + c + a = debca（后序）
```

第一个节点是入口：两串同源于一棵树。第二个节点展示一次切分如何同时确定根与两个子问题的边界。第三个节点是递归的两个分支各自触底后回填，最后一个节点按"左 + 右 + 根"把返回值拼成最终答案，与样例 `debca` 一致。

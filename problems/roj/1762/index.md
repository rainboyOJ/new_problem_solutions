## 形式化题目

定义 $k$ 位按位与非运算

$$x\ \mathrm{nand}\ y = \lnot(x \mathbin{\&} y) \mathbin{\&} (2^k - 1),$$

即先按位与、再按位取反，最后只保留低 $k$ 位。

给定一棵 $n$ 个结点的树，第 $i$ 个结点带权值 $w_i$（$0 \le w_i < 2^k$）。依次处理 $m$ 个操作：

- `Replace x y`：$w_x \leftarrow y$；
- `Query x y`：设 $x \to y$ 的路径依次为 $S_1, S_2, \dots, S_L$（$S_1 = x$，$S_L = y$，$L \ge 1$），定义

$$f(0) = 0, \qquad f(i) = f(i-1)\ \mathrm{nand}\ w_{S_i} \quad (1 \le i \le L),$$

  输出 $f(L)$。

数据范围：$1 \le n, m \le 10^5$，$1 \le k \le 32$，$0 \le w_i, y < 2^k$。时间限制 2000 ms，空间限制 256 MB。

以题面样例（$n = 3$、$k = 3$、链 $1-2-3$、$w = (2, 7, 3)$）对照：`Query 2 3` 沿 $2 \to 3$ 得
$f(1) = 0\ \mathrm{nand}\ 7 = 7$、$f(2) = 7\ \mathrm{nand}\ 3 = \lnot 3 \& 7 = 4$；
随后 `Replace 1 3`，`Query 1 1` 是长度为 1 的退化路径，得 $0\ \mathrm{nand}\ 3 = 7$。
注意反向走 $3 \to 2$ 会得到 $0$，可见**路径方向是 $x \to y$ 且结果对方向敏感**。

## 正解

### 思路

**朴素做法的瓶颈。** 每次查询沿路径逐点折叠，单次 $O(n)$，总计 $O(nm)$，$n, m \le 10^5$ 时是 $10^{10}$ 量级，必然超时。直觉上树上路径求值应该上「树链剖分 + 线段树」，但 $\mathrm{nand}$ **不满足结合律**：

$$(1\ \mathrm{nand}\ 1)\ \mathrm{nand}\ 0 = 0\ \mathrm{nand}\ 0 = 1, \qquad 1\ \mathrm{nand}\ (1\ \mathrm{nand}\ 0) = 1\ \mathrm{nand}\ 1 = 0 \quad (k = 1),$$

两边的括号位置给出不同答案。所以不能像区间和、区间异或那样把左右子区间的「答案」直接串起来，线段树这条路看似被堵死。

（顺带澄清一个常见口误：$\mathrm{nand}$ 本身是**交换**的——$\lnot(x \& y) = \lnot(y \& x)$；真正让本题棘手的只是「折叠一段序列」这件事不可结合。）

**关键观察：值不可结合，函数可以。** 换一个视角：不要维护「这一段折叠出来等于多少」，而是维护「这一段把输入变成什么」——即这一段序列诱导的**变换** $F$。虽然 $\mathrm{nand}$ 不可结合，但**函数复合天然满足结合律**：

$$F_C \circ (F_B \circ F_A) = (F_C \circ F_B) \circ F_A,$$

于是线段树可以照常合并——只不过合并的是变换而不是数值。

**把变换压成两个掩码。** 还剩一个问题：$k$ 位输入的变换有 $2^{2^k}$ 种，无法存储。但按位运算**逐位独立**：第 $i$ 位的输出只依赖第 $i$ 位的输入，没有进位、借位，位与位之间互不影响。因此每一位上的变换都只是 $\{0,1\} \to \{0,1\}$ 的映射，一共只有 4 种，而它由「输入 0 时的输出」与「输入 1 时的输出」唯一确定。

把 $k$ 位放在一起，一段区间诱导的变换 $F$ 就只需两个 $k$ 位整数刻画：

$$A = F(0^k), \qquad B = F(1^k), \qquad F(x) = \bigl((x \mathbin{\&} B) \mid (\lnot x \mathbin{\&} A)\bigr) \mathbin{\&} mask, \qquad mask = 2^k - 1.$$

逐位看这个式子就是：输入为 1 的位取 $B$ 的对应位、输入为 0 的位取 $A$ 的对应位。于是 $2^{2^k}$ 种变换被无损压缩进两个整数。

**单点与复合。**

| 变换 | $A = F(0^k)$ | $B = F(1^k)$ |
| --- | --- | --- |
| 恒等 $F(x) = x$ | $0$ | $mask$ |
| 单点 $F_w(x) = \lnot(x \& w) \& mask$ | $mask$ | $(\lnot w) \& mask$ |
| 复合 $F_{after} \circ F_{before}$ | $(A_{bef} \& B_{aft}) \mid (\lnot A_{bef} \& A_{aft})$ | $(B_{bef} \& B_{aft}) \mid (\lnot B_{bef} \& A_{aft})$ |

复合公式的含义很直白：先做 $before$ 后，输入 $0$ 变成了 $A_{bef}$；它的第 $i$ 位为 1 的位在 $after$ 里走 $B_{aft}$、为 0 的位走 $A_{aft}$，按位或起来即得新变换在 $0$ 处的取值。

**线段树 + 树链剖分。** 线段树的每个结点维护两套掩码：正向（按 dfs 序递增，即自顶向下）的 $(A, B)$ 与反向（按 dfs 序递减，即自底向上）的 $(A, B)$；单点修改 $O(\log n)$，区间查询直接返回变换。

树链剖分把路径 $x \to y$ 拆成 $O(\log n)$ 条重链上的连续区间，拼接时**必须严格区分两个方向**：

- **$x$ 侧**（$x$ 向上到 $\mathrm{LCA}$，含 $\mathrm{LCA}$）：沿链向上跳，先处理的是**较深**的一段，而它在路径上排在**前面**——是内层函数，用反向查询，并按「新段在外层」累积：$F \leftarrow F_{new} \circ F$；
- **$y$ 侧**（$\mathrm{LCA}$ 的孩子向下到 $y$，不含 $\mathrm{LCA}$）：同样沿链向上跳，先处理的是**较深**的一段，但它在路径上排在**后面**——是外层函数，用正向查询，并按「新段在内层」累积：$F \leftarrow F \circ F_{new}$；
- $\mathrm{LCA}$ 归 $x$ 侧，只算一次，别重复计入；
- 最后把两侧按「$x$ 侧先、$y$ 侧后」合起来：$F = F_y \circ F_x$，答案即 $A = F(0^k)$（初始值为 $0$）。

**两个易错点。**

1. $k = 32$ 时 `1u << k` 是未定义行为，必须特判 $mask = \texttt{0xFFFFFFFF}$（C++ 用 `unsigned int`；Python 的整数无溢出之虞，`(1 << k) - 1` 直接可用）。
2. $\lnot$ 作用于整个机器字，每次取反后**必须**立刻 `& mask`，否则高位会污染结果。

### 复杂度

- 时间：建树 $O(n)$；单次 `Replace` $O(\log n)$；单次 `Query` 树剖最多跳 $O(\log n)$ 条重链、每条链上查询 $O(\log n)$，故 $O(\log^2 n)$。总计 $O\bigl(n + m \log^2 n\bigr)$。
- 空间：树剖与线段树各 $O(n)$，线段树按 $4n$ 开、每结点存 4 个 32 位整数，$n = 10^5$ 时约 6 MB。
- 实测（本机 `g++-16 -O2`）：顶格点 $n = m = 10^5$ 纯链 0.04 s、毛毛虫 0.05 s、完全二叉树 0.07 s，峰值内存约 12 MB，离 2000 ms / 256 MB 余量极大；Python 版同阶（短区间用阈值 `THRESH = 32` 直接逐点扫，避开线段树的固定开销），最大点约 0.9 s。

## 总结

本题是「**运算不可结合时，改用变换的复合**」这一技巧的模板题，两个关键动作：

1. **换对象**：把「区间折叠出的值」换成「区间诱导的变换」。$\mathrm{nand}$ 不可结合，但函数复合恒满足结合律，线段树因此复活。
2. **换表示**：$k$ 位按位运算逐位独立，变换 $F$ 只需 $F(0^k)$ 与 $F(1^k)$ 两个掩码即可无损表示，$2^{2^k}$ 种变换被压进两个整数；单点、复合、求值全部是常数次位运算。

剩下的就是树链剖分的常规拼接，但**方向**是本题真正的坑：路径是有序序列，$x$ 侧要用反向复合、$y$ 侧要用正向复合，两侧的累积方向还相反，$\mathrm{LCA}$ 只能算一次。凡是「线段树 + 树上路径 + 不可结合的运算」，这一套「双向维护 + 两侧反向拼接」几乎是标准套路。

关于素材与数据：本题素材目录带数据生成脚本 `data.py`，说明 `data/` 是**自造数据**；题面 `content.md` 也有残留缺损（$f$ 的定义只剩 `\0\` 残片），本解按题面样例反推为 $f(0) = 0$、$f(i) = f(i-1)\ \mathrm{nand}\ w_{S_i}$（沿 $x \to y$），这与网络流传的同题题解一致，样例 `4` / `7` 亦完全吻合。

需要如实指出的是：随仓 `data/problem*.out` 由素材源的 `std.cpp` 生成，而该 `std.cpp` 在 $y$ 侧跨多条重链拼接时把复合顺序写反了（先深后浅，即 `fy = merge_trans(query_fwd(...), fy)`），这与题面 $x \to y$ 的语义不符——同一棵树形状不同、路径与权值完全相同，它的输出都会变，例如路径 $1-2-3-4-5$、权值 $0,1,0,3,3$、$k = 2$ 时，链状树给 3、20 个结点的树给 0，可见它并非一个自洽的语义。本解按题面语义实现（先浅后深），因此第 1、2、3、8 组数据（单链 / 退化路径，$y$ 侧只有一段）与随仓 `.out` 完全一致，而第 4、5、6、7、9、10 组（$y$ 侧跨多链）不一致；这些点的正确答案已用独立的朴素暴力（BFS 求路径后逐点折叠）在 $n \le 5000$ 的全部测例上逐行核对通过。

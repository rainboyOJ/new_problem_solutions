## 形式化题目

字符集为 $\{1, 2, \dots, C\}$。"交换 $p$ 中任意两个字符的位置"是对整串施加一次字母表上的对换，
反复施加可以生成字母表的任意置换；而交换两个**相同**字符的位置等于什么都没做。
所以题面的"匹配"就是同构：

$$q \text{ 与 } p \text{ 匹配} \iff \exists\, \varphi: \{1,\dots,C\} \to \{1,\dots,C\} \text{ 是双射，使得 } q_i = \varphi(p_i)\ \ (\forall i).$$

给定 $s[1..n]$、$t[1..m]$（$T$ 组数据），求出所有 $l \in [1, n-m+1]$ 使得窗口
$w = s[l..l+m-1]$ 与 $t$ 匹配，输出匹配个数 $k$ 和这些 $l$（升序，下标从 1 开始）。

注意两个边界：$m > n$ 时没有任何窗口，答案为 $0$（第二行是空行）；$m = 1$ 时每个位置都匹配，
因为任意两个单字符之间总能建立双射。

## 正解

### 思路

**先想清楚"匹配"在比什么。** 双射 $\varphi$ 只关心"哪些位置上的字符彼此相等"，
不关心字符本身叫什么名字。所以我们要给每个串造一个与字母表无关的指纹。

对串 $x$ 的第 $i$ 位，定义它到上一次出现同一字符的距离

$$d_x[i] = i - \max\{\, j < i : x_j = x_i \,\}, \qquad \text{若这样的 } j \text{ 不存在则记 } 0 .$$

对窗口 $s[l..l+m-1]$ 的第 $k$ 位（即 $s$ 的下标 $i = l+k-1$），
"它在窗口内有同字符"当且仅当 $d_s[i] \le k-1$；若 $d_s[i] \ge k$，说明这个字符在窗口里
是**首次出现**，那个"同字符"落在窗口外面。于是定义窗口签名

$$\sigma_l(k) = \begin{cases} d_s[l+k-1], & d_s[l+k-1] < k,\\[2pt] 0, & d_s[l+k-1] \ge k,\end{cases}
\qquad
\text{sig}[k] = \begin{cases} d_t[k], & d_t[k] < k,\\[2pt] 0, & d_t[k] \ge k.\end{cases}$$

$0$ 是"窗口内首次出现"的记号，因为 $d \ge 1$ 恒成立，它不会和真实距离撞车。
模式侧的签名 $\text{sig}$ 是**静态**的：模式永远从自己的第 1 位开始对齐，
第 $k$ 位参与比较时窗口长度恒为 $k$。

**命题.** 窗口 $s[l..l+m-1]$ 与 $t$ 匹配 $\iff$ 对一切 $k \in [1, m]$ 都有 $\sigma_l(k) = \text{sig}[k]$。

**证明.** 从左往右扫描建立映射：两边第 $k$ 位都是"首次出现"时，把这两个字符配成一对；
两边都不是首次出现时，第 $k$ 位的字符已由它上一次出现的位置确定，$\sigma_l(k) = \text{sig}[k]$
恰好说明"重复指向的位置"也一致，不会与已有配对冲突。所以映射良定义；
两边字符出现次数的分布相同，映射既是单射又是满射，即双射。
反过来，若存在双射 $\varphi$ 把窗口映到 $t$，则"相等关系"在 $\varphi$ 下保持不变，
必然逐位得到 $\sigma_l(k) = \text{sig}[k]$。$\blacksquare$

**瓶颈在哪？** 对每个 $l$ 逐个比 $m$ 位是 $O(nm)$，$n = m = 10^6$ 时不可行。
但上面的判据是"逐位比较、相等就往后走、不等就回退"，这正是 KMP 的形状。

**关键观察：模式侧静态裁剪，文本侧动态裁剪。** KMP 每一步比较的是
"文本第 $i$ 位"与"模式第 $k = j+1$ 位"（$j$ 是当前已匹配长度）：

- 模式第 $k$ 位的窗口永远是它的前 $k$ 位，$\text{sig}[k]$ 与 $j$ 无关，可以预处理；
- 文本第 $i$ 位的窗口是"以 $i$ 结尾、长度 $k$"的那一段，$k$ 随 $j$ 变化，
  所以文本侧必须用当前的 $k$ 现算：$d_s[i] < k$ 取 $d_s[i]$，否则取 $0$。

于是只要把 KMP 的字符比较换成

$$\operatorname{clip}(d, k) = \begin{cases} d, & d < k,\\ 0, & d \ge k,\end{cases}
\qquad \text{比较 } \operatorname{clip}(d_s[i],\, j+1) \;=\; \text{sig}[j+1].$$

失配数组的求法一模一样，只是把 $t$ 自己既当模式又当文本：
比较 $t$ 的第 $i+1$ 位（按窗口长度 $k = j+1$ 现算裁剪）与 $\text{sig}[k]$。
注意 $k = 1$ 时 $\operatorname{clip}$ 恒为 $0$，而 $\text{sig}[1] = 0$，
所以"任何单字符都能匹配任何单字符"，长度为 2 的前缀的 border 长度恒为 1。

**小例子.** 样例第一组 $s = 1\,2\,1\,2\,3\,2$，$t = 3\,1\,3$：

$$d_s = [1,2,2,2,5,2], \quad d_t = [1,2,2], \quad \text{sig} = [0,0,2]$$

（$\text{sig}[1] = 0$ 因为 $d_t[1] = 1 \ge 1$；$\text{sig}[2] = 0$ 因为 $d_t[2] = 2 \ge 2$，
模式第 2 位的字符 1 在模式里是首次出现；$\text{sig}[3] = d_t[3] = 2$，位置 3 与位置 1 的字符相同。）

| $l$ | 窗口 | $\sigma_l$ | 是否匹配 |
| :-: | :-: | :-: | :-: |
| 1 | 1 2 1 | $(0,0,2)$ | ✓ |
| 2 | 2 1 2 | $(0,0,2)$ | ✓ |
| 3 | 1 2 3 | $(0,0,0)$ | ✗ |
| 4 | 2 3 2 | $(0,0,2)$ | ✓ |

得到 $k = 3$、位置 $1,2,4$，与样例输出一致。

**答案为什么天然升序？** KMP 从左往右扫文本，匹配的**结束**位置 $i$ 递增，
起始位置 $i-m+1$ 也随之递增，按顺序记录即可，不用排序。

**实现要点.**

- 距离数组按"上一次出现位置"递推：$d[i] = i - last[x]$ 后令 $last[x] = i$；
  $last$ 的下标是字符值，范围 $1..C$，每组数据只需清 $4(C+1)$ 字节。
- 输入最大约 31MB（$T = 3$，每组两组 $10^6$ 个整数），用 `fread` 缓冲逐字符读整数，
  避免 `getchar`/`cin` 的开销。
- 输出：先输出 $k$ 与换行，再按顺序输出每个下标后跟一个空格，最后换行；
  $k = 0$ 时第二行是空行。

### 复杂度

- **时间**：每组数据 $O(n + m)$（KMP 失配指针均摊），总计 $O(T(n+m))$。
  实测最慢一组 `problem9`（$T=3$，$n = m = 10^6$）热缓存下约 0.06 s，
  首次读入 31MB 输入时约 0.45 s，限时 1000 ms。
- **空间**：$O(n + m + C)$。实测峰值内存 23 MB，限 256 MB。
- **Python 版**：算法同阶，实测 `problem9` 约 1.69 s，约为限时的 1.7 倍，
  存在 TLE 风险（慢在纯 Python 的逐位循环常数，不是把算法换成了暴力）。
  同样的算法在 C++ 里就是上面那份 `main.cpp`：`fread` 读入 + 全局数组 + 两个 KMP 循环。

## 总结

- **同构匹配 = 相等关系结构的匹配**：把"字符叫什么"换成"它上一次出现在哪里"，
  字母表就被彻底抹掉了，问题退化成"两个距离数组逐位相等"。
- **裁剪是本题的核心技巧**：距离只在"上一次出现位置还在窗口内"时才有意义，
  否则必须统一记成 0。模式侧的窗口永远是前缀，所以裁剪是静态的、可以预处理；
  文本侧的窗口长度随已匹配长度变化，只能在 KMP 里现算。
- **判据形状决定算法**：一旦把匹配写成"逐位比较、失败回退"，
  它就和 KMP 完全同形，$O(nm)$ 直接降到 $O(n+m)$，连失配数组的求法都只需换掉比较函数。
- **边界**：$m > n$ 输出 0 与空行；$m = 1$ 时每个位置都是答案；
  单字符之间的匹配永远成立，这解释了 $\text{sig}[1] = 0$ 和"长度为 2 的前缀 border 恒为 1"。
- **输出顺序**：KMP 的扫描方向保证下标升序，不需要额外排序。

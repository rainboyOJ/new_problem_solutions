## 形式化题目

给出 $n$ 与模数 $p$，全集为 $U = \{2, 3, \dots, n\}$（题面的「寿司」编号为 $1 \dots n-1$，
美味度即 $i+1$，正好是 $2 \dots n$）。

求把 $U$ 切成两个**不相交**子集 $A$（小 G 选的）与 $B$（小 W 选的）的方案数，满足

$$\forall x \in A,\; \forall y \in B: \quad \gcd(x, y) = 1,$$

答案对 $p$ 取模。$A$ 与 $B$ 都可以为空集，但一个寿司不能同时出现在两边
（因为 $x \ge 2$ 时 $\gcd(x, x) = x > 1$）。

$2 \le n \le 500$，$0 \le p \le 10^9$（数据规模表原文如此；原 NOI 题面为 $0 < p \le 10^9$，
本目录数据取 $1 \le p \le 10^9$）。

**互质条件的质因子改写。** $\gcd(x, y) = 1$ 等价于「没有公共质因子」。于是设

$$P_A = \bigcup_{x \in A} \text{pf}(x), \qquad P_B = \bigcup_{y \in B} \text{pf}(y),$$

条件是**每一名质数最多只能被一个人占用**：$P_A \cap P_B = \emptyset$。
这就是全部约束，下面只讨论质因子集合。

## 正解

### 思路

**朴素的状压为什么不行。** 最直接的想法是让状态直接记住两人各占了哪些质数：
$dp[S_1][S_2]$ 表示小 G 占用的质数集合为 $S_1$、小 W 为 $S_2$ 的方案数，逐个寿司转移。
但 $500$ 以内的质数有 $95$ 个，$2^{95}$ 的状态空间直接爆炸。

**根号分治打开缺口。** 关键观察是：

> $n \le 500$ 时，任何 $x \le 500$ 至多含**一个**大于 $\sqrt{n} \approx 22.36$ 的质因子，
> 且该因子的指数必定为 $1$（因为 $23 \times 23 = 529 > 500$）。

于是把所有质数切成两半：

- **小质数**：$2, 3, 5, 7, 11, 13, 17, 19$，共 **8 个**，用 $2^8 = 256$ 的掩码完全够用；
- **大质数**：$23$ 以上，每个 $\le 500$ 的数里最多带一个。

把每个 $x \in [2, n]$ 拆成 `(小质因子掩码 mask, 剩下的大质因子 bigp)`，
其中 `bigp = 1` 表示这个数**只由小质数构成**。

**大质数的绑定效应。** 设 `bigp = L > 1` 的数有若干个（例如 $L = 23$ 对应 $23, 46, 92, \dots$）。
它们两两共享质因子 $L$，**任何两个都不能分给不同人**（否则两人各有一个 $L$ 的倍数，不互质）。
所以：

> 同一大质数的所有寿司，要么**整组给小 G**，要么**整组给小 W**，要么**整组都不选**。

而 `bigp = 1` 的数不含大质数，彼此不受这条约束约束，**每个数各自独立成一组**。

**DP 形态。** 全局状态只有

$$dp[x][y] = \text{小 G 已用小质数集合为 } x,\ \text{小 W 为 } y \text{ 的方案数}
\qquad (x \cap y = \emptyset),$$

初始 $dp[0][0] = 1$。逐组转移：

- 对当前组，先各复制一份 $dp$ 到 $g_1$（本组**只能给小 G**）与 $g_2$（本组**只能给小 W**），
  再把组内每个寿司逐个并入这两份；
- 组内逐个并入时，$g_1$ 的转移是 $g_1[x|s][y] \gets g_1[x][s] + g_1[x][y]$（要求 $s \cap y = \emptyset$），
  $g_2$ 对称（要求 $s \cap x = \emptyset$）。取一个数只能选一次，故枚举 $x, y$ 时**倒序**；
- 合并回全局：$dp'[x][y] = g_1[x][y] + g_2[x][y] - dp[x][y]$。

**容斥为什么是对的。** $g_1$ 统计的是「本组给小 G 或都不选」，$g_2$ 统计「本组给小 W 或都不选」。
两者都合法，但把「**本组一个都不选**」重复数了两次（$g_1$ 里那次「不选」与 $g_2$ 里那次「不选」
是同一个方案），所以减去一份 $dp_{\text{旧}}$。而「整组给 G」与「整组给 W」这两类互不重叠，
无需额外处理。

**答案。** 最后把所有合法状态累加：$\text{Ans} = \sum_{x \cap y = \emptyset} dp[x][y] \bmod p$。
非法状态在转移中永远取不到值（$g_1$、$g_2$ 的转移都带交集判断），所以直接遍历
$0 \le x, y < 256$ 全部相加即可。

**正确性小结。** 每个合法方案被唯一地按「每个 (大质数组, 分配方式)」拆分计数，
容斥消掉重复的「不选」；每个非法方案必在第一次出现「两人各持同一质数」时被交集判断挡住。
所以答案既无重复也无遗漏。

### 复杂度

- **时间**：小质数只有 $8$ 个，每轮状态对数为 $3^8 = 6561$（每个质数有三种归属：给 G / 给 W / 都不给），
  最坏 $n - 1 = 499$ 个寿司各扫一遍，总时间 $O(n \cdot 3^8) \approx 3.3 \times 10^6$ 次运算。
  实测 $n = 500$ 时 C++ **0.08 s**、Python **0.84 s**（限时 2000 ms）。
- **空间**：$dp$ 与两份临时数组各 $256 \times 256$ 个 `ll`，约 1.5 MB（限时 512 MB）。
  实测 C++ 峰值 8.3 MB。
- **与 Python 版的关系**：$O(n \cdot 3^8)$ 的算法在 Python 里同样可跑，$n = 500$ 顶格约 0.84 s，
  无需降级为暴力。Python 版把状态写成 `dict[(maskG, maskW)]`、天然只存可达状态，
  复杂度与 C++ 同阶。

## 总结

- **先找「最多一个」的结构**：$\sqrt{n}$ 分治的实质是「大质数在一个数里至多出现一次」，
  这一句把 $2^{95}$ 压成 $2^8$，是本题的命门。
- **大质数 = 绑定标记**：同一大质数的数必须同归一人，把「独立选数」变成「组内背包」。
- **`bigp = 1` 必须逐个数各成一组**：所有只含小质数的数若并成一大组，就会被误绑成
  「全给同一人」，这是实现时最容易踩的坑。
- **容斥合并 $g_1 + g_2 - dp$**：两个「只能给某人」的表都包含「本组不选」那一支，
  合并时必须减掉一次重复计数。
- **倒序枚举保证组内不重复选用**：组内逐个并入时，一维 0/1 背包的倒序技巧在这里同样适用。
- **数据来源说明**：素材源带有 `data.py` 生成脚本，说明本目录的 `data/` 是自造的
  （题面与官方 NOI2015 原题一致，但数据非官方原始数据）；其中两个样例点
  $n = 4, p = 10000 \to 21$ 与 $n = 100, p = 10^8 \to 3107203$ 已与题面输出逐字核对通过。
- **$p = 0$ 的说明**：数据规模表写作 $0 \le p \le 10^9$，但取模 $p = 0$ 无定义；
  本目录数据严格 $p \ge 1$，代码对 $p \le 0$ 仅作输出 $0$ 的保底。

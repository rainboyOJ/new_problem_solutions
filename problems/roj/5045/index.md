## 形式化题目

输入一个整数 $n$（$2 \le n \le 20$）。
输出杨辉三角形的前 $n$ 行。
其中第 $i$ 行（$1 \le i \le n$）有恰好 $i$ 个数字，表示组合数 $C(i-1, j-1)$（$1 \le j \le i$）。
在同一行内，数字之间恰好用一个空格隔开，**行末没有多余的空格**。

- 第 $i$ 行第 $j$ 列的值记为 $a[i][j]$
- 边界条件：对所有的 $i \ge 1$，有 $a[i][1] = 1$、$a[i][i] = 1$
- 递推关系：对 $i \ge 3$ 且 $2 \le j \le i-1$，有 $a[i][j] = a[i-1][j-1] + a[i-1][j]$

## 正解

### 思路

根据杨辉三角形的定义，第 $i$ 行由 $i$ 个数字组成，第一个数字和最后一个数字都是 1，中间的数字等于上一行对应位置的相邻两个数字之和。

可以直接使用二维数组 $a[i][j]$ 表示第 $i$ 行第 $j$ 列的数字。
1. **初始化**：对于所有的行 $i$，将每行的首列设为 1，即 $a[i][1] = 1$。
2. **递推**：对于第 $i$ 行（$i \ge 2$）的第 $j$ 个数字（$2 \le j \le i$），可以由前一行（第 $i-1$ 行）的第 $j-1$ 个数字和第 $j$ 个数字相加得到，即 `a[i][j] = a[i-1][j-1] + a[i-1][j]`。
   - 注意：如果我们将二维数组声明在全局域使其默认初始化为 0，当 $j = i$ 时，$a[i-1][i]$ 恰好为 0，那么 $a[i][i] = a[i-1][i-1] + a[i-1][i] = 1 + 0 = 1$，这使得每行的最后一个数字由递推自然得到。
3. **输出格式**：遍历前 $n$ 行输出结果。在一行中，只有在输出第一个数字之后才输出空格，这样可以保证每一行的数字之间恰有一个空格，而行尾没有多余的空格。
4. **数据类型**：当 $n = 20$ 时，最大的数字是 $C(19,9) = 92378$。这个数值远小于 `int` 的最大值 $2147483647$，因此普通的 32 位整型（`int`）即可。但在具体工程实现中通常按项目统一规范使用 64 位整数（`long long`）。

### 复杂度

- **时间复杂度**：计算并填充二维数组的过程嵌套了两次循环，外层循环从 1 到 $n$，内层循环从 1 到 $i$，总计执行了大约 $\frac{n^2}{2}$ 次操作；输出的过程同样执行了约 $\frac{n^2}{2}$ 次操作。因此时间复杂度为 $\mathcal{O}(n^2)$。当 $n \le 20$ 时，计算次数不到 400，可以忽略不计。
- **空间复杂度**：由于需要保存整个杨辉三角形的前 $n$ 行，我们需要一个规模至少为 $21 \times 21$ 的二维数组。所以空间复杂度为 $\mathcal{O}(n^2)$。考虑到 $n$ 很小，这部分内存占用极少。

## 总结

- **杨辉三角的递推关系与等价形式**：第 $i$ 行第 $j$ 个数即组合数 $\binom{i-1}{j-1}$。其递推关系为 $C(i,j) = C(i-1,j-1) + C(i-1,j)$，边界为 $C(i,1) = C(i,i) = 1$。
- **防止未初始化的脏数据**：在 C++ 中把数组定义在全局变量能够自动清零，这让 $j=i$ 时递推边界自动补上 0，从而使每行末尾的 $a[i][i]$ 自动等于 1，简化了额外的判断逻辑。
- **数值范围与边界**：$n \le 20$ 最大数为 $C(19,9) = 92378$，完全在 `int` 范围内（但我们遵循规范使用了 `long long`）。题面写 $2 \le n \le 20$，评测数据中也确实无 $n=1$ （属于题面未定义情形）。
- **题面自相矛盾的裁决**：题目【题目描述】中有一段带前导空格的代码块（形成一个对称的等腰三角形），这是为了帮助读者理解的**视觉示意图**。紧接着的下一块无前导空格、左对齐的形式，才是**真正的输出格式**，一切必须以真实数据为准。
- **换行符不一致陷阱**：题面中无前导空格的样例代码块本身带有 CRLF 换行符（这在文本处理时很少见），但**评测数据的行尾是 LF 格式**。如果基于样例去做逐字节对比或硬编码，容易发生由于换行符导致的误报错误。必须做归一化处理。

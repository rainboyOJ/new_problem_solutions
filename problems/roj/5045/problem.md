### 【题目描述】

例5.11  打印杨辉三角形的前$n(2\le n\le 20)$行。杨辉三角形如下图：
当$n=5$时

```
        1
      1   1
    1   2   1
  1   3   3   1
1   4   6   4   1
```

输出：

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

```
        1\n      1   1\n    1   2   1\n  1   3   3   1\n1   4   6   4   1
```

```
1\n1 1\n1 2 1\n1 3 3 1\n1 4 6 4 1
```

### 【输入】

输入行数$n$。

### 【输出】

输出如题述三角形。$n$行，每行各数之间用一个空格隔开。

### 【输入样例】

```
5
```

### 【输出样例】

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

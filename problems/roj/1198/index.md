## 形式化题目

给定一个由运算符 `+ - * /` 和浮点数组成的前缀表达式序列，序列中运算符与运算数之间用空格分隔。该序列对应一棵满二叉树的前序遍历：每个内部节点是四则运算符，每个叶子节点是浮点数。要求按这棵树计算并输出表达式的值，保留 6 位小数。

## 正解

### 思路

前缀表达式的第一个 token 就是当前子树的根。若根是运算符，则紧跟其后的两个连续片段分别是左子表达式和右子表达式；若根是数字，则它本身就是一个叶子节点。因此可以用递归直接求值：

1. 从输入流中取出一个 token；
2. 若 token 是运算符，则递归调用两次得到左右两个操作数，再执行对应运算；
3. 否则 token 是数字，直接转成浮点数返回。

这种方法不需要括号，也不需要显式建树，只需要一个顺序读取 token 的迭代器即可。

### 复杂度

- 时间复杂度：$O(n)$，其中 $n$ 是 token 数量；每个 token 只被访问一次。
- 空间复杂度：$O(h)$，为递归栈深度，$h$ 为表达式树高度，最坏情况下 $h = O(n)$。

## 总结

前缀表达式的结构天然适合递归下降求值。抓住“第一个 token 是根，后面紧跟两个子式”的性质，就能把看似需要栈或括号处理的问题直接写成简洁的递归函数。

## 形式化题目

给定正整数 $n$（$n < 100$），求

$$\sum_{\substack{1 \leqslant i \leqslant n \\ i \bmod 7 \neq 0 \,\wedge\, 7 \notin \text{digits}(i)}} i^2$$

其中 $\text{digits}(i)$ 表示 $i$ 的十进制各位数字。即：跳过所有 7 的倍数和十进制中含数字 7 的数，把剩下的数的平方加起来。

## 正解

### 思路

最朴素的想法是照着题面写循环：枚举 $i = 1 \dots n$，用一个 `if` 判断"$i$ 与 7 无关"，成立就把 $i^2$ 累加进答案：

```python
s = 0
for i in range(1, n + 1):
    if i % 7 != 0 and '7' not in str(i):
        s += i * i
```

这份循环本身就是正解的量级——$n < 100$，判断是 $O(1)$，总共 $O(n)$，不需要任何优化。真正容易出错的是**条件的逻辑**。

题面把"与 7 相关"定义成两个条件的**或**：能被 7 整除，或者某一位数字是 7。"与 7 无关"是它的否定，由德摩根律必须**同时**满足两条：

- 不是 7 的倍数：$i \bmod 7 \neq 0$；
- 十进制每一位都不是 7。

常见的错误是只否定其中一个条件，比如只写 `i % 7 != 0`（漏掉 17、27 这类含 7 的数），或者把否定写成"不能被 7 整除 **或** 各位无 7"（两者是矛盾关系，恒真/恒假，取决于写法）。正确做法是把整个析取条件取反。

"某一位是 7"的检查有两种等价写法：

- **数位拆分**：$n < 100$ 只需查十位和个位，即 `i // 10 == 7 or i % 10 == 7`（C++ 标程就是这么写的）；
- **字符串包含**：`'7' in str(i)`，把 $i$ 转成十进制字符串后查是否出现字符 `'7'`。它不依赖位数，对任意 $i$ 都成立，而且和"某一位上的数字为 7"逐位等价——本题采用这种写法。

用样例 $n = 21$ 检查过滤结果（这正是样例答案 2336 的来源）：

| 剔除原因 | 命中的数 | 说明 |
| --- | --- | --- |
| 是 7 的倍数 | 7, 14, 21 | $7k$ 型 |
| 某位数字是 7 | 7, 17 | 7 自身两条都命中，17 个位是 7 |
| 合计剔除（并集） | 7, 14, 17, 21 | 两类取并集，$[1,21]$ 共剔 4 个 |

剩下的 17 个数是 $1 \dots 21$ 去掉上面 4 个，它们的平方和正是样例输出：

$$\sum_{i=1}^{21} i^2 - (7^2 + 14^2 + 17^2 + 21^2) = 3311 - 975 = 2336$$

最后把朴素循环折叠成 Python 的表达式形式：`range` 承担计数循环，`if` 从句承担过滤判断，`sum` 承担累加，一行就是完整算法。其中 `i % 7` 直接当布尔用（非零即真）是 Python 惯用法，省去 `!= 0`。

### 复杂度

- 时间：$O(n \log_{10} n)$，枚举 $n$ 个数、每个数转字符串查 $O(\text{位数})$；$n < 100$ 时位数不超过 2，实际就是 $O(n)$。
- 空间：$O(1)$，生成器逐个产出，不建任何数组。

## 总结

本题是"条件枚举"的入门题，核心只有两点：一是用德摩根律把"相关"的析取条件正确取反成"非 7 倍数且各位无 7"的合取；二是选一种不漏位的数字 7 检查（字符串包含写法天然不依赖位数）。实现上，计数循环、过滤、累加分别映射到 `range`、`if` 从句和 `sum`，折叠成一个生成器表达式即可。

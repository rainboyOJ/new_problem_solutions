## 形式化题目

有 $n$ 个站台和 $m$ 条环形公交线路。第 $i$ 条线路长度 $t_i \geqslant 2$，站台序列为 $s_{i,1}, s_{i,2}, \dots, s_{i,t_i}$（同一站台可在一条线路中重复出现，但不会相邻）。$0$ 时刻第 $i$ 辆车位于 $s_{i,1}$，之后每个时刻驶向序列中的下一个站台，到达末站后的下一个时刻回到始发站，即车 $i$ 在时刻 $T$ 位于位置

$$j = (T \bmod t_i) + 1 \quad(\text{下标从 } 1 \text{ 起})$$

$0$ 时刻我在站台 $1$。若某时刻我与某辆车同处一个站台，我即可上车，并可在任意时刻下车，上下车不耗时；一次只能乘坐一辆车，但可以任意换乘。求最早到达站台 $2, 3, \dots, n$ 的时刻，不可达输出 $-1$。

## 正解

### 思路

**先把“车”改写成“相位固定的班次”。** 车 $i$ 在时刻 $T$ 位于位置 $j = T \bmod t_i$（改用 $0$ 起下标），也就是说：位置 $j$ 这个站台**只在时刻 $T \equiv j \pmod{t_i}$ 时才有这班车停靠**。于是每条线路的相邻两站 $s_i[j] \to s_i[(j+1) \bmod t_i]$ 构成一条“开放相位为 $j$、周期为 $t_i$”的道路，坐一站固定花 $1$ 个时刻。

**关键观察：早到永远不会更差。** 我若在 $d$ 时刻就站在站台 $v$，那么我可以在 $v$ 一直等到任何更晚的时刻再上车——等车不要钱。所以“到达某站台的时刻”这个量越小，我能接上的车只会更多，不会更少。于是每个站台只需要保留**最早到达时刻** $\mathrm{dist}[v]$，这就是一个最短路问题。

**等车时刻怎么算。** 设我在 $d$ 时刻位于站台 $v = s_i[j]$，想坐线路 $i$ 往下一站走。我必须等到该位置下一次“开门”：

$$T = d + \bigl((j - d) \bmod t_i\bigr)$$

（取非负余数，即 $((j - d) \bmod t_i + t_i) \bmod t_i$。）若 $T = d$，说明车此刻正好停在这里，立刻上车。上车后再花 $1$ 个时刻，于 $T + 1$ 到达 $s_i[(j+1) \bmod t_i]$。所以从 $v$ 出发、经由线路 $i$ 的这一次松弛给出

$$\mathrm{dist}\bigl[s_i[(j+1) \bmod t_i]\bigr] \gets \min\bigl(\cdot,\ T + 1\bigr)$$

**为什么可以套 Dijkstra，而不必把图建出来。** 普通边权最短路要求边权固定；这里的“边权”是 $T + 1 - d = \bigl((j-d) \bmod t_i\bigr) + 1$，随出发时刻 $d$ 而变。但由“早到不劣”可知：以 $\mathrm{dist}[v]$ 为出发时刻算出的到达时刻，一定不劣于用任何更晚出发时刻算出的结果。因此把 $\mathrm{dist}$ 当作松弛用的标号，Dijkstra 的贪心仍然成立——每次弹出堆顶（当前最早可到达的站台）时，它的标号已经是最优的，用这个最优时刻去松弛别人只会得到正确（或更优）的结果。

**不建图的实现。** 显式建图要对每个站台的每一条出边存相位与周期，而且边权还得在松弛时重算，不如直接预处理出“每个站台上出现过哪些（线路号，线路内位置）对”，Dijkstra 弹出一个站台 $v$ 时，遍历这张表实时算 $T$ 与下一站即可。因为每个 (线路号, 位置) 只属于一个站台，总条目数恰为 $\sum t_i$，所以复杂度与显式建图同阶。

下面用题面样例重演前几步（$0$ 时刻我在站台 $1$）：

| 当前站台（最早时刻 $d$） | 可搭的班次（位置 $j$，周期 $t_i$） | 等到 $T$ | 到达 |
| --- | --- | --- | --- |
| $1$（$d=0$） | 线路 $2$ 的 $j=2$，$t=3$（$1$ 在 $t \equiv 2$） | $T = 0 + 2 = 2$ | 站台 $2$，时刻 $2$ |
| $1$（$d=0$） | 线路 $3$ 的 $j=3$，$t=4$（$1$ 在 $t \equiv 3$） | $T = 0 + 3 = 3$ | 站台 $3$，时刻 $3$ |
| $2$（$d=2$） | 线路 $2$ 的 $j=3$，$t=3$（$2$ 在 $t \equiv 3$） | $T = 2$，车正好在此 | 站台 $6$，时刻 $3$ |
| $3$（$d=3$） | 线路 $3$ 的 $j=4$，$t=4$（$3$ 在 $t \equiv 4$） | $T = 3$，车正好在此 | 站台 $4$，时刻 $4$ |
| $4$（$d=4$） | 线路 $1$ 的 $j=2$，$t=2$（$4$ 在 $t \equiv 2$） | $T = 4 + 1 = 5$ | 站台 $5$，时刻 $6$ |

得到 $\mathrm{dist} = (2, 3, 4, 6, 3)$，站台 $7, 8$ 从未出现在任何可达路径上，输出 $-1$，与样例 `2 3 4 6 3 -1 -1` 一致。

实现上有两个易错点：

1. **余数必须取非负。** C++ 里 `(j - d) % t_i` 当 $j < d$ 时为负，要写成 `((j - d) % t_i + t_i) % t_i`；Python 的 `%` 天然非负，可直接写 `(j - d) % t_i`。
2. **`dist` 要用 64 位。** 每跳最多等 $t_i - 1$ 个时刻，总时刻上界约 $n \cdot \sum t_i \approx 10^5 \times 2 \times 10^5 = 2 \times 10^{10}$，超过 `int`，`long long` 与 Python 大整数都没问题。

### 复杂度

设 $\Sigma = \sum_i t_i$。预处理把每个 (线路号, 位置) 对挂到站台上：$O(n + \Sigma)$。Dijkstra 中每个站台出堆一次，每条条目被扫描至多一次，每次入堆 $O(\log n)$，故时间 $O(\Sigma \log n)$，空间 $O(n + \Sigma)$。

按题面数据范围 $n, m \leqslant 10^5$、$\Sigma \leqslant 2 \times 10^5$：C++ 实现实测最大测例约 $0.02$ s；Python 实现（`heapq` + 站台分桶）实测最大测例约 $0.24$ s。

## 总结

本题的难点不在最短路模板，而在**把“随时间移动的公交车”翻译成“相位固定的边”**：车 $i$ 的位置 $j$ 只在时刻 $\equiv j \pmod{t_i}$ 开门，于是“坐一站”的代价是“等到相位 $j$”的等待量 $((j - d) \bmod t_i) + 1$。第二个支点是**早到不劣**：既然等待免费，到达时刻就是唯一的标号，任何更晚到达都不会带来更多机会。有了这条单调性，即使边权依赖出发时刻，Dijkstra 的贪心依然成立，边权可以在松弛时现算，不需要把“时刻 × 站台”的时间展开图建出来（那会是 $O(\Sigma \cdot \text{lcm})$ 级别的爆炸）。把站台分桶成 (线路号, 位置) 列表后，每个条目只被扫描一次，总复杂度与显式建图同阶。

观察重点：同一辆车的周期表里，每个站台出现的位置决定了我能等到它的时刻。若我 $d$ 时刻才到站台 $1$（位置 $1$），就要等到 $T = d + ((1 - d) \bmod 3)$；这正是“相位对齐”的代价，也是本题唯一需要小心取模的地方。

## 形式化题目

给定一个 $1 \sim n$ 的排列 $P$，允许使用两个栈 $S_1, S_2$ 进行四种操作：
- `a`: 将输入序列的第一个元素压入 $S_1$
- `b`: 将 $S_1$ 栈顶元素弹出至输出序列
- `c`: 将输入序列的第一个元素压入 $S_2$
- `d`: 将 $S_2$ 栈顶元素弹出至输出序列

要求判断是否可以通过一系列操作将排列升序排序（即最终输出为 $1, 2, \dots, n$）。若不能，输出 `0`；若能，输出字典序最小的操作序列（由 `a`, `b`, `c`, `d` 组成，以空格分隔）。

数据范围：$1 \le n \le 1000$。

## 正解

### 思路

本题的核心在于判断哪些元素**绝对不能**进入同一个栈。
假设元素 $P_i$ 和 $P_j$（$i < j$）被分到了同一个栈。因为 $i < j$，$P_i$ 会先入栈。如果 $P_i < P_j$，为了按升序输出，$P_i$ 必须在 $P_j$ 之前出栈。如果此时输入序列中还有某个元素 $P_k$（$k > j$）满足 $P_k < P_i$，那么 $P_i$ 就不能在 $P_j$ 入栈前出栈（因为比 $P_i$ 更小的 $P_k$ 还没进入体系被处理）。这样一来，$P_j$ 必然会被压在 $P_i$ 之上，导致较大的数压在较小的数上面，这在要求升序输出的栈排序中是非法的。

因此，两个元素 $P_i$ 和 $P_j$ 不能在同一个栈的**充要条件**是：
$$ i < j \quad \text{且} \quad P_i < P_j \quad \text{且} \quad \exists k > j, \ P_k < P_i $$

我们可以预处理一个后缀最小值数组 `min_val`，其中 `min_val[i]` 表示 $P_i \sim P_n$ 中的最小值。
上述冲突条件即可化简为：$i < j \land P_i < P_j \land \text{min\_val}[j+1] < P_i$。

对于所有满足冲突条件的点对 $(i, j)$，我们在它们之间连一条无向边，表示它们必须进入不同的栈。
- 如果该冲突图不是二分图（无法用两种颜色染色），说明无论怎么分配都会产生冲突，即无法排序，输出 `0`。
- 如果是二分图，则一定可以排序。由于题目要求字典序最小，且字典序 `a < b < c < d`，我们应该尽可能让元素提前进入 $S_1$。因此，在给二分图的每个连通块染色时，我们将第一个未访问的节点固定染成颜色 $1$（代表分配给 $S_1$），然后再 DFS/BFS 染完整个连通块。

染色完成后，每个元素应该进入哪个栈就已经确定了。最后，我们只需按照 `a, b, c, d` 的优先级顺序，贪心地模拟每一步操作即可：
1. **a 操作**：如果当前输入元素属于 $S_1$，且 $S_1$ 为空或栈顶元素大于当前元素，则执行 `a`。
2. **b 操作**：如果 $S_1$ 栈顶恰好等于当前需要输出的元素（`expected`），则执行 `b`。
3. **c 操作**：如果当前输入元素属于 $S_2$，且 $S_2$ 为空或栈顶元素大于当前元素，则执行 `c`。
4. **d 操作**：如果 $S_2$ 栈顶恰好等于当前需要输出的元素（`expected`），则执行 `d`。

只要能够合法执行，就从上述 `1` 到 `4` 尝试，保证字典序是最优的。

### 复杂度

- **时间复杂度**：
  预处理后缀最小值需要 $O(n)$。
  建图过程需要双重循环遍历 $i$ 和 $j$，时间复杂度为 $O(n^2)$。
  二分图 BFS/DFS 染色遍历所有点和边，时间复杂度为 $O(n^2)$。
  模拟过程最多发生 $2n$ 次进栈和出栈操作，时间复杂度为 $O(n)$。
  因此总时间复杂度为 $O(n^2)$，在 $n \le 1000$ 时极为高效。
- **空间复杂度**：
  需要存储邻接表表示的图，最多有 $O(n^2)$ 条边。空间复杂度为 $O(n^2)$，常数较小，完全符合 128 MB 的限制。

## 总结

1. **核心转化**：将“能否放入同一个栈”的问题转化为判定是否存在 $P_k < P_i < P_j\ (i < j < k)$ 的冲突组合，进而转换为无向图的二分染色判定问题。
2. **贪心模拟**：由于严谨的冲突排除，安全的进出栈操作一定不会死锁，因此可以严格按照优先级 `a > b > c > d` 取得字典序最优解，无需回溯。
3. **防坑点**：判断连边时的条件必须同时满足三个子条件，遗漏任何一个都会错判；在贪心模拟中，`a` / `c` 操作的条件除了检查对应栈的颜色分配，还需判定 `top() > P[ptr]` 以维持栈内的单调递减性。

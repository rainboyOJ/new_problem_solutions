## 形式化题目

棋盘可以看成整点集合 $\mathbb{Z}^2$。给定起点 $S=(f_x,f_y)$、终点 $T=(t_x,t_y)$，
以及 $n$ 个非零向量 $v_1,\dots,v_n \in \mathbb{Z}^2$（$v_i=(x_i,y_i)$）。
一次移动把当前点 $p$ 变成 $p+v_i$（可以重复使用同一个向量）。
求最小的 $k$，使得存在下标序列 $i_1,\dots,i_k$ 满足

$$
S + v_{i_1} + v_{i_2} + \cdots + v_{i_k} = T ,
$$

即目标位移 $\Delta = T - S$ 能写成若干个（可重复）$v_i$ 之和，且使用的向量个数最少。
无解输出 `IMPOSSIBLE`。

输入规模：$T < 20$ 组数据，坐标满足 $-5000 \le f_x,f_y,t_x,t_y \le 5000$，
$1 \le n \le 10$，向量分量 $1 \le x,y \le 10$。

**一个小判据。** 因为题面保证向量分量都非负，若目标落在起点左下方
（$t_x < f_x$ 或 $t_y < f_y$），无论怎么走都只能让坐标不减，直接不可达。
另外一个不写进代码、只用于理解的做法：若所有向量的分量都是偶数、而某个坐标差是奇数，
则由奇偶性不变可知无解——但 BFS 本身就会得出 `IMPOSSIBLE`，所以代码里只保留了
上面那条非负性判据。

## 正解

### 思路

**朴素做法：BFS。** 每个状态是一个整点，边是「加一个向量」。这是一张无权图，
从起点 BFS 第一次走到终点时的层数就是答案。

**瓶颈在哪？** 棋盘无限大，从 $(-5000,-5000)$ 走到 $(5000,5000)$ 时，
BFS 会向外扩散到半径 $10^4$ 的区域，即约 $4\times 10^8$ 个状态；即使每步只走 (10,10)，
走 1000 步的过程中如果按「所有点」展开，队列规模也是 $O(\text{步数} \times n)$ 的
多层爆炸。真正的浪费是：**绝大多数被搜到的点根本不在「起点到终点」的方向上。**

**关键观察：最优路径可以贴着连线走。**
设 $L = |T-S|$ 是起终点距离，$v_{\max}$ 是所有向量中模长最大者，
$D = \max_i |v_i|^2$。把最优解中的向量按顺序重排（向量加法可交换！），
可以证明存在一条同样长度的最优路径，其中每一时刻当前点到线段 $ST$ 的距离不超过
$v_{\max}$。直觉：如果某一步之后点离连线太远，那么后面必然有一步要把它拉回来；
而「拉回来」这一步和「拉出去」那一步的合成位移仍然是一个合法位移，把这两步的
位置对调不会增加总步数，但会让路径更贴线。因此**存在一条最优路径全程落在
走廊 $\{p : \operatorname{dist}(p, ST) \le \sqrt{D}\}$ 内**。

走廊的面积：长度 $O(|dx| + |dy|)$、宽度 $O(\sqrt D)$，于是状态数上界约为
$(|dx|+|dy|) \cdot 2\sqrt{2D}$。本题 $|dx|+|dy| \le 2\times 10^4$、$D \le 200$，
约 $4\times 10^5$ 个状态，可以放心 BFS。

**走廊怎么判？** 设连线方向 $\vec n = T - S = (dx, dy)$，法向量 $\vec m = (dy, -dx)$，
连线方程 $dy \cdot x - dx \cdot y + C = 0$，其中 $C = f_y t_x - f_x t_y$（代入 $S$、$T$ 都成立）。
点 $p$ 到连线的距离平方为 $\dfrac{(\vec m \cdot p + C)^2}{|\vec m|^2}$，
$|\vec m|^2 = dx^2 + dy^2$，与 $D$ 比较时把分母乘过去即可，全程整数运算不需要开方：

$$
(\vec m \cdot p + C)^2 \le D \cdot (dx^2 + dy^2).
$$

另外必须要求**投影落在段内**（而不是整条直线上）：用两端点各做一次点积判方向，
$(T-S)\cdot(p-S) \ge 0$ 且 $(S-T)\cdot(p-T) \ge 0$ 表示 $p$ 的投影在线段 $ST$ 之中。
否则点会顺着连线的延长线跑到无穷远，走廊变成半无限长条。

**退化情形保留。** 当起终点非常近（$|T-S| \le \sqrt D$，比如起点等于终点、
或目标就在一步之内）时，走廊本身很窄甚至无宽度，而最优路径可能是先「绕远再回来」。
所以额外无条件保留**起点和终点各自半径 $\sqrt D$ 的球内**的所有点：
$(p_x-f_x)^2+(p_y-f_y)^2 \le D$ 或 $(p_x-t_x)^2+(p_y-t_y)^2 \le D$。
这两个球总共才 $O(D)$ 个点，不会破坏复杂度，但覆盖了所有「短距离」情形。

**去重。** 走廊内的点数量级是 $10^5 \sim 10^6$，坐标范围 $[-5000,5000]$ 只用
$10^4 \times 10^4$ 就够放布尔表，但每次查询都要清空整张表代价太大。
可以直接用 `int` 坐标哈希成一个 $\Theta(1)$ 的集合：C++ 手写开散列（质数
$999983$ 取模 + 邻接链表），Python 直接用 `set`。**用「是否见过」代替「记 dist」**：
BFS 每层推进一格，第一次弹出的终点所在层号就是答案。

### 复杂度

- **时间**：设 $N$ 为走廊内的状态数，$N = O\big((|dx|+|dy|)\sqrt D\big)$，
  每个状态扩展 $n$ 条边，故 $O(N n)$。本题 $|dx|+|dy| \le 2\times10^4$、
  $D \le 200$、$n \le 10$，$N$ 约 $4\times 10^5$，单组数据为千万级常数次运算，
  加上 $T<20$ 与 3000 ms 限时余量充足。
- **空间**：状态哈希表与 BFS 队列各 $O(N)$。C++ 用 `Entry{x, y, nxt}` 结构数组（$10^6$ 个）
  加 $999983$ 个桶头，共约 $4\times10^6$ 个 `int` ≈ 16 MB，符合 64 MB 限制；
  实测峰值 10.7 MB（预分配但未全部触页）。
- **实测**（真实数据 10 点，`main.cpp`）：最大状态数出现在点 9（答案 1000、
  向量含 (10,10)），为 **408 163** 个状态，与上界估算吻合并正好顶到题目上限；
  单点耗时 ≤ 0.025 s，峰值内存 ≤ 10.7 MB。
- **为什么不用「数学解法」**：向量的 $x$、$y$ 分量互相耦合（不能把两个坐标拆开独立
  做完全背包），且 $n$ 小时最优解的步数可以很大（例如单向量 (10,10) 要走 1000 步），
  整数规划式的做法无法通用，BFS + 走廊剪枝是本题的标准做法。
- **Python 侧的 TLE 风险**：`main.py` 与 C++ 同阶（都是走廊内 $N$ 个状态的 BFS），
  但常数大很多。实测 10 组真实数据单点 ≤ 0.55 s；把真实数据里最重的点 9
  （$N=408\,163$）重复 20 遍凑成极限输入时约 9.9 s，而 C++ 只要 0.3 s。
  本题给 Python 的预算需要 3 s 以上，题面 3000 ms 下属于边界情况，
  这也是本仓库允许 Python 短解法 TLE 的典型情形。

## 总结

- **无限图上的最短路，先想办法把状态压回有限且小。** 本题的状态数是无限的，
  唯一出路是证明「存在一条最优路径落在某个窄区域里」，再用区域面积估界。
- **向量加法可交换是剪枝的合法性来源。** 因为顺序无关，才能对调步骤把路径「拉直」，
  这是「贴线走廊」成立的本质原因。
- **距离比较用平方，投影判定用点积**，全程整数运算，避免浮点误差把边界点误剪。
- **退化情形（起终点很近）要单独兜底**：走廊宽度为 0 时 `<= D` 的球内保留就是兜底。
- **关于素材的 `std.cpp`**：它与本题题面一致（示例输出、10 组真实数据均对得上），
  本仓库的实现独立重写了数据结构（BFS 按层推进、手动开散列）与剪枝写法，
  但走廊剪枝这一核心思路的确相同——这是本题唯一可行的思路，不属于照抄。
- 本题素材源自带的 `data.py` 说明测试数据是**自动生成**的，题面是网络重建版
  （与 POJ 3985 同题），出题意图与原官方题可能略有偏差；本解法的正确性依据是
  题面本身加真实数据比对，而不是「官方 AC」。

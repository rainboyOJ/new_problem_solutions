## 形式化题目

给定 $n$ 扇防御门，每扇门是一个运算 $op_i \in \{\text{AND}, \text{OR}, \text{XOR}\}$ 与一个非负整数参数 $t_i$。
定义 $f(x)$ 为把 $x$ 依次送过所有门的结果：

$$
f(x) = \big(\cdots((x\ op_1\ t_1)\ op_2\ t_2)\cdots\big)\ op_n\ t_n
$$

求 $\max\limits_{0 \leqslant x \leqslant m} f(x)$。只需输出最大值，不需要输出取到最大值的 $x$。
按位运算的规则是：两个数前补 0 到等长后逐位计算。

样例 $n=3,\ m=10$，门依次为 `AND 5`、`OR 6`、`XOR 7`：

| $x$ | $x \wedge 5$ | $\ \vee 6$ | $\oplus 7 = f(x)$ |
| :---: | :---: | :---: | :---: |
| 0 | 0 | 6 | **1** |
| 1 | 1 | 7 | 0 |
| 2 | 0 | 6 | **1** |
| 3 | 1 | 7 | 0 |
| 4 | 4 | 6 | **1** |
| $\vdots$ | | | |
| 10 | 0 | 6 | **1** |

为什么偶数得 1、奇数得 0？只看最低位：$5 = 101_2$ 和 $6 = 110_2$ 的第 0 位分别是 1 和 0，
所以 `AND 5`、`OR 6` 都把 $x$ 的第 0 位**原样透传**；而 $7 = 111_2$ 的第 0 位是 1，
`XOR 7` 把它翻一次：偶数 $x$ 的第 0 位是 0，翻成 1；奇数 $x$ 的第 0 位是 1，翻成 0。
更高位更简单：`AND 5` 把第 2 位以上全部清零，`OR 6` 再把第 1、2 位固定成 $11_2$，
此时值只能是 6 或 7，再经 `XOR 7` 后全部归零。
所以最终伤害只能取 0 或 1，最大值是 $1$。
这个样例还提示了两件事：**结果既不随 $x$ 单调增长，也不总在 $x = m$ 处取到**
（后者例如 $n=1$、门 `AND 3`、$m=4$：$f(4) = 0$，而 $f(3) = 3$ 更大），必须真的去做最大化。

## 正解

### 思路

**朴素做法**：枚举 $x = 0, 1, \dots, m$，每个 $x$ 依次穿过 $n$ 扇门，取最大值。
时间是 $O(nm)$：最坏 $n = 10^5$、$m = 6.6 \times 10^8$，约 $10^{13}$ 次运算，不可行。

**瓶颈一：候选太多。** 要枚举 $m+1$ 个 $x$，这本身就是天文数字。能不能不枚举 $x$？

**关键观察：位与位互不影响。** 题面规定两个数前补 0 到等长再逐位运算，
AND / OR / XOR 又都是逐位运算——所以一次运算的第 $b$ 位只用到两个数的第 $b$ 位。
$n$ 扇门串起来后这条性质依旧成立：**$f(x)$ 的第 $b$ 位只取决于 $x$ 的第 $b$ 位**，与其他位无关。

于是 $f$ 可以按位拆开。记 $f_b(c)$ 为「输入的第 $b$ 位是 $c$ 时，输出的第 $b$ 位」，则

$$
f(x) = \sum_b f_b(x_b)\cdot 2^b
$$

$B$ 位的联合决策被拆成了 $B$ 个互不相干的二元决策，未知量只剩 $f_b(0)$ 与 $f_b(1)$。

先建立一点直觉。一扇门对某一比特只有四种可能的作用，写成 $(\text{输入 }0\text{ 的输出},\ \text{输入 }1\text{ 的输出})$：

| 单扇门 | 该位输入 0 的输出 | 该位输入 1 的输出 | 作用 |
| :---: | :---: | :---: | :--- |
| `AND 0` | 0 | 0 | 强制清零 |
| `AND 1` | 0 | 1 | 原样透传 |
| `OR 0` | 0 | 1 | 原样透传 |
| `OR 1` | 1 | 1 | 强制置一 |
| `XOR 0` | 0 | 1 | 原样透传 |
| `XOR 1` | 1 | 0 | 该位取反 |

六种门按参数的一位展开就是这四种：$t$ 的该位是 0 时 `AND` 是恒 0、`OR` 与 `XOR` 是透传；
该位是 1 时 `AND` 是透传、`OR` 是恒 1、`XOR` 是取反。多扇门串起来只是这四种作用的复合，
复合结果仍落在这四种里。所以 $f_b$ 只需两个比特就能描述：$(f_b(0), f_b(1)) \in \{00, 01, 10, 11\}$——
`00` 是恒 0，`11` 是恒 1，`01` 是透传，`10` 是取反。

**瓶颈二：求 $f_b(0)$、$f_b(1)$ 还要不要 $O(nB)$？** 不用。由位独立性，
$f_b(1)$ 恰好是 $f(2^b)$ 的第 $b$ 位。把**所有**需要用到的位同时摆成 1，一次穿越就同时得到全部 $f_b(1)$：

$$
lo = f(0), \qquad hi = f(2^B - 1)
$$

$lo$ 的第 $b$ 位是 $f_b(0)$，$hi$ 的第 $b$ 位是 $f_b(1)$。总共只穿越两次。

**瓶颈三：$x_b$ 怎么定？** 现在目标变成最大化

$$
f(x) = \sum_{b} c_b(x_b)\cdot 2^b, \qquad c_b(0) = lo_b,\quad c_b(1) = hi_b
$$

这是加权最大化，**高位权重大于所有低位之和**（$2^b > \sum_{j<b} 2^j$），
所以必须从高位到低位决定，高位能拿 1 就拿 1。唯一的约束是 $\sum_b x_b 2^b \leqslant m$，
用一个累加变量 `a` 记录已经花掉的预算即可。对第 $b$ 位：

1. 若 $lo_b = 1$：输入 0 就已经得到 1，**白拿**，令 $x_b = 0$，不花一分预算；
2. 否则若 $hi_b = 1$ 且 $a + 2^b \leqslant m$：花 $2^b$ 买下这一位，$a \gets a + 2^b$；
3. 否则这一位拿不到 1（$lo_b = hi_b = 0$，或预算不够），令 $x_b = 0$。

第 1 条必须排在第 2 条之前，这是全题最容易写错的一步：既然输入 0 就能拿到 1，
再花 $2^b$ 去买 1 就是纯浪费，省下的预算还能在更低位买到更多的 1。
跳过这条优先级，答案会变小——例如 $n=4$、$m=24$、门为 `AND 6`、`OR 1`、`OR 27`、`XOR 0` 时
（此时 $lo = 27$、$hi = 31$），先买高位的版本取 $x = 24$ 得 27，而正确的是 $x = 4$ 得 31。

三个瓶颈各消除一层，算法就定下来了：读入 $n$ 扇门 $\to$ 穿越两次得 $lo, hi \to$ 从高位到低位贪心。

## 总结

本题的核心只有两句话：

1. **按位独立**：AND / OR / XOR 逐位运算，所以 $f$ 的每一位只由 $x$ 的同一位决定，
   $m+1$ 个候选取值根本不必枚举；把所有位一起摆 1（再摆 0）穿越两次，就能一次性测出全部位的性质。
2. **高位优先贪心**：位权 $2^b$ 大于所有低位权重之和，所以从高位往低位能拿就拿，
   但要先用累计预算 `a` 检查 $a + 2^b \leqslant m$；输入 0 就能拿到的位免费，绝不为它花钱。

这是一个「$O(nm)$ 枚举 $\to$ $O(n + \log)$ 贪心」的典型转化：先用量词结构（按位独立）砍掉候选集合，
再用权重结构（二进制位权）砍掉搜索顺序。

| 位 $b$ | $2^b$ | $lo$ 的该位 | $hi$ 的该位 | 预算 $a$ | 判定 | $x_b$ | 伤害位 |
| :---: | :---: | :---: | :---: | :---: | :--- | :---: | :---: |
| 3 | 8 | 0 | 0 | 0 | $lo_b = hi_b = 0$，两种输入都得 0，放弃 | 0 | 0 |
| 2 | 4 | 0 | 0 | 0 | 同上 | 0 | 0 |
| 1 | 2 | 0 | 0 | 0 | 同上 | 0 | 0 |
| 0 | 1 | 1 | 0 | 0 | 输入 0 就已经是 1，**白拿** | 0 | 1 |

贪心构造出的 $x = 0$，伤害 $f(0) = 1$，与枚举得到的最大值一致。
观察重点有两个：一是四位里只有第 0 位有机会，其余位在 $lo$ 和 $hi$ 中都是 0，说明它们被门强制清零了；
二是第 0 位是「白拿」的——输入 0 就有 1，因此不需要动预算，这也说明了为什么 `free` 必须优先于 `buy`。

## 题目描述

杭州人称那些傻乎乎粘嗒嗒的人为 62（音：laoer）。杭州交通管理局以后发放的士牌照不再含有不吉利的数字：一个号码是**不吉利**的，当且仅当它含有数字 $4$，或含有相邻子串 $62$。例如 $62315, 73418, 88914$ 都不吉利；而 $61152$ 虽含 $6$ 和 $2$ 但不相邻，属于吉利号码。你的任务是，对每次给出的牌照区间 $[n, m]$，输出其中吉利号码的个数，每个数占一行；输入为多组整数对 $n, m$，遇到 $n = m = 0$ 时输入结束。样例中区间 $[1, 100]$ 内不吉利的数共 $20$ 个（含 $4$ 的 $19$ 个，加上 $62$），故答案为 $101 - 1 - 20 = 80$。

```
1 100
0 0
```

```
80
```

## 思路

区间计数先化成前缀相减：答案 $= f(m) - f(n-1)$，其中 $f(x)$ 是 $[0, x]$ 内不含 $4$ 和 $62$ 的数的个数。求 $f(x)$ 用数位 DP：从高到低逐位填数，状态记（当前位、是否贴着上界、上一位是否为 $6$），当前位填 $4$、或上一位是 $6$ 而本位填 $2$ 时剪掉；只有贴上界走到位值才保持 tight，前导零无需特判。状态数只有位数 $\times 2 \times 2$，每个询问调用两次即可。

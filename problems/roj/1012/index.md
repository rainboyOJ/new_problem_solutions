## 形式化题目

给定实数 $x$ 与四个系数 $a、b、c、d$（五个数的绝对值都不超过 $100$），求三次多项式

$$f(x) = ax^3 + bx^2 + cx + d$$

在 $x$ 处的值，并把结果四舍五入到小数点后 $7$ 位。

输入样例：

```
2.31 1.2 2 2 3
```

输出样例：

```
33.0838692
```

样例解释：$x = 2.31$，$a = 1.2$，$b = 2$，$c = 2$，$d = 3$，逐项代入得到下表。

| 项 | 计算式 | 值 |
| --- | --- | --- |
| $ax^3$ | $1.2 \times 2.31^3 = 1.2 \times 12.326391$ | $14.7916692$ |
| $bx^2$ | $2 \times 2.31^2 = 2 \times 5.3361$ | $10.6722$ |
| $cx$ | $2 \times 2.31$ | $4.62$ |
| $d$ | 常数项 | $3$ |
| 合计 | $f(2.31)$ | $33.0838692$ |

四项之和恰好是 $33.0838692$，本身就已经是 $7$ 位小数，所以输出与求和结果完全相同。

## 正解

### 思路

公式已经写在题面里，解法就是把公式直译成代码，分三步。

**第一步：按题面顺序读入。** 题面的顺序是 $x$ 在前、系数 $a、b、c、d$ 在后，这是本题最容易读错的地方（样例里的 `2.31` 是 $x$，不是 $a$）。用一次 `sys.stdin.buffer.read().split()` 取到全部实数，再按 `x, a, b, c, d` 解包，读入顺序就写在变量名里，肉眼即可核对。

**第二步：代入求值。** 把 $f(x)$ 展开成常数个乘加：

$$
f(x) = a \cdot x \cdot x \cdot x + b \cdot x \cdot x + c \cdot x + d
$$

这里刻意不写 `pow(x, 3)`，而写成 `a * x * x * x` 这样的连乘：浮点乘法不满足结合律，左结合的连乘与常见标准写法（`a*x*x*x + b*x*x + c*x + d`）逐位一致，避免"数学上相等、末位却不同"在输出 $7$ 位小数时露出差异。另一种更省乘法的写法是秦九韶（Horner）形式 $((ax+b)x+c)x+d$，乘法次数从 $6$ 次降到 $3$ 次，但复杂度同为 $O(1)$，反而可能改变末位，收益为零，因此不采用。

精度上本题也不需要额外处理。真实数据里 $|x|、|a| \leqslant 100$，于是 $|ax^3| \leqslant 100 \times 100^3 = 10^8 < 2^{53}$，每一步乘加的中间结果都是 double 能精确表示的整数，求值过程本身不会引入舍入误差，剩下的只有输出格式。

**第三步：按固定小数位输出。** "保留到小数点后 $7$ 位"是定点格式，用 f-string 的 `:.7f` 一次完成四舍五入与补尾零：整数结果 `2156925` 会输出成 `2156925.0000000`。不要改用 `round(y, 7)`，它按有效数字工作，也不会补齐末尾的 $0$。

## 总结

本题的知识点只有两条：

- **读入顺序要对着题面写。** $x$ 是第一个数。把顺序直接写进变量名（`x, a, b, c, d = ...`）是最便宜的防错手段。
- **"保留 $k$ 位小数"用定点格式化。** Python 里是 `f"{y:.7f}"`，等价于 C++ 的 `fixed << setprecision(7)`，它同时负责四舍五入与补尾零。

代入求值本身没有算法难度，但连乘顺序、是否改写成秦九韶、用哪种取整方式，都会在"精确到 $7$ 位小数"的要求下变成可见差异，这是入门阶段值得养成的习惯。

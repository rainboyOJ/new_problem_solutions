## 形式化题目

给出 $N$ 个点、$M$ 条带权无相边的图，边权 $c_j$ 表示两点间的怨气值。要把所有点划分成两个集合（两座监狱），一条边 $(a,b,c)$ 产生冲突当且仅当 $a,b$ 被分进**同一个**集合，冲突影响力为 $c$。

求一种划分方案，使得所有冲突的最大影响力最小，输出这个最小值；若不存在任何冲突则输出 $0$。

数据范围：$N \le 20000$，$M \le 100000$，$0 < c_j \le 10^9$。

## 正解

### 思路

**朴素做法。** 最直接的想法是枚举每个罪犯去哪座监狱（$2^N$ 种方案），对每种方案算出最大冲突影响力，取最小。$N \le 20000$ 时完全不可行，必须利用问题的特殊结构。

**关键观察一：答案只由"某条边被迫同狱"决定。** 设答案为 $x$，意味着：怨气值 $> x$ 的仇恨对都被成功分开了（同一座监狱里不存在这样的对），而某条怨气值为 $x$ 的边无法分开。反过来看，如果按怨气值**从大到小**处理仇恨对，尽量把每对都分到不同监狱，那么第一个"分不开"的对，它的怨气值就是答案——因为比它怨气值更大的对都已经处理完且没有冲突，市长看到的最大影响力恰好就是它。

**关键观察二："分开所有怨气值大的对"本质是二分图判定。** 把怨气值 $> x$ 的边全部保留，要求把点染成两色、每条边两端异色——这就是经典的二分图 2-染色问题。于是答案可以二分：判定"怨气值 $\ge x$ 的边构成的图是否是二分图"，随 $x$ 减小判定只会更容易，具有单调性。二分 + 每次染色是 $O(M \log C)$ 或 $O((N+M)\log M)$，已经可以过。但本题有更优雅、常数更小的写法：**不开两座监狱反复染色，而是用并查集一次扫完**。

**扩展域并查集（"敌人的敌人是朋友"）。** 把每个罪犯 $i$ 拆成两个域：

- $i$："$i$ 在第一监狱"这个身份；
- $i+n$："$i$ 在第二监狱"这个身份。

约束 "$a$ 与 $b$ 必须分居两狱" 翻译成两条合并：

- 合并 $a$ 与 $b+n$（$a$ 在一狱 $\Rightarrow$ $b$ 在二狱）；
- 合并 $b$ 与 $a+n$（$b$ 在一狱 $\Rightarrow$ $a$ 在二狱）。

一个并查集分量里所有"$a$ 或 $a+n$ 型"域是**必须同时成立**的绑定关系，所以 $find(a) = find(b)$ 就表示"$a$ 在一狱"与"$b$ 在一狱"被绑死了，即 $a,b$ 被迫同狱。

**算法流程：** 仇恨边按怨气值**降序**排序，逐条处理：

1. 若 $find(a) = find(b)$：这条边无法再分开，它的怨气值 $c$ 就是答案，直接输出（更大的边都已被合法安置，之后也不会产生更大的冲突）。
2. 否则合并 $a \sim b+n$、$b \sim a+n$，继续处理下一条。

所有边都处理完仍未冲突，说明图可以完全二分，答案为 $0$。

用样例走一遍。$n=4$，第一监狱域用 $1..4$ 表示，第二监狱域用 $1'..4'$（即 $5..8$）表示。边按怨气值降序处理，前三条都能安置：

| 步骤 | 边 $(a,b,c)$ | 检查 | 动作（合并后同色块绑定） |
| :---: | :---: | :--- | :--- |
| 1 | $(1,2,28351)$ | $find(1)=1 \ne find(2)=2$ | 合并 $1 \sim 2'$、$2 \sim 1'$ |
| 2 | $(3,4,12884)$ | $find(3)=3 \ne find(4)=4$ | 合并 $3 \sim 4'$、$4 \sim 3'$ |
| 3 | $(1,3,6618)$ | $find(1)=2' \ne find(3)=4'$ | 合并 $2' \sim 3'$、$4' \sim 1'$ |
| 4 | $(2,3,3512)$ | $find(2)=1'$、$find(3)=4'$，而步骤 3 已把 $4'$ 并入 $1'$ 所在分量，$find(2)=find(3)$ | **被迫同狱 → 输出 3512** |

步骤 3 之后，$2'$ 与 $3'$ 同分量、$4'$ 与 $1'$ 同分量；步骤 4 检查 $2$ 与 $3$ 时，$find(2)=1'$、$find(3)=4'$，而 $4'$ 已并入 $1'$ 所在分量——$2$ 和 $3$ 已被前面的大怨气值关系绑到同一座监狱，这条怨气值 $3512$ 的边无法满足，直接输出 $3512$，与样例一致。

这正体现了算法的正确性：**输出的一定是降序扫描中第一条无法满足的边**，比它大的边都已安置，因此这就是最大冲突的最小值。

### 复杂度

- 排序 $O(M \log M)$；并查集近似 $O(M\, \alpha(N))$（$\alpha$ 是阿克曼反函数，可视为常数）。总时间 $O(M \log M)$，对 $M \le 10^5$ 绰绰有余。
- 扩展域数组大小 $2N + 1$，空间 $O(N)$。

## 总结

- 答案 = 按怨气值**降序**扫描时第一条"无法分居"的仇恨边的怨气值；全部可分则答案为 $0$。
- "分居"约束用**扩展域并查集**表达：$i$ 与 $i+n$ 两个域，合并 $a \sim b+n$、$b \sim a+n$；$find(a) = find(b)$ 即被迫同狱。
- 正确性核心是单调性：大怨气值全部安置后，第一次失败处就是最优的最大冲突，无需二分。
- 对比另一常见写法（二分答案 + 染色判二分图），扩展域并查集一次排序加一次扫描即可，实现更短、常数更小。

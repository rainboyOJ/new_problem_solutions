## 形式化题目

给定两个非负整数 $x$ 和 $y$（$0 \le x, y \le 10^6$），分别代表男生和女生的人数。已知男生平均分为 $87$，女生平均分为 $85$。
求全体学生的加权平均分：
$$ \text{avg} = \frac{87x + 85y}{x + y} $$
结果需保留 $4$ 位小数。

## 正解

### 思路

计算加权平均分的原始公式为：
$$ A = \frac{87x + 85y}{x + y} $$
在数学上，该公式等价于 $C = 85 + \frac{2x}{x+y}$。但 $C$ 形式仅供理解其上下界特性使用，**在代码实现时必须直接使用 $A$ 形式**。浮点运算由于精度问题，在极其微弱的舍入边界上两者存在分歧，因此应保持最直接的计算方式。由于计算只需一次四则运算，过程是绝对的 $O(1)$ 常数时间。

## 总结

1. **算法**：基于公式 $A = \frac{87x+85y}{x+y}$ 进行计算，输出保留 4 位小数（`%.4f`），时间复杂度 $O(1)$。
2. **平局点存在且有闭式刻画**：设 $g=\gcd(x,y)$，$x=ga$，$y=gb$（$\gcd(a,b)=1$），该分数在保留 4 位小数时表现为“半整数”（第 5 位小数恰好为 5）的充要条件是 $a+b \in \{64, 320, 1600, 8000, 40000\}$。
   - 在 $0 \le x, y \le 10^6$ 范围内，共存在 **2,901,234** 个平局点（占比约 0.29%）。
   - 最小平局点为 $(1, 63) \to 85.03125$。
   - **双重验证**：闭式计数与在 $[0, 1500]^2$ 网格内的 2348 个穷举点进行交叉验证，结果 100% 吻合（不一致 0 个）。
3. **平局点上不同实现会分裂**：在这些平局点上，输出结果取决于 `double` 的舍入残差方向，而该方向**无规律可循**（实测表明 38.1% 上偏、38.1% 下偏、23.9% 恰好可精确表示）。以 `printf` 为基准测试 2,901,234 个平局点：
   - 常见写法 `math.floor(v*1e4+0.5)` 有 **1,296,238** 处分歧（44.7%），例如 $(1,63)$ 输出 `85.0313` 而非 `85.0312`。
   - 精确 `ROUND_HALF_UP` 存在 50.0% 分歧，精确 `ROUND_HALF_EVEN` 存在 38.1% 分歧。
   - **真实数据恰好避开了全部平局点**（距半整数最近的数据点为 `p8`，差值达 0.0373）。本题能稳定通过是**纯粹的数据运气**，并不代表各种实现形式在浮点特性上绝对安全一致。
4. **公式等价性陷阱**：等价公式 $85 + \frac{2x}{x+y}$ 仅供数学层面理解，**实现必须用 A 形式**。实测在平局点上比对 A 形式与 C 形式，产生了 **2822** 个格式化输出分歧（且全数落在平局点上）。例如 `(10107, 29893)` A 输出 `85.5054`，而 C 输出 `85.5053`。
5. **极值未定义不对称**：输入 `0 0` 时 $x+y=0$。C++ 侧计算得 `nan` 且 `rc=0`（并非 UB）；而 Python 侧会抛出 `ZeroDivisionError` 崩溃且 `rc=1`。此极值在两语言中表现不对称，目前**数据未覆盖**（评测数据中最小的 $x+y=1$）。
6. **V1 反事实诊断表**：
   | 变体 | 失败点数 | 最小复现 |
   |---|---|---|
   | BASELINE（交付版）| **0/10** | — |

   | 分母写成 `x*y` | **10/10** | `1 1` → `172.0000` |
   | 分母只写 `x` | **9/10** | `1 1` → `172.0000`（★ 只有 `p9` 恰好蒙对，因该点 $y=0$）|

7. **数值范围**：$x=y=10^6$ 时，分子 $87x+85y = 1.72\times 10^8$。该数值远小于 $2^{53}$，故在 `double` 内完全精确无损；同时也小于 $2^{31}-1$，在 32 位 `int` 中具有 12.5 倍的余量，同样安全。项目中使用 `long long` 算分子是一种规范与防御性选择，而非正确性上的强制要求。
8. **两个极值端点**：数据点均已覆盖极值。`p2 = 0 1` (全女生) 输出 `85.0000`，`p9 = 1000000 0` (全男生) 输出 `87.0000`。
9. **输出格式**：末尾 0 必须保留，无多余行尾空格，并恰好有一个 `\n`。
10. **T9 五项**：
    - 类型转换：分子在防御性 `long long` 中计算后统一转 `double` 相除。
    - 溢出：均在安全范围内，无溢出。
    - 整除取模：无。
    - 浮点格式化：`printf("%.4f")` 与 Python `f"{v:.4f}"` 在非平局的真实数据上逐字节一致。本题唯一的浮点敏感点仅存在于上文刻画的平局点中。
    - 排序字典序：无。

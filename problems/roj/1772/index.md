## 形式化题目

给出 $N$ 部动漫。除 $1$ 号外，每部动漫有且仅有一部「前传」（父亲），于是 $N$ 部动漫构成
一棵以 $1$ 号为根的树。一个「排序方案」就是 $1 \sim N$ 的一个排列 $p$，要求

1. **祖先限制**：若 $v$ 是 $u$ 的后继（子孙），则 $u$ 必须排在 $v$ 之前；
2. **兄弟限制**：设 $u$ 的孩子按喜爱度从大到小为 $c_1, c_2, \dots, c_k$（即输入顺序），
   则必须满足 $c_1$ 排在 $c_2$ 之前、$c_2$ 排在 $c_3$ 之前……即
   $c_1 \prec c_2 \prec \cdots \prec c_k$。

求合法排列的数量 $\bmod 10007$。

注意「$u$ 排在子孙之前」与「孩子按序出现」都只是**偏序**，并不要求某个子树整体连续。
把树边和孩子之间的链式边合起来看，这是一张 DAG，求它的拓扑序个数——一般 DAG 的拓扑序计数
是 #P 完全的，状压 DP 需要 $O(2^n n)$，$n = 1000$ 时完全不可行。但本题的 DAG 有特殊形状：
除了树边，只有**同一个父亲的孩子之间**的链式边，这正好容许一个 $O(n)$ 的树形 DP。

输入格式：第一行 $T$（数据组数）；每组第一行 $n$；接下来 $n$ 行，第 $i$ 行先是 $tot$，
再是 $tot$ 个编号，按喜爱度从大到小给出 $i$ 号动漫的续集。输出每组一行答案。

题面样例：$n = 5$，$1$ 的孩子是 $(4, 3, 2)$，$3$ 的孩子是 $(5)$，其余为叶子，答案为 $2$。
两个合法排列分别是

$$1,4,3,5,2 \qquad \text{与} \qquad 1,4,3,2,5 .$$

（$1$ 必须最先（它是全树祖先）；然后是 $4, 3$ 的先后固定；$5$ 是 $3$ 的孩子、必须紧跟 $3$
之后；而 $2$ 与 $5$ 之间没有任何约束，可前可后——答案恰好是 $2$。）

## 正解

### 思路

**朴素做法。** 把树边和兄弟链边当成一般 DAG，枚举全排列逐一检验，$O(n! \cdot n)$；
或状压 DP，$O(2^n n)$。前者只能跑 $n \le 10$，后者只能跑 $n \le 20$。

**瓶颈在哪？** 状压爆炸的根源是「必须把已排好的节点集合原样记住」。但本题的约束是
分层给出的：祖先限制只关心「谁是谁的祖先」，兄弟限制只关心「同一父亲的孩子们谁先谁后」。
约束既然能按子树分解，就应当按子树聚合——这正是树形 DP 的形状。

设

- $sz_u$ = 子树 $T(u)$ 的节点数；
- $f_u$ = 只考虑子树 $T(u)$ 内部的节点，满足「祖先在前」与「兄弟按序」的排列个数。

**关键观察一：每个子树内部自成序列，且子树根必在首位。** 由祖先限制，$u$ 必须排在
$T(u)$ 的所有节点之前，所以 $T(u)$ 的合法排列一定长成 $(u, \sigma)$，其中 $\sigma$ 是
$T(u) \setminus \{u\}$ 的合法排列。

**关键观察二：不同子树之间的约束只有「根谁先谁后」。** 兄弟限制 $c_i \prec c_{i+1}$
只约束这两个根节点的先后，**没有**约束 $T(c_i)$ 中 $c_i$ 的子孙与 $T(c_{i+1})$ 中元素的先后。
把若干子树的合法序列拼成一段长序列时，唯一新增的约束就是「各子树首元素的出现先后」。

于是可以**倒序合并**。设已经合并好 $c_{i+1}, \dots, c_k$，得到一段长度 $R = \sum_{j>i} sz_{c_j}$
的合法序列，方案数 $W$。现在要并入 $T(c_i)$：

- 由观察二，$c_i$ 与右侧所有元素无约束；由观察一，$c_i$ 在 $T(c_i)$ 中最靠前；
  又由兄弟限制 $c_i \prec c_{i+1}$，$c_{i+1}$ 是右侧那段的首元素——三者合起来，
  在 $T(c_i) \cup \bigcup_{j>i} T(c_j)$ 这段并集中，**$c_i$ 必定占据第一位**；
- 而 $c_i$ 一旦占了首位，剩下的 $sz_{c_i} - 1$ 个 $T(c_i)$ 内节点与右侧 $R$ 个节点之间
  **再无任何交叉约束**，可以任意交错插空：先在 $R + sz_{c_i} - 1$ 个位置里挑 $R$ 个位置
  放右侧那段（放法即 $\binom{R + sz_{c_i} - 1}{R}$），然后两段各自按合法顺序填入。

所以合并一步就是

$$W \leftarrow W \cdot f_{c_i} \cdot \binom{R + sz_{c_i} - 1}{R}, \qquad R \leftarrow R + sz_{c_i},$$

从 $i = k$ 起（此时 $W = f_{c_k}$、$R = sz_{c_k}$）倒序推到 $i = 1$，最后令
$f_u = W$、$sz_u = R + 1$（把 $u$ 自己算进子树大小）。叶子节点 $f_u = 1$、$sz_u = 1$。

**换一种写法**：记 $N_i = \sum_{j \ge i} sz_{c_j}$，上面的组合数可改写为
$\binom{N_i - 1}{sz_{c_i} - 1}$，于是

$$f_u = \prod_{i=1}^{k} f_{c_i} \cdot \binom{N_i - 1}{sz_{c_i} - 1}.$$

**为什么必须倒序？** 因为「$c_i$ 占首位」这个结论只在集合是
$T(c_i) \cup T(c_{i+1}) \cup \cdots \cup T(c_k)$ 时成立。若正序合并，右侧就不存在
「$c_{i+1}$ 已经在段内」这个事实，组合数会算多。手算验证样例：$f_5 = 1$、$sz_5 = 1$；
节点 $3$ 只有孩子 $5$，$N_1 = 1$，$\binom{0}{0} = 1$，故 $f_3 = 1$、$sz_3 = 2$；
节点 $1$ 的孩子依次为 $(4,3,2)$，从右往左：$R = sz_2 = 1$，$W = f_2 = 1$；
并入 $3$：$\binom{1 + 2 - 1}{1} = \binom{2}{1} = 2$，$W = 2$、$R = 3$；
并入 $4$：$\binom{3 + 1 - 1}{3} = \binom{3}{3} = 1$，$W = 2$。故 $f_1 = 2$，与样例一致。

**实现细节。**

- 自底向上：用**迭代**后序遍历（$n = 1000$ 的链会爆递归栈），得到一个「孩子必在父亲之前」
  的序列，正序扫描即为自底向上。
- 组合数：$10007$ 是质数且 $n \le 1000 < 10007$，阶乘预处理 + 费马小定理求逆元即可，
  不需要 Lucas，分母恒不为 $0 \pmod{10007}$。
- 多组数据记得清空每个点的孩子表（本实现用 `vector` 的 `clear()` 逐点重置）。
- $n = 1$ 时没有孩子，$f_1 = 1$，DP 自动兼容。

### 复杂度

- 时间：阶乘预处理 $O(\max n)$；每组数据后序遍历 $O(n)$，每次合并 $O(1)$，合并总数
  $\sum_u \deg(u) = n - 1$，故每组 $O(n)$，总计 $O(T \cdot n)$。$n = 1000$ 时运算量在
  $10^6$ 量级，$1000$ ms 时限绰绰有余。
- 空间：孩子表、`f`、`sz`、阶乘数组各 $O(n)$，总计 $O(n)$。

## 总结

这道题的关键不是「树形 DP」这四个字，而是**看清跨子树之间到底还剩什么约束**：
祖先限制被「子树根必在首位」吸收掉，兄弟限制在并集里退化成「$c_i$ 占首位」，
于是剩下的部分完全自由、只剩组合插空。凡是「约束能按子树分层、层间只剩根的先后」的
拓扑序计数题，都可以照这个套路：**后序遍历自底向上，倒序合并兄弟子树，组合数统计插空**。

反过来，如果兄弟限制被换成「$c_i$ 的整棵子树都排在 $c_{i+1}$ 的整棵子树之前」，
那么上面的插空就不再自由、组合数会退化成 $1$，这也说明了「约束究竟作用在哪些节点上」
是这类题唯一需要盯紧的地方。

## 形式化题目

给定 $n$ 个只含小写字母的字符串的集合 $S$，以及轮数 $k$。游戏进行 $k$ 轮，每轮的过程相同：

- 从空串开始，两人轮流在末尾追加一个字符；
- 追加后得到的串必须是 $S$ 中某个串的**前缀**（空串本身也算合法前缀）；
- 轮到自己却无法追加的人输掉本轮。

第 1 轮由「第一轮先手」开始，此后**每一轮由上一轮的输家先手**；第 $k$ 轮的胜者赢得整个游戏。双方都最优决策，问第一轮先手能否获胜。多组数据读到文件结尾，每组输出一行 `HY wins!` 或 `Teacher wins!`。

规模：$1 \leqslant n \leqslant 10^5$，$1 \leqslant k \leqslant 10^9$，每组字符串长度之和不超过 $10^5$，数据组数不超过 $10$。

## 正解

### 思路

**第一步：把加字符的过程换成在 Trie 上走。**

所有可以出现的串（$S$ 中每个串的所有前缀）恰好就是 $S$ 的 Trie 里的节点：根是空串，从节点 $u$ 沿字符 $c$ 走到 $v$，等价于在串尾追加字符 $c$。于是单轮游戏就是：从根出发，两人轮流沿一条树边往下走，**走到叶子的人赢**（因为对手下一步无路可走）。这是一张有向无环图，每轮游戏必然在有限步内结束，不存在平局。

**第二步：注意到多轮游戏的接力规则会翻转「赢」的价值。**

$k$ 轮的连接方式是「输者下一轮先手」。也就是说**赢下第 $r$ 轮是要付出代价的**：第 $r+1$ 轮你就变成了后手。反过来说，「第 1 轮的先手」这个身份是可以一直握在手里的——只要他在前 $k-1$ 轮里**故意输**。于是单轮里「想赢」和「想输」这两种能力都要算，不能只算传统的胜负态。

对 Trie 上任意节点 $u$（轮到在 $u$ 处行棋的人视角），定义两个独立的布尔量：

- $\mathrm{win}(u)$：从 $u$ 出发的这个人，是否存在一种策略，无论对手怎么应对都能**强行赢下本轮**；
- $\mathrm{lose}(u)$：从 $u$ 出发的这个人，是否存在一种策略，无论对手怎么应对都能**强行输掉本轮**。

$\mathrm{lose}$ 的定义听起来别扭，但它是完全对称的：它就是「把同一个游戏当成我的目标」求必胜，只是把"我赢"换成"我输"。

**第三步：树形 DP 求这两个量。**

设 $u$ 的子节点为 $v_1 \dots v_m$。

- **叶子**（$m = 0$）：轮到的人无路可走，本轮已经输定了，因此 $\mathrm{win}(u) = \text{false}$，$\mathrm{lose}(u) = \text{true}$。

  这里最容易踩坑：「叶子」是 Trie 上**没有子节点**的点，不是某个串的结尾点。比如 $S = \{\texttt{a}, \texttt{ab}\}$，节点 `a` 虽然是一个串的结尾，但它在 Trie 上还有儿子，游戏完全可以继续加 `b`，所以它不是叶子。
- **内部节点**：走一步到 $v$ 后，轮到对手在 $v$ 处行棋。要强行赢，就必须存在一个子节点 $v$ 让**对手无法强行赢**；要强行输，就必须存在一个子节点 $v$ 让**对手无法强行输**（对手无法强输，意味着他被迫赢，于是输的就是我）：

$$\mathrm{win}(u) = \bigvee_{i=1}^{m} \neg \mathrm{win}(v_i), \qquad \mathrm{lose}(u) = \bigvee_{i=1}^{m} \neg \mathrm{lose}(v_i).$$

两个转移互相独立，各自只用到子节点的同名量，所以一次自底向上的遍历就能同时算出。

**第四步：把根节点的两个量翻译成 $k$ 轮的结果。**

记 $W = \mathrm{win}(\text{root})$，$L = \mathrm{lose}(\text{root})$。注意 Trie 每轮都一样，所以「身为先手时的 $W, L$」对所有轮都适用。

| 情况 | 第 1 轮先手的结局 |
| --- | --- |
| $W = \text{false}$ | 无论怎么下，对手都有强赢策略；每轮先手都必输，输者又成为下一轮先手 → 先手连输 $k$ 轮，**必败** |
| $W = \text{true},\; L = \text{true}$ | 前 $k-1$ 轮故意输（把先手权牢牢留在自己手里），第 $k$ 轮改用强赢策略 → **任意 $k$ 必胜** |
| $W = \text{true},\; L = \text{false}$ | 先手只能赢，于是每轮都是先手的一方获胜，胜负严格交替 → $k$ 为奇数**必胜**、$k$ 为偶数**必败** |

用三组样例各验证一支：

- `1 2 / ab`：Trie 是 `根 -a-> A -b-> B`，`B` 是叶子（$\mathrm{win}=0,\mathrm{lose}=1$），于是 `A`（有子 `B`）$\mathrm{win}=1,\mathrm{lose}=0$，根 $\mathrm{win}=0$ —— 命中第一行，输出 `Teacher wins!`。
- `2 3 / a, b`：根有两个子节点，且两个都是叶子，$\mathrm{win}(\text{root}) = \neg 0 = 1$、$\mathrm{lose}(\text{root}) = \neg 1 = 0$ —— 命中第三行，$k=3$ 为奇，输出 `HY wins!`。
- `3 2 / ab, ac, b`：根的 `b` 子节点是叶子，`a` 子节点有 `b`、`c` 两个叶子儿子。于是叶子 $\mathrm{lose}=1$、`a` 处 $\mathrm{win}=\mathrm{lose}=0$ 一算，根处 $\mathrm{win}=1$（走 `b`，对手无路可走）、$\mathrm{lose}=1$（走 `a`，对手在 `a` 上有两个叶子，被迫赢）—— 命中第二行，$k$ 取什么都输出 `HY wins!`，$k=2$ 也不例外。这正是「能输」比「能赢」多出来的那一半信息：先手第一轮可以故意输掉，第二轮再赢回来。

  对照组 `2 2 / a, bcd` 则属第三行：节点 `b` 只有一条单链 `b-c-d`，长度固定，先手想输做不到（$\mathrm{lose}(\text{root})=0$），所以 $k=2$ 时输出 `Teacher wins!`。两条数据只差「有没有一条深度可控的分支」，结论正好相反。

**为什么不需要枚举 $k$ 轮？** 因为单轮结构在每轮完全相同，玩家的能力集只有「能赢 / 不能赢」与「能输 / 不能输」四种组合，而多轮的接力规则只按「谁是先手」翻面。上面三行把 $k$ 轮的走向一次性穷尽了，所以 $k$ 只以奇偶性进入答案，$k \leqslant 10^9$ 也无需模拟。

### 复杂度

建 Trie 为 $O(\sum |S|)$。DP 用先序遍历的逆序代替递归后序（$|S|$ 可达 $10^5$，深链会爆递归栈），每个节点扫 $26$ 条转移，总时间 $O(26 \sum |S|)$；节点数不超过 $\sum |S| + 1$，空间 $O(26 \sum |S|)$，两组数据间清空 Trie 即可复用。$10$ 组数据、每组 $10^5$ 字符时总量约 $10^6$，时限 $1000\text{ ms}$ 下余量很大。

## 总结

本题的教学价值集中在「**注意第二维状态**」。第一眼的直觉是算单轮的胜负态就够，于是很容易只维护 $\mathrm{win}$。但多轮接力规则把「赢一轮」变成了——下一轮让出先手权的代价，因此一个只会赢不会输的玩家会被迫和对手交替获胜，$k$ 的奇偶直接决定生死。补上 $\mathrm{lose}(u) = \bigvee \neg \mathrm{lose}(v)$ 这一维后，三行判定就覆盖了全部情况，$k$ 从 $10^9$ 退化成一次取奇偶。

两个实现细节值得固定下来：其一，叶子的判据是 Trie 上无子节点，而不是「是某个串的结尾」；其二，$10^5$ 级别深链必须用迭代遍历，C++ 的 `dfs` 与 Python 的递归都会爆栈。多组数据时把节点计数和子节点数组整体重置，不要靠局部变量残留。

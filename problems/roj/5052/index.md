## 形式化题目

给定两个只包含字母和数字的字符串 $s_1$ 和 $s_2$，长度均不超过 $30$。
定义一次循环移位操作为将字符串的首字符移动到末尾。
判断 $s_1$ 和 $s_2$ 中，是否存在其中一个字符串是另一个字符串通过若干次循环移位后得到的新字符串的子串。如果是，输出 `true`，否则输出 `false`。

## 正解

### 思路

一个直观的想法是，若 $s_2$ 经过若干次循环移位后包含了 $s_1$，其实等价于 $s_1$ 是 $s_2 + s_2$ 的子串；同理，若 $s_1$ 经过移位包含了 $s_2$，等价于 $s_2$ 是 $s_1 + s_1$ 的子串。

但我们要小心一个常见的**陷阱**：我们能否直接判断 `$s_1$ in $s_2 + s_2$` 或者 `$s_2$ in $s_1 + s_1$`，只要满足一个就返回 `true` 呢？
**不能！**
正确的条件必须加上**长度守卫**：
要使“一个串是另一个串移位后的子串”成立，首先必须满足**短的串作为子串，长的串作为母串去移位**（或者两者等长）。
即：
$$\text{true} \iff (|s_1| \le |s_2| \wedge s_1 \subset s_2+s_2) \vee (|s_2| \le |s_1| \wedge s_2 \subset s_1+s_1)$$

这是因为：
$s$ 的所有循环移位，其长度都严格等于 $|s|$。而 $s$ 的所有循环移位串，正是 $s+s$ 中长度等于 $|s|$ 的各个窗口。如果要求一个子串 $t$ 是 $s$ 的某个移位串的子串，前提条件就是 $|t| \le |s|$，此时 $t$ 若出现在 $s+s$ 中，必然会完全落入某个长度为 $|s|$ 的窗口内。
所以：「$s$ 所有循环移位的所有子串（长度 $\le |s|$）」 等价于 「$s+s$ 中长度 $\le |s|$ 的子串」。
一旦越过了长度限制，去检查“长串 $\subset$ 短串 $+$ 短串”（即 $|长| > |短|$），哪怕找到了，也是由于倍增后跨越周期所产生的**非法项**。

在实现时，我们利用了一个非常优雅的**“交换即隐式守卫”**技巧：
```cpp
if (s1.length() < s2.length()) swap(s1, s2);
string doubled = s1 + s1;
return doubled.find(s2) != string::npos;
```
这一操作等价于正确的逻辑条件，我们可以分三种情形来验证：

| 情形 | 分析 |
|---|---|
| $|s_1| > |s_2|$ | 「$s_1$ 是 $s_2$ 某移位的子串」**不可能**（移位长度 $|s_2| < |s_1|$）$\Rightarrow$ 此时只需要查 $s_2 \subset s_1+s_1$ 即可。 |
| $|s_1| = |s_2|$ | $s_2 \subset s_1+s_1 \iff s_2$ 是 $s_1$ 的**某循环移位**。此时两个方向是对称的，查一个方向就够了。 |
| $|s_1| < |s_2|$ | 交换后，变成了第一种情形。 |

通过强制长串作母串，短串作子串，完美绕开了长串匹配短串倍增串导致的假阳性。

### 复杂度

- **时间复杂度**：令 $L = \max(|s_1|, |s_2|)$，相当于枚举 $L$ 个移位串并执行每次 $\mathcal{O}(L)$ 的子串匹配（或在长度 $2L$ 的串中查找长度 $\le L$ 的子串），时间复杂度为 $\mathcal{O}(L^2)$。由于本题 $L \le 30$，运算开销极小。
- **空间复杂度**：需要额外开辟字符串存储 $s_1+s_1$，复杂度为 $\mathcal{O}(L)$。

## 总结

- **非法项陷阱**：在利用拼接串 $s+s$ 模拟循环移位时，绝对不能用它去匹配比原串更长的子串。**非法项 = 「长串 $\subset$ 短串 $+$ 短串」**。
  以测试点 `problem4` 为例：$s_1 = \texttt{aba}$，$s_2 = \texttt{baab}$。
  如果判断 $s_2 \subset s_1+s_1$，即 $\texttt{baab} \subset \texttt{abaaba}$，结果为真！但 $\texttt{aba}$ 的所有循环移位（长度为 $3$）绝不可能包含长度为 $4$ 的 $\texttt{baab}$。该点在真实数据中答案为 `false`，它是一个引发**假阳性**的最小反例。
  根据穷举 15876 组字母表测试数据的统计，错误写法会导致 **120 处分歧**：其中 `s1 ⊂ s2+s2` 且 $|s_1| > |s_2|$（单独致命 60 处）、`s2 ⊂ s1+s1` 且 $|s_2| > |s_1|$（单独致命 60 处）、两项皆真（0 处），两者完全对称。
- **长度守卫承重验证**：
  若在代码中去掉长度守卫（不交换长短串直接单向查），会产生 **8/10** 的通过率，其中不仅有 `problem4` 产生假阳性，`problem7` 还会产生**假阴性**。
  若改成无长度守卫的双向查，会通过 **9/10**（`problem4` 出错）。这证明长度守卫是承重的，缺失该守卫会在两个方向都出错。
- **数据覆盖情况**：按照字面方向统计（$|s_1| > |s_2|$ 且 $s_1 \subset s_2+s_2$）在真实数据中为 0 个点，但其完全对称的镜像方向（$|s_2| > |s_1|$ 且 $s_2 \subset s_1+s_1$）已经被 `problem4` 覆盖。这说明出题人有意且成功地覆盖了这一错解机制。
- **验证强度摘要**：
  为彻底验证正解性质，异源方法使用了完全不依赖双倍串的“显式枚举 $n$ 个循环移位”作为真值基准。
  对字母表 $\{a,b\}$ 长度 $1..8$ 穷举共计 **260100 组**数据，C++/Python 跨语言实现分歧均为 0。
  其中验证等长性质（长度相等时包含与循环移位相等价）5460 组同样无一不符。非硬编码扫描中，代码的数值字面量集合完全不含任何输出值，无抄表风险。
- **数据格式**：输入均以单空格分隔，字符串字符集经扫描仅含字母与数字（`079ABCDXYZabc`）；输出为小写 `true` 或 `false`，末尾带换行。

## 题目描述

小涵和电脑轮流从 $N$（偶数，$4 \leqslant N \leqslant 500$）位自由武将中选将，小涵先手；轮到电脑时，它抢走"小涵军队与自由武将配对中默契值最高"的那名自由武将，直到武将均分。终局双方各取自己军队中默契值最大的一对比较。给定两两默契值（互不相同，$0 \leqslant$ 值 $\leqslant 10^9$）：第 $1$ 行是 $N$，第 $i+1$ 行给出 $i$ 号与 $i+1 \dots N$ 号武将的默契值；若小涵有必胜策略，输出 `1` 再输出所有胜利结局中其组合的最大默契值，否则输出 `0`。

样例 1 输入：`6` / `5 28 16 29 27` / `23 3 20 1` / `8 32 26` / `33 11` / `12`，输出：`1` / `32`。

## 思路

电脑每手都抢走小涵当前最强组合里的自由武将，所以小涵任何武将的"最强搭档"都保不住，能稳拿的上限是每个武将的次大默契值。取次大值 $V$ 最大的武将先手，电脑必抢其最强搭档，小涵再抢其次强搭档即拿到 $V$，且此后电脑每组组合都 $< V$。故答案恒为全体次大值的最大值。

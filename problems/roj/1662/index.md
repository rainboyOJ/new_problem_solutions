## 形式化题目

用 $N$ 个 $1 \times 1$ 尺的空心方钢拼出高度、宽度各 $N$ 尺的阶梯（每阶高宽均为 1 尺），钢材可任意切割拼接但空心面不能朝上。求拼法总数。

## 正解

### 思路

#### 1. 建模为阶梯切割

「钢材空心面不能向上」等价于把一个 $n$ 阶阶梯（轮廓为 $1+2+\cdots+n$ 的直角三角形）用矩形拼满，且每个矩形内部不能有"凹形"缺口。经典结论：这等价于对阶梯做**递归二分割**，方案数满足卡特兰递推。

#### 2. 卡特兰递推的来源

考虑包含阶梯最右下角那个 $1 \times 1$ 方格的矩形。它必然切出一个横跨某一层的"断层"，把剩余部分分成一个同构的小阶梯问题：

$$f(n) = \sum_{k=0}^{n-1} f(k) \cdot f(n-1-k), \quad f(0) = 1$$

这正是**卡特兰数**的标准递推，闭式为：

$$f(n) = \frac{1}{n+1}\binom{2n}{n} = \binom{2n}{n} - \binom{2n}{n-1}$$

#### 3. 精确计算

$n \le 500$ 时 $C_{500}$ 约有 297 位十进制数字，必须用**高精度**。Python 的任意精度整数与 `math.comb`（精确二项式系数）让实现只需一行：

```python
print(comb(2 * n, n) // (n + 1))
```

先整除后输出，`comb` 返回精确值，除法可整除，无浮点误差。

### 复杂度

- **时间复杂度**：`math.comb` 内部为 $O(n)$ 次大整数乘除量级（Karatsuba 之下更快），对 $n = 500$ 瞬时完成。
- **空间复杂度**：$O(n \log n)$ 位，存储 $C_{2n}^n$ 的中间大整数。

## 总结

- 「拼阶梯」问题的组合结构是卡特兰数：按包含角落的矩形切分得到标准递推 $f(n) = \sum f(k)f(n-1-k)$。
- 大数方案数直接交给 Python 任意精度整数 + `math.comb`，无需手写高精度。
- 与 Catalan 圆括号、凸多边形三角剖分、出栈序列同源，识别出卡特兰模型即可秒杀。

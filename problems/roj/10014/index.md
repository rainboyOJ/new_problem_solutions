## 形式化题目

给定一个 $n$ 个点 $m$ 条边的有向无环图（DAG），每个点有权值 $w_i$（可以为负数，图中保证无环）。一条路径的权值定义为路径上所有点的权值之和（允许不经过任何点，空路径权值为 $0$）。

你需要选择一条完整的路径走过。从这条路径中，你能生成若干条“项链”，每条项链对应了路径上的一个连续子段。
Monster 会拿走所有能生成的项链中权值最大的那条。你需要保证拿走的这条项链是**整个图中所有可能形成的项链里权值最大的**。
作为回报，你可以在你选择的完整路径的**剩余部分**（即完整轨迹去掉了 Monster 拿走的那段之后）中，再任意选取一个连续子段作为你自己的项链。

求：Monster 拿走的项链的最大权值，以及你能拿走的项链的最大权值。

数据范围：$1 \le n, m \le 10^5$，$|w_i| \le 10^9$。

## 正解

### 思路

本题需要求解两个值：
1. 全图的最大权路径 $P_{max}$，其权值即为 Monster 的收益。
2. 剔除掉 $P_{max}$ 所包含的点后，我们要寻找在它的“前驱”部分或“后继”部分中的最大连续子段和。

为了最大化我们自己的收益，我们选择的完整路径必须包含 $P_{max}$，并且在这段路径的前面或后面走一条使得局部连续子段和最大的路线。
因此，属于我们的备选项链一定产生在两种情况之中：
- **情况一：在 $P_{max}$ 之后**。从 $P_{max}$ 的终点 `r1` 出发，寻找一条与 $P_{max}$ 不相交的路径。这条备选子段的起点一定是 `r1` 的某个后继节点。
- **情况二：在 $P_{max}$ 之前**。终止于 $P_{max}$ 的起点 `l1`，且与 $P_{max}$ 不相交。这条备选子段的终点一定是 `l1` 的某个前驱节点。

具体算法流程如下：
1. **第一次 DP**：在原图上按照拓扑序进行动态规划（类似 Kadane 算法求最大子段和），求出全图的最大权路径 $P_{max}$，记录其权值 `ans1`、起点 `l1` 和终点 `r1`。若 `ans1 <= 0`，说明不选任何点收益为 0 且最大，直接输出 `0 0` 结束。
2. 通过记录的路径前驱数组 `lw` 向上回溯，将 $P_{max}$ 上的所有节点打上标记 `tag2`。
3. **第二次 DP（求后继）**：找出 `r1` 的所有直接出边对应的点，将其标记为 `tag1`。按照正向拓扑序，对所有打过 `tag1` 的点做最大路径 DP，且在转移时强制绕开 `tag2` 的点。这相当于在后继子图内寻找最大权路径。
4. **第三次 DP（求前驱）**：在反向图上进行拓扑排序。找出原图中所有直接指向 `l1` 的点（即反向图里 `l1` 的出边对应的点），标记为 `tag3`。按照反向拓扑序，对所有打过 `tag3` 的点做最大路径 DP，同样避开 `tag2`。这相当于在前驱子图内寻找最大权路径。
5. 取后继和前驱中得到的最大权值作为你的收益，若最大权值仍为负，则可以取空项链（收益为 $0$）。

### 复杂度

- **时间复杂度**：拓扑排序需要遍历所有的点和边，三次 DP 每次均是沿着边转移，转移次数最多为 $m$。总时间复杂度为 $O(n + m)$。
- **空间复杂度**：需要存储原图和反向图，以及若干用于 DP 与拓扑排序的状态数组。总空间复杂度为 $O(n + m)$。

## 总结

1. **题目语义的抽象**：“剩余的项链”是指在选择一条包含全图最大路径的完整轨迹后，由未被占用的前驱部分和后继部分形成的子段。这里要求对路径组合有深刻的理解。
2. **负数初始值的陷阱**：节点的权值可能低至 $-10^9$，一条包含多个负数节点的有效路径权值可能小到 $-10^{14}$。如果按照常用的 `-1e9` 初始化 DP 数组，在计算时可能会发生状态不更新的错误（原参考实现 `std.cpp` 即存在此隐患）。正解中应当使用充分小的极小值（如 `-1e18`）进行初始化。
3. **验证声明**：本题缺乏线上评测数据。上述推导和实现基于官方 `std.cpp` 进行了严格的逆向重构，修复了初始化越界问题，并确保算法逻辑完全对齐。如需验证，可与 `std.cpp` 进行对拍。

## 形式化题目

有 $n$ 件物品，第 $i$ 件体积 $s_i$、价值 $v_i$，每件最多选一次。对**每一个**容量
$j = 1, 2, \dots, m$ **独立**求解一次 0/1 背包，输出 $m$ 个最大价值。

数据规模：

$$1 \leqslant n \leqslant 10^6,\quad 1 \leqslant m \leqslant 10^5,\quad 1 \leqslant s_i \leqslant 300,\quad 1 \leqslant v_i \leqslant 10^9.$$

记 $dp[j]$ 为容量不超过 $j$ 时能取得的最大价值（$j$ 单调不减的阶梯函数），
答案即 $dp[1], dp[2], \dots, dp[m]$。

朴素做法对每个 $j$ 各跑一遍 0/1 背包，或写成 `for j: for i: dp=...`，
复杂度 $O(nm) = 10^{11}$，**必然超时**。

## 正解

### 思路

**第一步：按体积分组。**

体积只有 $300$ 种，这是本题唯一的突破口。把物品按体积 $s$ 分成 $300$ 组。
同一组内物品体积完全相同，因此"在容量 $j$ 里取 $k$ 个体积 $s$ 的物品"这件事，
取得的最大收益一定是**组内价值最大的那 $k$ 个之和** —— 与取哪几个无关，只与 $k$ 有关。

于是每组内把价值**降序**排序，做前缀和

$$pre[k] = \text{组内价值最大的 } k \text{ 个之和},\qquad pre[0] = 0,$$

（第 $k$ 个的贡献是组内第 $k$ 大价值，$k$ 超过组内物品数时贡献为 $0$，
相当于补上若干体积 $s$、价值 $0$ 的“幽灵物品”。因为 $dp$ 单调不减，
取幽灵物品永远不会更优，所以“常数延拓”是无损的，而且能顺带消掉
“每个容量最多取 $|G_s|$ 个”的窗口约束，实现更简洁。）

> 关键性质：因为价值已降序，增量 $pre[k] - pre[k-1] = $ 组内第 $k$ 大价值单调不增，
> 所以 $pre$ 是**凹函数**（离散意义下增量单调不增）。

**第二步：按组做一次“完全背包式”的整组转移。**

设当前 $dp[j]$ 为已处理过的若干组、容量不超过 $j$ 的最大价值。加入体积 $s$ 这一组：

$$dp'[j] = \max_{0 \leqslant k \leqslant \lfloor j/s \rfloor} \Big( dp[j - k\,s] + pre[k] \Big). \tag{1}$$

这就是一个“同一种物品可重复取、但第 $k$ 个的收益为 $pre[k]-pre[k-1]$”的
**无界完全背包**（幽灵物品贡献为 $0$，不改变最优值，所以不必再设个数上界）。

**第三步：固定余数，拆成独立链。**

(1) 式里 $j$ 与 $j - ks$ 模 $s$ 同余。对每个余数 $r \in [0, s)$，令

$$j = r + i\,s \ (0 \leqslant i \leqslant L_r),\qquad f[i] = dp[r + i\,s],\qquad g[i] = dp'[r + i\,s],$$

则 (1) 变成 $s$ 条**互不干扰**的一维链（这是标准的“同类同余”卷积）：

$$g[i] = \max_{0 \leqslant t \leqslant i} \Big( f[t] + pre[i - t] \Big). \tag{2}$$

下标 $t$ 的语义是"从旧链位置 $t$ 转移而来"，等价于在本组取了 $i - t$ 个物品。

**第四步：决策单调性 + 分治优化。**

(2) 式对固定 $i$ 求 argmax。设两个决策 $t_1 < t_2$，若在 $i$ 处 $t_2$ 比 $t_1$ 优：

$$f[t_2] + pre[i - t_2] \geqslant f[t_1] + pre[i - t_1].$$

$i$ 增大 $1$ 时，左边增量是 $pre[i+1-t_2]-pre[i-t_2]$，
右边增量是 $pre[i+1-t_1]-pre[i-t_1]$；由 $pre$ 凹（增量单调不增）且
$i+1-t_2 < i+1-t_1$，左增量 $\geqslant$ 右增量，即**优势不会反转**。

所以 argmax $opt(i)$ 关于 $i$ **单调不减**。这正是分治优化的适用条件：

```
solve(l, r, optl, optr):        # 求解 g[l..r]，已知 opt(i) ∈ [optl, optr]
    mid = (l+r)/2
    在 [optl, min(optr, mid)] 内暴力找 opt(mid) 并填 g[mid]
    solve(l,   mid-1, optl,  opt(mid))
    solve(mid+1, r,    opt(mid), optr)
```

每条链长度 $L_r \approx m/s$，代价 $O(L_r \log L_r)$（每层均摊 $O(L_r)$）。
对固定的 $s$，所有链合起来 $O(m \log(m/s))$。

**总复杂度：**

$$O\Big(n + m \log m + \sum_{s=1}^{300} m \log \frac{m}{s}\Big) \approx 3 \times 10^8,$$

在 7000 ms 限时下 C++ 可以过（$s$ 越大链越短，$\sum_s \log(m/s)$ 远小于 $300 \log m$）。

**细节：** 体积 $s > m$ 的物品任何容量都装不下，直接丢弃；答案用 $dp[1..m]$，
$dp$ 全程保持单调（初始全 $0$，(2) 式的转移保序性由 $pre$ 单调保证）。

### 复杂度

- 时间：$O\big(n + m\log m + \sum_{s=1}^{300} m \log(m/s)\big)$，量级约 $3\times10^8$ 次简单运算。
- 空间：$O(n + m)$（分组存储 + 若干长度 $m$ 的全局数组），约十几 MB。

## 总结

1. **先找"种类数少"的特征。** 本题 $n$ 高达 $10^6$ 但 $s \leqslant 300$，把物品按体积
   分组后，"取几个"取代了"取哪些"，问题立刻从物品维度降到体积维度。
2. **单调 + 前缀和 = 可拆链。** 同余类分组是背包类 DP 的常用解耦手段，
   把二维 $dp[j]$ 摊平成 $300$ 条一维链。
3. **凹性 ⇒ 决策单调。** 降序排序后的前缀和天然凹，任意两个决策点的优劣只反转一次，
   于是分治优化 / 单调队列都可以用。这里分治写法最短，且常数小。
4. 反过来看，如果 $s$ 没有上界，这题就是 $O(nm) = 10^{11}$ 的不可做题；
   **数据的特殊限制往往就是算法的入口**。

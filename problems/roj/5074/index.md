## 形式化题目

给定三角形的三条边长 $a, b, c$（输入均为 $1$ 位小数的正浮点数）。
要求输出该三角形的面积，结果保留 $3$ 位小数。

## 正解

### 思路

根据题面提示，直接使用海伦公式即可求出三角形面积：
$$p = \frac{a+b+c}{2}$$
$$S = \sqrt{p(p-a)(p-b)(p-c)}$$

**注意**：
必须使用 `double` 类型以保证浮点数计算精度。在实践中，如果对于大边长三角形使用了单精度 `float` 将会产生致命的小数位丢失。虽然极端情况下（近退化三角形）朴素海伦公式可能会在计算 $p-a$ 时由于大数相减损失一定有效位，但对于本题的数据范围和仅保留 $3$ 位小数的格式要求而言，双精度的裕度完全足够，无需使用复杂的稳定版公式。为防止亚正规下溢出或不可控输入导致的 $S^2 \le 0.0$ 从而引发 `NaN`，实现中可添加防卫行将 $S^2 \le 0.0$ 的情形强制归零。

### 复杂度

- **时间复杂度**：计算公式仅包含常数次算术运算与开方，时间复杂度为 $\mathcal{O}(1)$。
- **空间复杂度**：只需常数个浮点变量，空间复杂度为 $\mathcal{O}(1)$。

## 总结

- **算法**：海伦公式 $s = \sqrt{p(p-a)(p-b)(p-c)}$，$p = \frac{a+b+c}{2}$，输出 `%.3f`。$\mathcal{O}(1)$。

- **防御行是离数据承重**：在实际 $10$ 组非退化三角形数据上，`s2` 全部 $> 0$，防御行 `if (!(s2 > 0.0)) s2 = 0.0;` 未被触发一次。如果去掉该防御行进行测试，真实数据有 $0/10$ 失败，说明它对通过本题的测试点并不必要，但它是工程上严密的离数据承重保护。
  触发条件及最小复现如下表。注意，对于真正 $s^2 == +0.0$ 的退化三角形，该防御行**并无作用**（因为 $\sqrt{+0.0}$ 本就会正确输出 `0.000`）；它纯粹防的是 `-0.0`、负数以及 `NaN`，这才是“防御行到底防什么”的精确刻画。
  | 类别 | 最小复现 | 无防御 | 有防御 |
  |---|---|---|---|
  | `s2 = -0.0`（亚正规下溢出） | `echo '1e-320 1e-320 3e-320'` | **`-0.000`** | `0.000` |
  | `s2 < 0`（不可能三角形） | `echo '1 2 4'` | **`nan`** | `0.000` |
  | 近平退化非法 | `echo '1 1 2.0000000001'` | **`nan`** | `0.000` |
  | NaN 输入 | `echo 'nan 1 1'` | **`nan`** | `0.000` |
  | **`s2 == +0.0`（退化）** | `echo '1 2 3'` | `0.000` | `0.000` |

- **`T23` 乘法结合律只动 ulp**：如果改变连乘顺序（如 `(p*(p-a))*((p-b)*(p-c))`），在真实 $10$ 个点上与原始实现 $0$ 分歧。在 $0.1$ 精度网格产生的 $7,658,038$ 组数据中，绝对误差 $> 1\text{e-}12$ 的有 $16.8\%$，但 $> 1\text{e-}6$ 的有 $0$ 组。即结合律的影响仅在 ulp 级别，不动 `%.3f` 格式化。
- **`T24` FMA 指令收缩**：确实没有发生。由于表达式为纯连乘与简单的 `a+b+c`（没有 `a*b+c` 的相邻模式），在各个优化级别下也未生成 `fma`。对照组中包含 `x*y+1.0` 的探针能在 `-O2` 触发 `fmadd`，说明探针有分辨力。
- **反事实表与 `V8` 稳定式不可区分**：
  在 $10$ 组真实数据中，朴素式与各种等效的海伦稳定版公式（如 Kahan 版等）**输出相同**（差距 $< 1 \text{ ulp}$），数据无法也无需裁定使用哪种公式；此处实现与参考标程保持一致（朴素式）。
  | 破坏方式 | 失败点 | 说明 |
  |---|---|---|
  | `p=(a+b+c)/2`（整数除法字面量） | **0/10** | `a,b,c` 是 `double`，`2` 被提升为 `2.0`，**不截断** |
  | 去掉防御行 | **0/10** | ⇒ **离数据承重**（触发条件见上述表格）|
  | `%.3f` → `%.2f` | **10/10** | 格式精度承重 |
  | `%.3f` → `%.4f` | **10/10** | 同上 |
  | `sqrt(s2)` → `s2` | **10/10** | 开方承重 |
  | `(p-a)` → `(a-p)`（符号反）| **10/10** | 全部输出 `0.000`（`s2` 变负被防御归零）|
  | 乘法结合律改写 | **0/10** | 结合律只动 ulp 级，不动 `%.3f` 格式化 |
  | 稳定式 / `1/4√(...)` / `long double` | **0/10** | 朴素式与稳定式在 10 点上不可区分 |
- **结构不变量 (`V2`, `V4`)**：`main.cpp` 的所有硬编码集 $\{0, 0.0, 2.0, 3\}$ 与全部答案值交集为空。输入文件中每次恰包含 $3$ 个正浮点 token、均独占 $1$ 行，且**小数位固定为 $1$ 位**；三角形不等式 $10/10$ 严格成立，不存在退化或不可能的三角形。
- **`T9` 语言细节探针五项**：
  - **类型转换**：公式中除数 `2` 隐式提升为双精度浮点数 `2.0`。
  - **溢出**：本题数据范围未触及双精度边界，无溢出风险。
  - **整除取模**：因 `a,b,c` 均为浮点类型，`(a+b+c)/2` 为实数除法，不发生整数截断。
  - **浮点格式化**：`cout << fixed << setprecision(3)` 与 Python `f"{v:.3f}"` 的底层进位舍入策略（如 half-even）在跨语言上表现一致；且此处唯一的敏感点在于距 `.5` 边界的裕度（而本题因为数据良态，裕度极大，无任何歧义）。
  - **排序字典序**：本题不涉及。

## 题目描述

珠心算老师随机生成一个由 $n$ 个互不相同正整数组成的集合，问其中有多少个数恰好等于集合中另外两个（**不同的**）数之和。

**输入格式**：第一行一个整数 $n$；第二行 $n$ 个正整数，用空格隔开。**输出格式**：一个整数，表示答案。

**样例输入**：`4` 与 `1 2 3 4`；**样例输出**：`2`（由 $1+2=3$、$1+3=4$；两个加数必须不同，故 $2+2=4$ 不算）。

**数据范围**：$3 \le n \le 100$，每个正整数不超过 $10000$。

## 思路

枚举所有两个不同数的组合（每个数只与它后面的数配对）把和收进一个集合，答案就是原集合与和集合的交集大小。注意统计的是"数"的个数而不是等式的个数，多个数对凑出同一个和只算一次。

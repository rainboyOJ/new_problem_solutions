## 形式化题目

给定两个仅由大写英文字母组成的字符串 $S_1$ 与 $S_2$（长度满足 $1 \leqslant |S_1|, |S_2| \leqslant 6$）。

定义字符到整数的映射：字母表中第 $k$ 个字母对应整数 $k$（即 $\text{'A'} \to 1, \dots, \text{'Z'} \to 26$）。

定义字符串 $S$ 的权值为其所有字符对应数值的乘积对 $47$ 取模的结果：

$$f(S) = \left( \prod_{c \in S} (\text{ord}(c) - \text{ord}(\text{'A'}) + 1) \right) \bmod 47$$

若 $f(S_1) = f(S_2)$，则输出 `GO`；否则输出 `STAY`。

## 正解

### 思路

本题为基础的字符串映射与数值计算模拟题：

1. **字符映射**：对于大写字母 $c$，其对应的数值可以通过 ASCII 码差值计算，即 $\text{ord}(c) - \text{ord}(\text{'A'}) + 1$。
2. **累乘与取模**：遍历字符串中的每个字符，将对应数值依次累乘，并对模数 $47$ 取模。因为字符串长度至多为 $6$，$26^6 = 308\,915\,776$，即使计算完所有乘积再取模也不会产生大数计算开销；在 Python 中，直接使用表达式连乘后取模即可。
3. **结果判定**：分别计算两个名字所得结果，如果相等输出 `GO`，否则输出 `STAY`。

```
输入: "CGOZK"
映射: C(3) * G(7) * O(15) * Z(26) * K(11) = 90090
取模: 90090 mod 47 = 38

输入: "VMOU"
映射: V(22) * M(13) * O(15) * U(21) = 90090
取模: 90090 mod 47 = 38

38 == 38 -> 输出 "GO"
```

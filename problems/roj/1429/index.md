## 形式化题目

数轴上有 $n$ 条线段，第 $i$ 条由两个整数 $a_i, b_i$（$0 \leqslant a_i < b_i$）表示端点。选出一个尽量大的子集，使其中任意两条线段都没有重合部分（端点相接不算重合），求能选出的最大条数 $k$。

样例：三条线段 `[0,2]`、`[2,4]`、`[1,3]` 中，`[0,2]` 与 `[2,4]` 端点相接可同时选取，而 `[1,3]` 与两者都相交，所以 $k = 2$。

## 正解

### 思路

最朴素的做法是枚举所有线段子集、检查两两不相交，复杂度是指数级的，$n$ 稍大就不可行。稍微优化可以按左端点排序做 DP + 二分，复杂度 $O(n \log n)$，但这题有更简单的贪心。

**关键观察：一条线段选不选、以及它多长都不重要，重要的是它"堵住了数轴上哪一段"。右端点越小的线段，给后面留的空间越大。** 于是有经典贪心：

1. 把所有线段按右端点从小到大排序；
2. 从左往右扫，维护"已选最后一条线段的右端点" `last_right`；
3. 当前线段的左端点 $\geqslant$ `last_right`（或还没选过任何线段）就选它，更新 `last_right` 为它的右端点；否则跳过。

**为什么按右端点，而不是按左端点或长度？** 用交换论证：设贪心解选的第一条是 $g$（右端点最小），某最优解的第一条是 $o$。因为 $r_g \leqslant r_o$，把最优解里的 $o$ 换成 $g$ 后，$g$ 占用的数轴前缀不超过 $o$，后面的选择全部仍然合法。对贪心解的每个位置重复这个替换，就得到一个与贪心解逐条相同的"最优解"，说明贪心解本身就是最优解。

样例的贪心过程：排序后为 `[0,2], [1,3], [2,4]`。先选 `[0,2]`（`last_right=2`）；`[1,3]` 左端点 $1 < 2$ 跳过；`[2,4]` 左端点 $2 \geqslant 2$，选上。答案 $2$。

### 复杂度

- 时间：排序 $O(n \log n)$，扫描 $O(n)$，总计 $O(n \log n)$，$n \leqslant 10^6$ 时轻松通过。
- 空间：$O(n)$ 存所有线段。

## 总结

这是最经典的**区间调度问题**：按右端点排序 + 一遍贪心。核心直觉是"早结束的先选，给后面留更多空间"，正确性由交换论证保证。同样的套路适用于活动安排、会议 rooms 系列问题；若改成"最少线段覆盖整条数轴"或"选区间使总长最大"，贪心策略就不同，需要 DP 或其他模型。

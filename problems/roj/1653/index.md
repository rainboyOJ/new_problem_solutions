## 形式化题目

给定正整数 $k$ 与 $x$（$k \geqslant 2$），定义：

$$g(x) = x^x \bmod 1000$$

求满足下列条件的不定方程的正整数解 $(a_1, a_2, \ldots, a_k)$ 的组数：

$$a_1 + a_2 + \cdots + a_k = g(x), \quad a_i \in \mathbb{N}^*$$

题目保证 $k \leqslant g(x)$。

## 正解

### 思路

本题分为两个独立的计算步骤：

1. **计算常数项 $g(x)$**：
   目标值为 $g(x) = x^x \bmod 1000$。
   虽然 $x < 2^{31}$ 数值较大，但由于只对模数 $1000$ 取模，可以使用整数快速幂在 $O(\log x)$ 时间内求出 $g(x)$。
   因为 $1000$ 是较小的模数，计算出的 $g(x)$ 满足 $0 \leqslant g(x) < 1000$。题面保证 $k \leqslant g(x)$，因此 $g(x) \geqslant k \geqslant 2$。

2. **隔板法求不定方程正整数解的个数**：
   问题转化为将正整数 $N = g(x)$ 拆分成 $k$ 个正整数之和的方案数：
   $$a_1 + a_2 + \cdots + a_k = N, \quad a_i \geqslant 1$$
   这等价于将 $N$ 个相同的小球排成一列，在它们形成的 $N - 1$ 个间隔中放置 $k - 1$ 块隔板，将小球分成非空的 $k$ 段。
   因此，满足条件的正整数解组数即为组合数：
   $$\binom{N - 1}{k - 1} = \binom{g(x) - 1}{k - 1}$$

3. **数值范围与精度**：
   数据范围中 $k \leqslant 100$，$g(x) < 1000$。
   组合数 $\binom{g(x) - 1}{k - 1}$ 的最大值可能达到几百位数字，远超 $64$ 位整型范围，需要高精度计算。
   在 Python 中，内置整型天然支持任意精度大整数，且标准库 `math.comb(n, k)` 提供了高效的组合数实现。

### 图示解析

以 $g(x) = 6, k = 3$（求 $a_1 + a_2 + a_3 = 6$ 的正整数解组数）为例，将 $6$ 个小球排成一行，在 $5$ 个间隔中选 $2$ 个位置插入隔板：

```text
小球序列：  ( 1 )  |  ( 2 )   ( 3 )   ( 4 )  |  ( 5 )   ( 6 )
间隔编号：       1         2       3       4         5
所选间隔：    [选 1]                     [选 4]
对应解组：    a1 = 1           a2 = 3              a3 = 2
```

从 $N - 1 = 5$ 个间隔中任意选取 $k - 1 = 2$ 个隔板，方案总数为 $\binom{5}{2} = 10$。

### 复杂度

- **时间复杂度**：
  - 快速幂计算 $x^x \bmod 1000$ 的时间复杂度为 $O(\log x)$；
  - 计算组合数 $\binom{g(x) - 1}{k - 1}$ 时，$k \leqslant 100$，乘除计算次数不超过 $O(k)$ 次大整数乘除，总运行时间小于 $1\text{ ms}$。
- **空间复杂度**：
  - 仅存储若干中间大整数与输入变量，空间复杂度为 $O(k)$（大整数所占位数），即 $O(1)$ 常数级内存。

## 总结

- 利用快速幂计算较小模数下的幂次取模，将大输入 $x$ 迅速收缩至常数级别 $g(x) < 1000$。
- 方程正整数解组数是典型的**隔板模型**，结论为 $\binom{N - 1}{k - 1}$。
- 组合数结果达到上百位，采用高精度计算（Python 内置大整数天然支持）。

## 形式化题目

给定球半径 $r$（非负实数），按题面指定的圆周率 $\pi = 3.14$ 计算球的体积

$$V = \frac{4}{3} \cdot \pi \cdot r^3$$

并将 $V$ 保留小数点后 2 位输出（第 3 位四舍五入，不足补 0）。

样例：输入 `4`，输出 `267.95`。核算：$V = \frac{4}{3} \times 3.14 \times 4^3 = \frac{4}{3} \times 3.14 \times 64 = 267.9466\ldots$，第 3 位小数为 6，进位后得 `267.95`。

## 正解

### 思路

题目给的是闭式公式，代入求值就是全部工作，没有可以单独教学的暴力层或优化层，因此按直接正解型组织。全部难点集中在两处语义：

1. **π 必须取 3.14，不能用 `math.pi`**。题面明确"这里取 π=3.14"，两者相差在小数第 3 位，舍入后常常差 0.01（样例 $r=4$：用 3.14 得 `267.95`，用 `math.pi` 得 `268.08`），直接 Wrong Answer。所以把 `PI = 3.14` 写成模块级常量并注释来源。
2. **格式化交给 `:.2f`，不要 `round` 后再打印**。`f"{V:.2f}"` 把 double 的精确十进制值四舍五入到 2 位小数并补零，与 C 的 `printf("%.2f", V)` 同语义；而 `round(V, 2)` 返回的 float 会省略末尾的 0——真实数据 `problem3.out` 恰好是 `90774.90`，用 `round` 会打成 `90774.9`，逐字符比对必错。

另外注意 `4 / 3` 必须用真除法：Python 3 的 `/` 直接得到 double，`4 // 3 = 1` 则会让体积少算 25%。

## 总结

这是一道"公式直译 + 格式化"的入门题：`PI = 3.14` 保证与题面精度语义一致，`4 / 3` 的真除法保证双精度求值，`:.2f` 一次性解决四舍五入、补零两件事并与 C `printf` 舍入行为对齐。最典型的两个坑是顺手换成 `math.pi` 和先 `round` 再打印丢尾随 0。本题计算量为 $O(1)$，实测 10 组真实数据全部通过，每例约 0.016 s、峰值 14.5 MB，相对 1000 ms / 128 MB 的限制毫无压力。

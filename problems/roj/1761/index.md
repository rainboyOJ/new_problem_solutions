## 形式化题目

给定无向无权简单图 $G=(V,E)$（$|V| = N$，$|E| = M$，无重边无自环），并给出 $G$ 的一棵生成树 $T$。
一个**割**是一组边，删去它之后图不连通；等价地，割由一个非平凡二分 $(A, B)$（$A \cup B = V$，
$A, B \neq \varnothing$）给出，割边集就是两端分居 $A$、$B$ 的边集。求

$$
\min \bigl\{\, |\delta(A, B)| \;:\; A \cup B = V,\ A, B \neq \varnothing,\ |\delta(A,B) \cap T| = 1 \,\bigr\},
$$

即**在"恰好包含 $T$ 中一条边"的割里取边数最小者**。多组数据：第一行组数 $T_0 \leqslant 5$；
每组第一行 $N, M$（$N \leqslant 20000$，$M \leqslant 200000$），随后 $N-1$ 行是 $T$ 的树边，
再随后 $M-N+1$ 行是 $G$ 中不在 $T$ 中的边。每组输出一行答案。

## 正解

### 思路

**第一步：割的形状被"恰好一条树边"锁死了。** $T$ 是生成树，任取非平凡二分 $(A,B)$，
$T$ 中必然有边跨过它（否则 $T$ 会落在 $A$ 或 $B$ 内部，而不可能连通全部 $N$ 个点）。
所以 $\delta(A,B) \cap T \neq \varnothing$。现在要求它恰好只含一条边 $e$：删掉 $e$ 后 $T$ 断成
两个连通块 $V_1, V_2$，它们之间的树边只有 $e$；既然 $e$ 是唯一跨过的树边，
$V_1$、$V_2$ 各自必须整体落在 $A$ 或 $B$ 里（块内若有边跨过割，那条边也是树边，矛盾）。
于是

$$A = V_1,\; B = V_2 \quad \text{或} \quad A = V_2,\; B = V_1 .$$

**结论：一个合法的割与一条树边 $e$ 一一对应**，它的边集是

$$\delta(e) \;=\; \{e\} \;\cup\; \{\, f \in E \setminus T \;:\; f \text{ 的两端分居 } T-e \text{ 的两个连通块} \,\}.$$

（$T$ 中的其他边都在某个块内部，跨不过去。）记 $c(e)$ 为"跨过 $T-e$ 两个块的非树边条数"，
则这个割的大小是 $1 + c(e)$，答案就是

$$\boxed{\,1 + \min_{e \in T} c(e)\,}$$

**第二步：$c(e)$ 的几何含义。** $G$ 中每条非树边 $f=(u,v)$ 与 $T$ 上的 $u\!-\!v$ 路径合成一个
基本回路。$f$ 跨过 $T-e$ 的两个块 $\iff$ 路径 $u\!-\!v$ 经过树边 $e$。所以

$$c(e) = \#\{\, \text{基本回路经过 } e \text{ 的非树边} \,\},$$

也就是"覆盖 $e$ 的非树边条数"。答案是 $1$ 加上**覆盖数最小的那条树边的覆盖数**：
某条树边一条非树边都没覆盖（它是 $G$ 的桥），答案就是 $1$。

**第三步：一次树上差分求出所有 $c(e)$。** 以 $1$ 为根把 $T$ 定根，把树边 $(\mathrm{par}[x], x)$
的值记在节点 $x$ 上。对每条非树边 $(u,v)$，要给 $u\!-\!v$ 路径上的所有树边 $+1$：

$$\mathrm{diff}[u] \mathrel{+}= 1, \qquad \mathrm{diff}[v] \mathrel{+}= 1, \qquad \mathrm{diff}[\mathrm{lca}(u,v)] \mathrel{-}= 2 .$$

然后把 $\mathrm{diff}$ 按**逆 BFS 序**自底向上做子树和：处理完所有孩子之后，
节点 $x$ 上的值就是树边 $(\mathrm{par}[x], x)$ 的覆盖数 $c$。为什么正确？子树和
$\mathrm{diff}[x]$ 等于"子树内非树边端点个数"减去 $2$ 倍的"两端都在子树内的非树边条数"，
正是**恰好一个端点在子树内**的非树边条数，也就是跨过这条树边的非树边条数。

用样例验一遍（$N=4$，$T$ 是链 $1-2-3-4$，非树边 $1\!-\!3$、$1\!-\!4$）：

| 树边 $e$ | $T-e$ 的两块 | 跨过的非树边 | $c(e)$ | 割的大小 |
| :-: | :-: | :-: | :-: | :-: |
| $1-2$ | $\{1\}\mid\{2,3,4\}$ | $1\!-\!3$、$1\!-\!4$ | 2 | 3 |
| $2-3$ | $\{1,2\}\mid\{3,4\}$ | $1\!-\!3$、$1\!-\!4$ | 2 | 3 |
| $3-4$ | $\{1,2,3\}\mid\{4\}$ | $1\!-\!4$ | 1 | **2** |

最小是 $3-4$ 对应的割 $\{3\!-\!4,\;1\!-\!4\}$，大小 $2$，与样例输出一致。

**LCA 怎么求。** $N \leqslant 20000$、$M \leqslant 200000$、$T_0 \leqslant 5$，合计 $10^6$ 条非树边，
需要 $10^6$ 次 LCA。$O(\log N)$ 的倍增法总共约 $3 \times 10^7$ 次操作，C++ 里毫无压力
（实测单点最大 $20$ ms、$5$ 组顶格的 `problem10` 约 $70$ ms），Python 里则偏慢，
所以 `main.py` 换成**欧拉序 + 稀疏表**的
$O(1)$ LCA：欧拉序长 $2N-1$，$u,v$ 的 LCA 就是 $\mathrm{first}[u] \dots \mathrm{first}[v]$
区间里深度最小的节点，稀疏表把区间取最小压成常数次操作。两种实现复杂度同阶
（$O(N \log N + M)$），Python 只是把每次询问的常数再压小一截。

**实现要点。**

- 建树用迭代 BFS / 迭代 DFS，链状树（$N=20000$ 深链是数据里的最坏形状）不会爆栈。
- 多组数据、每组上界 $N=20000$、$M=200000$，输入量到 $2 \times 10^6$ 个数，
  C++ 用 `fread` 快读。
- 数组每次进新一组都要重置（`head` 置 `-1`、`diffCnt` 清 $0$）。
- 退化输入 $N=1$：$T$ 没有边，不存在"恰好含一条 $T$ 边"的割，两种实现都输出 $0$
  并在代码里注明。题面约束 $M \geqslant N-1$ 且无自环，所以这个分支在真实数据里不可达。

### 复杂度

- **时间**：每组 $O(N \log N + M)$。C++ 版是 $O((N+M)\log N)$（每条非树边一次 $O(\log N)$ 的 LCA）；
  Python 版建稀疏表 $O(N \log N)$、每条非树边 $O(1)$，同阶。按题面顶格数据
  $T_0=5$、$N=20000$、$M=200000$（合计 $10^6$ 条边），C++ 版实测 `problem10` 约 $70$ ms，
  远低于 $4000$ ms 限时；Python 版同一测试点约 $0.4$ s（本题 Python 无需担心 TLE）。
- **空间**：C++ 版 $O(N \log N + N)$（倍增表 $16 \times 20005$ 个 `int`，约 $1.3$ MB）；
  Python 版稀疏表约 $N \log N$ 个整数引用。两者都在 $256$ MB 之内。

## 总结

- **先给"合法割"定性，再谈算法**：本题最容易卡住的地方不是数据结构，而是"恰好含一条树边"
  这个条件的含义。想清楚"跨过割的树边唯一 $\Rightarrow$ 割的两侧就是 $T-e$ 的两个连通块"，
  问题立刻退化成"给每条树边数一数有多少非树边跨过它"。
- **把"跨过割"翻译成"基本回路经过"**：非树边 $f$ 跨过 $T-e$ 当且仅当 $f$ 的基本回路含 $e$，
  于是一条边的覆盖数就有了两种等价视角，差分统计的合法性也来自这里。
- **树上差分是"多条路径 $+1$"的标准解法**：端点 $+1$、LCA $-2$、子树和还原，
  这三步合起来是 $O(N+M)$ 的（不含 LCA 的 $\log$），比"枚举每条树边再扫一遍非树边"的
  $O(NM)$ 快了一个量级。
- **答案下界是 $1$**：若某条树边是 $G$ 的桥，$c(e)=0$，最小割就是这条桥本身。
- **数据与题源说明**：本题素材目录里带有数据生成脚本 `data.py`，说明 `data/` 的 $10$ 个测试点
  是**自造**的（按题面上限分层生成：边界 $N=2$ → 小规模 → 顶格 $N=20000,M=200000$ →
  多组顶格 $T_0=5$，树形状覆盖链 / 星 / 随机并含随机重标号）；题面本身是网络重建版本，
  与官方原题的措辞、数据强度可能不完全一致。目录里的 `std.cpp` 是自研标程（其头注释也说明
  未检索到公开题解），它与本题解互相印证：`data/*.out` 就是 `std.cpp` 的产物，
  本题解对 $10$ 个测试点逐点比对 $10/10$ 一致；另外我还写了一份**枚举全部二分**的
  暴力（不依赖本题结论）对 $1200$ 组 $N \leqslant 8$ 的随机小数据验证，同样全部一致。

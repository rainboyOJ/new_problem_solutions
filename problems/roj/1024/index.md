## 形式化题目

给定一个单精度浮点数 $x$，输出把 $x$ 四舍五入保留 3 位小数后的定点表示。

输入样例：

```
12.34521
```

输出样例：

```
12.345
```

## 正解

### 思路

这道题的计算只有一步：把浮点数按十进制四舍五入到小数点后 3 位再输出。它没有"先写朴素做法、再消除瓶颈"的分层——任何手写的舍入（乘 $10^3$、取整、再除回去）都只会得到更长、还更容易引入二次浮点误差的代码。因此本题练的是**把浮点数变成定点格式**这条链路，思路与 [[roj/1000]] 的"读入链路"对应，只是把 `split + map(int, ...)` 换成格式说明符。

以样例 `12.34521` 为例，`f"{x:.3f}"` 内部完成的事情：

| 步骤 | 动作 | 结果 |
| --- | --- | --- |
| 读入并转浮点 | `float(input())` | `12.34521` |
| 取第 4 位小数判断舍入 | `2 < 5` | 舍去，不进位 |
| 补足 3 位小数 | 定点格式化 | `12.345` |

要点有三个：

1. `:.3f` 里的 `3` 就是"保留 3 位小数"，`f` 表示定点（fixed-point）表示，等价于 C 的 `printf("%.3f", x)`；舍入规则由格式化统一实现，不必自己乘除。
2. 负数不需要特判：格式化自带符号位。真实数据 10 组里有 7 组是负数（如 `-677.14911385` → `-677.149`），全部直接通过。
3. 题面说"单精度"，但判断只看第 4 位小数，Python 的 `float`（双精度）完全覆盖单精度的范围与精度需求，读进来不会有任何信息损失。

题面没有给出数据范围；`config.json` 限制 1000ms / 128MB，对一次格式化来说绰绰有余。

## 总结

- 输出"保留 $k$ 位小数"的定点浮点数，Python 里直接用 `f"{x:.3f}"`，舍入、补零、负号一次完成。
- 不要手写"乘 $10^3$ 再除回去"的舍入：多一步浮点运算，还要单独处理负数，没有收益。
- 单精度题面不等于要用单精度类型：Python `float` 是双精度，覆盖单精度数据绰绰有余。
- 题型上它和 A+B 一样属于输入输出格式题，算法没有优化空间，练习点全在语言的格式化能力。

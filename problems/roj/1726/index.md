## 形式化题目

有一个 $n \times m$ 的矩阵，初始每个格子的权值都是 $0$。可以重复执行两种操作：

1. 选一行，该行每个格子的权值同时 $+1$ 或 $-1$；
2. 选一列，该列每个格子的权值同时 $+1$ 或 $-1$。

给出 $k$ 个限制，每个限制是三元组 $(x, y, c)$，要求操作结束后格子 $(x, y)$ 的权值恰好为 $c$。
问是否存在这样的操作序列：存在输出 `Yes`，否则输出 `No`。

多组数据，第一行给出组数 $T \leqslant 5$；每组先给 $n, m, k$（$1 \leqslant n, m, k \leqslant 1000$，且 $k \leqslant n \times m$），
随后 $k$ 行限制。

把操作过程的信息压缩掉以后，题目等价于：**求一组整数
$(r_1, \dots, r_n,\; c_1, \dots, c_m)$，使得对每条限制 $(x, y, c)$ 都有 $r_x + c_y = c$。**

## 正解

### 思路

**为什么可以只看净次数。** 对第 $i$ 行一共加 $a$ 次、减 $b$ 次，它的净效果是整行加 $a-b$；
对第 $j$ 列同理，净效果是整列加 $c_j$。操作之间的先后顺序对最终矩阵毫无影响，
格子 $(x, y)$ 的权值只等于 $r_x + c_y$。反过来任意一组整数 $r, c$ 都能实现：
第 $i$ 行做 $|r_i|$ 次加减（$r_i > 0$ 就加、$r_i < 0$ 就减），列同理。
于是**操作序列存在 $\iff$ 方程组 $r_x + c_y = c$ 有整数解**。

**朴素做法卡在哪。** 直接搜索 $r$ 的取值是无穷的（可正可负、可任意大），枚举范围说不出来；
而 $k \leqslant n \times m$，逐格模拟矩阵也无法判定解是否存在。

**关键观察：约束全是"等式"。** 每条限制只涉及两个变量，而等式可以改写成差值形式：
把第 $y$ 列的净操作数取负，令列点（编号 $n+y$）的"值"为 $-c_y$，限制就变成

$$\text{值}(x) - \text{值}(n + y) = c,$$

即"两个点之间的**差值**被定死了"。这类约束有一个漂亮性质：**差值沿路径可加**。
已知 $\text{值}(a) - \text{值}(b) = w_1$ 与 $\text{值}(b) - \text{值}(d) = w_2$，
就有 $\text{值}(a) - \text{值}(d) = w_1 + w_2$，不必再检查什么。
把行点、列点都当成图的顶点，每条限制当成一条带权边，则同一连通分量内的所有点值差
都被唯一确定；分量之间互不干扰，可以各自独立赋值。

**矛盾长什么样。** 只有一种出错可能：绕一圈回来发现某点和"自己"的值差不是 $0$。
也就是存在闭合走法，把沿途边的权值按行走方向带符号相加后得到非零值——
这正是方程组无解（矛盾）的充要条件。

**用带权并查集维护。** 上述"路径可加 + 同分量差值唯一"正好是带权并查集能表达的形态。
为每个点 $i$ 维护两个量：

| 名称 | 含义 |
| --- | --- |
| `fa[i]` | 并查集的父节点，`fa[i] == i` 表示 $i$ 是根 |
| `val[i]` | $\text{值}(i) - \text{值}(\texttt{fa}[i])$，即 $i$ 到父节点的值差 |

对每条限制 $(x, y, c)$，令 $\text{col} = n + y$：

1. **同根**：两点的值差已被完全确定，就是 $\texttt{val}[x] - \texttt{val}[\text{col}]$，
   它必须等于 $c$，否则这条限制与已有信息冲突，答案 `No`。
2. **不同根**：两点之间原本没有任何约束，这条限制不可能矛盾，直接合并两棵树。
   设两根为 `root_x`、`root_col`，把 `root_col` 挂到 `root_x` 下，偏移量由等式反解：

$$\texttt{val}[\text{root\_col}] = \texttt{val}[x] - \texttt{val}[\text{col}] - c .$$

推导只需两步：由 $\text{值}(x) - \text{值}(\text{col}) = c$ 代入
$\text{值}(x) = \text{值}(\text{root\_x}) + \texttt{val}[x]$、
$\text{值}(\text{col}) = \text{值}(\text{root\_col}) + \texttt{val}[\text{col}]$，
移项即得 $\text{值}(\text{root\_col}) - \text{值}(\text{root\_x}) = \texttt{val}[x] - \texttt{val}[\text{col}] - c$。

**为什么整数解一定存在。** 上面所有运算都只是整数加减（$c$ 是整数，路径偏移是整数之和），
根的值随便取一个整数即可，解出的 $r, c$ 自然全是整数。
所以这里"实数可解"与"整数可解"没有区别，不需要额外讨论。

用样例第 2 组数据看看矛盾是如何暴露的。限制为 $(1,1,0), (1,2,0), (2,1,2), (2,2,1)$，
不妨取 $\text{值}(1) = 0$，则 $(1,1,0)$ 给出 $\text{值}(3) = 0$，$(1,2,0)$ 给出 $\text{值}(4) = 0$；
再由 $(2,1,2)$ 得 $\text{值}(2) = \text{值}(3) + 2 = 2$。
最后的 $(2,2,1)$ 与前面已连通，要求 $\text{值}(2) - \text{值}(4) = 1$，
但已推出 $2 - 0 = 2 \neq 1$，故输出 `No`。

**实现上的两个易错点。** 一是 `val` 是"对父节点"的差值，路径压缩必须先把整条路径的
偏移量求出来再自近根端往叶端改写（先累加出 `值(x) - 值(root)`，再逐点把 `val` 改成对根的差值），
否则 `val` 里混着对不同祖先的差值，链长 $\geqslant 3$ 就会错；
二是合并时挂的是**根**的偏移量（`val[root_col]`），而不是列点的偏移量。

### 复杂度

每组数据的时间为 $O((n + m) + k\,\alpha(n + m))$：初始化 $n+m$ 个点，每条限制一次查根加可能的合并；
组数 $T \leqslant 5$，实际总量 $\leqslant 5 \times (2000 + 1000)$ 次操作。空间 $O(n + m)$。
在 2000 ms / 256 MB 下余量极大，CPython 实测本目录 10 个测点（含 $T=5$、$n=m=1000$、$k=1000$ 的顶格数据）
全部在数十毫秒量级完成。

## 总结

本题是"等式型约束系统 = 带权并查集"的模板题，核心是三步转换：

1. **消掉操作序列**：行、列的加减互相独立且可抵消，只留下净次数 $r_i, c_j$，
   存在性等价于方程组 $r_x + c_y = c$ 有整数解；
2. **把加法等式改成差值等式**：列点点值取 $-c_y$，约束统一成 $\text{值}(x) - \text{值}(n+y) = c$，
   差值沿路径可加；
3. **带权并查集承载差值**：同集合核对值差是否等于 $c$，不同集合按
   `val[root_col] = val[x] - val[col] - c` 合并。

变体说明：同一模型也可以用"每个格子一条边、跑 SPFA 判负环"的差分约束写法实现
（$r_x - (-c_y) \leqslant c$ 与 $-c_y - r_x \leqslant -c$ 两条边），复杂度为 $O(VE)$，
在本题规模下更慢也更绕；带权并查集是这组"全等式约束"的最省做法。

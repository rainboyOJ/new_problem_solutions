## 形式化题目

有一排 $n$ 个球瓶，第 $i$ 个球瓶的分值为 $a_i$（可为负）。另有 $k$ 个保龄球，每个球占据**连续 $w$ 个位置**。

一次投球等价于在数轴上选一个长度恰为 $w$ 的区间 $[L, L+w-1]$：把该区间与 $[1, n]$ 相交部分中**仍立着**的球瓶全部击倒，并得到它们分值之和；已经倒下的球瓶再被盖住不再计分（球可以经过空位）。击倒的球瓶永远留下空位，而位置 $0, -1, \dots$ 与 $n+1, n+2, \dots$ 也是空位——所以区间允许部分伸出序列左右两端（例如 $L \leqslant 0$ 时只打中 $1 \dots L+w-1$）。

于是一个区间覆盖其左端到右端之间的位置，而击倒的球瓶集合恰好是 $k$ 个长度 $w$ 的区间之并（再与 $[1,n]$ 相交）。求 $k$ 次投球后能得到的最大总分；一个球瓶最多计一次分。

多组数据：第一行 $t \leqslant 10$，接着每组给出 $n, k, w$ 与 $n$ 个分值（每行一个）。数据范围 $1 \leqslant n \leqslant 10000$，$1 \leqslant k \leqslant 500$，$1 \leqslant w \leqslant 100$，$-10000 \leqslant a_i \leqslant 10000$。

## 正解

### 思路

**为什么贪心会错。** 最顺手的想法是每次投出"当前 $w$ 连和最大的区间"再把那些球瓶清空，重复 $k$ 次。这个贪心在负数球瓶出现时就崩了。看题面第二个例子 $2, 8, -5, 3, 5, 8, 4, 8, -6$（$k=3, w=3$，答案是 $38$）：最优解是 $(2+8) + (3+5+8) + (4+8)$。第一个球**故意伸到左边界之外**，只打中 $2, 8$，从而跳过 $-5$；第三个球**故意和第二个球重叠一格**，用第二个球已经打出的空位避开 $-6$。这两步都依赖"当前最大 $w$ 连和"之外的信息：一个区间可以只覆盖 $1$ 个到 $w$ 个新球瓶，取决于它的左右两端有多少已经是空位。贪心看不到这个自由度。

**把状态挂到"区间的右端点"上。** 观察重叠的几何：设上一个球的区间是 $[p-w+1, p]$，本球的区间是 $[i-w+1, i]$，且 $i-w+1 \leqslant p \leqslant i-1$（两个区间相交）。由于 $i-w+1 \geqslant p-w+1$，本球压住的那一段 $[i-w+1, p]$ 完整落在上一个球的区间里——**那几个位置一定是空的**。所以本球真正新增的只有 $p+1 \dots i$，得分恰好是 $S_i - S_p$（$S$ 为前缀和），无需关心 $p$ 之前发生过什么。

这说明：只要知道"上一个球的右端点 $p$ 在哪"，就能 $O(1)$ 算出本次投球的增量。于是状态就定义为**最后一个球的右端点**：

- $A[i]$：用 $j$ 个球、且第 $j$ 个球的右端点**恰为** $i$ 时的最大得分；
- $B[i]$：用**至多** $j$ 个球、且所有球的右端点都 $\leqslant i$ 时的最大得分（位置 $i$ 打不打都行）。

$B$ 从 $A$ 的前缀最大值得到：$B[i] = \max(B[i-1], A[i])$，故 $B$ 对下标单调不减。$j=0$ 时 $A[i]$ 全部不可达，$B[i] = 0$。

**处理越界。** 把序列右侧补 $w-1$ 个分值为 $0$ 的空位，令 $\mathrm{pos} = n + w - 1$，右端点 $i$ 就允许取到 $\mathrm{pos}$，这正是"球悬在右边界外"的情形，而且因为补位分值为 $0$，前缀和在补位段保持不变。左边界外伸的情形不用补位：只要 $i-w+1 \leqslant 0$，本球的窗口左端就越出序列，此时"上一球的右端点"直接钳到 $0$，即 $B[\max(0, i-w)]$。

**两条转移。** 第 $j$ 个球右端点在 $i$，它的窗口是 $[i-w+1, i]$：

1. **不重叠 / 越出左边界。** 上一球的右端点 $p \leqslant i-w$，本球覆盖的 $[i-w+1, i]$ 全是新球瓶，增量 $S_i - S_{\max(0,i-w)}$，前置状态取 $B[\max(0,i-w)][j-1]$。
2. **重叠。** 上一球的右端点 $p \in [\max(0, i-w+1),\, i-1]$，本球只新增 $p+1 \dots i$，得增量 $S_i - S_p$，前置状态是 $A[p][j-1]$（右端点**恰为** $p$，不能是 $B$）。这一项 $S_i + \max_p\big(A[p][j-1] - S_p\big)$，内层是固定 $j-1$、随 $i$ 右移的滑动窗口最大值，窗口长度 $w-1$，用单调队列摊还 $O(1)$ 取出。

$$A[i][j] = \max\Big(\underbrace{B[\max(0,i-w)][j-1] + S_i - S_{\max(0,i-w)}}_{\text{不重叠}},\ \underbrace{S_i + \max_{p \in [\max(0,i-w+1),\, i-1]}\big(A[p][j-1] - S_p\big)}_{\text{重叠}}\Big)$$

**为什么重叠项只能从 $A$ 转移。** 如果允许从 $B[p']$ 转移，等于说"上一个球的右端点可以随便 $\leqslant p'$"，那本球压住的位置到底空不空就无从保证了——会把还立着的负分球瓶当成空位跳过去，答案偏大。反过来，如果从 $A[p]$ 转移（右端点恰为 $p$），窗口 $[p-w+1,p]$ 必然覆盖 $[i-w+1,p]$，空位性质是**推导出来的**，不用额外假设。这是本题唯一的坑。

**答案。** $B[\mathrm{pos}][k]$。$B$ 对球数也单调不减（多出来的球扔到界外即可），所以它就是"至多 $k$ 个球"的答案；因为总能一个球瓶都不打，答案 $\geqslant 0$，全负数据下输出 $0$。

**验证。** 用 $n \leqslant 12$ 的完全搜索（枚举所有右端点组合取并集）对拍 3000 组随机数据，C++ 与 Python 两版全部一致；题面样例 $39 / 38$ 也均可复现。

### 复杂度

- 时间：对每个球数 $j \in [1, k]$、每个右端点 $i \in [1, n+w-1]$ 做一次摊还 $O(1)$ 的转移，共 $O\big(t \cdot k \cdot (n + w)\big)$。顶格 $t=10, k=500, n=10000, w=100$ 约 $5 \times 10^7$ 次操作，C++ 跑完整个文件约 $0.12$ s（峰值内存 $8.3$ MB），Python 同规模约 $8.4$ s。
- 空间：前缀和、$A$、$B$、单调队列各 $O(n + w)$，配滚动数组后与 $k$ 无关。注意到 $A[p][j-1] - S_p$ 与 $j$ 无关地复用，实现里每层重算一次即可，不需要 $O(nk)$ 的表。

## 总结

本题的关键在于把"球击倒球瓶"的游戏动作翻译成**数轴上的区间覆盖**，再把"同一个球瓶只计一次分"翻译成"后一个球与前一球重叠的部分不算分"。有了这个几何视角，"每次只新增 $1$ 到 $w$ 个球瓶"这件事就有了确切含义：新增段 = 本窗口减去上一窗口，长度由两球右端点的距离决定。

由此得到的状态设计比朴素 DP 多记一个量——**最后一个球的右端点**，换来了重叠转移的精确性。很多错误解法（包括本题素材的早期版本）只用"前 $i$ 个位置、$j$ 个球的最优值"做状态，会把没打空的负分球瓶当空位跳过，在随机数据上系统性偏大。写完 DP 后必须用 $n \leqslant 12$ 的暴力对拍确认这一点。

最后，把重叠项写成 $S_i + \max_p(A[p][j-1] - S_p)$ 之后，内层前缀最大值的窗口长度恒为 $w-1$，单调队列顺理成章地把 $O(nkw)$ 降到 $O(nk)$。这道题因此串起了"区间覆盖建模 → 记录端点 → 滑动窗口最大值优化"三步，是单调队列优化 DP 里几何感最强的一类练习。

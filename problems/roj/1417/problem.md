### 【题目描述】

外汇保证金交易可以通过兑换不同国家的货币来获得汇率差价带来的利润。

例如，在 1 美元 100 日元时买入 1000 美元，等价格变动到 1 美元 108 日元时卖出，可以获得 $(108 - 100) \times 1000 = 8000$ 日元的利润。

现在给出某种货币在时刻 $t$（$t = 0, 1, 2, \dots, n-1$）的价格 $R_t$，请求出价格差 $R_j - R_i$（其中 $j > i$）的最大值。

### 【输入】

第一行一个整数 $n$。

接下来 $n$ 行，按顺序给出 $R_t$（$t = 0, 1, 2, \dots, n-1$），每行一个整数。

### 【输出】

输出最大值，占一行。

### 【数据范围】

$2 \leqslant n \leqslant 200000$

$1 \leqslant R_t \leqslant 10^9$

### 【输入样例 1】

```
6
5
3
1
3
4
3
```

### 【输出样例 1】

```
3
```

### 【输入样例 2】

```
3
4
3
2
```

### 【输出样例 2】

```
-1
```

### 【提示】

注意利润可能为负数：当价格一路下跌时，最优的做法仍然必须先买后卖，此时最大差值就是最小的负数（如样例 2）。

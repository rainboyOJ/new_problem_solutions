## 题目描述

给定两个位数不超过 $299$ 的十进制正整数 $A$、$B$（各占一行，无前导零），求 $A = qB + r$（$0 \le r < B$）的商 $q$ 与余数 $r$，各占一行、不带前导零，商为 $0$ 时输出 `0`；样例输入 `1231312318457577687897987642324567864324567876543245671425346756786867867867` 与 `1231312318767141738178325678412414124141425346756786867867867`，对应输出 `999999999748590` 与 `179780909068307566598992807564736854549985603543237528310337`。

## 思路

用竖式长除法：从高位到低位依次把 $A$ 的一位拉下来，令当前余数 $r = 10r + d$，再反复减 $B$ 直到 $r < B$，减的次数就是这一位的商数字；商的位数至多 $n-m+1$，每位的试商是 $O(m)$，总复杂度 $O\big((n-m+1)m\big)$。注意商要去掉前导零（$A < B$ 时商为 `0`），余数已保持无前导零的规范表示，直接输出即可。

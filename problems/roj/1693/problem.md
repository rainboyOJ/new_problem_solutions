### 【题目描述】

试卷中共有$m$道判断题，小H与小Y一共从其他$n$个神犇那问了答案。之后又从小G那里得知，这$n$个神犇中有$p$个考了满分，$q$个考了零分，其他神犇不为满分或零分。你能帮助他们还原出标准答案吗？如有多解则输出字典序最小的那个，无解输出$-1$。

### 【输入】

第一行四个整数$n, m, p, q$，意义如上描述。
接下来$n$行，每一行$m$个字符“$N$”或“$Y$”，表示这题这个神犇的答案。

### 【输出】

仅一行，一个长度为$m$的字符串或是$-1$。

### 【输入样例】

```
2 2 2 0
YY
YY
```

### 【输出样例】

```
YY
```

### 【提示】

【数据规模】
对于30%的数据，满足$n≤100$。
对于60%的数据，满足$n≤5000，m≤100$。
对于100%的数据，满足$1≤n≤30000，1≤m≤500$。$0≤p,q$且$p+q≤n$。

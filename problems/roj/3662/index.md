## 形式化题目

给定一个 $n \times m$ 的矩阵，要在每个格子中填入 0 或 1。
对于任意两条从左上角 $(0,0)$ 到右下角 $(n-1,m-1)$ 的只能向下（D）或向右（R）走的路径 $P_1$ 和 $P_2$，
如果路径字符串满足字典序 $w(P_1) > w(P_2)$，则要求它们经过的格子填的数字组成的字符串满足字典序 $s(P_1) \le s(P_2)$。
求满足要求的填数方案数，答案对 $10^9+7$ 取模。

数据范围：$1 \le n \le 8$，$1 \le m \le 10^6$。

## 正解

### 思路

根据题目条件 $w(P_1) > w(P_2) \implies s(P_1) \le s(P_2)$，可以推导出对于任意局部 $2 \times 2$ 的矩阵，左下角格子的值必定 $\ge$ 右上角格子的值。也就是说，每条从左下到右上的斜线上的元素必须是非降的。

当两条路径在某一个格子开始分叉（例如 $P_1$ 向右，$P_2$ 向下）时，它们产生的后续子路径受到严格制约。进一步地，如果一条斜线上存在相邻两个格子填的数字相同，就会导致它们右下方的元素呈现出大面积必须完全对称或者完全相等的限制。

基于状态压缩动态规划，如果以列为单位转移，我们可以针对小范围的 $n$ 跑出准确答案。这题的一个著名结论是：由于行列具有对称性（即交换 $n$ 和 $m$ 不影响方案数），我们假设 $n \le m$。当 $n \le 8$ 且 $m > n$ 时，方案数呈现明显的等比数列规律：
对于 $n \ge 1, m > n$，$ans(n, m+1) = ans(n, m) \times 3$。

因此，我们只需要通过打表或者公式推导出边界情况 $m=n$ 和 $m=n+1$ 时的前几项，剩下的部分直接使用快速幂计算即可。
对于 $1 \le n \le 8$，我们可以通过打表给出 $A_n = ans(n, n)$ 和 $B_n = ans(n, n+1)$ 的值：
- $n=1$: $A_1 = 2$ 且对任意 $m$ 有 $ans(1, m) = 2^m$。
- $n=2$: $A_2 = 12, B_2 = 36$
- $n=3$: $A_3 = 112, B_3 = 336$
- $n=4$: $A_4 = 912, B_4 = 2688$
- $n=5$: $A_5 = 7136, B_5 = 21312$
- $n=6$: $A_6 = 56768, B_6 = 170112$
- $n=7$: $A_7 = 453504, B_7 = 1360128$
- $n=8$: $A_8 = 3626752, B_8 = 10879488$

对于 $m > n$ 的情况，答案即为 $B_n \times 3^{m - n - 1} \pmod{10^9+7}$。这种方法将复杂的插头 DP 简化为了时间复杂度 $O(\log m)$ 的算法。

### 复杂度

- **时间复杂度**: $O(\log \max(n, m))$。算法的瓶颈仅仅在于一次底数为 2 或 3 的快速幂，非常高效。
- **空间复杂度**: $O(1)$。仅需要常数级的变量与预处理数组空间。

## 总结

这是一道非常经典的寻找性质和规律的题目。在考场上，即使不能用复杂的插头 DP（轮廓线 DP）解决 $10^6$ 级别的数据，依然可以通过编写暴力 DFS 打表观察 $ans(n, n)$ 和 $ans(n, n+1)$，以及 $ans(n, m)$ 在 $m > n$ 时每次乘以 3 的规律。利用这种规律性可以直接拿到满分，是数论/找规律算法中经常遇见的“缩减状态机”的一个经典体现。

### ★★ 为什么仍然要标注风险（`T28` 的用法）

1. **20/20 只证明「在这些 `n` 上正确」** —— 不证明「表本身可推导」
2. 若某天出现 `n = 9`（或更大的 `n`）的测试点，**会数组越界**（表只到下标 8）
3. ★ 更根本的：**「凭记忆打表」不是可复现的解法** ——
   正确做法应是**写一个暴力/搜素程序把表打出来**，让表**可复现、可验证**
   （先例 `T69`：任务里不要放「非必需的重活」；但这里「打表」正是必需的重活）

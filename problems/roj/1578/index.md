## 形式化题目

给定一棵包含 $N$ 个节点的无向树（节点编号为 $0$ 到 $N - 1$）。要求在树上的某些节点放置士兵，如果一个节点放置了士兵，则与该节点相连的所有边都被瞭望（覆盖）。

求最少需要放置多少个士兵，才能使得树上的所有边都被至少一个士兵瞭望到。即求树的**最小点覆盖**（Minimum Vertex Cover）。

### 样例说明

输入样例：
```
4
0 1 1
1 2 2 3
2 0
3 0
```

对应一棵以节点 $0$ 或 $1$ 为中心相连的树：
- 节点 $0$ 连接 $1$
- 节点 $1$ 连接 $2, 3$
- 节点 $2, 3$ 没有子节点

树的边集为 $(0, 1), (1, 2), (1, 3)$。只需在节点 $1$ 放置 $1$ 名士兵，由于节点 $1$ 与节点 $0, 2, 3$ 都有边相连，所有 $3$ 条边都被覆盖。最少士兵数为 $1$。

```mermaid
graph TD
    0((0)) --- 1((1 [士兵]))
    1 --- 2((2))
    1 --- 3((3))
```

## 正解

### 思路

本题是树上经典的**最小点覆盖**问题。根据题意，对于树上的任意一条边 $(u, v)$，端点 $u$ 和 $v$ 中必须至少放置一个士兵，才能覆盖该边。

我们可以任选一个节点（如输入中入度为 0 的节点，或任意指定根）作为树根，将无向树转化为有向有根树。

#### 1. 朴素思考与瓶颈

若采用搜索回溯枚举每个节点选或不选，共有 $2^N$ 种状态，当 $N$ 达到上千时复杂度为 $O(2^N)$，不可承受。

观察树的局部无后效性：对于以 $u$ 为根的子树，如果子树外的边如何被覆盖不影响子树内部结构，子树内部最优决策仅取决于节点 $u$ 本身是否放置了士兵。因此可以使用**树形动态规划**。

#### 2. 状态定义

对于以 $u$ 为根的子树：
- 定义 $dp[u][0]$ 表示：节点 $u$ **不放置**士兵时，覆盖以 $u$ 为根的子树内所有边所需的最少士兵数。
- 定义 $dp[u][1]$ 表示：节点 $u$ **放置**士兵时，覆盖以 $u$ 为根的子树内所有边所需的最少士兵数。

#### 3. 状态转移方程

对于节点 $u$ 的每一个子节点 $v$：
1. **当 $u$ 不放置士兵（$dp[u][0]$）时**：
   连接边 $(u, v)$ 必须被覆盖，由于端点 $u$ 没有士兵，端点 $v$ 处**必须放置士兵**！
   此时子节点 $v$ 只能取状态 $dp[v][1]$。累加所有子节点贡献：
   $$dp[u][0] = \sum_{v \in sons(u)} dp[v][1]$$

2. **当 $u$ 放置士兵（$dp[u][1]$）时**：
   边 $(u, v)$ 已经由端点 $u$ 处的士兵覆盖。此时子节点 $v$ 处放不放士兵均可覆盖边 $(u, v)$，为了让子树所需总士兵数最少，子节点 $v$ 应取两种情况的较小值：
   $$dp[u][1] = 1 + \sum_{v \in sons(u)} \min(dp[v][0], dp[v][1])$$
   （初始时 $dp[u][1] = 1$，表示在节点 $u$ 放置了 1 名士兵）。

#### 4. 计算顺序与实现细节

由于树形 DP 依赖于子节点的结果，我们需要按照**自底向上**（即树的后序遍历或拓扑逆序）依次转移。
在 Python 中，如果树深度较大，使用深递归容易导致爆栈。可以使用栈进行自顶向下收集遍历序列（模拟 DFS），随后将遍历序列反转，得到逆拓扑序，直接做自底向上的迭代循环。

最终整棵树的答案为：
$$\min(dp[root][0], dp[root][1])$$

### 复杂度

- **时间复杂度**：$\mathcal{O}(N)$。每个节点和每条树边在建树与自底向上的动态规划中仅被遍历常数次。
- **空间复杂度**：$\mathcal{O}(N)$。邻接表、DP 数组及遍历栈的空间占用均为 $O(N)$。

## 总结

1. **模型转化**：将“瞭望所有路”精确刻画为图论中的“最小点覆盖”。在树形结构上，每条边的两个端点必须至少选一个。
2. **两状态转移**：当前节点不选时，所有子节点必须全选；当前节点选时，每个子节点取放或不放的极小值。
3. **实现注意**：树形 DP 使用显式栈收集逆拓扑序做迭代转移，可以彻底消除递归爆栈风险，在 Python 下运行效率高且代码精简。

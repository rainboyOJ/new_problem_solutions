## 形式化题目

给定序列 $x_1, x_2, \ldots, x_n$ 与函数 $g(u) = a u^2 + b u + c$，其中 $a < 0$。记前缀和

$$S_i = x_1 + x_2 + \cdots + x_i, \qquad S_0 = 0 .$$

选择一组下标 $0 = p_0 < p_1 < \cdots < p_k = n$，把序列切成 $k$ 个连续段 $(p_{t-1}, p_t]$，使

$$\sum_{t=1}^{k} g\big(S_{p_t} - S_{p_{t-1}}\big)$$

最大，输出这个最大值。

约束：$1 \leqslant n \leqslant 10^6$，$-5 \leqslant a \leqslant -1$，$|b|, |c| \leqslant 10^7$，$1 \leqslant x_i \leqslant 100$，故 $S_n \leqslant 10^8$。

## 正解

### 思路

**第一步：写出划分 DP。**

"同一支特别行动队编号连续"这句话把问题完全定死了：任何编队方案就是序列的一个**划分**，一支队伍对应一段连续区间。于是设 $f[i]$ 为前 $i$ 个士兵的最大修正战斗力和，$f[0] = 0$，枚举最后一支队伍的起点 $j$：

$$f[i] = \max_{0 \leqslant j < i} \Big\{ f[j] + g(S_i - S_j) \Big\} . \tag{1}$$

答案就是 $f[n]$，且 $f[0] = 0$ 对应"一个人不编队"这个唯一合法起点。任何合法方案都能被"最后一次切在哪里"唯一描述，所以 (1) 式不重不漏。注意 $f$ 可以取到负数（例如 $a=-1,b=-3,c=0$ 时 $g(1)=-4$），所以不能把初值当癈断下界。

以样例 $n=4,\ a=-1,\ b=10,\ c=-20,\ x=[2,2,3,4]$ 为例，前缀和为 $S = [0,2,4,7,11]$，把每个候选 $j$ 的取值都算出来（✅ 是取到最大值的 $j$）：

| $i$ | $S_i$ | 候选 $j$（单元格为 $f[j]+g(S_i-S_j)$） | $f[i]$ | 最优 $j$ |
| --- | --- | --- | --- | --- |
| 1 | 2 | $j=0$: -4✅ | -4 | 0 |
| 2 | 4 | $j=0$: 4✅ / $j=1$: -8 | 4 | 0 |
| 3 | 7 | $j=0$: 1 / $j=1$: 1 / $j=2$: 5✅ | 5 | 2 |
| 4 | 11 | $j=0$: -31 / $j=1$: -15 / $j=2$: 5 / $j=3$: 9✅ | 9 | 3 |

读表可以看出 $f[4] = 9$ 与样例一致，最优的切点是 $j=3$：把最后一名士兵单独编一队（$g(4)=4$），前三人的最优值是 $f[3]=5$——而 $f[3]$ 又切在 $j=2$ 处，对应"$\{1,2\},\{3\},\{4\}$"三支队伍。同时注意每行的候选值随 $j$ 先升后降，最优 $j$ 随 $i$ 单调右移（$0 \to 0 \to 2 \to 3$），这正是后面优化的线索。

**第二步：瓶颈在哪里。** (1) 式状态数 $O(n)$，每个状态要扫 $O(n)$ 个候选 $j$，总时间 $O(n^2)$。$n = 10^6$ 时约 $5 \times 10^{11}$ 次转移，即使 C++ 也远远超时。瓶颈是"每个 $i$ 都要把所有 $j$ 扫一遍"。

**第三步：把转移线性化。** 展开 $g$：

$$
\begin{aligned}
f[i] &= \max_j \big\{ f[j] + a(S_i - S_j)^2 + b(S_i - S_j) + c \big\} \\
     &= \max_j \Big\{ \underbrace{f[j] + aS_j^2 - bS_j}_{\text{只与 } j \text{ 有关}} \;-\; 2aS_i \cdot S_j \Big\} \;+\; \underbrace{aS_i^2 + bS_i + c}_{\text{只与 } i \text{ 有关}} .
\end{aligned}
$$

最后那个括号与 $j$ 无关，可以直接提到 $\max$ 外面。含 $j$ 的部分里，只有 $-2aS_i \cdot S_j$ 把 $i$ 和 $j$ 乘在一起。记

$$Y_j = f[j] + aS_j^2 - bS_j, \qquad u_i = -2aS_i,$$

得到等价的转移：

$$f[i] = \max_{0 \leqslant j < i} \Big\{ Y_j + u_i \cdot S_j \Big\} + aS_i^2 + bS_i + c . \tag{2}$$

**第四步：看成"直线族的上包络"。** 每个候选 $j$ 对应一条以 $u$ 为自变量的直线

$$l_j(u) = S_j \cdot u + Y_j \qquad (\text{斜率 } S_j,\ \text{截距 } Y_j),$$

(2) 式括号里做的正是"在 $u = u_i$ 处，问这族直线谁的函数值最大"。把这族直线画在平面上，只有落在**上包络**（upper envelope）上的直线才有机会成为最大值——被别的直线压在下方的直线，在任何 $u$ 处都不可能是第一。

**第五步：双单调性让上包络退化成单调队列。** 两条单调性在本数据范围内同时成立：

- **新直线的斜率单调增**：$x_i \geqslant 1$ 使 $S_j$ 随 $j$ 严格递增。上包络上直线的斜率从左到右递增，所以新直线只会接在包络的右端；
- **查询点单调增**：$a < 0$ 且 $S_i$ 递增 $\Rightarrow u_i = -2aS_i$ 严格递增。查询点只会向右走，最优直线在包络上也只会越来越靠右。

于是双端队列（单调队列）就能维护整条上包络：

1. **查询**：设队头为 $h_0$、次队头为 $h_1$。若在 $u_i$ 处 $h_1$ 已经不劣于 $h_0$，由于后续要用的查询点只会更大，$h_0$ 不可能再赢，直接弹出；反复执行直到队头严格最优；
2. **插入**：新直线 $i$ 入队前，检查队尾两条直线 $p, q$。设 $x_{pq}$ 是 $p,q$ 的交点横坐标（$x_{pq} = \frac{Y_q-Y_p}{S_q-S_p}$）。上包络要求交点位置递增：$x_{pq} < x_{qi}$。若 $x_{pq} \geqslant x_{qi}$，说明 $q$ 还没等到超过 $p$，就已经被 $i$ 超过，它的领先区间为空，不再出现在包络上，弹出；反复执行后把 $i$ 接到队尾；
3. 判定 $x_{pq} \geqslant x_{qi}$ 时用整数**交叉相乘**代替除法（两边分母 $S_q-S_p>0$、$S_i-S_q>0$ 均正，不等号不翻转）：
   $$\frac{Y_q - Y_p}{S_q - S_p} \geqslant \frac{Y_i - Y_q}{S_i - S_q} \iff (Y_q - Y_p)(S_i - S_q) \geqslant (Y_i - Y_q)(S_q - S_p).$$
   代码里的 `slope_pq >= slope_qi` 正是左边这个不等式（取等号时三线共点，丢中间那条不影响答案）；整数运算在 Python 中没有精度问题。

下图把样例的单调队列执行过程逐步列出来（$k_i = 2aS_i = -u_i$，即代码里取负后的写法）：

| $i$ | 查询用 $k_i=2aS_i$ | 查询时弹出队头 | 队头（最优 $j$） | 插入前弹出队尾 | 入队后上包络（各直线的 $(S_j, Y_j)$） |
| --- | --- | --- | --- | --- | --- |
| 1 | -4 | 无 | $j=0$（$f=0$） | 无 | (0,0) → (2,-28) |
| 2 | -8 | 无 | $j=0$（$f=0$） | $j=1$ | (0,0) → (4,-52) |
| 3 | -14 | $j=0$ | $j=2$（$f=4$） | 无 | (4,-52) → (7,-114) |
| 4 | -22 | $j=2$ | $j=3$（$f=5$） | 无 | (7,-114) → (11,-222) |

表中括号里的两个数是直线的参数 $(S_j, Y_j)$，即斜率与截距。可以看到 $i=2$ 时直线 $j=1$ 刚入队就被 $j=2$ 顶掉（队尾弹出），$i=3$ 时队头 $j=0$ 因为查询点变大而失效（队头弹出）——两种弹出合起来保证每条直线最多进出队各一次，主循环是摊还 $O(1)$ 的。

### 代码

`max_power()` 就是上面第四、五步的实现：`hull` 存直线编号，第一个 `while` 是查询前弹队头，第二个 `while` 是插入前弹队尾，`y[i]` 就是截距 $Y_i$，`k = 2*a*s` 是 $-u_i$（两边同乘 $-1$ 后把 $\max l_j(u)$ 写成 $\max (Y_j - k S_j)$）。`solve()` 只负责读入、算前缀和、输出；`pre`、`f`、`y` 用 `array('q')` 存放（$n = 10^6$ 时把峰值内存压到 128 MB 以内），读入用的临时表在求完前缀和后立即释放。

### 复杂度

- 时间复杂度：读入、前缀和、主循环都是 $O(n)$，主循环的两次 `while` 摊还 $O(1)$（每条直线最多入队一次、出队一次），总计 $O(n)$，与标准 C++ 斜率优化解法同阶。
- 空间复杂度：$O(n)$，即前缀和、$f$、$Y$ 三张表和队列；$n = 10^6$ 时实测峰值约 74 MB。
- 数值范围：$f$ 可达 $10^{13}$ 量级，叉积比较约 $10^{24}$，Python `int` 任意精度不会溢出（C++ 需要 `__int128`）。
- Python 侧风险：本地 10 组真实数据 $n = 10^6$ 用时约 0.9 s，若 OJ 解释器更慢存在 TLE 风险（按任务约定允许）。

## 总结

- **建模**：编号连续 ⇒ 问题就是"把序列切成若干连续段、段费用由段和决定"的划分 DP，$f[i] = \max_j \{ f[j] + g(S_i - S_j) \}$。
- **线性化**：展开 $g$ 后，只与 $j$ 有关的项收成截距 $Y_j = f[j] + aS_j^2 - bS_j$，与 $i$ 有关的项提到 $\max$ 外，转移变成"在直线族 $l_j(u) = S_j u + Y_j$ 的上包络上查询 $u_i = -2aS_i$"。
- **上包络**：只有上包络上的直线可能成为最大值，被压在下方的直线可以永久丢弃。
- **双单调**：$a < 0$ 使查询点 $u_i$ 单调增，$x_i \geqslant 1$ 使直线斜率 $S_j$ 单调增，两者同向 ⇒ 双端队列摊还 $O(1)$ 维护上包络，总复杂度 $O(n)$。
- **易错点**：交点判据必须用交叉相乘（浮点除法会在大数下失准）；插入用 `<=` 弹出可顺带处理三线共点；$S$ 严格递增是"分母恒正、不等号不翻转"的前提，若 $x_i$ 可能为 0 需要改写。


观察重点：C→D 是分水岭，它把"枚举切点"换成"在直线族的上包络上查询"；D→E→F 说明为什么可以只用双端队列而不是三分查找或李超树——查询点与直线斜率**同向单调**，最优直线只向右移，队头可以直接弹掉；G 的两个 `while` 分别对应"旧直线过期"与"新直线让旧直线失去包络地位"。

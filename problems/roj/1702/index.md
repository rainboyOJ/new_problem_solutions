## 形式化题目

给定两个非负整数数列

$$X = \{x_1, x_2, \dots, x_n\}, \qquad Y = \{y_1, y_2, \dots, y_m\},$$

构造 $n \times m$ 的矩阵 $A$，其中 $A_{ij} = x_i \oplus y_j$（$\oplus$ 表示按位异或）。
下述 $p$ 次询问互相独立，每次给出 $u, d, l, r, k$，要求输出子矩形

$$\{\, A_{ij} \;\big|\; u \leqslant i \leqslant d,\; l \leqslant j \leqslant r \,\}$$

中**第 $k$ 大**的元素值（$k$ 从 $1$ 开始计数，即 $k = 1$ 求最大值）。

数据规模：$0 \leqslant x_i, y_j < 2^{31}$，$1 \leqslant n \leqslant 1000$，$1 \leqslant m \leqslant 300000$，
$1 \leqslant k \leqslant (d-u+1)(r-l+1)$，$1 \leqslant p \leqslant 500$。

以题目样例为例，$X = (1,2,4)$、$Y = (7,6,5)$ 时矩阵为

| $A_{ij}$ | $y_1 = 7$ | $y_2 = 6$ | $y_3 = 5$ |
| :-: | :-: | :-: | :-: |
| $x_1 = 1$ | 6 | 7 | 4 |
| $x_2 = 2$ | 5 | 4 | 7 |
| $x_3 = 4$ | 3 | 2 | 1 |

第一次询问取 $i \in [1,2]$、$j \in [1,2]$ 的四个数 $6, 7, 5, 4$，第 2 大为 $6$；
第二次取 $i \in [1,2]$、$j \in [1,3]$ 的六个数，第 4 大为 $5$。

## 正解

### 思路

**先看朴素做法。** 每次询问把子矩形里的 $(d-u+1)(r-l+1)$ 个数全部枚举出来排序，
取第 $k$ 个。单次代价已经高达 $n \times m = 3 \times 10^8$ 量级，$p$ 次询问完全不可行。
就算把排序换成桶，也还是绕不开"枚举整个子矩形"这一步。

**关键观察一：第 $k$ 大可以逐位确定，不需要排序。** 把所有值看成定长的二进制串，
"第 $k$ 大"就是"按字典序（高位优先）第 $k$ 大"。于是可以把候选集合按**最高位**劈成两半：

- 若最高位为 $1$ 的元素有 $\mathrm{cnt}_1$ 个，且 $k \leqslant \mathrm{cnt}_1$，
  则答案的最高位是 $1$，且第 $k$ 大落在"最高位为 1"这一半里；
- 否则答案最高位是 $0$，并把 $k$ 减去 $\mathrm{cnt}_1$——那一半已经被整块跳过了。

确定一位后，候选集合收缩到对应的那一半，再对次高位做同样的事。
重复 31 次就得到完整答案。**排序被换成了 31 次"某一半有多少个"的计数。**

**关键观察二：二维的位计数能拆成一维的按位计数。** 对固定的 $i$ 和位 $b$，

$$A_{ij} \text{ 的第 } b \text{ 位} = x_i \text{ 的第 } b \text{ 位} \oplus y_j \text{ 的第 } b \text{ 位},$$

所以 $A_{ij}$ 第 $b$ 位为 $1$ 等价于 $y_j$ 的第 $b$ 位等于 $x_i$ 第 $b$ 位的**取反**。记

$$\mathrm{want}_i = \text{（}x_i \text{ 的第 } b \text{ 位）} \oplus 1,$$

于是整个子矩形的按位计数是

$$\mathrm{cnt}_1 = \sum_{i=u}^{d} \#\{\, j \in [l,r] \;\big|\; y_j \text{ 的第 } b \text{ 位} = \mathrm{want}_i \,\}.$$

二维问题被拆成了 $d-u+1$ 个一维问题：**在 $Y$ 的区间 $[l,r]$ 上，统计某一位等于某值的元素个数。**
异或的每一位互不干扰，这是整个算法能拆开的根源。

**关键观察三：可持久化 01-Trie 一次同时给出计数和下钻目标。** 01-Trie 按位分层，
把一个数从高位到低位插入，每个节点记录子树元素个数，那么"第 $b$ 位等于 $v$ 的个数"
就是"沿第 $b$ 位对应的分支走到那个子树，读它的计数"。

要做区间 $[l,r]$ 而不是整个 $Y$，经典手法是**可持久化**：`roots[j]` 表示只插入 $y_1..y_j$
的那个版本。两个版本的节点逐位同步下钻时，

$$\mathrm{cnt}\big(\text{version } r \text{ 的子树}\big) - \mathrm{cnt}\big(\text{version } l-1 \text{ 的子树}\big)$$

恰好是 $Y[l..r]$ 上落进这棵子树的元素个数——又因为 Trie 的层与位一一对应，
"落进子树"就等于"前若干高位等于给定前缀"，正是逐位确定所需要的候选集合。

更妙的是**下钻本身就是候选集合的收缩**。对每个 $i$ 维护一对指针：

| 指针 | 含义 |
| :-: | :-: |
| `cur[i]` | 第 $r$ 版本中，代表"已确定前缀 + $\mathrm{want}_i$"的那个节点 |
| `prv[i]` | 第 $l-1$ 版本中的同一位置 |

两者相减即当前候选集合（前缀已固定的那一批 $A_{ij}$）的规模；若答案该位取 $1$，
就让所有 `cur[i] / prv[i]` 走 $\mathrm{want}_i$ 分支（"也想取反过来那位"的那个方向），
取 $0$ 则走另一位。$n \leqslant 1000$，把 $d-u+1$ 对指针整排一起推进只有 $O(n)$ 的常数。

**一次询问的执行流程：**

1. 把 `cur[i] ← roots[r]`、`prv[i] ← roots[l-1]`（$i = u..d$）；
2. 从第 30 位往第 0 位，对每一位 $b$：按上式累计 $\mathrm{cnt}_1$；
3. $k \leqslant \mathrm{cnt}_1$ 则答案该位记 1 并整排走 $\mathrm{want}_i$ 分支，
   否则 $k \leftarrow k - \mathrm{cnt}_1$、该位记 0、整排走另一位；
4. 31 位走完，累计出的二进制数就是第 $k$ 大。

下面用样例的第一次询问（$X[u..d] = (1,2)$，$Y[l..r] = (7,6)$，$k = 2$）逐位跟踪。
候选集合是 $\{6, 7, 5, 4\}$，其中 $i=1$（$x_1=1$）贡献 $\{7, 6\}$、$i=2$（$x_2=2$）贡献 $\{5, 4\}$；
表中"计数"一列是当前候选集合里该 $i$ 贡献的元素中、$A$ 的第 $b$ 位为 $1$ 的个数：

| 位 $b$ | $x_1, x_2$ 的该位 | $\mathrm{want}_1, \mathrm{want}_2$ | $i=1$ 计数 | $i=2$ 计数 | $\mathrm{cnt}_1$ | 判断 | 答案位 |
| :-: | :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| 30..3 | 0, 0 | 1, 1 | 0 | 0 | 0 | $2 > 0$，$k$ 不变 | 0 |
| 2 | 0, 0 | 1, 1 | 2 | 2 | 4 | $2 \leqslant 4$，取高 | 1 |
| 1 | 0, 1 | 1, 0 | 2 | 0 | 2 | $2 \leqslant 2$，取高 | 1 |
| 0 | 1, 0 | 0, 1 | 1 | 0 | 1 | $2 > 1$，$k \leftarrow 1$ | 0 |

高位全 0 时 $k$ 不动。第 2 位上 $i=1$ 的 $\{7, 6\}$ 与 $i=2$ 的 $\{5, 4\}$ 都满足
$y_j$ 的第 2 位 $= \mathrm{want}_i = 1$，四个数全在这一位为 1，$\mathrm{cnt}_1 = 4$；
取高之后两个 $i$ 的指针都沿"$y_j$ 第 2 位为 1"的分支下钻，候选集合不变。
第 1 位时 $x_2$ 的该位是 1，$\mathrm{want}_2 = 0$，而 $\{7, 6\}$ 的第 1 位全是 1，
$i=2$ 的计数掉到 0；$i=1$ 那边仍是 2 个，共 $\mathrm{cnt}_1 = 2$，$k=2$ 刚好取高，
候选集合收缩为 $\{7, 6\}$。第 0 位上 $\mathrm{want}_1 = 0$，$\{7, 6\}$ 里只有 $6$ 的第 0 位为 0，
计数为 1，$k=2 > 1$，只好取 0 并把 $k$ 减到 1，候选集合只剩 $\{6\}$。
最终答案 $110_2 = 6$。✔

**为什么不用别的结构？** "区间内第 $b$ 位为 $v$ 的个数"也可以对每一位各开一个前缀和数组
（31 个长度为 $m$ 的数组），单次统计同样是 $O(1)$——但它没法回答"下钻到哪"，
每次收缩候选集合都得重新在 $O(n)$ 个前缀和数组上对齐前缀，实现上等价于手写一棵 31 层 Trie。
可持久化 01-Trie 把"计数"和"下一步往哪走"放进同一个结构，代码反而更短；
它也正是这类"区间内按位第 $k$ 大"问题的标准工具。

### 复杂度

- **时间**：建树每插入一个 $Y$ 元素要走 31 层并复制 31 个节点，共 $O(31m)$。
  单次询问对 $d-u+1$ 个 $i$ 走 31 层，每层 $O(1)$，共 $O(31(d-u+1))$，
  总时间 $O\big(31(m + pn)\big)$。取上限 $m = 3 \times 10^5$、$p = 500$、$n = 1000$：
  约 $9.3 \times 10^6 + 1.55 \times 10^7 \approx 2.5 \times 10^7$ 次基本操作。
- **空间**：可持久化 Trie 每个元素占 $31 + 1$ 个节点，节点存两个儿子编号和一个计数，
  共 $O(31m)$ 个节点、约 $113$ MB。C++ 用静态 `Node` 数组（`int ch[2]; int cnt;` 一个节点 12 字节）
  实测峰值 $113.2$ MB；Python 用三个 `list[int]`。
- **与 C++ 解法的关系**：`main.cpp` 是同一算法的 C++ 落地，节点做成
  `struct Node { int ch[2]; int cnt; }` 的动态化静态数组，用 `node_cnt` 当期分配指针；
  Python 版把 `ch[2]` 摊成 `L` / `R` 两个列表以省掉下标算术，两者逐位逻辑一致。
- **实测**（本机 `/opt/homebrew/bin/g++-16 -O2` 与 CPython 3.13，数据 $m = 3 \times 10^5$、$p = 500$、$n = 1000$ 的顶格点）：
  C++ 约 $0.15$ s / 峰值 $113$ MB（限时 2 s、限内存 512 MB）；
  Python 约 $3.5 \sim 3.9$ s，在 2 s 限时下**有 TLE 风险**，仅作教学对照。

## 总结

- **第 $k$ 大不必排序**：二进制下的"字典序第 $k$ 大"可以逐位确定，
  每层只需回答"当前位为 1 的元素有多少个"，把 $O(N \log N)$ 的排序换成 $\log V$ 次计数。
- **异或让二维可拆**：$A_{ij}$ 的第 $b$ 位只由 $x_i, y_j$ 的第 $b$ 位决定，
  于是"矩形内的按位计数"$\to$ $\sum_i$"$Y[l..r]$ 上第 $b$ 位等于 $\mathrm{want}_i$ 的个数"。
- **可持久化版本差 = 区间计数**：`cnt(roots[r]) - cnt(roots[l-1])` 是"区间 $[l,r]$ 落进该子树"
  的标准写法，把区间查询转成两个前缀版本的同步下钻。
- **下钻即收缩候选集合**：逐位贪心的每一步同时完成两件事——统计 $\mathrm{cnt}_1$、
  把指针移到答案该位对应的分支。这是"可持久化 Trie 求区间异或第 $k$ 大"的通用套路，
  本题只是把单个 $Y$ 换成了 $n$ 排指针并行推进。
- **注意值域**：$x_i, y_j < 2^{31}$ 所以只有 0..30 共 31 位，答案同样落在 $[0, 2^{31})$，
  C++ 里用 `long long` 承接即可，不需要 `unsigned`。

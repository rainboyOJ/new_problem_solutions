## 题目描述

病人登记看病，按三条规则排出看病顺序：年龄 $\geqslant 60$ 的老年人优先；老年人按年龄从大到小，年龄相同的按登记先后；非老年人一律按登记先后。数据范围 $n < 100$，ID 为长度小于 $10$ 的数字字母串（可含前导零）。输入第一行 $n$，其后 $n$ 行每行一个 ID 和一个年龄，按登记先后给出；输出每行一个 ID。样例输入 `5 / 021075 40 / 004003 15 / 010158 67 / 021033 75 / 102012 30`，期望输出 `021033 / 010158 / 021075 / 004003 / 102012`。

## 思路

把三条规则压成一个排序键 `(age < 60, 老年人 ? -age : 0, 登记序号)`，按它排一次序再依次输出：第 1 位让老年人排前面，第 2 位让老年人年龄大的在前（非老年人固定为 0，年龄不参与），第 3 位由登记序号兜底裁决平局。ID 含前导零，必须按字符串处理。

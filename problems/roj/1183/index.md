## 形式化题目

给定 $n$ 个病人，第 $i$ 个病人（登记序号 $i$，从 0 计）有一个互不相同的字符串标识 $\mathrm{id}_i$ 和一个整数年龄 $a_i$。求 $0, 1, \dots, n-1$ 的一个排列 $\pi$，使病人序列满足：

1. 老年人（$a_{\pi(k)} \geqslant 60$）全部排在非老年人之前；
2. 老年人内部按年龄非增排列，年龄相同时登记序号小者在前；
3. 非老年人内部严格按登记序号递增（年龄不参与）。

按 $\pi$ 依次输出每行一个 $\mathrm{id}_{\pi(k)}$。

样例：登记的 5 人依次为 `(021075, 40)`、`(004003, 15)`、`(010158, 67)`、`(021033, 75)`、`(102012, 30)`。其中 `021033`（75 岁）与 `010158`（67 岁）是老年人，按年龄降序排最前；其余 3 人按登记先后跟在后面，输出 `021033`、`010158`、`021075`、`004003`、`102012`。

## 正解

### 思路

这题只要"按规则排一次序"，任何正确做法都是**设计排序键 + 排序**。参考实现 `std.cpp`（数据仓，只读参考）的写法是：第一遍把病人分进"老年人 / 非老年人"两个桶，第二遍分别冒泡排好：老年人桶按年龄降序（同龄按登记先后），非老年人桶按登记先后（病人按序入桶，其实已经有序），最后先输出老年人桶、再输出非老年人桶。分桶 + 排序与"带键单次排序"是同一个模型的两种表达，$n < 100$ 下 $O(n^2)$ 与 $O(n \log n)$ 没有教学落差，也不存在能暴露瓶颈的更朴素层，所以本题不设暴力层，直接讲最终做法（直接正解型布局的依据）。

关键在于：题面的三条规则正好是**字典序可分层**的——先比组，再比组内，最后比平局。于是每条规则对应排序键的一个位置，三元组的字典序比较天然复现规则的优先级：

- 规则 1（老年人优先）→ 键第 1 位 `age < ELDERLY_AGE`：布尔值 `False = 0 < True = 1`，老年人取 0 排前面；
- 规则 2（老年人按年龄降序）→ 键第 2 位 `-age`：取负号让"年龄大"变"键小"；**非老年人这一位统一记 0**，把年龄显式抹平——否则非老年人会被按年龄排序，直接违反规则 3；
- 规则 2/3（同序按登记先后）→ 键第 3 位 `idx`（输入下标）：平局裁决写成显式规则。非老年人的前两位完全相同，这一位就完整还原了登记先后；老年人同龄时也由它兜底。

用样例推演这条链路（登记序号从 0 计，键为三元组）：

| 登记序 $i$ | ID | 年龄 | 键 `(组, 组内, 登记序)` | 排序后位置 |
| --- | --- | --- | --- | --- |
| 0 | `021075` | 40 | `(True, 0, 0)` | 3 |
| 1 | `004003` | 15 | `(True, 0, 1)` | 4 |
| 2 | `010158` | 67 | `(False, -67, 2)` | 1 |
| 3 | `021033` | 75 | `(False, -75, 3)` | 0 |
| 4 | `102012` | 30 | `(True, 0, 4)` | 2 |

表中值得多看一眼的两点：其一，`False` 组（老年人）两个键都小于任何 `True` 组，规则 1 由第 1 位一次搞定；其二，`True` 组内第 2 位全是 `0`——40 岁、15 岁、30 岁的年龄差被显式抹平，位置只由第 3 位的登记序号决定，这正是规则 3 要求的"与年龄无关"。若非老年人的第 2 位偷懒写成 `-age`，输出会变成按年龄降序的 `021075, 102012, 004003`，样例立刻不过。

两个实现细节随键一起定下来：ID 含前导零（`021075`）必须按字符串处理，全程保持 `bytes`、只在最终输出时 `decode()`，一旦转成整数就丢了前导零；读入沿用本系列标准链路 `sys.stdin.buffer.read().split()` 一次读完、按空白切分，推导式里用 `2 * i + 1` / `2 * i + 2` 配对第 $i$ 行的 ID 与年龄。

### 复杂度

- 时间复杂度：$O(n \log n)$：一次读入 $O(n)$、`list.sort` $O(n \log n)$、join 输出 $O(n)$；键计算每次 $O(1)$。与参考实现 `std.cpp` 的老年人冒泡 $O(n^2)$ 同属"排一次序"的模型，$n < 100$ 下同样远快于 1000 ms 限制。
- 空间复杂度：$O(n)$：一个 $n$ 元素的三元组列表，加上输入缓冲与输出串。

## 总结

- 三条排队规则 = 排序键的三个位置：`age < 60` 分组、老年人 `-age` 组内降序、`idx` 登记序号兜底，元组的字典序比较天然按规则优先级生效，一次 `list.sort` 替代"分桶 + 冒泡 + 两处记录登记序号"的三段式模拟。
- 非老年人的年龄必须在键第 2 位显式抹成 0，否则会被按年龄排序、违反"非老年人一律按登记先后"；平局裁决靠显式 `idx` 而非排序稳定性，换任何排序实现都不变。
- ID 是带前导零的字符串：保持 `bytes` 到最后 `decode()`，不经过 `int`。
- 真实数据 10 个评测点全部一致，单点约 0.017–0.019 s、峰值内存 14.6 MB，相对 1000 ms / 128 MB 的限制十分宽裕。

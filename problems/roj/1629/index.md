## 形式化题目

给定正整数 $S$，求所有满足 $\sigma(n)=S$ 的正整数 $n$（$\sigma(n)$ 表示 $n$ 的正约数之和），并把它们升序排列。

若 $n=\prod_i p_i^{a_i}$ 是 $n$ 的质因数分解，则

$$\sigma(n)=\prod_i\bigl(1+p_i+p_i^2+\cdots+p_i^{a_i}\bigr).$$

记 $G(p,a)=1+p+\cdots+p^a=\dfrac{p^{a+1}-1}{p-1}$，下称**编号段**。题目等价于：把 $S$ 分解成若干个编号段之积，再按 $G(p,a)\leftrightarrow p^a$ 还原出 $n$。

样例 $S=42$：

| 编号段分解 | 还原出的 $n$ | 验证 |
| --- | --- | --- |
| $42=(1+2)\times(1+13)$ | $2\times 13=26$ | $\sigma(26)=1+2+13+26=42$ |
| $42=(1+2+4)\times(1+5)$ | $4\times 5=20$ | $\sigma(20)=1+2+4+5+10+20=42$ |
| $42=(1+41)$ | $41$ | $\sigma(41)=1+41=42$ |

三行分别对应 $42$ 的三种编号段拆法，所以输出 `3` 与 `20 26 41`。注意第三行说明答案可以是很大的质数本身，$41$ 不可能被「枚举质数」提前覆盖。

## 正解

### 思路

**为什么不能枚举 $n$。** 由 $\sigma(n)\geqslant n+1$ 得 $n\leqslant S-1\approx 2\times 10^9$，逐个数分解质因数在 $k\leqslant 100$ 组数据下完全不可行。而且 $n$ 是答案、$S$ 才是已知量，枚举 $n$ 等于丢掉了 $S$ 的全部信息。

**换成枚举 $S$ 的因子。** 由于 $\sigma(n)=\prod_i G(p_i,a_i)$，每个 $G(p_i,a_i)$ 都必须是 $S$ 的因子，并且 $G(p_i,a_i)\geqslant 2$。于是问题变成在 $S$ 的因子上做分解。枚举时只用到 $S$，与答案的大小无关。

**两类编号段要分开处理。**

- **指数 $a\geqslant 2$ 的编号段**：此时 $G(p,a)\geqslant 1+p+p^2>p^2$，而 $G(p,a)\mid S$，所以
  $p^2<S\leqslant 2\times 10^9$，即 $p<44722$。这一范围内的质数只有 $4648$ 个，可以预筛出来遍历。
  同时，当枚举到某个质数 $p$ 满足 $p^2>rest$ 时，$p$ 的指数已不可能 $\geqslant 2$，可以直接停止枚举。
- **指数为 $1$ 的编号段**：$G(p,1)=p+1$，其中 $p$ 可以是任意大的质数（如样例中的 $41$），
  无法枚举。但它可以反向识别：当前还剩 $rest$ 没被解释时，只要 $rest-1$ 是质数，就用编号段 $1+p=rest$
  收尾，把 $p=rest-1$ 乘进答案。

**DFS 状态。** 用 `(start, rest, cur)` 表示：只能用第 `start` 个及之后的质数，编号段乘积还差 `rest`，
已确定的答案为 `cur`。转移过程如下。

```text
search(start, rest, cur)
├─ rest == 1                  -> 收集 cur
├─ rest-1 >= p_start 且是质数 -> 收集 cur*(rest-1)      # 一次收尾，指数取 1
└─ 对 j = start.. 且 p_j^2 <= rest：
     令 pk = p^a, segment = 1+p+...+p^a 逐次增长
     segment | rest 时 search(j+1, rest/segment, cur*pk)
```

**$S=42$ 的递归过程。** 下图展示 DFS 在样例上的全部分支，可见三条成功路径恰好对应表中的三个答案。

```text
search(start=2, rest=42, cur=1)
├─ 收尾：rest-1 = 41 是质数 ──────────────────────────────► 答案 41
├─ 枚举 p=2（2^2 = 4 ≤ 42），逐段尝试：
│    G(2,1)=3  | 42  -> search(start 取 3 及以后, rest=14, cur=2)
│         └─ 收尾：14-1 = 13 是质数 ──────────────────────► 答案 26
│    G(2,2)=7  | 42  -> search(start 取 3 及以后, rest=6, cur=4)
│         └─ 收尾：6-1 = 5 是质数 ────────────────────────► 答案 20
│    G(2,3)=15 不整除 42；G(2,4)=31 不整除 42；G(2,5)=63 > 42 停
├─ p=3：G(3,1)=4 不整除 42，不递归
├─ p=5：G(5,1)=6 | 42 -> search(start 取 7 及以后, rest=7, cur=5)
│         └─ 7-1 = 6 不是质数，且 7^2 = 49 > 7，死路
└─ p=7：7^2 = 49 > 42，break
```

三点观察：一是样例的三个答案分别来自「只用一个收尾编号段」「一个指数 1 的段加一个收尾段」「一个指数 $\geqslant 2$ 的段加一个收尾段」，正好覆盖了 DFS 的三种收尾方式；二是 $p=5$ 那条分支说明 $p^2>rest$ 的剪枝是必要的，否则会继续试探更大的质数。

**为什么要把 $p$ 限制在递增顺序。** $n$ 的质因子集合与顺序无关，固定「从小到大取」后，
每个 $n$ 的编号段序列唯一，既不漏也不重：递归传 `j+1` 使同一个质数不会被用两次，
收尾分支同样要求 $rest-1\geqslant p_{start}$，否则又会取到已经用过的较小质数。
这条规则也保证了算法能**枚举完整**：设 $n=\prod_i p_i^{a_i}$（$p_i$ 递增），
只要 DFS 依次选中 $a_i\geqslant 2$ 的那些编号段，剩下的 $rest$ 就是所有 $a_i=1$ 的段之积；
若只剩一个这样的段，$rest-1$ 就是质数，被收尾分支产出，否则 `rest` 已化为 $1$。

### 复杂度

- 预处理：埃氏筛出 $p<44722$ 的质数，$O(\sqrt{S}\log\log\sqrt{S})$，只做一次。
- 每组询问：根层遍历 $\pi(\sqrt{S})=4648$ 个质数做常数次尝试；递归深度不超过 $n$ 的不同质因子个数
  （最多 $9$ 个，因为 $2\cdot3\cdot5\cdots23>2\times 10^9$），且每层枚举范围随 $rest$ 收缩。
  因此单组代价约为 $O\bigl(\pi(\sqrt{S})+\text{可行分支数}\bigr)$，与 $n$ 的大小无关。
- 空间：$O(\sqrt{S})$ 的表 + $O(\log S)$ 递归栈 + 答案列表。
- 实测 11 组真实数据共约 460 个询问，最慢一组 0.47s（含 $m=12554$ 的大输出），峰值内存 27.5MB。

## 总结

关键在于**不枚举答案 $n$，而是分解已知的 $S$**：$\sigma(n)$ 的乘性公式把「求 $n$」变成了
「把 $S$ 拆成编号段 $G(p,a)=1+p+\cdots+p^a$ 的乘积」。其中指数 $\geqslant 2$ 的编号段保证
$p<\sqrt{S}\leqslant 44722$，可以预筛质数遍历；指数为 1 的编号段 $G(p,1)=p+1$ 用
「$rest-1$ 是质数」反向收尾，从而覆盖任意大的质数因子。质数按下标严格递增取，保证不漏不重。

## 图示解析

### 从 $S$ 到答案的主线

```text
S = 42
 │  约数和公式 σ(n)=∏(1+p+…+p^a)
 ▼
把 S 拆成编号段之积 42 = G(p1,a1) × G(p2,a2) × …
 │  ├── a ≥ 2 的段：G(p,a) > p^2，故 p < √S < 44722 ──► 预筛质数 + p^2 > rest 剪枝
 │  └── a = 1 的段：G(p,1) = p+1 ────────────────► rest-1 是质数时一次收尾
 ▼
DFS (start, rest, cur)  ├─ rest == 1        ─► 收集 cur
                        ├─ rest-1 是质数    ─► 收集 cur×(rest-1)
                        └─ 枚举 p_j^2 ≤ rest 的编号段 ─► 递归 (j+1, rest÷段, cur×p^a)
 ▼
答案 {20, 26, 41} ──► 排序输出 m 与列表
```

图中三个分支分别对应：直接收尾（大质数答案）、剩余部分收尾、继续枚举指数 $\geqslant 2$ 的编号段。
只要注意到每个编号段必是 $S$ 的因子，就能理解为什么搜索空间与 $n$ 的上界无关。

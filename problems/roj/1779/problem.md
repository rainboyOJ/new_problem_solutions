### 【题目描述】

给你一个长度不超过$17$的字符串$S$，它由$0\sim 9$组成，无前导$0$。
要求求$S$中的数字排列组成的无前导零并能被$17$整除的第$K$小数。

### 【输入】

一行，一个由$0\sim 9$组成的字符串S和一个不超过$17!$的正整数$K$。

### 【输出】

一行，即第K小数。数据保证有解。

### 【输入样例】

```
2242223 2
```

### 【输出样例】

```
2242232
```

### 【提示】

【数据规模】
对于40%的数据，$|S|≤12，K≤2×10^6$。
对于100%的数据，$|S|≤17，K≤17!$。

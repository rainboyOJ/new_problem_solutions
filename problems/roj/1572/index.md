## 形式化题目

给定一个仅由小括号 `()` 与中括号 `[]` 构成的字符串 $s$。
合法括号序列（GBE）定义如下：
1. 空串是合法括号序列；
2. 若 $A$ 是合法括号序列，则 $(A)$ 与 $[A]$ 也是合法括号序列；
3. 若 $A$ 与 $B$ 都是合法括号序列，则拼接串 $AB$ 也是合法括号序列。

求在原串中插入最少数量的字符，使其变为合法的括号序列。

## 正解

### 思路

根据合法括号序列的归纳定义，任何非空的合法括号串只有两种基本形成形式：
1. **外层包裹**：形如 $(A)$ 或 $[A]$，即最外层的两个字符互相匹配，内部子串自身也是合法括号序列；
2. **中间拼接**：形如 $AB$，即可以从某一处断开，拆分为两个非空的合法括号序列拼接而成。

这表明子串的最优配对方案具有明显的**最优子结构**和**重叠子问题**性质，因此可以使用**区间动态规划**求解。

#### 1. 状态定义

设 $dp[i][j]$ 表示将子串 $s[i \dots j]$ 补齐为合法括号序列所需添加的最少字符数（$0 \leqslant i \leqslant j < n$）。

#### 2. 边界与初始化

- 单个字符无法自行配对，必须补上对应的另一个括号才能合法，因此：
  $$dp[i][i] = 1 \quad (0 \leqslant i < n)$$
- 当 $i > j$ 时，对应空串，代价为 $0$。在实现中未访问的位置默认初始化为 $0$ 即可。

#### 3. 状态转移

对于区间 $[i, j]$（长度 $len \geqslant 2$）：
1. **两端匹配**：若两端字符 $s[i]$ 与 $s[j]$ 能够闭合配对（即 `(` 与 `)`，或 `[` 与 `]`），则可以利用这两个字符作为最外层括号，代价等于内部子串 $s[i+1 \dots j-1]$ 的代价：
   $$\text{cost} = dp[i+1][j-1]$$
   若两端不配对，则置为 $+\infty$。
2. **区间分割**：考虑将区间在位置 $k$（$i \leqslant k < j$）切分成两半，分别补齐后再拼接：
   $$\text{split\_cost} = \min_{i \leqslant k < j} \{dp[i][k] + dp[k+1][j]\}$$
   *注：当 $k = i$ 时，$dp[i][i] + dp[i+1][j] = 1 + dp[i+1][j]$，即单独为左端点字符补齐一个配对；当 $k = j-1$ 时同理。因此单侧补齐的情况已被分割点枚举完全覆盖。*

综合上述两种转移方式，状态转移方程为：
$$dp[i][j] = \min \left( \text{cost}, \min_{i \leqslant k < j} \{dp[i][k] + dp[k+1][j]\} \right)$$

按区间长度由小到大递推计算，最终答案即为 $dp[0][n-1]$（若原串为空串则答案为 $0$）。

### 复杂度

- **时间复杂度**：共有 $O(n^2)$ 个子区间状态，计算每个状态需要枚举 $O(n)$ 个分割点，总时间复杂度为 $O(n^3)$。对于 $n < 100$，运算量约在 $1.6 \times 10^5$ 次量级，能在几十毫秒内完成。
- **空间复杂度**：需要维护一个大小为 $n \times n$ 的二维 DP 数组，空间复杂度为 $O(n^2)$。

## 总结

- 本题是区间动态规划的经典入门问题，核心在于抓住合法括号序列的递归定义：要么最外层两端闭合匹配，要么中间存在分割点拼接。
- 将两端字符匹配作为直接继承转移，将所有可能的分割点合并作为区间松弛，涵盖了所有最小补齐方案。

## 图示解析

以样例输入 `[])`（长度为 $3$，$s[0]=\text{`[`}, s[1]=\text{`]`}, s[2]=\text{`)`}$）为例说明 DP 表的填表与转移过程：

```
       j=0     j=1     j=2
       '['     ']'     ')'
i=0 '['  1       0       1
i=1 ']'  -       1       2
i=2 ')'  -       -       1
```

- **长度 1**：$dp[0][0]=1, dp[1][1]=1, dp[2][2]=1$。
- **长度 2**：
  - $s[0 \dots 1] = \text{`[]`}$：$s[0]$ 与 $s[1]$ 匹配，两端代价为 $dp[1][0]=0$；分割点 $k=0$ 时代价为 $dp[0][0]+dp[1][1]=2$。取最小值得到 $dp[0][1]=0$。
  - $s[1 \dots 2] = \text{`])`}$：两端不匹配，分割点 $k=1$ 代价为 $dp[1][1]+dp[2][2]=1+1=2$。因此 $dp[1][2]=2$。
- **长度 3**：
  - $s[0 \dots 2] = \text{`[])`}$：两端 `[` 与 `)` 不匹配，枚举分割点：
    - $k=0$：$dp[0][0] + dp[1][2] = 1 + 2 = 3$；
    - $k=1$：$dp[0][1] + dp[2][2] = 0 + 1 = 1$。
    - 取最小值得到 $dp[0][2] = 1$。

只需在最右侧补齐一个小括号 `(` 变成 `[]()`，增加 $1$ 个字符即满足条件。

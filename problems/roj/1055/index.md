## 形式化题目

给定整数 $a$（$0 < a < 3000$），按公历（格里高利历）规则判断公元 $a$ 年是否为闰年，是输出 `Y`，否输出 `N`。

样例：$a = 2006$，不被 4 整除，输出 `N`。

## 正解

### 思路

公历闰年规则是一条「特例链」：

1. 不是 4 的倍数 → 平年；
2. 是 4 的倍数、但不是 100 的倍数 → 闰年；
3. 是 100 的倍数（整百年）、但不是 400 的倍数 → 平年；
4. 是 400 的倍数 → 闰年。

写成嵌套 `if` 就是标准写法：先判 `a % 4`，再判 `a % 100`，最后判 `a % 400`。它的判断顺序是固定的，因此四层嵌套可以原样合并成一个布尔表达式：

$$
a \bmod 4 = 0 \ \land\ \bigl(a \bmod 100 \neq 0 \ \lor\ a \bmod 400 = 0\bigr)
$$

`and`/`or` 的短路求值顺序与嵌套 `if` 完全一致，逻辑等价。用几个典型年份核对这条判定式：

| 年份 | ÷4 | ÷100 | ÷400 | 判定式结果 | 输出 |
| --- | --- | --- | --- | --- | --- |
| 2004 | ✓ | ✗ | ✗ | 真 | Y |
| 2006 | ✗ | ✗ | ✗ | 假 | N |
| 1900 | ✓ | ✓ | ✗ | 假 | N |
| 2000 | ✓ | ✓ | ✓ | 真 | Y |

表格中列是年份 $a$ 对 4、100、400 的整除性与最终输出。注意 1900 与 2000 这两行：整百年必须再看能否被 400 整除，这是本题最容易判错的地方。

本题考查的是把闰年规则的三层特例（4 的倍数、100 的例外、400 的再例外）翻译成正确的条件判断。把嵌套分支压成一个短路布尔表达式后，判断顺序不变、代码更短；易错点只在整百年（1900 是平年、2000 是闰年）。纯分支判断题，无图示解析需求，判定式与核对表已在思路中给出。

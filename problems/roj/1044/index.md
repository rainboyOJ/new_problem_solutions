## 形式化题目

给定一个正整数 $n$，判断命题

$$10 \leqslant n \leqslant 99$$

是否成立：成立输出 $1$，否则输出 $0$。

样例 $n = 54$ 落在区间内，输出 $1$。

## 正解

### 思路

这道题只有一次区间判定，没有值得单独教一层暴力的算法瓶颈——把 C++ 的写法直译过来
就已经是最优解了。本文重点放在**用 Python 表达这个判定**：题面那句话
"大于等于 10 且小于等于 99"怎样写成最短、且不失可读性的代码。

先看上游的参考实现，它是 C++ 的常规写法：

```cpp
cin >> n;
if (n >= 10 && n <= 99) cout << 1 << endl;
else                    cout << 0 << endl;
```

这里花了三样东西：`&&` 连接的两个单边比较、一个 `if/else`、两次 `cout`。
把这段直译成 Python，会写成

```python
if n >= 10 and n <= 99:
    print(1)
else:
    print(0)
```

正确，但把 Python 当 C++ 写了。可以逐步折叠掉两处冗余。

**第一处折叠：`and` 的两个比较合成一次链式比较。** 两个比较只是同一个区间
$[10, 99]$ 的两半，端点被拆开写、变量 $n$ 出现两次。Python 允许把区间**一次性**写成

```python
10 <= n <= 99
```

这是 Python 特有的链式比较语法糖：`a <= b <= c` 求值为 `(a <= b) and (b <= c)`，
**不是** `(a <= b) <= c` 那种布尔算术。所以它就是题面那句话的直译——"10 不大于 $n$、
并且 $n$ 不大于 99"——中间操作数 $n$ 只求值一次，端点各出现一次，
读者一眼就能看出被判断的是哪个区间。

**第二处折叠：`if/else` 换成 `int(bool)`。** 两个分支做的事完全相同：把同一个真值
写成两种字面量。而在 Python 里 `bool` 是 `int` 的子类，`True == 1`、`False == 0`，
所以"真值 $\to$ 0/1"这一步本身就是一次类型转换，不需要分支：

```python
int(10 <= n <= 99)
```

这一行同时完成了"求命题"和"转成题面要求的输出格式"，四行的 `if/else` 收缩成一次调用。

**读入部分**：输入只有一个整数，用 `int(sys.stdin.buffer.read())` 一次读完并解析即可。
`int()` 自身会忽略字节串两端的空白与换行（`int(b'54\n')` 得 `54`），所以既不
需要 `strip()`，也不需要 `split()`。这与本仓库其它固定输入格式的题
（如 [ROJ 1000](../1000/index.md)）使用同一条"一次读完 → 解析 → 处理"的链路，
只是 token 只有一个时可以更短。

于是判定部分只剩 `int(10 <= n <= 99)` 这一个表达式，其余的只剩读入与输出两端的管道；
完整的可提交代码见下方的 `### 代码`。

判定成立与否只取决于 $n$ 落在 $[10, 99]$ 的哪一侧，用一张边界表核对：

| $n$ | $10 \leqslant n$ | $n \leqslant 99$ | 命题 | 输出 |
| --- | --- | --- | --- | --- |
| $9$ | 假 | 真 | 假 | `0` |
| $10$ | 真 | 真 | 真 | `1` |
| $54$ | 真 | 真 | 真 | `1` |
| $99$ | 真 | 真 | 真 | `1` |
| $100$ | 真 | 假 | 假 | `0` |
| $164$ | 真 | 假 | 假 | `0` |

这张表说明两端点都必须用 `<=` 才会把 $10$ 和 $99$ 算作两位数，并且
"大于 99"与"小于 10"两类错误答案分别由两个比较拦住，缺一不可。
真实数据里 $164, 159, 141, 106, 151, 133, 111, 198$ 走的是右侧为假的分支，
$69, 81$ 走的是两侧都为真的分支，$0/1$ 两种输出都被覆盖到。

### 复杂度

- 时间复杂度：$O(1)$，输入长度固定，一次解析、两次比较、一次输出，与 $n$ 的大小无关。
- 空间复杂度：$O(1)$，只保存输入字节串与一个整数。

## 总结

- 本题没有算法瓶颈，要练的是**表达**：题面那句"大于等于 10 且小于等于 99"
  在 Python 里就是一条链式比较 `10 <= n <= 99`，`and` 不必写。
- 链式比较是语法糖而非布尔算术：`a <= b <= c` 等价 `a <= b and b <= c`，
  中间操作数只求值一次。
- `bool` 是 `int` 的子类，`True`/`False` 天然就是 $1$/$0$，
  用 `int(...)` 把判定结果直接变成题面要求的输出，省掉 `if/else` 两个分支。
- 单 token 输入可以一步 `int(read())`：`int()` 会忽略两端空白与换行；
  多 token 输入再退回 `read()` → `split()` → `map(int, ...)` → 解包的链路。
- 验证：真实测试数据 10/10 全部 PASS（约 0.015 s/组，峰值内存 14.5 MB，
  限额 1000 ms / 128 MB），并手工补测端点 $9/10/54/99/100/1000$，
  输出依次为 `0/1/1/1/0/0`。

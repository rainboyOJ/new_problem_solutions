## 形式化题目

给定一年 12 个月的预算序列 $b_1, b_2, \dots, b_{12}$。初始手中现金 $h = 0$，存在妈妈那里的存款 $s = 0$。按 $m = 1, 2, \dots, 12$ 依次执行：

1. 月初拿到零花钱：$h \leftarrow h + 300$；
2. 若 $h < b_m$（手中现金不够本月预算，且存款不可动用），输出 $-m$ 并停止；
3. 按预算花完：$h \leftarrow h - b_m$，得到本月结余；
4. 若结余 $h \geqslant 100$，把其中的整百存入妈妈处：$s \mathrel{+}= \lfloor h / 100 \rfloor \times 100$，$h$ 只留下 $h \bmod 100$ 的零头。

若 12 个月全部通过，输出年末结算总额

$$h + s + 0.2s = h + \tfrac{6}{5}s.$$

注意两个时序：**判断在花钱之前**（只能用手中的现金），**存款在花钱之后**（存的是花完的结余）。

## 正解

### 思路

题面本身就是一份按月推进的操作说明，把它直译成代码就是正解：12 次固定迭代、两个整数状态，没有任何搜索或重复子问题，也就没有值得单独写的"暴力层"。真正要推敲的是三处等价改写，它们让代码更短也更不易错。

**其一，把"预计月末结余 $\geqslant 100$ 才存"化进整除表达式。** 先减预算得到结余，再无条件执行 `deposit = hand // 100 * 100`：结余小于 100 时整除结果本来就是 0，等于自动"不存"；结余恰为 100 的倍数时正好整存。条件分支消失了，语义完全一致。

**其二，利息用整数整除。** 每笔存款都是 100 的倍数，累计 $s$ 也是 100 的倍数，所以 $0.2s = s / 5$ 恒为整数，写成 `saved // 5` 精确无误差；用 `saved * 1.2` 反而要处理浮点转整数的格式问题。

**其三，第一个出问题的月份立刻 `return`。** 题目只要求第一个 $m$，后续月份无需再算。

用样例 2（输出 1580）走一遍完整轨迹，列含义：**月初** 是加完 300 后的可支配现金，**结余** 是花完预算后的钱，**存入** 是转走的整百，**剩余** 和 **存款** 是循环结束时的 $h$、$s$：

## 总结

这是一道顺序模拟题：状态只有手中现金 $h$ 和存款 $s$，按"加 300 → 判够不够 → 花预算 → 存整百"四步推进 12 次即可。写对它的关键是把握两个时序（判断在花钱前、存款在花钱后）和两处等价改写（结余条件化进 `// 100 * 100`、20% 利息化进 `// 5`），全程整数运算，第一个违约月份立即输出 $-m$，否则输出 $h + s + s // 5$。

## 形式化题目

给定正整数 $a$、$b$、$m$（均不超过 $10^9$），求

$$
a^b \bmod m
$$

的值，即 $a$ 的 $b$ 次幂除以 $m$ 的余数。

## 正解

### 思路

#### 1. 先看两条不可行的朴素做法

最直接的写法是先算出精确幂再取模：

```python
print(a ** b % m)   # 不可行
```

Python 的 `**` 确实是快速幂，但它工作在**不取模**的整数环上，最后得到的整数有 $b\log_{10}a$ 位十进制数字。$b$ 最大 $10^9$，即使取 $a = 2$，$2^{10^9}$ 也有约 $3\times 10^8$ 位十进制数字，折合 $\lfloor b\log_2 a\rfloor + 1 = 10^9$ 个二进制位（约 119 MB 连续内存），远超 128 MB 限制；而且 CPython 对超大整数的十进制转换还有 4300 位的位数上限，输出阶段会直接抛错。

另一条路是逐次相乘、每次取模：

```python
ans = 1
for _ in range(b):
    ans = ans * a % m   # 不可行
print(ans)
```

取模保证数值不会膨胀，但循环次数就是 $b$，$b = 10^9$ 时必然超时。它的问题不在浮点或溢出，而在于**把指数当成了"次数"**。

#### 2. 把指数拆成二进制

注意 $a^{x+y} = a^x\,a^y$，指数可以任意切分。把 $b$ 写成二进制

$$
b = \sum_{k=0}^{L-1} \beta_k 2^k,\qquad \beta_k \in \{0, 1\},\ L = \lfloor \log_2 b\rfloor + 1 \leqslant 30,
$$

就有

$$
a^b = \prod_{k=0}^{L-1} \left(a^{2^k}\right)^{\beta_k}.
$$

也就是说，只要手里备好 $B_k = a^{2^k}$ 这一串"底数"，答案就是那些 $\beta_k = 1$ 的 $B_k$ 连乘。而这一串 $B_k$ 根本不用分别求幂——相邻两项只差一次平方：

$$
B_0 = a \bmod m,\qquad B_{k+1} = B_k^2 \bmod m.
$$

于是"指数折半"把 $b$ 次乘法压成了 $\log_2 b \leqslant 30$ 轮，每轮只做一次平方和至多一次乘法。又因为 $(xy) \bmod m = \big((x \bmod m)(y \bmod m)\big) \bmod m$，每一步都能立刻取模，中间值始终小于 $m^2 \leqslant 10^{18}$，不会膨胀。

#### 3. 样例推演

以样例 $a=2,\ b=100,\ m=1007$ 为例，$100 = (1100100)_2$，从最低位 $k=0$ 扫到 $k=6$：

| $k$ | $\beta_k$ | 当前底数 $B_k$ | 是否乘入答案 | 累乘结果 `ans` |
| --- | --- | --- | --- | --- |
| 0 | 0 | 2 | 否 | 1 |
| 1 | 0 | 4 | 否 | 1 |
| 2 | 1 | 16 | 是 | 16 |
| 3 | 0 | 256 | 否 | 16 |
| 4 | 0 | 81 | 否 | 16 |
| 5 | 1 | 519 | 是 | 248 |
| 6 | 1 | 492 | 是 | **169** |

观察重点：每一行的底数都等于上一行底数的平方模 1007（例如 $256^2 = 65536$，$65536 \bmod 1007 = 81$），所以"下一位要用的底数"是免费递推出来的，不需要重新求幂；整列里只有 $\beta_k = 1$ 的三行真正改动了 `ans`。最终 `ans` $=169$，与样例输出一致。

#### 4. Python 落地

Python 内建的三参数 `pow(a, b, m)` 正是上面这套二进制快速幂：它在内部按位平方乘、每一步取模，返回值一定落在 $[0, m)$ 内，而运行时间只与 $\log_2 b$ 有关，与 $b$ 本身的数值无关。所以本题不需要手写循环，一行即可。

等价的手写版本如下，便于对照理解上面的推导（正式代码使用内建 `pow`）：

```text
ans  = 1
base = a mod m
while b > 0:
    if b 的最低位是 1:
        ans = ans * base mod m
    base = base * base mod m
    b >>= 1
```

### 复杂度

- 时间复杂度：$O(\log b)$。循环轮数等于 $b$ 的二进制位数，$b \leqslant 10^9 < 2^{30}$ 时不超过 30 轮，每轮一次平方乘和至多一次乘法。对比朴素连乘的 $O(b)$，在 $b = 10^9$ 时相差约 $3\times 10^7$ 倍。
- 空间复杂度：$O(1)$。只用常数个整数变量，中间结果均小于 $m^2 \leqslant 10^{18}$；对比"先算精确幂再取模"需要的 $O(b\log a)$ 位存储（GB 量级），这里完全不占额外空间。

## 总结

本题是"大指数取模"的最基础形态。它的全部内容是两条性质：指数可加（$a^{x+y} = a^xa^y$）带来二进制拆分，模运算对乘法封闭（$(xy)\bmod m = ((x\bmod m)(y\bmod m))\bmod m$）保证中间值不膨胀。二者合起来把 $O(b)$ 次乘法降为 $O(\log b)$ 次，代价是 $b$ 必须先看成二进制串而非常规数字。

在 Python 中，这套算法就是标准库的三参数 `pow(a, b, m)`，应直接使用，不要写成 `a ** b % m`——后者虽然语法合法，却会在 $b$ 很大时因构造出天文数字般的中间整数而耗尽内存。

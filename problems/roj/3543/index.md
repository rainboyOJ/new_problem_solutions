## 形式化题目

给定一个关于变量 $a$ 的代数表达式 $E$，以及 $n$（$2 \leqslant n \leqslant 26$）个表达式 $E_1, \dots, E_n$。每个表达式由变量 `a`、小于 $10000$ 的正整数常量、运算符 `+ - * ^` 和括号组成，长度不超过 $50$，且可能含任意多的空格。运算优先级为 `^` $>$ `*` $>$ `+`/`-`，`+` 与 `-` 同级，**同优先级一律从左到右结合**（包括 `^`）；`^` 的指数是 $1$ 到 $10$ 的正整数。

要求找出所有与 $E$ **恒等**（对任意 $a$ 取值都相等）的 $E_i$，按字母序输出它们的标号 `A, B, C, …`（无分隔符）。数据保证至少存在一个等价选项。

## 正解

### 思路

**朴素做法**是把每个表达式按 $a$ 的幂展开成多项式，再逐项比较系数。但 `^` 的指数最高 $10$，乘方还能套乘方（如 $(a-6)^{10^{10}}$），展开后的系数动辄上百位，多项式乘法写起来又长又容易错。

**为什么可以只代入几个点？** 判断恒等其实不需要完整的多项式：把 $E - E_i$ 看成一个关于 $a$ 的多项式 $f$，它是零多项式当且仅当处处取值为 $0$。反过来，只要 $f$ 不是零多项式，它的根就严格少于它的次数加一个。本题中表达式次数最高也就几十到一百量级，所以**随便挑几个不同的 $a$ 值分别代入两边求值**，四次取值全部相等才认定等价，就足以把数据里所有不恒等的式子对区分开——这就是"多点代入判定恒等"的思想。

剩下的只是**对一个具体数值求表达式的值**。用经典的递归下降，按优先级分四层文法，每层一个函数：

```text
expr  := term  ( (+|-) term )*      ← 加减层，从左到右累加
term  := power ( * power )*         ← 乘层，从左到右连乘
power := atom  ( ^ atom )*          ← 幂层，左结合！2^3^2 = 64
atom  := a | ( expr ) | 数字        ← 变量代入 x，括号递归回 expr
```

每层用 `while` 循环"吃掉"同优先级的后续运算符，天然实现左结合；`a` 直接返回代入值 $x$。空格在读入后统一删掉。Python 的大整数让 $(a-6)^{10^{10}}$ 这类天文数字也能精确求值，完全不需要担心溢出。

以样例 `10 + (1 - a) + (a + 8) - (9 - 8)` 代入 $a=2$ 为例，求值过程就是一棵自底向上折叠的表达式树：

| 层 | 片段 | 计算过程 | 结果 |
| --- | --- | --- | --- |
| atom | `a` | 代入 $x=2$ | $2$ |
| expr | `(1 - a)` | $1-2$ | $-1$ |
| expr | `(a + 8)` | $2+8$ | $10$ |
| expr | `(9 - 8)` | $9-8$ | $1$ |
| expr | 整体 | $10+(-1)+10-1$ | $18$ |

而选项 `10+8` 代入 $a=2$ 得 $18$，四次代入全对上，所以它和题干等价（样例输出 `IJ`）。

### 复杂度

设表达式长度上界 $L=50$。单次求值时每个字符只被扫描一次，为 $O(L)$；每个选项代入 $4$ 个点，共 $n+1 \leqslant 27$ 个表达式，总计算量约 $27 \times 4 \times 50 = 5400$ 次字符操作，远低于 $1\text{s}$ 限制。空间为递归深度 $O(L)$。

## 总结

- 判断两个含变量表达式是否恒等，不必展开成多项式：挑 $4$ 个不同的 $a$ 值代入，两边取值都相等即可认定等价（不同多项式的公共根个数小于次数）。
- 求值用递归下降四层文法 `expr → term → power → atom`；`^` 是**左结合**的（`2^3^2 = 64`），这是本题最容易踩的坑。
- Python 的精确大整数让最高达 $10^{210}$ 量级的中间结果无需取模；同样的算法在 C++ 中需要对大质数取模实现。

## 图示解析

### 递归下降的分层消化

以 `(a + 1 + 5) * a ^ 2` 代入 $a = 3$ 为例，展示四层函数如何接力：

```text
expr  ──► term ──► term ──► power ──► atom ──► ( expr )     ┐
   │                                   │                   │ 括号内重新
   │                                   │                   ▼ 从 expr 开始
   │                                   │            a+1+5 = 3+1+5 = 9
   │                                   ◄── 9 ^ atom = 9 ^ 2 = 81
   │            ◄── 9 * 81 = 729  （乘层从左到右连乘）
   └──► 729
```

观察重点：`atom` 遇到 `(` 时**重新从 expr 层进入**，括号内算完返回，外层的 `power` 再继续处理 `^ 2`。乘层在两个幂 $9$ 和 $81$ 都备好后连乘——每层只关心自己优先级的运算符，优先级高的自然先算完。

## 形式化题目

$n$ 个节点的有根树，每个节点有左右孩子指针与点权。若一棵子树是二叉树且左右子树互为镜像（结构与点权对称），称其为**对称二叉树**。求节点数最多的对称二叉子树的节点数。

## 正解

### 思路

#### 1. 镜像判定

两棵子树 $a,b$ 互为镜像 $\iff$ `L[a]` 与 `R[b]` 互为镜像且 `R[a]` 与 `L[b]` 互为镜像，且对应点权相等。自底向上递推，同一节点对只算一次（记忆化）。

#### 2. 枚举中心

对每个节点作为「对称中心」，检查其左右子树互为镜像；中心也可以是点权对称的相邻两节点（按题面定义）。答案取所有成立情形的最大节点数。

递归深度可能达到 $n$，用**显式栈模拟两阶段展开**（先下探子对、回收时汇总）避免 Python 递归限制。

- 「对称子树」= 镜像同构判定 + 枚举中心，镜像关系传递成记忆化子问题。
- Python 树递归一律显式栈两阶段（下探/回收），规避递归深度与栈开销。

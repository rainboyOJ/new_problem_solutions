## 形式化题目

给定两个正整数 $A$ 与 $B$（$1 \leqslant A, B \leqslant 50000$），求它们的积 $A \times B$。

样例：输入 `3 4`，输出 `12`。

## 正解

### 思路

这道题的计算只有一步：把输入里的两个整数乘起来输出，算法上没有任何可以优化的地方——
再写一个暴力版本只会得到一模一样的代码。它真正要练的有两件事。

**第一件是乘积范围与数据类型的选择**，这也是题面专门提醒的一句话。数据范围是
$1 \leqslant A, B \leqslant 50000$，乘积最大可达

$$50000 \times 50000 = 2\,500\,000\,000 = 2.5 \times 10^9,$$

而 32 位有符号整数的上限是 $2^{31}-1 = 2\,147\,483\,647 \approx 2.147 \times 10^9$。
$2.5 \times 10^9$ 超过了它，所以 C++ 里若用 `int` 接乘积会发生溢出、得到错误答案，
必须像参考实现那样改用 `long long`。Python 的 `int` 是任意精度整数，`a * b` 直接精确，
这条坑在 Python 里天然不存在——但换语言实现时要记得它。

**第二件是把输入文本变成整数**这条链路。以样例 `3 4` 为例：

| 步骤 | 表达式 | 结果 |
| --- | --- | --- |
| 一次读入整份输入 | `sys.stdin.buffer.read()` | `b'3 4\n'` |
| 按空白切分 | `.split()` | `[b'3', b'4']` |
| 逐个转成整数 | `map(int, ...)` | `3`、`4` |
| 解包到两个名字 | `a, b = ...` | `a = 3, b = 4` |
| 相乘输出 | `print(a * b)` | `12` |

这张表说明了为什么用 `split()` 而不是手工找空格：按空白切分能把行尾换行、连续空格、
甚至"两个数分两行写"都统一处理成同一个 token 序列，代码不必关心输入的具体排版。
写成 `a, b = ...` 而不是先建列表再取下标，则是把"输入恰好是两个整数"这条格式约定
直接写进代码：万一 token 数量不是两个，程序会立刻报错，而不是悄悄算出错误答案。

### 复杂度

- 时间复杂度：$O(1)$，输入长度固定为常数，只做一次整数乘法。
- 空间复杂度：$O(1)$，只保存读入的字符串和两个整数。

## 总结

- 本题是"读入 → 单步算术 → 输出"的最小版本，算法上没有优化空间，考点是乘积范围与数据类型。
- 乘积最大 $2.5 \times 10^9$ 超过 32 位 `int` 上限：C++ 要用 `long long`，Python `int` 任意精度不溢出。
- Python 读固定个数的整数记住这条线：`read()` 读全部 → `split()` 切分 → `map(int, ...)` 转换 → 解包。
- 元组解包让"输入恰好是两个整数"这条格式约定在代码里显式可见。

## 形式化题目

给定 $N$ 个整数位置 $x_1, x_2, \dots, x_N$ 与整数 $C$（$2 \leqslant C \leqslant N$），从这些位置中选出 $C$ 个，分给 $C$ 头牛，每头牛独占一个被选中的位置。

设被选中的位置集合为 $T$（$|T| = C$），定义这组分配的最小间距为

$$f(T) = \min_{\substack{a, b \in T \\ a \neq b}} |a - b|$$

要求最大化 $f(T)$，输出这个最大值：

$$\max_{T \subseteq \{x_1, \dots, x_N\},\ |T| = C} f(T)$$

## 正解

### 思路

#### 朴素做法走不通

最直接的想法是枚举所有大小为 $C$ 的位置子集，对每个子集算出两两距离的最小值，再取最大。子集数量是 $\binom{N}{C}$，而 $N$ 最大到 $10^5$，这条路完全走不通。

换个角度：我们并不真的关心"选了哪 $C$ 个位置"，只关心"最小间距是多少"。答案一定等于某个具体的距离值，而距离值只有 $O(N^2)$ 种（所有点对之差）。于是可以**枚举答案 $d$**，从大到小逐个试探，第一个可行的 $d$ 就是答案。$N=10^5$ 时 $O(N^2)$ 个候选值乘上每次 $O(N)$ 的判定，$O(N^3)$ 依然超时。

真正的浪费在于：候选的 $d$ 有 $O(N^2)$ 个，却是**一个一个线性试过来的**，完全没有利用这些 $d$ 之间的秩序。

#### 第一步：把问题拆成"判定 $P(d)$"

先不管怎么求最优，只问一个更简单的问题——给定间距 $d$，能不能放下 $C$ 头牛？

记 $P(d)$ 表示"存在 $C$ 个位置，两两距离都 $\geqslant d$"。**注意一个关键事实：如果两头牛之间的距离要求从 $d$ 放宽到更小的 $d'$，原来合法的方案依然合法。** 所以

$$P(d) \text{ 成立} \implies \text{对一切 } d' \leqslant d,\ P(d') \text{ 也成立}$$

反过来看就是：随着 $d$ 变大，$P(d)$ 只会从真变成假，不会再变回真。也就是说，把 $d$ 从小到大排列，$P$ 一定长成一串"前面全是真、后面全是假"的形状，中间只有一个分界点——这正是我们要找的答案：

```text
d  =  1     2     3     4     5
P  = 真    真    真    假    假
                     ↑
              答案 = 3（最后一个真值）
```

#### 第二步：$O(N)$ 判定 $P(d)$ 的贪心

先给位置排序（题面不保证有序），得到 $s_1 \leqslant s_2 \leqslant \dots \leqslant s_N$。

判定 $P(d)$ 用贪心：**第一头牛放在最左边 $s_1$；之后每一头牛，放在第一个距离上一头牛至少 $d$ 的隔间上。**

```text
s = 1  2  4  8  9      d = 3
    ↑
  第1头放这里
        ↑        ↑
      4-1=3≥3   8-4=4≥3
      第2头      第3头       → 放下 3 头，P(3) 成立
```

为什么贪心是对的：每头牛都尽量往左压，等于把右侧的空间尽可能多地留给还没安排的牛。如果连这种"最省地盘"的排法都塞不下 $C$ 头，那么任何其它排法（每头牛的位置都更靠右）只会让后面更没地方可放。

严格的交换论证：设最优解的选点为 $o_1 < o_2 < \dots < o_C$，贪心选点为 $g_1 < g_2 < \dots$。对 $j$ 归纳可证 $g_j \leqslant o_j$：基础是 $g_1 = 1 \leqslant o_1$；若 $g_j \leqslant o_j$，由 $s_{o_{j+1}} - s_{o_j} \geqslant d$ 与 $s_{o_j} \geqslant s_{g_j}$ 得 $s_{o_{j+1}} \geqslant s_{g_j} + d$，即 $o_{j+1}$ 是一个"距离 $s_{g_j}$ 至少 $d$"的下标，而 $g_{j+1}$ 取的是满足该条件的**最小**下标，故 $g_{j+1} \leqslant o_{j+1}$。于是贪心选出的牛数不少于任何合法解，贪心放得下 $C$ 头当且仅当 $P(d)$ 成立。

#### 第三步：二分代替枚举

既然 $P$ 是"前真后假"的单调阶梯，就完全不必逐个试 $d$。直接在答案的取值区间 $[lo, hi]$ 上二分：

- 取中点 $mid = \lfloor (lo + hi + 1)/2 \rfloor$（**上取整**）；
- 用贪心判定 $P(mid)$：真则答案不小于 $mid$，令 $lo = mid$；假则答案小于 $mid$，令 $hi = mid - 1$；
- 区间每轮减半，循环到 $lo = hi$ 即得答案。

之所以取上取整，是因为可行时执行的是 `lo = mid`：若用下取整，当 $hi = lo + 1$ 时会出现 $mid = lo$，$lo$ 永不前进而死循环。

区间端点这样定：

- 左端 $lo = 1$；
- 右端 $hi = \left\lfloor \dfrac{s_N - s_1}{C-1} \right\rfloor$。因为 $C$ 头牛两两距离 $\geqslant d$ 时，首尾两头至少隔开 $(C-1)d$，而首尾距离不会超过总跨度 $s_N - s_1$；又 $C \geqslant 2$ 保证分母非零。这个上界恒不小于答案，却比硬套 $10^9$ 小得多，能明显减少二分轮数。

#### 一个容易踩的边界：位置可以重复

题面只写 $0 \leqslant x_i \leqslant 10^9$，**并没有承诺位置互不相同**。而上面把左端点定在 $1$，隐含假设了"总能放下 $C$ 头牛且间距至少为 1"。

当**不同位置的个数小于 $C$** 时这个假设就不成立了：此时必然至少有两头牛共处一个隔间，最小距离只能是 $0$，而 $[1, hi]$ 的二分区间根本覆盖不到 $0$，程序会错答成 $1$。

修复只需在二分前补一次检查：

```python
if len(set(stalls)) < c:   # 不同位置不够 c 个，必有两头牛同处一室
    print(0)
    return
```

值得一提的是，本题 10 个官方数据文件的 $x_i$ 恰好全部互不相同，所以不加这个检查也能通过官方数据；但那是数据的巧合，不是算法的正确性。

### 复杂度

- 排序：$O(N \log N)$。
- 二分的轮数：$O(\log V)$，其中 $V = \left\lfloor (s_N - s_1)/(C-1) \right\rfloor \leqslant 10^9$。
- 每次判定：$O(N)$，单趟扫描。

总时间复杂度 $O(N \log N + N \log V)$，空间复杂度 $O(N)$。

$N = 10^5$ 时最慢测例实测约 0.05 s、峰值内存约 31 MB，远低于 1000 ms / 128 MB 的限制。

## 总结

本题的核心不在"选哪些隔间"，而在于两点：

1. **把最优化转成判定**。"最大化最小距离"直接枚举子集是指数级的；一旦改问"给定 $d$ 能不能放下 $C$ 头牛"，就得到一个 $O(N)$ 的贪心判定。
2. **用单调性把枚举换成二分**。判定问题的可行性关于 $d$ 单调（放宽要求只会更容易），于是"最大的可行 $d$"就是单调阶梯的最后一个真值，一次二分 $O(\log V)$ 解决。

这套"**最大值最小 / 最小值最大 → 二分答案 + 贪心判定**"是竞赛里的通用套路：只要判定函数关于答案单调，且判定本身足够快，就能把 $O(\text{值域} \times \text{判定})$ 压到 $O(\log \text{值域} \times \text{判定})$。本题的判定格外简单——排序后从左往右"能放就放"。

## 图示解析

下面用样例 $N=5, C=3$，位置排序后为 $1, 2, 4, 8, 9$，走一遍从枚举到二分的完整路线。

```text
          位置集合 {1, 2, 4, 8, 9}, 要选 3 个
                        │
          ┌─────────────┴─────────────┐
          │ 枚举 C 个位置的子集        │  C(5,3)=10 组，N 大时爆炸
          │ 对每组算两两距离最小值     │
          └─────────────┬─────────────┘
                        │
                 改问判定问题 P(d)
                        │
          ┌─────────────┴─────────────┐
          │ 排序后贪心：第一头放最左    │  O(N)
          │ 之后每头放第一个够远的位置  │
          └─────────────┬─────────────┘
                        │
             P 关于 d 单调（前真后假）
                        │
          ┌─────────────┴─────────────┐
          │ 在 [1, (s5-s1)/(C-1)] 二分  │  O(log V) 轮
          │ lo=mid(真) / hi=mid-1(假)   │
          └─────────────┬─────────────┘
                        │
                    答案 = 3
```

样例上逐个 $d$ 的判定结果如下。注意"贪心放下的牛数"和 $P(d)$ 的真假只在 $d=4$ 处翻转一次，这就是单调性的直观体现。

| 候选间距 $d$ | 贪心放下的牛数 | $P(d)$ | 落点位置 |
| --- | --- | --- | --- |
| 1 | 5 | 真 | 1, 2, 4, 8, 9 |
| 2 | 3 | 真 | 1, 4, 8 |
| 3 | 3 | 真 | 1, 4, 8 |
| 4 | 2 | 假 | 1, 8 |
| 5 | 2 | 假 | 1, 8 |

下面是把 $d = 3$ 的贪心判定逐格展开，展示"能放就放、且放最左"的执行细节。

| 扫到隔间 | 与上一头牛的距离 | 是否落点 | 落点后基准位置 | 已放牛数 |
| --- | --- | --- | --- | --- |
| 1 | —（首头） | 是 | 1 | 1 |
| 2 | 1 | 否（$1 < 3$） | 1 | 1 |
| 4 | 3 | 是（$3 \geqslant 3$） | 4 | 2 |
| 8 | 4 | 是（$4 \geqslant 3$） | 8 | 3 |
| 9 | 1 | 否（$1 < 3$） | 8 | 3 |

扫描结束时放下了 3 头，满足 $C = 3$，所以 $P(3)$ 为真。其中隔间 2 因为离已落点的 1 号位只有 1 而被跳过，这正是贪心"不浪费左侧空间"的体现：若第一头牛不是压在 1 而是从 2 出发，同样的规则只能得到 $\{2, 8\}$ 两头牛，$P(3)$ 就会失败。可见"每头牛都放最左"直接决定了判定结果。

## 形式化题目

给定正整数 $m$ 和长度为 $n$ 的序列对 $(a_i, b_i)$，把下标序列 $1, 2, \dots, n$ 切成连续的若干段。
设划分为 $[l_1, r_1], [l_2, r_2], \dots, [l_k, r_k]$（$l_1 = 1$、$r_k = n$、$l_{t+1} = r_t + 1$），要求

- **条件①**：若 $i < j$ 且 $i$、$j$ 不在同一段中，则 $b_i > a_j$；
- **条件②**：$\displaystyle\sum_{t=1}^{k} \max_{l_t \le i \le r_t} a_i \le m$。

在所有满足条件的划分中，最小化

$$\max_{1 \le t \le k} \sum_{i = l_t}^{r_t} b_i .$$

数据范围：$n \le 10^5$，$m \le 10^{12}$，$1 \le a_i, b_i \le 2 \times 10^9$。

> **关于题面的一处残缺**：素材源 `content.md` 中条件①被写成「① 若$ia_j$。」，
> 显然是被网页渲染吞掉了尖括号内容。结合条件②的写法与本题的原始出处，它应当是
> 「若 $i < j$ 且 $i$、$j$ 不在同一段中，则 $b_i > a_j$」。下文按这个补全后的表述分析与实现。

## 正解

### 思路

直接枚举所有划分方案是指数级的，但「最小化最大值」这个目标形状提示我们**二分答案**：
二分「每段 $b$ 之和的上限」$X$，问题变成判定题——

> 在「每段 $b$ 之和 $\le X$」的前提下，所有合法划分中 $\sum \max(a)$ 的**最小值**是否 $\le m$？

于是有两件事要解决：合法划分怎么刻画（条件①），以及判定怎么做得够快（条件② + 单调性）。

#### 第一步：合法切点的刻画

先只看条件①。划分只由**切点**决定，记「切在 $c$ 与 $c+1$ 之间」为切点 $c$。关键观察是：

$$c \text{ 是合法切点} \iff \min_{i \le c} b_i > \max_{j > c} a_j .$$

- **（$\Longleftarrow$）** 设对**每个**切点 $c'$ 都有 $\min_{i \le c'} b_i > \max_{j > c'} a_j$。
  取分属不同两段的 $i < j$，则必有某个切点 $c$ 满足 $i \le c < j$（两段之间一定切过一刀）。
  由 $i \le c$ 得 $\min_{i' \le c} b_{i'} \le b_i$，由 $j > c$ 得 $a_j \le \max_{j' > c} a_{j'}$，
  于是 $b_i \ge \min_{i' \le c} b_{i'} > \max_{j' > c} a_{j'} \ge a_j$，条件①成立。
- **（$\Longrightarrow$）** 反证：若条件①成立而某切点 $c$ 使
  $\min_{i \le c} b_i \le \max_{j > c} a_j$，取 $i^\* = \arg\min_{i \le c} b_i$、$j^\* = \arg\max_{j > c} a_j$，
  则 $i^\* \le c < j^\*$，二者分属 $c$ 两侧、必在不同段中，而 $b_{i^\*} \le a_{j^\*}$，与条件①矛盾。

结论：**每个切点可以独立判定是否合法，合法切点集合唯一确定**，与划分方案无关。用一遍 $O(n)$ 的前缀 $\min$ 与后缀 $\max$ 就能求出所有合法切点。于是把所有合法切点强制切开，得到若干「**原子段**」：每段记录

$$A_t = \max a, \qquad B_t = \sum b .$$

任何合法划分都恰好是把**连续若干原子段合并成一块**，块与块之间只使用合法切点。这一步把问题彻底简化了。

#### 第二步：判定 DP 及其优化

固定 $X$。设 $dp[i]$ 为「把前 $i$ 个原子段合法分块、每块 $B$ 之和 $\le X$」时 $\sum \max(A)$ 的最小值，则

$$dp[i] = \min_{L_i - 1 \le j \le i-1} \bigl\{\, dp[j] + \max_{j+1 \le t \le i} A_t \,\bigr\},$$

其中 $L_i$ 是使 $PB_i - PB_{L_i-1} \le X$ 的最小起点（$PB$ 为 $B$ 的前缀和；若 $B_i > X$ 则该 $X$ 直接不可行，
这也是二分下界必须取 $\max B_t$ 的原因）。目标是比较 $dp[s] \le m$。

朴素转移是 $O(s^2)$。两条单调性让它可以降到 $O(s \log s)$：

1. **$dp$ 单调不降**。因为 $A_t \ge 1$，把前缀 $i+1$ 的某个划分的最后一段去掉末尾那个原子段，
   留下的仍是前缀 $i$ 的合法划分且代价不增，故 $dp[i+1] \ge dp[i]$。
2. **后缀最大值是阶梯**。固定 $i$，让 $j$ 从 $i-1$ 往左走，$\max_{j+1 \le t \le i} A_t$ 单调不降、分段恒定，
   每次突变对应 $A$ 在这段区间里的一个「前缀最大位置」。用一个 **$A$ 值严格递减的单调队列**维护这些位置。

两者一碰就有结论：**在同一个阶梯平台上，$\max$ 是常数，而 $dp$ 单调不降，所以最优的转移点一定是该平台最左端**。
于是不需要线段树：队列中相邻两个元素 $q_{k-1}, q_k$ 界定一个阶梯（平台范围 $(q_{k-1}, q_k]$），该阶梯的
最优转移值是 $dp[q_{k-1}] + A[q_k]$。把这些值丢进一个可重集（C++ 的 `multiset`、Python 用惰性堆模拟）即可 $O(\log s)$ 取全局最小。

细节是**队首阶梯的左端点不是队列前驱，而是随窗口滑动的游标 $L_i - 1$**（它左端可以一直延伸到窗口边界），
所以队首阶梯的候选值单独现算：$dp[L_i-1] + A[q_0]$。相应地：

- 队尾被 $A_i$ 压住的元素（$A \le A_i$）永久出队：$A_i$ 更大且更靠右，它再也不会成为任何后缀的最大值；
- 队首元素滑出窗口（$q_0 < L_i$）时出队，**此时新的队首要从可重集里摘掉它的旧候选值**——
  因为它从「有前驱」变成了「队首」，最优左端点改由游标 $L_i - 1$ 决定，必须去掉旧的、改用现算的。

于是

$$dp[i] = \min\bigl(\, dp[L_i - 1] + A[q_0],\ \min(\text{可重集}) \,\bigr).$$

外层对 $X$ 在 $[\max B_t,\ \sum B_t]$ 上二分，总复杂度 $O(n \log n \log \sum b)$。

### 样例走一遍

以题面样例 $n = 4$、$m = 6$、$(a,b) = (4,3),(3,5),(2,5),(2,4)$ 为例。

前缀 $\min b$：$3, 3, 3, 3$；后缀 $\max a$（$c$ 之后部分）：$\max(3,2,2) = 3$、$\max(2,2) = 2$、$2$。
于是切点 $c=1$：$3 > 3$ 不成立；$c=2$：$3 > 2$ 成立；$c=3$：$3 > 2$ 成立。
合法切点为 $2, 3$，压缩后原子段为

| 原子段 | 元素 | $A$ | $B$ |
| --- | --- | --- | --- |
| 1 | $(4,3),(3,5)$ | 4 | 8 |
| 2 | $(2,5)$ | 2 | 5 |
| 3 | $(2,4)$ | 2 | 4 |

于是 $X = 9$ 时把原子段分成「1 ｜ 2,3」两块：两块 $B$ 之和分别为 $8$ 和 $9$，都 $\le 9$，
且 $\sum \max(A) = 4 + 2 = 6 \le m = 6$，所以 $X = 9$ 可行。

而 $X = 8$ 时：原子段 $1 \vert 2 \vert 3$ 三块分开才满足 $B$ 约束（$2$ 与 $3$ 合并后 $B = 9 > 8$，
$1$ 与 $2$ 合并后 $B = 13 > 8$，三块合并 $B = 17 > 8$），此时 $\sum \max(A) = 4 + 2 + 2 = 8 > 6$，
所以 $X = 8$ 不可行。故答案为 $9$，与样例一致。

### 复杂度

- **时间**：设原子段数 $s \le n$。单次判定中双指针、单调队列各 $O(s)$，可重集的插入/删除各有
  常数次 $O(\log s)$，故 $O(s \log s)$；外层二分 $O(\log \sum b) \le 61$ 次。
  总计 $O(n \log n \log \sum b)$，$n = 10^5$ 时在 C++ 上实测最坏点 0.4 s（时限 3000 ms）。
- **空间**：$O(n)$（原数组、原子段数组、DP、队列、可重集），实测峰值 8.3 MB，远低于 256 MB。
- **Python 侧**：算法与 C++ 同阶（单调队列 + 惰性堆 + 二分），同样跑满 10 个点；
  最大点约 3.1 s，与 C++ 的 0.4 s 是同一量级的常数差异，其余点均在 0.1 s 内。

## 总结

- **切点合法性可以被「逐点」判定**：条件①看起来是任意两元素之间的大范围约束，但它等价于
  「对每个切点 $c$，前缀 $b$ 最小值 > 后缀 $a$ 最大值」。一旦意识到合法切点集合与划分方案无关，
  问题就从「搜索划分」变成「在固定切点集合上合并块」。
- **$dp$ 单调不降 + 后缀最大值阶梯** 是这题的真正破局点：单调性把「区间取 min」变成「每个阶梯只取最左端」，
  于是可重集（`multiset` / 惰性堆）就够了，不必上线段树。
- **坑点**：二分下界必须取 $\max B_t$（否则某个原子段自身就超限，双指针会把 $L$ 推过 $i$）；
  可重集删除必须按迭代器删单个而不是按值删全部（C++ 用 `ms.erase(ms.find(v))`；
  Python 没有可重集，用惰性堆 + 槽位版本号做等价物）；
  队首出队或队尾合并时，务必同步失效掉被删元素的旧候选值。
- **无解输出**：若 $\max a > m$，整体一段也无法满足条件②，程序输出 `-1`。
  本批 10 个数据点都保证有解，故该分支未被真实数据覆盖，只经随机无解用例与暴力对照验证。
- **来源说明**：本题素材源自带数据生成脚本（`data.py`）与自研 `std.cpp`，说明测试数据是自造的，
  题面也可能是网络重建（条件①原文残缺即为佐证）。验证时先把 `std.cpp` 编译跑完 10 个点，
  结果与 `.out` 全部一致，才把它当作交叉参照；子问题的单调队列 + 堆 DP 与 POJ 3017
  《Cut the Sequence》同型；`std.cpp` 用线段树 + 单调队列实现同一判定子问题，本解不用线段树——
  队首单独现算后，可重集已足够。C++ 与 Python 两版均在全部 10 个数据点与 `.out` 一致，
  另与 $O(n^2)$ 暴力、$O(n^2)$ 判定 DP 参照实现各对拍数百组无差异。

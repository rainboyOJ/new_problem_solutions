## 形式化题目

给定两个整数：甲流确诊数 $c$ 与死亡数 $d$（$d \leqslant c$）。计算该省的甲流死亡率，以百分数形式输出，精确到小数点后 3 位。

输入样例：

```
10433 60
```

输出样例：

```
0.575%
```

样例解释：死亡率 $= 60 \div 10433 \times 100 \approx 0.57510\ldots\%$，四舍五入保留 3 位小数得 `0.575%`。

## 正解

### 思路

这是一道公式计算题。死亡率的定义就是"死亡数占确诊数的百分比"：

$$
r = \frac{d}{c} \times 100\%
$$

于是思路自然分成三步：

1. **读入**：一行两个整数，先按空白切分再逐个转成整数，得到确诊数 `confirmed` 与死亡数 `died`。
2. **计算**：算出百分数值 `rate = died / confirmed * 100`（此时已经是 0~100 的数，不再乘第二次 100）。
3. **输出**："精确到小数点后 3 位"就是四舍五入保留 3 位小数，Python 的 `:.3f` 格式化正好完成这件事，再把 `%` 拼在末尾即可。

不需要任何数据结构或循环：单组数据、常数次浮点运算，一步到位。整数除法不行（会截断小数），必须用浮点除法 `/`。

## 总结

本题的核心是把题面的自然语言"死亡率、百分数、精确到 3 位"翻译成一个公式加一个格式化：

- 公式 $r = d / c \times 100$ 用浮点除法计算；
- `f"{rate:.3f}%"` 同时完成四舍五入保留 3 位与百分号拼接。

理解"百分数 = 比例 × 100"与输出格式化是入门阶段必须掌握的两个基本功。

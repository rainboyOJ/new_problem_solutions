## 形式化题目

教室里同学坐在 $M$ 行 $N$ 列的网格上。相邻两行之间、相邻两列之间各有一个可以开通道的"缝"：行方向共 $M-1$ 条，列方向共 $N-1$ 条。给定 $D$ 对会交头接耳的同学，每对要么左右相邻、要么前后相邻。

现在要在行方向恰好开 $K$ 条通道、列方向恰好开 $L$ 条通道。一条通道隔开所有跨越它所在缝的相邻同学对，被隔开的对不再算交头接耳。要求选缝的方案，使得剩下仍在交头接耳的对数最少，输出所选的行缝编号（升序）与列缝编号（升序）。

题目保证最优方案唯一。

**样例**：$M=4,N=5,K=1,L=2$，三对说话同学是 $(4,2)\text{-}(4,3)$、$(2,3)\text{-}(3,3)$、$(2,5)\text{-}(2,4)$：

| | 列1 | 列2 | 列3 | 列4 | 列5 |
| --- | --- | --- | --- | --- | --- |
| 行1 |  |  |  |  |  |
| 行2 |  |  | ※ |  | + |
| 行3 |  |  | ※ |  |  |
| 行4 |  | \* | \* |  |  |

图中 `*`、`※`、`+` 标出三对会交头接耳的同学。样例答案在行 2/3 之间、列 2/3 之间、列 4/5 之间开通道，三条通道恰好各隔开一对说话同学，剩下的对数为 $0$。

## 正解

### 思路

先想最朴素的做法：从 $M-1$ 条行缝里选 $K$ 条、$N-1$ 条列缝里选 $L$ 条，方案数是 $\binom{M-1}{K}\binom{N-1}{L}$，$M,N$ 达到 $1000$ 时这是天文数字，枚举显然不可行。

**关键观察一：行缝与列缝互不影响。** 一对说话同学要么左右相邻（只能被列缝隔开），要么前后相邻（只能被行缝隔开）。开哪些行缝只影响前后相邻的对，开哪些列缝只影响左右相邻的对，两组决策完全独立，可以分开解决。

**关键观察二：每条缝的贡献可以单独统计。** 对每一条行缝 $i$（第 $i$ 行与第 $i+1$ 行之间），数一数有多少对前后相邻的说话同学恰好跨在它上面，记为 $c_i$。同样对每条列缝统计 $c_j$。以样例验证：

- 列缝 2（列 2/3 之间）隔开 `*` 对：$c_2=1$；列缝 4（列 4/5 之间）隔开 `+` 对：$c_4=1$；其余列缝贡献为 $0$。
- 行缝 2（行 2/3 之间）隔开 `※` 对：$c_2=1$；其余行缝贡献为 $0$。

于是"开一条缝"收益就是这条缝的 $c$ 值，且不同缝之间收益互不叠加、互不冲突——选缝 $A$ 不会改变选缝 $B$ 能隔开的对（每对同学只跨一条缝）。要最大化被隔开的总对数，就是在行缝中选 $K$ 个 $c$ 最大的、在列缝中选 $L$ 个 $c$ 最大的，一个直接交换论证就能证明贪心最优：如果选了 $c$ 较小的缝而放弃更大的，交换两者总收益不减。

**实现**：读入每对同学 $(X_i,Y_i),(P_i,Q_i)$ 时，行号在前：若 $X_i \neq P_i$ 则前后相邻，给编号为 $\min(X_i,P_i)$ 的行缝计数加一；否则左右相邻，给编号为 $\min(Y_i,Q_i)$ 的列缝计数加一。最后把行缝按计数从大到小取前 $K$ 个下标、列缝取前 $L$ 个下标，升序输出即可。由于最优方案唯一，不需要处理计数相同的平局。

可视化一下"缝"与"贡献"的模型（样例）：

| 缝类型 | 编号 | 隔开的对 | 贡献 $c$ |
| --- | --- | --- | --- |
| 列缝 | 2 | `*`（(4,2)-(4,3)） | 1 |
| 列缝 | 4 | `+`（(2,5)-(2,4)） | 1 |
| 行缝 | 2 | `※`（(2,3)-(3,3)） | 1 |
| 其余所有缝 | — | 无对跨越 | 0 |

取列缝贡献前 2 名 `{2,4}`、行缝贡献前 1 名 `{2}`，正好是样例答案。

### 复杂度

读入与统计是 $O(D)$；排序行缝、列缝各 $O(M\log M)$、$O(N\log N)$。总复杂度 $O(D + M\log M + N\log N)$，在 $M,N \leqslant 1000$、$D \leqslant \min(MN, 10^5)$ 下远小于限制（实测每组数据十几毫秒）。空间 $O(M+N)$。

## 总结

本题是"逐条统计贡献 + 贪心选前 $K$ 大"的入门级贪心。两个观察撑起整个解法：横纵通道独立、每条缝贡献独立可加。实现上唯一的小陷阱是坐标含义——输入是 $(行, 列)$，判断相邻方向时比较的是第 1、3 个数（行），跨缝编号取相邻两坐标的较小值。

## 形式化题目

棋盘是一个 **L 形（阶梯形）区域**，由两个左对齐的矩形拼成：

- **上矩形**：$b$ 行、$a$ 列；
- **下矩形**：$d$ 行、$a+c$ 列，与上矩形共用最左边的 $a$ 列。

题面用 $a,b,c,d$ 标注四条边：$a$ 是上矩形的宽度，$b$ 是上矩形的高度，$c$ 是下矩形
比上矩形向右多伸出的宽度，$d$ 是下矩形的高度。$a=b=c=d=2$ 时的图形是：

```text
    +--+                       <- 上矩形：b=2 行、a=2 列
    |  |
    |  |
  +-+--+                       <- 下矩形顶边，以下区域总宽 a+c = 4
  |    |
  |    |                       <- 下矩形：d=2 行、a+c=4 列
  +----+
   a  c
```

在棋盘上放 $k$ 个**互不攻击**的车（国际象棋的 rook），要求任意两个车**不在同一行**、
也**不在同一列**。求合法摆放的方案数对 $100003$ 取模的结果。

数据范围：$0 \leqslant a,b,c,d,k \leqslant 1000$（题面写 $1 \leqslant$，但真实数据中存在 $0$，
例如 `0 0 1000 1000 1000`，实现必须容忍 $0$）。题目保证至少存在一种可行方案。

样例：$a=b=c=d=2,\ k=2$ 时答案为 $38$。

## 正解

### 思路

**第一步：把“互不攻击”翻译成“行列都互不相同”。**

$k$ 个车互不攻击，等价于它们占据的 $k$ 个格子两两不同行、两两不同列。
于是计数问题变成：选出 $k$ 个格子，使它们用到的行数 = 列数 = $k$。

**第二步：先解决矩形，得到闭式 $f(R,C,t)$。**

在 $R$ 行 $\times$ $C$ 列的矩形里放 $t$ 个互不攻击的车，可以分两步决策：

1. 选出被占用的 $t$ 行，方案数 $\binom{R}{t}$；
2. 把这 $t$ 行**按行序**依次配上互不相同的列：第 1 行有 $C$ 种选法，第 2 行剩 $C-1$ 种……
   共 $C(C-1)\cdots(C-t+1)=P(C,t)$ 种。

两步的决策互不影响，所以

$$f(R,C,t)=\binom{R}{t}\cdot P(C,t).$$

**第三步：按上矩形里放几个车来分类。**

L 形棋盘没法直接用矩形闭式，但它由两个矩形拼成，而**上下两块的行完全不相交**。
于是按“上矩形里放了多少个车”分类是天然的切入点：枚举

$$i=0,1,\dots,\min(a,b,k),$$

表示上矩形（$b$ 行 $\times$ $a$ 列）中放了 $i$ 个车。

- 上矩形的贡献直接由闭式给出：$\binom{b}{i}P(a,i)$。
- 上矩形占用的 $i$ 列，全都落在上矩形的列集 $\{0,\dots,a-1\}$ 内；
  而这个列集又是下矩形列集 $\{0,\dots,a+c-1\}$ 的**子集**。
  所以上矩形放完车后，下矩形**恰好有 $i$ 列不可用**，可用列数变成 $a+c-i$。
  注意这里扣减的量精确等于 $i$，与“上矩形具体占了哪 $i$ 列”无关。
- 上下两矩形的行集不相交，所以行方向不会再产生任何额外约束。
- 下矩形（$d$ 行）还要放完剩下的 $k-i$ 个车，贡献 $\binom{d}{k-i}P(a+c-i,k-i)$。

把两者相乘，对所有 $i$ 求和：

$$\text{ans}=\sum_{i=0}^{\min(a,b,k)}\binom{b}{i}P(a,i)\cdot\binom{d}{k-i}P(a+c-i,k-i)\pmod{100003}.$$

**为什么这样分类不重不漏。** 任何一个合法摆放，它在 $L$ 形上矩形中的车数必然是某个
$i\in[0,\min(a,b,k)]$，因此都会被统计到，**无漏**；而 $i$ 由上矩形内的车数**唯一确定**，
不同 $i$ 对应的摆放集合互不相交，**无重**。固定 $i$ 之后，上下两块各自都是“选行 $\times$
分配列”的独立性论证，下矩形的可用列数又被精确扣减，所以项内计数也是正确的。

**实现要点。** $a+c$ 上界是 $2000$，预处理 $\binom{n}{r}$ 与 $P(n,r)$ 到 $n=2000$ 即可。
$P(n,r)$ 是下降幂 $n(n-1)\cdots(n-r+1)$，用前缀积一次生成一整行，比每个格子单独循环快得多。
模数 $100003$ 虽是质数，但这里完全不需要求逆元——$\binom{n}{r}$ 用杨辉递推、
$P(n,r)$ 用前缀积累乘，都是 $O(n^2)$ 总代价。

下面这张表画出 $i$ 变化时两块矩形的方案数如何拆分，以样例 $a=b=c=d=2,\ k=2$ 为例
（表中的 $\binom{2}{2}=1$，注意别与 $P$ 混淆）：

| $i$（上矩形车数） | 上矩形方案 $\binom{b}{i}P(a,i)$ | 下矩形可用列数 $a+c-i$ | 下矩形方案 $\binom{d}{k-i}P(a+c-i,k-i)$ | 该项乘积 |
| :---: | :---: | :---: | :---: | :---: |
| 0 | $\binom{2}{0}P(2,0)=1\times1=1$ | 4 | $\binom{2}{2}P(4,2)=1\times12=12$ | 12 |
| 1 | $\binom{2}{1}P(2,1)=2\times2=4$ | 3 | $\binom{2}{1}P(3,1)=2\times3=6$ | 24 |
| 2 | $\binom{2}{2}P(2,2)=1\times2=2$ | 2 | $\binom{2}{0}P(2,0)=1\times1=1$ | 2 |
| 合计 | | | | $12+24+2=\mathbf{38}$ |

上表的行就是 $i$ 的三种取值。可以看到 $i$ 每增加 $1$，下矩形的可用列数就少 $1$
（$4\to3\to2$），这正是“上矩形占掉的列与下矩形共享”的体现；三行乘积相加恰好等于
样例的 $38$。

### 复杂度

- **时间复杂度**：$O(a+c)$。表只建到 $\max(b,\,a+c,\,d,\,k)$ 行（不超过 $a+c$ 量级），
  杨辉递推与下降幂前缀积各 $O(a+c)$；枚举 $i$ 共 $\min(a,b,k)+1 \leqslant 1001$ 项，
  每项 $O(1)$。与标准 C++ 正解同阶。
- **空间复杂度**：$O(a+c)$ 存储两张下三角表。实测最坏一组（$a=b=c=d=1000$）耗时

## 总结

题目把“在 L 形棋盘上放 $k$ 个互不攻击的车”化归为**两个左对齐矩形的拼接**。
核心结论有两条：其一，单个 $R\times C$ 矩形放 $t$ 个车的方案数是
$\binom{R}{t}P(C,t)$（选行 $\times$ 分配列）；其二，上下两块共享左侧 $a$ 列，
于是**上矩形占用 $i$ 列后下矩形恰好只剩 $a+c-i$ 列可用**。
按 $i$ 分类枚举求和，复杂度 $O(a+c)$，$a,b,c,d,k$ 到 $1000$ 也能瞬间出解。

## 图示解析

下图给出求和的整体流程：先枚举上矩形的车数 $i$，再分别用矩形闭式算出两块区域的方案数，
相乘后累加取模。重点看中间“下矩形可用列数 $a+c-i$”这一步——它是全题唯一的跨区域耦合。

```mermaid
flowchart TD
    Start["读入 a b c d k"] --> Pre["建表 C(n,r) 与 P(n,r)，n 到 max(b, a+c, d, k)"]
    Pre --> Loop[“枚举 i = 0 .. min(a,b,k)”]
    Loop --> Up[“上矩形 b×a：C(b,i)·P(a,i)”]
    Loop --> Down[“下矩形 d×(a+c-i)：C(d,k-i)·P(a+c-i,k-i)”]
    Up --> Mul[“两项相乘并累加取模”]
    Down --> Mul
    Mul --> More{“i 枚举完 ?”}
    More -- 否 --> Loop
    More -- 是 --> Out[“输出累加和对 100003 取模”]
```

矩形闭式 $f(R,C,t)=\binom{R}{t}P(C,t)$ 的来源可以在一个小矩形里看清：
选行（哪些行被占）与分配列（每行配哪一列）是两次**互相独立**的决策。
下面用 $R=C=2,\ t=2$ 说明这两步如何相乘：

```text
第一步：选 2 行——只有一种，两行都占     第二步：给这 2 行配 2 个不同的列
      col0 col1                              row0 可选 col0 或 col1  (2 种)
row0   [X]  [X]          C(2,2) = 1         row1 只能选剩下那列     (1 种)
row1   [X]  [X]                        P(2,2) = 2 * 1 = 2

合成：1 * 2 = 2 种，恰好是两条对角线摆法：
   X .        . X
   . X        X .
```

观察重点是“选行”和“分配列”之间没有先后依赖：无论先做哪一步，结果都是
$\binom{R}{t}\cdot P(C,t)$。这解释了为什么矩形闭式可以直接相乘，
而 L 形棋盘必须再按 $i$ 分类——因为上下两块在**列**上并不独立。

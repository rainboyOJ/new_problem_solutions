## 形式化题目

给定若干个大于 $4$ 的偶数 $n$（满足 $6 \leqslant n \leqslant 10^6$），对于每个 $n$，求一组奇素数对 $(a, b)$，满足：
$$n = a + b$$
且在所有满足条件的素数对中使差值 $b - a$ 最大。若无解则输出无解提示。

## 正解

### 思路

因为 $a + b = n$，两数之差可以表示为：
$$b - a = (n - a) - a = n - 2a$$
在 $n$ 给定的前提下，$b - a$ 随着 $a$ 的增大而严格递减。因此，要求 $b - a$ 最大，等价于寻找满足条件且**数值最小**的奇素数 $a$。

由于 $n \leqslant 10^6$，我们可以先通过欧拉筛（线性筛）在 $O(N)$ 时间内预处理出 $10^6$ 范围内的所有素数以及素数判定布尔表（`is_prime`）：

1. 预处理上限 $N = 10^6$ 内的素数列表和标记数组；
2. 对于每个给定的偶数 $n$，按升序枚举奇素数 $a \in [3, \lfloor n / 2 \rfloor]$；
3. 计算补数 $b = n - a$，借助布尔表在 $O(1)$ 时间内检查 $b$ 是否为素数；
4. 找到的第一组有效 $(a, b)$ 即为 $a$ 最小、差值 $b - a$ 最大的解，直接输出并终止当前枚举。

#### 样例推演

以 $n = 20$ 为例：
- 升序枚举奇素数 $a$：
  - $a = 3$：计算 $b = 20 - 3 = 17$，$17$ 是素数，因此 $(3, 17)$ 满足条件，$b - a = 14$；
  - 若继续枚举 $a = 7$，$b = 13$，$b - a = 6 < 14$。
- 显然首个找到的素数对即为最优解。

### 复杂度

- **时间复杂度**：
  - 预处理素数表：使用欧拉筛时间复杂度为 $O(N)$，其中 $N = 10^6$；
  - 单次查询：平均只需极少次检验即可找到解，单次检验复杂度为 $O(1)$。总运行时间远在 1 秒时限内。
- **空间复杂度**：$O(N)$，主要开销为大小为 $10^6$ 的标记数组和素数列表，内存占用在数兆字节内，远低于 128 MB 限制。

## 总结

本题利用 $b - a = n - 2a$ 的单调性将“最大化差值”转化为“贪心枚举最小的素数”，结合线性筛做全局预处理，将高频多次查询的均摊单次耗时降至 $O(1)$。

## 形式化题目

有 $n$ 名选手，每人有一个互不相同的报名号 $k$ 和一个成绩 $s$。定义一个全序：$p$ 排在 $q$ 前面，当且仅当 $s_p > s_q$，或者 $s_p = s_q$ 且 $k_p < k_q$。由于报名号互不相同，这个全序唯一确定了一个序列 $P$。

令 $r = \lfloor m \times 150 / 100 \rfloor$，其中 $m$ 是计划录取人数。要求：

- 面试分数线为 $P$ 中第 $r$ 名选手的成绩 $s_{P_r}$；
- 进入面试的是所有满足 $s \geqslant s_{P_r}$ 的选手，因此与分数线同分者一并进入，实际人数 $c$ 可能严格大于 $r$；
- 输出分数线、实际人数 $c$，以及 $P$ 中前 $c$ 名选手的报名号与成绩。

以题面样例 $n = 6, m = 3$ 为例，$r = \lfloor 3 \times 150 / 100 \rfloor = 4$，排序后的名次如下。

| 名次 | 报名号 | 成绩 | 是否入面 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | 1005 | 95 | 是 | 并列最高分，报名号小者在前 |
| 2 | 2390 | 95 | 是 | |
| 3 | 1000 | 90 | 是 | |
| **4** | **1001** | **88** | **是** | 第 $r$ 名，成绩 88 即分数线 |
| 5 | 3239 | 88 | 是 | 与分数线同分，被一并纳入 |
| 6 | 7231 | 84 | 否 | 低于分数线 |

第 4 名的成绩 88 是分数线，第 5 名虽然名次在 $r$ 之后，但成绩同样是 88，所以实际入面人数是 5 而不是 4。这正是本题最容易被漏掉的一点：**人数必须按分数统计，不能直接输出 $r$**。

## 正解

### 思路

题目把「分数线」和「输出顺序」都定义在同一把排序上，所以整道题只有一件事要做：**把 $n$ 名选手按规则排好序**。

最朴素的做法是逐句翻译题面：反复扫描剩下的人，每次挑出「成绩最高，并列时报名号最小」的那一个放到序列尾部，重复 $n$ 次构造出 $P$。这是选择排序，$O(n^2)$。但它的全部时间都花在排序上，后面的取分数线和过滤都已经是 $O(n)$，也就是说**瓶颈只有一个，而且就是一个排序问题**——那就没有必要手写双重循环。

于是把排序交给标准库，键写成两级关键字的元组：

```python
players.sort(key=lambda p: (-p[1], p[0]))   # 成绩降序、报名号升序
```

- `-p[1]` 把「成绩从高到低」翻译成「键从小到大」，省掉自定义比较函数；
- 元组按分量依次比较，所以成绩相同时自动比较报名号，第二级关键字免费获得；
- 复杂度降到 $O(n \log n)$，比较规则集中在一行里，不容易写错。

排好序后，分数线只是一次位置查询：

```python
cut_rank = admitted_plan * RATIO // FULL   # floor(m * 150 / 100)
line = players[cut_rank - 1][1]
```

这里用 `//`（整除，正数上等价于向下取整）而不是四舍五入：$m = 3$ 时 $3 \times 1.5 = 4.5$，向下取整得到 $r = 4$，五入却会得到 $5$，取到的是另一个人的成绩。

最后一步是产出面试名单。这里**不能**写成 `players[:cut_rank]`，因为与分数线同分的选手可能排在第 $r$ 名之后：

```python
admitted = [p for p in players if p[1] >= line]
```

过滤条件 `p[1] >= line` 就是题面「笔试成绩不低于面试分数线」的直译。由于 `players` 已经按成绩降序，满足条件的元素必然构成它的一个前缀，所以 `admitted` 的顺序天然满足「成绩从高到低，成绩相同按报名号从小到大」，不需要再排一次。

还有一个来自真实数据的行为需要处理：题面保证 $\lfloor m \times 150 / 100 \rfloor \leqslant n$，但测试数据 `problem9.in` 中 $n = 4334$、$m = 3040$、$r = 4560 > n$，此时 `players[cut_rank - 1]` 会越界，而官方答案是分数线 0、全员 4334 人入面。因为成绩下界是 1，令 `line = 0` 恰好让过滤条件对所有人成立，与官方输出一致：

```python
line = players[cut_rank - 1][1] if cut_rank <= n else 0
```

### 复杂度

- 时间复杂度：$O(n \log n)$，来自一次排序；取分数线 $O(1)$，过滤与输出各 $O(n)$。$n \leqslant 5000$ 时约 $6 \times 10^4$ 次比较。
- 空间复杂度：$O(n)$，存放 `players`、`admitted` 和输出行。

## 总结

本题是一个「排序 + 阈值过滤」的模板题：先把题面里「成绩降序、同分按报名号升序」翻译成排序键 `(-s, k)`，用一次标准排序构造全序，再按名次 $\lfloor m \times 150 / 100 \rfloor$ 读出分数线，最后用 `s >= line` 过滤出真正入面的人。两个易错点：分数线要用向下取整而不是四舍五入；实际人数要按分数统计，同分者会越过第 $r$ 名被一并纳入。真实数据里还出现了 $r$ 超出总人数的情况，按官方答案处理为分数线 0、全员入面。实测 10/10 测例通过，最慢 0.020 s、峰值约 16 MB，远低于 1000 ms / 128 MB 的限制。

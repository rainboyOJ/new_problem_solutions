## 形式化题目

有 $N$ 只动物编号 $1 \sim N$，每只是 A、B、C 三类之一（具体类别未知），三类构成环形食物链：A 吃 B，B 吃 C，C 吃 A。给定 $K$ 句话，每句形如「1 X Y」（X 与 Y 同类）或「2 X Y」（X 吃 Y）。一句话是**假话**当且仅当满足以下之一：

1. 与前面已确定为真的话冲突；
2. X 或 Y 的编号大于 $N$；
3. 话意是「X 吃 X」。

求 $K$ 句话中假话的总数。

## 正解

### 思路

**朴素想法**：如果对每句话直接检查它之前所有真话的两两关系，最坏 $O(K^2)$，$K \leqslant 10^5$ 时约 $10^{10}$ 次操作，不可行。我们需要的其实不是每对动物的关系都显式存下来，而是一个能**增量维护**"已确认为真的关系集合"并能**快速询问任意两只动物当前关系**的结构——这正好是带权并查集。

**核心建模**：给并查集的每条边带上权值 $rel(x) \in \{0,1,2\}$，表示 $x$ 相对它父亲的"关系"：

- $0$：$x$ 与父亲同类；
- $1$：$x$ 吃父亲；
- $2$：$x$ 被父亲吃（即父亲吃 $x$）。

关键观察是**关系在模 3 意义下封闭**。设 $r(x)$ 为 $x$ 相对树根的关系（沿路径权值之和模 3），则任意同树两点 $x,y$ 的真实关系为：

$$rel(x,y) = (r(x) - r(y)) \bmod 3$$

其中 $0$ 为同类、$1$ 为 $x$ 吃 $y$、$2$ 为 $y$ 吃 $x$。这个减法之所以成立，是因为三条链规则都满足模 3 加法：

| 已知 | 已知 | 合成结果 |
| --- | --- | --- |
| $x$ 吃 $y$（$+1$） | $y$ 吃 $z$（$+1$） | $x$ 吃 $z$？不，A 吃 B、B 吃 C 则 C 吃 A，即 $z$ 吃 $x$（$1+1 \equiv 2 \pmod 3$） |
| $x$ 吃 $y$（$+1$） | $y$ 被 $z$ 吃（$+2$） | $x$ 与 $z$ 同类（$1+2 \equiv 0 \pmod 3$） |
| $x$ 与 $y$ 同类（$0$） | $y$ 吃 $z$（$+1$） | $x$ 吃 $z$（$0+1 \equiv 1 \pmod 3$） |

模 3 的环正好对应"食物链是三元环"这一题设。

**逐句判定**：先把第 2、3 类假话（编号越界、X 吃 X）直接判掉；然后对每句话 $d,x,y$：

- 若 $x,y$ 不同根：说明这句话提供全新信息，必为真，用来合并两棵树。设 $w=(d-1+r(y)-r(x)) \bmod 3$，把 $x$ 的根挂到 $y$ 的根上、边权为 $w$，恰好保证合并后 $(r'(x)-r'(y)) \bmod 3 = d-1$。
- 若 $x,y$ 同根：真实关系为 $(r(x)-r(y)) \bmod 3$，若它 $\neq d-1$ 则是假话（$d-1$：同类 $=0$，$x$ 吃 $y$ $=1$）。

**路径压缩**：压缩时要把中间节点的 $rel$ 顺手下放为"该节点直接到根"的权值——从根往路径起点逐层累加即可。注意实现顺序的坑：不能在覆盖 `rel[x]` 之后再读旧值。

样例中三句假话分别为：`1 101 1`（101 越界）、`2 3 3`（3 吃 3）、`1 1 3`（由"1 吃 2、2 吃 3"推出 1 与 3 不是同类）。

## 总结

本题是「带权并查集（种类并查集）」的模板题。要点有两个：一是把环形三元关系编码成模 3 加法，使"同类/吃/被吃"三种判断统一成一次减法；二是路径压缩时边权要同步下放。数据全部真实测试通过。

节点标注了各自的 $rel$ 值。此时 $r(1) = (1+1) \bmod 3 = 2$，$r(3)=0$，故 $rel(1,3) = (2-0) \bmod 3 = 2 \neq 0$：第 5 句「1 1 3 同类」与已有真话冲突，判为假话——这正是输出 3 句假话中的最后一句。整棵树上任意两点的真假判定都只需要各一次 `find` 加一次模 3 减法。

## 形式化题目

给定一排 $n$ 堆石子，石子数分别为 $a_1, a_2, \dots, a_n$。
两名玩家轮流操作。每一步操作者必须且只能从当前序列的最左端或最右端的一堆中取走任意正整数颗石子（可以取完整堆，但不能不取）。
取走最后一颗石子使其无法操作的一方获胜（即无法操作者输）。
假设双方均采取最优策略，判断先手是否存在必胜策略。若先手必胜输出 $1$，否则输出 $0$。

## 正解

### 思路

由于每步只能从序列的最左端或最右端取石子，且石子数高达 $10^9$，常规的记忆化搜索或 SG 函数无法直接处理。注意到取石子的位置天然对应着区间收缩，我们考虑从区间博弈的角度切入。

#### 1. 核心观察与状态定义

对于任意连续子序列 $[i, j]$，我们考虑在其左侧额外放置一堆石子，使得新序列（包含新增的这堆以及原区间 $[i, j]$）成为一个**先手必败态**（P-position）。

- **唯一性**：如果存在两个不同的石子数 $x_1 < x_2$ 均使得左侧放该数量时为必败态，那么在面对数量为 $x_2$ 的局面时，先手可以直接从该堆中取出 $x_2 - x_1$ 颗石子，将其转移到数量为 $x_1$ 的局面。这意味着先手可以一步将一个必败态转移到另一个必败态，违背了博弈论中必败态的所有后继都是必胜态的基本定理。因此，使局面成为必败态的左侧石子数**至多只有一个**。
- **存在性**：可以证明这样的石子数必定存在且非负。

基于此，我们定义：
- $L[i][j]$：在区间 $[i, j]$ 的**最左侧**添加一堆石子，使得整个新局面为先手必败态时，该堆石子的唯一数量。
- $R[i][j]$：在区间 $[i, j]$ 的**最右侧**添加一堆石子，使得整个新局面为先手必败态时，该堆石子的唯一数量。

#### 2. 边界条件

当区间长度为 $1$ 时（即只有单堆 $[i, i]$，石子数为 $a_i$）：
如果在左侧放一堆数量相同的石子 $a_i$，局面变成两堆数量相等的石子。后手可以使用**对称模仿策略**（先手在某一堆取多少，后手就在另一堆取同样多的石子），先手必败。
因此：
$$L[i][i] = R[i][i] = a_i$$

#### 3. 状态转移推导

考虑如何利用区间 $[i, j-1]$ 的已知信息推导 $L[i][j]$。
令 $l = L[i][j-1]$，$r = R[i][j-1]$，$x = a_j$。我们需要寻找一个石子数 $L = L[i][j]$，使得序列在最左端加上 $L$、最右端加上 $x$ 后的局面为必败态。根据 $x$ 与 $l, r$ 的大小关系，分五种情况讨论：

| 关系条件 | $L[i][j]$ 的值 | 转移逻辑解释 |
| :--- | :--- | :--- |
| $x = r$ | $0$ | 由 $R[i][j-1] = r$ 的定义，右端本身已有 $r$ 颗石子就已经是必败态，左侧无需石子（$0$ 颗）。 |
| $x < l$ 且 $x < r$ | $x$ | 左右两端石子数相同。先手无论取哪一端，后手都在另一端取相同数量；任一端被取光后留下的状态均在临界值之内，先手无法反制。 |
| $r < x < l$ | $x - 1$ | 左右两端保持差值 $1$。先手取左或取右时，后手可通过对称性或将状态拉回到 $z = r$ 的必败态。 |
| $l < x < r$ | $x + 1$ | 与上述情况对偶，后手可通过将差值抵消或触发必败转移使先手落败。 |
| $x > l$ 且 $x > r$ | $x$ | 当石子数同时超出两侧临界值时，只需保持左右两端石子数相等即可保持对称控制。 |

同理，推导 $R[i][j]$ 时令 $l = L[i+1][j], r = R[i+1][j], x = a_i$：
- 若 $x = l$，则 $R[i][j] = 0$；
- 若 $(x > l \land x > r)$ 或 $(x < l \land x < r)$，则 $R[i][j] = x$；
- 若 $l < x < r$，则 $R[i][j] = x - 1$；
- 若 $r < x < l$，则 $R[i][j] = x + 1$。

#### 4. 全局胜负判定

区间递推到区间 $[2, n]$ 后，其左侧使得局面成为必败态所需的石子数为 $L[2][n]$。
- 当 $n = 1$ 时，先手直接取完整堆石子即可获胜，结果为 $1$。
- 当 $n > 1$ 时，原序列最左端的实际石子数为 $a_1$：
  - 若 $a_1 = L[2][n]$，则当前整个局面恰好是先手必败态，先手必输，输出 $0$；
  - 若 $a_1 \ne L[2][n]$，先手必能将第一堆调整至 $L[2][n]$（若 $a_1 > L[2][n]$），或原局面本身是先手必胜态，输出 $1$。

### 复杂度

- **时间复杂度**：$\mathcal{O}(T \cdot n^2)$。状态数为 $\mathcal{O}(n^2)$，每个状态的转移仅涉及常数次大小比较与算术运算。对于 $T \leqslant 10, n \leqslant 1000$，总计算量约为 $5 \times 10^6$ 次，在时限内非常充裕。
- **空间复杂度**：$\mathcal{O}(n^2)$。使用二维数组记录 $L$ 和 $R$ 状态表，空间占用几十兆，满足内存限制。

## 总结

本题是典型的**端点操作类博弈问题**。面对极大的单堆石子数和无法直接套用 Nim 结论的限制，突破口在于：
1. 建立基于区间的**必败阈值定义**（$L[i][j]$ 和 $R[i][j]$），并严格证明该阈值的唯一性与存在性；
2. 将博弈胜负的判定转化为对临界石子数的大力分类讨论，从而在 $\mathcal{O}(n^2)$ 的区间 DP 中完成对博弈态的递推求解。

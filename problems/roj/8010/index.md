## 形式化题目

给定两个字符串 $s_1$ 和 $q$，其中 $s_1$ 中的字符互不相同。需要判断 $q$ 中的字符是否按与 $s_1$ 中相同的相对顺序出现，即判断 $q$ 是否是 $s_1$ 的子序列。

**输入格式**：
输入包括两个字符串，第一行为 $s_1$，第二行为 $q$（通过空白符分隔的 token 方式读取）。

**输出格式**：
如果 $q$ 的字符相对位置与 $s_1$ 一致，输出 `Yes`；否则输出 `No`。
> ⚠️ **输出格式是假设**：题面完全未定义输出格式，且 `roj.ac.cn` 无任何一手来源可确认。若官方数据用 `1/0` 或 `YES/NO`，逐字节比对会全错。

**数据范围**：
题面未给出具体数据范围。时限 1000ms，内存 128MB。

## 正解

### 思路

这道题本质上是判断字符串 $q$ 是否是字符串 $s_1$ 的**子序列**。
因为题目末句明确指出：“本题目就变成了 $q$ 中的字符之间的相对位置是否和 $s_1$ 中一样。” 
虽然题面中使用了“子串”一词，但与样例解释（`b, a` 的相对位置不一样）矛盾，因此以末句和样例为准，判定条件即为**子序列判定**。

使用**双指针**算法：
1. 维护两个指针 $i$ 和 $j$，分别指向 $s_1$ 和 $q$ 的起始位置。
2. 当 $s_1[i] == q[j]$ 时，说明 $q[j]$ 找到了在 $s_1$ 中的对应字符，将 $j$ 向后移动一位。
3. 无论是否匹配成功，指针 $i$ 始终向后移动一位，直到其中任意一个指针越界。
4. 最后检查 $j$ 是否等于 $q$ 的长度。如果等于，说明 $q$ 中所有字符都已按顺序匹配成功，输出 `Yes`；否则输出 `No`。

### 复杂度

- **时间复杂度**：$O(|s_1| + |q|)$。两个指针各自最多遍历整个字符串一次，因此时间复杂度为线性的。
- **空间复杂度**：$O(1)$ 或 $O(|s_1| + |q|)$。除了存储字符串本身外，只需要常数级别的额外变量。

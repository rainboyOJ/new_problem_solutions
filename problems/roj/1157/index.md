## 形式化题目

给定固定范围 $[6, 100]$。对其中**每个偶数** $n$，求一对素数 $(p, q)$ 使得

$$n = p + q,$$

且 $p$ 取**所有合法拆分中最小的那一个**。每个 $n$ 恰好输出一行 `n=p+q`，按 $n$ 从小到大依次换行输出，共 $48$ 行。

本题**没有输入**：拆分结果只由数值范围决定。注意范围同时包含端点 $6$（题面叙述"大于 6"，但输出要求明确写"6～100 所有偶数"，以输出要求为准，真实数据也从 `6=3+3` 开始）。

「$p$ 最小」这条要求是本题唯一的坑：只要枚举顺序是升序、取**第一个**满足条件的候选，答案就自动最小——但像 $98$ 这样的数，前六个奇数候选全部失败，想当然地"从最小素数开始凑"极易填错。

## 正解

### 思路

**朴素做法。** 按题面字面翻译：对每个偶数 $n$，从 $p = 2$ 起逐个候选，现场用试除法判断 $p$ 与 $n - p$ 是否都是素数，第一个成立就输出。

```python
for n in range(6, 101, 2):
    for p in range(2, n):
        if is_prime_by_trial(p) and is_prime_by_trial(n - p):
            print(f"{n}={p}+{n - p}")
            break
```

这份代码是**正确**的，$n \leqslant 100$ 时也能直接通过——但它的正确性来自数据规模极小，而不是结构好。它的瓶颈是：**素性是一个只与数值有关的纯函数，却被当成每次现算的过程**。同一个数反复出场（$97$ 既是 $n=100$ 的候选 $p$，又是 $100 - 3$ 的 $q$），每次都重做一遍试除。

**关键观察一：偶数的合法拆分必是「奇 + 奇」。** 若 $p = 2$，则 $q = n - 2 \geqslant 4$ 是偶数，必为合数。所以第一个加数只需枚举奇数 $3, 5, 7, \ldots$，候选直接减半，且一个解都不丢。

**关键观察二：升序枚举取首个命中，就是"最小第一加数"。** 候选按升序产生，第一个使「$p$ 素数且 $n - p$ 素数」成立的 $p$ 天然最小——这与题面「请保证第一个加数最小」逐字对应。以 $n = 98$ 为例，扫描过程是：

| 候选 $p$ | $q = 98 - p$ | $q$ 的分解 | 命中？ |
| --- | --- | --- | --- |
| 3 | 95 | $5 \times 19$ | 否 |
| 5 | 93 | $3 \times 31$ | 否 |
| 7 | 91 | $7 \times 13$ | 否 |
| 11 | 87 | $3 \times 29$ | 否 |
| 13 | 85 | $5 \times 17$ | 否 |
| 17 | 81 | $9 \times 9$ | 否 |
| 19 | 79 | 素数 | **是** |

所以 $98$ 必须输出 `98=19+79`：前六个奇数候选全军覆没，只有扫到 $19$ 才第一次两头都是素数。若手写拆分时凭直觉填 $98 = 31 + 67$ 之类，就会与标准输出不一致。

**关键观察三：解必然存在。** 哥德巴赫猜想在 $[6, 100]$ 范围内已被验证（测试数据就是逐行答案），所以"取首个命中"一定取得到，不会取空。

**优化。** 把纯函数变成查表：先用埃氏筛一次性标好 $100$ 以内的素数表，判断退化为一次列表下标访问 $O(1)$；"首个命中"交给 `next(生成器)`——升序生成器的第一个合法值，`break` 和手写循环变量全部消失，语义与题面要求一一对应。

### 复杂度

- 时间复杂度：$O(N \log \log N + N^2)$，$N = 100$：筛表 $O(N \log \log N)$，48 个偶数各扫 $O(N)$ 个奇数候选、每次判断 $O(1)$。$N$ 固定故实际为常数级，实测约 $0.02\,\mathrm{s}$，远低于 $1000\,\mathrm{ms}$ 限制。
- 空间复杂度：$O(N) = O(100)$，一张布尔素数表加 48 行输出；实测峰值约 $14.7\,\mathrm{MB}$（主要是 Python 解释器自身），远低于 $128\,\mathrm{MB}$。

## 总结

- 「保证第一个加数最小」的直接实现就是**升序枚举 + 取首个命中**，不要靠手算挑一个"顺眼"的拆分。
- 偶数 $n \geqslant 6$ 拆成两个素数必为「奇 + 奇」，候选从 $3$ 起、步长 $2$，不丢解。
- 会被反复查询的纯谓词（素性）先筛成表，判断从试除 $O(\sqrt{x})$ 降为查表 $O(1)$——这正是朴素做法里"白做的功"。
- 本题无输入，输出行数固定为 48 行；范围端点 $6$ 和 $100$ 都要包含。

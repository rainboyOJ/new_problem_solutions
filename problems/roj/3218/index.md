## 形式化题目

给定一个包含 $N$ 个节点（$2 \le N \le 100$）的有向图，表示成员相互认识的情况。要求将所有节点划分为两个非空集合 $A$ 和 $B$（即两支队伍），满足：
1. $A \cap B = \emptyset$ 且 $A \cup B = \{1, 2, \dots, N\}$。
2. $|A| \ge 1$ 且 $|B| \ge 1$。
3. 若某两人被分配到同一队伍，则在原图中二者之间必须互有有向边（即互相认识：$u \to v$ 且 $v \to u$）。
4. 在满足前三个条件的所有合法划分中，要求两队规模差 $| |A| - |B| |$ 最小化。

若存在合法解，输出任意一种两队差值最小的方案：第一行先输出第一队的人数及所有成员编号，第二行同样输出第二队（成员编号由空格分隔）。若无解则输出 `No solution`。

## 正解

### 思路

根据题意，“同队中两人必须互相认识”意味着：一旦两人 $u$ 和 $v$ 缺乏相互连接的边（即 $u$ 不认识 $v$ 或 $v$ 不认识 $u$），他们就**绝对不能**被分到同一队。

因此我们可以通过构建原图的**补图**来解决这一冲突问题：
对于任意不同节点 $i, j$，只要原图中不同时存在 $i \to j$ 与 $j \to i$，我们就在补图中连接一条无向边 $(i, j)$。这在补图上形成了必须被分配到“不同队伍”的互斥关系。
一个合法的划分，等价于对补图进行**二分图黑白染色**。如果在染色时遇到奇环，说明产生了不可调和的互斥冲突，直接判定为无解（输出 `No solution`）。

如果染色成功，补图会被划分为 $C$ 个连通块。每个连通块被染成了两种颜色（颜色 $0$ 与颜色 $1$）。对于第 $i$ 个连通块，假设颜色 $0$ 有 $w_{i,0}$ 人，颜色 $1$ 有 $w_{i,1}$ 人。我们可以选择将颜色 $0$ 放入第一队、颜色 $1$ 放入第二队，或者将其反向分配。
由此，问题转化为在保证方案存在的情况下，如何选择这 $C$ 个二选一组合，使得最终第一队的人数最接近 $N/2$。这就是一个标准的**背包 DP**：

定义状态 $f[i][j]$ 表示前 $i$ 个连通块能否使得第一队总人数达到 $j$。
转移方程：
$f[i-1][j] == \text{true} \implies \begin{cases} f[i][j + w_{i,0}] = \text{true} \\ f[i][j + w_{i,1}] = \text{true} \end{cases}$

最后，在所有使得 $f[C][j] = \text{true}$ 且 $j \in [1, N-1]$ 的可行总人数中，寻找使得 $|N - 2j|$ 最小的 $j$ 即可。利用 `path` 数组回溯记录，就能得出两队各自的具体成员列表。

### 复杂度

- **时间复杂度**：构造补图需 $O(N^2)$；使用 DFS 划分连通块与二分图染色遍历所有边及点，用时 $O(N^2)$；背包 DP 的状态规模为 $C \times N \le 100 \times 100 = 10000$，整体转移时间亦为 $O(N^2)$。总时间复杂度为 $O(N^2)$，对于 $N \le 100$ 的数据表现极佳。
- **空间复杂度**：由于只用到了规模为 $100 \times 100$ 的邻接矩阵及 DP 状态表，空间复杂度为 $O(N^2)$。

## 总结

本题是包含严谨图论逻辑和细节要求的“多解题”，评测反馈暴露了诸多潜在的判据盲区及极其珍贵的数据现象：

1. **★★★ 最危险的组合：SPJ 的格式盲区与 `check_bytes` 的 CRLF 卡死**
   - SPJ（特判程序）仅负责验证【合法性与最优性】（互识、人数、差值等），对**排版格式免疫**。如果在代码中去掉了对队员的升序排序，SPJ 的失败点数量仍为 **0**。
   - 理论上，此漏洞应由传统的精确字节匹配 `check_bytes` 拦截，但偏偏因为官方测试数据 `.out` 末尾使用了 `CRLF`（`\r\n`），导致 `check_bytes` 整体失效卡住（失败 56/56）。
   - 结论：**这两个判据的盲区恰好互补成了一个极其危险的大洞**。在此类叠加漏洞下，“升序”输出的修复对于保证逻辑一致性是必要的（排序+CRLF转LF后 `check_bytes` 通过 41/56），但单纯修复排序仍不能让原版 `check_bytes` 直接绿灯（被 CRLF 卡住）。
2. **★★ `.in` 与 `.out` 文件全是 CRLF**
   - 不只是输出结果，所有 56 个测试点的 `.in` 和 `.out` 文件全为 CRLF 格式（56/56），并在评测与判题中产生了各种因行尾换行符引起的不可预期错误。
3. **★★ 「可同队」必须是互认：极其严格的约束**
   - 题面明确声明：“A 认识 B 不代表 B 认识 A”。实测发现，56 个测试点中有 36 个点存在不对称的认识关系（共计 13541 对）。如果误将「可同队」判定条件写成单向（`i 认识 j`），在 SPJ 中将导致 25/56 的点出现“队内并非互相认识”的非法判决。严格的互认（`j in know[i] and i in know[j]`）是不可动摇的先决条件。
4. **★★ SPJ 审阅：数学等价 vs 数据盲区**
   - **数学等价**：有人怀疑 DP 的人数状态是否该防御 `k = 0` 的情况（即某一队为空）。穷举证明指出，在 $N \le 14$ 的 1.5e6 种可实现连通块形状中，合法容量一定与 $[1, N-1]$ 有交集，导致 $k=0$ 的误差 $N$ 永远不可能是最小差值（极小值必然 $\le N-2$）。因此，限制与不限制 $k=0$ 的算法在根本上是**数学等价**且不可区分的，并非数据盲区。
   - **防御性正确**：SPJ 中存在关于 `k ± |a-b|` 背包写法的警告。在 56 点真实数据上，甚至在 $N \le 6$ 的全部 5603 张二分图上，用直接统计（count背包）、差值之和等写法分歧均为 0（数据无区分度）。但在更极端的形状下确实可能产生偏差。结论：该警告是“防御性正确”的有效隔离措施，需如实向维护者说明**两者在实战数据中没有表现差异，但理论层面防微杜渐是有必要的**。
5. **★★ `V6` 暴力穷举的算力背书**
   - 针对二分图与 DP 算法是否百分百正确，校验工序枚举了海量用例：
     - $N=2 \dots 5$ 的所有 **1,052,740** 张有向图，同 SPJ DP 分歧为 **0**。
     - $N=2 \dots 4$ 的 **4,164** 张有向图，用真实的 `main.cpp`/`main.py` 跑出非法结果为 **0**。
   - 这从暴力破解的层面证实了“互联补图二分染色”算法的严密性。
6. **★ 算法运行指纹（`V7`）与反取巧（`V8`）**
   - 追踪运行指纹发现：在所有 48 个有解点上，补图 DFS 的点对检查次数精确等于 $N^2$（如 `teams13`：$10000 = 100^2$），而背包容量的 `j` 扫描次数精确等于 $C \cdot (N+1)$。这彻底证明了运行逻辑确实是二分染色与背包 DP。
   - 相比之下，若采用直接大连通块喂给第一队的贪心算法，会在测试中爆出 30/56 的失败，说明“最小规模差”的要求使得 DP 操作是必须的。
7. **★ 非硬编码 (`V2` / `V4`) 且输出异源检验合法**
   - 代码里的数值字面量极度干净（C++: `{0, 1, 2, 105}`，Python: `{0, 1, 2}`），而数据产生的结果涉及 92 个较大的人员编号，彻底隔绝了硬编码风险。
   - 用输入独立校验官方 `.out`：48 个有解点的互认识和规模差完美符合理论最小值；56/56 的完整数据流消费无越界。结论：官方数据的**结果内容完全合法可靠**，唯一的微小瑕疵只是行尾包含了不可见的 CRLF。
8. **★ T9 五项规范**
   - **数据范围**：$N \le 100$，所有 DP 容量与枚举不涉及大数，标准 `int` 足矣。
   - **数组防越界**：开 `105` 完美兜底。
   - **读入鲁棒性**：输入每行可能仅有 `0`（表示此人全都不认识），代码通过 `while (cin >> x && x != 0)` 可做到零遗漏吸纳。
   - **多解判据**：对于任意满足最小差的最优解，均作了多路线包容（由 spj 核实结果）。
   - **多组判定与清空**：题目的逻辑封装进单次 `solve()`，无全图状态黏连。
9. **格式细节补充**
   - `No solution` 为首字母大写，后续全小写，不带句号，原版字节包含 `\r\n`。共有 8 个点是完全无解。
   - 存在 6 个点存在“孤狼”用户，他们只认识自己以外的 0 个人（对应行只包含一个 0），此时图产生游离节点并在补图中转化为互相排斥的边，算法天然兼容。

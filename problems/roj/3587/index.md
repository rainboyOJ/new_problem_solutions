## 题目描述

对 1 位二进制变量定义两种运算：⊕（字符 `+`）结果为 0 当且仅当两边都为 0（即逻辑或），×（字符 `*`）结果为 1 当且仅当两边都为 1（即逻辑与）；求值顺序为先算括号内、再算 ×、最后算 ⊕，同级从左到右。

给定一个只含 `+ * ( )` 四种字符的未完成表达式，操作数位置是横线，横线数 = 运算符个数 + 1，每条横线独立填入 0 或 1，求使表达式值为 0 的填法数模 10007。输入共 2 行：第一行为整数 L（0 ≤ L ≤ 100000），第二行为长度为 L 的表达式串；输出一行一个整数。例如输入 L=4、串 `+(*)`（即 `_+(_*_)`）时，答案为 3。

## 思路

对每个子表达式只记录 (c0, c1)——使它取 0 / 取 1 的横线填法数，叶子横线是 (1,1)；× 合并时 c1=a1·b1，⊕ 合并时 c0=a0·b0，另一维用总方案数 (a0+a1)(b0+b1) 相减（注意题面的 ⊕ 按真值表是逻辑或而非异或）。用调度场双栈按优先级一遍扫描、边扫边合并（该出现操作数时补一条横线 (1,1)，括号用栈边界隔离），最后栈底 c0 即答案，时间 O(L)、空间 O(L)，不怕深括号嵌套。

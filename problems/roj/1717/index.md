## 形式化题目

给定 $n$ 个点、$m$ 条边的带权**有向**图，无重边、无自环（题面描述段写"无向图"，但输入段与样例都明确是"从 $u_i$ 到 $v_i$ 的有向边"，以输入段为准）。求一个**点数最少**的环，使环上边权和为负；不存在这样的环则输出 $0$。

$2 \leqslant n \leqslant 300$，$0 \leqslant m \leqslant n(n-1)$，$|w_i| \leqslant 10^4$。

## 正解

### 思路

#### 先解决"怎么判定负环"

常规的 Bellman-Ford / SPFA 判负环只回答"有没有"，回答不了"最短的有多长"。但这题要的是**最少点数**，所以必须换一个能同时控制"边数"的判定工具。

关键是把判定条件改写成一句关于**步数上界**的陈述：

> 存在负环 $\iff$ 存在某个 $L \leqslant n$，使得存在一条**用不超过 $L$ 条边**的负权闭迹。

两个方向都要说清楚。

- 负环本身就是一条长度 $\leqslant n$ 的负权闭迹（简单环上点数不超过 $n$，而环的边数等于点数），所以右边成立。
- 反过来，若有一条 $\leqslant L$ 条边的负权闭迹，把它拆成若干个简单回路。若每个简单回路的权都非负，则闭迹总权非负，矛盾；所以其中至少有一个简单回路的权为负，即存在负环，且它的边数不超过 $L$。

于是答案就是"存在负权闭迹的最小 $L$"，记作 $L^*$；不存在负环时输出 $0$。注意闭迹允许重复经过点，所以它是简单环的宽松版本——正是这个宽松让它可以被矩阵幂描述。

#### 用 min-plus 矩阵幂描述"不超过 L 条边的最短路"

把图写成邻接矩阵 $A$，并**把主对角线改成 $0$**：$A_{ii} = 0$ 表示"停在原地不动"，代价为 $0$。这个约定把"恰好用 $k$ 条边"松弛成"**至多**用 $k$ 条边"——因为原地踏步不花钱，走不满的边数可以用自环补足。

定义 min-plus 乘法（也就是 Floyd 的矩阵形式）

$$(X \otimes Y)_{ij} = \min_k \left(X_{ik} + Y_{kj}\right),$$

它的含义是"先按 $X$ 走一段、再按 $Y$ 走一段"。用 $\mathrm{pw}[k]$ 表示"**至多**用 $2^k$ 条边"时任意两点间的最小权值和，则

$$\mathrm{pw}[0] = A, \qquad \mathrm{pw}[k] = \mathrm{pw}[k-1] \otimes \mathrm{pw}[k-1].$$

$\mathrm{pw}[k]$ 的主对角线 $(\mathrm{pw}[k])_{ii}$ 就是"从 $i$ 出发、不超过 $2^k$ 条边回到 $i$ 的最小权值"。只要它出现负数，就说明存在边数不超过 $2^k$ 的负权闭迹，进而存在负环。

#### 按位贪心定位最小 L

$L^* \leqslant n \leqslant 300 < 511 = 2^9 - 1$，所以取 $k = 0 \ldots 8$ 共 9 层就够（`BITS = 8`，$2^8 = 256$，加上贪心累加能表示到 $511$）。

设 `cur` 表示"至多用 $\mathrm{tot}$ 条边"的最短路矩阵，初始 $\mathrm{tot} = 0$、`cur` 为单位矩阵（只能原地不动）。从高位 $k$ 往低位扫：

1. 试算 $T = \mathrm{cur} \otimes \mathrm{pw}[k]$，它表示"至多用 $\mathrm{tot} + 2^k$ 条边"。
2. 若 $T$ 的主对角线**没有**负数，说明"至多 $\mathrm{tot} + 2^k$ 条边"里还没有负权闭迹，这一位可以安全地吃掉：`cur = T`，$\mathrm{tot} \mathrel{+}= 2^k$。
3. 否则跳过这一位。

贪心的正确性来自 $L^*$ 的二进制分解：如果 $\mathrm{tot}$ 的已定高位与 $L^*$ 一致，而 $\mathrm{tot} + 2^k < L^*$，那么第 2 步的条件必然成立（还没到 $L^*$ 就没有负闭迹）；反之若 $\mathrm{tot} + 2^k \geqslant L^*$，条件必然不成立（已经越过 $L^*$）。所以每一位的判定都与 $L^*$ 的该位一致，循环结束后 $\mathrm{tot} = L^* - 1$。

最后再乘一次 $\mathrm{pw}[0]$（只允许"一条边"这一层），主对角线出现负数就输出 $\mathrm{tot} + 1$，否则输出 $0$（此时 $\mathrm{tot}$ 已经涨到 $511$，等价于"图里根本没有负环"）。

#### 举个样例走一遍

样例是 $n = 4$、$m = 8$，答案为 $4$。把边按题意连上后，唯一能形成负环的是 $1 \to 3 \to 4 \to 2 \to 1$：

$$(-1) + 0 + 1 + (-3) = -3 < 0,$$

四条边、四个点。用上面的倍增检查：$\mathrm{pw}[2]$（不超过 $4$ 条边）的主对角线已经出现 $-3$，而贪心会在更高位先探路，最终定位到 $\mathrm{tot} = 3$，输出 $4$。

#### 实现要点

- **主对角线始终 $\leqslant 0$**。这保证矩阵元素恒 $\leqslant \mathrm{INF}$：任何"至多 $511$ 条边"的路径权值绝对值都不超过 $511 \times 10^4$，两个 $\mathrm{INF}$ 相加也不会溢出。用 `long long` + `INF = 1e15` 是安全的（`main.cpp` 里这么写）；`main.py` 用 `INF = 1 << 60`。
- **不可达剪枝**：`mul` 里若 $a_{ik} = \mathrm{INF}$ 或 $b_{kj} = \mathrm{INF}$ 就直接跳过。这不只是常数优化：min-plus 乘法里 $\mathrm{INF} + (-10^4) < \mathrm{INF}$，若不剪掉，会凭空造出"从不可达的点绕过去"的假路径，把答案算小。`main.py` 用向量式 `min(map(add, 行, 列))` 无法逐个跳过，因此对每个结果元素做夹回：只要求出的值超过 $\mathrm{INF}/2$ 就置回 $\mathrm{INF}$（真实权值绝对值 $< 511 \times 10^4 \ll \mathrm{INF}/2$，夹不掉任何真值）。
- **注意原地踏步的语义**：把主对角线置 $0$ 之后，"闭迹"是允许在某点滞留的，但滞留不影响权值，所以"存在负闭迹"与"存在负环"仍然等价。

### 复杂度

时间 $O(n^3 \log n)$：预处理 $9$ 次 min-plus 乘法，贪心 $9$ 次，共 $18$ 次 $O(n^3)$；$n = 300$ 时约 $5 \times 10^8$ 次加法，C++ 在 2s 内可过（含不可达剪枝后实际更快）。空间 $O(n^2 \log n)$，存 $9$ 个矩阵，$n = 300$ 时约 $2.6$ MB。

`main.py` 只用标准库（`python-oj-short` 明确「不用第三方库」）：内层用 `min(map(add, 行, 列))` 把一个 $300 \times 300$ 的乘法压到 $9$ 万个 C 层调用上，而不是 $9$ 万个纯 Python 循环。算法与 C++ 完全同阶，**没有降级成暴力**。代价是常数：实测 n=300 时单点 8.6–11.8 s，超过 1000 ms 限，Python 版在大点会 TLE——按 `python-oj-short` 的约定（「允许 Python TLE/MLE，但绝不能因此把算法换成暴力枚举」）这是可接受的，正式提交请用 `main.cpp`（n=300 时 0.28 s）。

## 总结

这道题把"判定负环"从"能不能"升级成"最少多少条边"，核心桥梁是**把步数上限变成矩阵维度的语义**：

1. 主对角线置 $0$，让"恰好 $k$ 步"变成"至多 $k$ 步"，这是让矩阵幂能表达"不超过 $L$ 条边的负闭迹"的关键一步。
2. min-plus 乘法就是把"两段路拼起来"，于是 $\mathrm{pw}[k]$ 可以倍增得到。
3. 答案的二进制位可以逐位确定：每一步只需要一次乘法 + 一次主对角线符号检查。

它与经典的"二分 + 倍增"是同一思想的两种写法；按位贪心省掉一层 $\log$ 的外层二分，代码更短，也是 BZOJ 4773《负环》的常见做法。

本题素材来自 `new_ROJ/problems/1717/`，目录里带 `data.py` 生成脚本，说明 `data/` 是自造的、`content.md` 也是网络重建的题面（与 BZOJ 4773《负环》的题面、数据范围一致）。因此 `data/*.out` 是**由同目录 `std.cpp` 生成的**，不是官方数据。`std.cpp` 的做法（倍增 Floyd + 按位贪心）与题面自洽，我没有发现它算错；但为了不盲信 `.out`，我用与 `std.cpp` **不同**的方法独立复核了每个点：

- 复核方法：`dp_k[i][j]` = 恰好 $k$ 条边的最短路，逐层做一次 min-plus 乘法（`cur = cur ⊗ A`），检查最小的 $k$ 使主对角线出现负数；这就是"最短负环的边数"，与按位贪心、倍增都无关。另外用 Bellman-Ford 单独判定"有没有负环"。

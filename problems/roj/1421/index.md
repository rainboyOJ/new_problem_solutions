## 形式化题目

给定 $n$ 个点、$m$ 条边的有向图，第 $e$ 条边是 $s_e \to t_e$，长度为 $d_e$（$d_e$ 可以为负）。
记 $a$ 到 $b$ 的最短距离为

$$
\mathrm{Dis}(a,b) =
\begin{cases}
a \to b \text{ 的最短路长度}, & b \text{ 从 } a \text{ 可达},\\
10^{16}, & b \text{ 从 } a \text{ 不可达},
\end{cases}
\qquad \mathrm{Dis}(a,a) = 0 ,
$$

要求输出

$$
S \;=\; \bigoplus_{i=1}^{n} \bigoplus_{j=1}^{n} \bigl(\mathrm{Dis}(i,j) + f\bigr),
\qquad f = 10^{16},
$$

其中 $\oplus$ 表示按位异或，$i, j$ 都按**有序点对**枚举，$(i,j)$ 与 $(j,i)$ 各算一次。
数据规模：$n \leqslant 500$，$0 \leqslant m \leqslant 250000$，$-10^9 \leqslant d_e \leqslant 10^9$，
保证没有负环。

把每一项拆开看：$j$ 从 $i$ 不可达时贡献 $2 \times 10^{16}$（因为 $\mathrm{Dis}(i,j)$ 本身就是 $f$），
可达时贡献「最短距离 $+ f$」。所以本题只有两件事要做——**读懂那段程序**，
以及**求出所有点对的最短距离**。

## 正解

### 思路

**第一步：那段程序在算什么。** 题面给的是一段代码而不是一句话，先把它翻译成人话：

```cpp
long long S, f = 1e16;
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= n; j++)
        S ^= Dis(i, j) + f;
```

不是求和、不是取模、也不是最大值，而是把 $n^2$ 个 $\mathrm{Dis}(i,j)+f$ **全部异或**起来。
异或与顺序无关，于是这个程序的唯一难点就落在了「把 $n^2$ 个 $\mathrm{Dis}(i,j)$ 都算出来」。

**第二步：为什么只能是 Floyd。** 需要全源最短路，候选做法有三种，代入 $n \leqslant 500$、$m \leqslant 250000$ 比一比：

| 做法 | 复杂度 | 代入规模 | 结论 |
| --- | --- | --- | --- |
| 以每个点为源跑堆优化 Dijkstra | $O(n\,m\log n)$ | $500 \times 250000 \times 18 \approx 2.3 \times 10^9$ | 太慢；而且负权边根本不能直接进 Dijkstra |
| 以每个点为源跑 SPFA | 单次最坏 $O(nm)$ | 最坏 $500 \times 500 \times 250000 = 6.3 \times 10^{10}$ | 卡不住，随时被构造数据打崩 |
| Floyd | $O(n^3)$ | $500^3 = 1.25 \times 10^8$ | 可行，而且天然支持负权边（只要无负环） |

两个关键点：$n$ 只有 $500$，$n^3$ 是 $1.25 \times 10^8$ 这个量级，正好是「能过」的规模；
而边权可以为负，这一条直接把 Dijkstra 排除在外（用 Johnson 势函数也要先求一遍最短路，绕回原点）。
所以本题就是 Floyd 的模板题，出题人甚至把「求最短路」这一步藏在了「读懂程序」后面。

**第三步：Floyd 的循环不变式。** 记 `dis[i][j]` 为「只允许把编号 $\leqslant k$ 的点当作中转点」时
$i$ 到 $j$ 的最短距离。外层枚举中转点 $k$，内层用 $i \to k \to j$ 这条两段路去松弛 $i \to j$：

$$\texttt{dis}[i][j] \leftarrow \min\bigl(\texttt{dis}[i][j],\ \texttt{dis}[i][k] + \texttt{dis}[k][j]\bigr).$$

每跑完一轮 $k$，允许的中转点集合就多了一个 $k$，不变式成立；当 $k$ 走到 $n$ 时中转点不再受限，
`dis[i][j]` 就是真正的最短路。初始化很直接：`dis[i][i] = 0`（题面规定），其余为 $f = 10^{16}$；
读边时 `dis[s][t] = min(dis[s][t], d)`，重边只留最短的一条。

**第四步：本题唯一容易踩的坑——负权下 INF 不能直接参与比较。** 很多人的 Floyd 模板写成

```cpp
// 危险写法：非负权数据上没问题，本题会出错
if (dis[i][k] + dis[k][j] < dis[i][j]) dis[i][j] = dis[i][k] + dis[k][j];
```

它默认「$\text{INF} + \text{任何东西} > \text{INF}$」，这在非负权数据上成立。但本题 $d_e$ 可以为负：
只要 $\texttt{dis}[i][k] < 0$ 而 $\texttt{dis}[k][j] = \text{INF}$（$k$ 到不了 $j$），就有

$$\text{INF} + \texttt{dis}[i][k] \;<\; \text{INF},$$

于是「$i$ 到 $j$ 不可达」会被改写成一条超长的**假路**；更糟的是，这条假路会在后面的轮次里
继续被当作中转使用，错误从一对点扩散到整张表。正确做法是先判可达性再相加：

```cpp
if (dis[i][k] == INF) continue; // i 到不了中转点 k，本轮 i 松弛不了任何点
...
if (dis[k][j] == INF) continue; // k 到不了 j，这条 i->k->j 根本不存在
```

**第五步：拿样例走一遍。** 样例是 $n = 2$，三条边：$1 \to 2$ 长 $1$、$1 \to 2$ 长 $3$、$2 \to 2$ 长 $0$。
重边取小后 $1 \to 2$ 长 $1$；点 $2$ 只有一条自环，所以 $2$ 到 $1$ 不可达：

| 点对 $(i,j)$ | $\mathrm{Dis}(i,j)$ | $\mathrm{Dis}(i,j)+f$ | 异或完的 $S$ |
| :-: | --: | --: | --: |
| $(1,1)$ | $0$ | $10000000000000000$ | $10000000000000000$ |
| $(1,2)$ | $1$ | $10000000000000001$ | $1$ |
| $(2,1)$ | $10^{16}$（不可达） | $20000000000000000$ | $20000000000000001$ |
| $(2,2)$ | $0$ | $10000000000000000$ | $28300427233787905$ |

前两项只差最低位，异或后只剩一个 $1$；最后一步 $20000000000000001 \oplus 10000000000000000 = 28300427233787905$，
与样例输出一致。这也说明：**可达与不可达的点对在异或里地位相同**，
不要想着「先把不可达挑出来单独处理」。

### 复杂度

- **时间**：Floyd 是三重循环，共 $n^3 = 500^3 = 1.25 \times 10^8$ 次内层松弛，
  每次只做一次加法与一次比较，$O(n^3)$。C++ 实测最慢一组（$n = 500$，$m = 250000$）
  耗时约 $0.13$ s，限时 $1000$ ms 内非常安全。
- **空间**：邻接矩阵 $n^2$ 个 `long long`，$500 \times 500 \times 8\text{B} \approx 2$ MB，
  $O(n^2)$；实测峰值内存 8.4 MB，限 128 MB。
- **Python 版**：算法完全相同，但 $1.25 \times 10^8$ 次内层松弛由解释器逐条执行，
  实测最慢一组约 10 s，会 TLE。这是解释器常数问题，不是算法问题；
  本题的正确提交语言是 C++，Python 版仅用于对照理解与对拍。

## 总结

- **先读懂程序再动手**：本题的题意藏在一段代码里，$S$ 是异或和而不是求和，读错就全错。
  读出「异或」之后，剩下的就只是全源最短路。
- **用约束反推算法**：$n \leqslant 500$ 配上全源最短路需求，$O(n^3)$ 的 Floyd 是唯一顺手的选择；
  $m$ 再大也不影响 Floyd 的复杂度（边只在读入时用一次），负权边又排除了 Dijkstra。
- **负权下 INF 是危险值**：$\text{INF} + \text{负数} < \text{INF}$ 会让「不可达」变成一条假路，
  并且沿着中转点扩散到整张表。凡是「边权可为负 + 用 $10^{16}$ 之类大数当不可达标记」的题，
  都必须显式判断两端可达再松弛，不能把标记值直接丢进加法。
- **重边与自环**：重边只留最短的一条；自环 $s \to s$ 长度为 $0$ 时对 `dis[s][s] = 0` 无影响，
  长度为负的自环就是负环，题面已保证不存在。

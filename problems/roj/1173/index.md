## 形式化题目

记 $i! = 1 \times 2 \times \dots \times i$，要求计算

$$S = 1! + 2! + 3! + \dots + n! = \sum_{i=1}^{n} i!$$

其中 $n$ 是正整数且 $n \leqslant 50$。输出必须是**精确**的十进制整数，不允许近似或取模。

令 $f_i = i!$、$S_i = \sum_{k=1}^{i} f_k$，则本题的结构就是两条递推：

$$f_i = f_{i-1} \times i,\qquad S_i = S_{i-1} + f_i,\qquad f_0 = 1,\ S_0 = 0 .$$

也就是说，第 $i$ 项阶乘可以由第 $i-1$ 项乘上 $i$ 得到，不需要每次都从 $1$ 乘起。

## 正解

### 思路

**第一步：把"每项重算"改成"滚动递推"。**

最直白的写法是对每个 $i$ 从 $1$ 乘到 $i$ 得到 $i!$，再累加，乘法次数是
$\sum_{i=1}^{n} i = O(n^2)$。但 $i! = (i-1)! \times i$，上一轮的乘积这一轮还能用：
只要用一个变量保存"当前阶乘"，每轮乘一次 $i$ 就得到新的 $i!$，乘法次数降到 $n$ 次。

以样例 $n = 5$ 为例，逐轮推演如下（`f` 是当前阶乘，`S` 是已经累加的和）：

| 轮次 $i$ | `f = f * i` | `S = S + f` | 说明 |
| --- | --- | --- | --- |
| 开始 | `f = 1` | `S = 0` | `f = 0! = 1`，加法单位元起步 |
| 1 | `f = 1` | `S = 1` | 得到 $1!$ |
| 2 | `f = 2` | `S = 3` | 得到 $2!$ |
| 3 | `f = 6` | `S = 9` | 得到 $3!$ |
| 4 | `f = 24` | `S = 33` | 得到 $4!$ |
| 5 | `f = 120` | `S = 153` | 得到 $5!$，与样例一致 |

这张表说明两件事：**每一轮只用到上一轮的 `f`**（所以不需要保存所有阶乘），
以及**答案就是在 `f` 每次更新后把它加进去**。

**第二步：解决数值宽度，这是本题真正的瓶颈。**

题目要求精确值，而阶乘增长极快，定长整型装不下：

| $i$ | $i!$ | 十进制位数 | 能否装进 64 位 |
| --- | --- | --- | --- |
| 20 | 2432902008176640000 | 19 | 能（$< 2^{63}-1$） |
| 21 | 51090942171709440000 | 20 | **不能**（$> 2^{64}-1$） |
| 50 | $50!$ | 65 | 不能，差得远 |

$21!$ 就已经越过 64 位无符号整数的上限，而本题 $n$ 最大到 50，$50!$ 有 65 位十进制数字。
因此 C++ 必须手写高精度：参考实现 `std.cpp` 用两个数组分别存当前阶乘与和，
`mul` 里做 `a[i] *= x` 再逐位 `a[i+1] += a[i]/10; a[i] %= 10`，`add` 里做同样的进位。
**这两段进位循环就是全部的手工负担**——数学上要做的仍然只是"乘 $i$"和"加上去"。

Python 的 `int` 是任意精度整数，乘法和加法的进位由解释器内部按机器字打包完成，
所以第一步的模型可以原样落地，不必翻译任何进位代码：

```python
sum(accumulate(range(1, n + 1), mul))
```

- `range(1, n + 1)` 给出 $i = 1, 2, \dots, n$；
- `accumulate(..., mul)` 以 $1 = 0!$ 为起点、把 $1, 2, \dots, n$ 依次乘进累积器，
  产出的正是 $1!, 2!, \dots, n!$ 这个序列，对应 C++ 里反复调用的 `mul(i)`；
- 外层 `sum` 把序列加起来，对应 `add()`。

这两个动作在循环里是**交替进行**的：先由 `f = f * i` 把 `f` 从 $(i-1)!$ 推到 $i!$，
紧接着 `S = S + f` 把它并入答案。由于每一轮只用到上一轮的 `f` 和 `S`（而不是历史全部项），
整个过程中只需要两个大整数。

### 复杂度

记 $D_i$ 为 $i!$ 的十进制位数，$D_i = O(i \log i)$。

- **时间复杂度**：第 $i$ 步是"$D_{i-1}$ 位整数乘一个不超过 50 的小整数"，代价 $O(D_{i-1})$；
  累加两个 $D_i$ 位整数同样 $O(D_i)$。总计 $\Theta\!\left(\sum_{i=1}^{n} D_i\right) = O(n \cdot D_n)$，
  $n = 50$ 时约为几千次机器字运算，实测单组数据 0.017 s（含解释器启动）。
  这与 C++ 参考实现的十进制高精度做法**同阶**，区别只在进位的实现层面。
- **空间复杂度**：$O(D_n)$。`range` 与 `accumulate` 都是惰性的，不物化阶乘序列，
  任意时刻只保存"当前阶乘"与"当前和"两个大整数；$n = 50$ 时约 65 位十进制数字。

## 总结

- 本题的计算只有两条递推：$f_i = f_{i-1} \times i$ 与 $S_i = S_{i-1} + f_i$。
  用滚动变量维护 $f$，就把朴素写法的 $O(n^2)$ 次乘法降到 $n$ 次，且与 C++ 参考实现的骨架一致。
- 真正的瓶颈是**数值宽度**而不是循环次数：$21!$ 已经超出 64 位整数，$50!$ 有 65 位，
  所以必须用高精度。Python 的 `int` 任意精度且自带进位，本题不需要手写 `mul` / `add` 的进位循环。
- Python 侧记住这条映射：`accumulate(..., mul)` = C++ 的高精乘 `a *= i`，
  `sum(...)` = 高精加，两者一起构成 `sum(accumulate(range(1, n + 1), mul))` 这一行答案。
- 官方 10 组数据实测全部通过（10/10），单组约 0.017 s、峰值内存 14.5 MB，
  相对 1000 ms / 128 MB 的限制十分宽裕。

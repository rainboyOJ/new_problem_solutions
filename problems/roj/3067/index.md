## 形式化题目

给定 $N \times M$ 的 01 矩阵 $A$，格子 $(i,j)$ 与 $(k,l)$ 之间的曼哈顿距离为 $|i-k|+|j-l|$。对每个格子求

$$B[i][j]=\min_{A[x][y]=1}\{|i-x|+|j-y|\}$$

即到**最近的**一个 $1$ 的曼哈顿距离，输出矩阵 $B$。

## 正解

### 思路

**朴素做法**：对每个格子 $(i,j)$，枚举全部 $NM$ 个格子找最近的 $1$，单格 $O(NM)$，总计 $O(N^2M^2)$。$N=M=1000$ 时是 $10^{12}$ 量级，完全不可行——而且大量枚举是重复劳动：相邻的两个格子，答案几乎总是一样的或只差 1。

**关键观察：距离结构天然分层。** 想象从每一个 $1$ 同时向四周"泛洪"（波纹扩散）：距离为 $0$ 的格子就是那些 $1$ 本身；离所有 $1$ 的距离都恰好为 $d$ 的格子，一定与某个距离为 $d-1$ 的格子上下左右相邻。于是"格子到最近 1 的距离"恰好等于**从全体 1 出发做 BFS 的层数**：

- BFS 从**所有** $1$ 同时出发（距离 $0$），放进同一个队列——这就是**多源 BFS**（超级源点技巧：想象一个虚拟源点向所有 $1$ 连边，等价于把它们一起塞进队列初始层）。
- 每弹出一个格子，尝试扩展它的四邻；邻居尚未被访问过（距离还是 $-1$），就把它的距离设为当前距离 $+1$ 并入队。

正确性与普通 BFS 相同：队列中的距离单调不减，每个格子**第一次**被扩展到时用的路径层数就是最小层数。而曼哈顿距离下每个中间格子都恰好比目标近 1，所以"层内步数 = 曼哈顿距离"，且队列保证第一次到达即最近。若矩阵里没有任何 $1$，题面保证最小值在非空集合上取，此情形不出现；每个格子只入队一次，答案自然填满整个矩阵。

用样例看波纹扩散过程（`*` 表示该轮新被点亮的格子，数字为最终距离）：

| 轮次 | 队列里的格子（距离） | 此时矩阵状态（`.` 为未确定） |
| :---: | :--- | :--- |
| 初始 | 四个 1（距离 0） | `...0` / `..00` / `.00.` |
| 第 1 层 | (1,3)(2,2)(2,3)(3,1)(3,2) 的邻居 → 距离 1 | `..10` / `.100` / `100.` |
| 第 2 层 | 距离 1 格子的新邻居 → 距离 2 | `.210` / `2100` / `1001` |
| 第 3 层 | (1,1) → 距离 3 | `3210` / `2100` / `1001` |

再看一眼距离矩阵与队列的对应关系：

```mermaid
flowchart LR
    Q0["第 0 层队列<br/>00 格子: 4 个"] -->|"扩展 +1"| Q1["第 1 层队列<br/>距离 1: 5 个"]
    Q1 -->|"扩展 +1"| Q2["第 2 层队列<br/>距离 2: 3 个"]
    Q2 -->|"扩展 +1"| Q3["第 3 层队列<br/>距离 3: 1 个"]
    Q3 -->|"队列空，BFS 结束"| Done["B 矩阵填满"]
```

每一轮恰好把"离最近 1 的距离 = 当前层数"的格子全部确定，队列空时整个矩阵填完。

**实现细节**：把矩阵压成一维下标 $i \cdot M + j$，四邻用 `±1`（列方向）与 `±M`（行方向）表示，用 `r, c = divmod(u, m)` 判断是否越界，省去二维坐标与边界判断的样板代码；`dist` 数组兼任"是否访问过"标记。每个格子至多入队一次，总时间 $O(NM)$，$10^6$ 规模毫无压力。

### 复杂度

- 时间复杂度：$O(NM)$。每个格子至多入队、出队各一次，每次检查 4 个邻居。

## 总结

- **多源 BFS** 解决"到最近源点集合的距离"这一类问题：把所有源点距离置 0、一起入队，BFS 层数就是答案，时间 $O(NM)$，比逐格枚举的 $O(N^2M^2)$ 降了两个数量级。
- 判定信号：题目问"每个位置到最近的某个特殊格子的距离"，且距离按步数（四邻 +1）度量——这正是 BFS 分层的形状。
- 同类模型：01 矩阵最远距离（两次扫描/单调队列）、火的蔓延、多个起点的时间扩散等，全部可以用"超级源点 + 一次 BFS"统一处理。

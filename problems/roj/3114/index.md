## 形式化题目

给定平面上的 $n$ 个轴平行闭矩形 $R_k = [x_{1k}, x_{2k}] \times [y_{1k}, y_{2k}]$，
其中 $x_{1k} < x_{2k}$、$y_{1k} < y_{2k}$，坐标可为实数。要求所有矩形的面积并

$$\left|\bigcup_{k=1}^{n} R_k\right|$$

即被至少一个矩形覆盖的区域的面积，重复覆盖只计算一次。坐标可以不是整数，需要按浮点处理。
坐标系方向（题面 $x$ 向下、$y$ 向右）只影响方位命名，不影响面积，下面按普通坐标轴说明。

数据范围：$1 \leqslant n \leqslant 10000$，$0 \leqslant x_1 < x_2 \leqslant 100000$，
$0 \leqslant y_1 < y_2 \leqslant 100000$；$n = 0$ 表示输入结束。

样例：两个矩形 $(10,10,20,20)$ 与 $(15,15,25,25.5)$，重叠区是
$[15,20]\times[15,20]$，面积 $100 + 105 - 25 = 180$，故答案为 `180.00`。

## 暴力解法

### 思路

面积并的原始定义是「被覆盖点集的测度」，最直接的切入点是把平面切碎成小块，
逐块判断是否被覆盖。切分的关键依据是：

> 任何矩形的 $x$ 边界只会出现在 $x_{1k}$ 或 $x_{2k}$ 处，
> 所以把全部 $x$ 坐标排序去重得到 $x_1^* < x_2^* < \cdots < x_X^*$ 后，
> 每个竖条 $[x_i^*, x_{i+1}^*)$ 内部**不包含任何矩形的竖直边**。

由此得到一个竖条内的覆盖情况是恒定的：矩形 $R_k$ 要么完整盖住整个竖条的 $x$ 跨度，
要么与它完全不相交，不存在「盖一半」的矩形。于是

$$\text{ans} = \sum_{i=1}^{X-1} \bigl(x_{i+1}^* - x_i^*\bigr)\cdot
\Bigl|\bigcup_{k \in S_i} [y_{1k},\, y_{2k}]\Bigr|,\qquad
S_i = \{\, k \mid x_{1k} \leqslant x_i^*,\ x_{2k} \geqslant x_{i+1}^* \,\}$$

括号内是一个一维问题：把 $S_i$ 中矩形的 $y$ 区间排序后从左往右合并，
累加各段长度即可。

样例的两个矩形产生 $x$ 坐标 $\{10, 15, 20, 25\}$，对应 3 个竖条（$R_1 = [10,20]\times[10,20]$，
$R_2 = [15,25]\times[15,25.5]$）：

```text
 25.5 |                 +-------------------------+   <- R2 上边
      |                 | R2                      |
      |                 |                         |
   20 |    +------------+------------+            |   <- R1 上边 (与 R2 相交)
      |    | R1         |            |            |
      |    |            |            |            |
   15 |    |            +------------+------------+   <- R2 下边 (与 R1 相交)
      |    |                         |
      |    |                         |
   10 |    +-------------------------+               <- R1 下边
      +----+------------+------------+------------+
          10           15           20           25
          |            |            |            |
          └─ 竖条1 ─────┴─ 竖条2 ────┴─ 竖条3 ────┘
```

| 竖条 | $x$ 跨度 | 完整覆盖它的矩形 | $y$ 区间并 | 覆盖长度 | 贡献面积 |
| :-- | :-- | :-- | :-- | :-: | :-: |
| 1 | $[10,15)$ | $R_1$ | $[10,20]$ | 10 | $10 \times 5 = 50$ |
| 2 | $[15,20)$ | $R_1, R_2$ | $[10,25.5]$ | 15.5 | $15.5 \times 5 = 77.5$ |
| 3 | $[20,25)$ | $R_2$ | $[15,25.5]$ | 10.5 | $10.5 \times 5 = 52.5$ |

三个竖条贡献相加 $50 + 77.5 + 52.5 = 180$，与样例一致。
观察点：竖条 2 里两个矩形都参与，一维合并把重叠的 $[15,20]$ 只算了一次——
这就是「重复覆盖只计一次」在实现层面的落点。

### 复杂度

- 时间 $O(n^2 \log n)$：竖条数 $X - 1 = O(n)$；每个竖条要 $O(n)$ 筛选矩形，
  再对至多 $n$ 个区间排序合并 $O(n \log n)$。$n = 10^4$ 时约 $10^8$ 量级，Python 必然超时。
- 空间 $O(n)$。

### 瓶颈

瓶颈不在「离散化」这一步——竖条的划分是必要的，问题出在**每个竖条都要从头重算**：

1. 筛选 $S_i$ 需要扫一遍全部 $n$ 个矩形；
2. 求出 $S_i$ 后还要重新排序、重新合并一遍 $y$ 区间。

但相邻竖条的 $S_i$ 之间只差「在 $x_{i+1}^*$ 结束的矩形」与「在 $x_{i+1}^*$ 开始的矩形」，
覆盖长度的变化是**增量**的。既然只有竖边处会变，为每个竖条重做一次完整的一维区间并
就是纯粹的浪费。

## 正解

### 关键观察

把「关注竖条」换成「关注竖边」，瓶颈立刻消失：

> 矩形 $R_k$ 的两条竖直边 $x = x_{1k}$、$x = x_{2k}$ 携带增量 $+1$、$-1$。
> 按 $x$ 升序依次处理（同 $x$ 的边连续处理），则**处理完 $x_{\text{prev}}$ 处的全部竖边后**，
> $y$ 轴上被覆盖的总长度，就是区间 $[x_{\text{prev}}, x_{\text{next}})$ 上的覆盖长度。

展开就是：进入竖条 $[x_i^*, x_{i+1}^*)$ 的矩形满足 $x_{1k} \leqslant x_i^*$ 且 $x_{2k} \geqslant x_{i+1}^*$。
对竖条内任意 $y$，$R_k$ 覆盖它的充要条件是 $x_{1k} \leqslant x_i^*$ 且 $x_{2k} > x_i^*$
（因为 $x_i^*$ 与 $x_{i+1}^*$ 之间没有矩形的竖直边，$x_{2k} > x_i^*$ 会自动加强为 $x_{2k} \geqslant x_{i+1}^*$）。
而「$+1$ 边已处理」等价于 $x_{1k} \leqslant x_i^*$，「$-1$ 边未处理」等价于 $x_{2k} > x_i^*$，
二者的次数差就是该 $y$ 处被覆盖的次数。于是这个集合在整段上不变，
「当前总覆盖长度」是一个**只依赖已处理竖边**的量，可以增量维护，
不必每个竖条重新求区间并。

剩下的问题变成：维护一个 $y$ 轴上的**动态区间加 / 询问总覆盖长度**结构。
这正是线段树的经典应用——把所有 $y_{1k}, y_{2k}$ 离散化，
在「段」上做区间加 $\pm 1$，并维护整棵树被覆盖的长度。

### 思路

**第一步，离散化 $y$。** 把全部 $y_{1k}, y_{2k}$ 排序去重得到 $m + 1$ 个坐标，
形成 $m$ 个基本段，第 $i$ 段是 $[y_i, y_{i+1}]$，长度 $y_{i+1} - y_i$。
线段树就建在这 $m$ 个段上（叶子是段，不是点）。矩形 $R_k$ 落在段编号
$[\text{rank}(y_{1k}),\ \text{rank}(y_{2k}) - 1]$ 上，因为 $y_{2k}$ 是段的右端点，
不应该再往右多算一段。

**第二步，确定每个结点存什么。** 每个结点维护两个值：

- `cover_cnt`：**完整覆盖**该结点段区间的竖边条数。关键性质是它**不下传**；
- `cover_len`：该结点段区间内被覆盖的总长度。

回填（`pushup`）规则：

$$
\text{cover\_len} =
\begin{cases}
y_{nr+1} - y_{nl}, & \text{cover\_cnt} > 0 \quad\text{（整段被覆盖，长度直接是段长）}\\[2pt]
0, & \text{cover\_cnt} = 0 \ \text{且是叶子}\\[2pt]
\text{cover\_len}_{左} + \text{cover\_len}_{右}, & \text{其他（由子结点拼出）}
\end{cases}
$$

为什么 `cover_cnt` 不下传也正确？因为一个结点只有两种状态：
被**整段**覆盖时长度由自己决定（哪怕子结点什么都没记），
否则长度必然等于左右儿子之和。被部分覆盖的信息已经记在更深层的结点上，
父结点不需要重复计数，也不会漏算。

**第三步，扫描竖边。** 把 $2n$ 条竖边 $(x, l, r, \pm 1)$ 按 $x$ 升序排序
（$l, r$ 是段编号，$r$ 含端点；为与代码对应，记 $m = \text{seg\_cnt}$），
顺序处理：先按「上一条边之后的状态」结算区间 $[x_{\text{prev}}, x)$，
再应用本条边的区间加。**结算必须在更新之前**，这是最容易写反的地方。

```text
area = 0; prev_x = edges[0].x
for (x, l, r, d) in edges:
    area += cover_len[根] * (x - prev_x)    # 结算 [prev_x, x)，此时树里只有 x' <= prev_x 的边
    cover(1, 0, m-1, l, r, d)               # 再应用本条边
    prev_x = x
```

样例的 4 条竖边（$y$ 去重后为 $10, 15, 20, 25.5$，$m = 3$ 段：$[10,15],[15,20],[20,25.5]$，
编号 $0,1,2$）：

| 顺序 | $x$ | 类型 | 覆盖段 | $\Delta x$ | 结算前 `cover_len` | 本段贡献 | 更新后 `cover_len` |
| :-: | :-: | :-- | :-- | :-: | :-: | :-: | :-: |
| 1 | 10 | $R_1$ 左 | $0 \sim 1$ | 0 | 0 | 0 | 10 |
| 2 | 15 | $R_2$ 左 | $1 \sim 2$ | 5 | 10 | 50 | 15.5 |
| 3 | 20 | $R_1$ 右 | $0 \sim 1$ | 5 | 15.5 | 77.5 | 10.5 |
| 4 | 25 | $R_2$ 右 | $1 \sim 2$ | 5 | 10.5 | 52.5 | 0 |

四段贡献 $0 + 50 + 77.5 + 52.5 = 180$，与暴力层竖条表逐条对应：
第 $j$ 行的「结算前 `cover_len`」正是第 $j$ 个竖条的覆盖长度。
观察点有两个：一是第一行 $\Delta x = 0$（还没走过任何宽度），
二是相同 $x$ 上的多条竖边可以任意顺序处理，因为此时 $\Delta x = 0$，
中间不会插入错误的贡献。

### 复杂度

- 时间 $O(n \log n)$：竖边排序 $O(n \log n)$；$2n$ 条竖边各做一次
  $O(\log n)$ 的区间加，每次 `pushup` 是常数次算术；面积累加 $O(n)$。
  离散化排序同样 $O(n \log n)$。
- 空间 $O(n)$：`ys`、`y_rank`、`edges` 与两棵四倍数组均为线性。

## 总结

- 破题点是**竖条内部覆盖状态恒定**：所有矩形的竖直边只落在有限个 $x$ 坐标上，
  于是二维面积并可拆成有限个竖条，竖条内的覆盖是一维区间并。
- 暴力做法每个竖条重算一次区间并，瓶颈是 $O(n^2\log n)$；
  观察到相邻竖条之间只差一小部分竖边，把「竖条」换成「竖边事件」，
  覆盖长度就能增量维护。
- 增量维护的工具是**线段树**：`cover_cnt` 记录整段被覆盖次数且不下传，
  `cover_len` 按「整段覆盖→段长 / 叶子→0 / 否则左右相加」回填，
  区间加与询问都是 $O(\log n)$。
- 扫描线上两个容易写错的细节：**先结算 $\Delta x$ 再更新**；
  以及 `y` 区间是**段**不是点，右端点要减 1。
- 同一套模型可以直接推广到矩形周长并：把面积换成「相邻竖条覆盖长度之差」
  与「竖条内被覆盖段数」，只需要在线段树上多维护一个段数与左右端点是否被覆盖。

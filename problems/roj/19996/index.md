## 题目描述

给出一个 $k$ 位十进制整数 $n$，对它进行**按位四舍五入**：从最低位开始向前依次操作当前数从右数第 $j$ 位——该位数字 $\leqslant 4$ 就把它及其右侧所有位全部置 $0$；$\geqslant 5$ 同样置 $0$，但向左一位进 $1$，进位按十进制连锁传播，最高位进位可使位数增加（位数编号规则不变）。共执行 $k-1$ 次操作（$k=1$ 时无操作）。每组数据第一行是位数 $k$，第二行是 $n$（共 $T$ 组）；输出从原数开始共 $k$ 个数，用 `" -> "` 连接。

**输入样例**：第一行 `3` 表示 3 组数据，三组依次为 `k=4, n=2023`、`k=1, n=9`、`k=3, n=197`。**输出样例**：`2023 -> 2020 -> 2000 -> 2000`、`9`、`197 -> 200 -> 200`（每组一行）。**数据范围**：$1 \leqslant T \leqslant 10$，$1 \leqslant k \leqslant 100$。

## 思路

每一步就是把"当前数"舍入到 $10^j$ 的倍数（从右数第 $j$ 位 $\geqslant 5$ 就进位）：$n$ 最多 100 位装不进整数，用字符串读入、逆序存进数组（个位在 0 号位）模拟。关键在两点：低位进位会改写高位数字，所以每步必须看当前数而不是原始数（如 14995 最低位进位后千位 4 变 5，之后还要再进位）；某位达到 10 要用 while 连锁向高位进位并预留位数增加的空间（如 299997 -> 300000、95 -> 100）。每步判断与置 0 是 $O(1)$，进位链最多 $O(k)$，总复杂度 $O(k^2)$。

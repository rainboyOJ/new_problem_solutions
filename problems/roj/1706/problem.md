### 【题目描述】

给定正整数$m$以及$n$个$01$串$s_1\sim s_n$，你需要求出长度为$2m$的反对称的包含这$n$个$01$串作为子串的$01$串的个数。$998244353$取模。
一个$01$串$s$是反对称的当且仅当它对于$1≤i≤|s|$都满足$s[i]≠s[|s|-i+1]$。

### 【输入】

第一行两个整数$n,m$。接下来$n$行每行一个字符串$s_1\sim s_n$。

### 【输出】

一行一个整数表示答案。

### 【输入样例】

```
2 3
011
001
```

### 【输出样例】

```
4
```

### 【提示】

【数据规模】
对于10%的数据，$m≤15$。
对于40%的数据，$n≤4，|s_i|≤20$。
对于60%的数据，$n≤6，|s_i|≤30，m≤100$。
对于另外20%的数据，$n=1$。
对于100%的数据，$n≤6，|s_i|≤100，m≤500$。

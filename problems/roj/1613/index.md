## 形式化题目

给定非负整数序列 $C_1, C_2, \dots, C_N$ 和常数 $M$。要把这 $N$ 个数按原顺序切成若干个连续段，一段 $C_{l} \dots C_{r}$ 的费用为该段和的平方加上 $M$，即

$$\left(\sum_{i=l}^{r} C_i\right)^2 + M$$

求一种切分方式，使所有段的费用之和最小，输出这个最小值。多组数据，读到文件末尾为止。

## 正解

### 思路

**第一步：分段 DP。** 设 $dp_i$ 表示打印前 $i$ 个单词的最小费用，$S_i = C_1 + C_2 + \dots + C_i$ 为前缀和。枚举最后一段的起点 $j$（即前 $j$ 个单词已归入前面的段，第 $j+1 \dots i$ 个单词单独成一段）：

$$dp_i = \min_{0 \leqslant j < i} \left\{ dp_j + (S_i - S_j)^2 + M \right\}, \qquad dp_0 = 0$$

这有 $O(N^2)$ 个候选转移，$N \leqslant 5 \times 10^5$ 时无法接受，必须优化。

**第二步：把「选来源」变成「选直线」。** 展开平方项并整理：

$$dp_i = \min_{0 \leqslant j < i} \left\{ \underbrace{2S_i}_{\text{斜率}} \cdot \underbrace{S_j}_{x_j} + \underbrace{\left(dp_j + S_j^2\right)}_{y_j} \right\} - S_i^2 + M$$

把每个决策 $j$ 看成平面上的点 $P_j = (S_j,\ dp_j + S_j^2)$，那么 $dp_i$ 就是：用斜率为 $2S_i$ 的直线去扫这些点，取最小截距，再减去 $S_i^2$ 加上 $M$。

**第三步：两个单调性引出单调队列。** 最小截距只会在这个点集的**下凸壳**上取到。而本题恰好有两个天然的单调性：

1. $C_i$ 非负 $\Rightarrow$ $x_j = S_j$ 随 $j$ 递增，点按 $j$ 从小到大依次产生，天然按 $x$ 排好序；
2. $S_i$ 递增 $\Rightarrow$ 询问斜率 $k_i = 2S_i$ 只增不减。

于是用单调队列维护下凸壳：

- **队头弹出**：若队头相邻两点的斜率 $\leqslant k_i$，说明切点已经在更右边，队头以后永远不会再优，弹出；
- **队尾弹出**：新点 $P_i$ 入队前，若 $\text{slope}(q_{tail-2}, q_{tail-1}) \geqslant \text{slope}(q_{tail-2}, P_i)$，则 $q_{tail-1}$ 落在上凸的位置上，不可能再成为任何询问的最小截距点，弹出。

每个下标至多进出队列一次，转移总复杂度 $O(N)$。

**斜率怎么比？** 全部用交叉相乘：$\dfrac{y_b - y_a}{x_b - x_a} \leqslant k$ 改写成 $y_b - y_a \leqslant k \cdot (x_b - x_a)$。$S_j \leqslant 5\times10^5 \times 10^3 = 5\times 10^8$（按题面权值上限估计），$dp \leqslant 10^{10}$ 量级，乘积会到 $10^{20}$——Python 的整数无所谓，C++ 需要注意 `long long`。

**一个坑：$C_i = 0$。** 此时会出现 $S_i = S_j$，即 $x$ 相同的重复点。由于 $dp$ 非降，新点的 $y = dp_i + S_i^2$ 必不小于旧点的 $y$，新点完全被旧点覆盖——直接不入队即可。这样队列内 $x$ 严格递增，队头、队尾的比较都不会出现除零（我们用乘法比较，本来也不会除零，但 $x$ 相同的点留在队列里会让凸壳判断出错）。

**边界：$N = 0$。** 一个单词都不用打印，费用为 $0$。

**样例推演**（$N=5,\ M=5$，$C = 5\ 9\ 5\ 7\ 5$，$S = 0,5,14,19,26,31$）：

| $i$ | 处理后队列中的下标 | 队头 $j$ | $dp_i = dp_j + (S_i-S_j)^2 + M$ |
|-----|--------------------|----------|----------------------------------|
| 1 | 0, 1 | 0 | $0 + 25 + 5 = 30$ |
| 2 | 0, 1, 2 | 1 | $30 + 81 + 5 = 116$ |
| 3 | 0, 2, 3 | 2 | $116 + 25 + 5 = 146$ |
| 4 | 0, 2, 3, 4 | 3 | $146 + 49 + 5 = 200$ |
| 5 | 0, 2, 4, 5 | 4 | $200 + 25 + 5 = 230$ |

注意 $i=3$ 时下标 $1$ 被队尾弹出、$i=5$ 时下标 $3$ 被队尾弹出——它们已经不可能再成为最优决策，这正是凸壳在收缩。最终 $dp_5 = 230$，与样例输出一致。

## 图示解析

### 凸壳与切点：为什么队头就是最优决策

下图展示样例推演到 $i = 5$（询问斜率 $k_5 = 2S_5 = 62$）时，队列中的点构成的下凸壳（示意图，纵轴 $y = dp_j + S_j^2$）：

```text
 y
 │                       ● P4(26, 876)      ← 队头即切点：slope(P3,P4)≈52.7 ≤ 62 ≤ slope(P4,P5)=63
 │                  ● P3(19, 507)
 │        ● P2(14, 312)
 │   ● P0(0, 0)
 └──────────────────────────────────── x = S[j]
        P0      P2      P3     P4    P5(31,1191)
```

读图要点：

- 询问直线是一族斜率为 $2S_i$ 的平行线，从下往上平移，第一个碰到的点就是最小截距点（切点）；
- 切点左侧相邻边的斜率一定 $\leqslant k$、右侧相邻边的斜率一定 $> k$；$k$ 只增，所以切点只会右移，被淘汰的队头不必保留；
- 队尾弹出的对象是「上凸点」：如 $P_1(5, 55)$ 在 $P_0$ 与 $P_2$ 连线上方，任何直线扫到 $P_1$ 时都先碰到 $P_0$ 或 $P_2$，它永远不优。

## 总结

- 本题是斜率优化的入门经典：平方代价分段 DP + 决策单调。
- 推导套路：把 $\min$ 里的 $(S_i - S_j)^2$ 展开，将转移改写成「定斜率直线扫点取最小截距」；$x$、斜率两个单调性成立时，用单调队列维护下凸壳即可 $O(N)$。
- 实现要点：斜率比较用交叉相乘防溢出/防除零；$C_i = 0$ 导致的 $x$ 重复点不入队；$N = 0$ 输出 $0$；多组数据逐组重建。

## 形式化题目

给定一个中缀算式字符串，其中只出现括号 `(` `)`、数字 `0-9`、双目运算符 `+ - * / ^`。要求求出它的值：

- `+ - * /` 是普通的左结合双目运算符；
- `/` 是整数除法（商向零截断），`^` 是乘方；
- 括号改变结合顺序，且保证括号两两配对、算式本身合法。

样例：`1+(3+2)*(7^2+6*9)/(2)`，先算括号得 `1+5*103/2`，再按 `*`、`/` 从左到右得 `1+515/2 = 1+257 = 258`。

## 正解

### 思路

**朴素做法错在哪。** 最直接的想法是"从左到右扫一遍，遇到数就记下来，遇到运算符就算"。试一下
`1+2*3`：它会在读到第二个数 `2` 时立刻算 `1+2=3`，最后得到 `9`，而正确答案是 `7`。
问题的根源是**优先级**：`*` 必须等到右边的数读完才能算，而 `+` 必须等右边整段算完才能算。
所以扫描到某个运算符时，还有一批"先算谁"的信息没被使用。

**保留这批信息。** 想象一个只存放"还没轮到执行的运算符"的栈：

- 读到 `+`，栈里已经有 `*` —— 说明 `*` 更该先算，先把 `*` 执行掉，再压 `+`；
- 读到 `*`，栈里是 `+` —— `+` 得等 `*` 的结果，不能让 `+` 先走，直接把 `*` 压栈；
- 同级时按从左到右，也就是把栈里同级的先执行掉，再压新的（左结合）。

把这个"什么时候弹栈"的规则写清楚，就是**调度场算法**：数字直接输出，运算符先让栈里
优先级不低于自己的运算符出栈，再自己入栈。等整个串扫完，把栈里剩下的运算符依次弹出。
这样一来，"谁先算"被一次性编码进了输出序列的顺序里。

**为什么输出序列可以直接求值。** 经过上面处理的输出序列，每个运算符都恰好紧跟在它的两个
操作数之后 —— 这就是**后缀表达式（逆波兰式）**。对 `1+2*3`：

| 步骤 | 读到 | 输出序列 | 运算符栈 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | `1` | `1` | | 数字直接输出 |
| 2 | `+` | `1` | `+` | 栈空，直接入栈 |
| 3 | `2` | `1 2` | `+` | |
| 4 | `*` | `1 2` | `+ *` | `*` 优先级高于栈顶 `+`，不弹栈 |
| 5 | `3` | `1 2 3` | `+ *` | |
| 6 | 结束 | `1 2 3 * +` | | 栈底到栈顶依次弹出 |

后缀序列 `1 2 3 * +` 的读法就是：先把 `2 * 3` 算成 `6`，再算 `1 + 6 = 7`。求值也只需一个栈：
**数字压栈，遇到运算符就弹出栈顶两个数，先弹出的是右操作数、后弹出的是左操作数**，
算完把结果压回去，最后栈里剩下的唯一一个数就是答案。

**括号怎么处理。** 括号不参与计算，它只规定"里面这一段要先算完"：

- 读 `(`：直接压进运算符栈，当成一道屏障；
- 读 `)`：把栈里 `(` 之上的运算符全部弹出（这些就是括号内部剩余的计算），
  最后把 `(` 弹掉丢弃。`(` 永远不会进入后缀序列。

**`^` 的结合方向要小心。** 数学上幂是右结合的（`2^3^2 = 2^9`）。而本题的数据只有五个，
且都不含连写的幂，两种约定的结果一致。为了让实现与规则一一对应，代码统一采用左结合：
弹栈条件是"栈顶优先级 $\geqslant$ 当前优先级"，这样同级就全部先弹。若将来需要右结合，
只需把 `^` 改成"栈顶优先级 $>$ 当前优先级"才弹。

**`/` 的取整方向。** 正数除法两种取整方式没有区别，样例 `5*103/2 = 515/2 = 257` 也不涉及负数。
但被除数、除数都可能由减法产生负值，题面只说"用整数除法"，明确的做法是按 C/C++ 的
普通整除处理：**商向零截断**，`-7/2 = -3` 而不是 `-4`。

整个过程只扫两遍（转后缀一趟、求值一趟），每趟都是 $O(n)$。

### 复杂度

- 时间复杂度：$O(n)$。`tokens` 逐字符切分一趟；`to_postfix` 里每个运算符最多入栈、出栈各一次；
  `evaluate` 对长度为 $O(n)$ 的后缀序列线性扫一趟。乘方 `^` 在 Python 中是 $O(\log e)$ 次
  乘法（$e$ 为指数），本题指数都很小。
- 空间复杂度：$O(n)$。后缀序列、运算符栈、求值栈的长度都不超过算式长度。
  数据规模下（单个算式，一行输入）常量极小，实测峰值不到 15 MB。

## 总结

- 中缀算式不能从左到右直接算，因为优先级和括号决定了"先算谁"，必须先保留这批信息。
- **调度场算法**把中缀转成后缀，规则只有三条：数字直接输出、`(` 压栈、`)` 弹出到 `(` 为止；
  普通运算符则先弹出栈里优先级 $\geqslant$ 自己的，再入栈。
- 后缀表达式的求值只需要一个栈：数字入栈，运算符弹出两个数算完压回，天然满足优先级。
- 遇到"先算谁"这类问题，先想清楚需要保留哪些中间状态，往往就是一个栈。

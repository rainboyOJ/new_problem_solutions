## 形式化题目

给定一个长度为 $n$ 的数组 $a$。若存在 $1 < i < n$，满足 $a_{i-1} > a_i$ 且 $a_i < a_{i+1}$，则称位置 $i$ 为“山谷点”（注意第一个和最后一个元素不能为山谷点）。
一个数组的价值定义为所有山谷点位置的元素值之和。
至多可以进行 $k$ 次操作，每次操作可以选择一个位置并将其值修改为一个更小的数。
求经过至多 $k$ 次修改后，该数组能达到的最大价值。

数据范围：$1 \le k \le n \le 2000$，$1 \le a_i \le 10^9$。

## 正解

### 思路

首先，题意要求最大化“山谷点”的值之和。我们有至多 $k$ 次机会把某些数变小。为了让某个位置成为山谷点，要么它原本就是山谷点，要么我们可以主动将它改小，使得它严格小于两侧的相邻元素。

关键观察如下：
1. **只有不相邻的位置才能同时是山谷点。**因为若 $i$ 和 $i+1$ 均为山谷点，根据定义必然推出 $a_i < a_{i+1}$ 和 $a_i > a_{i+1}$ 的矛盾。
2. **要让某个非原生山谷点 $i$ 成为山谷点，最优策略必然是直接修改 $a_i$。**
   如果我们去修改 $i-1$ 或 $i+1$ 变小，这不仅消耗了修改次数，反而会让它们更小，导致 $i$ 更加难以成为山谷点。因此，如果 $i$ 要成为山谷点，它的相邻元素在最优解中一定不能被修改，保留原值。
   既然 $i-1$ 和 $i+1$ 保持原值，要使得 $a_i$ 成为山谷点并最大化它的值，我们应该将 $a_i$ 修改为 $\min(a_{i-1}-1, a_{i+1}-1)$。
3. **对于原数组中已经是山谷点的元素，我们绝对不会主动去把它变小。**
   如果把它变小，只会白白损失它的价值；如果放弃它，试图让其相邻元素成为山谷点，相邻元素修改后能达到的最大值必定 $\le a_i-1 < a_i$，收益不增反降且浪费了修改次数。
   因此，原生山谷点如果被放弃，唯一的可能原因是为了在它的**左右两侧（即 $i-1$ 和 $i+1$）同时构造出两个新的山谷点**，以“一换二”的形式获得更大价值。

基于上述观察，我们可以使用动态规划解决此题：
设 `dp[i][j][0]` 表示考虑前 $i$ 个位置，已使用 $j$ 次修改，且第 $i$ 个位置**不是**山谷点时的最大价值。
设 `dp[i][j][1]` 表示考虑前 $i$ 个位置，已使用 $j$ 次修改，且第 $i$ 个位置**是**山谷点时的最大价值。

状态转移如下：
- 若第 $i$ 个位置在原数组中已经是山谷点（满足 $a_i < a_{i-1}$ 且 $a_i < a_{i+1}$）：
  - 它可以直接成为山谷点（无需消耗修改次数），由于相邻不能为山谷点，故从 `dp[i-1][j][0]` 转移过来：
    `dp[i][j][1] = dp[i-1][j][0] + a[i]`
  - 若它不作为山谷点，那么根据前文分析，这必定是因为在第 $i-1$ 处构造了一个山谷点破坏了它（为将来的“一换二”铺路）。因此直接从 `dp[i-1][j][1]` 转移：
    `dp[i][j][0] = dp[i-1][j][1]`
- 若第 $i$ 个位置在原数组中不是山谷点：
  - 要让它成为山谷点，我们需要消耗 1 次修改次数，并将其值改为 $\min(a_{i-1}-1, a_{i+1}-1)$。前提是 $j > 0$：
    `dp[i][j][1] = dp[i-1][j-1][0] + \min(a_{i-1}-1, a_{i+1}-1)`
  - 若它不成为山谷点，那么它可以承接前一个位置无论是否为山谷点的最大值：
    `dp[i][j][0] = \max(dp[i-1][j][0], dp[i-1][j][1])`

最终答案为所有状态的最大值。由于判断需要用到 $i-1$ 和 $i+1$，并且边界点不可能为山谷点，我们只需从 $i=2$ 遍历到 $i=n-1$ 即可。

### 复杂度

- 时间复杂度：状态数为 $O(n \cdot k)$，转移时间为 $O(1)$，总时间复杂度为 $O(n \cdot k)$。
- 空间复杂度：$O(n \cdot k)$。可以使用滚动数组优化至 $O(k)$，但对于 $N,K \le 2000$ 的数据开普通三维数组仅约 $64\text{MB}$ 左右空间，满足常规内存限制。

## 总结

1. 本题在设计 DP 状态与转移时，很容易误以为原生山谷点可以随便作为“非山谷点”处理而继承任意状态。事实上，“放弃”一个原生山谷点的代价必须被严格约束在“前一个位置被迫成为山谷点”这一特殊情况下，通过 `dp[i][j][0] = dp[i-1][j][1]` 完美地做到了这种状态转移，否则可能会因违背贪心最优性而算入错误情况。
2. 挖掘出**“要想把某点变成山谷点，只需要且只能修改它自身，其余相邻点维持原值”**是解题的核心，这保证了每次修改后的最佳取值可以极其简单地用 $\min(a_{i-1}-1, a_{i+1}-1)$ 求得，无需记录每一个元素实际被修改到了何值。

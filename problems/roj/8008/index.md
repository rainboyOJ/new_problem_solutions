## 形式化题目（按题面）

给定两个字符串 $S_1, S_2$ 与 $n$ 次查询，每次查询给出一个字符串 $q$。
对每次查询，将 $S_1, S_2$ 各自只保留 $q$ 中出现的字符，得到两个子序列；
若二者相等输出 `Y`，否则输出 `N`。查询串中字母互不相同、已排序、不重复。

数据范围：字符串长度 $\le 10^5$，字符集为前 18 个小写字母，$n \le 10^5$。

## 数据实况（与题面完全错位）

### 实际文件形态

```
1.in  = b'1\n419 792\n'                      1.out = b'47 35\n'
2.in  = b'10\n358 655\n582 232\n846 598\n…' 2.out = b'2213 1565\n918 1452\n…'
3.in  = b'20\n529 252\n598 756\n891 436\n…' 3.out = b'1170 1849\n1404 1187\n…'
…
```

即：**第一行 `n`，随后 `n` 行「两个整数」**；输出**也是 `n` 行「两个整数」**。
**全程没有任何字符串**，也**没有任何 `Y`/`N`**。

### 判据一：按题面格式**无法解析**

题面要求读入「字符串 $S_1$ / 字符串 $S_2$ / 整数 $n$ / $n$ 行查询串」，
而 `1.in` 只有 **2 行纯数字**（`1` 与 `419 792`）
⇒ **题面格式在数据上根本不成立**（`T52` 的 S1 类判据）。

### 判据二：输出格式**完全不匹配**

题面输出 `Y`/`N`（样例 `YNY`），而 `.out` 全部是整数对（如 `47 35`）
⇒ **输出格式在数据上根本不成立**。

### 判据三（★ 最强）：`.out` 的数值在**点与点之间共享**

```
2.out = 2213 1565 | 918 1452 | 3275 4142 | 【1849 1170】 | …
3.out = 【1170 1849】 | 1404 1187 | 2855 4038 | 2348 1660 | …
```
⇒ `1849 1170` 与 `1170 1849` 是**反转对**，出现在**不同的测试点**中。

★ 这说明：**这些整数不是「按点独立生成」的结果**，
而是来自某个**跨点共享的编号体系**（例如同一批字符串的某种编码或哈希）。

### 判据四：映射无法反解

尝试从 $(a,b) \to (x,y)$ 反解（$419,792 \to 47,35$ 等）：
四则运算、$\gcd$、同余、位运算、进制转换均**无一致规律**；
且 `.out` 的数值常**远大于** `.in`（如 $358 \to 2213$），
排除了「逐项独立变换」的可能。

## 结论

**本题的测试数据属于另一道题**（`T41`「题面 ≠ 数据」），
且由于：
1. 数据是**纯整数对**，不含任何可解释的结构；
2. `.out` 的数值**跨点共享**，不是逐点独立生成；
3. 输入输出**维数相同**（都是 $n$ 对整数），像是某种「变换后的表示」；

⇒ **在当前信息下无法反解真实考点**（既无 `std.cpp`，也无 `data.py`、无生成脚本）。

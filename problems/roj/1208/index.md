## 题目描述

任何一个正整数都能拆成 2 的幂之和。约定 $2^1$ 写作 `2`，$2^0$ 写作 `2(0)`，$2^k\ (k\ge 2)$ 写作 `2(...)` 且指数 $k$ 继续展开，项之间用 `+` 连接。如 $137=2^7+2^3+2^0$ 最终表示为 `2(2(2)+2+2(0))+2(2+2(0))+2(0)`。

输入：一个正整数 $n$（$n \le 20000$）。输出：一行，$n$ 的 0、2 表示，不含空格。

样例输入：

```
137
```

样例输出：

```
2(2(2)+2+2(0))+2(2+2(0))+2(0)
```

## 思路

取 $x$ 的最高位下标 $i=\lfloor\log_2 x\rfloor$，按 $i=0$、$i=1$、$i\ge 2$ 分别写出 `2(0)`、`2`、`2(expand(i))`，再对剩余 $x-2^i$ 递归并用 `+` 拼接。指数的展开规则与 $x$ 完全相同，同一个函数递归调用自身即可；$x=0$ 返回空串方便拼接。

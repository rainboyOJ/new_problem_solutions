## 形式化题目

给定 $n$ 条网线，第 $i$ 条长度为两位小数（米）。要求把它们切成 $k$ 条**等长**的段（每条原线可贡献多段，剩余部分丢弃），求段长的最大值；输出保留两位小数。若不存在长度至少 $1$ 厘米的可行切法，输出 `0.00`。

把所有长度换算成厘米整数 $a_1, \ldots, a_n$ 后，即求最大的整数 $L \ge 1$ 使得

$$\sum_{i=1}^{n} \left\lfloor \frac{a_i}{L} \right\rfloor \ge k$$

以样例说明：长度 $\{802, 743, 457, 539\}$（厘米），$k = 11$。取 $L = 200$ 厘米时——

| 网线（cm） | $\lfloor a_i / 200 \rfloor$ | 实际切法 |
| :--: | :--: | :--: |
| $802$ | $4$ | $200 \times 4 = 800$，剩 $2$ 厘米丢弃 |
| $743$ | $3$ | $200 \times 3 = 600$，剩 $143$ 厘米丢弃 |
| $457$ | $2$ | $200 \times 2 = 400$，剩 $57$ 厘米丢弃 |
| $539$ | $2$ | $200 \times 2 = 400$，剩 $139$ 厘米丢弃 |
| 合计 | $11$ | 恰好凑够 $k = 11$ 段 |

而 $L = 201$ 厘米时合计只有 $10$ 段，所以答案是 $200$ 厘米 $= 2.00$ 米。

## 暴力解法

### 思路

按定义直接做：切割长度 $L$ 从 $\max a_i$ 往下逐个枚举（所有长度精确到厘米，答案必然是 $1$ 厘米的整数倍），每个 $L$ 用一次 $O(n)$ 扫描检验 $\sum \lfloor a_i / L \rfloor \ge k$ 是否成立，第一个可行的就是答案；扫到 $L = 0$ 仍不可行则输出 `0.00`：

```text
for L in range(max_a, 0, -1):
    if sum(a_i // L) >= k: 输出 L; 结束
输出 0.00
```

正确性显然：可行长度全部被检查，从大到小第一个命中的就是最大值。

### 复杂度

时间 $O(V \cdot n)$，其中 $V$ 是答案域上界：长度至多 $100$ 公里 $= 10^7$ 厘米，$n \le 10^4$，总计约 $10^{11}$ 次整除。

### 瓶颈

答案域 $10^7$ 太大，而单次检验 $O(n)$ 并不便宜，逐点枚举不可承受。浪费的本质在于：**可行性关于 $L$ 单调，但暴力没有利用它**——明知某个 $L$ 不可行还去试 $L-1, L-2, \ldots$，明知可行还继续向下扫。

## 正解

### 思路

**一句话本质**：切出段数随切割长度单调不增，"最大可行长度"就是一个单调判定问题——整数化后开区间二分，$O(n \log V)$。

**第一步：整数化，绕开浮点。** 题面所有长度"精确到厘米"，即答案落在 $0.01$ 米的整数倍网格上。把每个长度乘 $100$ 变成厘米整数，答案就是 $[1, \max a_i]$ 里的整数，二分天然精确。注意换算要写 `int(float(x) * 100 + 0.5)` 而不是 `int(float(x) * 100)`：`float("8.02") * 100` 在二进制浮点里是 $801.9999\ldots$，直接截断会丢 $1$ 厘米；加 $0.5$ 四舍五入即可无损还原（真实数据中形如 `56.100` 的三位小数都是尾零写法，数值仍是两位小数，同样被覆盖）。

**第二步：单调性。** 令 $f(L) = \sum_i \lfloor a_i / L \rfloor$。正整数上除数变大、商不会变大，所以 $L_1 < L_2 \Rightarrow f(L_1) \ge f(L_2)$：**可行域是前缀 $[1, L^*]$**。于是"求最大可行 $L$"等价于"找可行与不可行的分界点"，对半排除即可。

**第三步：开区间二分。** 维护不变量：`lo` 总是可行的（初值 $0$——一个虚拟的"永远可行"哨兵，恰好对应题面"切不出 1 厘米就输出 0.00"的约定），`hi` 总是不可行的（初值 $\max a_i + 1$，比最长网线还长必然一段都切不出）。每轮 `mid = (lo + hi) // 2`：

- $\sum \lfloor a_i / \text{mid} \rfloor \ge k$：`mid` 可行，答案不小于它，`lo = mid`；
- 否则：答案小于它，`hi = mid`。

当 `lo + 1 == hi` 时区间只剩分界，`lo` 即答案；`lo = 0` 即无解，直接输出 `0.00`——**无解分支被哨兵吸收，一行特判都不用写**。循环条件 `lo + 1 < hi` 同时保证 `mid ≥ 1`，不会零除。

以样例（$\{802, 743, 457, 539\}$，$k=11$，上界 $803$）演示二分收敛，$6$ 轮后区间收缩到 $[200, 201]$：

| 轮次 | lo（可行） | hi（不可行） | mid | $f(\text{mid})$ | $\ge 11$ ? | 动作 |
| :--: | :--: | :--: | :--: | :--: | :--: | :--: |
| 初始 | $0$ | $803$ | — | — | — | — |
| 1 | $0$ | $803$ | $401$ | $5$ | ✗ | hi = 401 |
| 2 | $0$ | $401$ | $200$ | $11$ | ✓ | lo = 200 |
| 3 | $200$ | $401$ | $300$ | $6$ | ✗ | hi = 300 |
| 4 | $200$ | $300$ | $250$ | $8$ | ✗ | hi = 250 |
| 5 | $200$ | $250$ | $225$ | $10$ | ✗ | hi = 225 |
| 6 | $200$ | $225$ | $212$ | $10$ | ✗ | hi = 212 |

之后继续减半到 `hi = 201`（$f(201) = 10 < 11$，确为分界），输出 $200$ 厘米 $= 2.00$ 米。区间每轮至少减半，$V \le 10^7 + 1$ 时至多 $\lceil \log_2 10^7 \rceil = 24$ 轮。

## 总结

- "最大化最小值 / 最大化可行长度"是二分答案的信号：先写出 $O(n)$ 的单调判定 $\sum \lfloor a_i / L \rfloor \ge k$，再对答案域对半排除；答案域 $10^7 \gg$ 判定代价 $10^4$，二分收益最大。
- "输出精确到两位小数 + 答案就是精确值"往往意味着**答案在整数网格上**：长度统一乘 $100$ 化整后全程整数运算，浮点二分的 eps、迭代次数、`8.02 × 100 = 801.99…` 截断坑一次性消失；唯一要记得的是换算时 `+0.5` 四舍五入。
- 开区间二分用 `lo = 0` 的"总是可行"哨兵初始化，把"无解输出 0.00"的题面分支吸收进统一出口，代码零特判；`lo + 1 < hi` 的收敛条件同时排除了零除。
- 真实数据 10 个测点全部一致：单点 0.016–0.020 s、峰值内存约 15.8 MB，对 1000 ms / 128 MB 的限制十分宽裕。

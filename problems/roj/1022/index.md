## 形式化题目

给定一个整数 $n$，把它赋给布尔型变量，再把该布尔型变量的值赋回整型变量，求最终得到的整数。

样例：输入 `3`，输出 `1`。

## 正解

### 思路

题面已经把计算链写出来了，照着类型语义翻译即可：

1. **整型 → 布尔型**：`bool(n)` 回答"$n$ 是否非零"。Python 中 `bool(0)` 是 `False`，而任何非零整数（包括负数）都是 `True`。这一步把整数的"数值大小"全部丢掉，只保留一个比特的信息：**是否非零**。
2. **布尔型 → 整型**：`int(True)` 是 1，`int(False)` 是 0。这一步把那个比特编码回整数。

两步合起来，输出就是"非零则 1、为零则 0"，即 $[n \neq 0]$。以样例 $n = 3$ 为例：

| 步骤 | 表达式 | 结果 |
| --- | --- | --- |
| 读入整数 | `int(b'3\n')` | $n = 3$ |
| 整型 → 布尔型 | `bool(3)` | `True` |
| 布尔型 → 整型 | `int(True)` | $1$ |

为什么不需要任何"算法"：输入规模是一个常数长度的整数，计算链长度也是常数 2，不存在随数据增长的代价，也就没有可优化的瓶颈——再写一个暴力版本只会得到一模一样的代码。本题真正要练的是**类型转换的语义**：`bool` 只保留"是否非零"，`int(bool(n))` 正是许多语言里惯用的"归一化成 0/1"写法。

一个容易踩的坑：负数不是 0，`bool(-7)` 是 `True`，所以 $-7$ 的答案是 1 而不是 0。

### 复杂度

- 时间复杂度 $O(1)$：一次读入、一次 `bool` 判断、一次 `int` 转换。
- 空间复杂度 $O(1)$：只存一个整数。

## 总结

布尔型是整型的"信息压缩"：`bool(n)` 只留下 $n \neq 0$ 这一位，`int()` 再把它展开成 1/0。因此 `int(bool(n))` 与题面的 int → bool → int 赋值链完全等价，$O(1)$ 时间、$O(1)$ 空间；唯一要注意的边界是 0 输出 0，其余（含负数）都输出 1。

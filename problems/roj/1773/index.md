## 形式化题目

给定一棵 $N$ 个点的无向树（输入给出编号 $1$ 为国王以及每个点的直接上级，等价于给出
一棵以 $1$ 为根的树；但消息既能向上级传也能向下属传，所以约束只落在无向边上）。
时刻 $0$ 选定一个起点 $s$，花费 $1$ 单位时间把消息告诉 $s$（即 $s$ 在时刻 $1$ 得知消息）。
此后每个单位时间内，**每个**已知消息的点都可以向至多一个尚未知情的邻居传消息，
各点同时进行、互不影响。

记 $g(s)$ 为"若 $s$ 在 $0$ 时刻就已知消息，传遍全树所需的时间"，则总耗时为 $1 + g(s)$。
要求输出

$$\min_{s} \bigl(1 + g(s)\bigr),$$

以及所有取到该最小值的起点编号，按升序用空格分隔。

## 正解

### 思路

**朴素做法。** 枚举起点 $s$，把 $s$ 当作根做一次树形 DP。对每个点 $u$ 定义

$$f[u] = \text{「} u \text{ 已知消息时，} u \text{ 的子树全部知情所需的时间」}.$$

若 $u$ 有 $k$ 个儿子，它每秒只能通知一个儿子，所以耗时大的儿子要优先通知：
把儿子的 $f$ 值从大到小排序成 $f_1 \ge f_2 \ge \dots \ge f_k$，第 $i$ 个儿子在第 $i$ 秒被通知，
于是

$$f[u] = \max_{1 \le i \le k} \bigl(i + f_i\bigr), \qquad \text{叶子 } f[u] = 0 .$$

$g(s) = f[s]$，对每个起点做一遍就是 $O(N^2 \log N)$。$N \le 200\,000$ 时
$N^2$ 达到 $4 \times 10^{10}$，1000 ms 内不可能跑完，必须换根。

**换根：把「删掉一个方向」的答案用前后缀最大值 $O(1)$ 求出。** 起点从 $u$ 挪到相邻的 $v$ 时，
整棵树只有 $u$ 的"方向清单"少了一项。所谓**方向**，就是把 $u$ 的每个邻居看成一个待通知的
分支：儿子 $c$ 方向的耗时是 $f[c]$，父亲方向（记为 $up[u]$）的耗时是"砍掉 $u$ 子树后，
剩下的那一大块从 $u$ 开始扩散完的时间"。

把 $u$ 的全部 $m$ 个方向按耗时降序排成 $w_1 \ge w_2 \ge \dots \ge w_m$，预处理

$$
pref[i] = \max_{1 \le j \le i} \bigl(j + w_j\bigr), \qquad
suff[i] = \max_{i \le j \le m} \bigl((j - 1) + w_j\bigr).
$$

$suff$ 里刻意写成 $j-1$：一旦排在第 $idx$ 位的方向被剔除，
排在它后面的方向在队列里全部**前移一位**，耗时从 $j + w_j$ 变成 $(j-1) + w_j$。
于是

$$up[v] = \max\bigl(pref[idx-1],\; suff[idx+1]\bigr),$$

其中 $idx$ 是 $v$ 在降序序列里的位置；$idx = 1$ 或 $idx = m$ 时对应的越界项取 $0$
（表示那一侧没有方向，不需要再等）。

同时 $u$ 自己的答案就是整张清单的前缀最大值：

$$g[u] = pref[m] \quad(\text{度为 } 0 \text{ 时 } g[u] = 0).$$

整个流程只需两次遍历：先以 $1$ 为根自底向上算出所有 $f[u]$，再自顶向下按上式算出
所有 $up[v]$ 与 $g[u]$，最后取 $1 + \min g[u]$ 并顺序扫出所有最优起点。

**用第二个样例核对一遍。** 树的边为 $1\!-\!2$、$1\!-\!3$、$3\!-\!4$、$3\!-\!8$、$4\!-\!5$、
$4\!-\!6$、$4\!-\!7$。以 $1$ 为根先算 $f$：$f[4] = \max(1,2,3) = 3$（三个叶子儿子）、
$f[3] = \max(1 + 3,\; 2 + 0) = 4$（儿子 $4$ 与 $8$）、$f[8] = 0$。
再换根：

| 起点 $u$ | $u$ 的方向清单（降序） | $g[u]$ | $1 + g[u]$ |
| :-: | :-- | :-: | :-: |
| 1 | $f[3]=4,\; f[2]=0$ | $\max(5,2)=5$ | 6 |
| 2 | $up[2]=5$（$1$ 一侧只剩 $3$ 方向） | $1+5=6$ | 7 |
| 3 | $f[4]=3,\; up[3]=1,\; f[8]=0$ | $\max(4,3,3)=4$ | **5** |
| 4 | $up[4]=2,\; f[5]=f[6]=f[7]=0$ | $\max(3,2,3,4)=4$ | **5** |
| 5 / 6 / 7 | $up[\cdot]=3$ | $1+3=4$ | **5** |
| 8 | $up[8]=4$ | $1+4=5$ | 6 |

最小值 $4$ 出现在 $3,4,5,6,7$，加上最初的 $1$ 单位时间得 $5$，与样例输出
`5` / `3 4 5 6 7` 完全一致。注意 $up[3]=1$ 这一项：它来自节点 $1$ 的清单
$[4,0]$ 去掉 $f[3]$ 后剩下的 $f[2]=0$，虽然值为 $0$，但 $3$ 把它排在第 $2$ 位，
仍然要额外花 $2$ 秒，所以是 $\max(4,\,2+0,\,3+0)=4$ 而不是 $4+1$。

**边界 $N = 1$。** 只有国王一个人，$0$ 时刻花 $1$ 单位时间通知他，答案为第一行 `1`、
第二行 `1`；此时 $u$ 的方向清单为空，$g[1] = 0$，公式给出的 $1 + 0 = 1$ 依然正确。

### 复杂度

- **时间**：第一次 DP 与换根各遍历每个点一次，代价是对该点的邻居排序。
  设点 $u$ 的度数为 $d_u$，树满足 $\sum d_u = 2N - 2$，故排序总耗时为
  $\sum O(d_u \log d_u) \le O(N \log N)$（最坏是菊花图，根要排 $N-1$ 项）；
  前后缀数组的构建与回填 $up$ 都是 $O(d_u)$。总时间 $O(N \log N)$，
  $N = 2 \times 10^5$ 时约 $3.6 \times 10^6$ 次基本运算，实测远低于 1000 ms。
- **空间**：邻接表 $O(N)$，$f / up / g / pref / suff$ 各 $O(N)$，
  单个点的临时清单最坏 $O(N)$（菊花图根节点），总空间 $O(N)$，远低于 256 MB。
- **与 C++ 解法的关系**：两者是同一套换根 DP，复杂度同为 $O(N \log N)$。
  Python 版把两次遍历都写成迭代（BFS 序 + 逆序 / 正序），
  避免 $N = 2 \times 10^5$ 的链触发递归深度上限；由于核心工作是排序，
  常数主要在 `sorted` 上，本题不存在 Python 特有的算法降级。

## 总结

- **先定义好"一个方向的耗时"**：$f[u]$ 管子树、$up[u]$ 管父亲那一侧，
  两者语义对称，换根转移才能写得干净。
- **大耗时分支优先通知**：给定一组方向的耗时，最优策略是把它们降序发送，
  最大完成时间 $\max_i (i + w_i)$；这一步的贪心交换论证是本题的出发点。
- **删一项的极值用前后缀维护**：换根时唯一的变化是清单少一项、后面的项集体前移，
  前缀最大值配一个 $-1$ 偏移的后缀最大值就能 $O(1)$ 回答，
  这是"$O(N^2)$ 枚举根 $\to$ $O(N \log N)$"的关键一步。
- **别忘了初始的 $1$ 单位时间**：题目是"用 1 单位时间把消息告诉某一个人"，
  所以输出要写 $1 + \min g[u]$，直接输出 $g$ 会全部差 1。

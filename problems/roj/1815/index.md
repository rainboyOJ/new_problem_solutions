## 形式化题目

给定一张 $n$ 个点、$m$ 条边的有向无环图，每条边带一个颜色 $c$（边可以有重边、可以有相同颜色）。
图上有 $q$ 颗石子，第 $i$ 颗位于点 $pos_i$，同一个点可以放多颗。

一次操作：选一个有出边且至少有一颗石子的点 $x$，先取走 $x$ 上的**一颗**石子，
再选一个颜色集合 $S$，对**点 $x$ 的**每条颜色属于 $S$ 的出边，在它的终点上各放一颗石子。

双方轮流操作，无法操作者负（Normal Play）。问先手必胜（输出 `1`）还是后手必胜（输出 `0`）。

设 $SG(u)$ 为"点 $u$ 上单独放一颗石子"这个子游戏的 SG 值，则初始局面的 SG 值为

$$SG_{total} = \bigoplus_{i=1}^{q} SG(pos_i),$$

$SG_{total} \ne 0$ 时先手必胜。

> **题意注记。** 原题面写的"对于每条满足颜色 $e \in S$ 的出边 $i$"没有写明是谁的出边，
> 只能理解为**点 $x$ 自己的出边**——否则这条规则与"选点 $x$"毫无关系，题目不可作答。
> 公开样例 `2 1 / 2 1 1 / 1 / 2` 也支持这一读法：$SG(1)=0$（汇点）、$SG(2)=1$，
> 总异或 $1 \ne 0$，输出 `1`，与样例一致。

## 正解

### 思路

**朴素做法与瓶颈。** 最直接的模型是把石子分布写成一个状态向量 $(a_1, \dots, a_n)$，
用记忆化搜索从终态（所有石子都落在出度为 $0$ 的点上）反推 P/N 态。

状态数就已经爆炸：$q$ 颗石子分配到 $n$ 个点的方案数是 $\binom{q+n-1}{n-1}$，
$q \leqslant 10000$ 时是天文数字。而且每个状态的转移分支还要枚举 $2^k$ 种颜色集合
（$k$ 为该点的出边颜色种数）。状态空间与转移分支**双重爆炸**，这条路线不可行。

**关键观察 1：石子之间是独立的。** 一步操作只取走**某一个点**的一颗石子，
再往它的后继上放新石子，整个过程完全不依赖其他石子是否存在、放在哪。
所以 q 颗石子构成 q 个**互不干扰**的独立子游戏，由 Sprague–Grundy 定理：

$$SG_{total} = \bigoplus_{i=1}^{q} SG(pos_i).$$

问题从"$q$ 颗石子的联合局面"塌缩成"每个点单独一颗石子的 SG 值"，与 $q$ 无关。

**关键观察 2：颜色集合 $S$ 的选择对应 $\mathbb{F}_2$ 上的线性张成。**
只考虑点 $x$ 上有一颗石子的局面。把 $x$ 的出边按颜色分组，记

$$h_c(x) = \bigoplus_{(x, y, c) \in E} SG(y),$$

即颜色 $c$ 下**所有**出边终点 SG 值的异或和（同色多条边要逐条异或，不去重、不漏算）。
为什么是异或？因为选了颜色 $c$ 就同时在这些终点上各放一颗石子，这几个新石子又是彼此
独立的子游戏，局面 SG 值就是它们的异或和；不选 $c$ 则贡献为 $0$。

于是选了颜色集合 $S$ 后到达局面的 SG 值为 $\bigoplus_{c \in S} h_c(x)$。
颜色之间"选 / 不选"完全自由，所以 $x$ 能到达的**全部**后继 SG 值集合恰为

$$T_x = \operatorname{span}_{\mathbb{F}_2}\{\, h_c(x) \,\},$$

一个 $\mathbb{F}_2$（二进制异或意义下）的线性子空间。

**关键观察 3：线性基 + mex。** 由 SG 定义 $SG(x) = \operatorname{mex}(T_x)$。
因为 $T_x$ 是线性空间，用"最高位为主元"的线性基消元后有一个漂亮结论：

- 若位置 $0, 1, \dots, k-1$ 全都有主元，则 $0 \sim 2^k - 1$ 全落在 $\operatorname{span}$ 里。
  归纳：主元在 $k-1$ 的基向量形如 $2^{k-1} \oplus r$（$r < 2^{k-1}$ 已在 span 内），
  异或一下就把 $2^{k-1}$ 加了进来，而子空间对异或封闭。
- 若位置 $j$ 不是主元，则 $2^j \notin \operatorname{span}$：任何基向量子集的异或值，
  其最高位恰是所取基向量中最大的主元位，不可能是 $j$。

两者合起来就是：$\operatorname{mex}(T_x) = 2^{j^*}$，$j^*$ 是**最小的非主元位**。
（也就是"找最小线性无关位并置 1"，与逐位枚举 $v = 0, 1, 2, \dots$ 试 representability
的结果一致，但不必真的枚举。）

**正解步骤。**

1. 对 DAG 做逆拓扑排序（Kahn，初值是原图出度为 $0$ 的点，它们的 $SG = 0$）。
2. 处理点 $x$：把出边按颜色分组，算出每个颜色的 $h_c(x)$，依次插入线性基。
3. 找出最小非主元位 $j^*$，令 $SG(x) = 2^{j^*}$。
4. 把 $SG(x)$ 回报给 $x$ 的所有前驱（即累加到前驱的对应颜色桶里，并递减其剩余出度）。
5. 最后把全部 $q$ 颗石子所在点的 $SG$ 值异或起来，非 $0$ 输出 `1`，否则 `0`。

**位宽要多少？** $SG$ 值恒为 2 的幂。若某点 $SG(x) = 2^k$，说明它的后继里出现了
$SG = 2^0, 2^1, \dots, 2^{k-1}$ 的点，各至少一条出边；而 $SG = 2^i$ 的点自己又至少要
$i$ 条出边（它的 $h_c$ 里必须凑出 $i$ 个线性无关的主元）。于是

$$m \;\geqslant\; k + \sum_{i=0}^{k-1} i \;=\; k + \frac{k(k-1)}{2} \;=\; \frac{k(k+1)}{2}.$$

$m \leqslant 5000$ 时 $k \leqslant 99$，即 $SG < 2^{100}$。C++ 用 `bitset<256>`（余量 2.5 倍），
Python 用原生大整数，都不需要额外处理高精度。

**验证。** 公开样例 $n=2, m=1$，边 $2 \to 1$ 颜色 $1$，石子一颗在点 $2$：$SG(1) = 0$（汇点），
点 $2$ 只有一个颜色、$h_1 = SG(1) = 0$，span$=\{0\}$，$SG(2) = \operatorname{mex}\{0\} = 1$。
总异或 $1 \ne 0$ → 输出 `1`，与样例一致。

**小构造对照。** 数据中另有一个手工构造可手算校验：点 $1$ 是汇点，$2 \to 1$（色 1）、
$3 \to 2$（色 2）、$4 \to 2$（色 3）、$4 \to 3$（色 4）。则 $SG(1)=0$、$SG(2)=\operatorname{mex}\{0\}=1$、
$SG(3)=\operatorname{mex}\{1\}=\operatorname{mex}\{0,1\}=2$、$SG(4)=\operatorname{mex}\{1,2\}=\operatorname{mex}\{0,1,2,3\}=4$。
石子 $\{4,3,1\}$ → $4 \oplus 2 \oplus 0 = 6 \ne 0$ → `1`；石子 $\{4,4,1\}$ → $4 \oplus 4 \oplus 0 = 0$ → `0`
（同点两颗石子自动抵消，这也说明重复石子必须逐颗异或、不能去重）。

### 复杂度

- 时间：逆拓扑排序 $O(n + m)$；每对 (点, 颜色) 至多插入线性基一次，
  Python 侧用整数位运算，单次插入 $O(B)$（$B \leqslant 100$ 位）；
  C++ 侧用 `bitset<256>`，单次插入 $O(W/64) = 4$ 个机器字。
  总计 $O(m \log n + n \cdot B)$，$n \leqslant 200, m \leqslant 5000$ 时运算量在 $10^5$ 量级。
  最后汇总石子 $O(q)$。
- 空间：邻接表 / 反图各 $O(n + m)$，SG 值与线性基 $O(n B)$。
  C++ 用全局数组，$200$ 个 `bitset<256>` 仅约 6.4 KB。

## 总结

这道题的骨架是两句话：**独立子游戏的异或和**，以及**"选颜色集合"落在 $\mathbb{F}_2$ 的线性张成里**。

第一步（SG 定理）把 $q$ 颗石子的联合状态切成 $q$ 个互不干扰的单石子游戏，
状态空间从指数级降到 $O(n)$ 个点；第二步把"枚举 $2^k$ 种颜色集合"这一分支爆炸
变成一次线性基消元，再用"最小非主元位"直接读出 $\operatorname{mex}$。

容易写错的地方有三处：

1. **同色多条出边**必须逐条异或进同一个 $h_c$，不能按颜色去重；
2. **递推顺序**必须是逆拓扑序，保证算 $SG(x)$ 时后继的 SG 值都已就绪；
3. **重复石子**要逐颗异或（偶数颗自然抵消），不能先去重再算。

另外要注意位宽：$SG$ 值可以是 $2^{99}$ 量级的巨大整数，Python 靠原生大整数天然支持，
C++ 必须显式给足位数（本轮取 `bitset<256>`），否则会静默截断成错误答案。

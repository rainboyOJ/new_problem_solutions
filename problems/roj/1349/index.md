## 题目描述

学校有 $n$ 台计算机（$2 \le n \le 100$），要用数据线把它们连通（允许经其它计算机中转），不同两台计算机之间的连接费用不同，求总费用最小的连通方案。输入：第一行 $n$，接下来 $n$ 行每行 $n$ 个整数，第 $x$ 行第 $y$ 列表示直接连接第 $x$、$y$ 台计算机的费用。输出：一个整数，即最小连接费用。样例：输入 `3 / 0 1 2 / 1 0 1 / 2 1 0`，输出 `2`（连接 1-2 与 2-3，费用 $1+1=2$）。

## 思路

把费用矩阵看成一张完全无向带权图，「所有计算机连通且总费用最小」就是求它的最小生成树。用朴素 Prim：维护 `dist[v]` 表示已接入点集连到 `v` 的最便宜边权，每轮取未接入点中 `dist` 最小的接入并累加费用，再用它那一行松弛其余未接入点，$n$ 轮后得到答案，时间 $O(n^2)$。

## 形式化题目

给定 $m \times n$ 的网格，第 $i$ 行第 $j$ 列的格子上摞着 $h(i,j)$ 个单位立方体。每个立方体按题面给定的**唯一一种朝向**（不翻转、不旋转）画成字符图形，把整幅立体图打印出来：图中所有空白背景一律用 `'.'` 表示；并规定第 $(m,1)$ 格（前排最左格）最底层积木的**前面左下角顶点**是整幅图最左、最下的点。数据范围：$1 \leqslant m,n \leqslant 50$，$1 \leqslant h(i,j) \leqslant 100$。

单个积木的字符图形固定为 7 列 × 6 行，**左下角**（`dy=0` 行最左的 `+`）就是上面说的锚点：

```text
dx:  0123456
dy=-5   +---+
dy=-4  /   /|
dy=-3 +---+ |
dy=-2 |   | +
dy=-1 |   |/
dy= 0 +---+
```

三张可见面：`dy=-3..0`、`dx=0..4` 是**前面**（矩形）；`dy=-5..-3` 是**上面**（平行四边形）；`dx=4..6` 是**右面**（平行四边形）。题面给的"左右相邻 / 上下相邻 / 前后相邻"三张图，本质都是这个字形沿长、高、宽三个方向平移相接的样子。

**样例**：

```text
3 4
2 2 1 2
2 2 1 1
3 2 1 2
```

输出（13 行 × 23 列）：

```text
......+---+---+...+---+
..+---+  /   /|../   /|
./   /|-+---+ |.+---+ |
+---+ |/   /| +-|   | +
|   | +---+ |/+---+ |/|
|   |/   /| +/   /|-+ |
+---+---+ |/+---+ |/| +
|   |   | +-|   | + |/.
|   |   |/  |   |/| +..
+---+---+---+---+ |/...
|   |   |   |   | +....
|   |   |   |   |/.....
+---+---+---+---+......
```

读法：最后一行是前排四座塔的底面 `+---+---+---+---+`，其右端 6 个 `'.'` 是背景；最左列从下往上是 `+||+||+||+`，正是 $(3,1)$ 三层积木的前面一层压一层（相邻两层共用一条 `+---+` 边，三层共 10 行）；最上一行是后排三座两层塔的顶面后沿，$(1,3)$ 只有一层所以它的塔顶在更下面，行中留出的 `...` 是背景而非字形。

## 正解

### 思路

**朴素做法**：把题面三张"相邻图"当拼图，逐个积木往空白画布上贴。单个积木能贴出来，但一到多塔交错就卡住两件事：① 每个积木该落在画布的哪一行哪一列？$m \times n$ 最多 2500 个塔、25 万个积木，靠人眼数格子必然出错；② 笔画重叠时谁盖谁？（右邻的前面挡住本格的右面、前排挡住后排、上层挡住下层的顶面。）两个观察把作图变成纯粹的"坐标 + 顺序覆盖"。

**观察一：斜投影是线性的，锚点有公式。**三个位移都能直接从上面的字形读出：前面一行 `+---+` 占 4 列，所以长方向每格右移 4 列；上面的后沿比前沿右移 2 列、上移 2 行，所以宽方向（行 $i$ 减小，即往"后"）每格右移 2 列、上移 2 行；前面从上沿到下沿相隔 3 行，相邻两层恰好共用一条 `+---+` 边，所以高方向每层只上移 3 行。

由定位基准，前排 $i=m$ 的锚点就是全图最左下的点，落在画布最后一行、第一列，即 $y(m) = H-1$、$x(m,1) = 0$（$H$ 为画布总行数）。于是第 $i$ 行第 $j$ 列最底层积木的锚点为

$$x(i,j) = 4(j-1) + 2(m-i), \qquad y(i) = (H-1) - 2(m-i),$$

第 $k$ 层（从 1 数起）的锚点再上移 $3(k-1)$ 行。以样例验证（$H=13$）：

| 格子 $(i,j)$ | $h(i,j)$ | 后移量 $2(m-i)$ | 锚点 $x$ | 锚点 $y$ | 顶层锚点 $y-3(h-1)$ |
| :-: | :-: | :-: | :-: | :-: | :-: |
| $(1,1)$ | 2 | 4 | 4 | 8 | 5 |
| $(1,4)$ | 2 | 4 | 16 | 8 | 5 |
| $(3,1)$ | 3 | 0 | 0 | 12 | 6 |
| $(3,4)$ | 2 | 0 | 12 | 12 | 9 |

读表："后移量"列 $2(m-i)$ 同时加进 $x$、减进 $y$，这就是"越靠后的行画得越靠右上"；"顶层锚点"列说明塔越高、字形顶行越靠上，画布必须为最高的那座塔预留行数——这正是下文 $H$ 公式的来源。

**观察二：字形固定，且要"整格落笔"。**每个积木都是开头那个 7×6 模板，三张面连边框一起写满：边上写 `+ - / |`，**面的内部写空格**而不是保留原字符。这一步是覆盖式作图的关键——后画的积木把先画积木被遮挡的笔画连同内部一起抹掉，遮挡就不用单独判断。

**观察三：覆盖顺序 = 视线由远及近（画家算法）。**按固定的三重顺序落笔，后画的覆盖先画的：

| 相对位置 | 裁决 | 图中的表现 |
| --- | --- | --- |
| 同格：上层 vs 下层 | 下层先、上层后 | 上层的前面盖住下层的顶面 |
| 同行：右邻 vs 本格 | 本格先、右邻后 | 本格右面的 `/`、`|` 被右邻的前面抹掉 |
| 同列：前排 vs 后排 | 后排先、前排后 | 后排塔的下半截被前排挡住 |

即 $i = 1 \to m$（后排→前排）、$j = 1 \to n$（左→右）、$k = 1 \to h$（下→上）。其余重叠位置（如"后排右格"与"前排左格"）两积木写入的字符恰好相同，顺序无关，因此这个偏序对全图成立。

**画布尺寸取包络**，使落笔永不越界。塔的字形顶行 $= y(i) - 3(h(i,j)-1) - 5$（顶行比锚点再高 5 行），要求对所有格都不小于 0 且恰好取最紧，解出：宽 $= 4(n-1)+2(m-1)+7$（最右锚点再加字形的 6 列和 1）；高 $H = \max\limits_{i,j}\big(3h(i,j) + 2(m-i)\big) + 3$。样例：宽 $= 4\cdot3+2\cdot2+7 = 23$，$H = (3\cdot2+4) + 3 = 13$，与输出吻合。

### 复杂度

- 时间复杂度：$O(S + HW)$。$S$ 为总积木数（每个积木固定写 36 格），$H \times W$ 为画布面积；上界 $S \leqslant 250{,}000$、$H \leqslant 401$、$W \leqslant 301$，与标准 C++ 解法同为逐积木作图，同阶。
- 空间复杂度：$O(HW)$，画布至多约 12 万个字符，另有输入矩阵 $O(mn)$，远小于 32MB。

## 总结

- 斜投影的每个方向都是常数位移，先把"画图"翻译成"算锚点"：$x$、$y$ 各是一个二元一次式，层数只影响 $y$。
- 单积木字形固定 7×6，三张可见面**连边框整格落笔、面内写空格**，让遮挡退化成普通的字符覆盖。
- 覆盖顺序按视线由远及近：后排→前排、左→右、下→上；三类相邻关系各对应一条裁决，其余重叠处字符天然一致。
- 画布按包络公式一次取准：最高塔顶行恰为 0、最右字形恰到最后一列，边界无需特判；背景 `'.'` 预填，字形之外自动保留。

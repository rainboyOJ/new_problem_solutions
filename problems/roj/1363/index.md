## 题目描述

一棵深度为 $D$ 的满二叉树按层序编号：根为 $1$，节点 $k$ 的左孩子是 $2k$、右孩子是 $2k+1$。小球从根出发逐层下落：每个节点带一个初始为 false 的布尔值，球到达节点时把它翻转——翻转前为 false 则走左子树，为 true 则走右子树，直到落在叶子上。输入一行两个整数 $D$ 和 $I$（$2 \leqslant D \leqslant 20$，$I$ 不超过叶子数 $2^{D-1}$），输出第 $I$ 个小球停止时的叶子编号。例如深度 $D=4$ 时，第 1、2、3 个球分别停在节点 8、12、10；样例输入 `4 2`，输出 `12`。

## 思路

所有球都要经过根，所以第 $I$ 个球就是第 $I$ 个到达根的球；第 $j$ 个到达某节点的球遇到的标记值为 $(j-1)\bmod 2$，因此 $j$ 为奇数走左、偶数走右，且这一判断只依赖本节点的到达序号。于是只需维护一个序号：$I$ 为奇数走左子节点、偶数走右子节点，然后走左的球占前 $\lceil I/2\rceil$ 个序号、走右的占后一半，序号更新为 $(I+\text{走左})/2$，逐层进行 $D-1$ 次即得叶子编号，时间 $O(D)$、空间 $O(1)$。

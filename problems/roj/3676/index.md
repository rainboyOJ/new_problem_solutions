## 题目描述

小 Y 有一把五个拨圈的密码锁，每个拨圈是 $0 \sim 9$ 的循环数字（$9$ 再拨一格变 $0$）。锁车方式为：从正确密码出发，恰好转动一次，且必须是以下两种之一：转动一个拨圈，幅度为任意非零值（模 10）；或同时转动一对相邻拨圈，两圈幅度相同且非零（模 10），例如可把 $\tt{0\;0\;1\;1\;5}$ 转成 $\tt{1\;1\;1\;1\;5}$，但不会转成 $\tt{1\;2\;1\;1\;5}$。给定 $n$ 个锁车后的状态（每个都是五个 $0 \sim 9$ 的数字，且都不是正确密码），求有多少个可能的正确密码，使得每个给定状态都能由它经过一次上述转动产生。数据范围：$1 \leqslant n \leqslant 8$。

输入格式：第一行一个正整数 $n$；接下来 $n$ 行每行五个整数，表示一个状态。输出格式：一行一个整数，表示可能的正确密码数。样例输入 `1` 与 `0 0 1 1 5` 对应样例输出 `81`。

## 思路

不从密码正向枚举，而是从每个锁车后的状态反推：一次合法转动只有 5×9=45 种单拨圈和 4×9=36 种相邻双拨圈模板，倒放即得该状态的 81 个一步可达前驱（正确密码）。「正确密码能一步转到所有 n 个状态」等价于它属于全部前驱集合的交集，从第一个状态的 81 个前驱出发依次与其余状态的 81 个前驱求交，交集大小就是答案。

## 形式化题目

给定 $N \times N$ 的方格图，每格有一个非负整数 $a_{i,j}$（未在输入中出现的格子为 $0$）。
在图上取**两条**从 $A=(1,1)$ 到 $B=(N,N)$ 的路径，每条路每步只能向下或向右。

格子里的数只能被取走一次：某个格子被两条路先后经过时，只有第一次经过算数
（等价于"取走后变为 $0$"）。求两条路径取走的数字之和的最大值：

$$\max_{P_1,\,P_2}\ \sum_{(i,j) \in S(P_1) \cup S(P_2)} a_{i,j}$$

其中 $S(P)$ 是路径 $P$ 经过的格子集合。注意求和对象是**并集**，重合格子只计一次。

本题数据规模很小（$N \leqslant 10$），但路径对的组合数约 $2.4 \times 10^9$，
所以难点不在数据量，而在如何把两条路径的进度压缩进一个状态里。

样例（$N=8$）的输出为 `67`。下面用一个小例子说明"重合格只算一次"这个题眼。

**样例讲解**：取 $N=3$ 的网格，非零格为 $(1,1)=10$、$(1,3)=5$、$(2,2)=6$、$(2,3)=4$、
$(3,1)=8$、$(3,2)=2$。

| | 列 1 | 列 2 | 列 3 |
| --- | --- | --- | --- |
| **行 1** | **10** | 0 | 5 |
| **行 2** | 0 | **6** | **4** |
| **行 3** | **8** | **2** | 0 |

两条最优路径分别是

- $P_1$：$(1,1) \to (1,2) \to (2,2) \to (2,3) \to (3,3)$，取到 $10, 6, 4$；
- $P_2$：$(1,1) \to (2,1) \to (3,1) \to (3,2) \to (3,3)$，取到 $8, 2$。

两条路只在起点 $(1,1)$ 重合：并集共取到 $10 + 6 + 4 + 8 + 2 = 30$，起点 $10$ 只算一次。
若按"两条路各自求和再相加"的直觉写法会得到 $20 + 20 = 40$，比正确答案还大——这是本题最容易踩的坑。

## 正解

### 思路

朴素做法是枚举所有路径对：

$$\max_{P_1,\,P_2}\ \sum_{c \in S(P_1) \cup S(P_2)} a_c$$

从 $(1,1)$ 到 $(N,N)$ 的路径条数是 $\binom{2N-2}{N-1}$，$N=10$ 时为 $48620$ 条，两两组合约
$2.4 \times 10^9$ 种，再乘上每次求和的 $O(N)$，显然不可行。

它失败的根源是把两条路径当成两个**互相独立**的对象。于是状态里要同时记录
"第一条走到哪、第二条走到哪"，也就是 $(i,j,k,l)$ 四个量——这个四维状态里一半以上是
"两条路步数不同步"的非法状态，纯属浪费。

关键观察：**从 $(1,1)$ 到 $(N,N)$ 的任意一条合法路径，步数恒为 $2N-2$，且走完 $t$ 步后一定落在
反对角线 $i+j = t+1$ 上。**（每步让 $i+j$ 恰好加 1，起点 $i+j=2$。）

所以可以让两条路**齐步走**：走完 $t$ 步时，两个终点必然在同一条反对角线上。只要记下两个终点的
**行号** $i$ 和 $j$，列号就被 $t$ 唯一确定，两个位置是 $(i,\ t+1-i)$ 和 $(j,\ t+1-j)$。
状态由此从四维压成三维：

$$f_t[i][j] = \text{两条路各走 } t \text{ 步、终点行号为 } i \text{ 和 } j \text{ 时的最大收益}$$

转移时，一条路到达 $(i,\ t+1-i)$，它的前一格只能是 $(i-1,\ t+1-i)$（从上方下来）或
$(i,\ t-i)$（从左边过来），对应上一层行号 $i-1$ 或 $i$。两条路各两种来源，共 4 种组合：

$$f_t[i][j] = \max_{\substack{i' \in \{i-1,\ i\} \\ j' \in \{j-1,\ j\}}} f_{t-1}[i'][j'] + a_{i,\,t+1-i} + [\,i \neq j\,] \cdot a_{j,\,t+1-j}$$

最后一项的指示函数 $[i \neq j]$ 就是去重：同一反对角线上行号相同蕴含列号相同
（$j = t+1-i$ 由 $i$ 唯一确定），此时两个终点是同一格，只能加一次。

初始状态 $f_1[1][1] = a_{1,1}$；$t=2$ 时两条路都还在 $(1,1)$，不产生新状态，所以循环从 $t=3$ 开始。

下表是上面 $N=3$ 例子中 $t=3$ 那一层的完整状态（反对角线 $i+j=4$，只列出可达格）：
第一列是行号对 $(i,j)$，中间一列给出对应的两个终点坐标，最后一列是该状态的最大收益。

| $f_3[i][j]$ | 位置（终点 1 / 终点 2） | 收益 |
| --- | --- | --- |
| 1, 1 | $(1,3)$ / $(1,3)$ | 15 |
| 1, 2 | $(1,3)$ / $(2,2)$ | 21 |
| 1, 3 | $(1,3)$ / $(3,1)$ | 23 |
| 2, 3 | $(2,2)$ / $(3,1)$ | 24 |
| 3, 3 | $(3,1)$ / $(3,1)$ | 18 |

例如 $f_3[2][3] = 24$ 的来源是 $f_2[1][2] = 10$（此时两路在 $(1,2)$ 与 $(2,1)$），加上
$(2,2)$ 的 $6$ 和 $(3,1)$ 的 $8$。而 $f_3[1][1]$ 只有 $15$：两条路都停在 $(1,3)$，
该格的值 $5$ 只加一次（$10 + 5 = 15$），不是 $10 + 5 + 5 = 20$。

继续推到 $t=4$ 得 $f_4[2][3] = f_4[3][2] = 30$，$t=5$ 收敛到 $f_5[3][3] = 30$，即样例的答案。

```
t=1  state(1,1)  cells (1,1) / (1,1)   f=10   两条路都在起点，10 只算一次
t=2  state(1,2)  cells (1,2) / (2,1)   f=10   两条路在起点之后分道
t=3  state(2,3)  cells (2,2) / (3,1)   f=24   取到 6 与 8，两格不同，各自计入
t=4  state(2,3)  cells (2,3) / (3,2)   f=30   取到 4 与 2，两路分开到最远
t=5  state(3,3)  cells (3,3) / (3,3)   f=30   同时抵达 B，格子无值
```

状态里的 $i, j$ 是行号，格子坐标还要由列 $t+1-i$、$t+1-j$ 补出来，所以同一状态 `(2,3)` 在
$t=3$ 与 $t=4$ 对应的是不同的两对格子。可以看到两条路只在起点和终点汇合，中间两格始终不同，
全程没有任何重合格。

### 复杂度

- 时间：共 $2N-2$ 层，每层 $O(N^2)$ 个状态，每个状态 4 次比较的 $O(1)$ 转移，总计 $O(N^3)$。
  $N \leqslant 10$ 时状态数不到 $10^3$。
- 空间：滚动保存相邻两层 $O(N^2)$ 的 DP 表，加上网格本身，总计 $O(N^2)$。

对照：未同步的四维写法 $f[i][j][k][l]$ 是 $O(N^4)$ 时间、$O(N^4)$ 空间。按反对角线同步推进
并没有改变算法本质，只是删掉了"两条路步数不一致"的非法状态，把维度压掉一维。

## 总结

原题的状态之所以看起来必须四维，是因为"两条路"的进度被当成两个独立变量。一旦注意到
**所有合法路径的步数相同、第 $t$ 步必在第 $t+1$ 条反对角线上**，两条路的进度就被绑在一起，
只需两个行号即可定位，状态降到三维，每个状态也只剩 4 种来源。

这类"同时进行多个同构过程、彼此有冲突（不能重复取同一格）"的题，都是同一个套路：
把多个过程按同一"时钟"同步推进，把各自的进度压进一个维度。做题时要特别留意舍去的那一项——
这里的 $[i \neq j]$ 就是"重合格只算一次"的全部实现。

这张图串起本题从题面到答案的主线：

```text
两条路径的最大取数和
`- 朴素：枚举路径对 -> C(2N-2,N-1)^2 ~ 2.4e9，不可行
   `- 瓶颈：两条路进度互相独立，状态被迫 (i,j,k,l) 四维
      `- 关键观察：任意合法路径步数恒为 2N-2，第 t 步在反对角线 i+j=t+1
         `- 同步推进：位置由行号 i 和步数 t 唯一确定 -> 状态 (t, i, j)
            `- 转移：4 种来源取最大，增量 = a[i][t+1-i] + (i!=j) * a[j][t+1-j]
               `- 去重：i==j 即同一格，只加一次（题眼）
                  `- 答案：f[2N-2][N][N]，复杂度 O(N^3) / O(N^2)
```

先看第一个节点：问题本身只是"取两条路"，没有别的操作。第二个节点说明朴素解为什么爆炸——
不是路径多到没法枚举单条，而是路径对的组合数太大。第三个节点是本题唯一的建模决定：
把"两条路"换成"两条路齐步走"，用步数这个公共时钟绑住两条路的进度。
第四个节点给出状态定义与转移，其中最难记的是 $i=j$ 必须去重，否则会像样例里那样算出 40 而不是 30。
最后一个节点是答案位置与复杂度。

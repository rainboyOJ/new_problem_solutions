## 形式化题目

给定三个整数 $a, b, c$（$-10{,}000 < a,b,c < 10{,}000$），按题面指定的
运算顺序计算 $(a+b) \times c$，输出结果。

输入样例 `2 3 5` 的计算过程如下——先算括号里的加法，再做乘法：

| 步骤 | 运算 | 中间值 |
| --- | --- | --- |
| 1 | $a + b = 2 + 3$ | $5$ |
| 2 | $5 \times c = 5 \times 5$ | $25$ |

输出 $25$。若漏掉括号按 `a + b * c` 计算，乘法优先级先算 $3 \times 5=15$，
得到 $2+15=17$，与答案不符——括号是本题的全部要害。

## 正解

### 思路

本题的"算法"就是题面本身：读入三个整数，按 $(a+b)\times c$ 算两步并输出。
没有随规模增长的循环、没有需要维护的状态，因此不存在值得单独铺陈的暴力层，
朴素做法即最终做法，直接给出正解。

推导只有一条主线：

1. **读入**。一行三个空格分隔的整数，用一次 `sys.stdin.buffer.read().split()`
   拿到全部 token，`map(int, ...)` 转整数后解包成 `a, b, c`。这种读法对
   "一行三个数"和"三个数各占一行"都成立，格式容错更好，也是本仓库 Python
   短解的统一读入风格。
2. **计算**。表达式写成 `(a + b) * c`：括号显式保证**先加后乘**。这是本题
   唯一容易出错的地方——Python 中乘法优先级高于加法，裸写 `a + b * c` 会被
   解析成 $a+(b\times c)$，样例上直接从 $25$ 变成 $17$。
3. **输出**。`print` 打印整数结果即可。

两点边界自动被语言保证，无须特判：数据含负数时，整数乘法的符号规则
（负×负=正、负×正=负）内建正确；结果绝对值小于 $2\times10^8$，且 Python
`int` 是任意精度整数，不存在溢出。

### 复杂度

- **时间复杂度**：$O(1)$。读入固定 3 个 token，1 次加法、1 次乘法、1 次输出。
- **空间复杂度**：$O(1)$。只有一行输入缓冲和三个整数，没有随规模增长的结构。

## 总结

这是一道入门级表达式计算题，学习价值在两处：

1. **输入解析链路**：`read().split()` + `map(int, ...)` + 解包，一行完成
   读入、转换、赋值，且对空白分隔方式不敏感。
2. **运算顺序由括号锁定**：乘法优先级高于加法，题面用括号规定"先加后乘"，
   代码就必须写 `(a + b) * c`。照抄题面却不带括号，是本题唯一的系统性错误来源。

复杂度 $O(1)$，10 组真实测试数据全部通过（单测例约 0.02 s、峰值约 14.5 MB，
远低于 1000 ms / 128 MB 的限制）。

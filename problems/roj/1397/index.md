## 形式化题目

给定一行字符串，形如「运算数 运算符 运算数」，两个运算数是十进制正整数，运算符是 `+ - * / %` 之一，`/` 为整数整除；运算符前后可能有空格。求这一次运算的整数结果。

## 正解

### 思路

表达式里**恰好只有一个**非数字、非空格的字符——运算符。所以不需要通用表达式解析，只要把它定位出来，整行就被切成左运算数、运算符、右运算数三段。

朴素写法是逐字符扫描找运算符，再用五个 `if` 分支选择运算。Python 里两步都能压掉：

1. **切分**：`re.split(r'\s*([+\-*/%])\s*', s)` 用捕获组把运算符留在结果里，运算符前后的空格由 `\s*` 吃掉，一次得到 `(a, op, b)` 三段。
2. **运算**：`operator` 模块自带五种二元整数函数，其中 `/` 用 `floordiv`（整数地板除，正整数下与 C++ 的 `/` 完全一致），`%` 用 `mod`。用字典 `{'+' : add, ...}` 建立运算符到函数的映射，`OPS[op](int(a), int(b))` 一行完成计算，不需要 if-elif 链。

注意题面说「两位正整数」，但真实数据里出现了 `234%245234`、`321/8890` 这样的输入（结果分别是 `234` 和 `0`），说明运算数位数并不严格是两位、结果也可能为 $0$——用 `int()` 转换任意位数比写死两位更稳。

## 总结

- 唯一运算符是本题的关键结构：找到它，表达式就自然三段切分。
- 正则捕获组 + `\s*` 把「去空格、切分、保留运算符」合并成一步。
- 运算符查 `operator` 函数表是消除多路分支的常用手法，`/` 记得用 `floordiv` 保持整数语义。

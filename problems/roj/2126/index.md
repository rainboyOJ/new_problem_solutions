## 形式化题目

给定 $N$ 个加工站（编号 $1 \dots N$，$1 \leqslant N \leqslant 100$）和 $N-1$ 条**单向**传送带，第 $k$ 条为 $a_k \to b_k$。题面括号说明这些通道是用「最小数量」把所有站连起来的，即忽略方向后 $G$ 的底图是一棵有 $N$ 个点、$N-1$ 条边的连通无环树。

定义可达关系 $u \to^* v$ 为存在从 $u$ 到 $v$ 的有向路径（$u \to^* u$ 恒成立，空路径）。求**最小的** $i \in \{1,\dots,N\}$，使得对任意 $j \in \{1,\dots,N\}$ 都有 $j \to^* i$；若不存在这样的 $i$，输出 $-1$。

以题面样例为例，$N = 3$、两条边 $1 \to 2$、$3 \to 2$，站 $2$ 是唯一的汇合点：$1 \to^* 2$、$3 \to^* 2$、$2 \to^* 2$，故答案为 $2$。

## 正解

### 思路

最直接的判定是：反向建图（把 $a \to b$ 存成 $b \to a$），对每个 $i$ 从 $i$ 出发做一次 DFS/BFS 数能反向走到的点数，第一次达到 $N$ 的 $i$ 就是答案，全都不行输出 $-1$。复杂度 $O(N(N+M)) = O(N^2)$，$N \leqslant 100$ 时轻松通过。但它完全没有用到「底图是一棵树」这个约束，而这个约束恰恰能把判定压缩到一次出度统计。

关键在于观察**路径的终点**：

- 由于底图是树、边数是 $N-1$，$G$ 里不可能出现有向环（有向环要求底图有环）。于是在这个有限的有向无环图上，从任意站 $u$ 出发顺着出边一直走，路径只可能一路延伸或者停在某个**出度为 0** 的站，不会绕圈，必然终止。
- 设 $u$ 是出度为 0 的站。它没有任何出边，所以从 $u$ 出发只能到达它自己。若要 $u \to^* i$，就必须 $i = u$。也就是说：**任何出度为 0 的站，一旦答案存在，答案只能是它本身**。

两条观察合起来给出充要条件：

| 出度为 0 的站数 | 结论 |
| --- | --- |
| $\geqslant 2$ | 取其中两个 $u \neq v$。由上一条，答案存在时须同时有 $i = u$ 与 $i = v$，矛盾，故输出 $-1$ |
| $= 1$（记为 $i$） | 从任意 $j$ 出发的路径必然终止在某个出度为 0 的站，而全图这样的站只有 $i$，所以 $j \to^* i$ 对一切 $j$ 成立，$i$ 就是答案 |

于是**「答案存在」等价于「出度为 0 的站恰好一个」，且该站即为答案**。值得注意的是答案天然唯一：若两个站 $i \neq j$ 同时被所有点可达，则 $i \to^* j$ 且 $j \to^* i$，在树的有向定向中构成有向环，与边数为 $N-1$ 矛盾。所以「取最小的 $i$」在这道题的合法输入下不需要额外处理，升序扫描的第一命中就是唯一解。

细看这条判定为什么**必须**依赖树性：对一般有向图，「唯一出度为 0 的点」只是必要条件。例如边集 $1 \to 3,\ 2 \to 1,\ 4 \to 5,\ 5 \to 4$：出度为 0 的站只有 $3$，但站 $4,5$ 构成的底图环根本无法到达 $3$。本题的输入保证排除了这种情形（题面保证 $N-1$ 条通道连通所有站）。若想对任意有向图都稳妥，可以退回上面 $O(N^2)$ 的反图 DFS 逐点验证——但本题的数据生成脚本已断言每一组数据都是树。

### 复杂度

时间 $O(N)$：读入 $N-1$ 条边时顺带累加出发站出度，再线性扫一遍 $1 \dots N$ 统计出度为 0 的站。空间 $O(N)$，只有一个出度数组。$N = 100$ 时总操作数不到 $300$ 次，远低于 1000 ms 时限。

## 总结

这道题的关键不是「可达性」，而是「可达性在树的有向定向下退化成什么」。有向环不存在，所以每条路都有终点；终点的出度为 0，所以终点只能是自己；出度为 0 的站一旦多于一个就谁也到不了谁。三步推理把 $O(N^2)$ 的反图搜索压缩成一次出度统计，也解释了答案为什么必然唯一——同一条「无环」性质既保证了判定充分、又保证了「最小」这一要求不会真的起作用。

实现上的两个坑：一是边的方向，输入「从 $a_i$ 到 $b_i$」增加的是 $a_i$ 的出度而非 $b_i$；二是 $N = 1$ 的退化情形，没有通道，站 1 出度为 0 且是全图唯一的 sink，答案 $1$，与「其他加工站集合为空、条件真空成立」的理解一致，算法天然覆盖。

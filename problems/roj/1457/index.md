## 形式化题目

给定若干个仅含英文字母的非空字符串，对每个字符串 $s$ 求最大的正整数 $k$，
使得存在某个字符串 $t$ 满足 $s = \underbrace{t + t + \cdots + t}_{k \text{ 个 } t}$
（把 $t$ 重复连接 $k$ 次恰好得到 $s$）。

例如 `ababab = (ab)^3`，$k = 3$；`abcd` 无法由更短的串重复得到，$k = 1$。

## 正解

### 思路

**朴素做法与其瓶颈。** 设 $|s| = n$。若 $s = t^k$，则周期 $d = |t| = n/k$ 一定是 $n$ 的约数。
于是可以枚举 $n$ 的每个约数 $d$，验证 `s[:d] * (n // d) == s`，取最小的可行 $d$，答案即 $n/d$。
单次验证要做一遍全长比较，代价 $O(n)$；而 $n \leqslant 10^6$ 的正整数最多有 240 个约数，
单串最坏 $O(240n)$，输入又是"若干行"串，累加起来无法接受。
瓶颈在于：对每个约数都要独立做一次全文比较，彼此之间没有任何信息复用。
理想目标是**一次线性扫描就把最短周期求出来**。

**关键转化：把串看成环，用"循环移位"刻画周期。** 把 $s$ 首尾相接围成一个环，定义
"左移 $i$ 位不变"：把环整体转 $i$ 格后读出的串仍是 $s$。两个方向：

- 若 $s = t^k$，$d = |t|$：环上每隔 $d$ 格的内容完全相同，左移 $d$ 位后逐位对齐，$s$ 不变。
- 若左移 $i$ 位不变：从环上任一位置出发，沿环每走 $i$ 步字符都相同（走 $-i$ 步同理）。
  由裴蜀定理，存在整数 $a, b$ 使 $a \cdot i + b \cdot n = \gcd(i, n)$，即模 $n$ 意义下
  走 $a$ 个 $\pm i$ 步等价于走 $g = \gcd(i, n)$ 步，所以左移 $g$ 位也不变。

于是"不变移位"集合对加法封闭，构成模 $n$ 的子群。设最小的正不变移位为 $d$，则：

1. $d$ 整除所有不变移位；对 $d$ 自己用一次上面的推理得 $\gcd(d, n)$ 也是不变移位且
   $\leqslant d$，由最小性 $\gcd(d, n) = d$，即 $d \mid n$。
2. 左移 $d$ 位不变说明环转 $d$ 格后逐位相同，而 $d \mid n$，所以把环剪开恰好得到
   $n/d$ 段相同的 $s[:d]$，即 $s = (s[:d])^{n/d}$。
3. 不存在更短的 $t$ 使 $s = t^k$，否则 $|t|$ 是比 $d$ 更小的正不变移位。

所以**答案 $= n/d$，其中 $d$ 是最小正不变移位（最小整除周期）**。

**线性求 $d$：在 $s+s$ 里找 $s$ 的第一次再现。** 把 $s$ 接在自己后面得 $s+s$（长 $2n$）。
$s$ 在 $s+s$ 的位置 $i$（$1 \leqslant i \leqslant n$）出现，意味着
$(s+s)[i+k] = s[k]$ 对所有 $k$ 成立，而 $(s+s)[i+k] = s[(i+k) \bmod n]$，
这恰好就是"左移 $i$ 位不变"；反之亦然。因此：

$$d = (s+s).\text{find}(s,\ 1)$$

位置 $0$ 是平凡出现要跳过；位置 $n$ 处 $s$ 总是出现——那是平凡的移位 $n \equiv 0 \pmod n$，
对应答案 1——所以 `find` 一定有返回，无需判 $-1$。

用样例 `ababab`（$n = 6$，`s+s = abababababab`）逐个起点检查 $s$ 是否再现：

| 出现起点 $i$ | 从该位起取 6 个字符 | 是否等于 `ababab` |
| :---: | :---: | :---: |
| 0 | `ababab` | 是（平凡：自己，跳过） |
| 1 | `bababa` | 否 |
| 2 | `ababab` | **是（第一次再现）** |
| 3 | `bababa` | 否 |
| 4 | `ababab` | 是 |
| 5 | `bababa` | 否 |
| 6 | `ababab` | 是（平凡：第二个 $s$） |

观察重点：再现位置恰好是 $\{2, 4, 6\}$——全是最小周期 $2$ 的倍数，
这正是"不变移位构成子群"的直观体现；第一个再现位置 $2$ 就是 $d$，答案 $6/2 = 3$。
而左移 $1$ 位得到 `bababa` $\neq$ `ababab`，与表中 $i=1$ 不匹配一致。
另外两组样例同样吻合：`aaaa` 的再现位置是 $\{1, 2, 3, 4\}$，$d = 1$，答案 $4$；
`abcd` 除位置 $0$ 和 $4$ 外没有再现，$d = 4$，答案 $1$。

这个 `find` 并不比 KMP 慢：经典 KMP 做法先求 fail 数组，令 $p = n - \text{fail}[n-1]$
（补上最长公共前后缀），$p$ 是最小周期，$n \bmod p = 0$ 时答案 $n/p$，否则 $1$；
而 CPython 的 `str/bytes.find` 底层采用 Two-Way（Crochemore–Perrin）算法，
最坏情况同样是线性 $O(n)$——与手写 KMP 同阶，却以 C 速度运行，还省掉了 $O(n)$ 的
fail 数组。本文的 `main.py` 就采用 `find` 写法。

## 总结

- 幂串问题 $s = t^k$ 的核心是求**最小整除周期** $d$，答案 $n/d$。
- 把串看成环后，"$s$ 是幂串"等价于"存在非平凡循环移位使 $s$ 不变"；由裴蜀定理，
  不变移位构成子群，最小正元自动整除 $n$——这一步把"逐个验证约数"变成了"找第一个再现位置"。
- $s$ 在 $s+s$ 中（位置 $\geqslant 1$）第一次再现的位置就是 $d$，任何线性字符串匹配
  （KMP、Z 函数、Two-Way `find`）都能完成这最后一步。
- Python 实现要点：`bytes` 读入免解码，内建 `find` 以 C 速度做线性匹配，
  全程没有 Python 层的逐字符循环。

## 形式化题目

给定三个整数 $a, b, c$，求第二个分量 $b$ 并输出。整数为 32 位有符号整数（含负数）。

输入样例 `123 456 789` 对应 $(a,b,c) = (123, 456, 789)$，输出 $b = 456$。

## 正解

### 思路

这道题的"算法"就是不处理：计算量为零，输入长度固定，**没有任何可以优化的瓶颈**。
写一个暴力版本只会得到与正解逐字相同的代码，所以本文不设暴力层，直接给出做法。
真正要练的是 **把输入文本变成整数、再挑出需要的那个** 这条链路。

朴素想法是 `input().split()` 拿到三个字符串、逐个 `int(...)`、再取下标 1 输出——
完全正确，但要自己处理"先存成列表再取下标"。把它压缩成一条表达式后，
以样例 `123 456 789` 为例：

| 步骤 | 表达式 | 结果 |
| --- | --- | --- |
| 一次读入整份输入 | `sys.stdin.buffer.read()` | `b'123 456 789\n'` |
| 按任意空白切分 | `.split()` | `[b'123', b'456', b'789']` |
| 逐个转成整数 | `map(int, ...)` | `123`、`456`、`789` |
| 解包只留第二个 | `_, second, *_ = ...` | `second = 456` |

两点观察支撑这个写法：

1. **`split()` 归一化排版**：它按任意连续空白切分，行尾换行、多余空格、
   甚至三个数被换行分开，都统一成同一个 token 序列；Python 的 `int` 是任意精度整数，
   32 位边界（$-2^{31}$、$2^{31}-1$）与负号天然覆盖，不需要溢出处理。
2. **解包把格式约定写进代码结构**：`_` 收下第一个、`second` 绑定第二个、
   `*` 吃掉剩余的第三个，既表达"只要中间那个"，又让"恰好三个整数"成为硬约束——
   token 数不是 3 就立刻抛 `ValueError`，而不是悄悄取错值输出错误答案。

### 复杂度

- 时间复杂度：$O(1)$：输入长度固定，只有一次切分、三次整数转换和一次输出。
- 空间复杂度：$O(1)$：输入约 30 字节，token 列表与三个整数都是常数大小。

## 总结

- 没有算法瓶颈的题，重点在输入输出链路：`read()` 读全部 $\to$ `split()` 切分
  $\to$ `map(int, ...)` 转换 $\to$ 解包取值，一行完成。
- 用元组解包而非"存列表再取下标"，让"输入恰好三个整数"的约定显式可见、
  出错即刻暴露。
- Python 整数任意精度，32 位有符号范围（含负数与边界值）无需额外处理。
- 验证：真实测试数据 10/10 全部 PASS（约 0.02 s/组，远低于 1000 ms 限时）。

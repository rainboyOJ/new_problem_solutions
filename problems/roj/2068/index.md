## 形式化题目

给定 $F$（$1 \leqslant F \leqslant 5$）个前齿轮和 $R$（$1 \leqslant R \leqslant 10$）个后齿轮的**型号个数**：前齿轮齿数从 $[F_1, F_2]$ 中选 $F$ 个互不相同的整数，后齿轮从 $[R_1, R_2]$ 中选 $R$ 个互不相同的整数（$25 \leqslant F_1 < F_2 \leqslant 80$，$5 \leqslant R_1 < R_2 \leqslant 40$）。

每组方案产生 $n = F \times R$ 个传动比 $x = f / r$（前齿数除以后齿数），要求：

1. **3 倍约束**：最大传动比至少是最小传动比的 3 倍；
2. **方差最小**：把 $n$ 个传动比排序为 $x_1 \leqslant x_2 \leqslant \cdots \leqslant x_n$，记相邻差 $d_i = x_{i+1} - x_i$（共 $m = n-1$ 个），使
$$\bar d = \frac{1}{m}\sum_{i=1}^{m} d_i,\qquad \text{方差}=\frac{1}{m}\sum_{i=1}^{m}(d_i-\bar d)^2$$
最小。

**并列规则**：方差相同时，前齿轮组合字典序最小的优先；仍相同，后齿轮组合字典序最小。输出两行：前、后齿轮齿数各按升序。

**样例**：$F=2, R=5$，前区间 $[39,62]$、后区间 $[12,28]$。最优解为前齿轮 `39 53`、后齿轮 `12 13 15 23 27`；它排序后的 10 个传动比见「正解 · 思路」，相邻差方差约 $0.00785$。

## 正解

### 思路

**这是一道"先读题、后编码"的题。** 剥掉奶牛和别墅的故事，任务就是把两组数、$F\times R$ 个比值、排序、相邻差的方差按定义算清楚。没有隐藏的数学结构，正确做法就是**枚举所有方案并精确比较**——真正的挑战是让枚举在数据范围内跑完。

**第一步：确定枚举框架与字典序。** 前齿轮组合至多 $\binom{56}{5}\approx 3.8\times10^6$ 种，后齿轮组合至多 $\binom{36}{10}\approx 2.5\times10^8$ 种，显然不能盲目做两层笛卡尔积。但注意：

- 合法方案必须通过 3 倍约束，枚举后齿轮组合时可以先过这道闸再算方差；
- `itertools.combinations` 按升序枚举，天然产生字典序。只要只在"分数严格更小"时更新答案，第一次拿到某个分数值的方案就是字典序最小的，自动满足并列规则。

流程如下：

```mermaid
flowchart LR
    A[按字典序枚举前齿轮组合] --> B[对每个前齿轮组合<br/>枚举后齿轮组合]
    B --> C{3 倍约束<br/>f_max*r_max >= 3*f_min*r_min}
    C -- "否: 剪枝" --> B
    C -- 是 --> D[排序 n 个传动比]
    D --> E[整数方差分数<br/>m*sum(d^2) - 首尾差^2]
    E --> F{分数严格小于<br/>当前最优?}
    F -- 否 --> B
    F -- 是 --> G[更新答案并回到 B]
    G --> B
```

图中只有两处分支：3 倍约束剪枝（$O(1)$ 整数比较，砍掉不合法组合）和分数比较（决定是否更新答案）。

**第二步：3 倍约束 = 一次整数乘法。** 传动比的最大值是 $\dfrac{f_{\max}}{r_{\min}}$，最小值是 $\dfrac{f_{\min}}{r_{\max}}$，所以

$$\frac{f_{\max}}{r_{\min}} \geqslant 3 \cdot \frac{f_{\min}}{r_{\max}} \iff f_{\max}\cdot r_{\max} \geqslant 3\,f_{\min}\cdot r_{\min}.$$

不等号两边交叉相乘，一次 $O(1)$ 整数比较，完全避开浮点。对每个前齿轮组合，$f_{\min}, f_{\max}$ 已固定：

- $R \geqslant 3$ 时枚举后齿轮组合，先查上式、不过再算方差；
- $R = 2$ 时（真实数据最重的 cowcycle7 正是 $F=3, R=2$），设两个后齿轮为 $x < y$，合法条件即 $y \geqslant \lceil 3 f_{\min} x / f_{\max}\rceil$。对每个 $x$ 直接从该下界开始枚举 $y$，**一个非法对都不会访问**，把 $\binom{36}{2}=630$ 个齿对压到约 200--340 个。

**第三步：方差比较变成纯整数运算。** 方差是相邻差的方差。记 $m = n-1$ 个差为 $d_i$，展开：

$$\text{方差}=\frac{1}{m}\sum_i d_i^2 - \bar d^2,\qquad \bar d=\frac{1}{m}\sum_i d_i.$$

两边乘 $m^2$（对每个方案都是同一个常数）：

$$m^2 \cdot \text{方差} \;=\; m\sum_i d_i^2 - \left(\sum_i d_i\right)^2.$$

两个观察让这个表达式可以直接用整数算：

1. **望远镜求和**：$\sum_i d_i = x_n - x_1$，只需首尾两个传动比；
2. **公共标度**：令 $L=\operatorname{lcm}(5,6,\dots,40)$，$W[b]=L/b$，则每个传动比 $a/b$ 等于整数 $a\cdot W[b]$ 除以 $L$。于是每个 $d_i=\Delta_i/L$，代入上式后 $L^2$ 也是常数，最终只需比较整数

$$S = m\sum_i \Delta_i^2 - \Delta_{\text{span}}^2,\qquad \Delta_{\text{span}} = x_n - x_1 \text{ 对应的整数跨度}.$$

排序传动比其实是在排序若干个整数 $a\cdot W[b]$：排序、求差、求和全是整数运算——比 `fractions.Fraction` 快一个数量级，同时绝对精确，不会因浮点噪声把"并列取字典序最小"的规则破坏。

**第四步：看懂"方差最小"长什么样。** 对样例答案前 `39 53`、后 `12 13 15 23 27`，把 10 个传动比排序并列出相邻差：

| 排序后的传动比 | 近似值 | 相邻差 |
| :---: | :---: | :---: |
| 39/27 | 1.4444 | — |
| 39/23 | 1.6957 | 0.2512 |
| 53/27 | 1.9630 | 0.2673 |
| 53/23 | 2.3043 | 0.3414 |
| 39/15 | 2.6000 | 0.2957 |
| 39/13 | 3.0000 | 0.4000 |
| 39/12 | 3.2500 | 0.2500 |
| 53/15 | 3.5333 | 0.2833 |
| 53/13 | 4.0769 | 0.5436 |
| 53/12 | 4.4167 | 0.3397 |

观察两点：最大/最小传动比为 $4.4167 / 1.4444 \approx 3.058 \geqslant 3$，最优解贴着 3 倍约束线；9 个相邻差围绕均值 $0.330$ 上下波动，方差约 $0.00785$——所谓"最佳齿轮组合"，就是让挡位差尽可能均匀的一组齿轮。

### 复杂度

设 $N = F_2 - F_1 + 1 \leqslant 56$，$M = R_2 - R_1 + 1 \leqslant 36$。枚举框架为

$$O\left(\binom{N}{F}\cdot \binom{M}{R}\cdot n\log n\right),\qquad n = F\times R \leqslant 50,$$

与标准 C++ 枚举解法同阶；$n\log n$ 来自每组合法方案的排序。真正的收益在剪枝与常数：3 倍约束把不合法后齿轮组合整体跳过，$R=2$ 时又从下界直接弹掉全部非法齿对（cowcycle7 的 $8436\times630$ 组合对实际只访问约 210 万合法对）。空间 $O(n)$。

真实数据验证：8 组测例全部通过，最重的 cowcycle7（$F=3,R=2,[43,80]\times[5,40]$）本地约 1.7s。理论极端组合（$F=5,R=10$ 且两个区间都拉满）对任何枚举类解法都不可行，不在本题数据中，Python 侧允许 TLE。

## 总结

- **先翻译、再编码**：把"传动比、3 倍约束、相邻差方差、字典序并列"逐条变成数学条件后，本题是一个干净的枚举 + 剪枝 + 精确比较问题。
- **整数化三件套**：约束用整数乘法判、传动比用 lcm 标度变整数、方差只用整数分数 $m\sum\Delta^2 - \Delta_{\text{span}}^2$ 比较，全程零浮点。
- **并列规则白嫖枚举顺序**：组合升序枚举 + 只在严格更小时更新，字典序要求自动满足。
- **剪枝按最重数据特化**：$R=2$ 时直接从 3 倍约束解出 $y$ 的下界，一个非法对都不访问。

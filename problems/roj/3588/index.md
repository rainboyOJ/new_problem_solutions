## 形式化题目

平面上有 $n$ 个与坐标轴平行的矩形地毯，按编号 $1 \sim n$ 的顺序依次铺设，后铺的覆盖在先铺的上面。第 $i$ 张地毯是左下角 $(a_i, b_i)$、$x$ 方向长 $g_i$、$y$ 方向长 $k_i$ 的矩形（含边界）。给定查询点 $(x, y)$，求覆盖它的编号最大的地毯编号；若无地毯覆盖输出 $-1$。

**样例 1**：三张地毯 `1 0 2 3`、`0 2 3 3`、`2 1 3 3`，查询点 $(2,2)$，答案是 $3$。三种线型分别对应 $1$、$2$、$3$ 号地毯：

| \ | 0 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- | --- |
| **4** | | | | | |
| **3** | `222` | `222` | `222` | `222` | |
| **2** | | `111` | `123` | `333` | `333` |
| **1** | | `111` | `123` | `333` | `333` |
| **0** | | `111` | `111` | | |

单元格里写的是该格左上角参照点最顶层的地毯编号（样例里 $x,y$ 都落在格点上）。重点看 $(2,2)$：$1$、$2$、$3$ 号地毯都盖到这里，最后铺的 $3$ 号在最上面，所以输出 $3$。

## 正解

### 思路

最朴素的想法是把整个平面铺成网格：开一个二维数组，对每张地毯把矩形内的每个格子改成当前编号，最后查一格。但坐标最大到 $10^5$，网格要 $10^{10}$ 个格子，时间和空间都装不下——更何况我们只关心**一个点**。

关键观察：**查询点只有一个**。一张地毯要么盖住这个点、要么盖不住，与它盖住的其他地方无关。所以"顶层是谁"只需从后往前检查：最后铺的第 $n$ 张如果盖住 $(x,y)$，它就是答案；否则看第 $n-1$ 张……第一个盖住该点的地毯编号最大，它就是最上面那张。

判断点 $(x,y)$ 是否在矩形内（含边界）就是两个不等式：

$$a_i \leqslant x \leqslant a_i + g_i \quad\text{且}\quad b_i \leqslant y \leqslant b_i + k_i$$

n = 0（一张地毯都没有）时循环一次都不执行，直接输出 $-1$；边界上的点两个不等式都取等号，同样算覆盖。

### 复杂度

- 时间复杂度 $O(n)$：从后往前最多检查 $n$ 张地毯，每张 $O(1)$。
- 空间复杂度 $O(n)$：存下全部地毯的坐标。

## 总结

本题的"反直觉"之处在于看到"矩形覆盖"容易先想到二维网格/差分/扫描线，但**只查询一个点**时这些结构全是浪费：让地毯和点直接做 $O(1)$ 的包含判断，再利用"后铺的在上"这一顺序性质从后往前找第一个命中者即可。把坐标范围 $10^5$ 与查询次数 $1$ 对比一下，就能确定枚举才是与正解同阶的做法。


第 $3$ 张地毯左下角 $(2,1)$、长宽 $3 \times 3$，覆盖 $x \in [2,5]$、$y \in [1,4]$，$(2,2)$ 恰在左边界上（边界算覆盖）。因为它是最后铺的，倒序第一步就命中，无需再检查 $1$、$2$ 号——这也解释了样例 2 里 $1 \sim n$ 全部不命中时输出 $-1$ 的收尾方式。

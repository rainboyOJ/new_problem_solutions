## 形式化题目

给定两个整数 $a, b \in [0, 100]$，分别表示语文、数学成绩。成绩小于 60 分记为
**不及格**。统计两门课中不及格的门数 $S$：

- 恰好有一门不及格（$S = 1$）时，输出 `1`；
- 否则（两门都及格 $S = 0$，或两门都不及格 $S = 2$）输出 `0`。

样例 $a=50,\ b=80$：语文不及格、数学及格，$S = 1$，输出 `1`。
下表列出全部四种组合的判定过程：

| $a < 60$ | $b < 60$ | 不及格门数 $S$ | 输出 |
| --- | --- | --- | --- |
| 否（如 71） | 否（如 87） | 0 | 0 |
| 否（如 80） | 是（如 51） | 1 | 1 |
| 是（如 50） | 否（如 80） | 1 | 1 |
| 是（如 41） | 是（如 34） | 2 | 0 |

## 正解

### 思路

**朴素做法**直接翻译题面的「恰好一门」，写一个对称的长条件：

```python
ok = (a < 60 and b >= 60) or (b < 60 and a >= 60)
```

它正确，但两支完全对称，读者必须逐支核对才能确信没有漏掉
「语文不及格、数学及格」的另一侧——这正是这类题最容易出错的地方。

**关键观察**：把每门课的及格状态映射成一个计数，「恰好一门」就变成
「计数和恰为 1」，四种组合一次性覆盖：

$$
S = [a < 60] + [b < 60], \qquad \text{answer} = [S = 1]
$$

Python 的布尔值 `True` / `False` 可以直接参与加法（`True + False == 1`），
所以两个比较表达式相加就是 $S$，既不用写 `if`，也不用为单次使用抽函数。
最后 `int(...)` 把 `True/False` 转成题目要求的 `1/0` 输出。

两个细节：

- **及格线命名**：`60` 含义固定且出现两次，提为模块级常量 `PASS_LINE = 60`，
  注释写明「小于 60 记为不及格」，避免把边界误写成 `<= 60`——`60` 分是及格的。
- **读入的硬约束**：`chinese, maths = map(int, sys.stdin.buffer.read().split())`
  用元组解包把「输入恰好两个整数」变成结构上的约束，格式不符会立刻抛
  `ValueError` 而不是悄悄少读错位；`split()` 对空格与行尾换行不敏感。

### 复杂度

- 时间复杂度：$O(1)$：一次 `read()` 与 `split()`、两次整数转换、两次比较、
  一次加法和一次输出，全部是常数次操作。
- 空间复杂度：$O(1)$：输入不足 10 字节，token 列表与解包变量都是常数大小。

## 总结

- 「恰好一门」改写成**不及格计数和等于 1**：`failed_cnt = (chinese < PASS_LINE) + (maths < PASS_LINE)`，
  对称的两支合并为一个表达式，四种组合由枚举表逐行验证。
- Python 布尔值可加是这套写法的支点：比较结果直接当 `1 / 0` 用，`int(...)` 收尾得到输出。
- 边界只有一个：**恰好 60 分算及格**（`60 < 60` 为假），由 `PASS_LINE` 常量与注释固定。
- 验证：数据仓 10 组真实测试数据全部 PASS（约 0.015 s/组，peak 14.5 MB，
  远低于 1000 ms / 128 MB 限制）；样例 `50 80` 手工运行输出 `1`。

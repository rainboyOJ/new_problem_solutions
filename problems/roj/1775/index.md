## 形式化题目

给定一棵 $N$ 个点的树 $T=(V,E)$。你在树上做**随机游走**：身处点 $x$ 时，
等概率地（概率 $\frac{1}{\deg(x)}$）选择 $x$ 的一条出边走一步。
给出 $Q$ 次询问，每次给出起点 $u$ 与终点 $v$，求从 $u$ 出发**首次到达** $v$ 时
所走的期望步数，答案对 $10^9+7$ 取模后输出。

$N, Q \leqslant 10^5$，$N=1$ 时无输入边（此时唯一的询问只能是 $1\ 1$，答案为 $0$）。

## 正解

### 思路

**朴素做法。** 随机游走的期望步数一般要列全局线性方程组高斯消元，单次 $O(N^3)$；
即便利用树的结构，对每个询问从起点单独列方程，单次也要 $O(N)$，总复杂度 $O(NQ)$，
$N=Q=10^5$ 时约 $10^{10}$，远超 1 s 的时限。瓶颈在于"每次询问都重新解一遍方程"。

**关键观察一：路径可加。** 树上 $u \to v$ 的简单路径唯一，记作
$p_1(=u), p_2, \dots, p_k(=v)$。因为树上无环，从 $p_i$ 走到 $v$ 之前**必须先首次到达**
$p_{i+1}$；而一旦到达 $p_{i+1}$，之后的过程与"在 $p_i$ 侧枝里绕了多久"完全无关
（马尔可夫无后效性）。所以

$$E(u \to v) = \sum_{i=1}^{k-1} E(p_i \to p_{i+1}),$$

即**整条路径的期望步数等于逐条边期望步数之和**。

**关键观察二：方向解耦。** 树上每条边只有两个方向，于是只需两类量：

- $f(x)$：从 $x$ 出发**向上**首次走到父亲 $\mathrm{fa}[x]$ 的期望步数；
- $g(x)$：从父亲 $\mathrm{fa}[x]$ 出发**向下**首次走到 $x$ 的期望步数。

任意询问 $(u,v)$ 取 $z=\mathrm{LCA}(u,v)$，就把路径拆成了"$u$ 向上走到 $z$"与
"$z$ 向下走到 $v$"两段，只需分别累加 $f$ 与 $g$。

**关键观察三：两条递推式都极简。** 设 $x$ 的度数为 $d(x)$，儿子集合为
$\mathrm{son}(x)$。在 $x$ 处有 $\frac{1}{d(x)}$ 的概率一步到父亲；有
$\frac{1}{d(x)}$ 的概率到某个儿子 $c$，之后要先花 $f(c)$ 步回到 $x$，再花 $f(x)$ 步到父亲：

$$f(x) = 1 + \frac{1}{d(x)}\sum_{c \in \mathrm{son}(x)} \bigl(f(c) + f(x)\bigr).$$

两边乘 $d(x)$ 移项，$f(x)$ 的系数只剩 $1$，直接解出

$$\boxed{f(x) = d(x) + \sum_{c \in \mathrm{son}(x)} f(c)}.$$

它的直观含义是：**从子树内部首次跳出到父亲，期望步数恰好等于该子树内所有点的度数之和。**

向下走同理，在父亲 $x$ 处展开一步并消去其他儿子与祖先方向的影响后得到

$$\boxed{g(c) = g(x) + f(x) - f(c)} \qquad (c \in \mathrm{son}(x),\ g(\text{根}) = 0).$$

它的直观含义是：向上走的"开销"满足一个望远镜式的关系，向下走可以由父节点的 $g$ 直接推出，
不必重新遍历子树。

**步骤。**

1. 以 $1$ 为根 BFS，得到每个点的父亲 $\mathrm{fa}$、深度 $\mathrm{dep}$ 和自顶向下的遍历序；
2. 按**逆**遍历序自底向上做 $f(x) = d(x) + \sum f(c)$；
3. 按遍历序自顶向下做 $g(c) = g(x) + f(x) - f(c)$，同时递推两条树上前缀和
   $pf[x] = pf[\mathrm{fa}[x]] + f(x)$、$pg[x] = pg[\mathrm{fa}[x]] + g(x)$；
4. 倍增预处理 $\mathrm{LCA}$；
5. 每次询问求出 $z=\mathrm{LCA}(u,v)$，答案为
   $\bigl(pf[u]-pf[z]\bigr) + \bigl(pg[v]-pg[z]\bigr) \bmod (10^9+7)$。
   $u=v$ 时 $z=u$，两项都是 $0$，边界自然成立。

**为什么不用取模的中间量也不会溢出？** 因为 $f(x)$ 恰好是子树内度数之和
$\leqslant 2N$，而 $g(c)=f(\text{根})-f(c)$（沿路径望远镜求和），所以
$g$ 也不超过 $2N$；前缀和沿深度不超过 $N$ 个点累加，上界约 $2 \times 10^{10}$，
`long long` 绰绰有余。答案本身是整数，不存在有理数取模的麻烦。

### 复杂度

- **时间**：BFS 建树与两次树形 DP 都是 $O(N)$；倍增表预处理 $O(N \log N)$；
  每次询问 $O(\log N)$ 求 LCA、$O(1)$ 查前缀和。总计 $O\bigl((N+Q)\log N\bigr)$，
  $N=Q=10^5$ 时约 $3 \times 10^6$ 次基本操作。实测最大点 0.05 s、峰值 16 MB（限时 1 s / 256 MB）。
- **空间**：邻接表、$f/g/pf/pg$、倍增表均为 $O(N)$ 或 $O(N \log N)$，
  约 $10^5 \times 18 \times 4\text{B} \approx 7$ MB，远低于 256 MB。
- **与 C++ 解法的关系**：`main.py` 与 `main.cpp` 是同一算法的两个实现，
  复杂度同阶。$N=Q=10^5$ 的链/菊花/完全二叉树点上 Python 实测 0.16~0.25 s，
  即使常数再放大数倍也仍在 1 s 时限内，本题不存在 Python 特有的 TLE 风险。

## 总结

- **期望问题先找可加性**：树上的随机游走满足马尔可夫无后效性，整条路径的期望可以
  拆成逐条边的期望之和，这一步把 $O(NQ)$ 的"每次重新解方程"变成全局一次预处理。
- **按方向而不是按点设状态**：树上每条边只有上下两个方向，$f$（向上）与 $g$（向下）
  两个状态就覆盖了所有情况；$g$ 的递推式 $g(c)=g(x)+f(x)-f(c)$ 还是望远镜式的，
  直接说明 $g$ 不会比 $f$ 大一个量级。
- **式子能化简就化简**：$f(x)=d(x)+\sum f(c)$ 是消元后的封闭形式，
  一眼看出 $f$ 就是子树度数和，既给出了溢出上界，也让代码只有一行累加。
- **树上任意两点路径用 LCA + 前缀和**：这是把"路径求和"从 $O(\text{路径长})$
  压到 $O(\log N)$ 的标准套路，本题只是把求和对象换成了期望值。

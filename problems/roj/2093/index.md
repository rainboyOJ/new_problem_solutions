## 形式化题目

给定一个 $5 \times 5$ 的矩阵，在其中填入字符集合 $\{\text{'A'}, \text{'B'}, \dots, \text{'Y'}\}$，每个字符恰好出现一次。
矩阵必须满足偏序约束：每一行从左至右严格递增，每一列从上至下严格递增。
将矩阵按行优先顺序（从上到下、从左到右）展开得到的 25 字符字符串称为合法单词。
所有合法单词按照字典序升序排列，编号从 1 开始。

任务为实现双向转换：
- 给定字典序排名，求对应的合法单词；
- 给定合法单词，求其字典序排名。

## 正解

### 思路

#### 1. 杨表性质与状态空间

矩阵中的每行递增且每列递增，与组合数学中的**标准杨表（Standard Young Tableaux, SYT）**定义完全一致。

若我们按照字母从小到大（$\text{'A'} \to \text{'B'} \to \dots \to \text{'Y'}$）的顺序依次将字母填入网格，任何时刻已经填入字母的格子所构成的图形必须是左上对齐的阶梯形（即杨图）。

设 5 行中各行已经填入的字符数分别为 $a, b, c, d, e$。由于每列递增，下方的行长度绝不能超过上方的行长度，因此状态必然满足约束：
$$5 \ge a \ge b \ge c \ge d \ge e \ge 0$$

这一状态空间的大小可以通过隔板法计算：
$$\binom{5 + 5}{5} = \binom{10}{5} = 252$$
所有可能达到的合法中间状态仅有 **252** 个。

#### 2. 部分预填条件下的计数 DP

当部分格子已经确定了具体字符时，我们需要求出在满足这些预填约束下的合法填数方案数。

定义状态函数 `dfs(a, b, c, d, e)` 表示第 0 到 4 行分别已填入 $a, b, c, d, e$ 个字符时，填满整个网格的合法方案数。当前正要填入的字符编号为 $ch = a + b + c + d + e$（$0 \le ch < 25$）：

- 若 $ch = 25$，全部 25 个字符均已合法放入，返回 $1$；
- 否则，字符 $ch$ 只能放置在某行的末尾：
  - 放至第 0 行第 $a$ 列：需满足 $a < 5$ 且位置 $(0, a)$ 未预填或预填字符恰为 $ch$；
  - 放至第 1 行第 $b$ 列：需满足 $b < a$ 且位置 $(1, b)$ 未预填或预填字符恰为 $ch$；
  - 放至第 2 行第 $c$ 列：需满足 $c < b$ 且位置 $(2, c)$ 未预填或预填字符恰为 $ch$；
  - 放至第 3 行第 $d$ 列：需满足 $d < c$ 且位置 $(3, d)$ 未预填或预填字符恰为 $ch$；
  - 放至第 4 行第 $e$ 列：需满足 $e < d$ 且位置 $(4, e)$ 未预填或预填字符恰为 $ch$。

将所有合法转移分支的方案数累加，并使用记忆化缓存，单次计算只需遍历最多 252 个状态。

#### 3. 字典序逐位确定（数位 DP 思想）

单词由网格中位置 $0$ 到 $24$（按行优先展开）的字符依次组成。我们从第 0 个格子到第 24 个格子依次确定字符：

- **根据排名求单词（模式 N）**：
  从第 0 个格子开始，从小到大枚举尚未使用的字符 $ch$。在满足相邻偏序关系（不小于上方和左侧已填字符）的前提下，临时将该格子填为 $ch$，调用计数函数得到后续合法方案数 $ways$。
  - 若 $ways \ge rank$，说明目标单词该位必为 $ch$，固定此字符并继续处理下一个格子；
  - 若 $ways < rank$，说明目标单词还在后面，执行 $rank \leftarrow rank - ways$，并尝试下一个候选字符。
- **根据单词求排名（模式 W）**：
  从第 0 个格子开始，设题目单词当前位置实际字符为 $target$。从小到大枚举未使用的字符 $ch < target$，若合法则计算当前尝试下的后续方案数并累加进总排名。之后将该位置固定为 $target$，继续处理下一位。最后总排名需加 1。

### 复杂度

- **时间复杂度**：
  - 网格共 25 个格子，每个格子尝试字符最多 25 种，单次查询中最多调用约 $25 \times 25 / 2 \approx 312$ 次计数 DP。
  - 单次 DP 的状态数仅 $\binom{10}{5} = 252$ 个，每次转移为 $\mathcal{O}(1)$。
  - 总运算量约在 $10^5$ 次操作以内，实际运行时间约为 $15 \sim 20\,\text{ms}$，远快于 $1000\,\text{ms}$ 的时限。
- **空间复杂度**：
  - 记忆化搜索状态数最多 252 个，递归栈深最多 25 层。
  - 空间复杂度为 $\mathcal{O}(1)$（常数级极小内存）。

## 总结

本题是标准杨表（SYT）与字典序逐位贪心计数的经典结合：
1. 观察到行列递增的本质即为杨表，按数值从小到大填入时，已填图形必须保持非严格递减的阶梯状；
2. $5 \times 5$ 的阶梯形状数量仅有 $\binom{10}{5} = 252$ 个，状态空间极度收敛；
3. 将预填字符作为转移过滤条件，把原问题转化为标准杨表上的动态规划计数与逐位试填。

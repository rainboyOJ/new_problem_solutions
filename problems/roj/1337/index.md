## 题目描述

文法分析时需要检测一个单词是否在单词列表里，为此画出对应的单词查找树：根结点不包含字母，其余每个结点仅包含一个大写字母；从根到某结点路径上的字母依次连起来是该结点对应的单词，单词列表中的每个单词都对应树上某个结点，且在满足这些条件下树的结点数最少。对一个确定的单词列表，请统计对应的单词查找树的结点数（包含根结点）。输入若干行、每行一个仅由大写字母组成的单词（长度不超过 63 个字母，文件总长度不超过 32K，至少有一行），输出一个整数即结点数。输入样例 `A / AN / ASP / AS / ASC / ASCII / BAS / BASIC`（每行一个单词），输出样例 `13`。

## 思路

结点数最少时，树上每个非根结点恰好对应"某个输入单词的一个前缀"，所以答案就是去重后的非空前缀个数加 1（根结点），重复单词不影响答案。把单词按字典序排序后，一个单词与前面所有单词的最长公共前缀（LCP）的最大值总在相邻位置取到，于是第 $i$ 个单词新贡献 $|w_i| - LCP(w_i, w_{i-1})$ 个结点，第一个单词贡献全部 $|w_1|$ 个前缀。因此答案 $= 1 + |w_1| + \sum_{i=2}^{n} (|w_i| - LCP(w_i, w_{i-1}))$，无需真正建树，复杂度为读入加排序的 $O(S \log n)$（$S \le 32\text{K}$）。

## 形式化题目

三项成绩 $A$（作业）、$B$（小测）、$C$（期末考试）按固定权重合成课程总成绩：

$$S = A \times 20\% + B \times 30\% + C \times 50\%$$

其中每项成绩都是 $0$ 到 $100$ 之间 $10$ 的整数倍，题目要求输出整数形式的 $S$。
"都是 $10$ 的整数倍"不是普通的数据范围，它是本题能把计算全程放在整数域完成的根据。

两个样例的代入计算：

| 样例输入 | 计算过程 | 输出 |
| --- | --- | --- |
| `100 100 80` | $100 \times 20\% + 100 \times 30\% + 80 \times 50\% = 20 + 30 + 40$ | `90` |
| `60 90 80` | $60 \times 20\% + 90 \times 30\% + 80 \times 50\% = 12 + 27 + 40$ | `79` |

两个样例的每项乘积都是整数——$10$ 的倍数乘上 $20\%/30\%/50\%$ 恰好落在整数上，
这正是题面敢声明「输出一个整数」的底气；下面要做的，是让代码也走这条整数路径。

## 正解

### 思路

**朴素做法**：把公式直接翻译成浮点算式——读入三个数，算 `a*0.2 + b*0.3 + c*0.5`，打印结果。
本题没有循环和状态，瓶颈不在复杂度（本来就是 $O(1)$），而在这条浮点算式本身：

1. **输出格式必然错**：`print` 得到的是 `90.0`，而题目要的是整数 `90`；
   必须再套一层 `int()` 或 `round()` 才能过输出检查。
2. **`int()` 敢不敢用，取决于浮点结果是否恰好等于真值**：$0.2,\ 0.3,\ 0.5$ 都不是
   二进制有限小数——Python 里 `0.1 + 0.2` 得到 `0.30000000000000004`，浮点加权和
   落在期望整数的哪一侧没有理论保证。把 $0 \sim 100$ 内所有 $10$ 的倍数组合
   （$11^3 = 1331$ 种）枚举验证，本题的浮点和恰好**全部精确**——也就是说这种写法
   “碰巧全对”，正确性押在巧合上，而不是押在证明上。

**优化推导**：两个坑的共同根源是"用了浮点数"，那就把百分数权重整体乘 $100$，
$20\%,\ 30\%,\ 50\%$ 变成整数 $2,\ 3,\ 5$，分母统一为 $10$：

$$S = \frac{2A + 3B + 5C}{10}$$

**关键观察**：三项成绩都是 $10$ 的倍数，设 $A = 10a,\ B = 10b,\ C = 10c$，则

$$2A + 3B + 5C = 10(2a + 3b + 5c)$$

分子恒被 $10$ 整除，所以整除是**精确**的：既没有取整误差，商也天然是整数类型，
精度与格式两个问题同时消失。用整数权重把两个样例重算一遍：

| 样例输入 | 分子 $2A + 3B + 5C$ | 商 $/10$ |
| --- | --- | --- |
| `100 100 80` | $200 + 300 + 400 = 900$ | $90$ |
| `60 90 80` | $120 + 270 + 400 = 790$ | $79$ |

两行的分子都以 $0$ 结尾，这是「$10$ 的倍数」的必然结果；商与上一张表的结果完全相同：
整数换算没有改变答案，却把小数和输出类型两个问题一起消掉了。

**最终做法**：一次读入全部输入并解包成三个名字，算出分子 `homework*2 + quiz*3 + final*5`，
再 `// 10` 输出。全程没有循环、没有分支，也没有浮点数。

## 总结

- 形如"固定权重求总分"的题，先问一句**结果是否必为整数**：能证明整除，就把权重整体放大成
  整数做纯整数运算，浮点数的格式与精度问题一次性消失。
- 数据里的"都是 $10$ 的整数倍"就是整除性的来源，读题时不要当成普通数据范围跳过。
- 输出要求整数时，`//` 同时给出精度和类型；`print` 出 `90.0` 是这类题最常见的失分点。

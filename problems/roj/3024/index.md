## 形式化题目

平面上给定 $n$ 个"红点"（核电站）与 $n$ 个"蓝点"（特工），坐标为整数且 $0 \leqslant X, Y \leqslant 10^9$。求**任意一个红点与任意一个蓝点**之间的最小欧氏距离，保留三位小数。多组数据。

注意：题目求的不是全部 $2n$ 个点的最近点对——红点与红点、蓝点与蓝点之间的距离一律不计入答案。

## 正解

### 思路

**一句话本质**：这是经典的"最近点对分治"的**二色版本**——分治框架原封不动，只在两处动刀：合并时跳过同色点对，并把"当前最优值"作为上界传进递归，而不是让左右两半各自算出只关于自己颜色的 $d$。

先看朴素做法：枚举每一对（电站，特工），$n = 10^5$ 时约 $10^{10}$ 次距离计算，完全不可行。$O(n^2)$ 挡在这里，必须找到与最近点对同阶的做法。

**第一步：从样例确认"跨色"这个约束。** 样例一中电站占据单位正方形四个角，特工占据 (2,2) 到 (3,3) 的小正方形。全部 8 个点的最近点对距离是 $1.000$（电站正方形的边），而期望输出是 $1.414$——那是跨过两块区域的最短距离。这证实：同色点对再多、再近，也不许更新答案。

**第二步：套用最近点对分治的骨架。** 把所有点（带上颜色标记）按 $x$ 排序，从中间切一刀，分界线为 $x = mid\_x$。任意跨色点对只有三类：两点都在左半、都在右半、一左一右跨界。前两类交给递归，剩下的问题是"跨界点对怎么不枚举也能查完"。

经典分析在这里照常生效：设当前最优平方距离为 $best$，若某个跨界点对要打败它，则

$$dx^2 \leqslant dx^2 + dy^2 < best \quad\Rightarrow\quad dx^2 < best$$

所以两个端点的 $x$ 都落在分界线两侧宽度为 $\sqrt{best}$ 的**窄条**内；同理 $dy^2 < best$。把窄条内的点按 $y$ 升序排好，对每个点 $p$ 只向后扫描到 $(y_q - y_p)^2 \geqslant best$ 为止——后面的点 $y$ 只会更大，全部可以放弃。

**第三步：二色版本真正的坑——$d$ 必须是"跨色的 $d$"。** 经典写法里 $d = \min(\text{左半答案}, \text{右半答案})$。但本题左右两半"自己内部的最近点对"可能是**同色**的，而且同色点可以无限密集地挤在一起：假如左半里 99999 个电站挤成一团，$\min$ 算出的 $d$ 就约为 0，窄条窄成一条缝，真正的跨界点对全被剪掉了——**错解**。

修法是把上界**下传**：递归函数写成 `divide(pts, best) -> (best', 按y有序的点)`。从根往下，`best` 一路带着"到目前为止已知的跨色最优平方距离"进入子问题；子问题里每发现一个更近的跨色点对就立刻收紧它，再传给更深处。这样剪枝裁掉的永远只是"不优于当前跨色答案"的点对，绝不会漏。代价是鸽巢原理的"每点至多比较 7 个后继"不再成立（那要求每个 $d \times d$ 方块内点数有限，而同色点不受限），所以内层循环必须老老实实用 $(y_q - y_p)^2 \geqslant best$ 就 `break` 的窗口扫描——好在同色点越挤，`break` 反而触发得越早，最坏情况不会劣化。

**第四步：初始上界与实现细节。**

- 递归进入前，用 `random.choices` 随机抽 1000 对（电站，特工），取最小平方距离当初始 `best`。这保证 `best` 一开始就是某个真实跨色点对的距离（从而 $n=1$ 这类"递归里根本没有跨色比较机会"的边界也天然正确），剪枝半径也一开始就有限。
- 递归返回**按 $y$ 升序**的点列表，两半 `merge` 归并成整体有序，每层线性，避免每层重新排序。
- 全程用**整数平方距离**比较（$dx^2 + dy^2 < 2 \times 10^{18}$，`int` 无忧），只在输出前开一次方，`%.3f` 格式化，精度无忧。

### 复杂度

按 $x$ 排序一次 $O(n \log n)$；递归 $O(\log n)$ 层，每层归并 $O(n)$、窄条收集与窗口扫描均摊 $O(n)$，总计 $O(n \log n)$。空间上递归切片为 $O(n \log n)$。$n = 10^5$、坐标 $10^9$ 级别下，Python 常数偏大，存在 TLE 风险（本仓库教学解允许）；同样的骨架用 C++ 实现（`long long` 存平方距离）可以稳过 1 秒限制。

## 图示解析

### 样例一：为什么答案是 1.414

下图画出样例一的 8 个点（`◆` 核电站，`★` 特工）：

```text
y
3 |          ★     ★
2 |          ★     ★
1 |  ◆     ◆
0 |  ◆     ◆
    0     1     2     3   x
```

观察重点：全局最近点对是 `◆—◆`（距离 1.000），但它是**同色**的，不许计入答案。跨色最近的一对是 `◆(1,0) — ★(2,1)` 之类，距离 $\sqrt{2} \approx 1.414$。这就是样例输出——题目在颜色维度上做了过滤，解法也必须跟着过滤。

### 分治合并：窄条内的窗口扫描

```text
            mid_x
              │
   左半  ┌────┼────┐  右半
         │ 窄条: (x-mid_x)² < best │
         │    │    │
         │    │  q ● │   ← 与 p 跨色，检查
         │    │      │
         │  p ●      │
         └────┼────┘
              │
   窄条外的点：dx² ≥ best，距离不可能更优，直接不收集
```

观察重点：窄条按 $y$ 升序排列后，对每个 $p$ 只向后看，一旦 $(y_q - y_p)^2 \geqslant best$ 就停止——$y$ 差是距离的一个下界，后面的点只会更远。与经典版本不同，这里 $p$ 的后继中同色点直接 `continue`，而 `best` 是从更上层传下来的**跨色**最优值，保证剪枝既紧又不漏。

## 总结

- 本题是二色最近点对：电站-特工才计答案，同色点对一律跳过。
- 分治骨架与经典最近点对一致：按 $x$ 切半、递归、窄条 + $y$ 升序窗口扫描。
- 关键差异是把跨色最优值 `best` 作为参数**下传**递归，而不是用左右两半各自的 $\min$——否则同色点密集时 $d$ 会失真、窄条漏解；相应地，内层循环用"y 差平方 $\geqslant$ best 即 break"的窗口扫描代替定长 7 后继。
- 比较全程用整数平方距离，只在输出前开一次方；随机抽样 1000 对提供初始上界，同时覆盖 $n=1$ 的边界。
- 总复杂度 $O(n \log n)$。

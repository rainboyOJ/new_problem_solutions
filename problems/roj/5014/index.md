## 形式化题目

在无限长数轴上有 $n$ 个孩子，初始位于 $n$ 个互不相同的整点 $p_i$ 上，各有一个初始朝向 $d_i \in \{0,1\}$（$1$ 向右、$0$ 向左）。所有孩子始终以每秒 $1$ 单位长度的速度沿当前朝向匀速运动；每当某一时刻若干个孩子同时到达同一位置，他们立即各自反转朝向并继续运动。

给定 $q$ 次询问，每次给定 $k_i$ 与 $t_i$，求**输入顺序中编号为 $k_i$**（从 $0$ 开始）的孩子在 $t_i$ 秒后所在的坐标。孩子走出「桥」外仍在数轴上运动，答案可以是负数。

数据范围：$1 \le n, q \le 2 \times 10^5$，$0 \le k_i < n$，$0 \le p_i, t_i \le 10^9$，$d_i \in \{0,1\}$。

## 正解

### 思路

**朴素想法**：直接模拟折返过程 —— 找出下一次相遇时刻、交换两人的朝向，一直推到 $t$ 秒。问题在于相遇事件可能极多（$n$ 个孩子两两交错时事件数可达 $O(n^2)$），更糟的是每次询问的 $t_i$ 不同，模拟无法在所有询问间共享结果。这条路走不通，必须找「运动过程的不变量」。

**关键洞察一：相遇折返 ≡ 穿过对方并交换身份。** 两个孩子迎面相遇时同时折返，此后各自走的路线，与「两人互不干扰地穿过对方、继续按原方向走」在**每一时刻的位置集合**上完全一致 —— 唯一的区别只是「谁在这条路线上的名字」不同。换一种说法：把孩子想成拿着号码牌的粒子，相遇折返的物理过程等价于粒子互相穿过、并在相遇瞬间**交换号码牌**。

**关键洞察二：按初始位置排序的名次永不改变。** 在折返模型里孩子之间无法互相穿越（相遇只会掉头，不会越过），因此任意时刻从左到右的第 $r$ 个位置上坐的一定是同一个「名次」的孩子（具体是哪个孩子会因交换身份而变化，但名次对应的**位置序**不变）。注意这里的「名次」是**按初始位置升序排出来的名次**，不是孩子的输入编号。

由这两点立刻得到：任意时刻 $t$，所有孩子占据的坐标**多重集合**恒等于

$$
S_t = \{\, p_i + t \mid d_i = 1 \,\} \;\cup\; \{\, p_i - t \mid d_i = 0 \,\},
$$

即「每个人都按初始方向不回头地走到 $p_i \pm t$」。而初始名次为 $r$（从 $1$ 开始）的孩子，$t$ 秒后恰好位于 $S_t$ 的**第 $r$ 小值**处。

于是问题变成两步：

1. 预处理：按初始位置把孩子升序排序，记录每个孩子（按输入编号 $k$）的名次 `rank_of[k]`（$1$ 起），并把向右走的初始位置收集为升序数组 `right_pos`、向左走的收集为升序数组 `left_pos`（由于是按位置升序遍历时顺手收集的，两个数组天然有序）。
2. 每次询问 $(k, t)$：求两个有序数组

   $$R = \{\texttt{right\_pos}[i] + t\}, \qquad L = \{\texttt{left\_pos}[j] - t\}$$

   合并后的第 $\texttt{rank\_of}[k]$ 小值。注意 $R$ 与 $L$ 各自仍是有序的（$+t$、$-t$ 都是保序变换），所以可以**二分划分**求第 $r$ 小。

**求两个有序数组的第 $r$ 小（划分二分）**：设答案的划分是从 `right_pos` 里取前 $x$ 个、从 `left_pos` 里取前 $y = r - x$ 个进入「左半部分」。合法划分需要

$$
\texttt{right\_pos}[x-1] + t \le \texttt{left\_pos}[y] - t
\quad\text{且}\quad
\texttt{left\_pos}[y-1] - t \le \texttt{right\_pos}[x] + t .
$$

合法时答案就是左半部分的最大值 $\max(\texttt{right\_pos}[x-1]+t,\ \texttt{left\_pos}[y-1]-t)$。$x$ 的合法范围是 $[\max(0, r-\texttt{left\_cnt}),\ \min(r, \texttt{right\_cnt})]$，在此区间上二分：

- 若 $\texttt{right\_pos}[x-1]+t > \texttt{left\_pos}[y]-t$，说明从 right 里取多了，令 `hi = x - 1`；
- 否则若 $\texttt{left\_pos}[y-1]-t > \texttt{right\_pos}[x]+t$，说明取少了，令 `lo = x + 1`；
- 否则划分合法，返回答案。

越界处（$x=0$、$x=\texttt{right\_cnt}$ 等）用哨兵 $\pm\text{INF}$（代码取 $\pm 4\times 10^{18}$）代替，保证比较不会误判；由于 $|p \pm t| \le 2\times 10^9 \ll 4\times 10^{18}$，哨兵不会与真实值混淆。实现上（两份代码一致）是「先取 $x = \lfloor(\texttt{lo}+\texttt{hi})/2\rfloor$ 检查划分，不合法则按上述方向收缩」，单次 $O(\log n)$。

由于位置互不相同但 $S_t$ 中可能出现相等值（例如 $p_j - p_i = 2t$），此时「第 $r$ 小」的相邻取值相等，`max(r_last, l_last)` 仍返回正确坐标。

### 复杂度

- **时间复杂度**：排序 $O(n \log n)$；每次询问二分一次划分，$O(\log n)$，共 $O(q \log n)$。总计 $O((n+q)\log n)$，对 $n, q \le 2\times 10^5$ 绰绰有余（实测 Python 最慢约 $0.56$ 秒，C++ 约 $0.07$ 秒）。
- **空间复杂度**：存孩子信息、两个方向的有序位置数组与名次映射，$O(n)$。

## 总结

1. **「相遇折返 ≡ 穿过对方」为什么成立**：所有孩子速度大小恒为 $1$，迎面相遇时双方同时掉头，之后各自走过的路线与「两人直接穿过对方、原方向匀速直走」完全重合 —— 唯一差别是两条路线上的「名字」互换了，即**穿过对方的瞬间交换了号码牌**。因此每一时刻的位置多重集合与「无碰撞直走」模型完全一致，我们才能写出 $S_t = \{p_i+t\} \cup \{p_i-t\}$。

2. **「名次不变」正是第 $r$ 小化归的依据**：在折返模型中孩子永远不会互相穿越（相遇只会掉头），所以从左到右的名次序是不变量；等价地，在「交换号码牌」视角下，名次就是号码牌的传递载体 —— 穿过不改变「第 $r$ 个位置上有一个孩子」这一事实。于是「编号 $k$ 的孩子 $t$ 秒后在哪」就等于「$S_t$ 中第 $r$ 小的值是多少」，其中 $r$ 是孩子 $k$ 按初始位置排序的名次。位置的多重集合恒为 $S_t$，这就是整个化归的合法性来源。

3. **为什么不能每次询问都排序**：$q$ 可达 $2\times 10^5$，若对每个询问把 $S_t$ 全部算出来再排序，单次 $O(n \log n)$，总 $O(qn \log n)$，必然超时。正确做法是注意到 $S_t$ 是**两个有序数组的并**（$R = \{p_i + t\}$ 升序、$L = \{p_i - t\}$ 升序，$\pm t$ 保序），对划分点 $x$ 二分即可 $O(\log n)$ 求出第 $r$ 小。

4. **64 位整数必要性**：$p_i$ 与 $t$ 都可达 $10^9$，$p_i + t$ 可达 $2\times 10^9$，`int` 存不下；哨兵 $\pm\text{INF} = \pm 4\times 10^{18}$ 更必须是 64 位。C++ 中坐标、时间与中间量一律用 `long long`（`scanf/printf` 用 `lld`）；Python 的 `int` 任意精度，天然安全。

5. **易踩的坑：「名次」≠ 孩子编号**。询问给的 $k$ 是**输入顺序中的编号**，要先用预处理出的 `rank_of[k]` 换成按初始位置排序的名次（本实现从 $1$ 起），再去 $S_t$ 里取第 $r$ 小；直接拿 $k$ 当名次用是最典型的错误。另外答案可能是**负数**（孩子走出桥外仍在运动），不要按「桥长」之类的假设截断。

补充说明：Python 实现中使用了 `type Positions = list[int]` 类型别名语法，需要 Python 3.12+；若评测环境版本更老，把它删掉即可，不影响算法。数据本身经核对无缺陷：10 个点的全部答案都落在 $S_t$ 内，素材 `std.cpp` 输出与 `.out` 逐字节一致；两份实现对三份独立暴力（含一份完全不用「名次不变」结论的事件驱动模拟）411 组小数据 + 46 组边界用例 0 分歧。

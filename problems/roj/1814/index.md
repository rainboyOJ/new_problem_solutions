## 形式化题目

棋盘是 $n \times n$ 的 $n^2$ 个互异格子，每个格子上均匀随机地填入 $1 \sim m$ 中**互不相同**的数；
另外从 $1 \sim m$ 中均匀随机地选出 $k$ 个数（可能选到没出现在棋盘上的数）。
凡是取值落在选中 $k$ 个数里的格子都被涂黑。设恰好被整行涂黑的行数为 $r$、
被整列涂黑的列数为 $c$，求 $E\left[2^{\,r+c}\right]$。

约束：$2 \leqslant n \leqslant 300$，$n^2 \leqslant m \leqslant 100000$，$n \leqslant k \leqslant m$。
若答案 $> 10^{99}$ 则输出 $10^{99}$；输出与标准答案的相对误差不超过 $10^{-6}$ 即算通过。

把随机过程拆成两个独立部分会更好用：

1. **填数**：$\{1,\dots,m\}$ 到 $n^2$ 个格子的均匀随机单射；
2. **选数**：$\{1,\dots,m\}$ 的均匀随机 $k$ 子集 $S$。

格子黑 $\iff$ 它的值 $\in S$。由于单射与子集抽样互相独立，任何指定的 $t$ 个格子的取值
构成 $\{1,\dots,m\}$ 的均匀 $t$ 子集，并且"这 $t$ 格全黑"只取决于 $t$，与它们的具体位置无关。
这一点是整道题的地基。

## 正解

### 思路

**朴素做法为什么走不通。** 最直白的写法是分别算出"恰好 $r$ 行、$c$ 列全黑"的概率 $P(r,c)$，
再乘 $2^{r+c}$ 求和。可是"恰好"这个词要通过容斥才能消掉，而行与列在交叉格上互相纠缠：
固定 $t$ 行全黑时，列的统计并不独立。展开成"恰好"需要 $O(2^{2n})$ 量级的多维容斥，
$n = 300$ 时 $2^{600}$ 完全不可行。

问题的根源在于：**$r$ 和 $c$ 是"恰好"量，而"恰好"天生难以直接计算。**

**关键跳跃一：把 $2^{r+c}$ 换成一个计数。** 注意 $2 = 1+1$，由二项式定理

$$2^{\,r+c} = 2^r \cdot 2^c = (1+1)^r (1+1)^c = \sum_{i=0}^{r}\binom{r}{i} \sum_{j=0}^{c}\binom{c}{j} = \sum_{i=0}^{r}\sum_{j=0}^{c}\binom{r}{i}\binom{c}{j}.$$

这个代数式有非常干净的组合意义：从**已经全黑的** $r$ 行里挑 $i$ 行、从 $c$ 列里挑 $j$ 列的方案数，
恰好是 $\binom{r}{i}\binom{c}{j}$。也就是说

$$2^{\,r+c} = \#\{(R, C) : R \subseteq \text{全黑行},\; |R| = i,\; C \subseteq \text{全黑列},\; |C| = j\}$$

把 $i, j$ 也一并求和，等价于

$$2^{\,r+c} = \sum_{R \subseteq [n]} \sum_{C \subseteq [n]} \bigl[\text{每行 } R \text{ 全黑} \wedge \text{每列 } C \text{ 全黑}\bigr],$$

其中 $R, C$ 遍历**所有** $2^n \cdot 2^n$ 对子集，方括号是指示函数。这一步把"恰好 $r$ 行全黑"
这种全局条件，换成了对每一对具体子集 $(R, C)$ 的**局部指示**——容斥消失了。

**关键跳跃二：期望的线性性替换掉"恰好"。** 对上面这个恒等式两边取期望，
指示函数的期望就是事件概率，求和可以和期望交换：

$$E\left[2^{\,r+c}\right] = \sum_{R \subseteq [n]} \sum_{C \subseteq [n]} P\bigl(R \text{ 的每行全黑} \;\wedge\; C \text{ 的每列全黑}\bigr).$$

右边的事件只要求"指定的这些行、这些列全黑"，**不要求别的行/列不黑**，因此不再需要容斥。
这正是它比 $P(r,c)$ 路线的优势：用线性性把"恰好"扔掉。

**归并成 $n^2$ 项。** 由对称性，事件概率只取决于 $|R| = i$、$|C| = j$，
而 $|R| = i$ 的子集有 $\binom{n}{i}$ 个：

$$E\left[2^{\,r+c}\right] = \sum_{i=0}^{n}\sum_{j=0}^{n} \binom{n}{i}\binom{n}{j} \cdot P\bigl(\text{指定的 } i \text{ 行 } j \text{ 列全黑}\bigr).$$

**算概率 $P(t)$。** 指定的 $i$ 行和 $j$ 列在棋盘上占据的是它们的并集，格子数为

$$t(i,j) = \underbrace{n\,i}_{\text{$i$ 个整行}} + \underbrace{n\,j}_{\text{$j$ 个整列}} - \underbrace{i\,j}_{\text{交叉格算了两次}} .$$

这 $t$ 个格子的取值构成 $\{1,\dots,m\}$ 的均匀 $t$ 子集（单射保证互不相同），
$t$ 格全黑 $\iff$ 选的 $k$ 个数把这 $t$ 个值全部包含进来。用超几何分布：

$$P(t) = \frac{\dbinom{m-t}{k-t}}{\dbinom{m}{k}} = \prod_{p=0}^{t-1}\frac{k-p}{m-p}, \qquad t > k \text{ 时 } P(t) = 0 .$$

最右侧的连乘形式最容易在程序里递推：$P(0) = 1$，$P(t) = P(t-1)\cdot\dfrac{k-t+1}{m-t+1}$。
注意 $t \leqslant n^2 \leqslant m$ 保证了分母 $m-p+1 \geqslant m-n^2+1 > 0$，永不除零。

**对照两个特例确认公式。** $k = m$ 时所有格子必黑，$P(t) = 1$，于是
$E = \sum_i\sum_j \binom{n}{i}\binom{n}{j} = 2^n \cdot 2^n = 4^n = 2^{2n}$，与"$r=c=n$ 得 $2^{2n}$"一致。
$k < n$ 时 $t \geqslant n > k$ 恒成立，$P(t) = 0$，$E = 1$，与"一行都涂不黑、得 $2^0$"一致。

**数值精度。** $\binom{300}{150} \approx 9.4 \times 10^{88}$，$64$ 位整型必然溢出，
所以组合数、概率、答案全程用 `double`（上限约 $1.7 \times 10^{308}$，精度约 $15 \sim 17$ 位有效数字，
远优于题面要求的相对误差 $10^{-6}$）。单项最大约 $9.4\times10^{88} \times 9.4\times10^{88} \approx 8.8\times10^{177}$，
仍在 `double` 范围内不会上溢。反过来，$P(t)$ 连乘下溢成 $0$ 时该项贡献 $< 10^{-308}$，
而答案下界是 $1$，忽略它造成的相对误差远低于 $10^{-6}$。

$n = 300$ 时循环次数是 $301^2 \approx 9.06 \times 10^4$，加上 $n^2$ 的递推，整体不到 $2\times10^5$ 次运算。

## 总结

- **"恰好"很难，"指定"很容易**：$P(r,c)$ 需要 $O(2^{2n})$ 的多维容斥，
  而 $P(\text{指定的 } i \text{ 行 } j \text{ 列全黑})$ 只要求覆盖的 $t$ 格全黑。
  期望的线性性把前者换成后者，是本解法的全部杠杆。
- **$2^{r+c}$ 是"子集计数"**：$2^r$ 就是"$r$ 个全黑行的子集个数"。
  这一步把得分从"指数型的随机量"变成"对子集的指示函数之和"，
  从而可以逐子集取期望，不再需要先知道 $r$、$c$ 的分布。
- **$2 = 1+1$**：$n = 1$、系数为 $2$ 的多项式看似平凡，却正好等于"所有子集求和"；
  见到 $2^{\text{某个计数}}$ 可以条件反射地往"子集计数"上想。
- **不管集合怎么叠，先数并集大小**：$i$ 行 $j$ 列的覆盖格子数是 $ni+nj-ij$，
  交叉部分被算了两次要减掉一次。这是所有"行列并集"型题目的通用一步。
- **精度先算量级再选类型**：$\binom{300}{150} \approx 9.4\times10^{88}$ 直接决定了
  不能用整型、必须用 `double`；而 $\prod$ 形式的下溢因为答案有下界 $1$ 所以无害。
  这两件事不看数量级是猜不出来的。
- **关于本题数据来源的说明**：仓库内该题的 `content.md` 题为"一本通 1814 方格染色"
  （见素材源头部注释，5 轮检索未找到公开题解/AC 代码），随仓 `data/` 由 `data.py` 生成，
  题面亦可能是网络重建，出题意图与官方原题可能存在偏差。
  本文的算法已用**独立暴力程序**核对：对 $n=2,m=4$ 穷举全部 $4! \times \binom{4}{k}$ 种
  （棋盘排列 $\times$ 选数集合），结果 $k=2$ 时 $5/3$、$k=3$ 时 $4$，与公式一致；
  另在 $n \leqslant 3$、$m \leqslant 13$ 上随机抽 $\binom{m}{k}$ 全枚举对拍 120 组，$120/120$ 一致。

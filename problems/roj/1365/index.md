## 形式化题目

给定长度为 $2^N$ 的 01 串（$0\leqslant N\leqslant 10$）。按规则构造 FBI 树：根结点类型由整串决定（全 0 为 B，全 1 为 I，否则为 F）；长度大于 1 时从中间分成左右等长子串，分别递归构造左右子树。输出该树的后序遍历序列。

**输入**：第一行整数 $N$，第二行 01 串。  
**输出**：一行字符串，即后序遍历序列。

样例输入：`3` / `10001011`，样例输出：`IBFBBBFIBFIIIFF`。

## 解法总览

两种解法共用同一条分治规则：**一段 01 子串就是一棵 FBI 子树**，根类型看整段含 0 还是 1，串长大于 1 就从中间对半切。差别只在「后序序列是直接拼出来，还是先把树存下来再走一遍」。

| | 解法一：子串递归直接拼（原实现） | 解法二：先建树再后序（正式主解） |
| --- | --- | --- |
| 做法 | 递归返回左右两半的后序串，拼上根类型 | `new_node()` 建出 `Node{type, lch, rch}`，再 `postorder(root)` 收集 |
| 中间结构 | 递归返回的临时字符串（Python 用 `@cache` 按子串去重） | 结点表 O(L)，可复用 |
| 时间 | 每个结点扫一遍自己的子串定类型，O(L log L) | 同左，另有 O(L) 的建树与遍历 |
| 代码 | `direct.py` / `direct.cpp` | `main.py` / `main.cpp` |

正式主解是 `main.py` / `main.cpp`。

## 解法一：子串递归直接拼

### 思路

子串区间与 FBI 子树一一对应。递归处理左右两半，返回后序序列，再拼接根结点类型即可。长度 1 时直接返回该字符对应的 B/I。

### 复杂度

- 时间：每个结点都要扫自己的子串判断类型，所有子串长度之和为 O(L log L)（树是完全二叉的，每层共 L 个字符，共 log L + 1 层）。
- 空间：递归栈 O(log L)，加上返回的字符串与缓存 O(L log L)。

## 解法二：先建树再后序

### 思路

规则完全一样，区别在于**先把树存下来**：`build(l, r)` 对子串开一个结点、算好类型，串长大于 1 时从 `mid = (l + r) / 2` 切开，把左右孩子接上；建完再从根做一遍 `postorder(u)`，左、右、根依次收集类型。

结点的类型、左儿子、右儿子收进同一个 `Node`，编号即下标（静态数组 + `node_cnt` 动态开点）。树一旦存下来，后序只是三行递归；要改成先序、中序或统计结点数，也不必再碰原串。

## 复杂度对比

| | 解法一 | 解法二 |
| --- | --- | --- |
| 时间 | O(L log L) | O(L log L) |
| 空间 | 字符串拼接 + 缓存 | 结点表 O(L) |
| 能否复用树结构 | 不能 | 能 |
| 适合场景 | 只求一次后序、写法最短 | 后续还要在树上做别的事 |

两法同阶。解法一最短、Python 里几乎是「一行一个递归」；解法二把题面的构造过程如实落到结点上，读题面与读代码能一一对上。

## 总结

1. **子串 ↔ 子树**是分治题的常见建模：想清楚「哪一段对应哪棵子树」，剩下的只是递归的返回值选字符串还是选结点编号。
2. 解法一的 `@cache` 与解法二的结点表，本质都是**避免重复算同一段**——前者按子串内容去重，后者按区间位置去重。
3. 结点用 `Node{type, lch, rch}` 聚合、编号即下标，是这本仓库建二叉树的标准写法（见《树的存储》）。

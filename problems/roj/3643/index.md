## 形式化题目

在平面上给定第一象限内的 $n$ 个点 $(x_i, y_i)$（$0 < x_i, y_i < 10$，互不相同）。每次操作选择一条形如 $y = ax^2 + bx$（$a < 0$，$a,b$ 为实数）的抛物线，所有恰好落在这条曲线上的点被"消灭"。求消灭全部 $n$ 个点所需的最少操作次数。共 $T$ 组数据，$1 \leqslant n \leqslant 18$。

## 正解

### 思路

**朴素做法。** 最直接的想法是：每只小猪单独发射一只鸟去打，答案上界是 $n$。要减少次数，就要让一只鸟顺路多打几只——问题变成"哪些小猪能被同一条抛物线一起带走"。

**第一步：小猪集合可以化成 bitmask。** 一条轨迹 $y = ax^2 + bx$ 必须过原点。任取两只不在同一竖直线上的小猪 $(x_1, y_1)$、$(x_2, y_2)$，把它们代入方程得到线性方程组

$$\begin{cases} a x_1^2 + b x_1 = y_1 \\ a x_2^2 + b x_2 = y_2 \end{cases} \quad\Longrightarrow\quad a = \frac{y_1/x_1 - y_2/x_2}{x_1 - x_2},\qquad b = \frac{y_1}{x_1} - a x_1$$

也就是说：**一条合法轨迹最多由两只小猪唯一确定**。反过来，若某次发射打中了 $\geqslant 2$ 只小猪，其中任意两只确定出的就是这条轨迹本身。所以值得考虑的抛物线只有

$$\text{LINE}[i][j] = \text{过原点与小猪 } i, j \text{ 的抛物线经过的小猪集合（bitmask）}$$

这 $O(n^2)$ 条。两种特殊情况退化成"只打 $i$ 自己"：$x_i = x_j$（两点同列，方程组无解）以及解出的 $a \geqslant 0$（开口向上或水平，不能从原点射进第一象限再落回地面）。坐标只有两位小数，"经过"用 $\varepsilon = 10^{-6}$ 判定：$|a x_k^2 + b x_k - y_k| < \varepsilon$。$\text{LINE}[i][i] = \{i\}$，代表"故意单打一只"。

**第二步：集合覆盖 → 状压 DP。** 现在每个候选抛物线对应一个"一次发射能消灭的小猪集合"，问题变成：用最少的集合把全集 $\{0, 1, \dots, n-1\}$ 覆盖。$n \leqslant 18$ 正是 bitmask DP 的信号：

$$dp[S] = \text{已消灭的小猪集合包含 } S \text{ 时，需要的最少小鸟数}$$

初值 $dp[0] = 0$，答案是 $dp[\text{全满}]$。若直接从每个状态枚举所有 $O(n^2)$ 条线，会有大量重复计数；标准技巧是**给转移定序**：设 $low$ 是当前还活着的编号最小的小猪，它迟早要被某只鸟"第一次"消灭——固定当前这只鸟就是解决它的那只，于是只需枚举 $\text{LINE}[low][j]$（$j$ 遍历所有小猪，含 $j = low$），从 $S$ 转到 $S \cup \text{LINE}[low][j]$。每只活猪的"第一次"都被恰好转移一次覆盖，不重不漏。

**题面的 $m$ 指令呢？** $m = 1$、$m = 2$ 保证的是最优解的形状（有 $\lfloor n/3 \rfloor$ 连杀、$\lceil n/3 + 1 \rceil$ 只内全灭），源自"任意三只小猪中必有两只确定的抛物线合法"的组合性质，用于引导搜索 + 剪枝的写法；状压 DP 不依赖这些性质，读入后直接忽略 $m$。

### 复杂度

- 预处理候选线：$O(n^2)$ 条 × 每条 $O(n)$ 次判定 = $O(n^3)$，$n \leqslant 18$。
- DP：$2^n$ 个状态 × 每状态 $n$ 次转移 = $O(2^n \cdot n) \approx 4.9 \times 10^7$，空间 $O(2^n)$。
- 这与标准 C++ 正解同阶；Python 实现在本仓库 20 组真实数据上每组不超过 $0.02\,\mathrm{s}$、峰值约 $15\,\mathrm{MB}$，远低于限制。

## 图示解析

以样例 2 的第 3 关为例：5 只小猪 $(2.72,2.72)$、$(2.72,3.14)$、$(3.14,2.72)$、$(3.14,3.14)$、$(5.00,5.00)$。其中前四只恰好构成关于直线 $x = y$ 的对称方阵，第 5 只在对角线方向更远处。第一步预处理后，几条有代表性的候选抛物线如下（猪从 0 开始编号）：

| 候选线 | 决定它的猪 | 打中的 bitmask | 含义 |
| --- | --- | --- | --- |
| $y = -x^2 + 5.44x$ | 0 与 3（对角） | `{0, 3}`（$0011$） | 顺路带走对角两只 |
| $y = -x^2 + 5.86x$ | 1 与 2（对角） | `{1, 2}`（$1100$） | 顺路带走反对角两只 |
| $y = -x^2 + 10x$ | 1 与 4 | `{1, 4}` | 顺路带走第 5 只 |
| 单打 | $i$ 自身 | `{i}` | 保底方案 |

注意同列的 0 与 1（$x$ 都是 $2.72$）、2 与 3（$x$ 都是 $3.14$）之间**没有**合法候选线——这正是 $x_i = x_j$ 需要特判的原因。

DP 从 $dp[0] = 0$ 出发，每次转移固定编号最小的活猪 $low$，用"解决 $low$ 的那条线"扩展集合。最优路线为：

$$dp[\varnothing]=0 \xrightarrow{\ \text{LINE}[0][3]\ } dp[\{0,3\}]=1 \xrightarrow{\ \text{LINE}[1][2]\ } dp[\{0,1,2,3\}]=2 \xrightarrow{\ \text{单打 } 4\ } dp[\{0..4\}]=3$$

答案 3。读者应观察两点：一条抛物线天然对应一个 bitmask 集合；"最小活猪定序"让每步枚举从 $O(n^2)$ 条线缩到 $O(n)$ 条，把指数里的 $n^2$ 因子压成 $n$。

## 总结

- 把"发射一只鸟"抽象成 $O(n^2)$ 条候选抛物线上的 bitmask 集合，是本题唯一的建模跳跃；两只猪定一条抛物线（$a<0$、不同列才合法）是核心观察。
- $n \leqslant 18$ 提示状压 DP；"编号最小活猪定序"消除排列重复，转移 $O(2^n \cdot n)$。
- 实现细节：同列与 $a \geqslant 0$ 特判成"单打"、$\varepsilon$ 判经过、$m$ 指令直接忽略。
- 验证：三个官方样例一致；data 仓 20 组真实测试数据全部 PASS。

## 形式化题目

给定正整数 $m$（$1 < m < 100000$）和 $k$（$1 < k < 5$），判断是否同时满足：

1. $m$ 能被 $19$ 整除；
2. $m$ 的十进制写法中数字 $3$ **恰好**出现 $k$ 次。

满足输出 `YES`，否则输出 `NO`。

## 正解

### 思路

这道题是两个独立判定的组合，$m$ 至多五位数，每个判定都是常数开销，不存在"朴素做法→优化"的推导空间，直接把两个条件翻译成代码即可。

**条件一：整除判定。** `m % 19 == 0`，一行取模，无需多说。

**条件二：数 3 的个数。** C++ 里通常写成"反复取个位再除以 10"的循环；Python 里把整数转成十进制字符串后直接数字符 `'3'`，是同一个算法的表达式形式：

| 写法 | 算法 |
| --- | --- |
| `while (m) { if (m % 10 == 3) cnt++; m /= 10; }` | 逐位取模统计 |
| `str(m).count('3')` | 转十进制字符串后数字符 |

两者逐位一一对应：字符串的每个字符就是 $m$ 的一个十进制数位。

**两个条件用逻辑与连接。** 注意题面里"恰好含有 $k$ 个 3"是**恰好**不是**至少**，所以用 `==` 比较，不能用 `>=`；两个条件都必须满足，缺一不可。

**样例走查：**

| 输入 | 各位数字 | 3 的个数 | $m \bmod 19$ | 结论 |
| --- | --- | --- | --- | --- |
| `43833 3` | 4 3 8 3 3 | 3 | $43833 = 19 \times 2307$，整除 | YES |
| `39331 3` | 3 9 3 3 1 | 3 | $39331 \bmod 19 = 1 \neq 0$ | NO |

第二个例子正是陷阱所在：3 的个数达标了，但整除条件不满足，两个条件是 AND 关系，答案仍是 `NO`。反过来，19 的某个倍数如果不含 3（比如 `90292`，一个 3 都没有），也应当输出 `NO`。

### 复杂度

- 时间复杂度：$O(d)$，其中 $d$ 是 $m$ 的十进制位数（$d \leqslant 5$），整除判定 $O(1)$。

## 总结

- 本题是把题面条件**逐条翻译**成布尔表达式再取逻辑与的最小练习。
- 数位统计在 Python 里的惯用写法：`str(m).count('3')`，与 C++ 的逐位取模循环是同一个算法。
- 审题陷阱有两个：**恰好** $k$ 个（`==` 不是 `>=`），两个条件是 **AND** 关系（一个不满足就输出 `NO`）。

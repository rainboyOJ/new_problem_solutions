## 形式化题目

给定一个自然数 $n$（$0 \le n < 20$）。要求在屏幕上输出一个由字符 `*` 构成的直角三角形，该三角形共有 $n$ 行。
对于其中的第 $i$ 行（$1 \le i \le n$），输出恰好 $i$ 个 `*`，然后紧跟一个换行符。当 $n = 0$ 时，输出应当精确为 $0$ 字节（不输出任何内容，哪怕是单独的换行符）。

## 正解

### 思路

这是一道非常经典的嵌套循环练习题。
题目要求我们输出 $n$ 行星号，第 $1$ 行 $1$ 个，第 $2$ 行 $2$ 个，依此类推，第 $n$ 行 $n$ 个。

我们可以使用两个循环来完成这个任务：
1. **外层循环**：控制行数。用一个变量 $i$ 从 $1$ 循环到 $n$。
2. **内层循环**：控制当前行输出的星号个数。在第 $i$ 行时，我们需要输出 $i$ 个星号，所以用另一个变量 $j$ 从 $1$ 循环到 $i$，每次输出一个 `*`。
3. **换行**：每当内层循环结束（即当前行的星号都输出完毕），我们需要在行末输出一个换行符，以便下一行的星号能够在新的一行输出。

需要注意的是，当输入的 $n = 0$ 时，按照常理（循环条件不满足）不应输出任何内容。自然数是包含 $0$ 的，且循环结构 `for(int i = 1; i <= n; i++)` 当 $n=0$ 时条件 `1 <= 0` 直接为假，整个外层循环不执行，恰好符合 $n=0$ 时输出为空的期望。

### 复杂度

- **时间复杂度**：每一行的星号数量为 $i$，我们需要执行内层循环 $1 + 2 + \cdots + n = \frac{n(n+1)}{2}$ 次输出操作。因此时间复杂度为 $O(n^2)$。
- **空间复杂度**：程序只使用了常数个变量用于循环控制，不依赖任何与 $n$ 相关的额外数据结构，因此空间复杂度为 $O(1)$。

## 总结

- **$n=0$ 的边界处理**：题面指出 $n$ 是自然数，意味着包含 $0$。真实数据第一点正是 $n=0$，对应的正确输出是 **0 字节**（不是输出一个空行）。如果将代码错误地改成在 $n=0$ 时强制输出一个换行 `\n`，就会在这一测试点报错（实测反事实双重锁定）。
- **输出格式与字节级刻画**：
  - 第 $i$ 行恰好 $i$ 个 `*`，**行尾没有空格**。
  - **每一行（包含最后一行）都必须以换行符结尾**。
  - 输出总字节数公式为 $\frac{n(n+1)}{2} + n$ 字节。真实数据完美符合这一定律，例如 $n=1$ 时精确输出 `*\n`（$2$ 字节），$n=5$ 输出 $20$ 字节，$n=19$ 输出 $209$ 字节。
- **易错提醒（Python `join` 的坑）**：在使用 Python 时，若想直接使用字符串拼接来一次性输出结果，很容易错误地写出 `"\n".join("*" * k for k in range(1, n + 1))`。这个表达式虽然拼出了多行，但它的**最后一行缺失了换行符**。实际上 `.join` 只是在每项元素“之间”插入分隔符。正确的写法是显式为每行附加换行 `"".join("*" * k + "\n" for k in range(1, n + 1))`，这是处理行级输出时经常容易踩坑的细节。
- **验证强度摘要**：为了确认实现的正确性，我们运用 Python 的字符串拼接生成器作为异源实现，对 $n \in [0, 19]$ 全 $20$ 个值进行穷举对拍并直接对比原始字节流。实测所有答案均 $0$ 字节分歧（无多余空格与换行），且最终代码里所有数值字面量只使用了 `{0, 1}` 控制循环界限，不存在硬编码答案。

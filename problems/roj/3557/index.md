## 形式化题目

给定三个参数 $p_1, p_2, p_3$ 和一个仅含小写字母、数字、减号 `-` 的字符串 $s$（$|s| \leqslant 100$）。

从左到右扫描 $s$，对每个位置的字符：

- 若它是 `-`，且左右两侧字符同为小写字母或同为数字，且右侧字符的 ASCII 码**严格大于**左侧字符，则把它替换为展开段：取左开右开区间 $(s_{i-1}, s_{i+1})$ 中的字符序列，$p_3 = 1$ 时正序、$p_3 = 2$ 时逆序；$p_1 = 1$ 时字母取小写、$p_1 = 2$ 时字母取大写（数字两种取法相同）、$p_1 = 3$ 时不输出字符本身，改为输出等个数的 `*`；$p_2 = k$ 表示每个字符连续重复 $k$ 次。
- 若它是 `-` 但不满足上述条件，或它是普通字符，则原样保留。

求最终得到的字符串。

样例：$p_1=1, p_2=2, p_3=1$，输入 `abcs-w1234-9s-4zz`，输出 `abcsttuuvvw1234556677889s-4zz`。

## 正解

### 思路

**朴素做法**：字符串总长不超过 $100$，展开后最多也就是几百个字符，直接按题面一步步模拟即可——事实上本题的"正解"就是**把题面规则逐条翻译成代码**，不存在数据范围逼出来的优化。

**逐条翻译规则**。扫描每个位置 $i$，遇到字符 $s_i$ 时分两类：

1. $s_i$ 是 `-`：先判定能否展开。三个条件缺一不可——
   - 两侧同为小写字母，或同为数字（**同是字母和数字混合不算**，如 `a-5` 保留减号）；
   - $s_{i-1} < s_{i+1}$（严格小于，所以 `d-d`、`3-1` 保留减号）；
   - 减号不在字符串两端（一端为空时另一侧不是合法字符，保留减号）。
   满足则把减号替换成展开段；否则减号原样输出。

2. $s_i$ 是普通字符：原样输出。

**展开段的生成**（这是全题唯一的"算法"部分）。设左、右端字符为 $l, r$，中间应填充的字符是 `chr(ord(l)+1), chr(ord(l)+2), ..., chr(ord(r)-1)`，共 $\text{ord}(r)-\text{ord}(l)-1$ 个。三个参数分别作用在这串字符上：

| 参数 | 作用位置 | 实现 |
| --- | --- | --- |
| $p_1$ | 决定"输出什么" | $p_1=3$ 时直接输出 `*`；$p_1=2$ 时仅字母子串转大写（数字子串不能 `upper`，保持不变） |
| $p_2$ | 决定"每个字符重复几次" | 每个字符 `ch * p2` |
| $p_3$ | 决定"字符顺序" | $p_3=2$ 时整段逆序 |

三个参数互相独立，先后顺序随意——因为逆序对称、逐字符重复也对称。用样例 2 验证：`a-d-d`，$p_1=2, p_2=3, p_3=2$：

```text
a - d - d
    │     中间字符序列 B C
    │     p3=2 逆序 → C B，p2=3 逐字符重复 → CCCBBB
    └→ CCCBBB
      │   d-d：右侧不严格大于左侧，保留减号
      └→ -
输出: aCCCBBBd-d  ✓
```

**两个易错点**：

- `d-e` 这类"右侧恰好是后继"的情况：中间区间 $(d, e)$ 为空，展开段是空串，效果恰好等价于"只删减号"，不需要单独分支。
- `$p_1=2$ 只影响字母`：数字子串（如 `1-5`）在 $p_1=2$ 时仍输出小写数字即原数字，若对数字串调用 `upper()` 虽然无副作用，但必须保证判断发生在字母子串上。

### 复杂度

设 $|s| = n$，每个减号最多生成 $p_2 \times 25 \leqslant 8 \times 25 = 200$ 个字符，总输出长度 $O(n \cdot p_2)$，扫描与拼接均为线性，时间复杂度 $O(n \cdot p_2)$，空间同阶。$n \leqslant 100$ 下远小于限制。

## 总结

- 字符串模拟题的关键是**把题面每条规则对应到一处代码**，先判定"要不要展开"，再按 $p_1 \to p_2 \to p_3$ 三个独立参数生成填充段。
- 边界与特判集中在减号判定上：两端、两侧异类、右侧不严格大于，这四种情况一律保留减号；"后继对"（`d-e`）靠空展开段自然覆盖，不必特判。
- $p_1=2$ 的字母判定要放在"同侧是字母"的前提内，数字子串不受影响。

## 形式化题目

给定 $N$ 个点、$M$ 条带权边的无向连通图，每条边 $i$ 用小写字符描述为四元组
$(x_i, y_i, u_i, v_i)$，其中 $x_i, y_i$ 是端点，$u_i, v_i$ 是两个非负整数**代价分量**。
给定正实数 $k_1, k_2$ 后，边 $i$ 的实际长度是

$$w_i(k_1, k_2) = u_i k_1 + v_i k_2 .$$

对 $Q$ 组独立的 $(k_1, k_2)$，求出以 $w_i(k_1,k_2)$ 为边权的最小生成树总长（保留三位小数）。

约束：$N \leqslant 35$，$M \leqslant 25000$，$Q \leqslant 200000$，$0 \leqslant u_i, v_i \leqslant 10^6$，
$k_1, k_2 > 0$。

把一棵生成树 $T$ 压缩成两个整数

$$a_T = \sum_{i \in T} u_i, \qquad b_T = \sum_{i \in T} v_i ,$$

于是 $T$ 的代价是 $k_1 a_T + k_2 b_T$，**只和点 $(a_T, b_T)$ 有关，与树的形状无关**。
所有生成树对应平面上至多 $O(\binom{M}{N-1})$ 个整数点，问题变成：

$$\text{ans}(k_1,k_2) = \min_{T} \bigl(k_1 a_T + k_2 b_T\bigr) .$$

## 正解

### 思路

**第一步：把"求 MST"换成"在点集里找最优投影点"。**

对固定的 $(k_1,k_2)$，Kruskal 会给出一个使 $k_1 a + k_2 b$ 最小的点，但 $(k_1,k_2)$ 有
$Q = 2 \times 10^5$ 组，逐组跑 MST 是 $O(QM\log M)$，不可接受。要利用的结构是：
**只有很少一部分点可能成为某个方向的最优解。**

**第二步：只有左下凸壳（Pareto 最小点）有用。**

若点 $p$ 被点 $q$ **支配**，即 $q_a \leqslant p_a$ 且 $q_b \leqslant p_b$，那么对任意
$k_1,k_2 > 0$ 都有 $k_1 q_a + k_2 q_b \leqslant k_1 p_a + k_2 p_b$，$p$ 永远不可能是答案。
删掉全部被支配点后剩下的点在 $(a, b)$ 平面上构成一条 **$a$ 递增、$b$ 严格递减的左下凸链**，
这就是所有 MST 点集的左下凸壳。于是

> **核心不变量**：$\text{ans}(k_1,k_2)$ 一定在左下凸壳的某个顶点上取到；
> 记凸壳顶点为 $P_0,\dots,P_{H-1}$（按 $a$ 递增），则
> $\text{ans} = \min_{0 \le i < H}\bigl(k_1 a_i + k_2 b_i\bigr)$。

**第三步：用"沿弦法向做一次 MST"来补全凸壳。**

凸壳未知，但两个极端的顶点可以直接拿到：

- 方向 $(1,0)$（$k_1=1, k_2=0$）：边权就是 $u$，MST 给出 $\min \sum u$，即 $a$ 最小的点；
- 方向 $(0,1)$：边权是 $v$，MST 给出 $b$ 最小的点。

这两个点分别是凸链的两个端点。接下来做与"QuickHull"同构的分治：已知凸壳上相邻的
两个候选 $l$（左上）与 $r$（右下），取**与弦 $lr$ 垂直、两个分量都正**的方向

$$d = (\,l_b - r_b,\; r_a - l_a\,) = (-\Delta b,\; \Delta a),$$

用 $d$ 当边权跑一次 MST，得到一个点 $mid$。若

$$\texttt{cross}(l,r,mid) = (r_a - l_a)(mid_b - l_b) - (r_b - l_b)(mid_a - l_a) < 0,$$

说明 $mid$ 严格落在弦 $lr$ 的下方，它是凸壳上的一个**新**顶点，且必然满足
$l_a < mid_a < r_a$（否则它早就被 $l$ 或 $r$ 支配）；于是对 $(l, mid)$ 与 $(mid, r)$
两段递归。若叉积 $\geqslant 0$，说明弦下方已经没有任何生成树点，这一段枚举完毕。

关于 $d$ 为什么取这个方向：$l, r$ 在方向 $(l_b - r_b,\, r_a - l_a)$ 上的投影相等
（$(-\Delta b) a + (\Delta a) b$ 在这两点上取值相同），所以它正是"扫过弦下方"的那一族
方向；$k_1,k_2>0$ 也说明我们只关心第一象限的方向。用整数方向做 MST 还有个好处：
边权 $d_1 u + d_2 v$、点积与叉积全是整数，**排序和判共线都没有浮点参与**。

**第四步：查询——凸链上的二分。**

链上 $a_i$ 递增、$b_i$ 递减，相邻两点的分界斜率

$$r_i = \frac{b_i - b_{i+1}}{a_{i+1} - a_i} > 0$$

随 $i$ 严格递减。从 $i$ 走到 $i+1$ 时代价的变化是
$k_2 \Delta a\,(k_1/k_2 - r_i)$：当 $k_1/k_2 < r_i$ 时往右更优，$k_1/k_2 \ge r_i$ 时停下。
所以最优顶点就是**第一个满足 $r_i \le k_1/k_2$ 的 $i$**，把这些 $r_i$ 倒序排成升序后
二分即可，单次询问 $O(\log H)$。

**样例验证。** 样例图的凸壳只有 3 个顶点：$(6,20)$、$(9,14)$、$(10,13)$，
两个分界斜率恰好是 $r_0 = 1$、$r_1 = 2$：

| 凸壳点 $(a,b)$ | 区间 | 询问 | $k_1/k_2$ | 最优点 | 代价 |
| :-: | :-: | :-: | :-: | :-: | :-: |
| $(6,20)$ | $k_1/k_2 > 2$ | `0.977631137354 0.190235819672` | 5.1390 | $(6,20)$ | 9.6705 → `9.671` |
| $(9,14)$ | $1 < k_1/k_2 < 2$ | `0.626436771146 0.472537839745` | 1.3257 | $(9,14)$ | 12.2534 → `12.253` |
| $(10,13)$ | $k_1/k_2 < 1$ | `0.418883351791 0.221987861358` | 1.8870 | $(9,14)$ | 6.8778 → `6.878` |

三组询问的输出与题目给出的样例完全一致。

**边界与精度。**

- $k_1,k_2 > 0$ 保证最优解在凸链内部（不会被"无穷远方向"抢走），端点两个方向
  $(1,0)$、$(0,1)$ 也一定落在第一象限闭包内，枚举不会漏段；
- 相同 $(k_1,k_2)$ 下可能有多个最优生成树（共线的凸壳点、或同一 $(\sum u,\sum v)$ 的不同树），
  但**答案只取最小代价**，取到哪个点不影响输出；
- 代码里排序用整数方向、叉积用 $\texttt{\_\_int128}$（C++）/ 大整数（Python）精确计算；
  只在与 $k_1,k_2$ 相乘求最终值时才出现浮点。本包数据由 `data.py` 生成时已断言每个询问
  的真值距 $x.xxx5$ 四舍五入边界至少 $10^{-6}$（见下方"关于本包数据"），
  所以第三位小数唯一确定，`printf("%.3Lf")` 与 `f"{x:.3f}"` 都会给出正确结果。

**关于本包数据（如实说明）。** 目录里带有生成脚本 `data.py` 与参考实现 `std.cpp`：
十组数据是脚本自造的（`problem9` 规模 $N=35, M=25000, Q=200000$，凸壳 $H=159$；
`problem8` $H=50$；`problem10` $H=35$），题面来自网络重建，出题意图与官方原题可能有偏差。
`std.cpp` 与题面一致（已在 `problem1/2/8/9` 上实跑并与 `.out` 逐字节比对通过，

### 复杂度

设 $H$ 为左下凸壳的顶点数，本包数据中 $H \leqslant 159$。

- **枚举凸壳**：每次分治调用跑一遍 Kruskal（$O(M\log M)$）。分治每次产生一个新的凸壳点，
  而每次调用若不产生新点就立即返回，故调用次数 $O(H)$，总时间 $O(HM\log M)$。
- **查询**：单次在凸链上二分，$O(\log H)$，总共 $O(Q\log H)$。
- **空间**：存边 $O(M)$，并查集与凸壳 $O(N + H)$。

$N \leqslant 35, M \leqslant 25000, Q \leqslant 200000$ 下，最坏一组实测（`problem9`）：
C++ 约 $0.41$ s（限时 6000 ms、内存 128 MB，实测峰值 8.3 MB）；
Python 约 $2.7$ s，在 6000 ms 内也能过，但余量不如 C++ 充足。

## 总结

这道题的题眼是**把"生成树的代价"降维成二维平面上的点**：代价 $k_1 a + k_2 b$ 只和
$(\sum u, \sum v)$ 有关，于是 $Q$ 组询问变成了"在点集里找某个方向的最优投影"。

- 方向最优解只可能落在**左下凸壳**上（其余点被支配）；
- 凸壳不必枚举所有生成树，用「**取弦的法向当边权跑一次 MST**」这一个 oracle 做**分治**，
  就能把凸壳顶点全部补齐（QuickHull 思想）；
- 凸链上询问最优点满足**单峰性**，边界斜率随下标单调，一次二分就能定位。

这套"参数化 MST / 最小乘积生成树"的框架适用于一切"边权是若干个固定分量的线性组合、
多组询问求 MST"的题目：把 oracle 换成对应方向的 MST 即可，注意用整数方向与精确
叉积避免浮点判共线。

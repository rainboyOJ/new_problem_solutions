## 形式化题目

给定一个包含 $n$ 个整数的序列 $a_1, a_2, \dots, a_n$。
其中 $1 \le n \le 100$，且对于任意 $1 \le i \le n$，有 $a_i \le 1000$。由于没有明确的下界限制，$a_i$ 可能为负数或零。
需要求出这 $n$ 个数中的最小值、最大值和平均值（保留 $3$ 位小数）。
输入个数不定，以遇到 `EOF` 为准结束读入。

## 正解

### 思路

因为输入的整数个数 $n$ 并没有在输入开始时直接给定，我们需要使用「读取直到文件末尾（EOF）」的方式进行读入。

我们可以维护四个变量：
- `mn`：记录当前的最小值，初始化为一个足够大的值（如 `INT_MAX`）。
- `mx`：记录当前的最大值，初始化为一个足够小的值（如 `INT_MIN`）。
- `sum_all`：记录当前读入所有数字的总和，由于 $n \le 100, a_i \le 1000$，总和不超过 $10^5$，使用普通的整数类型即可，但为了防止未知数据范围导致的溢出，可以使用 64 位整数（`long long`）。
- `cnt`：记录读入的数字个数。

在不断读入数据的过程中，同步更新这四个变量。读入结束后，平均值即为 `1.0 * sum_all / cnt`，将总和乘上 `1.0` 使得运算变为浮点数除法，防止发生整数除法而丢失小数部分。

输出格式为用单个空格隔开的三个数，即 `最小 最大 平均`。

### 复杂度

- **时间复杂度**：$O(n)$。遍历一遍所有的输入数字，读取的代价为常数时间乘以数字个数。
- **空间复杂度**：$O(1)$ 或 $O(n)$。C++ 版本边读边处理，只维护固定的几个变量，空间复杂度为 $O(1)$；Python 版本通过 `split()` 一次性读入所有数据，空间复杂度为 $O(n)$。

## 总结

- **不定量输入与跨行**：在 C++ 中可以通过 `while (cin >> x)` 或 `while (scanf("%d", &x) == 1)` 读到 EOF。虽然题目提到“一行”，但实际读取应具备跨行、多余空格或缺尾换行符的容忍能力，而不能使用“只读一行（`getline`）”的做法（会导致跨行测试点出错）。
- **最值的初始化防御**：题目未说存在下界，所以千万不要去依赖非负（比如把求最大值的初始变量 `mx` 设为 `0`、`mn` 设为 `1001`）。实测发现，若采用依赖非负的错误初始化方案处理全负数据，必将得到错误的结论。初值必须安全使用如 `INT_MIN` / `INT_MAX`。
- **避免整数除法**：在计算平均数时要注意，必须将和或者个数先转换为浮点数类型（如 `1.0 * sum_all`）再相除，否则会导致小数部分被直接阶段截断（如测试输入 `1 2 3`，会被误算为 `1 3 0.000`）。
- **舍入行为**：
  - C++ `printf("%.3f")` 与 Python f-string 都是采用 IEEE binary64 的 **round-half-even（平局取偶）**，即平局（恰好 $x.xxx5$）时，向上还是向下取决于保留位的奇偶：
    - 举例：`0.0625 → 0.062`（保留位 2 为偶数，舍）
    - 举例：`0.1875 → 0.188`（保留位 7 为奇数，进）
  - 因此，两者默认行为已经**完全一致**。如果采用 `Decimal(精确值) + ROUND_HALF_UP` 手动做“四舍五入”反而会适得其反，在 8 万个平局测试点中会引入 50% 的判题不符（即 $0.0625$ 被判为 $0.063$）。
  - **全空间穷举 0 分歧**：实测在 $n \le 100, 0 \le S \le 1000n$ 的 5,050,100 组穷举以及十余万组随机 / 特殊数据测试中，两者输出结果无一分歧，证明无需进行任何手动兼容层处理。
- **测试数据的鉴别力**：对于测试数据而言，能够排除“直接截断”（即区分出它是经过舍入还是截断）的只有唯一的一个平局点（如点 8 的 $495.2666\ldots$ 能够判定，因为截断得到 $495.266$，正确舍入得到 $495.267$）。但由于数据中只存在一个使得第 4 位小数恰好为 $5$ 的平分点（点 6 的 $0.1875$），在这个点上 `half-up` 和 `half-even` 得到的都是 `0.188`，因此这些测试数据无法鉴别 `half-up` / `half-even` 两种不同的舍入模式。
- **代码无关字面量**：代码 `main.cpp` 除了判断 `cnt == 0` 外没有引入任何额外的字面常量，算法不存在对特定测试数据的硬编码。

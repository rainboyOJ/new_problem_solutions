## 形式化题目

$n$ 只梦魔排成一列，梦魔 $i$ 防御力为 $a_i$，击杀后攻击力增加 $b_i$。初始攻击力为 $x$，从间隙 $p$（第 $p$ 与第 $p+1$ 只之间）开始，每次只能击杀当前最左端或最右端的梦魔，且当前攻击力必须不小于其防御力。

对每个 $p = 1 \dots n-1$，求能击杀全部梦魔所需的最小初始攻击力 $f(p)$，输出所有 $f(p)$ 的异或和。每次修改都从初始数组重新开始。

## 思路

先看直接做法：固定落点后，每次递归选择击杀左端或右端，返回所需的最小初始攻击力。

每个间隙都要枚举两端的所有击杀顺序，只适合小数据验证。

### 固定落点的贪心

固定间隙 $p$ 后，左侧梦魔只能按 $p, p-1, \dots, 1$ 的顺序出现，右侧只能按 $p+1, p+2, \dots, n$ 的顺序出现，任意时刻只有左右两个端点可选。

若两端防御力满足 $x \le y$，优先击杀 $x$ 不会变差：设某方案先击杀右端 $y$ 后再击杀左端 $x$，把它改成先击杀 $x$，再按原顺序击杀右侧那些梦魔，$x$ 的防御力不超过第一个右端点且提前获得 $b_x$，每一步攻击力都不更低，方案依然可行。

于是贪心策略确定：**始终优先击杀防御力较小的端点**。问题变成在贪心过程中，每一步对初始攻击力提出什么下界。

### 一个梦魔产生两个区间限制

用单调栈求每个位置两侧“最近的不小于自己”的边界：

$$L[j] = j \text{ 左侧最近的 } a[L[j]] \ge a[j] \text{ 的位置，不存在时为 } 0;$$
$$R[j] = j \text{ 右侧最近的 } a[R[j]] \ge a[j] \text{ 的位置，不存在时为 } n+1。$$

求 $L$、$R$ 时单调栈只能弹出严格更小的防御力，相等的必须保留。

若 $j$ 位于落点右侧（$p < j$），当 $L[j] \le p \le j-1$ 时，$j$ 左侧直到 $L[j]$ 之间的梦魔防御力都严格小于 $a_j$，贪心会先击杀它们，$j$ 才成为关键端点，因此产生限制：

$$\text{落点区间 } [\max(1, L[j]),\ j-1], \qquad \text{限制值 } a_j - (\text{prefix}_b[j-1] - \text{prefix}_b[L[j]])。$$

若 $j$ 位于落点左侧（$p \ge j$），对称地得到：

$$\text{落点区间 } [j,\ \min(n-1, R[j]-1)], \qquad \text{限制值 } a_j - (\text{prefix}_b[R[j]-1] - \text{prefix}_b[j])。$$

其中 $\text{prefix}_b[t]$ 是 $b_1 + \dots + b_t$。区间里每个 $p$ 都必须满足该限制，所以 $f(p)$ 是覆盖它的所有候选限制值的最大值。

### 嵌套区间扫描

这些候选区间不会交叉：任意两个区间要么相离、相等，要么一个包含另一个（否则交叉部分会同时违反“最近不小于自己”的定义）。把区间按 $(\text{left 升序}, \text{right 降序})$ 排序，扫描 $p = 1 \dots n-1$ 时，已经开始但尚未结束的区间正好形成一条嵌套链：

```text
外层区间 [1, 8]
    内层区间 [3, 6]
        更内层区间 [4, 5]
```

用栈维护这条链：进入新区间时，栈节点保存“从栈底到该节点的限制值最大值”；区间右端点小于当前 $p$ 时弹出。栈顶最大值就是当前 $f(p)$。

区间端点都在 $1 \dots n-1$ 内，用两次计数排序代替比较排序，整个询问只需 $O(n)$。

## 复杂度

- 时间：每次询问复制初始数组并应用 $k$ 个修改后，完成前缀和、两次单调栈、候选区间生成、两次计数排序与区间栈扫描，$O(n + k)$。
- 空间：$O(n)$。

## 总结

核心是把“左右端点交替击杀”转化为贪心过程。一个梦魔只有在两侧更小防御力都被清掉后才成为关键端点，于是它的限制自然对应一个落点区间；最近的不小于自身元素给出区间边界。所有区间具有嵌套结构，最后用栈维护区间最大值即可。

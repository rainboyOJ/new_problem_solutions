### 题意

有 `n` 只梦魔排成一列，梦魔 `i` 的防御力为 `a[i]`，击杀后攻击力增加 `b[i]`。
小 C 降落在一个间隙 `p`，也就是第 `p` 只和第 `p+1` 只梦魔之间。每次只能击杀当前最左端或最右端的梦魔；若当前攻击力不小于它的防御力，就能将其击杀。

对每个 `p=1..n-1`，求能击杀全部梦魔所需的最小初始攻击力 `p[p]`，并输出所有 `p[p]` 的异或和。每次修改都从初始数组重新开始，不继承上一次修改。

`n` 最大为 `2*10^6`，所有修改数量之和不超过 `5*10^5`，所以每次询问需要接近线性的算法。

### 思路

先看小数据暴力：固定落点后，每次递归选择击杀左端或右端，返回从当前攻击力出发所需的最小攻击力。

#### 1. 固定落点的贪心

固定间隙 `p` 后，左侧梦魔只能按 `p,p-1,...,1` 的顺序出现，右侧梦魔只能按 `p+1,p+2,...,n` 的顺序出现。因此任意时刻只有左右两个端点可以选择。

如果两个端点的防御力分别为 `x<=y`，优先击杀 `x` 不会变差。设某个可行方案先击杀右端点 `y`，再经过若干次操作才击杀左端点 `x`。把这段操作改成先击杀 `x`，再按原顺序击杀右侧的那些梦魔：`x` 的防御力不超过第一个右端点，且提前得到 `b[x]`，所以每一步的攻击力都不会更低；之后回到同一个剩余状态，方案仍然可行。

所以可以始终优先击杀防御力较小的端点。问题变成：在这条贪心过程中，每一步对初始攻击力提出了什么下界？

#### 2. 一个梦魔对应的两个区间限制

定义：

```text
L[j] = j 左侧最近的 a[L[j]] >= a[j] 的位置，不存在时为 0
R[j] = j 右侧最近的 a[R[j]] >= a[j] 的位置，不存在时为 n+1
```

单调栈求 `L` 和 `R` 时只能弹出严格更小的防御力，防御力相等的位置必须保留。

若 `j` 位于落点右侧，即 `p<j`，当 `p` 满足 `L[j] <= p <= j-1` 时，`j` 两侧、位于 `L[j]` 和 `j` 之间的梦魔防御力都严格小于 `a[j]`。贪心会先击杀它们，直到 `j` 与 `L[j]`（或左侧边界）相遇。因此 `j` 产生限制：

```text
落点区间 [max(1,L[j]), j-1]
限制值 a[j] - (prefix_b[j-1] - prefix_b[L[j]])
```

若 `j` 位于落点左侧，即 `p>=j`，对称地得到：

```text
落点区间 [j, min(n-1,R[j]-1)]
限制值 a[j] - (prefix_b[R[j]-1] - prefix_b[j])
```

其中 `prefix_b[t]` 是 `b[1..t]` 的和。区间里的每个 `p` 都必须满足这个限制，故 `p[p]` 是覆盖它的所有候选限制值的最大值。

#### 3. 嵌套区间扫描

上述候选区间不会交叉：任意两个区间只能相离、相等或一个包含另一个。否则交叉部分会同时违反某个位置是“最近的防御力不小于当前值”的定义。

把区间按 `(left 升序, right 降序)` 排序。扫描 `p=1..n-1` 时，已经开始但尚未结束的区间正好是一条嵌套链：

```text
外层区间 [1, 8]
    内层区间 [3, 6]
        更内层区间 [4, 5]
```

用栈维护这条链。进入一个新区间时，栈节点保存“从栈底到该节点的限制值最大值”；当区间右端点小于当前 `p` 时从栈顶弹出。栈顶的最大值就是当前 `p[p]`。

区间左右端点都在 `1..n-1`，因此用两次计数排序代替比较排序，整个询问只需 `O(n)` 时间。

### 复杂度

每次询问复制初始数组并处理 `k` 个修改，然后完成前缀和、两次单调栈、候选区间生成、两次计数排序和区间栈扫描，时间复杂度为 `O(n+k)`，空间复杂度为 `O(n)`。

### 总结

本题的核心是把“左右端点交替击杀”转化为贪心过程。一个梦魔只有在它两侧的更小防御力都被清掉后才会成为关键端点，于是它的限制自然对应一个落点区间；最近的更大等值元素给出了区间边界。所有区间具有嵌套结构，最后用栈维护区间最大值即可。

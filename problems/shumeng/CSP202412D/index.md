## 形式化题目

站在格子 $i$ 时，可以跳到区间 $[i+1, \min(n, i+k_i)]$ 中的任意落点 $j$；落到 $j$ 后立即后退 $a_j$ 格，下一次实际站在 $j - a_j$。

求从格子 $1$ 跳到格子 $n$ 的最少跳跃次数，不可达输出 $-1$。

## 思路

把每个状态 $i$ 到落点 $j$ 的跳跃看成转移 $i \to j - a_j$，问题就是一个 BFS 最短路。难点在于避免重复扫描同一段区间内的落点。

同一落点 $j$ 可能被许多状态的跳跃区间重复覆盖，最坏 $O(n^2)$。

### 关键观察：落点只需处理一次

BFS 按距离从小到大出队。对于某个落点 $j$，第一次有状态的跳跃区间覆盖它时，已经用到了能到达该状态的最小跳数；之后从更晚出队的状态使用同一个 $j$ 不可能得到更短路径。因此每个落点只处理一次即可。

### 用并查集跳过已处理的落点

维护一个并查集表示“下一个还未处理的落点”：

- `find(x)` 返回不小于 $x$ 的最小未删除下标；
- 处理完落点 $j$ 后删除它，令它指向 `find(j+1)`；
- 处理状态 $i$ 时，从 `find(i+1)` 开始逐个处理，直到超过 $\min(n, i + k_i)$。

处理落点 $j$ 时令 $v = j - a_j$；若 $v$ 未访问则入队并记录距离。注意删除的是**落点下标**而不是状态下标，所以多个落点后退到同一个状态也不会出错。

### 样例推演

下表记录样例一的 BFS 过程，落点只在第一次被扫描时出现：

| 出队状态 | 跳数 | 本次处理的落点及转移 | 新入队状态 |
| ---: | ---: | --- | --- |
| 1 | 0 | `2 -> 1`，`3 -> 2` | `2` |
| 2 | 1 | `4 -> 3`，`5 -> 4`，`6 -> 3` | `3, 4` |
| 3 | 2 | `7 -> 6`，`8 -> 8` | `6, 8` |
| 4 | 2 | 无（落点已删除） | 无 |
| 6 | 3 | `9 -> 6`，`10 -> 10` | `10` |

状态 `10` 首次以距离 $4$ 入队，答案为 $4$。状态 `8` 后续即使再覆盖部分落点，也不会改变已经得到的答案。

## 复杂度

- 时间：每个落点只被删除一次，并查集 `find` 均摊近常数，总复杂度 $O(n \alpha(n))$。
- 空间：$O(n)$。

## 总结

区间转移题的难点不是 BFS 本身，而是避免重复扫描区间内的落点。BFS 提供“第一次覆盖落点时距离最优”的顺序保证，并查集把所有已处理落点跳过，从而把大量区间枚举压缩成一次近线性的删除过程。

## 图示解析

这张流程图概括每个 BFS 状态的处理方式：

```text
出队状态 i
|- 确定落点区间 [i+1, min(n, i+k_i)]
   `- 并查集找到区间内尚未处理的 j
      |- 删除 j，转移到 j-a[j]
      `- 未访问状态入队
```

落点 $j$ 被处理后不会再次参与后续区间扫描。因为 BFS 出队距离单调不减，后面状态通过同一落点得到的路径不可能更短。

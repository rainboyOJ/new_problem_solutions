## 形式化题目

把内存看作从地址 $0$ 开始、容量足够大的连续空间，初始全部空闲。依次处理 $q$ 个操作：

- `new p L`：为进程 $p$ 新建编号递增的接口与队列，按 best-fit 原则分配一段长度为 $L$ 的内存，输出分配区间的左端点 $a$；
- `send p`：进程 $p$ 向它对接的所有接口各发送一个对象，对象在各自队列内按 $a\to b\to a\to\cdots$ 循环存放，输出本次所有写入地址之和；
- `delete p i`：删除进程 $p$ 的第 $i$ 个接口，释放其内存区间，其余编号大于 $i$ 的接口编号依次减一。

## 思路

### 空闲区间的两种视角

分配需要“长度最短且靠左”的区间，释放需要“按地址合并相邻区间”，两者排序依据不同，因此用两个有序结构同时维护空闲区间：

- `free_by_left`（`map<左端点, 右端点>`）：支持按地址找到相邻区间并合并；
- `free_by_size`（`set<(长度, 左端点)>`）：用 `lower_bound` 直接找到长度至少为 $L$ 的最短区间。

```text
分配:  set 找 best-fit 区间 -> map 取区间 -> 左端取 L 个地址 -> 剩余放回
释放:  加入 [a,b] -> 与左右相邻空闲区间合并 -> 两个结构同步更新
```

### 队列的循环写入

每个接口只需记住区间端点 `[a,b]` 和最近一次写入位置 `last`。发送时如果 `last` 还是初始值或已经到 `b`，就写回 `a`；否则 `last+1`。

### 删除操作

释放内存区间后调用区间合并，同时从进程的接口列表中删掉对应项即可，编号自动前移的效果由 `vector::erase` 天然完成。

## 复杂度

- 时间：`new` 和 `delete` 每次进行常数次 $O(\log q)$ 级有序结构操作；`send` 需要遍历该进程的全部接口。总时间复杂度为 $O((q+n)\log q+\text{总发送接口数})$。
- 空间：空闲区间与接口总数均为 $O(q)$，空间复杂度 $O(q)$。

## 总结

同时需要“按地址合并”和“按长度选择”的结构，分别维护两种排序键可以让两个操作都保持对数复杂度。同步删除/插入时注意 `map` 与 `set` 必须保持一致，否则后续操作会读到错误区间。

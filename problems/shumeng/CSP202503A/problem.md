**时间限制：** 1.0 秒

**空间限制：** 512 MB


## 题目描述

在了解了数值积分的基本原理后，小 P 打算用如下方法估算二次函数在 $[l, r]$ 区间的积分：

1. 给定二次函数 $f(x) = x^2 + bx + c$，其中两个系数 $b$ 和 $c$ 均为整数；

2. 对于给定区间 $[l, r]$（$l$ 和 $r$ 均为整数），选取闭区间内所有**偶数**坐标点：

$$
l \le x, \ x+2, \ x+4, \ \cdots \le r
$$

3. 分别计算每个坐标点的函数值并求和，再乘以坐标点间距 $2$，即计算：

$$
s = 2 \times (f(x) + f(x+2) + f(x+4) + \cdots)
$$

$s$ 即为小 P 估算的积分结果。

试帮助小 P 编程实现上述计算过程：对于任意给定的系数 $b,c$ 和区间 $l,r$，计算并输出 $s$。

## 输入格式

从标准输入读入数据。

输入仅一行，包含四个整数 $b,c,l,r$，含义如前文所述。

## 输出格式

输出到标准输出。

输出一个整数 $s$，表示小 P 估算的积分结果。

```input1
1 2 0 5
```

```output1
64
```

```input2
-20 -20 1 1000
```

```output2
324294000
```

## 子任务

全部测试数据保证 $0 \le l < l+2 \le r \le 1000,~-20 \le b, c \le 20$。

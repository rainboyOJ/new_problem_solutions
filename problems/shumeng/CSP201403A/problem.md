**时间限制：** 1.0 秒

**空间限制：** 256 MB

## 题目描述

有 $N$ 个非零且各不相同的整数。请你编一个程序求出它们中有多少对相反数（$a$ 和 $-a$ 为一对相反数）。

## 输入格式

从标准输入读入数据。

第一行包含一个正整数 $N$。

第二行为 $N$ 个用单个空格隔开的非零整数。

## 输出格式

输出到标准输出。

只输出一个整数，即这 $N$ 个数中包含多少对相反数。

```input1
5
1 2 3 -1 -2
```

```output1
2
```

## 数据范围

对于所有数据，保证 $1 \le N \le 500$，每个数的绝对值不超过 $1000$，保证这些整数各不相同。

# ch0101-01 Hello, World!

## 题目描述

对于大部分编程语言来说，能够输出“Hello, World!”的程序往往最基本、最简单。它常作为初学者接触一门语言时编写的第一个程序，也用于测试开发和编译环境能否正常工作。

现在请完成这样一个程序。

## 输入格式

无。

## 输出格式

输出一行，且这一行只包含：

```text
Hello, World!
```

使用英文标点，逗号后必须有一个半角空格。

## 输入输出样例

### 输入

```text
（无）
```

### 输出

```text
Hello, World!
```

## 限制

- 时间限制：1000ms
- 内存限制：128MB

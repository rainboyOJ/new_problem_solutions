# english-09 Least Common Multiple

<!-- generated from noiopenjudge local cache -->

## 描述


Given A and B. Find the least positive M which is a common multiple of both A and B.

## 输入


Two positive integers A and B (A,B <= 10000).

## 输出


One integer M.

## 样例输入


```
8 12
```


## 样例输出


```
24
```

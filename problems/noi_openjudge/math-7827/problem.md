# math-7827 质数的和与积

<!-- generated from noiopenjudge local cache -->

## 描述


两个质数的和是S，它们的积最大是多少？

## 输入


一个不大于10000的正整数S，为两个质数的和。

## 输出


一个整数，为两个质数的最大乘积。数据保证有解。

## 样例输入


```
50
```


## 样例输出


```
589
```

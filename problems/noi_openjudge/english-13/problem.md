# english-13 Same Remainder

<!-- generated from noiopenjudge local cache -->

## 描述


Given A and B. Find the smallest X that X is greater than 1 and A modulo X equals to B modulo X.

## 输入


Two positive integers A and B (A,B <= 10000).

## 输出


One integer X.

## 样例输入


```
17 26
```


## 样例输出


```
3
```

- 时间限制：1000ms
- 内存限制：128MB

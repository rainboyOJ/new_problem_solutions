# 复习卡字段与设计取舍

本文件记录卡片契约的取值来源与当初的决策理由，改版前先读这里，避免把已经否掉的方案重新提出来。

## 1. 字段表

| 卡面位置 | 字段（cards.json） | 来源 | 缺失时 |
| --- | --- | --- | --- |
| 卡头主标题 | `title` | `index.md` frontmatter `title`；无则题面首行 | 用 `oj id` |
| 卡头小字 | `difficulty` + `tags` | frontmatter；`tags` 过滤掉语言标签和与难度同名的标签 | 难度 `未知`，tag 省略 |
| 卡头右上 | `sid` = `oj#id`；难度方块 `dots` | `DIFFICULTY_DOTS` 映射洛谷档位 → 1–5 方块 | 0 格 |
| 卡体题意 | `statement.description` / `statement_note` | `problem.md` 正文 → `index.md`「题目描述」→ 截图 | — |
| 卡体输入 | `statement.input` | `problem.md` 的「输入格式/输入」小节，原文 | 省略整行 |
| 卡体输出 | `statement.output` | 同上「输出格式/输出」 | 省略整行 |
| 卡体样例 | `statement.samples[]` | `样例 N 输入/输出`、`输入 #N` / `输出 #N` 等标题配对 | 无样例则只有题意 |
| 卡体数据范围 | `statement.constraints` | 「数据范围/提示/说明/约定」小节，原文 | 省略整行 |
| 卡体图片 | `statement.images[]` | `problem.md` 的 `![]()` 与 `<img>/<video>` | — |
| 卡尾做法 | `solution.approach` | `index.md` 的 `正解/思路/题目解析/解法/分析` 首段 | 印「待补」 |
| 卡尾标记 | `solution.approach_note` | 人工填 `据参考代码反推` | 不印 |
| 卡尾复杂度 | `solution.complexity` | `index.md` 的 `复杂度` 小节，或正文里的 `O(...)` | 不印 |
| 卡尾考察 | `solution.points` | `tags` 或题解 | 不印 |
| 卡尾典型坑 | `solution.pitfall` | 人工填写，材料不足留空 | 印「待补」 |
| 卡底记录 | 固定印版 | — | — |
| 索引页 | `url` | frontmatter `source`；无则按 `URL_TEMPLATES` 拼 | 空串（仍打印行） |

`body.summary` 是 agent 的压缩题意，非空时覆盖 `statement.description`。`statement_note` 是脚本写的来源说明（截图/整理版），不要手改。

## 2. 已冻结的取舍

**复习卡，不是训练卷。** 卡片密排、含做法；不做留白写代码。因此卡底保留「掌握度 + 用时/得分/日期」一行，供首次实战后手写记录，而不是当成当场的答题卡。

**结构化保留题面，不做整篇摘要。** `输入格式/输出格式/样例/数据范围` 是判 AC 的唯一依据，必须原文；只压背景与叙述。超长时的裁剪顺序固定为：砍背景 → 砍叙述细节 → 样例从多到少（下限 1 组）→ 仍超预算才升为整页卡。

**做法与典型坑分开取材。** 做法可以从参考代码反推（代码本身就是做法），但必须打 `据参考代码反推` 标记；考察点与典型坑只取有材料的，宁可「待补」也不编。

**自适应版面。** 短题一面 2 张（131 mm 固定高，剩余空间直接留白）；长题一面 1 张且允许跨页。判定用估算行数，误判时用 `layout` + `layout_locked` 人工钉死。

**回连靠索引页。** 卡底只印 `oj#id` 短标识，完整 URL 集中在前置索引页 —— 卡面不被长链接挤占，也避免了 typst 无内置二维码的依赖问题。

**纯黑白。** 难度用方块填充数（`■■□□□`）而不是颜色，省墨打印和黑白复印都不丢信息。字体：宋体正文、黑体标题、等宽样例（等宽需带 CJK 回退容错）。

**输入方式只服务 agent。** 不维护人类 CLI 体验；参数形态以方便 agent 拼命令为准（`oj/id`、URL 混写）。

## 3. 已知限制

- 折算行数是启发式，长样例/宽表格会低估；靠人工看 `layout.json` 兜底。
- `index.md` 的「题目描述」是二手整理文本，用于补截图题时会在卡体注明来源。
- 图片题最多嵌 2 张截图，整页大截图会有大量留白；此类题更该补 `body.summary`。
- 卡片不做双栏、不做裁切线；2-up 两卡之间是 5 mm 间隙，直接整张 A4 打印。

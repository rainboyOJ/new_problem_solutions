  11| ### 题意
  12| 
  13| $m \times n$ 迷宫，1 可走 0 不可走。给定起点和终点，找出**所有**可行道路，要求：
  14| 
  15| - 路径中不能重复经过同一个点；
  16| - 只能上下左右四个方向；
  17| - 优先顺序：**上、左、右、下**；
  18| - 每条路径一行，用 `(x,y)->(x,y)->...` 输出；无路输出 $-1$。
  19| 
  20| 数据范围：$1 < m, n < 15$，数据随机生成。
  21| 
  22| ### 思路
  23| 
  24| 最直接的想法是枚举所有路径：
  25| 
  26| @include-code(./brute.cpp, cpp)
  27| 
  28| **关键点**：题目要输出**所有**路径，所以不能用 BFS（BFS 只找一条最短路径），必须用 DFS 回溯——每到达终点就输出当前路径，然后返回继续尝试其他分支。
  29| 
  30| DFS 结构：
  31| 
  32| ```text
  33| dfs(x, y)：当前在 (x, y)
  34|   ├─ 到达终点 → 输出 path_x[0..path_len-1]
  35|   └─ 按 上、左、右、下 顺序尝试四个方向
  36|        ├─ 出界 / 是墙 / 已访问 → 跳过
  37|        └─ 标记访问 → 记录路径 → dfs(nx, ny) → 回溯撤销
  38| ```
  39| 
  40| **方向顺序为什么重要**：题目要求按"上左下右"优先顺序输出路径。方向数组 `dx = {-1, 0, 0, 1}, dy = {0, -1, 1, 0}` 严格对应这个顺序，DFS 按这个顺序尝试，输出自然就是题目要求的顺序。
  41| 
  42| 以样例第一条路径为例，从 $(1,1)$ 出发：上、左出界，右 $(1,2)$ 是 0 不可走，只能下到 $(2,1)$，这正是样例输出的第一条：
  43| 
  44| ```text
  45| (1,1)->(2,1)->(2,2)->...->(5,6)
  46| ```

   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给出一个无向图，要求统计长度恰好为 `3` 的有向转发路径数量：
  14| 
  15| `a -> b -> c -> d`
  16| 
  17| 其中源点和终点可以相同，但两个中间点要和两端区分开。
  18| 
  19| ### 思路
  20| 
  21| 最直接的办法是暴力枚举四元组 `(a, b, c, d)`。
  22| 
  23| 先看一个可以直接验证想法的朴素解：
  24| 
  25| @include-code(./brute.cpp, cpp)
  26| 
  27| `brute.cpp` 会直接检查三条边是否存在，并判断中间点是否合法，适合小图对拍。
  28| 
  29| 真正的关键是固定中间那条有向边。对于一条合法路径：
  30| 
  31| `a -> b -> c -> d`
  32| 
  33| 中间边唯一就是 `b -> c`。一旦这条边方向固定：
  34| 
  35| - 左端 `a` 只能从 `b` 的其他邻居里选
  36| - 右端 `d` 只能从 `c` 的其他邻居里选
  37| 
  38| 这张图展示第二个样例里的小图结构：
  39| 
  40| ```dot
  41| graph G {
  42|   1 -- 2;
  43|   2 -- 3;
  44|   3 -- 1;
  45|   1 -- 4;
  46| }
  47| ```
  48| 
  49| 从这张图里可以看到，如果把 `1 -> 2` 当作中间边，那么左端只能从 `1` 的其余邻居 `{3,4}` 里选，右端只能从 `2` 的其余邻居 `{3}` 里选，所以这一条有向中间边贡献 `2 * 1 = 2` 条路径。其他边完全同理。
  50| 
  51| 于是对每条无向边 `(u, v)`：
  52| 
  53| - 把它看成中间有向边 `u -> v`，贡献是 `(deg[u] - 1) * (deg[v] - 1)`
  54| - 反过来 `v -> u` 再算一次
  55| 
  56| 把所有边贡献加起来就是答案。

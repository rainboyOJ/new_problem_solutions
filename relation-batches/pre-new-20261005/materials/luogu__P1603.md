   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给出一句英文句子。先找出其中所有表示数字的单词，把每个数字平方后对 `100` 取模，得到若干个两位数。然后重新排列这些两位数，拼出尽可能小的密码。
  14| 
  15| ### 思路
  16| 
  17| 先用字典保存单词到数字的映射。每遇到一个合法数字单词，就计算：
  18| 
  19| ```text
  20| value * value % 100
  21| ```
  22| 
  23| 题目要求把结果当作两位数，例如 `1` 要看成 `01`，`4` 要看成 `04`。在 Python 中可以写成：
  24| 
  25| ```python
  26| f"{x:02d}"
  27| ```
  28| 
  29| 因为每一段长度都固定为两位，想让拼接后的整体最小，只需要把这些两位字符串升序排序，再拼起来。最后把整体前导零删除；如果删完为空，就输出 `0`。
  30| 
  31| 这题不需要枚举排列，排序就是正解。历史目录中保留 C++ 暴力文件，本文不创建 `brute.py`。

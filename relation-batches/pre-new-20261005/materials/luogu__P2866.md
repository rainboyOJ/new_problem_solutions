  13| ### 题意
  14| 
  15| 每头牛能看到右侧连续比自己矮的牛，直到遇到第一头不矮于自己的牛。求所有可见数量之和。
  16| 
  17| ### 思路
  18| 
  19| 从左到右加入当前牛。栈中保存还没有被更高或等高牛挡住的历史高度，并保持严格递减。
  20| 
  21| 当前高度到来时，先弹出所有 `<= current` 的栈顶：这些牛会被当前牛挡住，也不能看到当前牛。剩余栈里的每头牛都比当前牛高且中间没有遮挡，因此答案增加 `len(stack)`，再压入当前高度。
  22| 
  23| ### Python 知识
  24| 
  25| - Python 列表尾部 `append/pop` 就是高效栈。
  26| - 只保存高度，不需要保存下标或完整序列。
  27| - `answer += len(stack)` 一次统计所有能看到当前牛的历史牛。

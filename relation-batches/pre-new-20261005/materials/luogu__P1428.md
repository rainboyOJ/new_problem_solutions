   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给出从左到右 `n` 条小鱼的可爱程度。每条小鱼只能看到自己左边的小鱼，要求输出每条小鱼左边有多少条小鱼的可爱程度严格小于它。
  14| 
  15| 注意相等不算“不如自己可爱”。
  16| 
  17| ### 思路
  18| 
  19| 数据范围只有 `n <= 100`，可以直接按定义做双重循环。
  20| 
  21| 对第 `i` 条小鱼，枚举所有 `j < i` 的小鱼。如果：
  22| 
  23| ```text
  24| a[j] < a[i]
  25| ```
  26| 
  27| 就把计数加一。把每个位置的计数放入 `answer`，最后一行输出。
  28| 
  29| 从教学视角看，也可以先生成候选对，再过滤计数：
  30| 
  31| ```python
  32| # 先生成再 filter（教学视角）
  33| answer = []
  34| for i in range(n):
  35|     pairs = [(i, j) for j in range(i)]
  36|     answer.append(sum(1 for _, j in pairs if a[j] < a[i]))
  37| ```
  38| 
  39| 含义是：
  40| 
  41| 1. 对每个 `i`，先生成所有左边下标对 `(i, j)`，其中 `j < i`；
  42| 2. 再 `filter` 出 `a[j] < a[i]` 的对；
  43| 3. 用 `sum` / `len` 得到答案。
  44| 
  45| 实战中通常直接双重循环边枚举边计数，不必真的建 `pairs` 列表；`n <= 100` 两种写法都可以。
  46| 
  47| 这题是数组枚举入门，正解就是直接实现定义，不创建 `brute.py`。

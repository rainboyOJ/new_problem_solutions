   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 有一张连通无向图，每个点代表一个城镇，每个城镇里正好有一个居民。
  14| 
  15| 原本一共应该发生：
  16| 
  17| - `n * (n - 1)` 次访问
  18| 
  19| 因为每个人都想访问其他所有人一次。
  20| 
  21| 现在如果封锁某个城镇 `u`，就会导致：
  22| 
  23| - 任何和 `u` 有关的访问都不可能发生
  24| - 删掉 `u` 以后，如果图被分成多个连通块，不同连通块之间的人也无法互相访问
  25| 
  26| 题目要求对每个点 `u` 输出：
  27| 
  28| - 如果封锁 `u`，最终有多少次访问无法进行
  29| 
  30| #### 样例图
  31| 
  32| 样例图长这样：
  33| 
  34| ```dot
  35| graph G {
  36|   1 -- 2;
  37|   1 -- 3;
  38|   2 -- 3;
  39|   3 -- 4;
  40|   4 -- 5;
  41| }
  42| ```
  43| 
  44| 从图上就能看出：
  45| 
  46| - 点 `3` 和点 `4` 是关键位置
  47| - 封锁 `3` 时，图会裂成 `{1,2}` 和 `{4,5}`
  48| - 封锁 `4` 时，图会裂成 `{1,2,3}` 和 `{5}`
  49| 
  50| 所以这两个点的答案会比普通点更大。
  51| 
  52| ### 思路
  53| 
  54| 先看一个最直接的暴力：
  55| 
  56| @include-code(./brute.cpp, cpp)
  57| 
  58| 暴力做法是：
  59| 
  60| 1. 枚举封锁哪个点 `u`
  61| 2. 真的把 `u` 删掉
  62| 3. 重新数删点后的每个连通块大小
  63| 4. 统计不同连通块之间一共有多少对访问作废
  64| 
  65| 这个方法容易理解，但每个点都重跑一遍 DFS，复杂度太高。
  66| 
  67| 正式做法的关键是把答案拆成两部分：
  68| 
  69| 1. 所有和 `u` 直接有关的访问  
  70|    这部分固定是 `2 * (n - 1)`  
  71|    因为别人去 `u`、以及 `u` 去别人，这两类访问都作废。
  72| 
  73| 2. 删掉 `u` 以后，不同连通块之间的访问  
  74|    这部分只有当 `u` 是割点时才会额外出现。
  75| 
  76| 所以问题就变成：
  77| 
  78| - 删掉点 `u` 后，会分出哪些连通块？它们大小是多少？
  79| 
  80| 这正是 Tarjan 割点里 `low[v] >= dfn[u]` 的含义。
  81| 
  82| 如果 `u` 有一个儿子 `v` 满足：
  83| 
  84| `low[v] >= dfn[u]`
  85| 
  86| 说明删掉 `u` 以后，`v` 这棵子树会单独裂成一个连通块，大小就是 `sub_size[v]`。
  87| 
  88| 于是我们在 DFS 回溯时，把每个这样的“被切下来的块”依次拿出来计数即可。
  89| 
  90| 设这些块的大小依次是：
  91| 
  92| - `c1, c2, ..., ck`
  93| 
  94| 那么它们和“前面已经切出来的点”之间会新增：
  95| 
  96| - `2 * c_i * (前面所有块大小之和)`
  97| 
  98| 次作废访问。
  99| 
 100| 最后还要补上一个“剩余大块”：
 101| 
 102| - 它的大小是 `n - 1 - (c1 + c2 + ... + ck)`
 103| 
 104| 这块和前面所有被切下来的块之间，也会产生同样的双向损失。
 105| 
 106| 所以整道题其实就是：
 107| 
 108| - Tarjan 求割点
 109| - 同时维护每棵子树大小
 110| - 在回溯时用这些大小直接算贡献

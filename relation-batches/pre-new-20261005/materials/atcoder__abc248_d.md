  11| ## 题目解析 
  12| 
  13| ### 1 核心解题思路
  14| 
  15| 题目要求查询在原数组  $A$  的区间  $\left[L,R\right]$  内，数值  $X$  出现了多少次。
  16| 
  17| 我的代码将原问题转化为了**二维点查找**问题的一个变种，具体步骤如下：
  18| 
  19| 1.  **数据重组**：将原数组的每个元素转化成二元组 `(数值, 原下标)`。
  20| 2.  **全局排序**：将这些二元组按照 **数值第一关键字**、**原下标第二关键字** 进行升序排序。
  21|     *   排序后，所有数值为  $X$  的元素会聚在一起，形成一个连续的块。
  22|     *   在这个块内部，元素的“原下标”是有序的。
  23| 3.  **四次二分查找**：
  24|     *   先通过数值  $X$ ，找到它在排序后数组中的**起始位置**和**结束位置**（划定数值范围）。
  25|     *   在上述范围内，再通过原下标  $L$  和  $R$ ，找到符合条件的元素个数（划定下标范围）。
  26| 
  27| ### 2 代码详细拆解
  28| 
  29| #### A. 数据结构与预处理 (Init)
  30| 
  31| ```
  32| struct node {
  33|     int val; // 数值
  34|     int pos; // 原数组中的下标
  35| } a[maxn];
  36| 
  37| bool compare(node & a ,node &b) {
  38|     if( a.val == b.val) {
  39|         return a.pos < b.pos; // 数值相同，按下标排序
  40|     }
  41|     return a.val < b.val;     // 否则按数值排序
  42| }
  43| ```
  44| 
  45| *   **作用**：这不仅让相同的  $X$  靠在一起，还保证了它们内部是按下标递增的。这就为后续对 `pos` 进行二分查找创造了单调性条件。
  46| 
  47| #### B. 手写二分查找函数
  48| 
  49| 代码中手写了两个 `lower_bound` / `upper_bound` 风格的函数。
  50| 
  51| 1.  **`bs_find_g(l, r, val)`**:
  52|     *   **功能**：在排序后的数组中，寻找**第一个** `val` 大于传入参数 `val` 的位置。
  53|     *   **用途**：用来确定数值  $X$  在数组 `a` 中的左右边界。
  54| 2.  **`bs_find_pos(l, r, pos)`**:
  55|     *   **功能**：在指定的区间 `[l, r)` 内（此时该区间内所有元素的 `val` 都相同），寻找**第一个** `pos` 大于传入参数 `pos` 的位置。
  56|     *   **用途**：在数值已经确定为  $X$  的范围内，筛选出原下标在  $\left[L,R\right]$  之间的元素。
  57| 
  58| #### C. 查询逻辑 (Query Processing)
  59| 
  60| 这是代码中最精彩的部分，对于每个查询  $L,R,X$ ：
  61| 
  62| ```
  63| // 1. 确定数值 X 的“地盘”
  64| // 找到第一个 val >= x 的位置 (等同于寻找 > x-1 的位置)
  65| int L = bs_find_g(1, n+1, x-1);
  66| 
  67| // 如果找不到，或者找到的位置数值不是 X，说明数组里根本没有 X
  68| if( L == n+1 || a[L].val != x) {
  69|     cout << 0 << "\n";
  70|     continue;
  71| }
  72| 
  73| // 找到第一个 val > x 的位置
  74| int R = bs_find_g(1, n+1, x);
  75| ```
  76| 
  77| 此时，排序后的数组 `a` 中，下标区间 `[L, R)` (左闭右开) 内的所有元素，其 `val` 都等于  $X$ 。
  78| 
  79| ```
  80| // 2. 在 X 的“地盘”里，筛选原下标 [l, r]
  81| // 在区间 [L, R) 中，找到第一个原下标 pos >= l 的位置
  82| int ll = bs_find_pos(L, R, l-1);
  83| 
  84| // 在区间 [L, R) 中，找到第一个原下标 pos > r 的位置
  85| int rr = bs_find_pos(L, R, r);
  86| 
  87| // 3. 计算数量
  88| cout << rr - ll << "\n";
  89| ```
  90| 
  91| 因为 `[L, R)` 区间内 `pos` 是有序的，`rr` 是大于  $R$  的第一个位置，`ll` 是大于等于  $L$  的第一个位置，两者相减 `rr - ll` 即为原下标在  $\left[L,R\right]$  范围内的元素个数。

  95| ### 3 算法复杂度分析
  96| 
  97| *   **时间复杂度**：
  98|     *   **预处理**：排序消耗  $O\left(N\log N\right)$ 。
  99|     *   **查询**：每次查询进行了 4 次二分查找。每次二分的时间是  $O\left(\log N\right)$ 。总查询时间为  $O\left(Q\log N\right)$ 。
 100|     *   **总时间**： $O\left(\left(N+Q\right)\log N\right)$ 。这完全可以通过  $2\times 10^{5}$  的数据规模。
 101| *   **空间复杂度**：
 102|     *    $O\left(N\right)$ ，用于存储结构体数组。相比于 `vector<int> idx[maxn]` 的邻接表写法，这种写法内存更加紧凑且连续，常数更小。

 104| ### 4 举例演示
 105| 
 106| 假设输入：
 107| 
 108| ```
 109| N = 5
 110| A = [3, 1, 4, 1, 5]
 111| Query: L=1, R=4, X=1
 112| ```
 113| 
 114| **1 预处理后 `a` 数组的状态：**
 115| 
 116| | 排序后索引 | `a[i].val` | `a[i].pos` |
 117| | --- | --- | --- |
 118| | 1   | **1** | **2** |
 119| | 2   | **1** | **4** |
 120| | 3   | 3   | 1   |
 121| | 4   | 4   | 3   |
 122| | 5   | 5   | 5   |
 123| 
 124| **2 处理查询 `L=1, R=4, X=1`：**
 125| 
 126| 1.  **定值域**：
 127|     *   `bs_find_g(..., 0)` 找第一个 `val >= 1`  $\to$  返回索引 **1** (`L`).
 128|     *   `bs_find_g(..., 1)` 找第一个 `val > 1`  $\to$  返回索引 **3** (`R`).
 129|     *   锁定区间 `[1, 3)`，即索引 1 和 2。
 130| 2.  **定下标**：
 131|     *   在索引 `[1, 3)` 中，找第一个 `pos >= 1`  $\to$  索引 1 的 pos 是 2 (满足)，返回 **1** (`ll`).
 132|     *   在索引 `[1, 3)` 中，找第一个 `pos > 4`  $\to$  索引 1 pos=2 (不满足)，索引 2 pos=4 (不满足)。循环结束返回 **3** (`rr`).
 133| 3.  **计算**：
 134|     *   `ans = rr - ll = 3 - 1 = 2`。
 135|     *   原数组中下标 1 到 4 之间确实有两个 1 (分别在原下标 2 和 4)。

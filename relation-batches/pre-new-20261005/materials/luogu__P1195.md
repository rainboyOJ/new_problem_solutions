   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给一张无向带权图，要从中选出一些边，把所有点连成恰好 `K` 个连通块，并让总代价最小。
  14| 
  15| 如果无论怎么选都做不到恰好 `K` 个连通块，就输出 `No Answer`。
  16| 
  17| #### 样例图
  18| 
  19| 这张图把样例画出来：
  20| 
  21| ```dot
  22| graph G {
  23|   1 -- 2 [label="1"];
  24|   3;
  25| }
  26| ```
  27| 
  28| 原图一共有 `3` 个点，只有一条边 `1-2`，目标是连成 `2` 个连通块。
  29| 选上这条边后，连通块从 `{1},{2},{3}` 变成 `{1,2},{3}`，刚好是 `2` 块，总代价是 `1`。
  30| 
  31| ### 思路
  32| 
  33| 先看一个只适合很小数据的暴力：
  34| 
  35| @include-code(./brute.cpp, cpp)
  36| 
  37| 暴力直接枚举所有边子集：
  38| 
  39| - 如果子集里形成了环，就不是最优结构，跳过
  40| - 统计最后有多少个连通块
  41| - 只保留恰好 `K` 个连通块的方案，取最小代价
  42| 
  43| 这个思路按定义是对的，但边数一大就完全不可行。
  44| 
  45| 这题本质上就是最小生成树的一个变形。
  46| 
  47| 普通最小生成树是：
  48| 
  49| - 从 `N` 个单点开始
  50| - 按边权从小到大连边
  51| - 一直连到只剩 `1` 个连通块
  52| 
  53| 而这题只是把终点改成：
  54| 
  55| - 一直连到只剩 `K` 个连通块
  56| 
  57| 所以可以直接套 Kruskal：
  58| 
  59| 1. 把所有边按权值升序排序
  60| 2. 用并查集维护当前连通块
  61| 3. 每次选一条能连接两个不同连通块的最小边
  62| 4. 当连通块数降到 `K` 时立即停止
  63| 
  64| 为什么这样就是最优？
  65| 
  66| 因为 Kruskal 在任何时刻都优先用最便宜的边去合并两个块。
  67| 当我们只要求停在 `K` 个连通块，而不是继续连到 `1` 个时，前面的贪心理由完全不变。
  68| 
  69| 如果所有边都扫完了，连通块数还是大于 `K`，就说明原图本身不够连通，答案不存在，输出 `No Answer`。

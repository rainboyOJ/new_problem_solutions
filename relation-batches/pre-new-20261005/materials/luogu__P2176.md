   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 有一张无向带权图，起点是 `1`，终点是 `N`。
  14| 
  15| 现在可以选一条边，把它的长度加倍一次。  
  16| 要求让 `1 -> N` 的最短路长度增加得尽可能多，输出这个最大增量。
  17| 
  18| #### 样例直觉图
  19| 
  20| 这张图展示了“把原最短路上的一条边加倍后，被迫改走别的路”的现象：
  21| 
  22| ```dot
  23| graph G {
  24|   rankdir=LR;
  25|   1 -- 3 [label="1"];
  26|   3 -- 4 [label="3", color="red", penwidth=2];
  27|   4 -- 5 [label="2"];
  28|   3 -- 5 [label="7"];
  29| }
  30| ```
  31| 
  32| 如果把红边 `3-4` 加倍，原来的最短路可能不再最优，答案就会变大。  
  33| 这说明我们真正关心的是：哪些边有能力把原最短路“挤掉”。
  34| 
  35| ### 思路
  36| 
  37| 先看一个最直接的小数据暴力：
  38| 
  39| @include-code(./brute.cpp, cpp)
  40| 
  41| 暴力做法就是：
  42| 
  43| 1. 枚举每一条边
  44| 2. 把它长度临时加倍
  45| 3. 重算 `1 -> N` 的最短路
  46| 4. 取增量最大值
  47| 
  48| 这个做法最贴近题意，但对大图来说没必要把所有边都试一遍。
  49| 
  50| 关键观察是：
  51| 
  52| - 如果某条边不在当前求出的一条最短路上
  53| - 那么把它加倍之后，这条最短路本身仍然原封不动地存在
  54| 
  55| 既然原来的这条最短路还在，新的最短路长度就不可能变大。  
  56| 而边长只会变大不会变小，所以新的最短路长度也不可能变小。  
  57| 因此：
  58| 
  59| - 不在这条最短路上的边，加倍后增量一定是 `0`
  60| 
  61| 所以我们只需要：
  62| 
  63| 1. 先求一遍 `1 -> N` 的最短路
  64| 2. 把这条最短路上的边重建出来
  65| 3. 只枚举这些边去加倍
  66| 
  67| 于是主解流程变成：
  68| 
  69| 1. 第一次 Dijkstra，求原最短路，并记录每个点的前驱边
  70| 2. 从 `N` 倒着回溯，得到一条完整最短路上的边编号
  71| 3. 对这条路上的每条边：
  72|    - 临时把边权乘 `2`
  73|    - 再跑一次 Dijkstra
  74|    - 更新答案
  75|    - 恢复边权
  76| 
  77| 最后取所有增量里的最大值即可。

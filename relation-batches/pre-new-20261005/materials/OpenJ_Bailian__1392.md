  11| ### 题目核心解析
  12| 
  13| 1. 问题本质：寻找字典序最小的 De Bruijn 序列
  14| 
  15| 题目中定义的 "Ouroboros number"（衔尾蛇数）实际上就是 De Bruijn 序列 $B(2, n)$。
  16| 
  17| - **定义**：一个长度为 $2^n$ 的二进制串，当首尾相连时，包含了所有可能的长度为 $n$ 的二进制子串（从 $0$ 到 $2^n-1$）各恰好一次。
  18| - **目标**：题目要求找到**字典序最小**的那个 Ouroboros number，并输出该序列中第 $k$ 个长度为 $n$ 的子串对应的十进制数值。
  19| - 图论模型：De Bruijn 图
  20| 
  21| 这个问题可以通过在 De Bruijn 图 上寻找 欧拉回路 (Eulerian Circuit) 来解决。
  22| 
  23| - **节点 (States)**：所有长度为 $n-1$ 的二进制串。共有 $2^{n-1}$ 个节点。
  24| - **边 (Edges)**：每个节点 $u$ 有两条出边，分别代表在当前 $n-1$ 位后面添加 `0` 或 `1`。
  25|   - 添加 `0`：形成的新 $n$ 位数是 `(u << 1) | 0`。这条边指向的新节点是该 $n$ 位数的后 $n-1$ 位。
  26|   - 添加 `1`：形成的新 $n$ 位数是 `(u << 1) | 1`。指向对应的新节点。
  27| - **欧拉回路**：因为每个节点的入度和出度都是 2，且图是强连通的，所以一定存在欧拉回路。这条回路经过每条边恰好一次，而每条边就对应一个唯一的 $n$ 位二进制数。回路上的边序列就是我们要找的答案。
  28| - 字典序最小策略
  29| 
  30| 为了得到字典序最小的序列（即让二进制串看起来尽可能小），我们需要使用 Hierholzer 算法（DFS 后序入栈）来寻找欧拉回路，并应用贪心策略：
  31| 
  32| - **贪心**：在 DFS 遍历时，对于每个节点，**总是优先尝试走 '0' 的边，然后再尝试走 '1' 的边**。
  33| - **Hierholzer 特性**：该算法是在回溯（离开节点）时将边加入栈中。因此，得到的路径是**逆序**的。
  34| - **结果**：当我们优先遍历 '0' 边时，'0' 边会比 '1' 边更晚进入栈底（或者说在递归树更深层被处理），这意味着在**逆序**输出时，'0' 边会排在前面。这正好满足字典序最小的要求。
  35| 
  36| **4. 算法流程**
  37| 
  38| 1. **建图**：隐式建图。节点状态为 `0` 到 `2^(n-1) - 1`。
  39| 2. **DFS**：从节点 `0` 开始。
  40|    - 尝试边 `0`（对应数值 `(u << 1) | 0`）。如果未访问，递归，回溯时记录该数值。
  41|    - 尝试边 `1`（对应数值 `(u << 1) | 1`）。如果未访问，递归，回溯时记录该数值。
  42| 3. **记录**：使用一个栈或数组记录路径。
  43| 4. **输出**：由于 Hierholzer 算法记录的是逆序路径，我们需要从数组的末尾开始索引。题目求第 $k$ 个数，即为路径数组 `path[path.size() - 1 - k]`。

  48|

  51| ```cpp
  52| /**
  53|  * Author by Rainboy
  54|  * Problem: POJ 1793 / OpenJ_Bailian 1392 Ouroboros Snake
  55|  * Analysis: 
  56|  * 1. 这是一个构造字典序最小的 De Bruijn 序列的问题。
  57|  * 2. 模型：在 n-1 位的 De Bruijn 图上寻找欧拉回路。
  58|  * 3. 策略：Hierholzer 算法 (DFS) + 贪心 (优先走 0 边)。
  59|  * 4. 注意：DFS 后序记录的是逆序路径，输出时需要倒着取。
  60|  */
  61| 
  62| #include <iostream>
  63| #include <vector>
  64| #include <algorithm>
  65| #include <cstring>
  66| #include <cmath>
  67| 
  68| using namespace std;
  69| 
  70| // 最大 N=15, 2^15 = 32768。
  71| // 边的总数是 2^N。我们需要标记边是否被访问。
  72| // 边的数值范围是 0 到 2^N - 1。
  73| const int MAX_EDGES = 1 << 16; 
  74| 
  75| int n, k;
  76| bool visited[MAX_EDGES]; // 记录边的数值是否已存在于序列中
  77| vector<int> path;        // 存储欧拉回路的边序列
  78| int node_mask;           // 用于取后 n-1 位
  79| 
  80| // Hierholzer 算法寻找欧拉回路
  81| // u: 当前节点 (n-1 位)
  82| void dfs(int u) {
  83|     // 贪心策略：优先尝试添加 0，再尝试添加 1
  84|     // 这样在逆序输出时，0 会排在前面，保证字典序最小
  85|     for (int i = 0; i <= 1; ++i) {
  86|         // 构造边的数值 (n 位)
  87|         // 左移一位腾出位置，加上当前的 bit (0 或 1)
  88|         int edge_val = (u << 1) | i;
  89|         
  90|         if (!visited[edge_val]) {
  91|             visited[edge_val] = true;
  92|             
  93|             // 下一个节点是 edge_val 的后 n-1 位
  94|             int v = edge_val & node_mask;
  95|             
  96|             dfs(v);
  97|             
  98|             // 回溯时记录路径 (Hierholzer 核心)
  99|             path.push_back(edge_val);
 100|         }
 101|     }
 102| }
 103| 
 104| void solve() {
 105|     // 0 0 结束输入
 106|     // 注意题目输入可能会有 n k 在一行，以 0 0 结尾
 107|     while (cin >> n >> k && (n != 0 || k != 0)) {
 108|         // 初始化
 109|         memset(visited, 0, sizeof(visited));
 110|         path.clear();
 111|         
 112|         // n-1 位的掩码。例如 n=3, mask=11(bin)=3
 113|         // 用于从 n 位的边数值中提取后 n-1 位作为下一个节点
 114|         node_mask = (1 << (n - 1)) - 1;
 115|         
 116|         // 从节点 0 (全是0的状态) 开始 DFS
 117|         dfs(0);
 118|         
 119|         // Hierholzer 算法生成的 path 是逆序的。
 120|         // path.back() 是第一个数，path[0] 是最后一个数。
 121|         // 第 k 个数 (0-indexed) 对应的就是倒数第 k+1 个元素。
 122|         int ans = path[path.size() - 1 - k];
 123|         
 124|         cout << ans << endl;
 125|     }
 126| }
 127| 
 128| int main() {
 129|     // 优化 IO
 130|     ios::sync_with_stdio(false);
 131|     cin.tie(0);
 132|     solve();
 133|     return 0;
 134| }
 135| ```

 137| ### 代码细节解释
 138| 
 139| 1. **`node_mask`**: 对于 De Bruijn 图，如果当前状态是 $b_1 b_2 \dots b_{n-1}$，添加一个位 $x$ 后，新状态应该是 $b_2 \dots b_{n-1} x$。在位运算中，这等价于 `((u << 1) | x) & mask`，其中 mask 是 $n-1$ 个 1。
 140| 2. **贪心顺序**: `for (int i = 0; i <= 1; ++i)` 确保了我们总是先走值较小的边。虽然这些边被压入栈底（`path` 的前面），但在最终的欧拉路径中，栈底元素对应路径的末尾？**不**，Hierholzer 算法回溯时入栈，最后回溯到起点的边最后入栈（在 `path` 的末尾/Top）。因此 `path` 的末尾是路径的起点。由于我们希望起点尽可能小，而递归越深的边在 `path` 中越靠前（栈底），递归越浅的边在 `path` 越靠后（栈顶）。这里利用贪心让较小的边进入更“浅”的递归层级或正确的拓扑序中，从而保证整体序列最小。
 141| 3. **索引计算**: `path.size() - 1 - k`。因为 `path` 存储的是 `[Last Edge, ..., Second Edge, First Edge]`。所以第 `0` 个数是 `path.back()`，第 `k` 个数就是从后往前数第 `k` 个。

   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 有 `n` 次挤奶，第 `i` 次挤奶最早不能早于 `S[i]` 这一天。
  14| 
  15| 另外有若干条记忆 `(a, b, x)`，表示第 `b` 次挤奶至少要在第 `a` 次挤奶之后 `x` 天进行，也就是：
  16| 
  17| `day[b] >= day[a] + x`
  18| 
  19| 题目保证这些记忆没有矛盾。要求输出每一次挤奶在满足所有条件时的最早日期。
  20| 
  21| #### 样例图
  22| 
  23| 这张图把样例中的下界和依赖关系画出来：
  24| 
  25| ```dot
  26| digraph G {
  27|   rankdir=LR;
  28|   1 [label="1\nS=1"];
  29|   2 [label="2\nS=2"];
  30|   3 [label="3\nS=3"];
  31|   4 [label="4\nS=4"];
  32|   1 -> 2 [label="+5"];
  33|   2 -> 4 [label="+2"];
  34|   3 -> 4 [label="+4"];
  35| }
  36| ```
  37| 
  38| 例如点 `2` 本来下界是 `2`，但因为 `2 >= 1 + 5`，所以它至少要到第 `6` 天。
  39| 点 `4` 既要满足 `4 >= 2 + 2`，又要满足 `4 >= 3 + 4`，所以要取这些限制中的最大值，最后得到 `8`。
  40| 
  41| ### 思路
  42| 
  43| 先看一个小数据暴力：
  44| 
  45| @include-code(./brute.cpp, cpp)
  46| 
  47| 这个暴力直接递归枚举某个点所有可能影响它的前驱链。
  48| 
  49| 如果定义 `f(i)` 表示第 `i` 次挤奶能安排的最早日期，那么：
  50| 
  51| - 至少要满足自己的下界：`f(i) >= S[i]`
  52| - 对每条约束 `u -> i (w)`，还要满足 `f(i) >= f(u) + w`
  53| 
  54| 因此就有转移：
  55| 
  56| `f(i) = max(S[i], f(u1) + w1, f(u2) + w2, ...)`
  57| 
  58| 这正是一个 DAG 上的最长路模型，只不过：
  59| 
  60| - 点的初值是 `S[i]`
  61| - 边权是约束里的 `x`
  62| 
  63| 直接递归会反复计算很多重叠子问题，所以正式做法改成拓扑排序 + DP。
  64| 
  65| 做法：
  66| 
  67| 1. 把每次挤奶看成一个点。
  68| 2. 对每条记忆 `(a, b, x)` 建边 `a -> b`，边权为 `x`。
  69| 3. 初始令 `dp[i] = S[i]`。
  70| 4. 求拓扑序。
  71| 5. 按拓扑序枚举点 `u`，对每条边 `u -> v (w)` 做：
  72| 
  73|    `dp[v] = max(dp[v], dp[u] + w)`
  74| 
  75| 6. 最后每个 `dp[i]` 就是答案。
  76| 
  77| 代码结构和你算法书里的拓扑模板一致：`add_edge()` 建图，`kahn()` 求序，然后在线性顺序上做带权转移。

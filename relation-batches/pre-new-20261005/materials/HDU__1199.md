   9| ## 题目解析（原文摘录）
  10| 
  11| ## 1. 题目核心难点
  12| 
  13| - **坐标范围极大**：球的编号（坐标）可以达到 $2^{31}-1$（约 20 亿），无法直接开数组模拟。
  14| - **操作次数较少**：$N \leqslant 2000$，这意味着涉及的关键坐标点最多只有 4000 个。
  15| - **区间操作**：涉及区间染色（覆盖），最后询问最长的连续白色区间。
  16| 
  17| ## 2. 解题思路
  18| 
  19| ### 第一步：离散化 (Discretization)
  20| 
  21| 由于坐标很大但关键点很少，我们需要将坐标“压缩”。
  22| 
  23| 对于区间染色问题，有一个经典的离散化技巧：
  24| 
  25| 如果题目给出的操作是闭区间 $[a, b]$，我们在离散化数组中不仅要存入 $a$，还要存入 $b+1$。
  26| 
  27| 为什么是 $b+1$？
  28| 
  29| 我们将数轴离散化为若干个左闭右开的区间 $[X_i, X_{i+1})$。
  30| 
  31| 如果要表示覆盖 $[1, 4]$，在逻辑上等同于覆盖 $[1, 5)$。如果不存 $b+1$，我们就无法精确地表示出“从 $b$ 结束，下一个区间从 $b+1$ 开始”这个分界点。
  32| 
  33| 具体步骤：
  34| 
  35| 1. 读取所有操作 $(a, b, type)$。
  36| 2. 将 $a$ 和 $b+1$ 加入一个数组 `X`。
  37| 3. 对 `X` 进行排序并去重 (sort + unique)。
  38| 4. 此时，两个相邻的离散化点 $X[i]$ 和 $X[i+1]$ 构成了一个基本区间 $[X[i], X[i+1]-1]$，其长度为 $X[i+1] - X[i]$。
  39| 
  40| #### 第二步：线段树 (Segment Tree)
  41| 
  42| 我们建立一棵线段树来维护离散化后的下标 $0$ 到 $M$（$M$ 是去重后点的数量）。
  43| 
  44| 线段树的每个叶子节点 $i$ 代表实际数轴上的区间 $[X[i], X[i+1]-1]$。
  45| 
  46| - **维护值**：因为这题只需要最后的结果，我们不需要在节点中维护复杂的“最大连续长度”。只需要维护一个标记 `val`：
  47|   - `-1`：表示该区间颜色不统一（杂色）。
  48|   - `0`：表示全黑。
  49|   - `1`：表示全白。
  50| - **懒惰标记 (Lazy Propagation)**：这是必须的，因为是区间修改。当我们将一个大区间染成白色时，不需要遍历到底，打个标记即可。只有当需要访问子节点时才下传标记 (`pushdown`)。
  51| 
  52| #### 第三步：统计答案
  53| 
  54| 题目问的是“最终”的最长连续白色序列。
  55| 
  56| 1. 处理完所有 $N$ 次操作。
  57| 2. 从左到右遍历离散化后的每一个基本区间 $[X[i], X[i+1]-1]$。
  58| 3. 查询该区间的颜色。
  59|    - 如果是**白色**，累加长度到 `current_len`。
  60|    - 如果是**黑色**，结算当前的 `current_len`，尝试更新最大值，并重置 `current_len` 为 0。
  61| 4. 注意处理连续两个基本区间都是白色的情况（它们在数轴上是首尾相接的，直接合并即可）。
  62|

  64|

  68| #include <iostream>
  69| #include <vector>
  70| #include <algorithm>

  73| using namespace std;
  74| 
  75| const int MAXN = 2005;
  76| const int MAXM = MAXN * 4; // 离散化后的点最多 2*N，线段树开 4 倍
  77| 
  78| // 存储原始操作
  79| struct Operation {
  80|     int a, b;
  81|     char type;
  82| } ops[MAXN];
  83| 
  84| // 离散化数组
  85| vector<int> X;
  86| 
  87| // 线段树数组，tree[i] 存储颜色的标记
  88| // -1: 杂色/无标记, 0: 黑色, 1: 白色
  89| int tree[MAXM * 4];
  90| 
  91| // 下传标记
  92| void pushdown(int node) {
  93|     if (tree[node] != -1) {
  94|         tree[node * 2] = tree[node];
  95|         tree[node * 2 + 1] = tree[node];
  96|         tree[node] = -1; // 标记下传后，当前节点设为杂色(或者不处理也行，但这题覆盖逻辑简单)
  97|                          // 其实严格来说，对于覆盖类线段树，父节点有值就意味着子节点全被覆盖
  98|                          // 父节点变为-1只在update在这个节点区间只有部分被覆盖时发生
  99|                          // 但为了方便最后统计，我们这里仅仅利用 pushdown 将颜色推到叶子即可
 100|     }
 101| }

 103| // 区间更新
 104| // L, R 是当前节点覆盖的离散化下标范围

 106| void update(int node, int L, int R, int qL, int qR, int color) {
 107|     if (qL <= L && R <= qR) {
 108|         tree[node] = color;
 109|         return;
 110|     }
 111|     
 112|     // 如果当前节点有纯色标记，先下传，否则子节点的数据是旧的

 114|         tree[node * 2] = tree[node];
 115|         tree[node * 2 + 1] = tree[node];
 116|         tree[node] = -1; // 当前节点不再纯色，因为下面即将只有一部分被修改
 117|     }

 119|     int mid = (L + R) / 2;
 120|     if (qL <= mid) update(node * 2, L, mid, qL, qR, color);
 121|     if (qR > mid) update(node * 2 + 1, mid + 1, R, qL, qR, color);

 129| void extract_colors(int node, int L, int R) {
 130|     if (L == R) {
 131|         colors[L] = tree[node];
 132|         return;
 133|     }
 134|     // 强制下传标记，确保叶子节点是最新的颜色
 135|     if (tree[node] != -1) {

 138|         tree[node] = -1;
 139|     }
 140|     int mid = (L + R) / 2;
 141|     extract_colors(node * 2, L, mid);
 142|     extract_colors(node * 2 + 1, mid + 1, R);
 143| }

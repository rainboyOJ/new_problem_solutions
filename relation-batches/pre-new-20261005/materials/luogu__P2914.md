   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 有 `n` 根电线杆，每根都有平面坐标。  
  14| 现在有 `w` 条现成电线还能继续使用，它们的代价视为 `0`。
  15| 
  16| 你还可以自己新拉电线，但只能在两点直线距离不超过 `M` 时才能拉，而且代价就是这段直线距离。
  17| 
  18| 要求让电力从 `1` 号点传到 `n` 号点，求需要补上的最小总长度。
  19| 
  20| 按题目要求，最后输出：
  21| 
  22| - 最小总长度乘 `1000` 后的整数部分
  23| 
  24| 如果无法连通，就输出 `-1`。
  25| 
  26| ### 思路
  27| 
  28| 先看一个最直接的小数据做法：
  29| 
  30| @include-code(./brute.cpp, cpp)
  31| 
  32| `brute.cpp` 的思路其实已经很接近正解了：
  33| 
  34| 1. 先把所有原有电线记成 `0` 权边
  35| 2. 再枚举所有点对
  36| 3. 若两点距离不超过 `M`，就补上一条代价为欧几里得距离的边
  37| 4. 最后 Floyd 求 `1 -> n` 的最短路
  38| 
  39| 这个做法在小数据上完全没问题，但 `n = 1000` 时，Floyd 的 $O(n^3)$ 就太大了。
  40| 
  41| 关键观察是：  
  42| 题目本质上只是一个非负边权最短路。
  43| 
  44| 建图方式如下：
  45| 
  46| - 已有电线：边权是 `0`
  47| - 可以新拉且长度 `<= M`：边权是两点欧几里得距离
  48| - 其他点对：没有边
  49| 
  50| 这张图可以用下面这个示意来理解：
  51| 
  52| ```mermaid
  53| graph LR
  54|   A["已有电线"] -->|"0"| B["中间点"]
  55|   B -. "sqrt(dx^2+dy^2), 且 <= M" .-> C["新拉电线"]
  56| ```
  57| 
  58| 图里真正重要的是“同一个点对可能有两种状态”：
  59| 
  60| 1. 本来就有线，代价直接是 `0`
  61| 2. 本来没线，但如果距离不超过 `M`，可以花这段距离去补
  62| 
  63| 既然所有边权都不为负，那就直接跑 Dijkstra。
  64| 
  65| 因为 `n` 只有 `1000`，这里甚至不需要链式前向星和堆优化。  
  66| 直接把边权整理成一个 `cost[i][j]` 矩阵，再写朴素 Dijkstra 就够了：
  67| 
  68| 1. 先预处理所有 `cost[i][j]`
  69| 2. `cost[i][j] = 0` 表示原来有线
  70| 3. `cost[i][j] = dist(i,j)` 表示可以新拉
  71| 4. `cost[i][j] = INF` 表示根本不能直接连接
  72| 5. 在这张图上求 `1 -> n` 最短路
  73| 
  74| 和代码的对应关系：
  75| 
  76| - `has_wire[i][j]`：原来是否有现成电线
  77| - `cost[i][j]`：建好的边权矩阵
  78| - `build_graph()`：完成建图
  79| - `dijkstra(1)`：求从 `1` 出发的最短路

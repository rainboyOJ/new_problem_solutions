   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 初始有一个长度为 `n` 的 `01` 序列，开始时全是 `1`。
  14| 
  15| 支持三类操作：
  16| 
  17| - 把一段区间全部变成 `0`
  18| - 把一段区间里的正常脑组织挖出来，拿去填另一段区间里最靠左的脑洞
  19| - 查询一段区间中最长连续 `0` 的长度
  20| 
  21| ### 思路
  22| 
  23| 先看一个可以直接验证想法的朴素解：
  24| 
  25| @include-code(./brute.cpp, cpp)
  26| 
  27| `brute.cpp` 完全按题意模拟：
  28| 
  29| - 统计供体区间里有多少个 `1`
  30| - 清空供体区间
  31| - 从左到右扫描目标区间，把最靠前的 `0` 填成 `1`
  32| - 查询时暴力扫最长连续 `0`
  33| 
  34| 这个思路容易理解，但大数据下显然太慢。
  35| 
  36| 这题的关键是把所有操作都放进线段树。
  37| 
  38| 线段树每个节点需要维护：
  39| 
  40| - 区间里 `1` 的数量
  41| - 前缀连续 `0`
  42| - 后缀连续 `0`
  43| - 最长连续 `0`
  44| 
  45| 这样：
  46| 
  47| - 区间清空就是整段赋值为 `0`
  48| - 查询最长脑洞就是查区间 `best_zero`
  49| 
  50| 操作 1 虽然特殊，但也可以拆开：
  51| 
  52| 1. 先查供体区间里当前有多少个 `1`
  53| 2. 把供体区间整段设为 `0`
  54| 3. 再把目标区间里最靠左的若干个 `0` 改成 `1`
  55| 
  56| 第三步用一个左优先递归就能实现：
  57| 
  58| - 如果某个完整节点里的 `0` 数量已经不超过还需填的数量，就整段直接设成 `1`
  59| - 否则继续优先递归左儿子，再递归右儿子
  60| 
  61| 这正好对应题意里“尽量填补位置比较靠前的脑洞”。
  62| 
  63| 可以用下面这个小表格理解样例里的第一次治疗：
  64| 
  65| | 步骤 | 区间状态 |
  66| | --- | --- |
  67| | 初始挖洞后 | `1 0 1 0 0 0 1 1 1 0` |
  68| | 挖出 `[8,10]` 后拿到的正常组织数 | `2` |
  69| | 清空 `[8,10]` 后 | `1 0 1 0 0 0 1 0 0 0` |
  70| | 从左到右填补 `[1,4]` 后 | `1 1 1 1 0 0 1 0 0 0` |
  71| 
  72| 这张表里最重要的是最后一步：
  73| 目标区间不会把已有的 `1` 改掉，而是只会把最靠左的两个 `0` 补上。
  74| 这正是代码里 `fill_leftmost_zero()` 的行为。

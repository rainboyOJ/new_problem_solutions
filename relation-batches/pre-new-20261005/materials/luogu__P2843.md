   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给出一个长度为 `n` 的序列，每个数是一个 `k` 位二进制数。
  14| 
  15| 第 `j` 位为 `1`，表示这个人具有第 `j` 种特性；为 `0` 表示没有。
  16| 
  17| 现在要找一个最长的连续区间，使得这段区间内 `k` 种特性出现的总次数全部相同。
  18| 
  19| 输出这个最长区间的长度。
  20| 
  21| ### 思路
  22| 
  23| 先看最直观的小数据暴力：
  24| 
  25| @include-code(./brute.cpp, cpp)
  26| 
  27| `brute.cpp` 先对每一种特性做前缀和，然后枚举所有区间 `[l,r]`，检查这段区间里 `k` 种特性的出现次数是否全部相等。
  28| 
  29| 这个方法能帮助理解题意，但复杂度是 $O(n^2 k)$，显然无法通过 `n = 10^5`。
  30| 
  31| 关键是把条件改写成前缀状态相等。
  32| 
  33| 设 `pre_t[i]` 表示前 `i` 个人中，第 `t` 种特性一共出现了多少次。
  34| 
  35| 如果区间 `[l,r]` 合法，那么：
  36| 
  37| ```text
  38| pre_1[r] - pre_1[l-1]
  39| = pre_2[r] - pre_2[l-1]
  40| = ...
  41| = pre_k[r] - pre_k[l-1]
  42| ```
  43| 
  44| 此时最自然的做法，是把所有特性都减去第一种特性，定义：
  45| 
  46| ```text
  47| state(i) = (pre_2[i]-pre_1[i], pre_3[i]-pre_1[i], ..., pre_k[i]-pre_1[i])
  48| ```
  49| 
  50| 如果两个前缀位置 `x < y` 满足：
  51| 
  52| ```text
  53| state(x) = state(y)
  54| ```
  55| 
  56| 那么对所有 `t >= 2`，都有：
  57| 
  58| ```text
  59| pre_t[y] - pre_1[y] = pre_t[x] - pre_1[x]
  60| ```
  61| 
  62| 移项后得到：
  63| 
  64| ```text
  65| pre_t[y] - pre_t[x] = pre_1[y] - pre_1[x]
  66| ```
  67| 
  68| 也就是说，区间 `(x,y]` 内每一种特性的出现次数都和第一种特性相同，因此这段区间就是合法区间。
  69| 
  70| 于是原问题变成：
  71| 
  72| > 找两个相同的前缀状态，使它们之间的距离最大。
  73| 
  74| 实现方式非常直接：
  75| 
  76| 1. 从左到右扫描每个人
  77| 2. 更新每种特性的前缀出现次数
  78| 3. 构造当前的差分状态 `state(i)`
  79| 4. 用哈希表记录这个状态第一次出现的位置
  80| 5. 如果当前状态以前出现过，就用当前位置减去第一次出现位置更新答案
  81| 
  82| 别忘了初始全 0 状态出现在位置 `0`，这样从开头开始的合法区间也能被统计进去。

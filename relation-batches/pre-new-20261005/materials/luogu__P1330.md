   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给出一张无向图。要选出若干个点去封锁，使得：
  14| 
  15| - 每条边至少有一个端点被封锁
  16| - 任意两个相邻点不能同时被封锁
  17| 
  18| 要求封锁点数量最少；若做不到，输出 `Impossible`。
  19| 
  20| ### 思路
  21| 
  22| 最直接的办法是暴力枚举选哪些点。
  23| 
  24| 先看一个可以直接验证想法的朴素解：
  25| 
  26| @include-code(./brute.cpp, cpp)
  27| 
  28| 下面是另一种「01 序列」风格的暴力写法。它按点编号依次决定“封锁 / 不封锁”，递归生成完整选择后，叶子节点统一检查每条边是否恰好有一个端点被选，并统计最少封锁点数：
  29| 
  30| <details>
  31| <summary>另一种暴力写法：01 序列</summary>
  32| 
  33| @include-code(./brute_01_style.cpp, cpp)
  34| 
  35| </details>
  36| 
  37| `brute.cpp` 直接检查每条边是否满足“恰好选一个端点”，适合小图对拍。
  38| 
  39| 真正的关键是：对任意一条边 `(u, v)`，
  40| 
  41| - 如果两个端点都不选，这条边没被封锁
  42| - 如果两个端点都选，会发生冲突
  43| 
  44| 所以每条边必须恰好选一个端点。
  45| 
  46| 这张图对比了两种典型情况：
  47| 
  48| ```dot
  49| graph G {
  50|   subgraph cluster_ok {
  51|     label="链";
  52|     a1 -- a2;
  53|     a2 -- a3;
  54|   }
  55|   subgraph cluster_bad {
  56|     label="奇环";
  57|     b1 -- b2;
  58|     b2 -- b3;
  59|     b3 -- b1;
  60|   }
  61| }
  62| ```
  63| 
  64| 从图中可以看到，链可以二分成两侧，任选一侧就能覆盖所有边；而奇环没法做到“每条边恰好跨越选与不选”，所以直接无解。
  65| 
  66| 因此做法就是：
  67| 
  68| 1. 对每个连通块做二分图染色
  69| 2. 若遇到相邻同色，输出 `Impossible`
  70| 3. 否则这个块只能整块选某一种颜色，答案加上 `min(cnt0, cnt1)`

   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 这题给了一张没有环的有向图。
  14| 
  15| - 前 `m` 个点是污水接收口，每个点一开始各有 `1` 吨污水
  16| - 每个点会把自己当前的污水平均分给所有出边
  17| - 没有出边的点就是最终排水口
  18| 
  19| 要求输出每个最终排水口最后流出的污水量，而且必须用最简分数表示。
  20| 
  21| #### 样例图
  22| 
  23| 这张图展示样例中的排水关系：
  24| 
  25| ```dot
  26| digraph G {
  27|   rankdir=LR;
  28|   1 -> 2;
  29|   1 -> 3;
  30|   1 -> 5;
  31|   2 -> 4;
  32|   2 -> 5;
  33|   3 -> 5;
  34|   3 -> 4;
  35| }
  36| ```
  37| 
  38| `1` 号点先把 `1` 吨水均分成三份，分别流向 `2,3,5`。
  39| 其中流到 `2` 和 `3` 的水还会继续被均分一次，所以最后 `4` 收到 `1/3`，`5` 收到 `2/3`。
  40| 因为题目要求精确输出，所以这里不能用浮点数近似，必须直接维护分数。
  41| 
  42| ### 思路
  43| 
  44| 先看一个最直接的小数据暴力：
  45| 
  46| @include-code(./brute.cpp, cpp)
  47| 
  48| 这个暴力完全按题意递归分流：
  49| 
  50| - 当前来到点 `u`，手里有 `cur` 吨污水
  51| - 如果 `u` 是汇点，就把 `cur` 加到答案里
  52| - 否则把 `cur` 平均分成 `outdeg[u]` 份，递归流向每个后继
  53| 
  54| 这个写法很直观，但如果图很大、路径很多，就会重复遍历很多公共后缀。
  55| 
  56| 题目已经保证整张图是 DAG，所以更高效的办法是按拓扑序传播流量。
  57| 
  58| 做法如下：
  59| 
  60| 1. 用分数 `num / den` 精确保存每个点当前累计到的污水量。
  61| 2. 前 `m` 个接收口初始都设成 `1/1`。
  62| 3. 求整张图的拓扑序。
  63| 4. 按拓扑序处理每个点 `u`：
  64|    - 如果 `u` 不是汇点，就把 `water[u]` 均分成 `outdeg[u]` 份
  65|    - 每个后继 `v` 都加上这一份
  66| 5. 最后所有出度为 `0` 的点就是答案。
  67| 
  68| 这里用到的关键实现是一个简单分数类：
  69| 
  70| - 加法时通分再约分
  71| - 除以整数时直接把分母乘上这个整数
  72| 
  73| 代码结构上和你算法书里的拓扑模板保持一致：先建图和统计入度，再用队列按拓扑序顺推。

   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 序列支持末尾追加。询问在 `l <= p <= r` 中最大化 `a[p] ^ ... ^ a[N] ^ x`。
  14| 
  15| ### 思路
  16| 
  17| #### 1. 离散数学视角的公式化简（消除区间遍历）
  18| 
  19| 题目要求在 $l \le p \le r$ 的范围内，最大化以下表达式：
  20| 
  21| $$a[p] \oplus a[p+1] \oplus \dots \oplus a[N] \oplus x$$
  22| 
  23| 在离散数学中，异或（XOR）运算构成了布尔代数的一个重要部分，它完美满足**结合律**和**自反性**（即 $y \oplus y = 0$）。
  24| 正是基于自反性，我们可以像构造加法前缀和一样构造**异或前缀和**。定义：
  25| 
  26| $$s[i] = a[1] \oplus a[2] \oplus \dots \oplus a[i]$$
  27| 
  28| 规定边界 $s[0] = 0$。
  29| 
  30| 利用自反性，任意区间 $[p, N]$ 的异或和可以表示为两个前缀和的异或：
  31| 
  32| $$a[p] \oplus \dots \oplus a[N] = s[N] \oplus s[p-1]$$
  33| 
  34| 我们将这个结论代入原式，原式转化为求解：
  35| 
  36| $$\max \left( (s[N] \oplus x) \oplus s[p-1] \right)$$
  37| 
  38| 在一次查询中，当前序列的总长度 $N$ 和新加入的异或常数 $x$ 都是已知的，因此 $(s[N] \oplus x)$ 是一个**定值**（我们不妨称其为 $Val$）。
  39| 因为 $p \in [l, r]$，所以 $p-1$ 的范围就是 $[l-1, r-1]$。
  40| 
  41| **问题被完美转化为：**
  42| 给定常数 $Val$，在已知数组 $s$ 的下标区间 $[l-1, r-1]$ 中找出一个元素 $s[idx]$，使得 $Val \oplus s[idx]$ 结果最大。
  43| 
  44| #### 2. 模型映射：从贪心到可持久化
  45| 
  46| 如果要最大化 $Val \oplus s[idx]$，最经典的模型是 **01-Trie（字典树）**。
  47| 贪心策略是：将所有候选数字按二进制位从高到低存入 Trie，查询时从最高位开始，优先走向与 $Val$ 当前位**相反**的分支。
  48| 
  49| 但普通的 Trie 只能处理"全局查询"，无法限定候选数字必须来自 $[l-1, r-1]$ 这一特定区间。
  50| 为了解决区间约束，我们需要引入**可持久化 01-Trie**。
  51| 
  52| 可持久化数据结构的核心在于**保存历史版本**。
  53| 我们将前缀和数组 $s[0], s[1], \dots, s[N]$ 依次插入，每次插入生成一个新的根节点 `root[i]`。
  54| 
  55| * `root[r-1]` 这棵树包含了时间戳在 $\le r-1$ 之前插入的所有数字。
  56| * 我们从 `root[r-1]` 开始查询，就天然满足了 $idx \le r-1$ 的上限约束。
  57| 
  58| 那下限约束 $idx \ge l-1$ 怎么满足呢？
  59| 我们在 Trie 的每个节点上维护一个附加属性：`time_id`（经过该节点的数字中，最大的原数组下标）。
  60| 
  61| #### 3. 查询逻辑的最优解
  62| 
  63| 当我们在 `root[r-1]` 版本上从高到低进行贪心查询时，假设当前 $Val$ 在第 $k$ 位的值为 $bit$，我们最期望走向相反的分支 `expected = bit ^ 1`。
  64| 
  65| 此时，除了要判断该分支指针是否存在，更关键的是**检查时间戳**：
  66| 
  67| ```cpp
  68| if (node[next].time_id >= l - 1)
  69| ```
  70| 
  71| 其中 `next = node[cur].ch[expected]`。如果这个条件成立，说明在这条分支的深处，**必定存在至少一个**在时刻 $l-1$ 或之后插入的数字。满足要求！我们就可以走向这个分支。反之，我们只能被迫走向另一个分支 `bit`。
  72| 
  73| #### 4. 边界与细节防坑指南
  74| 
  75| 1. **初始状态**：在所有操作开始前，必须先将 $s[0] = 0$ 插入到版本 0 中（即 `root[0]`）。因为当 $p=1$ 时，$p-1=0$，我们需要能查询到 $s[0]$ 这个合法前缀。
  76| 2. **空间计算**：由于最多有 $N+M$ 个元素被插入，数字最大 $10^7$（约等于 $2^{24}-1$），Trie 的深度为 24 层（从 23 到 0）。每次插入新增 24 个节点。所以空间至少要开到 $(N+M) \times 25$。
  77| 3. **空节点哨兵**：下标 0 表示"黑洞"节点（不存在），它的 `time_id` 要设为 $-1$，保证任何 `>= l-1` 的判断都会失败，从而不会错误地走入空分支。
  78| 4. **追加操作**：`A x` 的本质就是再插入一个新版本，和初始插入完全一样，没有特殊处理。这就是可持久化的好处：新版本不影响旧版本，随时可以回溯。

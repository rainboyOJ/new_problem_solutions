   9| ## 题目解析（原文摘录）
  10| 
  11| ### 思路
  12| 
  13| **朴素做法。** 最直接的想法是：每只小猪单独发射一只鸟去打，答案上界是 $n$。要减少次数，就要让一只鸟顺路多打几只——问题变成"哪些小猪能被同一条抛物线一起带走"。
  14| 
  15| **第一步：小猪集合可以化成 bitmask。** 一条轨迹 $y = ax^2 + bx$ 必须过原点。任取两只不在同一竖直线上的小猪 $(x_1, y_1)$、$(x_2, y_2)$，把它们代入方程得到线性方程组
  16| 
  17| $$\begin{cases} a x_1^2 + b x_1 = y_1 \\ a x_2^2 + b x_2 = y_2 \end{cases} \quad\Longrightarrow\quad a = \frac{y_1/x_1 - y_2/x_2}{x_1 - x_2},\qquad b = \frac{y_1}{x_1} - a x_1$$
  18| 
  19| 也就是说：**一条合法轨迹最多由两只小猪唯一确定**。反过来，若某次发射打中了 $\geqslant 2$ 只小猪，其中任意两只确定出的就是这条轨迹本身。所以值得考虑的抛物线只有
  20| 
  21| $$\text{LINE}[i][j] = \text{过原点与小猪 } i, j \text{ 的抛物线经过的小猪集合（bitmask）}$$
  22| 
  23| 这 $O(n^2)$ 条。两种特殊情况退化成"只打 $i$ 自己"：$x_i = x_j$（两点同列，方程组无解）以及解出的 $a \geqslant 0$（开口向上或水平，不能从原点射进第一象限再落回地面）。坐标只有两位小数，"经过"用 $\varepsilon = 10^{-6}$ 判定：$|a x_k^2 + b x_k - y_k| < \varepsilon$。$\text{LINE}[i][i] = \{i\}$，代表"故意单打一只"。
  24| 
  25| **第二步：集合覆盖 → 状压 DP。** 现在每个候选抛物线对应一个"一次发射能消灭的小猪集合"，问题变成：用最少的集合把全集 $\{0, 1, \dots, n-1\}$ 覆盖。$n \leqslant 18$ 正是 bitmask DP 的信号：
  26| 
  27| $$dp[S] = \text{已消灭的小猪集合包含 } S \text{ 时，需要的最少小鸟数}$$
  28| 
  29| 初值 $dp[0] = 0$，答案是 $dp[\text{全满}]$。若直接从每个状态枚举所有 $O(n^2)$ 条线，会有大量重复计数；标准技巧是**给转移定序**：设 $low$ 是当前还活着的编号最小的小猪，它迟早要被某只鸟"第一次"消灭——固定当前这只鸟就是解决它的那只，于是只需枚举 $\text{LINE}[low][j]$（$j$ 遍历所有小猪，含 $j = low$），从 $S$ 转到 $S \cup \text{LINE}[low][j]$。每只活猪的"第一次"都被恰好转移一次覆盖，不重不漏。
  30| 
  31| **题面的 $m$ 指令呢？** $m = 1$、$m = 2$ 保证的是最优解的形状（有 $\lfloor n/3 \rfloor$ 连杀、$\lceil n/3 + 1 \rceil$ 只内全灭），源自"任意三只小猪中必有两只确定的抛物线合法"的组合性质，用于引导搜索 + 剪枝的写法；状压 DP 不依赖这些性质，读入后直接忽略 $m$。

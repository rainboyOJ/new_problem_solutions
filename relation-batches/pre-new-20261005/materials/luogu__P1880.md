   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 有 `n` 堆石子围成一个环。
  14| 
  15| 每次只能选相邻两堆合并，得分等于这两堆石子数之和。
  16| 
  17| 问把所有石子最终合成一堆时：
  18| 
  19| - 最小总得分是多少
  20| - 最大总得分是多少
  21| 
  22| ### 思路
  23| 
  24| 先看一个可以直接验证想法的朴素解：
  25| 
  26| @include-code(./brute.cpp, cpp)
  27| 
  28| 暴力做法就是递归模拟：
  29| 
  30| - 当前环上有多少堆石子
  31| - 枚举把哪一对相邻石子合并
  32| - 继续递归
  33| 
  34| 这样可以帮助理解题目，但复杂度是指数级，只能做很小的数据。
  35| 
  36| 这题的标准做法是区间 DP。
  37| 
  38| 如果石子是排成一条链，那么设：
  39| 
  40| - `dp_min[l][r]`：把区间 `[l, r]` 合成一堆的最小代价
  41| - `dp_max[l][r]`：把区间 `[l, r]` 合成一堆的最大代价
  42| 
  43| 转移时枚举最后一次合并的位置 `k`：
  44| 
  45| - 左边先合成一堆
  46| - 右边先合成一堆
  47| - 最后再把这两堆合并
  48| 
  49| 所以有：
  50| 
  51| - `dp_min[l][r] = min(dp_min[l][k] + dp_min[k+1][r] + sum(l,r))`
  52| - `dp_max[l][r] = max(dp_max[l][k] + dp_max[k+1][r] + sum(l,r))`
  53| 
  54| 其中 `sum(l,r)` 表示区间石子总数，因为最后这一次把两大堆合起来，得分就是整个区间总和。
  55| 
  56| 但原题是一个环，不是链。
  57| 
  58| 处理环形区间 DP 的常见办法是：
  59| 
  60| 1. 把数组复制一遍，变成长度 `2n`
  61| 2. 这样所有“断环成链”的方案，都能对应成一个长度为 `n` 的连续区间
  62| 3. 枚举每个起点 `l`，看区间 `[l, l+n-1]` 的答案
  63| 
  64| 最后：
  65| 
  66| - 所有这些长度为 `n` 的区间里，最小值的最小者就是答案
  67| - 最大值的最大者就是答案
  68| 
  69| 
  70| #### DP 转移方程
  71| 
  72| 核心状态：
  73| 
  74| `dp_min[l][r]` 与 `dp_max[l][r]`
  75| 
  76| 核心转移：
  77| 
  78| `dp[l][r]=opt_k(dp[l][k]+dp[k+1][r]+sum(l,r))`
  79| 
  80| 答案收束：
  81| 
  82| 长度 n 的所有区间取最小/最大

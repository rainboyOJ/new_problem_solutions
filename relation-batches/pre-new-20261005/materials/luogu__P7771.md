   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给一张有向图，要求输出一条**字典序最小**的欧拉路径。
  14| 
  15| 也就是：
  16| 
  17| - 每条边恰好走一次
  18| - 输出经过的顶点序列
  19| - 如果不存在这样的路径，输出 `No`
  20| 
  21| #### 样例图
  22| 
  23| 这张图展示样例 2 的结构：
  24| 
  25| ```dot
  26| digraph G {
  27|   rankdir=LR;
  28|   1 -> 2;
  29|   2 -> 3;
  30|   3 -> 4;
  31|   4 -> 3;
  32|   3 -> 5;
  33| }
  34| ```
  35| 
  36| 从 `3` 出发时，既可以去 `4`，也可以去 `5`。
  37| 为了让最终顶点序列字典序最小，应该优先走向编号更小的 `4`，于是答案是 `1 2 3 4 3 5`。
  38| 这说明除了判定欧拉路存在，还要额外处理“出边按什么顺序走”。
  39| 
  40| ### 思路
  41| 
  42| 先看一个小数据暴力：
  43| 
  44| @include-code(./brute.cpp, cpp)
  45| 
  46| 暴力直接枚举所有可能的走法：
  47| 
  48| - 从每个点尝试作为起点
  49| - 每次任选一条还没用过的出边继续走
  50| - 如果最后恰好用完全部边，就得到一条候选欧拉路径
  51| - 在这些候选里取字典序最小
  52| 
  53| 这个办法只能验证小数据，正式做法要用 Hierholzer。
  54| 
  55| 先回顾有向欧拉路的存在条件：
  56| 
  57| 1. 把有向边看成无向边后，所有有边的点要连通
  58| 2. 度数满足以下两种之一：
  59|    - 所有点 `in = out`，存在欧拉回路
  60|    - 恰有一个点满足 `out = in + 1`，作为起点
  61|    - 恰有一个点满足 `in = out + 1`，作为终点
  62| 
  63| 有了解的判定后，再考虑字典序。
  64| 
  65| Hierholzer 的特点是：
  66| 
  67| - 走边时先不输出
  68| - 回溯时再把点放进答案
  69| - 所以答案会**倒着产生**
  70| 
  71| 为了让最终答案字典序最小，只要让每个点总是优先走向编号更小的后继即可。
  72| 
  73| 实现上：
  74| 
  75| 1. 每个点的出边按终点升序排序
  76| 2. 用栈模拟 Hierholzer
  77| 3. 当前点还有边，就沿最小的那条边继续走
  78| 4. 当前点没边了，就把它放进 `path`
  79| 5. 最后把 `path` 倒着输出

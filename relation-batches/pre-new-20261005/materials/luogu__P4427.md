   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给一棵以 `1` 为根的树。
  14| 
  15| 每次询问给出 `x, y, k`，要求计算：
  16| 
  17| - 从 `x` 到 `y` 这条路径上
  18| - 所有节点深度的 `k` 次方和
  19| 
  20| 其中深度定义为：
  21| 
  22| - 节点到根 `1` 的路径边数
  23| 
  24| 结果对 `998244353` 取模。
  25| 
  26| #### 样例树
  27| 
  28| 样例树结构如下：
  29| 
  30| ```dot
  31| graph G {
  32|   1 -- 2;
  33|   1 -- 3;
  34|   2 -- 4;
  35|   2 -- 5;
  36| }
  37| ```
  38| 
  39| 深度分别是：
  40| 
  41| - $dep[1]=0$
  42| - $dep[2]=1$
  43| - $dep[3]=1$
  44| - $dep[4]=2$
  45| - $dep[5]=2$
  46| 
  47| 比如查询 `4, 5, 1`，路径是 `4-2-5`，答案就是：
  48| 
  49| - $2^1 + 1^1 + 2^1 = 5$
  50| 
  51| ### 思路
  52| 
  53| 先看一个最直接的小数据暴力：
  54| 
  55| @include-code(./brute.cpp, cpp)
  56| 
  57| 暴力做法就是：
  58| 
  59| 1. 每次查询找出 `x -> y` 的唯一路径
  60| 2. 枚举路径上的每个点
  61| 3. 把它的 $depth^k$ 累加起来
  62| 
  63| 这个方法最贴近题意，但查询多时会很慢。
  64| 
  65| 这题的关键是把“路径和”拆成“根到点前缀和”。
  66| 
  67| 设：
  68| 
  69| - $sum_pow[u][k]$ 表示从根到 `u` 的路径上，所有节点 $depth^k$ 的和
  70| 
  71| 那么对查询 `(x, y, k)`，设 `p = lca(x, y)`，就有：
  72| 
  73| - 根到 `x` 的前缀和：$sum_pow[x][k]$
  74| - 根到 `y` 的前缀和：$sum_pow[y][k]$
  75| - 根到 `p` 这一段被重复算了两次
  76| 
  77| 所以答案自然是：
  78| 
  79| $sum_pow[x][k] + sum_pow[y][k] - 2 * sum_pow[p][k] + depth[p]^k$
  80| 
  81| 最后为什么还要加回 $depth[p]^k$？
  82| 
  83| 因为：
  84| 
  85| - `p` 本身属于真实路径
  86| - 但它在前面的减法里被减掉了两次
  87| 
  88| 于是只要预处理好两样东西：
  89| 
  90| 1. 倍增 LCA
  91| 2. 对每个节点、每个 $k (1..50)$ 的前缀和
  92| 
  93| 每次查询就能很快回答。
  94| 
  95| 由于 `k` 的范围只有 `50`，所以对每个节点把 $depth^1, depth^2, \dots, depth^{50}$ 全部顺手算出来是完全可行的。

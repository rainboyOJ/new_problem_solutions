   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给一棵树，首都编号为 `1`。
  14| 
  15| 商人从首都出发，接下来要按给定顺序依次去若干个城镇做生意。
  16| 
  17| 树上每条边的长度都是 `1`，要求输出：
  18| 
  19| - 按这个顺序走完全部行程的最短总时间
  20| 
  21| 因为图本身是一棵树，所以任意两点之间路径唯一，最短时间其实就是：
  22| 
  23| - 从当前城市到下一个城市的树上距离
  24| 
  25| 把这些相邻路段全部加起来。
  26| 
  27| #### 样例图
  28| 
  29| 样例树结构如下：
  30| 
  31| ```dot
  32| graph G {
  33|   1 -- 2;
  34|   1 -- 5;
  35|   5 -- 3;
  36|   5 -- 4;
  37| }
  38| ```
  39| 
  40| 路线是：
  41| 
  42| `1 -> 3 -> 2 -> 5`
  43| 
  44| 对应路程分别是：
  45| 
  46| - `1 -> 3`：2
  47| - `3 -> 2`：3
  48| - `2 -> 5`：2
  49| 
  50| 总和就是 `7`。
  51| 
  52| ### 思路
  53| 
  54| 先看一个最直接的小数据暴力：
  55| 
  56| @include-code(./brute.cpp, cpp)
  57| 
  58| 暴力做法就是：
  59| 
  60| 1. 当前在 `last`
  61| 2. 下一站是 `x`
  62| 3. 直接在树上找出 `last -> x` 的唯一路径长度
  63| 4. 把所有相邻两站距离累加
  64| 
  65| 这个方法很好理解，但如果每一段都重新搜路径，就会慢。
  66| 
  67| 真正需要高效解决的，其实只有一个子问题：
  68| 
  69| - 如何快速求树上两点距离
  70| 
  71| 这正是 LCA 的标准应用。
  72| 
  73| 设两点为 `u, v`，它们的最近公共祖先为 `p = lca(u, v)`。
  74| 
  75| 那么两点距离就是：
  76| 
  77| `depth[u] + depth[v] - 2 * depth[p]`
  78| 
  79| 所以整道题分成两步：
  80| 
  81| 1. 预处理倍增 LCA
  82| 2. 顺着给定路线，把相邻两站的距离加起来
  83| 
  84| 由于商人从首都出发，所以初始位置直接设成：
  85| 
  86| - `last = 1`
  87| 
  88| 后面每读到一个目的地 `x`，就：
  89| 
  90| 1. 累加 `dist(last, x)`
  91| 2. 再令 `last = x`

  11| ### 题目解析
  12| 
  13| 首先，我们将图中的强连通分量（SCC）缩成一个点，得到一个有向无环图（DAG）。
  14| 
  15| 1. **问题 1：至少需要向几个学校下发新软件？**
  16|    - **分析**：在 DAG 中，如果有边 $A \to B$，软件给了 $A$，$B$ 自然就有。唯一“接收不到”别人的软件的，就是那些**入度为 0** 的点（源点）。
  17|    - **结论**：只要给所有 **入度为 0 的 SCC** 发软件，所有人都能收到。答案 = **入度为 0 的 SCC 数量**。
  18| 2. **问题 2：至少添加几条边，使整个图变成强连通图？**
  19|    - **分析**：强连通图意味着任意两点互达（相当于一个大环）。
  20|    - **模型**：在 DAG 中，我们有 $P$ 个入度为 0 的点（源点），$Q$ 个出度为 0 的点（汇点）。
  21|    - **策略**：为了让图连通，我们需要消灭所有的源点和汇点（除了由它们合并成的那个大环）。我们可以把一个汇点连向一个源点，这样就同时减少了一个汇点和一个源点。
  22|    - **结论**：
  23|      - 如果图本身就是强连通的（SCC数量为1），答案是 0。
  24|      - 否则，答案 = **$\max(\text{入度为0的SCC数}, \text{出度为0的SCC数})$**。

  11| ## 题目解析
  12| 
  13| 二分答案题目。我们需要在连续的实数域上二分体积。
  14| 
  15| ### 1 题目解析：单调性证明（反证法）
  16| 
  17| 我们定义一个检查函数 `check(V)`：能否将  $N$  个派切分出至少  $F+1$  块（朋友+我自己），且每块体积为  $V$ 。
  18| 
  19| **命题**：该问题具有单调性。即：如果体积  $V$  是合法的（`check(V) == true`），那么任何比  $V$  小的体积  $V^{′}$  也一定是合法的。
  20| 
  21| **证明（反证法）**：
  22| 
  23| 1.  **假设**：存在一个体积  $V$  满足 `check(V) == true`，但存在一个更小的体积  $V^{′}<V$  使得 `check(V') == false`。
  24| 2.  **分析**：
  25|     *   对于第  $i$  个派，其体积为  $S_{i}$ 。
  26|     *   能切出体积为  $V$  的块数为  $\left⌊S_{i}/V\right⌋$ 。
  27|     *   所有派能切出的总块数为  $K=\sum_{i=1}^{N} \left⌊S_{i}/V\right⌋$ 。
  28|     *   根据前提 `check(V) == true`，我们知道  $K\geqslant F+1$ 。
  29| 3.  **推导**：
  30|     *   因为  $V^{′}<V$ ，所以  $\frac{1}{V^{′}}>\frac{1}{V}$ 。
  31|     *   进而对于任意派  $S_{i}$ ，有  $\frac{S_{i}}{V^{′}}>\frac{S_{i}}{V}$ 。
  32|     *   由于向下取整函数  $\left⌊x\right⌋$  是单调不减的，所以  $\left⌊S_{i}/V^{′}\right⌋\geqslant \left⌊S_{i}/V\right⌋$ 。
  33|     *   对所有派求和，得出  $V^{′}$  对应的总块数  $K^{′}\geqslant K$ 。
  34| 4.  **矛盾**：
  35|     *   既然  $K\geqslant F+1$ ，且  $K^{′}\geqslant K$ ，那么必然  $K^{′}\geqslant F+1$ 。
  36|     *   这意味着 `check(V')` 必须为 `true`。
  37|     *   这与假设（`check(V') == false`）**矛盾**。
  38| 5.  **结论**：假设不成立，单调性得证。我们可以使用二分法找到最大的  $V$ 。
  39| 
  40| 
  41| ```
  42| --------------------V ------------------
  43|        ^
  44|        |
  45|        |
  46|   V'---+
  47| ```
  48| 
  49| 核心: 证明: 如果`V'` 不合法,所有的 `x < V'` 都不合法

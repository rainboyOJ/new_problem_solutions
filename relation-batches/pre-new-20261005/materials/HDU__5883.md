  11| ## 题目解析
  12| 
  13| 这是一道结合了**图论（欧拉回路/欧拉路径）**和**位运算（异或 XOR）**性质的经典算法题。以下是题目的详细解析。
  14| 
  15| ### 题目核心分析
  16| 
  17| 1. 问题转化
  18| 
  19| 题目要求“恰好经过每条河流一次”，这正是图论中**欧拉路径（Eulerian Path）**的定义。
  20| 
  21| - 整个行程构成一个节点序列 $P_0 \to P_1 \to \dots \to P_t$。
  22| - 我们需要计算路径上所有节点权值的异或和 $a_{P_0} \oplus a_{P_1} \oplus \dots \oplus a_{P_t}$，并使其最大化。
  23| - 欧拉路径/回路存在的充要条件
  24| 
  25| 对于无向图，存在欧拉路径或回路的条件如下：
  26| 
  27| 1. **连通性**：所有度数大于 0 的节点必须属于同一个连通分量（即所有边必须连通）。
  28| 2. **度数限制**：
  29|    - **欧拉回路（起点终点相同）**：所有节点的度数都必须是**偶数**。
  30|    - **欧拉路径（起点终点不同）**：恰好有 **2 个**节点的度数为**奇数**（一个是起点，一个是终点），其余节点度数全为偶数。
  31|    - **其他情况**：不存在满足条件的路径，输出 "Impossible"。
  32| 
  33| ------
  34| 
  35| ### 异或和的计算推导
  36| 
  37| 这是本题最巧妙的地方。直接模拟路径寻找最大值太慢，我们需要利用异或的性质：$x \oplus x = 0$。我们需要确定每个节点的值在最终算式中出现了奇数次还是偶数次。
  38| 
  39| **节点在路径中出现的次数与度数的关系：**
  40| 
  41| 对于路径中的任意中间节点 $v$（非起点、非终点），每次“进入”该节点必然会“离开”该节点。这意味着每经过它一次，就会消耗它的 2 个度数。
  42| 
  43| - 如果一个节点度数为 $deg[v]$，它在路径中间被经过了 $deg[v] / 2$ 次（整除）。
  44| - 如果 $deg[v] / 2$ 是偶数，那么 $a_v$ 异或偶数次等于 0（抵消了）。
  45| - 如果 $deg[v] / 2$ 是奇数，那么 $a_v$ 异或奇数次等于 $a_v$（保留）。
  46| 
  47| 特殊情况：起点和终点
  48| 
  49| 起点和终点在序列中会多出现一次（起点的“出发”不消耗“进入”度数，终点的“停止”不消耗“离开”度数）。
  50| 
  51| - **实际贡献次数** = $(deg[v] / 2) + (\text{如果v是起点或终点则+1，否则+0})$。
  52| 
  53| 我们定义一个基础异或和 (Base XOR)：
  54| 
  55| 
  56| 
  57| $$ans = \bigoplus_{i=1}^{N} ( \text{如果 } (deg[i]/2) \text{ 是奇数，则异或 } a_i )$$
  58| 
  59| 接下来分两种情况讨论：
  60| 
  61| #### 情况 1：欧拉回路（所有点度数为偶数）
  62| 
  63| - 此时起点和终点是同一个点，设为 $S$。
  64| - 对于 $S$，它的贡献次数变成了 $(deg[S] / 2) + 1$。
  65| - 相较于基础异或和，只有起点 $S$ 的奇偶性发生了翻转（多异或了一次）。
  66| - **最终结果**：$ans \oplus a_S$。
  67| - **贪心策略**：因为是回路，我们可以从任意一个点出发。为了让结果最大，我们遍历图中所有点，计算 $ans \oplus a_i$，取最大值即可。
  68| 
  69| #### 情况 2：欧拉路径（恰好 2 个奇度数点）
  70| 
  71| - 设这两个奇度数点为 $U$和 $V$。路径必须从其中一个开始，到另一个结束。
  72| - 对于起点 $U$，贡献次数为 $(deg[U] / 2) + 1$（翻转）。
  73| - 对于终点 $V$，贡献次数为 $(deg[V] / 2) + 1$（翻转）。
  74| - **最终结果**：$ans \oplus a_U \oplus a_V$。
  75| - **策略**：路径端点固定，结果唯一。
  76| 
  77| ------
  78| 
  79| ### 解题步骤总结
  80| 
  81| 1. **连通性检查**：
  82|    - 使用**并查集 (DSU)**。遍历所有边，合并集合。
  83|    - 统计有多少个并查集根节点（只统计度数 > 0 的节点）。如果根节点数量 > 1，说明图不连通，输出 "Impossible"。
  84| 2. **度数统计**：
  85|    - 统计每个节点的度数 $deg[i]$。
  86|    - 统计度数为奇数的节点个数 $cnt$。
  87| 3. **计算基础异或和**：
  88|    - 遍历所有节点 $i$，如果 `(deg[i] / 2) % 2 == 1`，则 `ans ^= a[i]`。
  89| 4. **分类输出**：
  90|    - **如果 cnt == 0** (欧拉回路)：遍历所有节点 $i$，求 `max(ans ^ a[i])`。
  91|    - **如果 cnt == 2** (欧拉路径)：找到两个奇度数点 $u, v$，输出 `ans ^ a[u] ^ a[v]`。
  92|    - **其他情况**：输出 "Impossible"。
  93| 
  94| ### 复杂度分析
  95| 
  96| - **时间复杂度**：$O(N + M)$。并查集和度数统计都是线性的。
  97| - **空间复杂度**：$O(N)$，用于存储并查集和度数数组。

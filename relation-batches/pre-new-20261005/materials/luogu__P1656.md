   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给一张无向连通图，要求找出所有满足下面条件的边：
  14| 
  15| - 删除这条边后，图会变得不连通
  16| 
  17| 题目把这样的边叫做 `key road`。
  18| 
  19| 输出所有这样的边，按端点从小到大、再按字典序排序。
  20| 
  21| #### 样例图
  22| 
  23| 这张图把样例画成无向图：
  24| 
  25| ```dot
  26| graph G {
  27|   1 -- 2;
  28|   2 -- 3;
  29|   2 -- 4;
  30|   3 -- 5;
  31|   4 -- 5;
  32|   5 -- 6;
  33| }
  34| ```
  35| 
  36| 从图中可以看到：
  37| 
  38| - 删掉 `1-2` 后，点 `1` 会被单独隔开
  39| - 删掉 `5-6` 后，点 `6` 会被单独隔开
  40| 
  41| 所以答案是：
  42| 
  43| `1 2`
  44| 
  45| `5 6`
  46| 
  47| ### 思路
  48| 
  49| 先看一个最直接的小数据暴力：
  50| 
  51| @include-code(./brute.cpp, cpp)
  52| 
  53| 暴力做法很直观：
  54| 
  55| 1. 枚举每一条边
  56| 2. 假装把它删掉
  57| 3. 重新做一次 DFS/BFS 看图是否还连通
  58| 
  59| 这个方法好理解，但每删一条边都要重跑一遍搜索，总复杂度太高。
  60| 
  61| 正式做法就是 Tarjan 求桥。
  62| 
  63| 对每个点维护：
  64| 
  65| - `dfn[u]`：点 `u` 的 DFS 访问次序
  66| - `low[u]`：从 `u` 出发，沿 DFS 树边向下走、再最多走一条返祖边，能回到的最早时间戳
  67| 
  68| 设在 DFS 树里有一条树边 `u -> v`。
  69| 
  70| 如果：
  71| 
  72| `low[v] > dfn[u]`
  73| 
  74| 说明从 `v` 这棵子树出发，完全没有办法绕路回到 `u` 或 `u` 的祖先。
  75| 那么一旦删掉边 `u-v`，`v` 这整棵子树就和外部断开了，所以它就是桥。
  76| 
  77| 反过来，如果：
  78| 
  79| `low[v] <= dfn[u]`
  80| 
  81| 说明 `v` 子树里至少还能通过某条返祖边绕回去，那么删掉 `u-v` 后图仍然连通，这条边不是桥。
  82| 
  83| 这类题写代码时还有一个细节：
  84| 
  85| - 不要只写 `v != fa` 来跳过父边
  86| 
  87| 因为无向图里可能有重边。更稳妥的写法是记录“进入当前点的是哪一条边”，遍历时只跳过它的反向边。这样即使两个点之间有多条边，也不会误判桥。

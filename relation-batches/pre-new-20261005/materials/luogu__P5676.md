   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 有 `N` 个游戏。
  14| 
  15| - 第 `i` 个游戏的“看上去有趣程度”是 `w_i`
  16| - 玩完它以后，兴奋程度会变成 `e_i`
  17| 
  18| 小 z 只会玩那些满足下面条件的游戏：
  19| 
  20| - 当前兴奋程度 `x` 能整除这个游戏的 `w_i`
  21| 
  22| 初始兴奋程度是 `1`。
  23| 
  24| 问有多少个游戏“有可能被玩两次”。
  25| 
  26| 这里的“可能”表示：
  27| 
  28| - 存在某种选择顺序
  29| - 让这个游戏在整条序列中出现至少两次
  30| 
  31| #### 样例图
  32| 
  33| 用样例二来画状态转移图更直观。  
  34| 样例二的 5 个游戏是：
  35| 
  36| - `w = [2, 3, 5, 35, 21]`
  37| - `e = [7, 11, 7, 3, 2]`
  38| 
  39| 这张图展示“玩完一个游戏后，下一步还能选哪些游戏”：
  40| 
  41| ```dot
  42| digraph G {
  43|   1 -> 5;
  44|   3 -> 5;
  45|   4 -> 2;
  46|   4 -> 5;
  47|   5 -> 4;
  48| }
  49| ```
  50| 
  51| 其中 `2,4,5` 之间能绕成环，所以它们可能被再次玩到。
  52| 而 `1`、`3` 虽然能走出去，但回不来，所以不能玩第二次。
  53| 
  54| ### 思路
  55| 
  56| 先看一个最直接的小数据图论版：
  57| 
  58| @include-code(./brute.cpp, cpp)
  59| 
  60| `brute.cpp` 的想法是：
  61| 
  62| 1. 把每个游戏看成一个点
  63| 2. 如果玩完游戏 `i` 后，兴奋值 `e_i` 能整除 `w_j`，就连边 `i -> j`
  64| 3. 某个游戏能玩两次，当且仅当它所在的图里存在回路能回到自己
  65| 
  66| 所以在这个“游戏图”里，答案就是：
  67| 
  68| - 处在非平凡强连通分量里的点
  69| - 或者自己有自环的点
  70| 
  71| 这个建模是对的，但如果直接建游戏图，边数最坏可能是 $O(n^2)$，撑不住。
  72| 
  73| 关键优化是：  
  74| 后续能选什么游戏，只和“当前兴奋程度”有关，和你刚才玩的是哪个游戏无关。
  75| 
  76| 于是把点改成“兴奋值”会更自然：
  77| 
  78| - 图上的一个点表示某个可能出现的兴奋值
  79| - 如果当前兴奋值是 `x`，存在某个游戏满足 `x | w_i`，且玩完后兴奋值变成 `e_i`
  80| - 那么就在值图里连边 `x -> e_i`
  81| 
  82| 现在考虑某个具体游戏 `i` 什么时候能玩两次。
  83| 
  84| 第一次玩完它以后，兴奋值会变成 `e_i`。  
  85| 如果以后还能再次玩到它，说明中间经过若干步后，当前兴奋值一定变成了某个 `x`，并且：
  86| 
  87| - `x` 能整除 `w_i`
  88| 
  89| 这样才能再次选择游戏 `i`。
  90| 
  91| 所以游戏 `i` 能玩两次，当且仅当：
  92| 
  93| - 从值 `e_i` 出发，能够走到某个整除 `w_i` 的值 `x`
  94| 
  95| 而一旦有这样的 `x`，由于“再次玩游戏 `i`”本身就对应一条边 `x -> e_i`，所以：
  96| 
  97| - `x` 和 `e_i` 一定在同一个强连通分量里
  98| 
  99| 于是判定条件就变成了：
 100| 
 101| - 枚举 `w_i` 的所有约数里，哪些本身是某个出现过的兴奋值
 102| - 只要其中有一个约数值和 `e_i` 属于同一个 SCC，游戏 `i` 就能玩两次
 103| 
 104| 这样我们只需要在“不同兴奋值个数”这层图上跑一次 SCC，复杂度就降下来了。

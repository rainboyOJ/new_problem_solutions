  11| ## 题目解析
  12| 
  13| 求最多不相交区间的数量
  14| 
  15| 这是一个非常经典的算法题目，属于**贪心算法（Greedy Algorithm）中的区间调度问题（Interval Scheduling Problem）**。
  16| 
  17| 这道题的核心在于：如何在有限的时间内，尽可能多地安排互不冲突的活动。
  18| 
  19| 以下是对这道题目的详细解析、解题思路以及参考代码。
  20| 
  21| ------
  22| 
  23| ### 1. 题目核心分析
  24| 
  25| - **目标**：选择尽可能多的节目（区间）。
  26| - **约束**：节目之间不能重叠（即上一个节目的结束时间 $\leqslant$ 下一个节目的开始时间）。
  27| - **输入**：$n$ 个节目，每个都有开始时间 $T_s$ 和结束时间 $T_e$。
  28| 
  29| ### 2. 为什么是“贪心”？
  30| 
  31| 我们需要制定一个简单的规则（贪心策略），每次都做出当前看起来最好的选择，从而达到全局最优。对于这道题，我们有几种直觉上的策略，但只有一种是正确的：
  32| 
  33| 1. **策略一（错误）：优先选开始时间最早的。**
  34|    - *反例*：如果有一个节目从 0:00 播到 24:00，选了它就不能看其他任何节目了，但这显然不是最优解。
  35| 2. **策略二（错误）：优先选持续时间最短的。**
  36|    - *反例*：节目A [1, 5], 节目B [4, 7], 节目C [6, 10]。B最短（3小时），选了B就不能选A和C（结果为1）。但实际上选A和C能看2个节目。
  37| 3. **策略三（正确）：优先选结束时间最早的。**
  38|    - *原理*：**结束得越早，留给后面节目的时间资源就越多。** 只要这个节目能看（和前一个不冲突），我们就选结束时间最早的那个，这样能最大程度地保留后续空间。
  39| 
  40| ### 3. 解题步骤
  41| 
  42| 基于“策略三”，我们的算法流程如下：
  43| 
  44| 1. **存储**：将所有节目保存下来，每个节目包含 `start` 和 `end` 两个属性。
  45| 2. **排序**：按照**结束时间 ($T_e$) 从小到大**对所有节目进行排序。如果结束时间相同，开始时间早晚无所谓（或者按开始时间降序也可以，不影响计数）。
  46| 3. **选择**：
  47|    - 初始化计数器 `count = 1`（默认选第一个排序后的节目）。
  48|    - 记录变量 `last_end` 为第一个节目的结束时间。
  49|    - 从第 2 个节目开始遍历：
  50|      - 如果当前节目的 **开始时间 ($T_s$) $\geqslant$ `last_end`**：说明这个节目可以完整看完。
  51|      - 执行操作：`count++`，并将 `last_end` 更新为当前节目的结束时间。
  52|      - 否则：跳过该节目（因为它和上一个选中的节目冲突了）。
  53| 4. **输出**：打印 `count`。
  54| 
  55| 
  56| ### 4. 复杂度分析
  57| 
  58| - **时间复杂度**：主要消耗在排序上。对于 $n$ 个节目，使用 `std::sort` 的复杂度是 $O(N \log N)$。遍历过程是 $O(N)$。所以总时间复杂度是 **$O(N \log N)$**。
  59| - **空间复杂度**：需要存储 $n$ 个节目，复杂度为 **$O(N)$**。
  60| 
  61| ### 6. 示例演示
  62| 
  63| 假设输入是 Sample 中的前几个数据（手动演示逻辑）：
  64| 
  65| 数据：1 3, 3 4, 0 7, 3 8
  66| 
  67| 1. **排序**（按结束时间）：
  68|    - `1 3` (结束 3)
  69|    - `3 4` (结束 4)
  70|    - `0 7` (结束 7)
  71|    - `3 8` (结束 8)
  72| 2. **遍历**：
  73|    - 选第1个 `1 3`：`count` = 1, `last_end` = 3。
  74|    - 看第2个 `3 4`：开始时间 3 $\geqslant$ `last_end` 3。符合条件！
  75|      - 选它：`count` = 2, `last_end` = 4。
  76|    - 看第3个 `0 7`：开始时间 0 < `last_end` 4。冲突，跳过。
  77|    - 看第4个 `3 8`：开始时间 3 < `last_end` 4。冲突，跳过。
  78| 3. **结果**：2。

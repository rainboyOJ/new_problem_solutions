  11| ## 题目解析
  12| 
  13| > 有向图的欧拉路径（Eulerian Path）存在性判定
  14| 
  15| 这个问题实际上是一个经典的图论问题。我们可以将问题进行如下建模：
  16| 
  17| 1. **节点 (Nodes)**: 将26个小写英文字母 ('a' 到 'z') 看作图中的节点。
  18| 2. **有向边 (Directed Edges)**: 每一个单词看作一条有向边。单词的首字母是边的起点，尾字母是边的终点。例如，单词 "acm" 可以看作一条从节点 'a' 指向节点 'm' 的有向边。
  19| 
  20| 问题的目标:
  21| 
  22| 题目要求我们判断是否能将所有给定的单词（边）按顺序排列，使得前一个单词的尾字母等于后一个单词的首字母，并且所有单词都必须恰好被使用一次。
  23| 
  24| 转化到图论语言，这就是要求我们在构建的有向图中找到一条路径，这条路径**恰好经过图中所有的边一次**。这就是著名的 **欧拉路径 (Eulerian Path)** 问题。如果这条路径的起点和终点是同一个节点，则称为 **欧拉回路 (Eulerian Circuit)**。
  25| 
  26| ### 欧拉路径存在的充分必要条件（有向图）
  27| 
  28| 对于一个有向图，存在欧拉路径的条件有两个：
  29| 
  30| 条件 1：连通性 (Connectivity)
  31| 
  32| 忽略边的方向后，图中所有度数不为0的节点必须属于同一个连通分量。简单来说，就是所有出现过的字母必须能“串”在一起，不能出现几个单词自成一派，和别的单词完全搭不上边的情况。
  33| 
  34| 例如：单词组 {"ab", "bc"} 和 {"xy", "yz"}。虽然它们内部可以连接，但这两组之间无法连接，所以不行。
  35| 
  36| 条件 2：度数限制 (Degree Constraints)
  37| 
  38| 我们需要统计每个节点（字母）的入度 (In-degree) 和 出度 (Out-degree)。
  39| 
  40| - 入度：有多少个单词以该字母结尾。
  41| - 出度：有多少个单词以该字母开头。
  42| 
  43| 有向图存在欧拉路径，当且仅当满足以下两种情况之一：
  44| 
  45| 1. **欧拉回路情况**：所有节点的入度等于出度。
  46| 2. **欧拉路径情况**：
  47|    - 恰好有一个节点，其 出度 = 入度 + 1 (这个点是路径起点)。
  48|    - 恰好有一个节点，其 入度 = 出度 + 1 (这个点是路径终点)。
  49|    - 其余所有节点的 入度 = 出度。
  50| 
  51| 如果在这两种情况之外（例如，某个点的入度和出度差值大于1，或者有多个起点的特征），则不存在欧拉路径。
  52|

  55| ### 算法实现步骤
  56| 
  57| 我们可以使用以下步骤来解决这个问题：
  58| 
  59| 1. **数据结构准备**:
  60|    - `in[26]` 和 `out[26]` 数组：分别存储 'a'-'z' 的入度和出度。
  61|    - `present[26]` 布尔数组：标记哪些字母在单词中出现过。
  62|    - **并查集 (Disjoint Set Union, DSU)**：用于高效判断图的连通性。我们需要一个 `parent[26]` 数组。
  63| 2. **处理输入**:
  64|    - 对于每组数据的 $N$ 个单词，进行遍历。
  65|    - 对于每个单词，找到其首字母 `u` 和尾字母 `v`。
  66|    - 更新度数：`out[u]++`, `in[v]++`。
  67|    - 标记出现：`present[u] = true`, `present[v] = true`。
  68|    - 维护连通性：在并查集中合并 `u` 和 `v` 所在的集合 (`union(u, v)`)。
  69| 3. **验证条件**:
  70|    - **验证连通性**: 遍历 `present` 数组。统计对于所有出现过的字母，它们在并查集中是否都有同一个根节点（即属于同一个集合）。如果出现过的字母分属不同的集合，则不连通，输出不可行。
  71|    - **验证度数**: 遍历 26 个字母。
  72|      - 统计满足 `out[i] == in[i] + 1` 的节点数，记为 `start_nodes`。
  73|      - 统计满足 `in[i] == out[i] + 1` 的节点数，记为 `end_nodes`。
  74|      - 如果发现任何节点 `abs(out[i] - in[i]) > 1`，则直接输出不可行。
  75|    - 最后判断：如果 `(start_nodes == 1 && end_nodes == 1)` 或者 `(start_nodes == 0 && end_nodes == 0)`，则输出可行，否则不可行。

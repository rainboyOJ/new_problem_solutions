  11| ## 题目解析
  12| 
  13| 
  14| > 就是01背包,直接来
  15| 
  16| 这也是一道非常经典的**动态规划 (DP)** 题目，它的学名叫做 **“0/1 背包问题” (0/1 Knapsack Problem)**。
  17| 
  18| ## 1. 题目分析
  19| 
  20| - **问题模型**：你有一个容量有限的容器（背包/袋子），面前有一堆物品，每个物品都有自己的**体积**（消耗的成本）和**价值**（获得的收益）。
  21| 
  22| - **规则**：对于每一个骨头，你只有两种选择：
  23| 
  24|   1. **拿走 (1)**：占用背包体积，获得价值。
  25| 
  26|   2. 不拿 (0)：不占用体积，没有价值。
  27| 
  28|      （注：不能把骨头切开拿一半，也不能重复拿同一个骨头，这就是为什么叫 "0/1" 背包）。
  29| 
  30| - **目标**：在不超过背包总容量 $V$ 的前提下，让装入的骨头总价值最大。
  31| 
  32| ## 2. 核心思路
  33| 
  34| 如果要用暴力枚举（拿或不拿），复杂度是 $2^N$。当 $N=1000$ 时，这个数字大得宇宙都装不下。所以必须用动态规划。
  35| 
  36| 我们定义一个数组 dp。
  37| 
  38| $dp[j]$ 的含义是：当背包容量为 $j$ 时，能获得的最大价值。
  39| 
  40| ### 状态转移方程
  41| 
  42| 当我们面对第 $i$ 块骨头时（设它的体积是 $c$，价值是 $w$），对于当前的容量 $j$，我们怎么选？
  43| 
  44| 
  45| 
  46| $$dp[j] = \max(dp[j], \quad dp[j - c] + w)$$
  47| 
  48| 这个公式的意思是：
  49| 
  50| - **$dp[j]$ (不拿)**：我不拿这块骨头，那么最大价值就维持之前的状态，即容量为 $j$ 时的旧值。
  51| - **$dp[j - c] + w$ (拿)**：我决定拿这块骨头。前提是我必须给它腾出 $c$ 的空间。那么我就要找“容量为 $j-c$ 时的最大价值”，加上当前这块骨头的价值 $w$。
  52| - **$\max$**：在这两种选择中，谁大我就选谁。
  53| 
  54| ## 3. 关键技巧：一维数组优化
  55| 
  56| 为了节省空间，我们通常使用一维数组。但在使用一维数组解决 0/1 背包问题时，**内层循环必须从大到小（倒序）遍历**。
  57| 
  58| - 为什么要倒序？
  59| 
  60|   如果从小到大遍历（例如 $j$ 从 $c$ 到 $V$），当我们计算 $dp[j]$ 时，用到的 $dp[j-c]$ 可能已经是“放入了当前物品”之后的新值了。这就导致一个物品被放入了多次（变成了“完全背包问题”）。
  61| 
  62|   倒序遍历（$j$ 从 $V$ 到 $c$）能保证我们在计算 $dp[j]$ 时，引用到的 $dp[j-c]$ 还是上一轮（即没放当前物品前）的状态。
  63| 
  64| ## 4. 代码实现 (C++)
  65| 
  66| 注意：题目输入中，**第二行是价值，第三行是体积**。写代码时读取顺序不要搞反。
  67| 
  68| 
  69| ```cpp
  70| #include <iostream>
  71| #include <vector>
  72| #include <cstring> // for memset
  73| #include <algorithm> // for max
  74| 
  75| using namespace std;
  76| 
  77| // 全局变量定义，N和V最大为1000
  78| const int MAXV = 1005; 
  79| int dp[MAXV]; 
  80| int values[MAXV];
  81| int volumes[MAXV];
  82| 
  83| void solve() {
  84|     int N, V;
  85|     cin >> N >> V;
  86| 
  87|     // 清空 DP 数组，因为有多个测试用例
  88|     // 将 dp 数组全部初始化为 0
  89|     memset(dp, 0, sizeof(dp));
  90| 
  91|     // 读取价值 (题目说第二行是价值)
  92|     for (int i = 1; i <= N; ++i) {
  93|         cin >> values[i];
  94|     }
  95| 
  96|     // 读取体积 (题目说第三行是体积)
  97|     for (int i = 1; i <= N; ++i) {
  98|         cin >> volumes[i];
  99|     }
 100| 
 101|     // 核心算法：0/1 背包
 102|     for (int i = 1; i <= N; ++i) { // 遍历每一个骨头
 103|         // 必须倒序遍历容量！从 V 到 volumes[i]
 104|         for (int j = V; j >= volumes[i]; --j) {
 105|             dp[j] = max(dp[j], dp[j - volumes[i]] + values[i]);
 106|         }
 107|     }
 108| 
 109|     cout << dp[V] << endl;
 110| }
 111| 
 112| int main() {
 113|     // 优化输入输出
 114|     ios_base::sync_with_stdio(false);
 115|     cin.tie(NULL);
 116| 
 117|     int T;
 118|     cin >> T;
 119|     while (T--) {
 120|         solve();
 121|     }
 122|     return 0;
 123| }
 124| ```

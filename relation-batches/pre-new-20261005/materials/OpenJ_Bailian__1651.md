  11| ## 题目解析
  12| 
  13| 这道题是一道非常经典的**区间动态规划 (Interval DP)** 题目。
  14| 
  15| > 和 石子合并 这个题目的思路是一样的,从后(时间)往前思想
  16| 
  17| ## 1. 核心思维：逆向思考（最后一张是谁？）
  18| 
  19| 如果顺着想“第一步取哪张卡片”，你会发现之后的局面变得很复杂，因为相邻关系变了。
  20| 
  21| 技巧：我们要倒着想。
  22| 
  23| 假设我们只关注一段区间 [i, j]（即从第 $i$ 张卡片到第 $j$ 张卡片）。
  24| 
  25| 这一段区间最终只会剩下两张卡片：边界 $i$ 和 边界 $j$。
  26| 
  27| 那么，在这一段区间里，肯定有一张卡片 $k$ 是“最后”被取走的。
  28| 
  29| 当我们要取走这最后一张卡片 $k$ 时，它的左边一定是 $i$，右边一定是 $j$（因为 $i$ 和 $j$ 之间的其他卡片都已经被取光了）。
  30| 
  31| 此时取走 $k$ 的得分是：
  32| 
  33| 
  34| 
  35| $$\text{Cost} = A[i] \times A[k] \times A[j]$$
  36| 
  37| ## 2. 动态规划定义
  38| 
  39| 我们定义 $dp[i][j]$ 为：
  40| 
  41| 将第 $i$ 张到第 $j$ 张卡片中间的所有卡片取走（只剩下 $i$ 和 $j$），所需的最小得分。
  42| 
  43| - **目标**：求 $dp[1][N]$。
  44| - **初始条件**：
  45|   - 当 $j = i + 1$ 时（例如第1张和第2张），中间没有卡片可以取，所以 $dp[i][i+1] = 0$。
  46| 
  47| ## 3. 状态转移方程
  48| 
  49| 对于区间 $[i, j]$，我们需要枚举中间的分割点 $k$（$k$ 代表该区间内**最后一张**被取走的卡片，位置在 $i+1$ 到 $j-1$ 之间）。
  50| 
  51| 总代价由三部分组成：
  52| 
  53| 1. 先把 $i$ 到 $k$ 之间的取光的最小代价：$dp[i][k]$
  54| 2. 先把 $k$ 到 $j$ 之间的取光的最小代价：$dp[k][j]$
  55| 3. 最后取走 $k$ 的代价：$A[i] \times A[k] \times A[j]$
  56| 
  57| 公式如下：
  58| 
  59| 
  60| 
  61| $$dp[i][j] = \min_{k=i+1}^{j-1} \{ dp[i][k] + dp[k][j] + A[i] \times A[k] \times A[j] \}$$
  62| 
  63| ## 4. 算法流程 (区间 DP 模板)
  64| 
  65| 区间 DP 的遍历顺序很讲究，通常遵循以下三层循环：
  66| 
  67| 1. **枚举区间长度 (`len`)**：先解决小区间（长度为2, 3...），再解决大区间。
  68| 2. **枚举起点 (`i`)**：确定区间的左端点，算出右端点 $j$。
  69| 3. **枚举分割点 (`k`)**：尝试每一个可能的最后一张卡片。
  70| 
  71| ## 5. 图解演示
  72| 
  73| 假设输入为：10 1 50 20 ($N=4$)
  74| 
  75| 目标是求 $dp[1][4]$。
  76| 
  77| **第一轮：长度 len=3 (中间隔1个数)**
  78| 
  79| - **区间 [1, 3] (即 10, 1, 50)**：
  80|   - 中间只能取 $k=2$ (也就是数字1)。
  81|   - 代价 = $10 \times 1 \times 50 = 500$。
  82|   - $dp[1][3] = 500$。
  83| - **区间 [2, 4] (即 1, 50, 20)**：
  84|   - 中间只能取 $k=3$ (也就是数字50)。
  85|   - 代价 = $1 \times 50 \times 20 = 1000$。
  86|   - $dp[2][4] = 1000$。
  87| 
  88| **第二轮：长度 len=4 (中间隔2个数)**
  89| 
  90| - **区间 [1, 4] (即 10, 1, 50, 20)**：
  91|   - **选择 A：最后取 $k=2$ (数字1)**
  92|     - 意味着先搞定右边的 [2, 4] (变成 1和20)，再取1。
  93|     - 代价 = $dp[1][2] + dp[2][4] + (10 \times 1 \times 20)$
  94|     - $= 0 + 1000 + 200 = 1200$。
  95|   - **选择 B：最后取 $k=3$ (数字50)**
  96|     - 意味着先搞定左边的 [1, 3] (变成 10和50)，再取50。
  97|     - 代价 = $dp[1][3] + dp[3][4] + (10 \times 50 \times 20)$
  98|     - $= 500 + 0 + 10000 = 10500$。
  99|   - **比较**：1200 < 10500，所以最优解是 1200。

 101| ## 6. C++ 代码实现
 102| 
 103| 
 104| 
 105| ```cpp
 106| #include <iostream>
 107| #include <vector>
 108| #include <algorithm>
 109| #include <climits> // for INT_MAX
 110| 
 111| using namespace std;
 112| 
 113| const int MAXN = 105;
 114| int arr[MAXN];
 115| int dp[MAXN][MAXN];
 116| 
 117| int main() {
 118|     // 优化IO
 119|     ios_base::sync_with_stdio(false);
 120|     cin.tie(NULL);
 121| 
 122|     int N;
 123|     if (!(cin >> N)) return 0;
 124| 
 125|     for (int i = 1; i <= N; ++i) {
 126|         cin >> arr[i];
 127|     }
 128| 
 129|     // 初始化 DP 数组
 130|     // dp[i][i+1] 默认为 0 (相邻两张卡没法取中间的)
 131|     // 其他初始化为一个很大的数，方便求 min
 132|     for (int i = 1; i <= N; ++i) {
 133|         for (int j = 1; j <= N; ++j) {
 134|             dp[i][j] = 0; 
 135|         }
 136|     }
 137| 
 138|     // 核心代码：区间 DP
 139|     // 1. 枚举区间长度 len。
 140|     // 最小区间包含3张卡片(左、中、右)，长度定义为右下标-左下标
 141|     // len = 2 表示 i 和 i+2 之间有一个数
 142|     for (int len = 2; len < N; ++len) { 
 143|         // 2. 枚举左端点 i
 144|         for (int i = 1; i <= N - len; ++i) {
 145|             int j = i + len; // 计算右端点 j
 146|             
 147|             dp[i][j] = INT_MAX; // 先设为无穷大
 148| 
 149|             // 3. 枚举中间的分隔点 k (即最后被取走的卡片)
 150|             // k 必须在 i 和 j 之间
 151|             for (int k = i + 1; k < j; ++k) {
 152|                 int cost = dp[i][k] + dp[k][j] + arr[i] * arr[k] * arr[j];
 153|                 if (cost < dp[i][j]) {
 154|                     dp[i][j] = cost;
 155|                 }
 156|             }
 157|         }
 158|     }
 159| 
 160|     // 输出从 1 到 N 全部取完的最小代价
 161|     cout << dp[1][N] << endl;
 162| 
 163|     return 0;
 164| }
 165| ```

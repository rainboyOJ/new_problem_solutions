   9| ## 题目解析（原文摘录）
  10| 
  11| ## 1. 题目大意
  12| 
  13| 给定一个无向图（网络），定义 SPF (Single Point of Failure) 节点为：如果删除该节点，会导致剩余网络不再连通（即连通分量增加）。
  14| 
  15| 我们需要：
  16| 
  17| 1. 找出所有的 SPF 节点（即**割点**）。
  18| 2. 计算删除该节点后，剩余的全连通子网（连通分量）数量。
  19| 
  20| ## 2. 核心理论
  21| 
  22| ### 割点 (Articulation Point)
  23| 
  24| 在无向连通图中，若删除节点 $u$ 及其相连的边，图的连通分量数量增加，则 $u$ 为割点。
  25| 
  26| ### Tarjan 算法基础
  27| 
  28| 利用 DFS 生成树维护两个核心数组：
  29| 
  30| - **`dfn[u]`**：节点 $u$ 被访问的时间戳。
  31| - **`low[u]`**：节点 $u$ 通过**DFS 树边**或**返祖边**（不经过父节点）所能追溯到的最小时间戳。
  32| 
  33| 判定法则：
  34| 
  35| 对于边 $u \to v$（$u$ 是 $v$ 的父节点）：
  36| 
  37| 若 low[v] >= dfn[u]，说明 $v$ 及其子树无法回到 $u$ 的祖先，必须经过 $u$，因此 $u$ 是割点。
  38| 
  39| ------
  40| 
  41| ## 方法一：直接 Tarjan 判定法 (经典解法)
  42| 
  43| 这种方法直接在 DFS 过程中统计分量变化，空间极小，逻辑紧凑。
  44| 
  45| ### 算法逻辑
  46| 
  47| 我们用 `subnet_cnt[u]` 记录删除 $u$ 后产生的连通块数量。
  48| 
  49| 1. **根节点 (Root)**：
  50| - 在 DFS 树中，根节点每有一个“DFS 树子节点”（即 `!dfn[v]` 进入的分支），就是一个独立的连通块。
  51| - 若子节点数 $\geqslant 2$，则根是割点。
  52| - **子网数** = DFS 树中实际子节点的数量。
  53| 2. **非根节点 (Non-Root)**：
  54| - 每发现一个子节点 $v$ 满足 `low[v] >= dfn[u]`，说明切断 $u$ 后，$v$ 所在分支会掉落，`subnet_cnt` 加 1。
  55| - 除了掉落的子树外，**$u$ 的父节点方向**还连着一大块网络。只要 $u$ 切断了任意一个子节点，父节点方向的那块也算作一个独立的剩余子网。
  56| - **子网数** = (满足条件的子节点数) + 1。
  57|

  65| ## 方法二：v-BCC 分解法 (结构化解法)
  66| 
  67| 这种方法基于**点双连通分量 (v-BCC)** 的定义。它更加抽象，但能揭示图的内部结构（即圆方树的雏形）。
  68| 
  69| ### 算法逻辑
  70| 
  71| 1. **v-BCC 定义**：极大的不包含割点的子图（任意两点间至少有两条不相交路径）。
  72| 2. **割点与 BCC 的关系**：
  73| - 割点是多个 v-BCC 的“公共交点”。
  74| - 如果把每个 BCC 想象成一个“房间”，割点就是连接不同房间的“门”。
  75| 3. **计算子网数**：
  76| - 统计每个点 $u$ 出现在了多少个不同的 BCC 中。
  77| - $Count(u) =$ 包含 $u$ 的 BCC 数量。
  78| - 如果 $Count(u) > 1$，则 $u$ 是割点，且删除 $u$ 后，这 $Count(u)$ 个 BCC 会散开成为独立的连通块。
  79|

  85| /*
  86| * 方法二：v-BCC 分解法
  87| * 优点：结构清晰，根节点无需特殊逻辑，适用于后续构建圆方树
  88| * 核心：统计每个点属于多少个 BCC
  89| */

  91| #include <vector>
  92| #include <algorithm>
  93| #include <cstring>
  94| #include <stack>
  95| 
  96| // ... Edge 结构体同上 ...
  97| // ... add_edge 函数同上 ...

  99| struct TarjanBCC {
 100|  int n, timer;
 101|  std::stack<int> st;
 102|  int dfn[maxn], low[maxn];
 103|  int bcc_cnt; 
 104|  std::vector<int> bcc[maxn]; // 存储每个 BCC 中的点
 105| 
 106|  void set(int _n) {
 107|      n = _n;
 108|      timer = bcc_cnt = 0;
 109|      memset(dfn, 0, sizeof(dfn));
 110|      memset(low, 0, sizeof(low));
 111|      while (!st.empty()) st.pop();
 112|      for (int i = 0; i <= n; i++) bcc[i].clear();
 113|  }
 114| 
 115|  void dfs(int u, int fa) {
 116|      dfn[u] = low[u] = ++timer;
 117|      st.push(u);
 118| 
 119|      for (int i = head[u]; i; i = e[i].next) {
 120|          int v = e[i].v;
 121|          if (v == fa) continue;
 122| 
 123|          if (!dfn[v]) {
 124|              dfs(v, u);
 125|              low[u] = std::min(low[u], low[v]);
 126| 
 127|              // 发现 BCC 的闭环条件
 128|              if (low[v] >= dfn[u]) {
 129|                  bcc_cnt++;
 130|                  while (true) {
 131|                      int node = st.top(); st.pop();
 132|                      bcc[bcc_cnt].push_back(node);
 133|                      if (node == v) break;
 134|                  }
 135|                  // u 也是这个 BCC 的一部分
 136|                  bcc[bcc_cnt].push_back(u);
 137|              }
 138|          } else if (dfn[v] < dfn[u]) {
 139|              low[u] = std::min(low[u], dfn[v]);
 140|          }
 141|      }
 142|  }
 143| 
 144|  void solve() {
 145|      for (int i = 1; i <= 1000; i++) {
 146|          if (!dfn[i] && head[i]) dfs(i, 0);
 147|      }
 148|  }
 149| };
 150| 
 151| TarjanBCC solver;
 152| int node_bcc_count[maxn]; // 统计数组
 153| 
 154| int main() {
 155|  // ... 输入读取部分同上 ...
 156|  // ... (在 while 循环内) ...
 157| 
 158|  solver.solve();
 159| 
 160|  // 统计频率
 161|  memset(node_bcc_count, 0, sizeof(node_bcc_count));
 162|  for (int i = 1; i <= solver.bcc_cnt; i++) {
 163|      for (int node : solver.bcc[i]) {
 164|          node_bcc_count[node]++;
 165|      }
 166|  }
 167| 
 168|  // 输出结果
 169|  std::cout << "Network#" << ++case_id << "\n";
 170|  bool has_spf = false;
 171|  for (int i = 1; i <= 1000; i++) {
 172|      // 只要属于超过 1 个 BCC，就是割点
 173|      if (node_bcc_count[i] > 1) { 
 174|          has_spf = true;
 175|          std::cout << "  SPF node " << i << " leaves " << node_bcc_count[i] << " subnets\n";
 176|      }
 177|  }
 178|  // ... 后续输出同上 ...
 179| }

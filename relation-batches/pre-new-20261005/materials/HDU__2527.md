   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题目核心解析
  12| 
  13| 题目要求判断给定字符串经过哈夫曼编码后的**总长度**（所占空间）是否小于等于给定的安全值 $m$。
  14| 
  15| **哈夫曼编码的原理**：
  16| 
  17| 1. **频率越高的字符，编码越短**：为了让总长度最小，出现次数多的字符应该用更少的比特位（bit）表示。
  18| 2. **贪心算法**：每次从所有当前的节点中，找出**权值（频率）最小**的两个节点进行合并，生成一个新的节点（权值为两个子节点之和），直到只剩下一个节点（根节点）。
  19| 3. **计算总长度**：
  20|    - **方法一**：建好树后，$\sum (\text{字符频率} \times \text{该字符在树中的深度})$。
  21|    - **方法二（编程常用）**：在合并过程中，每次合并产生的**新节点的权值之和**，就是最终的加权路径长度（WPL）。
  22| 
  23| ### 算法步骤
  24| 
  25| 1. **统计频率**：遍历字符串，统计每个字符出现的次数。
  26| 2. **使用优先队列**：将所有出现过的字符的频率放入一个**小顶堆**（Min-Priority Queue）。
  27| 3. **模拟合并**：
  28|    - 如果队列中元素个数大于 1：
  29|      - 取出最小的两个数 $a$ 和 $b$。
  30|      - 计算 $sum = a + b$。
  31|      - 将 $sum$ 累加到最终结果 `ans` 中。
  32|      - 将 $sum$ 放回队列。
  33|    - 重复上述步骤。
  34| 4. **特殊情况处理**：如果字符串中只有一种字符（例如 "aaaa"），哈夫曼树只有根节点，通常在竞赛题中，这种情况每个字符至少需要 1 bit，所以长度等于字符串长度。
  35| 5. **比较输出**：判断 `ans <= m`，输出 yes 或 no。
  36| 
  37| ### C++ 代码实现
  38| 
  39| ```cpp
  40| #include <iostream>
  41| #include <string>
  42| #include <vector>
  43| #include <queue>
  44| #include <map>
  45| 
  46| using namespace std;
  47| 
  48| int main() {
  49|     int n;
  50|     // 读取测试组数
  51|     if (cin >> n) {
  52|         while (n--) {
  53|             int m;
  54|             string s;
  55|             cin >> m >> s;
  56| 
  57|             // 1. 统计字符频率
  58|             map<char, int> counts;
  59|             for (char c : s) {
  60|                 counts[c]++;
  61|             }
  62| 
  63|             // 2. 将频率放入小顶堆 (优先队列)
  64|             // priority_queue 默认是大顶堆，使用 greater<int> 变为小顶堆
  65|             priority_queue<int, vector<int>, greater<int>> pq;
  66|             for (auto const& [key, val] : counts) {
  67|                 pq.push(val);
  68|             }
  69| 
  70|             long long ans = 0;
  71| 
  72|             // 3. 特殊情况：如果只有一种字符 (例如 "aaaa")
  73|             // 队列里只有一个元素 4，循环不会执行，ans 为 0
  74|             // 但实际上一串字符至少占用 字符串长度 的位 (每个字符1位)
  75|             if (pq.size() == 1) {
  76|                 ans = s.length();
  77|             }
  78| 
  79|             // 4. 标准哈夫曼合并过程
  80|             while (pq.size() > 1) {
  81|                 int a = pq.top(); 
  82|                 pq.pop();
  83|                 int b = pq.top(); 
  84|                 pq.pop();
  85| 
  86|                 int sum = a + b;
  87|                 ans += sum; // 累加合并代价
  88|                 pq.push(sum); // 新节点入队
  89|             }
  90| 
  91|             // 5. 输出结果
  92|             if (ans <= m) {
  93|                 cout << "yes" << endl;
  94|             } else {
  95|                 cout << "no" << endl;
  96|             }
  97|         }
  98|     }
  99|     return 0;
 100| }
 101| ```

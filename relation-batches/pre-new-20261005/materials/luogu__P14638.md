   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给定长度为 `n` 的序列 `a`。每次询问给出长度范围 `[L,R]`。
  14| 
  15| 对每个位置 `i`，令 `k_i` 表示所有包含 `i`、且长度在 `[L,R]` 内的子区间中，区间和的最大值。
  16| 
  17| 样例输出对应的聚合方式是：
  18| 
  19| ```text
  20| (1*k_1) xor (2*k_2) xor ... xor (n*k_n)
  21| ```
  22| 
  23| 使用 unsigned 64 位输出。
  24| 
  25| ### 思路
  26| 
  27| 先看一个可以直接验证想法的朴素解：
  28| 
  29| @include-code(./brute.cpp, cpp)
  30| 
  31| 暴力会对每个位置枚举所有包含它的区间，检查长度并取最大区间和。这个做法清楚，但单个询问就可能达到二次复杂度。
  32| 
  33| 设前缀和为：
  34| 
  35| ```text
  36| s[0] = 0
  37| s[i] = a[1] + ... + a[i]
  38| ```
  39| 
  40| 区间 `[l,r]` 可以写成前缀坐标：
  41| 
  42| ```text
  43| x = l - 1, y = r
  44| sum(l,r) = s[y] - s[x]
  45| ```
  46| 
  47| 它包含位置 `i`，并且长度在 `[L,R]` 内，等价于：
  48| 
  49| ```text
  50| x < i <= y
  51| L <= y - x <= R
  52| ```
  53| 
  54| 所以对固定 `i`，问题是在一个梯形区域里最大化 `s[y] - s[x]`。
  55| 
  56| 代码把这个梯形拆成几个可以快速处理的块：
  57| 
  58| - 固定 `x` 后，`y` 的范围是一段区间，用 ST 表查询 `max s[y]`，再用单调队列维护当前位置可用的 `x`；
  59| - 固定 `y` 的块类似，用 ST 表查询 `min s[x]`；
  60| - 中间块中，`x` 和 `y` 的范围可以分开，答案就是 `max s[y] - min s[x]`。
  61| 
  62| 这样每个询问只需要线性扫描若干遍数组。

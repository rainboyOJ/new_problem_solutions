   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 每头奶牛挤奶都要花一定时间，同时还给出若干条先后约束：如果有一条 `A -> B`，就表示必须先把 `A` 完全挤完，才能开始挤 `B`。
  14| 
  15| 题目里有很多工人，所以不受“机器数量”限制。也就是说，只要一头奶牛的所有前置任务都做完了，它就可以立刻开始。
  16| 
  17| 问：满足这些先后约束的前提下，最少多久能把所有奶牛都挤完。
  18| 
  19| #### 样例图
  20| 
  21| 这张图把样例中的依赖关系和每头奶牛的耗时画出来：
  22| 
  23| ```dot
  24| digraph G {
  25|   rankdir=LR;
  26|   1 [label="1\n10"];
  27|   3 [label="3\n6"];
  28|   2 [label="2\n5"];
  29|   3 -> 2;
  30| }
  31| ```
  32| 
  33| 奶牛 `1` 和 `3` 一开始都没有前置任务，所以可以同时开始。
  34| 其中 `1` 单独完成需要 `10`，而 `3 -> 2` 这一条依赖链总耗时是 `6 + 5 = 11`。
  35| 因此最后答案不是把所有时间相加，而是看哪一条依赖链最慢。
  36| 
  37| ### 思路
  38| 
  39| 先看一个小数据暴力：
  40| 
  41| @include-code(./brute.cpp, cpp)
  42| 
  43| 这个暴力直接枚举“以某头奶牛结尾的依赖链”，递归去找它所有前驱里最慢的那一条，再加上当前奶牛自己的耗时。
  44| 
  45| 如果定义 `f(i)` 表示“完成第 `i` 头奶牛的最早结束时间”，那么就有：
  46| 
  47| - 如果 `i` 没有前驱，`f(i) = T[i]`
  48| - 如果 `i` 有前驱，`f(i) = max(f(pre)) + T[i]`
  49| 
  50| 这说明题目本质上就是：
  51| 
  52| - 点权是挤奶时间
  53| - 边表示先后依赖
  54| - 要求 DAG 上的最长路径
  55| 
  56| 直接递归会反复算很多相同子问题，所以正式做法改成拓扑排序 + DP。
  57| 
  58| 做法如下：
  59| 
  60| 1. 把每头奶牛看成一个点，约束 `u -> v` 建成有向边。
  61| 2. 先用 Kahn 算法求一个拓扑序。
  62| 3. 设 `dp[i]` 表示完成第 `i` 头奶牛的最早结束时间。
  63| 4. 初始时令 `dp[i] = T[i]`。
  64| 5. 按拓扑序枚举点 `u`，对每条边 `u -> v` 做转移：
  65| 
  66|    `dp[v] = max(dp[v], dp[u] + T[v])`
  67| 
  68| 6. 所有 `dp[i]` 的最大值就是答案。
  69| 
  70| 代码里沿用了算法书里的 `TopologicalSort` 结构：先 `add_edge()` 建图，再 `kahn()` 取拓扑序，最后在这个顺序上做 DP。

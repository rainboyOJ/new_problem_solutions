  11| ## 暴力
  12| 
  13| 暴力可以先写 01 序列：`choose[i] = 0/1` 表示第 `i` 个点不保留或保留。递归先生成完整的 `choose[]`，到叶子节点再检查是否恰好保留 `K` 个点、这些点是否连通；合法时统计当前比值。这种写法复杂度是指数级，只用于小数据理解。
  14| 
  15| ## 1. 题目核心分析
  16| 
  17| 目标：在一棵树上，拆除 $M$ 个点（即保留 $K = N-M$ 个点），要求剩下的点连通，且满足：
  18| 
  19| 
  20| 
  21| $$\text{最大化} \frac{\text{总产值}}{\text{总污染}} = \frac{\sum w_i}{\sum c_i}$$
  22| 
  23| 这道题是两个经典模型的结合：
  24| 
  25| 1. **数学模型**：01 分数规划（处理比值最大化）。
  26| 2. **算法模型**：树上背包 DP（处理树上连通块的最优选法）。
  27| 
  28| ------
  29| 
  30| ## 2. 第一步：数学推导 (01 分数规划)
  31| 
  32| 直接求比值很难，我们换个思路：**二分答案**。
  33| 
  34| 假设我们猜测最终的最大比值是 $x$。
  35| 
  36| 如果存在一种选法，使得 $\frac{\sum w_i}{\sum c_i} \geqslant x$，那么答案可能比 $x$ 更大。
  37| 
  38| 通过移项变形（这是分数规划的套路）：
  39| 
  40| 
  41| 
  42| $$\sum w_i \geqslant x \cdot \sum c_i$$
  43| 
  44| $$\sum w_i - \sum (x \cdot c_i) \geqslant 0$$
  45| 
  46| $$\sum (w_i - x \cdot c_i) \geqslant 0$$
  47| 
  48| 结论：
  49| 
  50| 二分一个 $x$ 后，我们只需要把每个工厂的权值重新定义为 $v_i = w_i - x \cdot c_i$。
  51| 
  52| 问题就变成了$P(x)$：能否在树上找到一个包含 $K$ ($K = n - M$)个节点的连通块，使得新的权值和 $\geqslant 0$？
  53| 
  54| 
  55| 
  56| 这里显然具体二分性
  57| 
  58| - 对于一个 $x$, 如果 $P(x)$ 成立, 则对于$P(x-1)$ 一定也成立
  59|   - 思维模型: 想象 节点$i$ 是一个 高度$w_i$的柱子,$x$ 想象成水位的高度
  60|   - 也可以用数学证明,关系那个最大污染值的 答案集合$A$
  61|     - A 如果在 x 成立,则一定在 $x-1$成立
  62| 
  63| ------

  65| ## 3. 第二步：算法设计 (树上背包 DP)
  66| 
  67| 现在问题简化为：**树上选 $K$ 个连通点求最大权值**。这是一个经典的**树上分组背包**问题（类似于 P2014 选课）。
  68| 
  69| 
  70| 
  71| 这里我来详细的写一下,我是如何理解 **树上选 $K$ 个连通点求最大权值** 是如何进行的DP思路的
  72| 
  73| 
  74| 
  75| 对于一个有根(root)的树, 最终的 **最大权值的$K$ 个连通点** 形成的集合: 
  76| 
  77|  	1. 包含root
  78|      	1.  这个问题就变成了: 把 $K-1$ 名额分配 给孩子$v$的能得到最大值是什么(枚举)
  79|  	2. 不包含root, 那么就是在root的子树上
  80|      	1. 这个问题就变成了 $\max(dp[v][K])$ ,其中 $v$ 是root的孩子	
  81| 
  82| 显然,得益于树的递归结构,孩子的问题依然可以拆分
  83| 
  84| 
  85| 
  86| ### 3.1 状态定义
  87| 
  88| - $dp[u][j]$：在以 $u$ 为根的子树中，选出 $j$ 个点（**必须包含 u 自己**），所能得到的最大权值和。
  89|   - 这种点i,选或不选的,设DP的时候,通常设为一定选
  90|     1.  方便思考
  91|     2.  不选这个节点的情况,被其他问题包含了
  92| - **为什么必须选 u？** 如果不选 $u$，它的子节点就没法和上面的节点连通了，连通性会断裂。
  93| 
  94| ### 3.2 转移方程
  95| 
  96| 我们在处理节点 $u$ 时，把它看作一个背包，它的每一个子节点 $v$ 都是一组物品。
  97| 
  98| - $u$ 初始状态：$dp[u][1] = v_u$ (只选自己)，其余为 $-\infty$。
  99| - 我们要决定给子树 $v$ 分配多少个名额（设为 $k$）。
 100| 
 101| $$dp[u][j] = \max(dp[u][j], \quad dp[u][j-k] + dp[v][k])$$

 105| ## 4. 第三步：代码实现的 3 个关键细节 (易错点)
 106| 
 107| 这是你之前最容易卡住的地方，请仔细阅读：
 108| 
 109| ### 🛑 细节 1：初始化为负无穷
 110| 
 111| 因为 $v_i = w_i - x \cdot c_i$ 可能是负数，且我们要求必须填满 $j$ 个点。如果初始化为 0，程序可能会错误地认为“没选够点权值为0”比“选够了点但权值为负”更优，导致逻辑错误。
 112| 
 113| C++
 114| 
 115| ```
 116| for (int i = 1; i <= K; i++) dp[u][i] = -1e9; // 也就是 -INF
 117| dp[u][1] = w[u] - x * c[u]; // 只有选1个点（自己）是合法的初始状态
 118| ```
 119| 
 120| ### 🛑 细节 2：循环的顺序 (背包的维度)
 121| 
 122| 这是一个分组背包。
 123| 
 124| 1. **第一层**：枚举子节点 $v$（物品组）。
 125| 2. **第二层**：枚举当前背包容量 $j$（**必须倒序！**，防止重复选取）。
 126| 3. **第三层**：枚举分给子树 $v$ 的容量 $k$。

 134| ### 🛑 细节 3：循环的边界 (连通性的保证)
 135| 
 136| 这是最难的一点。
 137| 
 138| 
 139| 
 140| ```cpp
 141| // j 从大到小枚举
 142| // 上限：不能超过 K，也没必要超过当前两棵树的大小之和
 143| for (int j = min(K, sz[u] + sz[v]); j >= 2; j--) {
 144|     
 145|     // k 枚举分给子树 v 的点数
 146|     // 上限 1：k <= sz[v] (子树只有这么大)
 147|     // 上限 2：k <= j - 1 (必须至少留 1 个名额给 u 自己！)
 148|     for (int k = 1; k <= min(sz[v], j - 1); k++) {
 149|         dp[u][j] = max(dp[u][j], dp[u][j-k] + dp[v][k]);
 150|     }
 151| }
 152| ```
 153| 
 154| PS: 可以不优化,这个题目 $N$ 最大100,可以过
 155| 
 156| - $N = 100$。
 157| - 我的代码1复杂度最坏是 $O(N^3)$（其实是 $O(N \cdot K^2)$）。
 158| - 计算量大约是 $100^3 = 1,000,000$ (一百万) 次运算。
 159| - 现在的评测机通常一秒钟能跑 $10^8$ (一亿) 次运算。
 160| 
 161| - **为什么要 `j - 1`？** 如果 $k=j$，意味着把所有名额都给了子树 $v$，那根节点 $u$ 就没名额了。$u$ 不选，$v$ 就断连了。

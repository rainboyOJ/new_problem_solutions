   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给一棵根为 `0` 的树，初始时每个点的果子数都是 `0`。
  14| 
  15| 有两类操作：
  16| 
  17| 1. `A u v d`  
  18|    把路径 `u -> v` 上所有节点的果子数都加上 `d`
  19| 
  20| 2. `Q u`  
  21|    询问当前以 `u` 为根的整棵子树里，一共有多少个果子
  22| 
  23| #### 样例树
  24| 
  25| 样例树是一条链：
  26| 
  27| ```dot
  28| graph G {
  29|   0 -- 1;
  30|   1 -- 2;
  31|   2 -- 3;
  32| }
  33| ```
  34| 
  35| 执行一次 `A 1 3 1` 后：
  36| 
  37| - 点 `1, 2, 3` 各加 `1`
  38| 
  39| 所以：
  40| 
  41| - 子树 `0` 的和是 `3`
  42| - 子树 `1` 的和是 `3`
  43| - 子树 `2` 的和是 `2`
  44| 
  45| ### 思路
  46| 
  47| 先看一个最直接的小数据暴力：
  48| 
  49| @include-code(./brute.cpp, cpp)
  50| 
  51| 暴力做法就是：
  52| 
  53| 1. 真正把路径 `u -> v` 上的每个点都加上 `d`
  54| 2. 查询时再暴力把子树里的点全部加起来
  55| 
  56| 这个做法最贴近题意，但显然扛不住大数据。
  57| 
  58| 这题的关键不是树剖本身，而是先把“路径加”换成“树上差分”。
  59| 
  60| 对于一次路径加 `u, v, d`，设 `p = lca(u, v)`，做：
  61| 
  62| - `diff[u] += d`
  63| - `diff[v] += d`
  64| - `diff[p] -= d`
  65| - `diff[parent(p)] -= d`（如果 `p` 不是根）
  66| 
  67| 这样做完以后，某个点 `x` 当前真正的果子数，等于：
  68| 
  69| - `diff` 在 `x` 子树里的总和
  70| 
  71| 也就是：
  72| 
  73| - `value[x] = sum(diff[y]), y 在 subtree(x)`
  74| 
  75| 现在题目要求的是：
  76| 
  77| - `subtree(u)` 里所有 `value[x]` 的总和
  78| 
  79| 把这个式子再展开一层：
  80| 
  81| `sum_{x in subtree(u)} value[x]`
  82| 
  83| 等于
  84| 
  85| `sum_{y in subtree(u)} diff[y] * (depth[y] - depth[u] + 1)`
  86| 
  87| 原因是：
  88| 
  89| - 一个点 `y` 的差分值，会贡献给它在 `subtree(u)` 里的所有祖先
  90| - 这样的祖先数量正好是 `depth[y] - depth[u] + 1`
  91| 
  92| 于是查询可以改写成：
  93| 
  94| `sum(diff * (depth+1)) - depth[u] * sum(diff)`
  95| 
  96| 这就很适合用 DFS 序来维护：
  97| 
  98| 1. 子树在 DFS 序上是连续区间
  99| 2. 用一棵树状数组维护 `diff`
 100| 3. 再用另一棵树状数组维护 `diff * (depth+1)`
 101| 
 102| 路径加时只做 4 次单点修改。  
 103| 查询子树和时，只要在 `[tin[u], tout[u]]` 上查这两个区间和，再套公式即可。

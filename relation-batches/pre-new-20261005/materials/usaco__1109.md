   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给定若干条由 $N/E/S/W$ 组成的闭合栅栏路径。路径不自交，只在最后回到起点。
  14| 
  15| 判断按字符串顺序沿着栅栏走时，围住的区域在右侧还是左侧；右侧输出 `CW`，左侧输出 `CCW`。
  16| 
  17| ### 思路
  18| 
  19| #### 用有向面积校验
  20| 
  21| 一个常见做法是按路径走出坐标点，再用多边形有向面积判断方向：
  22| 
  23| @include-code(./brute.cpp, cpp)
  24| 
  25| 在通常坐标系下，有向面积为正表示逆时针，为负表示顺时针。
  26| 
  27| #### 累计转角
  28| 
  29| 官方解析的思路是：顺时针路径整体更倾向于右转，逆时针路径整体更倾向于左转。
  30| 
  31| 把方向编号为：
  32| 
  33| ```text
  34| E = 0, N = 1, W = 2, S = 3
  35| ```
  36| 
  37| 相邻两段边形成一个转角：
  38| 
  39| - 左转贡献 `+1`；
  40| - 右转贡献 `-1`；
  41| - 直行贡献 `0`。
  42| 
  43| 沿简单闭合曲线走一圈，如果整体是逆时针，总转角为 $+360^\circ$；如果整体是顺时针，总转角为 $-360^\circ$。
  44| 
  45| 因此只需要比较每一对相邻方向：
  46| 
  47| ```text
  48| s[i] -> s[(i + 1) % len]
  49| ```
  50| 
  51| 最后如果 `total_turn > 0`，输出 `CCW`；否则输出 `CW`。
  52| 
  53| 以 `NESW` 为例：
  54| 
  55| ```text
  56| N -> E 右转
  57| E -> S 右转
  58| S -> W 右转
  59| W -> N 右转
  60| ```
  61| 
  62| 总转角为负，所以是 `CW`。

  11| ## 三点LCA 问题
  12| 
  13| > 这个题目本质 就是求 三个点的 最短路径, 转为求 lca 问题, 然后什么具体怎么呢:那个深度最深的 LCA，就是我们要找的最优集合点 $P$。
  14| 
  15| 这是一个非常深刻的图论直觉问题。把这个问题搞懂，你对树形结构的理解会上升一个层次。
  16| 
  17| ### 核心结论
  18| 
  19| 三个点在树上构成的连通子图，形状一定是一个“Y”字形（或者退化成一条链）。
  20| 
  21| 而那个深度最深的 LCA，正是这个 “Y”字形的分叉点（中心点）。
  22| 
  23| 我们分三步来解析为什么是这样。
  24| 
  25| ------
  26| 
  27| ### 第一步：直觉 —— “Y”字形结构
  28| 
  29| 想象树上的三个点 $x, y, z$。
  30| 
  31| 如果我们把它们两两之间的路径画出来，取并集，它们一定会形成一个类似 **“Y”** 的形状（中间有一个交汇点 $P$），或者是 **“I”** 字形（一条线上，$P$ 重合于某个点）。
  32| 
  33| 为什么集合点一定是这个分叉点 $P$？
  34| 
  35| 我们可以用“投票法”或者“物理重心”来理解：
  36| 
  37| 1. 如果在 $P$ 点集合：$x, y, z$ 各自走对应的分支过来。
  38| 2. 如果你尝试把集合点从 $P$ 向 $x$ 的方向移动一步到 $P'$：
  39|    - 距离 $x$ 近了 1 步（花费 -1）。
  40|    - 距离 $y$ 远了 1 步（花费 +1）。
  41|    - 距离 $z$ 远了 1 步（花费 +1）。
  42|    - **总花费变化**：$-1 + 1 + 1 = +1$。总路程变长了！
  43| 3. 同理，向 $y$ 或 $z$ 移动也会导致总路程变长。
  44| 4. 向上（根方向）移动：通常会同时远离三个点（或其中两个），代价更大。
  45| 
  46| **结论：** 这个“Y”字形的**中心交汇点** $P$，就是全局最优解。
  47| 
  48| ------
  49| 
  50| ### 第二步：LCA 的“二同一异”性质
  51| 
  52| 在有根树中，任意三个点 $x, y, z$ 求两两的 LCA，得到三个点：
  53| 
  54| - $a = LCA(x, y)$
  55| - $b = LCA(y, z)$
  56| - $c = LCA(x, z)$
  57| 
  58| 这三个点一定满足：有两个点是同一个点（较浅），另一个点是不同的点（较深）。
  59| 
  60| （或者特例：三个点全都是同一个点）。
  61| 
  62| 场景模拟：
  63| 
  64| 假设树的根在最上面。
  65| 
  66| - $y$ 和 $z$ 在左边的某个子树里“纠缠”得很深，它们在深处的一个点 $P$ 分叉。
  67|   - 那么 $LCA(y, z) = P$ （深）。
  68| - $x$ 在右边的另一个子树里，或者在很上面的位置。
  69|   - $x$ 要去够到 $y$，必须往上走到很高的“祖宗”节点 $Root'$。所以 $LCA(x, y) = Root'$ （浅）。
  70|   - $x$ 要去够到 $z$，也必须往上走到同一个“祖宗”节点 $Root'$。所以 $LCA(x, z) = Root'$ （浅）。
  71| 
  72| **结果：**
  73| 
  74| - $LCA(x, y)$ 和 $LCA(x, z)$ 都是那个高高在上的 $Root'$。
  75| - 只有 $LCA(y, z)$ 是那个深处的 $P$。
  76| 
  77| ------
  78| 
  79| ### 第三步：为什么选“最深”的那个？
  80| 
  81| 结合第一步和第二步：
  82| 
  83| 1. 我们知道最优集合点是 **“Y”字形的中心 $P$**。
  84| 2. 在有根树的视角下，这个 $P$ 点其实就是 **把这三个点分开的那个最下面的分叉口**。
  85| 
  86| 我们看刚才的例子：
  87| 
  88| - **浅点 ($Root'$)**：这是 $x$ 和 $(y, z)$ 分家的地方。如果在 $Root'$ 集合，$x$ 很高兴，但 $y$ 和 $z$ 需要先走到 $P$，再一起爬到 $Root'$。这显然让 $y$ 和 $z$ 多走了冤枉路（从 $P$ 到 $Root'$ 这段路走了两次）。
  89| - **深点 ($P$)**：这是 $y$ 和 $z$ 分家的地方。如果在 $P$ 集合，$y$ 和 $z$ 只要走到 $P$ 就到了。$x$ 虽然要先走到 $Root'$ 再下来走到 $P$，但这是不可避免的。
  90| - **对比**：选 $P$ 比选 $Root'$ 少走了“$y$ 和 $z$ 共同爬升的那段路”。
  91| 
  92| 数学证明：
  93| 
  94| 假设三个 LCA 分别是 $u, u, v$（其中 $depth[u] < depth[v]$）。
  95| 
  96| - $u$ 是上面那个浅点，$v$ 是下面那个深点。
  97| - $v$ 一定在 $u$ 的子树里。
  98| - 这意味有两个点（比如 $y, z$）在 $v$ 的下面，有一个点（$x$）在 $u$ 的其他分支。
  99| - **如果选 $u$ (浅点)**：代价是 $dist(x, u) + dist(y, u) + dist(z, u)$。
 100|   - 其中 $dist(y, u) = dist(y, v) + dist(v, u)$。
 101|   - 其中 $dist(z, u) = dist(z, v) + dist(v, u)$。
 102|   - 总代价 = $dist(x, u) + dist(y, v) + dist(z, v) + \mathbf{2 \times dist(v, u)}$。
 103| - **如果选 $v$ (深点)**：代价是 $dist(x, v) + dist(y, v) + dist(z, v)$。
 104|   - 其中 $dist(x, v) = dist(x, u) + dist(u, v)$。
 105|   - 总代价 = $dist(x, u) + \mathbf{1 \times dist(u, v)} + dist(y, v) + dist(z, v)$。
 106| 
 107| **显然：** 选 $v$ (深点) 的代价比选 $u$ 少了 $dist(u, v)$。
 108| 
 109| 所以，**那个深度最大的 LCA，就是所有人的“妥协点”，也就是最优集合点。**

 112| ## 1. 题目解析
 113| 
 114| 题目核心：
 115| 
 116| 给定一棵 $N$ 个节点的树，以及 $M$ 次询问。每次询问给出三个点 $x, y, z$，要求在树上找到一个集合点 $P$，使得 $x, y, z$ 到 $P$ 的距离之和最小（即 $dist(x, P) + dist(y, P) + dist(z, P)$ 最小）。输出这个点 $P$ 的编号以及最小距离和。
 117| 
 118| 数学/图论推导：
 119| 
 120| 这就好比三个人在树上要碰头，怎么走最省力？
 121| 
 122| 我们考虑三个点两两之间的 LCA（最近公共祖先）：
 123| 
 124| 1. $a = LCA(x, y)$
 125| 2. $b = LCA(y, z)$
 126| 3. $c = LCA(x, z)$
 127| 
 128| 重要结论：
 129| 
 130| 在树上的任意三个点 $x, y, z$，求出的这三个 LCA ($a, b, c$) 中，必然有两个是相同的，且另一个的深度比这两个更深（或者三个都相同）。
 131| 
 132| 那个深度最深的 LCA，就是我们要找的最优集合点 $P$。
 133| 
 134| - **直观理解**：想象三条路径汇聚成一个“Y”字形或者一条线。三条路径的交汇点就是那个“分叉口”。
 135|   - 如果有两条路径先汇合（比如 $x$ 和 $y$ 在深处汇合），然后再去汇合 $z$，那么 $x,y$ 的 LCA 深度最大，它就是集合点。
 136|   - 如果 $x$ 在 $y$ 到 $z$ 的路径上，那么 $x$ 就是集合点。
 137| 
 138| **算法步骤：**
 139| 
 140| 1. **建树**：使用链式前向星存储。
 141| 2. **LCA 预处理**：计算倍增数组 `f[][]` 和深度 `d[]`。
 142| 3. **处理查询**：
 143|    - 算出 $a = LCA(x, y)$, $b = LCA(y, z)$, $c = LCA(x, z)$。
 144|    - 比较 `d[a]`, `d[b]`, `d[c]`，取深度最大的那个点作为集合点 $P$。
 145|    - 利用公式计算代价：$Cost = dist(x, P) + dist(y, P) + dist(z, P)$。
 146|    - 其中树上距离公式：$dist(u, v) = d[u] + d[v] - 2 \times d[LCA(u, v)]$。

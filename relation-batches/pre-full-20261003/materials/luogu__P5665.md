   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给定正整数序列 `a[1..n]`，要把它划分成若干个连续段，要求每一段的段和非递减。设各段段和为：
  14| 
  15| ```text
  16| s1 <= s2 <= ... <= sk
  17| ```
  18| 
  19| 目标是最小化：
  20| 
  21| ```text
  22| s1^2 + s2^2 + ... + sk^2
  23| ```
  24| 
  25| `type=0` 时直接给出所有 `a_i`；`type=1` 时按题面给出的递推和区间参数生成数据。
  26| 
  27| ### 思路
  28| 
  29| 小数据可以做动态规划：枚举最后一段从哪里开始，再检查它的段和是否不小于上一段。
  30| 
  31| @include-code(./brute.cpp, cpp)
  32| 
  33| 满分做法的关键观察是：所有 `a_i` 都是正数。对于固定前缀 `i`，如果最后一段越短，它的平方贡献越小；因此在满足“上一段段和不超过最后一段段和”的前提下，我们希望最后一段尽量短，也就是上一段结尾尽量靠后。
  34| 
  35| 令：
  36| 
  37| ```text
  38| c[i] = a[1] + a[2] + ... + a[i]
  39| g[i] = 前缀 i 的最优上一段结尾
  40| ```
  41| 
  42| 最后一段是 `(g[i]+1)..i`，段和为：
  43| 
  44| ```text
  45| c[i] - c[g[i]]
  46| ```
  47| 
  48| 为了让它接在 `g[i]` 的最优划分后面，需要满足：
  49| 
  50| ```text
  51| c[g[i]] - c[g[g[i]]] <= c[i] - c[g[i]]
  52| ```
  53| 
  54| 移项得到：
  55| 
  56| ```text
  57| 2*c[g[i]] - c[g[g[i]]] <= c[i]
  58| ```
  59| 
  60| 也就是说，每个候选断点 `t` 有一个关键值：
  61| 
  62| ```text
  63| key(t) = 2*c[t] - c[g[t]]
  64| ```
  65| 
  66| 当 `key(t) <= c[i]` 时，`t` 可以作为前缀 `i` 的上一段结尾。我们要选满足条件且尽量靠后的 `t`。
  67| 
  68| 扫描 `i=1..n` 时，`c[i]` 单调递增；同时可以证明最优候选的 `key` 也适合用单调队列维护。队头给出当前可行且最靠后的断点，队尾则维护候选 `key` 的单调性。
  69| 
  70| 算出所有 `g[i]` 后，从 `n` 沿着 `g[n]`、`g[g[n]]` 往前跳，就得到最优划分的所有段，累加段和平方即可。答案可能超过 `long long`，代码用 `__int128` 输出。

   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 给一棵多叉树，允许任意安排每个结点孩子的顺序，再按左孩子右兄弟表示法转成二叉树。
  14| 
  15| 要求求出：
  16| 
  17| - 所有可能转化结果中
  18| - 二叉树的最大高度
  19| 
  20| ### 思路
  21| 
  22| 先看一个可以直接验证想法的朴素解：
  23| 
  24| @include-code(./brute.cpp, cpp)
  25| 
  26| `brute.cpp` 对每个结点枚举孩子排列，直接按定义求最大高度。
  27| 这个方法完全正确，但只能做很小的数据。
  28| 
  29| 关键观察是：
  30| 
  31| 如果结点 `u` 有 `k` 个孩子，那么某个孩子若排在第 `i` 个位置，它最终对高度的贡献是：
  32| 
  33| `1 + i + dp[child]`
  34| 
  35| 其中：
  36| 
  37| - `1` 来自左孩子边
  38| - `i` 来自它前面那些右兄弟边
  39| 
  40| 所以如果我们想让高度尽量大，显然应该把“子树最高”的那个孩子放到最后。
  41| 
  42| 于是立刻得到转移：
  43| 
  44| - 叶子：`dp[u] = 0`
  45| - 非叶子：`dp[u] = 儿子数 + max(dp[child])`
  46| 
  47| 因为题目保证父亲编号小于儿子编号，所以我们甚至不用 DFS 排序，直接从 `n` 倒着算到 `1` 就行。
  48| 
  49| 样例树可以画成这样：
  50| 
  51| ```dot
  52| graph G {
  53|   1 -- 2;
  54|   1 -- 3;
  55|   1 -- 4;
  56|   2 -- 5;
  57| }
  58| ```
  59| 
  60| 这里根 `1` 有 3 个孩子。
  61| 为了让高度最大，应该把“还带着一个孩子 `5`” 的结点 `2` 放在兄弟链最后。
  62| 这样它能多吃到最多的右兄弟边，所以最终答案是 `4`。

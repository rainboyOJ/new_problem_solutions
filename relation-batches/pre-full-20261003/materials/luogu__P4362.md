   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 把树上的 `N` 个果子分给 `M` 个头，每个头至少分到一个果子。
  14| 
  15| 其中大头必须吃到恰好 `K` 个果子，并包含那一个“最大的果子”。
  16| 
  17| 如果一条边两端的果子分给同一个头，这条边也会被一起吃掉，要付出这条边的难受值；如果两端分给不同的头，这条边会被砍断，代价为 `0`。
  18| 
  19| 要求最小化总难受值。
  20| 
  21| ### 思路
  22| 
  23| 先看一个可以直接验证题意的暴力：
  24| 
  25| @include-code(./brute.cpp, cpp)
  26| 
  27| `brute.cpp` 直接枚举每个点分给哪个头，然后按照题意计算代价。
  28| 它只能处理很小的数据，但很适合对拍。
  29| 
  30| 真正的关键是看清 `M=2` 和 `M>=3` 的区别。
  31| 
  32| 当 `M=2` 时，只有“大头 / 普通头”两种颜色。
  33| 所以一条边只要两端分给同一个头，就一定要付这条边的边权。
  34| 
  35| 当 `M>=3` 时，普通头至少还有两种颜色可用。
  36| 而“不属于大头”的那些点组成的是森林，一定可以二染色。
  37| 于是普通点之间的边总能安排成两端属于不同普通头，代价为 `0`。
  38| 这时只有“两端都给大头”的边才必须计入答案。
  39| 
  40| 所以做树形 DP：
  41| 
  42| - `dp[u][j][0]`：`u` 子树里有 `j` 个点给大头，且 `u` 不给大头的最小代价
  43| - `dp[u][j][1]`：`u` 子树里有 `j` 个点给大头，且 `u` 给大头的最小代价
  44| 
  45| 合并儿子 `v` 时，只需要根据：
  46| 
  47| - `u` 是否给大头
  48| - `v` 是否给大头
  49| - 当前是 `M=2` 还是 `M>=3`
  50| 
  51| 来决定边 `u-v` 是否要把边权加进去。
  52| 
  53| 下面这张图展示“同头付代价、异头不付代价”的规则：
  54| 
  55| ```dot
  56| graph G {
  57|   rankdir=LR;
  58|   A [label="u"];
  59|   B [label="v"];
  60|   A -- B [label="w"];
  61| }
  62| ```
  63| 
  64| 如果两个端点最终被分给同一个头，这条边就会被一起吃掉。
  65| 树形 DP 合并子树时，新增加的跨子树边只有父子这一条，所以状态转移可以写得很干净。
  66| 
  67| 
  68| #### DP 转移方程
  69| 
  70| 核心状态：
  71| 
  72| `dp[u][j][0/1]`
  73| 
  74| 核心转移：
  75| 
  76| `merge += edge_cost(su,sv,w,M)`
  77| 
  78| 答案收束：
  79| 
  80| `min(dp[1][K][0],dp[1][K][1])`

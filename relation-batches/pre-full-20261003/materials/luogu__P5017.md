   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 有 `n` 名同学要坐摆渡车。
  14| 
  15| 第 `i` 位同学会在时刻 `t_i` 到达车站开始等车。
  16| 
  17| 只有一辆车，容量无限。它每次从车站出发，把车上同学送到目的地，再回到车站，完整往返一次需要 `m` 分钟。
  18| 
  19| 车回到车站后可以立刻再次出发。
  20| 
  21| 要求安排每次发车时刻，使得所有同学等待时间之和最小。
  22| 
  23| ### 思路
  24| 
  25| 先看一个适合小数据验证的朴素搜索：
  26| 
  27| @include-code(./brute.cpp, cpp)
  28| 
  29| 暴力会把同学按到达时刻排序，然后枚举每一班车接走哪一段连续同学。
  30| 
  31| 因为同一班车的出发时刻只会取：
  32| 
  33| - 这一班最后一位上车同学的到达时刻
  34| - 或上一班车返回时刻
  35| 
  36| 两者的较大值，所以小数据可以直接搜。
  37| 
  38| 正解的关键是换一个视角。
  39| 
  40| 如果一辆车在时刻 `x` 返回车站，那么它最早要在时刻 `x` 再出发时，实际上能接走的是所有满足：
  41| 
  42| `t_i + m <= x`
  43| 
  44| 的同学。
  45| 
  46| 所以先把每个同学的时刻做一次平移：
  47| 
  48| `a_i = t_i + m`
  49| 
  50| 这样以后所有发车/回程的讨论都可以统一落在“回程时刻”上。
  51| 
  52| 设：
  53| 
  54| `dp[x]` 表示最后一班已经在时刻 `x` 回到车站，并且所有 `a_i <= x` 的同学都已经送走时，最小等待时间和。
  55| 
  56| 如果上一班回程时刻是 `y`，那么下一班最早只能在 `y + m` 时刻之后再次回到车站，也就是：
  57| 
  58| `x - y >= m`
  59| 
  60| 在这段转移里，所有满足：
  61| 
  62| `y < a_i <= x`
  63| 
  64| 的同学都会被这一班车接走，并且他们都要等到时刻 `x` 才“完成这次运输”。
  65| 
  66| 于是这批同学对答案的贡献就是：
  67| 
  68| `count * x - sum`
  69| 
  70| 其中：
  71| 
  72| - `count` 是区间 `(y, x]` 内的同学数
  73| - `sum` 是这些同学的 `a_i` 之和
  74| 
  75| 整理一下就得到：
  76| 
  77| `dp[x] = x * cnt[x] - sum[x] + min(dp[y] + sum[y] - x * cnt[y])`
  78| 
  79| 这里：
  80| 
  81| - `cnt[x]` 表示 `a_i <= x` 的人数
  82| - `sum[x]` 表示这些 `a_i` 的总和
  83| 
  84| 对固定的 `y` 来看，转移到 `x` 的部分是一条关于 `x` 的直线：
  85| 
  86| `(dp[y] + sum[y]) - cnt[y] * x`
  87| 
  88| 所以我们要做的就是：
  89| 
  90| 1. 按时间 `x` 从小到大枚举
  91| 2. 当 `y = x-m` 可用时，把对应直线加入凸包
  92| 3. 用单调队列维护下凸壳，查询当前最优直线
  93| 
  94| 这就是标准的斜率优化 DP。
  95| 
  96| 
  97| #### DP 转移方程
  98| 
  99| 核心状态：
 100| 
 101| `dp[x]` 为回程时刻 x 时的最小等待和
 102| 
 103| 核心转移：
 104| 
 105| `dp[x]=x*cnt[x]-sum[x]+min(dp[y]+sum[y]-x*cnt[y])`
 106| 
 107| 答案收束：
 108| 
 109| 覆盖所有同学后的最小 `dp[x]`

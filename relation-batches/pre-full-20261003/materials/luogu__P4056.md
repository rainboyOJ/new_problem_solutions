   9| ## 题目解析（原文摘录）
  10| 
  11| ### 题意
  12| 
  13| 我们从 `(1,1)` 出发，要走到 `(M,M)`。
  14| 
  15| 每次只能去右下方向的岛，也就是下一个岛必须满足：
  16| 
  17| - `x` 不减
  18| - `y` 不减
  19| 
  20| 走到一个岛能拿到这座岛的水果价值，两个岛之间的划船代价是横纵坐标差平方和。
  21| 
  22| 要求最大化：
  23| 
  24| `拿到的水果总价值 - 全部划船代价`
  25| 
  26| ### 思路
  27| 
  28| 先看最直接的暴力 DP：
  29| 
  30| @include-code(./brute.cpp, cpp)
  31| 
  32| 设 `dp(i)` 表示到达岛 `i` 的最大收益。
  33| 
  34| 如果 `j` 能转移到 `i`，那么：
  35| 
  36| `dp(i) = max(dp(j) + v_i - (x_i-x_j)^2 - (y_i-y_j)^2)`
  37| 
  38| 把平方项展开：
  39| 
  40| `dp(i) = v_i - x_i^2 - y_i^2 + max(dp(j) - x_j^2 - y_j^2 + 2x_ix_j + 2y_iy_j)`
  41| 
  42| 问题在于前驱要同时满足：
  43| 
  44| - `x_j <= x_i`
  45| - `y_j <= y_i`
  46| 
  47| 这是一个二维偏序约束。
  48| 
  49| 这时利用 `M <= 1000` 这个条件，可以按列 `x` 从小到大扫描。
  50| 
  51| 对于历史上的某个点 `(x_j, y_j)`，如果把 `y_j` 固定住，那么它对未来列 `x` 的贡献可以写成一条直线：
  52| 
  53| `f_j(x) = 2x_j * x + (dp(j) - x_j^2 - y_j^2)`
  54| 
  55| 所以我们对每一行 `y` 维护一个凸壳，表示“最后一个点落在这一行”的所有历史状态。
  56| 
  57| 扫描到当前列 `x` 时：
  58| 
  59| 1. 先对每一行查询出在当前 `x` 处的最优值 `g[y]`
  60| 2. 再在当前列内部按 `y` 从小到大处理
  61| 
  62| 当前列内部还要保证前驱的 `y_j <= y_i`，所以再维护两个凸壳：
  63| 
  64| - `prefix_hull`：收集所有 `y' <= y` 的历史行结果
  65| - `same_column_hull`：收集当前列里更上方点的结果
  66| 
  67| 这样就把二维偏序 DP 拆成了两次单调凸包优化。
  68| 
  69| 
  70| #### DP 转移方程
  71| 
  72| 核心状态：
  73| 
  74| `dp(i)` 为到达岛 i 的最大收益
  75| 
  76| 核心转移：
  77| 
  78| `dp(i)=v_i-x_i^2-y_i^2+max(dp(j)-x_j^2-y_j^2+2x_ix_j+2y_iy_j)`
  79| 
  80| 答案收束：
  81| 
  82| `dp` 到终点最大值
